# 考研数学二 · 从 0 到 130 分完整教程

> 适用对象：学过高数、线代但基本忘光的同学。目标：数学二 **130+**。
> 教程结构：**预备知识 → 高等数学 5 章 → 线性代数 6 章 → 2024/2025 真题逐题精讲 → 公式速查与易错清单**。
> 每章按「考什么 → 概念（由浅入深）→ 方法与题型 → 真题实战 → 练习（附答案）→ 本章检查清单」组织。

## 二、130 分意味着什么

130 分 = 最多丢 20 分。一个现实可行的分配：

| 题型 | 满分 | 目标 | 说明 |
|---|---|---|---|
| 选择题 | 50 | ≥ 45 | 最多错 1 题。靠「概念清晰 + 反例库 + 特殊值法」 |
| 填空题 | 30 | ≥ 25 | 最多错 1 题。靠「计算准确」 |
| 解答题 | 70 | ≥ 60 | 17–20 题（计算）必须拿满；21 题（证明）至少拿一半；22 题（线代）拿满 |

**结论：130 分不需要做出所有难题，需要的是：常规题零失误。** 本教程所有内容都围绕「常规题型的标准解法」展开，并在每章末给出「易错点」。

## 五、怎么用这份教程（非常重要）

1. **先看概念，再看例题，最后自己盖住答案重做一遍。** 看懂 ≠ 会做。
2. **每个例题都要动笔算。** 考研数学 80% 的丢分是计算错误。
3. **「真题实战」部分是本教程的核心**：每章都把 2024/2025 真题中属于这一章的题拿出来讲，你会直观看到「这个知识点在真题里长什么样」。
4. **建立错题本**：记录「错在哪一步 + 正确思路 + 对应章节」。
5. **反例库**（见第 14 章）是选择题的武器：很多选择题就是判断一个命题对不对，脑中有反例就能秒杀。
6. 读完每章，按章末「检查清单」自测，全部能打钩再往下走。
