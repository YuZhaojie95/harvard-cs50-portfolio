## 一、高等数学公式速查

### 1. 等价无穷小（$x\to0$）
$$\sin x,\tan x,\arcsin x,\arctan x,\ln(1+x),e^x-1\sim x;\quad 1-\cos x\sim\tfrac{x^2}2;\quad (1+x)^a-1\sim ax;\quad a^x-1\sim x\ln a$$
$$x-\sin x\sim\tfrac{x^3}6,\ \tan x-x\sim\tfrac{x^3}3,\ \tan x-\sin x\sim\tfrac{x^3}2,\ \arcsin x-x\sim\tfrac{x^3}6,\ x-\arctan x\sim\tfrac{x^3}3,\ x-\ln(1+x)\sim\tfrac{x^2}2,\ e^x-1-x\sim\tfrac{x^2}2$$

### 2. 泰勒展开（$x\to0$）
$$e^x=\sum\frac{x^n}{n!},\quad \sin x=x-\frac{x^3}6+\frac{x^5}{120},\quad \cos x=1-\frac{x^2}2+\frac{x^4}{24},\quad \ln(1+x)=x-\frac{x^2}2+\frac{x^3}3$$
$$(1+x)^a=1+ax+\frac{a(a-1)}2x^2,\quad \tan x=x+\frac{x^3}3,\quad \arcsin x=x+\frac{x^3}6,\quad \arctan x=x-\frac{x^3}3,\quad \frac1{1-x}=\sum x^n$$

### 3. 极限
- $1^\infty$：$\lim u^v=e^{\lim v(u-1)}$
- $\lim\frac1n\sum f(\frac kn)=\int_0^1f(x)dx$
- $x\to+\infty$：$\ln^\alpha x\ll x^\beta\ll a^x$

### 4. 导数
- 参数方程：$\frac{dy}{dx}=\frac{y_t}{x_t}$，$\frac{d^2y}{dx^2}=\frac{(dy/dx)_t}{x_t}$
- 反函数二阶：$\frac{d^2x}{dy^2}=-\frac{y''}{(y')^3}$
- 变限积分：$\left(\int_{\psi(x)}^{\varphi(x)}f\right)'=f(\varphi)\varphi'-f(\psi)\psi'$
- $(\sin x)^{(n)}=\sin(x+\frac{n\pi}2)$；$\left(\frac1{x+a}\right)^{(n)}=\frac{(-1)^nn!}{(x+a)^{n+1}}$；$f^{(n)}(0)=n!\,a_n$
- 曲率 $K=\frac{|y''|}{(1+y'^2)^{3/2}}$；参数 $K=\frac{|x'y''-x''y'|}{(x'^2+y'^2)^{3/2}}$

### 5. 中值定理辅助函数
| 结论 | $F(x)$ |
|---|---|
| $f'+kf=0$ | $e^{kx}f$ |
| $f'+g'f=0$ | $e^{g}f$ |
| $\xi f'+kf=0$ | $x^kf$ |
| $\xi f'-f=0$ | $f/x$ |

### 6. 积分
- $\int\sec x=\ln|\sec x+\tan x|$；$\int\frac{dx}{x^2-a^2}=\frac1{2a}\ln\left|\frac{x-a}{x+a}\right|$；$\int\frac{dx}{\sqrt{x^2\pm a^2}}=\ln|x+\sqrt{x^2\pm a^2}|$
- 华里士：$\int_0^{\pi/2}\sin^n=\frac{(n-1)!!}{n!!}\cdot\left(\frac\pi2\text{ 若 }n\text{ 偶}\right)$
- 区间再现：$\int_a^bf(x)=\int_a^bf(a+b-x)$；$\int_0^\pi xf(\sin x)=\frac\pi2\int_0^\pi f(\sin x)$
- p-积分：$\int_1^\infty\frac1{x^p}$ 收敛 ⇔ $p>1$；$\int_0^1\frac1{x^p}$ 收敛 ⇔ $p<1$
- $\int_0^\infty x^ne^{-x}=n!$，$\int_{-\infty}^\infty e^{-x^2}=\sqrt\pi$

### 7. 定积分应用
| 量 | 公式 |
|---|---|
| 极坐标面积 | $\frac12\int r^2d\theta$ |
| 绕 $x$ 轴体积 | $\pi\int f^2dx$ |
| 绕 $y$ 轴体积 | $2\pi\int x\lvert f\rvert dx$ |
| 弧长 | $\int\sqrt{1+y'^2}dx$ / $\int\sqrt{x'^2+y'^2}dt$ / $\int\sqrt{r^2+r'^2}d\theta$ |
| 侧面积 | $2\pi\int f\sqrt{1+f'^2}dx$ |
| 平均值 | $\frac1{b-a}\int_a^bf$ |
| 形心 | $\bar x=\frac{\iint x}{\iint1}$ |

### 8. 多元
- 可微判定：$\lim\frac{\Delta z-f_x\Delta x-f_y\Delta y}{\rho}=0$
- 隐函数：$z_x=-\frac{F_x}{F_z}$
- 极值：$AC-B^2>0$ 有极值（$A<0$ 大，$A>0$ 小）；$<0$ 无
- 极坐标：$dxdy=r\,dr\,d\theta$；$x^2+y^2=2ax\Leftrightarrow r=2a\cos\theta$

### 9. 微分方程
- 一阶线性：$y=e^{-\int P}\left[\int Qe^{\int P}dx+C\right]$
- 特征根：不等实根 / 重根 $(C_1+C_2x)e^{rx}$ / 复根 $e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$
- 特解：$P_m e^{\lambda x}\to x^kQ_me^{\lambda x}$（$k$ = $\lambda$ 作为特征根的重数）
- 欧拉：$x=e^t$，$xy'=Dy$，$x^2y''=D(D-1)y$

## 二、线性代数公式速查

| 主题 | 公式 |
|---|---|
| 行列式 | $\lvert kA\rvert=k^n\lvert A\rvert$，$\lvert AB\rvert=\lvert A\rvert\lvert B\rvert$，$\lvert A^*\rvert=\lvert A\rvert^{n-1}$，$\lvert A\rvert=\prod\lambda_i$ |
| 伴随 | $AA^*=\lvert A\rvert E$，$A^*=\lvert A\rvert A^{-1}$，$(A^*)^*=\lvert A\rvert^{n-2}A$ |

| 特征值 | $\sum\lambda=\operatorname{tr}A$；$f(A)\to f(\lambda)$；$A^{-1}\to\frac1\lambda$；$A^*\to\frac{\lvert A\rvert}\lambda$ |

| 施密特 | $\beta_2=\alpha_2-\frac{(\alpha_2,\beta_1)}{(\beta_1,\beta_1)}\beta_1$ |
| 正定 | 特征值全正 ⇔ 顺序主子式全正 |
| 实对称合同 | 正负惯性指数相同 |

## 三、反例库（选择题利器）

### 极限与连续
| 命题（均为**假**） | 反例 |
|---|---|
| $\lim(f+g)$ 存在 ⇒ $\lim f,\lim g$ 存在 | $f=(-1)^n,g=(-1)^{n+1}$ |
| $\lim\lvert a_n\rvert$ 存在 ⇒ $\lim a_n$ 存在 | $a_n=(-1)^n$（但 $\lvert a_n\rvert\to0\Leftrightarrow a_n\to0$ 为真） |
| 有界 ⇒ 收敛 | $(-1)^n$ |
| $f$ 在 $x_0$ 有定义 ⇒ 极限存在 | $\sin\frac1x$ 补定义 |
| $\lvert f\rvert$ 连续 ⇒ $f$ 连续 | $f=1\ (x\ge0),\ -1\ (x<0)$ |
| $g(a_n)$ 收敛 ⇒ $a_n$ 收敛 | $g=u+\frac1u$，$a_n=2,\frac12,2,\dots$【2024-4】 |

### 导数
| 命题（均为**假**） | 反例 |
|---|---|
| 连续 ⇒ 可导 | $\lvert x\rvert$ |
| $\lim\frac{f(2h)-f(h)}h$ 存在 ⇒ 可导 | $f=1\ (x\ne0),\ f(0)=0$ |
| $\lim\frac{f(h^2)-f(0)}{h^2}$ 存在 ⇒ 可导 | $\lvert x\rvert$ |
| $f'(x_0)>0$ ⇒ 某邻域内单增 | $x+2x^2\sin\frac1x$（补 $f(0)=0$） |
| $f'(x_0)=0$ ⇒ 极值 | $x^3$ |
| $f''(x_0)=0$ ⇒ 拐点 | $x^4$ |
| 导函数连续 | $x^2\sin\frac1x$（补 0）：可导但导数在 0 不连续 |

### 积分
| 命题（均为**假**） | 反例 |
|---|---|
| $\int f^2$ 收敛 ⇒ $\int f$ 收敛 | $\frac1{1+x}$【2024-7】 |
| $\int_0^\infty f$ 收敛 ⇒ $x^pf\to$ 有限（某 $p>1$） | $\frac1{x\ln^2x}$【2024-7】 |
| $\int_0^\infty f$ 收敛 ⇒ $f\to0$ | 在整数点附近有越来越窄的「尖峰」的函数 |
| 可积 ⇒ 有原函数 | 符号函数 $\operatorname{sgn}x$ |
| $\int_{-1}^1\frac{dx}{x^2}=-2$ | 错！$x=0$ 是瑕点，积分发散 |

### 多元
| 命题（均为**假**） | 反例 |
|---|---|
| 偏导存在 ⇒ 连续 | $\frac{xy}{x^2+y^2}$ |
| 连续 + 偏导存在 ⇒ 可微 | $\sqrt{\lvert xy\rvert}$ |
| 可微 ⇒ 偏导连续 | $(x^2+y^2)\sin\frac1{x^2+y^2}$；【2024-5】 |

### 线代
| 命题（均为**假**） | 反例 |
|---|---|
| $AB=O$ ⇒ $A=O$ 或 $B=O$ | $\begin{pmatrix}1&0\\0&0\end{pmatrix}\begin{pmatrix}0&0\\0&1\end{pmatrix}$ |
| $A^2=O$ ⇒ $A=O$ | $\begin{pmatrix}0&1\\0&0\end{pmatrix}$ |
| 特征值相同 ⇒ 相似 | $\begin{pmatrix}1&1\\0&1\end{pmatrix}$ 与 $E$ |
| $B$ 可对角化且 $AB=BA$ ⇒ $A$ 特征值互异 | $A=B=E$【2024-10】 |
| 等价 ⇒ 相似 | $\begin{pmatrix}1&0\\0&0\end{pmatrix}$ 与 $\begin{pmatrix}0&1\\0&0\end{pmatrix}$ |
| $r(A)=r(B)$ ⇒ $Ax=0,Bx=0$ 同解 | $A=(1,0)$，$B=(0,1)$ |

## 四、易错清单（每一条都曾让无数人丢分）

### 计算类
1. 等价无穷小在**加减**中乱替换。
2. 洛必达后极限不存在，就断言原极限不存在。
3. 参数方程二阶导写成 $\frac{y''(t)}{x''(t)}$。
4. 变限积分中被积函数含 $x$，没有先分离就求导。
5. 定积分换元**没换上下限**。
6. 极坐标**漏乘 $r$**。
7. 反常积分没有检查**区间内部的瑕点**。
8. 分部积分后正负号出错（尤其 $\int e^{-x}$ 类）。
9. 不定积分**漏写 $+C$**；$\int\frac1x$ 漏写绝对值。
10. 非齐次方程特解形式中，$\cos$ 型漏设 $\sin$ 项，或 $k$ 取错。

### 概念类
11. 分段点处的导数用求导公式而不是定义。
12. 求「拐点」写成了 $x_0$，应写 $(x_0,f(x_0))$；求「极值点」写成了极值。
13. $x\to\infty$ 求渐近线时没有分 $\pm\infty$。
14. 单调有界准则：没有先证明极限存在就解方程。
15. 由 $f(A)=O$ 得到的是特征值的**可能取值**，要结合秩/迹确定。
16. 正交对角化时 $Q$ 的列顺序与 $\Lambda$ 不对应；重特征值的特征向量忘记正交化；忘记单位化。
17. 二次型矩阵的交叉项系数忘记除以 2。
18. 配方法的变换不可逆（如 $(x_1+x_2)^2+(x_2-x_3)^2+(x_3+x_1)^2$）。
19. 行变换时用含参数的式子做除数。
20. $|kA|$ 写成 $k|A|$。

## 五、考场策略

1. **时间分配**：选择 + 填空 ≤ 70 分钟；解答题 ≈ 100 分钟；留 10 分钟检查。
2. **做题顺序**：选择填空按顺序，卡住超过 4 分钟先跳过；解答题先做 17（积分计算）、19/20（多元、二重积分）、22（线代），最后做证明题。
3. **选择题技巧**：特殊值代入、排除法、反例法、「阶数法」判断极值拐点、图像法。
4. **解答题书写**：写清关键步骤（求导结果、定限、结论），**即使算不出最后结果，过程分也要拿到**。证明题至少写出「用什么定理、在什么区间上、构造什么函数」。
5. **检查**：优先检查计算题的代入和符号；填空题答案是否化简、是否漏写 $+C$ 或定义域。
