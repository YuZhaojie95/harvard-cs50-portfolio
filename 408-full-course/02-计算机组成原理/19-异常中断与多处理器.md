## 🚪 课前引入

你正在家里写作业（CPU 执行程序）：
- **门铃响了**（快递员）→ 这件事**跟作业无关**，是**外面**发生的 → 你记下写到第几题，去开门，回来接着写。这是**中断（外中断）**
- **写到一半发现笔没水了** → 这是**做作业本身**引起的问题 → 去换一支笔，然后**重新写刚才那个字**。这是**故障（Fault）**
- **作业本上写着“做完第 5 题请找妈妈签字”** → 这是**事先安排好的**，你**故意**去找妈妈 → 签完字后**接着做第 6 题**。这是**自陷（Trap）**，比如系统调用
- **作业本被撕烂了** → 没法继续了 → **终止（Abort）**

这些事件的共同点：**打断当前程序的正常执行，转去处理一件事**。

## 一、基本概念（⭐⭐）

### 📐 定义
- **异常（Exception）**：由 **CPU 内部**、在**执行指令过程中**产生的意外事件，也叫**内中断**
  - 例：整数除以 0、溢出、非法操作码、**缺页**、访问越界、**陷阱指令（系统调用）**、断点
- **中断（Interrupt）**：来自 **CPU 外部**、与当前执行的指令**无关**的事件，也叫**外中断**
  - 例：**I/O 设备**完成（键盘按下、磁盘读完、**DMA 传送结束**）、**时钟中断**、打印机缺纸

🧒 一句话：**异常是“自己”的问题（和当前指令有关），中断是“别人”找你（和当前指令无关）**。

### 📐 检测时机（⭐⭐）
- **异常**：在**当前指令执行过程中**检测（如除法时发现除数为 0，取指时发现缺页）
- **中断**：在**每条指令执行结束后**（指令周期的最后）检测是否有中断请求

📝 **真题（2021 年第 21 题）**：异常事件在当前指令执行过程中进行检测，中断请求则在当前指令执行后进行检测。下列事件中，相应处理程序执行后，**必须回到当前指令重新执行**的是：A. 系统调用　B. 页缺失　C. DMA 传送结束　D. 打印机缺纸
→ **B**（页缺失是**故障**，处理完把页调入后，要**重新执行**引起缺页的指令；系统调用是自陷，返回到下一条；C、D 是外中断，在指令结束后才响应，返回下一条）

📝 **真题（2025 年第 22 题）**：下列选项中，会触发外部中断请求的事件是：A. DMA 传送结束　B. 总线事务结束　C. 页故障的处理结束　D. 执行断点指令
→ **A**（DMA 控制器在传送结束时向 CPU 发**中断请求**；D 是自陷，属于内中断；C 页故障处理是 OS 程序，结束后返回，不产生外部中断；B 总线事务结束不会发中断）

## 二、异常的分类（⭐⭐⭐）

### 📐 按异常的原因和返回方式分三类

| 类型 | 含义 | 例子 | 处理后返回到 |
|---|---|---|---|
| **故障（Fault）** | 执行指令时发生的、**可能被恢复**的错误 | **缺页**、非法地址、**除数为 0**、溢出（部分系统）、**段不存在**、保护违例 | **引起故障的那条指令**（重新执行）；若无法恢复则终止程序 |
| **自陷（Trap，陷阱）** | **事先安排好的**“异常”，程序**有意**引发 | **系统调用（trap/int/syscall 指令）**、**断点指令**（调试用 int 3）、单步跟踪 | **陷阱指令的下一条指令** |
| **终止（Abort）** | **硬件故障**等**不可恢复**的致命错误 | 控制器出错、存储器校验错、总线错误 | **不返回**，终止程序（甚至停机） |

### 📐 故障与自陷的区别
- **故障**：发生的时候，那条指令**没有执行完**（或者没执行成功），修复后要**重新执行**这条指令
  - 例：`mov eax, [addr]` 读的页不在主存 → 缺页故障 → OS 把页调入 → **重新执行这条 mov**
- **自陷**：陷阱指令**已经执行完**（它的功能就是引发异常），处理完继续执行**下一条**
  - 例：`int 0x80` 发起系统调用 → OS 完成服务 → 返回 `int 0x80` 的**下一条指令**

⚠️ **除数为 0**：一般归为**故障**。但通常操作系统无法“修复”除数，所以处理程序往往直接**终止**该进程。

### 📐 中断的分类
- **可屏蔽中断（INTR）**：可以通过**关中断**或**中断屏蔽**暂时不响应，如一般 I/O 设备中断
- **不可屏蔽中断（NMI）**：**必须立即响应**，不能屏蔽，如**掉电**、严重硬件故障

### 📐 总结图
```
            ┌── 故障 Fault（缺页、除 0、非法地址）→ 返回本条指令
     异常 ──┼── 自陷 Trap（系统调用、断点）       → 返回下一条指令
（内中断）   └── 终止 Abort（硬件故障）            → 不返回
            
     中断 ──┬── 可屏蔽中断 INTR（I/O 设备）        → 返回下一条指令
（外中断）   └── 不可屏蔽中断 NMI（掉电）
```

## 三、异常和中断的响应过程（⭐⭐⭐）

CPU 从检测到异常或中断事件，到调出相应处理程序的过程，称为**响应过程**。

### 📐 中断响应的条件（外中断）
1. **有中断请求**（且该中断源**未被屏蔽**）
2. **CPU 处于开中断状态**（中断允许触发器 IF = 1）
3. **一条指令执行完毕**（且没有更紧迫的任务，如 DMA 请求）

📝 **真题（2021 年第 22 题）**：下列关于多重中断系统中 CPU 响应中断的叙述中，**错误**的是：
A. 仅在用户态（执行用户程序）下，CPU 才能检测和响应中断
B. CPU 只有在检测到中断请求信号后，才会进入中断响应周期
C. 进入中断响应周期时，CPU 一定处于中断允许（开中断）状态
D. 若 CPU 检测到中断请求信号，则一定存在未被屏蔽的中断源请求信号
→ **A**（CPU 在**内核态**执行中断处理程序时，也可以检测和响应更高级别的中断——这就是**多重中断**）
- D 是对的：屏蔽的中断源的请求根本不会送到 CPU（被屏蔽电路挡掉了）

### 📐 响应过程的三步（由硬件完成）（⭐⭐⭐）
1. **关中断**：防止在保存现场的过程中又被新的中断打断，导致现场保存不完整
2. **保存断点和程序状态**：
   - **断点**：返回地址。对中断和自陷，是下一条指令的地址（PC 当前值）；对故障，是**发生故障的指令地址**
   - **程序状态字 PSW**：标志位、中断允许位、用户态/内核态等
   - 保存到**栈**中或特殊寄存器中（x86 保存到内核栈）
3. **识别异常/中断源，转到相应的处理程序**：
   - **软件识别**（查询）：CPU 设置一个**异常状态寄存器**记录原因，统一进入一个处理程序，由程序查询是哪种原因
   - **硬件识别**（**向量中断**）：每种异常/中断有一个**类型号（中断号）**，据此查**中断向量表**得到处理程序入口地址

同时，CPU 从**用户态切换到内核态**（处理程序是操作系统的代码）。

这些由硬件自动完成的操作叫**中断隐指令**（指令系统中并没有这条指令）。

### 📐 中断向量（⭐⭐）
- **中断向量**：中断服务程序的**入口地址**
- **中断向量表**：存放所有中断向量的表，位于主存中（其起始地址存放在**中断向量表基址寄存器**中，如 x86 的 IDTR）
- **向量地址**：中断向量在中断向量表中的**地址**
- 流程：中断类型号 n → 向量地址 = 表基址 + n × 表项大小 → 读出中断向量 → 送 PC
- 🧒 像电话簿：中断类型号是“姓名”，中断向量表是“电话簿”，向量地址是“这个名字在电话簿的第几行”，中断向量是“这一行写的电话号码”

（2025 年第 23 题：进程上下文切换时，**内核中断向量表基址寄存器不需要更新**，因为所有进程共用同一个内核、同一张中断向量表。）

### 📐 处理程序做什么（软件）
1. **保存现场**：保存通用寄存器等（硬件保存的只是 PC 和 PSW）
2. （多重中断时）设置新的屏蔽字，**开中断**
3. **执行具体的服务**
4. （多重中断时）关中断
5. **恢复现场**、恢复屏蔽字
6. **开中断**
7. **中断返回**（x86 的 iret 指令）：从栈中恢复 PSW 和 PC，回到用户态

📝 **真题（2023 年第 21 题）**：下列关于硬件和异常/中断关系的叙述中，**错误**的是：
A. CPU 在执行一条指令过程中检测异常事件　B. CPU 在执行完一条指令时检测中断请求信号　C. 开中断时 CPU 检测到中断请求后就进行中断响应　D. 外部设备通过中断控制器向 CPU 发中断结束信号
→ **D**（中断结束命令是由 **CPU（中断服务程序）发给中断控制器**的，告诉中断控制器“这个中断处理完了”，不是外设发给 CPU）

### 📝 真题（2025 年第 44 题第 2 问）
> 假设 idiv 指令（32 位带符号整数除法，R1 ← d[i] / x）执行过程中会检测并触发除法异常，则执行 idiv 指令时，哪些情况下会发生除法异常（要求给出此时 d 和 x 的十六进制表示机器数）？发生除法异常时，在异常响应过程中 CPU 需要完成哪些操作？

- **情况 1：除数为 0**：x = **0000 0000H**（d 为任意值）
- **情况 2：商溢出**：d = **8000 0000H**（−2³¹），x = **FFFF FFFFH**（−1）。商 = 2³¹，超出 32 位补码最大值 2³¹ − 1
- **响应过程**（硬件）：**关中断**；**保存断点**（idiv 指令的地址，因为是故障类）和**程序状态字**；**识别异常类型**（除法错异常的类型号），查中断向量表得到异常处理程序入口，送 PC，并切换到内核态

（详细的除法器分析见第 4 课。）

## 四、多处理器的基本概念（⭐⭐）

### 📐 Flynn 分类法（按指令流和数据流）
| 类型 | 含义 | 例子 |
|---|---|---|
| **SISD** | 单指令流单数据流 | 传统**单处理器**（可以有流水线） |
| **SIMD** | 单指令流多数据流：**一条指令同时处理多个数据** | **向量处理器**、**GPU**、x86 的 **SSE/AVX 指令** |
| **MISD** | 多指令流单数据流 | 实际上**不存在**（或仅理论上） |
| **MIMD** | 多指令流多数据流 | **多处理器、多核处理器**、多计算机（集群） |

🧒 SIMD：老师喊一声“全体向右转”（一条指令），全班同学（多个数据）同时转身。MIMD：每个同学做自己的事。

### 📐 MIMD 的两种结构
- **多处理器系统（共享存储）**：多个处理器**共享单一的物理地址空间**，通过**共享内存**通信（用 load/store 访问共享变量）
  - **UMA**（一致性存储访问）：每个处理器访问任何内存单元的时间**相同**，如 **SMP**（对称多处理器）
  - **NUMA**（非一致性存储访问）：访问本地内存快，访问其他处理器的内存慢
- **多计算机系统（消息传递）**：每台计算机有自己的**私有**地址空间，通过**消息传递**通信（如集群）

### 📐 硬件多线程
在**一个处理器核**中，为多个线程各配一套寄存器（PC、通用寄存器），让它们**共享**执行部件，**线程切换几乎无开销**。
| 类型 | 做法 |
|---|---|
| **细粒度多线程** | **每个时钟周期**切换一次线程，多个线程轮流交叉执行 |
| **粗粒度多线程** | 只在遇到**长时间停顿**（如 Cache 缺失）时才切换线程 |
| **同时多线程（SMT）** | 在**同一个时钟周期**中，发射**多个线程的指令**（结合超标量），如 Intel 的**超线程**（Hyper-Threading） |

⚠️ 硬件多线程可以用于**单核**处理器！（一个核内部就能支持多个线程）

### 📐 多核处理器
一个芯片上集成**多个处理器核**，每个核有自己的 L1（通常还有 L2）Cache，**共享 L3 Cache 和主存**。属于 **MIMD**、共享存储、通常是 **SMP**。

📝 **真题（2022 年第 22 题）**：下列关于并行处理技术的叙述中，**不正确**的是：
A. 多核处理器属于 MIMD 结构　B. 向量处理器属于 SIMD 结构　C. 硬件多线程技术只可用于多核处理器　D. SMP 中所有处理器共享单一物理地址空间
→ **C**（硬件多线程在**单核**上也可以用）

## ⚠️ 易错点

1. **异常 = 内中断**（执行指令过程中检测）；**中断 = 外中断**（指令结束后检测）
2. **故障**（缺页、除 0）→ **返回本条指令**重新执行；**自陷**（系统调用、断点）→ **返回下一条**；**终止** → 不返回
3. **DMA 传送结束、I/O 完成、时钟**是外中断；**断点指令、系统调用**是自陷（内中断）
4. 响应过程（硬件，中断隐指令）：**关中断 → 保存断点和 PSW → 识别中断源、送入口地址**
5. **保存通用寄存器（保存现场）是中断服务程序（软件）做的**
6. 中断向量 = 入口地址；向量地址 = 入口地址在向量表中的位置
7. 多重中断时，CPU 在内核态也能响应中断
8. 中断结束信号是 **CPU → 中断控制器**
9. **硬件多线程可以用于单核**；SMT 同一周期发射多个线程的指令
10. **MISD 实际不存在**；GPU、向量机是 SIMD；多核是 MIMD

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 异常 vs 中断 | 内部、与指令有关、指令中检测 vs 外部、与指令无关、指令后检测 |
| 故障/自陷/终止 | 返回本条 / 返回下一条 / 不返回 |
| 响应条件 | 有未屏蔽请求 + 开中断 + 指令结束 |
| 响应过程 | 关中断、保存断点和 PSW、识别源并转处理程序（切到内核态） |
| 向量中断 | 类型号 → 向量表 → 入口地址 |
| Flynn | SISD、SIMD（向量/GPU）、MISD（无）、MIMD（多核） |
| 硬件多线程 | 细粒度、粗粒度、SMT（超线程） |

2. 中断响应过程中，为什么要先“关中断”？
3. 中断服务程序中“保存现场”和中断隐指令中“保存断点”有何不同？
4. 某系统的中断向量表从主存地址 0 开始，每个表项 4 字节，某设备的中断类型号为 0x21，它的向量地址是多少？
5. 判断：(a) 单核处理器不能实现硬件多线程；(b) SIMD 适合处理图像中大量像素的相同运算；(c) NUMA 系统中各处理器访问任一内存单元的时间相同。

<summary>📖 答案</summary>

1. (a) **故障**，返回本条指令；(b) **自陷**，返回下一条；(c) **外中断**（可屏蔽），返回下一条；(d) **终止**，不返回；(e) **自陷**，返回下一条；(f) **故障**，通常终止进程；(g) **外中断**，返回下一条
