> 2. **熟练掌握 IEEE 754 单精度、双精度格式**：十进制 ↔ 机器数的相互转换
> 3. 掌握 IEEE 754 的**特殊值**（0、∞、NaN、非规格化数）和**表示范围**

## 🚪 课前引入：科学计数法

写一个很大或很小的数，我们用**科学计数法**：
- 光速 300000000 = **3 × 10⁸**
- 电子质量 0.000…00091（小数点后 30 个 0）= **9.1 × 10⁻³¹**

定点数的问题是：32 位整数最大只能到约 21 亿，也不能表示小数。
**浮点数**就是**二进制的科学计数法**：N = **尾数 × 2^阶码**。小数点的位置随阶码“浮动”，所以叫浮点数。

---

## 一、浮点数的一般表示

### 📐 格式
$$N = (-1)^S \times M \times R^E$$
- **S**：数符（0 正 1 负）
- **M**：尾数（一般是定点小数），决定**精度**
- **E**：阶码（定点整数），决定**范围**（小数点位置）
- **R**：基数，通常为 2（隐含，不存储）

```
┌──────┬──────────────┬──────────────────────┐
│ 数符 │   阶码（阶符+阶码数值）│      尾数数值          │
└──────┴──────────────┴──────────────────────┘
```

🧒 **阶码位数越多，表示范围越大；尾数位数越多，精度越高。** 总位数固定时，两者此消彼长。

### 📐 规格化
同一个数有多种浮点表示：0.01 × 2³ = 0.1 × 2² = 1.0 × 2¹……为了**充分利用尾数的位数、提高精度**，要求尾数的**最高数值位是有效值**，这叫**规格化**。
- **左规**：尾数最高数值位不是有效值时，尾数左移一位，阶码减 1（可能要左规多次）
- **右规**：尾数运算结果溢出（绝对值 ≥ 1）时，尾数右移一位，阶码加 1（最多一次）

**规格化尾数的形式**（基数为 2）：
- 原码表示：**0.1xxxx**（正）或 **1.1xxxx**（负）——最高数值位为 1
- 补码表示：**0.1xxxx**（正）或 **1.0xxxx**（负）——**符号位与最高数值位不同**
  - ⚠️ 补码中 −0.5 = 1.100…0 **不是**规格化数，−1 = 1.000…0 **是**规格化数

## 二、IEEE 754 标准（⭐⭐⭐）

### 📐 格式
| 类型 | 数符 S | 阶码 E | 尾数 M | 总位数 | 偏置值 |
|---|---|---|---|---|---|
| **单精度 float** | 1 | **8** | **23** | 32 | **127** |
| 双精度 double | 1 | 11 | 52 | 64 | 1023 |

```
单精度：
 31  30        23  22                                0
┌───┬────────────┬──────────────────────────────────┐
│ S │   E（8 位）│         M（23 位）                │
└───┴────────────┴──────────────────────────────────┘
```

### 📐 三个要点（⭐⭐⭐）
1. **尾数用原码**，符号 S 单独放在最高位
2. **阶码用移码，偏置值为 127**（单精度）：E（存储的阶码）= e（真实指数）+ 127
   - ⚠️ 不是普通移码的偏置 128！
3. **规格化尾数的最高位总是 1，这个 1 不存储（隐藏位）**，23 位 M 存的是**小数点后面**的部分，实际尾数是 **1.M**，有效位数 24 位

### 📐 规格化数的真值公式
$$\text{单精度：} \quad x = (-1)^S \times 1.M \times 2^{E - 127}$$
$$\text{双精度：} \quad x = (-1)^S \times 1.M \times 2^{E - 1023}$$

## 三、十进制 → IEEE 754（⭐⭐⭐ 四步法）

**步骤**：
1. **转二进制**：整数部分除 2 取余，小数部分乘 2 取整
2. **规格化**：写成 **1.xxx × 2ᵉ** 的形式
3. **求各字段**：S = 符号；**E = e + 127** 写成 8 位二进制；**M = 小数点后面的部分**，右边补 0 到 23 位
4. **拼接**：S E M，每 4 位一组写成十六进制

### ✏️ 例 1（真题 2022 年第 14 题）：−0.4375 的 IEEE 754 单精度表示
1. 0.4375 × 2 = 0.875 → 0；0.875 × 2 = 1.75 → 1；0.75 × 2 = 1.5 → 1；0.5 × 2 = 1.0 → 1 → **0.0111**
2. 0.0111 = **1.11 × 2⁻²**
3. S = 1；E = −2 + 127 = 125 = **0111 1101**；M = **1100 0000 … 0**（23 位）
4. 拼接：
```
S  E          M
1  0111 1101  1100 0000 0000 0000 0000 000
→ 1011 1110 1110 0000 0000 0000 0000 0000
→  B    E    E    0    0    0    0    0
```
结果 **BEE0 0000H**，选 A

### ✏️ 例 2：12.5
1. 12 = 1100，0.5 = 0.1 → **1100.1**
2. 1100.1 = **1.1001 × 2³**
3. S = 0；E = 3 + 127 = 130 = **1000 0010**；M = 1001 0…0
4. 0 1000 0010 1001 000… → 0100 0001 0100 1000 0… = **4148 0000H**

### ✏️ 例 3：−8.25
1. 8.25 = 1000.01
2. = 1.00001 × 2³
3. S = 1；E = 130 = 1000 0010；M = 00001 0…0
4. 1 1000 0010 0000 1000 … → 1100 0001 0000 0100 0… = **C104 0000H**

### ✏️ 例 4：100.0
100 = 110 0100 = 1.100100 × 2⁶；E = 133 = 1000 0101；M = 1001 0000…
0 1000 0101 1001 000… → 0100 0010 1100 1000 … = **42C8 0000H**

## 四、IEEE 754 → 十进制（⭐⭐⭐）

**步骤**：
1. 十六进制展开成 32 位二进制
2. 切分：第 1 位 S，接下来 8 位 E，最后 23 位 M
3. 看 E：若 E 不是全 0 也不是全 1，是规格化数：指数 e = E − 127，尾数 1.M
4. 真值 = (−1)^S × 1.M × 2ᵉ

### ✏️ 例 1（真题 2025 年第 13 题）：float x 的机器数为 4730 0000H，x 的值为？
```
4    7    3    0    0    0    0    0
0100 0111 0011 0000 0000 0000 0000 0000
S=0 | E=1000 1110 | M=011 0000 …
```
- E = 1000 1110 = 142 → e = 142 − 127 = **15**
- 尾数 1.011₂ = 1 + 0.25 + 0.125 = **1.375**
- x = **1.375 × 2¹⁵**，选 D

### ✏️ 例 2（真题 2020 年第 13 题，float 部分）：C800 0000H
```
1100 1000 0000 0000 …
S=1 | E=1001 0000 | M=000…
```
- E = 144 → e = 17；尾数 1.0
- x = **−1.0 × 2¹⁷ = −2¹⁷**
（当作 int 是 −7 × 2²⁷，见第 3 课。题目选项中只有 −7 × 2²⁷。）

### ✏️ 例 3（真题 2023 年第 14 题）：float x 的机器数为 8020 0000H，x 的值为？A. −2⁻¹²⁸ B. −1.01 × 2⁻¹²⁷ C. −1.01 × 2⁻¹²⁶ D. 非数（NaN）
```
8    0    2    0    0 0 0 0
1000 0000 0010 0000 0000 …
S=1 | E=0000 0000 | M=010 0000 …
```
- **E 全为 0，M 不为 0 → 非规格化数**！
- 非规格化数：x = (−1)^S × **0.M** × 2⁻¹²⁶
- 0.M = 0.01₂ = 2⁻²
- x = −2⁻² × 2⁻¹²⁶ = **−2⁻¹²⁸**，选 A
⚠️ 这道题的陷阱：如果按规格化数公式算，会得到错误答案 B 或 C

## 五、特殊值（⭐⭐）

| 阶码 E | 尾数 M | 表示 | 真值 |
|---|---|---|---|
| **全 0** | **全 0** | **±0** | ±0（S 决定正负，有 +0 和 −0） |
| **全 0** | **非 0** | **非规格化数** | (−1)^S × **0.M** × 2⁻¹²⁶ |
| 1 ~ 254 | 任意 | **规格化数** | (−1)^S × 1.M × 2^(E−127) |
| **全 1**（255） | **全 0** | **±∞** | 无穷大 |
| **全 1**（255） | **非 0** | **NaN** | 非数（如 0/0、√−1） |

🧒 **非规格化数的作用**：填补 0 和最小规格化数之间的空隙，实现“**逐渐下溢**”（数越来越小时平滑地变成 0，而不是突然变成 0）。
⚠️ 非规格化数的指数是 **−126**（不是 0 − 127 = −127），隐藏位是 **0**（不是 1）。

常用值速查：
| 值 | 单精度机器数 |
|---|---|
| +0 | 0000 0000H |
| −0 | 8000 0000H |
| 1.0 | 3F80 0000H |
| −1.0 | BF80 0000H |
| −2.0 | C000 0000H |
| 0.75 | 3F40 0000H |
| +∞ | 7F80 0000H |
| −∞ | FF80 0000H |

## 六、表示范围（⭐⭐）

### 📐 单精度
| | 表达式 | 近似值 |
|---|---|---|
| **最大正数** | E = 254，M = 全 1：**(2 − 2⁻²³) × 2¹²⁷** | ≈ 3.4 × 10³⁸ |
| **最小规格化正数** | E = 1，M = 全 0：**1.0 × 2⁻¹²⁶** | ≈ 1.18 × 10⁻³⁸ |
| 最小非规格化正数 | E = 0，M = 0…01：**2⁻²³ × 2⁻¹²⁶ = 2⁻¹⁴⁹** | ≈ 1.4 × 10⁻⁴⁵ |

### 📐 双精度
- 最大正数：(2 − 2⁻⁵²) × 2¹⁰²³
- 最小规格化正数：2⁻¹⁰²²

### 📐 溢出
```
    负上溢     可表示的负数     负下溢  0  正下溢    可表示的正数     正上溢
  ←────────|─────────────────|──────|──────|─────────────────|─────────→
       −最大值             −最小值     +最小值              +最大值
```
- **上溢**：绝对值太大，超过最大值 → 溢出，需要处理（IEEE 中变成 ±∞）
- **下溢**：绝对值太小，比最小值还接近 0 → **当作 0 处理**（不算真正的溢出错误）
- ⚠️ **浮点数的溢出是看阶码**：阶码上溢才是溢出

### 📐 能否精确表示（⭐）
一个数能被 IEEE 754 **精确表示**，需要满足：
1. 转成二进制后是**有限位**小数（即能写成 整数 / 2ᵏ）
2. 规格化后尾数的有效位数**不超过 24 位**（单精度）
3. 指数在范围内

📝 **真题（2021 年第 14 题）**：下列数值中，不能用 IEEE 754 浮点格式精确表示的是：A. 1.2 B. 1.25 C. 2.0 D. 2.5
- 1.25 = 1.01₂ ✓；2.0 = 1.0 × 2¹ ✓；2.5 = 10.1₂ ✓
- **1.2** = 1.001100110011…₂（0.2 转二进制无限循环）✗
→ 选 **A**

✏️ 0.1 在 float 中实际存的是 3DCC CCCDH ≈ 0.100000001490116…（**有舍入误差**）。这就是为什么 `0.1 + 0.2 != 0.3`。

## 七、浮点数的加减运算（⭐⭐）

### 📐 五个步骤
设 X = Mₓ × 2^Eₓ，Y = Mᵧ × 2^Eᵧ：
1. **对阶**：使两个数的阶码相等。**小阶向大阶看齐**：阶码小的那个数的尾数**右移**，每右移一位阶码加 1，直到两个阶码相等
   - 🧒 为什么是小阶向大阶？右移丢掉的是尾数的**低位**，误差小；如果大阶向小阶看齐，尾数要左移，丢掉的是**高位**，误差巨大
2. **尾数加减**：对阶后，尾数按定点小数加减
3. **规格化**：结果不是规格化形式时调整（左规或右规）
4. **舍入**：对阶和右规时尾数右移会丢掉低位，需要舍入
5. **溢出判断**：看阶码是否上溢/下溢

### 📐 舍入方式
- **就近舍入**（IEEE 默认）：舍入到最近的可表示数；正好在中间时，舍入到“最低位为 0”的那个（偶数）
- **朝 +∞ 舍入**、**朝 −∞ 舍入**
- **朝 0 舍入**（截断）
- 其他教材中还有“0 舍 1 入法”“恒置 1 法”

### ✏️ 例：X = 1.101 × 2³，Y = 1.11 × 2¹，求 X + Y（二进制尾数）
1. **对阶**：Eₓ = 3 > Eᵧ = 1，Y 的尾数右移 2 位：Y = 0.0111 × 2³
2. **尾数相加**：1.101 + 0.0111 = **10.0001**
3. **规格化**：尾数 ≥ 2，**右规**一次：1.00001 × 2⁴
4. **舍入**：若尾数只能保留 3 位小数，1.00001 → 1.000（就近舍入）
5. **溢出**：阶码 4，未溢出
结果 **1.000 × 2⁴ = 16**（精确值 13 + 3.5 = 16.5，因舍入产生误差）

## 八、C 语言中的浮点类型转换（⭐⭐）

| 转换 | 结果 |
|---|---|
| int → float | **可能丢失精度**：int 有 31 位有效数字，float 尾数只有 24 位有效位（但不会溢出） |
| int → double | **精确**：double 有 53 位有效位 |
| float → double | **精确** |
| double → float | 可能**溢出**（范围小），可能**丢失精度** |
| float/double → int | **小数部分截断**（向 0 取整）；可能溢出 |

✏️ 例：
```c
int i = 16777217;        // 2^24 + 1
float f = i;             // f = 16777216.0（丢失了最低位的 1）
double d = i;            // d = 16777217.0（精确）
int j = (int)3.99;       // 3（截断）
int k = (int)-3.99;      // -3（向 0 取整）
```

✏️ 判断以下表达式是否**永远为真**（x 是 int，f 是 float，d 是 double，且都不是 NaN、∞）：
- `x == (int)(float)x` → **不一定**（int → float 可能丢精度）
- `x == (int)(double)x` → **一定**
- `f == (float)(double)f` → **一定**
- `d == (double)(float)d` → **不一定**
- `(d + f) - d == f` → **不一定**（浮点加法不满足结合律，可能舍入）

---

## ⚠️ 易错点
1. IEEE 754 阶码偏置 **127**（不是 128），尾数用**原码**，隐藏位 **1**
2. 真实指数 = E − 127；真实尾数 = 1.M
3. **E 全 0 且 M 非 0 是非规格化数**：0.M × 2⁻¹²⁶
4. E 全 1：M 全 0 是 ∞，M 非 0 是 NaN
5. 对阶：**小阶向大阶看齐**，小阶数的尾数右移
6. 浮点数溢出看**阶码**；下溢按 0 处理
7. int → float 可能丢精度；int → double 精确

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 单精度格式 | 1 + 8 + 23，偏置 127 |
| 双精度格式 | 1 + 11 + 52，偏置 1023 |
| 真值 | (−1)^S × 1.M × 2^(E−127) |
| 转换四步 | 转二进制 → 规格化 → 求 S/E/M → 拼接转十六进制 |
| 特殊值 | E=0,M=0 → ±0；E=0,M≠0 → 非规格化；E=255,M=0 → ∞；E=255,M≠0 → NaN |

| 加减运算 | 对阶（小向大）→ 尾数加减 → 规格化 → 舍入 → 溢出判断 |

## 🏋️ 课后练习

1. 把 −5.625 转换为 IEEE 754 单精度格式（十六进制）。
2. IEEE 754 单精度数 C1A8 0000H 的真值是多少？
3. IEEE 754 单精度数 0040 0000H 的真值是多少？
4. 下列哪些数能被 float 精确表示：0.5，0.3，2²⁰ + 1，2³⁰ + 1，−1024.125
5. X = 1.011 × 2⁵，Y = −1.1 × 2³，按浮点加法步骤计算 X + Y。

<details>
<summary>📖 答案</summary>

1. 5.625 = 101.101 = 1.01101 × 2²；S=1，E=129=1000 0001，M=01101 0… → 1 1000 0001 0110 1000… = 1100 0000 1011 0100 0… = **C0B4 0000H**
2. 1100 0001 1010 1000 … → S=1，E=1000 0011=131→e=4，M=0101 → 1.0101 × 2⁴ = 10101₂ = **−21**
3. 0000 0000 0100 0000 … → E = 0，M = 100 0… ≠ 0 → 非规格化：0.1 × 2⁻¹²⁶ = **2⁻¹²⁷**
4. 0.5 ✓；0.3 ✗（无限循环）；2²⁰ + 1 ✓（有效位 21 位 ≤ 24）；2³⁰ + 1 ✗（有效位 31 位 > 24）；−1024.125 = −10000000000.001₂ = −1.0000000000001 × 2¹⁰，有效位 14 位 ✓
5. 对阶：Y 右移 2 位 → −0.011 × 2⁵；尾数：1.011 − 0.011 = 1.000；结果 **1.000 × 2⁵ = 32**（验证：44 − 12 = 32 ✓）
</details>
