# 组成原理 第 9 课 · 外部存储器：磁盘、固态硬盘、RAID

> 🎯 **本课目标**
> 1. **掌握磁盘的结构**：盘面、磁道、扇区、柱面、磁头；磁盘地址格式与各字段位数
> 2. **掌握磁盘性能计算**：容量、记录密度、**平均访问时间（寻道 + 旋转延迟 + 传输）**、数据传输率
> 3. 了解磁盘阵列 RAID
> 4. **掌握固态硬盘 SSD** 的原理与特点（按页读写、按块擦除、磨损均衡）
>
> 真题：2022 年第 44 题（磁盘地址字段位数、扇区访问时间、DMA，8 分）。磁盘调度算法在操作系统中讲。

## 🚪 课前引入：唱片机

老式唱片机：一张唱片在转，唱针（磁头）移到某一圈上，唱片转到要播放的位置时就能读出声音。
**机械硬盘**原理几乎一样：盘片高速旋转，磁头在盘片上方移动，找到数据所在的圈（磁道）和位置（扇区）后读写。
因为有**机械运动**（移动磁头、等待旋转），磁盘比主存慢**十万倍以上**。

## 一、磁盘的结构（⭐⭐）

### 📐 组成
- **盘片**：一个磁盘有若干个盘片，每个盘片有**上下两个盘面**（都可以记录数据，最外侧的面有时不用）
- **磁头**：每个**记录面**对应一个磁头，所有磁头装在同一个**磁头臂**上，**一起移动**
- **磁道**：盘面上的一个个**同心圆**，最外圈是 0 号磁道
- **扇区**：每个磁道被划分成若干个**扇区**（弧段），**扇区是磁盘读写的最小单位**（常见 512 B）
- **柱面**：所有盘面上**半径相同**的磁道组成一个**柱面**（像一个圆柱）

```
        俯视一个盘面：                    侧视多个盘片：
          ╭─────────╮                  ═══════════  ← 盘面 0（磁头 0）
        ╭─┼─────────┼─╮  ← 磁道        ═══════════  ← 盘面 1（磁头 1）
       │  │  ╭───╮  │  │                 ↕ 同一柱面
       │  │  │ ● │  │  │               ═══════════  ← 盘面 2
       │  │  ╰───╯  │  │               ═══════════  ← 盘面 3
        ╰─┼─────────┼─╯
          ╰─────────╯ （扇区 = 磁道上的一段弧）
```
🧒 **为什么要引入“柱面”？** 所有磁头一起移动，移动到某个位置时，**所有盘面上同一半径的磁道都在磁头下方**，读写同一柱面的数据**不用再移动磁头**。所以数据按柱面存放可以减少寻道。

### 📐 磁盘地址（⭐⭐）
```
| 柱面号（磁道号） | 盘面号（磁头号） | 扇区号 |
```
各字段的位数 = ⌈log₂(对应数量)⌉

📝 **真题（2022 年第 44 题第 1 问）**：假设某磁盘驱动器中有 **4 个双面盘片**，每个盘面有 **20000 个磁道**，每个磁道有 **500 个扇区**，每个扇区可记录 **512 字节**的数据，盘片转速为 **7200 RPM**，平均寻道时间为 **5 ms**。每个扇区包含数据及其地址信息，地址信息分为 3 个字段。这 3 个字段的名称各是什么？对于该磁盘，各字段至少占多少位？
- **柱面号（磁道号）**：20000 个 → 2¹⁴ = 16384 < 20000 ≤ 32768 = 2¹⁵ → **15 位**
- **磁头号（盘面号）**：4 × 2 = 8 个盘面 → **3 位**
- **扇区号**：500 个 → 2⁸ = 256 < 500 ≤ 512 = 2⁹ → **9 位**

## 二、磁盘的性能指标（⭐⭐⭐）

### 📐 记录密度
- **道密度**：沿**半径方向**单位长度上的磁道数（道/mm）
- **位密度**：沿**磁道方向**单位长度上能记录的二进制位数（位/mm）
- **面密度**：位密度 × 道密度

⚠️ 传统磁盘**每个磁道存储的位数相同**（扇区数相同），而外圈周长长 → **内圈的位密度最高**，外圈较低（现代磁盘采用分区记录，外圈扇区更多）。

### 📐 容量
- **非格式化容量** = 记录面数 × 每面磁道数 × 每道位数（内圈周长 × 最大位密度）
- **格式化容量** = 记录面数 × 每面磁道数 × 每道扇区数 × 每扇区字节数
- 格式化容量 < 非格式化容量（格式化要占用一些空间存扇区地址、校验码、间隙等）

✏️ 2022 年第 44 题的磁盘容量：8 × 20000 × 500 × 512 B = 40960000000 B ≈ **40.96 GB**（= 38.1 GiB）

### 📐 平均访问时间（⭐⭐⭐）
$$\text{平均访问时间} = \text{平均寻道时间} + \text{平均旋转延迟} + \text{传输时间} \;(+\text{控制器延迟})$$

| 组成 | 含义 | 怎么算 |
|---|---|---|
| **寻道时间** | 磁头移动到目标**磁道**的时间 | 题目给出**平均寻道时间** |
| **旋转延迟** | 目标**扇区**转到磁头下方的时间 | **平均 = 转半圈的时间** |
| **传输时间** | 读写数据的时间 | = 转一圈的时间 × 要读的扇区数 / 每道扇区数 |

🧒 **为什么平均旋转延迟是半圈？** 磁头到达磁道时，目标扇区可能在任何位置：最好刚好在磁头下（0 圈），最坏刚刚错过（要转 1 圈），平均 1/2 圈。

✏️ **转速换算**（常考）：
| 转速 | 转一圈 | 平均旋转延迟 |
|---|---|---|
| 5400 RPM | 11.1 ms | 5.56 ms |
| **7200 RPM** | **8.33 ms** | **4.17 ms** |
| 10000 RPM | 6 ms | 3 ms |
| 15000 RPM | 4 ms | 2 ms |
（转一圈 = 60 / 转速 秒）

📝 **真题（2022 年第 44 题第 2 问）**：一个扇区的平均访问时间约为多少？
- 平均寻道时间：**5 ms**
- 平均旋转延迟：60 s / 7200 = 8.33 ms 转一圈 → 半圈 **4.17 ms**
- 传输时间：一个扇区是一圈的 1/500 → 8.33 ms / 500 ≈ **0.017 ms**
- 平均访问时间 ≈ 5 + 4.17 + 0.017 ≈ **9.19 ms**

### 📐 数据传输率
磁盘在单位时间内向主机传送的数据量：
$$D_r = r \times N$$
（r：转速，单位 **转/秒**；N：每条磁道的容量）
✏️ 7200 RPM = 120 转/秒，每道 500 × 512 B = 256000 B → Dr = 120 × 256000 = **30.72 MB/s**

### 📐 与 DMA 的结合（2022 年第 44 题第 3 问）
> 若采用**周期挪用 DMA** 方式进行磁盘与主机之间的数据传送，磁盘控制器中的数据缓冲区大小为 **64 位**，则在一个扇区读写过程中，DMA 控制器向 CPU 发送了多少次总线请求？若 CPU 检测到 DMA 控制器的总线请求信号时也需要访问主存，则 DMA 控制器是否可以获得总线使用权？为什么？
- 每次 DMA 请求传送一个缓冲区的数据（64 位 = 8 B）：512 / 8 = **64 次**
- **可以**。DMA 请求的**优先级高于** CPU 访存（磁盘数据若不及时取走，会被后续数据覆盖而丢失；CPU 晚一点访存不会有问题）。周期挪用时，CPU 暂停一个存储周期，让出总线给 DMA

## 三、磁盘阵列 RAID（了解）

**RAID（廉价冗余磁盘阵列）**：把多个独立的物理磁盘组成一个逻辑磁盘，数据**分散**在多个磁盘上，**并行**访问以提高速度，并通过**冗余**提高可靠性。
| 级别 | 方法 | 特点 |
|---|---|---|
| RAID0 | 无冗余、无校验，数据**条带化**分布在多个盘上 | 速度最快，**无容错** |
| RAID1 | **镜像**：数据同时写两个盘 | 可靠性高，磁盘利用率 50% |
| RAID2 | 海明码纠错 | |
| RAID3 | 位交叉奇偶校验，一个专用校验盘 | |
| RAID4 | 块交叉奇偶校验，一个专用校验盘 | |
| RAID5 | 块交叉，**奇偶校验信息分布在所有盘上** | 常用，允许一个盘损坏 |
RAID 通过同时使用多个磁盘，提高了传输率；通过**镜像**或**校验**提供容错。

## 四、固态硬盘 SSD（⭐⭐）

### 📐 组成
- 基于 **闪存（Flash）**，**没有机械部件**
- 由**闪存翻译层（FTL）**和**闪存芯片**组成。FTL 负责把操作系统的**逻辑块号**翻译成闪存上的**物理页**
- 一个闪存芯片由若干**块**组成，每块由若干**页**组成（如每页 4 KB，每块 32~128 页）

### 📐 读写特点（⭐⭐）
- **以页为单位读写**
- **以块为单位擦除**：一个页被擦除（全部位变为 1）后才能写入；要擦除，必须擦除它所在的**整个块**
- 写一个已有数据的页：不能直接覆盖 → 要把该块中其他有用的页**复制**到一个新的（已擦除的）块中，再写入 → **随机写很慢**
- **随机读很快**（没有寻道和旋转延迟），比机械硬盘快得多
- 每个块**擦写次数有限**（几千到几万次），超过后就坏了

### 📐 磨损均衡（⭐）
为了延长 SSD 寿命，让擦除操作**平均分布**在所有块上：
- **动态磨损均衡**：写入数据时，**优先选择擦除次数少**的新闪存块
- **静态磨损均衡**：更进一步，把**长期不修改**的“冷数据”搬到擦除次数多的块上，让擦除次数少的块去承担经常修改的“热数据”

### 📐 SSD vs 机械硬盘
| | 机械硬盘 HDD | 固态硬盘 SSD |
|---|---|---|
| 原理 | 磁记录，机械运动 | 闪存，电子 |
| 随机访问 | 慢（有寻道、旋转延迟） | **快** |
| 写 | 可直接覆盖 | **写前要擦除**，随机写较慢 |
| 寿命 | 机械磨损 | **擦写次数有限** |
| 抗震、功耗、噪音 | 差 | 好 |
| 价格/容量 | 便宜、大 | 贵 |

🔗 操作系统中也会考 SSD（2025 年第 32 题：文件系统能为 HDD 和 SSD 都提供的功能是“确定盘块大小”，而“均衡磨损”由 SSD 内部的 FTL 实现）。

## ⚠️ 易错点
1. 磁盘地址：**柱面号 + 盘面号 + 扇区号**；位数向上取整
2. 双面盘片：盘面数 = 盘片数 × 2
3. **平均旋转延迟 = 转半圈的时间**
4. 转一圈 = 60 / RPM 秒；7200 RPM → 8.33 ms
5. 传输时间 = 一圈时间 / 每道扇区数（读一个扇区）
6. 传统磁盘内圈位密度最高
7. SSD：**按页读写，按块擦除**；写前要擦除

## 🏋️ 课后练习

1. 某磁盘有 6 个盘片（12 个记录面），每面 1024 条磁道，每道 64 个扇区，每扇区 512 B。求格式化容量和磁盘地址各字段位数。
2. 某磁盘转速 10000 RPM，平均寻道时间 4 ms，每道 400 个扇区。读一个扇区的平均时间？连续读同一磁道上的 100 个相邻扇区的平均时间？
3. 上题磁盘每扇区 512 B，数据传输率是多少？
4. 为什么 SSD 的随机写比随机读慢？

<details>
<summary>📖 答案</summary>

1. 12 × 1024 × 64 × 512 B = **384 MB**（2²⁸ × 1.5）；柱面号 10 位，盘面号 4 位（12 ≤ 16），扇区号 6 位
2. 转一圈 6 ms，半圈 3 ms；一个扇区传输 6/400 = 0.015 ms → **7.015 ms**；100 个扇区传输 6 × 100/400 = 1.5 ms → 4 + 3 + 1.5 = **8.5 ms**
3. 每道 400 × 512 = 204800 B，每秒 10000/60 ≈ 166.7 转 → ≈ **34.1 MB/s**
4. 闪存写入前必须擦除，而擦除以块为单位；修改一个页时可能要把整个块的有效数据复制到新块，再擦除旧块，开销很大；读则可以直接按页读出
</details>
