## 一、计算机的发展

### 📐 四代计算机（按电子器件划分）
| 代 | 时间 | 器件 | 特点 |
|---|---|---|---|
| 第一代 | 1946~1957 | **电子管** | 体积大、耗电多；ENIAC（第一台电子数字计算机） |
| 第二代 | 1958~1964 | **晶体管** | 出现高级语言（FORTRAN）和操作系统雏形 |
| 第三代 | 1965~1971 | **中小规模集成电路** | 出现分时操作系统 |
| 第四代 | 1972 至今 | **大规模、超大规模集成电路** | 微处理器、微型计算机 |

**摩尔定律**：集成电路上可容纳的晶体管数目，大约每 18~24 个月翻一番，性能也翻一番。

📝 **真题（2021 年第 12 题）**：2017 年“神威·太湖之光”浮点运算速度为 93.0146 PFLOPS，说明该计算机每秒钟内完成的浮点操作次数约为？
→ P = 10¹⁵，93 × 10¹⁵ = 9.3 × 10¹⁶。1 亿 = 10⁸，**1 亿亿 = 10¹⁶** → **9.3 亿亿次**，选 D
（A 9.3×10¹³ ✗；B 9.3×10¹⁵ ✗；C 9.3 千万亿次 = 9.3×10¹⁵ ✗）

## 二、冯·诺依曼计算机（⭐⭐⭐）

### 🧒 大白话：厨房
- **存储器** = 冰箱：放食材（数据）和菜谱（程序）
- **运算器** = 灶台和刀：真正加工食材（算术、逻辑运算）
- **控制器** = 厨师长：按菜谱一步步指挥
- **输入设备** = 进货口（键盘、鼠标）
- **输出设备** = 出菜口（显示器、打印机）

冯·诺依曼最伟大的思想是“**存储程序**”：把**程序和数据一起**提前放在存储器里，计算机自动按顺序取出指令执行，不需要人一步步操作。

### 📐 冯·诺依曼机的特点（⭐⭐ 必背）
1. 计算机由**运算器、控制器、存储器、输入设备、输出设备** 5 大部件组成
2. **指令和数据以同等地位存放在存储器内**，并可**按地址寻访**
3. **指令和数据均用二进制代码表示**
4. 指令由**操作码**和**地址码**组成：操作码指出操作的性质，地址码指出操作数在存储器中的位置
5. 指令在存储器内**按顺序存放**，通常按顺序执行，特定条件下可以改变顺序（跳转）
6. 早期的冯·诺依曼机以**运算器为中心**，输入输出设备通过运算器与存储器传送数据
7. **存储程序**：程序在执行前要先存入主存

### 📐 现代计算机：以存储器为中心
```
          ┌──────────────────────────┐
          │          主存储器          │
          └──────────────────────────┘
             ↑↓           ↑↓          ↑↓
          ┌──────┐   ┌──────────┐   ┌──────┐
          │输入设备│   │CPU（运算器│   │输出设备│
          └──────┘   │ + 控制器）│   └──────┘
                     └──────────┘
```
- **CPU = 运算器 + 控制器**
- **主机 = CPU + 主存**
- 外存（硬盘、U 盘）和输入输出设备统称**外设**（I/O 设备）

### 📐 CPU 怎么区分指令和数据？（⭐ 常考）
指令和数据都是二进制、都放在存储器里，**形式上没有区别**。CPU 靠**时间**区分：
- **取指阶段**（取指周期）从存储器取出的是**指令**
- **执行阶段**（执行周期）从存储器取出的是**数据**
（另一个角度：取指令用的地址来自 **PC**，取数据用的地址来自**指令的地址码**）

## 三、计算机硬件的基本组成（⭐⭐⭐）

### 3.1 存储器
```
┌────────────────────────────────────┐
│              存储体                 │ ← 由许多存储单元组成
├────────────────────────────────────┤
│  MAR（地址寄存器） │ MDR（数据寄存器） │
└────────────────────────────────────┘
```
| 术语 | 含义 |
|---|---|
| **存储元（存储位元）** | 存放一位二进制数的最小单元 |
| **存储单元** | 若干存储元组成，存放一串二进制代码（一个存储字） |
| **存储字** | 存储单元中的二进制代码组合 |
| **存储字长** | 一个存储单元中二进制代码的位数 |
| **MAR**（Memory Address Register） | **存储器地址寄存器**：存放要访问的存储单元的**地址** |
| **MDR**（Memory Data Register） | **存储器数据寄存器**：存放从存储器读出的或要写入的**数据** |

⭐ **位数关系**：
- **MAR 的位数 = 地址线位数**，决定存储单元的个数：2^(MAR 位数) 个单元
- **MDR 的位数 = 存储字长**（一般等于数据线位数）

✏️ 例：MAR 16 位、MDR 32 位 → 存储器有 2¹⁶ 个存储单元，每个单元 32 位 → 总容量 2¹⁶ × 32 位 = 256 KB

⚠️ 现代计算机中 MAR 和 MDR 通常**集成在 CPU 中**，但逻辑上属于存储器。

### 3.2 运算器
进行算术运算和逻辑运算。
| 部件 | 作用 |
|---|---|
| **ALU**（算术逻辑单元） | 运算器的核心，完成加减乘除、与或非等运算 |
| **ACC**（累加器） | 存放操作数和运算结果 |
| **MQ**（乘商寄存器） | 乘除运算时存放乘数、商 |
| **X**（操作数寄存器） | 存放操作数 |
| **GPRs**（通用寄存器组） | 存放操作数、地址等，程序员可以用 |
| **PSW / FR**（程序状态字 / 标志寄存器） | 存放运算结果的状态标志（ZF、SF、OF、CF）等 |

### 3.3 控制器
计算机的“指挥中心”，控制各部件协调工作。
| 部件 | 作用 |
|---|---|
| **PC**（Program Counter，程序计数器） | 存放**下一条要执行的指令的地址**，有自动加 1 的功能 |
| **IR**（Instruction Register，指令寄存器） | 存放**当前正在执行的指令** |
| **CU**（Control Unit，控制单元） | 分析指令，发出控制信号 |

⭐ **位数关系**：
- **PC 的位数** = 能访问的主存地址位数（一般等于 MAR 位数）
- **IR 的位数** = 指令字长

### 📐 各寄存器的“可见性”（⭐⭐ 常考）
**程序员可见**：程序员在写（汇编语言）程序时能直接用到或能影响的寄存器。
| 可见 | 不可见（透明） |
|---|---|
| **通用寄存器（GPRs）**、**PC**（跳转指令能修改）、**PSW/标志寄存器**（条件转移指令要用）、**基址寄存器**、**变址寄存器**、ACC | **IR**、**MAR**、**MDR**、**暂存寄存器**、微指令寄存器 |

📝 **真题（2021 年第 17 题）**：下列寄存器中，汇编语言程序员可见的是：I. 指令寄存器 II. 微指令寄存器 III. 基址寄存器 IV. 标志/状态寄存器
→ **III、IV**，选 D

📝 **真题（2020 年第 12 题）**：下列给出的部件中，其位数（宽度）**一定与机器字长相同**的是：I. ALU II. 指令寄存器 III. 通用寄存器 IV. 浮点寄存器
- **机器字长**：CPU 一次能处理的二进制数据的位数，通常等于 **ALU 的宽度**和**通用寄存器的宽度**
- 指令寄存器位数 = 指令字长，不一定等于机器字长
- 浮点寄存器常为 64 位或 80 位，与机器字长无关
→ **I、III**，选 B

I/O 设备通过 **I/O 接口**与主机相连（第 21 课详讲）。

## 四、计算机的工作过程（⭐⭐）

### 📐 一条指令的执行过程
以“**取数指令** LOAD M”（把主存地址 M 中的数取到 ACC）为例：
```
① (PC) → MAR          PC 中的指令地址送到 MAR
② M(MAR) → MDR        存储器根据 MAR 读出指令，放入 MDR
③ (MDR) → IR          指令送入 IR
④ OP(IR) → CU         指令的操作码送到控制单元分析
⑤ (PC) + 1 → PC       PC 指向下一条指令
—— 以上是“取指令、分析指令”，所有指令都一样 ——
⑥ Ad(IR) → MAR        指令的地址码（M）送到 MAR
⑦ M(MAR) → MDR        读出数据放入 MDR
⑧ (MDR) → ACC         数据送入 ACC
—— 以上是“执行”阶段，不同指令不一样 ——
```
（`(X)` 表示 X 中的内容；`M(MAR)` 表示以 MAR 的内容为地址的存储单元；`OP(IR)` 表示 IR 中的操作码字段；`Ad(IR)` 表示地址码字段）

🧒 **总结**：**取指 → 分析 → 执行**，然后 PC 指向下一条，周而复始。

### 📐 程序的执行过程
程序被装入主存 → PC 指向第一条指令 → 循环执行“取指令、分析指令、执行指令” → 直到遇到停机指令。

## 五、计算机软件

### 📐 系统软件 vs 应用软件
- **系统软件**：保证计算机系统高效、正确运行的基础软件——操作系统、数据库管理系统（DBMS）、语言处理程序（编译器、汇编器）、分布式软件系统、网络软件系统、标准库程序、服务性程序
- **应用软件**：为解决某个应用领域的问题而编写的程序——微信、Office、游戏

### 📐 三个级别的语言
| 语言 | 特点 |
|---|---|
| **机器语言** | 二进制代码，计算机**唯一可以直接识别和执行**的语言 |
| **汇编语言** | 用助记符（如 ADD、MOV）代替二进制操作码，要经**汇编程序**翻译成机器语言 |
| **高级语言** | C、Java、Python 等，要经**编译程序**或**解释程序**翻译 |

### 📐 翻译程序（⭐ 选择题）
- **汇编程序（汇编器）**：汇编语言 → 机器语言
- **编译程序（编译器）**：把高级语言源程序**一次全部翻译**成目标程序（可以反复执行，不用再翻译）
- **解释程序（解释器）**：把源程序的语句**逐条翻译、立即执行**，不生成目标程序（每次运行都要重新翻译，慢）

🧒 编译 = **笔译**（把一整本书翻译好再给你看）；解释 = **同声传译**（说一句翻一句）

### 📐 程序的转换过程（⭐⭐）
```
hello.c ──预处理器(cpp)──→ hello.i ──编译器(cc1)──→ hello.s ──汇编器(as)──→ hello.o ──链接器(ld)──→ hello
 源程序     处理 #include、  修改后的     翻译成       汇编程序    翻译成机器   可重定位     合并库函数、   可执行
 （文本）   #define 等        源程序      汇编语言     （文本）    指令        目标程序     重定位         目标程序
                                                                            （二进制）                  （二进制）
```
📝 **真题（2022 年第 20 题）**：将高级语言源程序转换为可执行目标文件的主要过程是：
A. **预处理 → 编译 → 汇编 → 链接** ✓

### 📐 软硬件的逻辑功能等价性
某些功能**既可以用硬件实现，也可以用软件实现**。例如乘法：可以用乘法器（硬件），也可以用加法和移位的程序（软件）。
- 硬件实现：速度快，成本高，灵活性差
- 软件实现：速度慢，成本低，灵活
→ 2020 年第 43 题就考了“没有乘法指令也能实现乘法”（见第 4 课）

## 六、计算机系统的层次结构（⭐）

```
第 6 层  应用程序（高级语言程序）       ← 应用程序员
第 5 层  高级语言机器                   ← 编译程序翻译
第 4 层  汇编语言机器                   ← 汇编程序翻译
第 3 层  操作系统机器                   ← 操作系统提供功能扩展
第 2 层  传统机器（机器语言机器）        ← 机器指令系统（ISA）
第 1 层  微程序机器                     ← 微指令系统（硬件直接执行）
第 0 层  硬联逻辑（电路）
```
- 下层是上层的基础，上层是下层的扩展
- **ISA（指令集体系结构）**是软件和硬件之间的**接口（界面）**

### 📐 ISA 与微体系结构（⭐⭐ 近年必考）
**ISA（Instruction Set Architecture，指令集体系结构）**：计算机硬件与软件之间的“**合同**”，规定了软件能看到、能使用的硬件功能：
- **指令格式、指令类型**、操作码、寻址方式
- **可访问的寄存器**（通用寄存器个数、位数、编号）
- 数据类型、数据格式、存储空间大小、编址方式、大端/小端
- I/O 空间的编址方式、中断和异常机制
- ……

**微体系结构（微架构）**：ISA 的**具体实现方式**，对软件透明：
- 用什么样的加法器（串行/并行进位）、乘法器（阵列乘法器？）
- 控制器用硬布线还是微程序
- 单总线还是多总线数据通路、流水线有几段
- 时钟频率、Cache 的大小和组织方式
- ……

🧒 **比喻**：ISA 是“**汽车的驾驶方式**”（方向盘、油门、刹车在哪、怎么用），微体系结构是“**发动机的内部构造**”。不同品牌的车，驾驶方式都一样，发动机可以完全不同。同一个 ISA（如 x86），Intel 和 AMD 可以设计出完全不同的微体系结构。

📝 **真题（2022 年第 18 题）**：下列选项中，属于指令集体系结构（ISA）规定的内容是：I. 指令字格式和指令类型 II. CPU 的时钟周期 III. 通用寄存器个数和位数 IV. 加法器的进位方式
→ **I、III**，选 B（时钟周期、加法器进位方式属于具体实现）

📝 **真题（2025 年第 16 题）**：下列选项中，由指令集体系结构（ISA）规定的是：A. 是否采用阵列乘法器 B. **是否采用定长指令字格式** C. 是否采用微程序控制器 D. 是否采用单总线数据通路 → **B**

## 七、计算机的性能指标（⭐⭐⭐）

### 7.1 基本概念
| 指标 | 含义 |
|---|---|
| **机器字长** | CPU 一次能处理的二进制数据的位数，通常等于通用寄存器的位数、ALU 的宽度 |
| **数据通路带宽** | 数据总线一次能并行传送的位数 |
| **主存容量** | 主存能存储的最大信息量，= 存储单元个数 × 存储字长 |
| **时钟周期（CPU 周期的基本单位）** | CPU 中最小的时间单位，**= 1 / 主频** |
| **主频（CPU 时钟频率）** | 每秒的时钟周期数，单位 Hz |
| **CPI**（Cycles Per Instruction） | 执行一条指令**平均**需要的时钟周期数 |
| **IPC** | 每个时钟周期执行的指令数 = 1 / CPI |
| **MIPS** | 每秒执行多少**百万**条指令 |
| **FLOPS** | 每秒执行多少次浮点运算（MFLOPS = 10⁶、GFLOPS = 10⁹、TFLOPS = 10¹²、PFLOPS = 10¹⁵、EFLOPS = 10¹⁸） |

⚠️ 频率、MIPS、FLOPS 中的 M、G、T 是 **10 的幂**，不是 2 的幂！

### 7.2 核心公式（⭐⭐⭐ 必背）
$$\text{CPU 执行时间} = \frac{\text{CPU 时钟周期数}}{\text{主频}} = \text{指令条数} \times \text{CPI} \times \text{时钟周期}$$
$$\text{MIPS} = \frac{\text{指令条数}}{\text{执行时间} \times 10^6} = \frac{\text{主频}}{\text{CPI} \times 10^6}$$

**平均 CPI**（不同类型指令 CPI 不同时）：
$$\text{CPI} = \sum_i \text{CPI}_i \times P_i \quad (P_i \text{ 为第 } i \text{ 类指令所占比例})$$

### 7.3 计算例题
📝 **真题（2022 年第 12 题）**：某计算机主频为 1 GHz，程序 P 运行过程中，共执行了 10000 条指令，其中 80% 的指令执行平均需 1 个时钟周期，20% 的指令执行平均需 10 个时钟周期。程序 P 的平均 CPI 和 CPU 执行时间分别是？
1. 平均 CPI = 0.8 × 1 + 0.2 × 10 = **2.8**
2. 时钟周期 = 1 / 1 GHz = 1 ns
3. 执行时间 = 10000 × 2.8 × 1 ns = 28000 ns = **28 μs**
→ 选 A

📝 **真题（2023 年第 12 题）**：若机器 M 的主频为 1.5 GHz，在 M 上执行程序 P 的指令条数为 5 × 10⁵，P 的平均 CPI 为 1.2，则 P 在 M 上的指令执行速度和用户 CPU 时间分别为？
1. 指令执行速度 = 主频 / CPI = 1.5 × 10⁹ / 1.2 = 1.25 × 10⁹ 条/秒 = **1.25 GIPS**（即 1250 MIPS）
2. CPU 时间 = 5 × 10⁵ × 1.2 / (1.5 × 10⁹) = 6 × 10⁵ / 1.5 × 10⁹ = 4 × 10⁻⁴ s = **0.4 ms**
→ 选 C（1.25 GIPS，0.4 ms）

✏️ **例**：两台机器 A、B 执行同一个程序。A 主频 2 GHz，CPI = 2；B 主频 3 GHz，CPI = 4。哪台快？快多少？
- A 的时间 ∝ CPI / 主频 = 2 / 2G = 1 ns/条
- B 的时间 ∝ 4 / 3G ≈ 1.33 ns/条
- **A 快**，是 B 的 1.33 倍
🧒 主频高不代表一定快，还要看 CPI！

### 7.4 用于比较性能的注意事项
- 不能只看主频，也不能只看 MIPS（不同机器的指令集不同，一条指令做的事情不同）
- 最可靠的指标是**执行同一程序的时间**
- **基准程序（Benchmark）**：专门用来测试性能的程序，如 SPEC

## ⚠️ 易错点
1. **CPU = 运算器 + 控制器**；主机 = CPU + 主存（**不包括**外存）
2. 冯·诺依曼机早期以运算器为中心，现代以存储器为中心
3. 指令和数据的区分依据：**取指/执行阶段**
4. MAR 位数 = 地址线位数；MDR 位数 = 存储字长
5. IR、MAR、MDR 对程序员**透明**；PC、PSW、通用寄存器**可见**
6. 机器字长 = ALU 宽度 = 通用寄存器宽度
7. 主频、MIPS 中的 M、G 是 10 的幂
8. ISA 管“能用什么”，不管“怎么实现”

---

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 冯·诺依曼 | 5 大部件；存储程序；指令数据同等地位、二进制 |
| 寄存器 | PC 下一条指令地址；IR 当前指令；MAR 地址；MDR 数据 |
| 指令执行 | 取指（PC→MAR→MDR→IR，PC+1）→ 分析 → 执行 |
| 翻译 | 预处理 → 编译 → 汇编 → 链接 |
| 编译 vs 解释 | 一次全译 vs 逐条翻译执行 |
| ISA | 指令格式、寄存器、寻址方式等；不含实现细节 |
| 执行时间 | 指令数 × CPI / 主频 |
| MIPS | 主频 / (CPI × 10⁶) |

## 🏋️ 课后练习

1. 某机 MAR 为 20 位，MDR 为 16 位，按字编址，主存容量是多少字节？
2. 一台计算机主频 800 MHz，执行某程序共 2 × 10⁸ 条指令，其中 ALU 指令 50%（CPI = 1），访存指令 30%（CPI = 4），转移指令 20%（CPI = 3），求平均 CPI、MIPS 和执行时间。
3. 判断：“解释程序会把源程序翻译成目标程序，然后执行。”
4. 下列哪些属于 ISA：(a) 通用寄存器有 16 个 (b) 采用 5 段流水线 (c) 有乘法指令 (d) Cache 容量 32 KB (e) 采用小端方式存储
5. 在取指阶段，哪个寄存器的内容被送到 MAR？执行“取数”指令时，哪个部分被送到 MAR？

<details>
<summary>📖 答案</summary>

1. 2²⁰ × 16 位 = 2²⁰ × 2 B = **2 MB**
2. CPI = 0.5×1 + 0.3×4 + 0.2×3 = 0.5 + 1.2 + 0.6 = **2.3**；MIPS = 800 / 2.3 ≈ **347.8**；时间 = 2×10⁸ × 2.3 / (8×10⁸) = **0.575 s**
3. **错**，解释程序不生成目标程序
4. **(a)(c)(e)** 属于 ISA；(b)(d) 属于具体实现（微体系结构）
5. 取指：**PC**；执行取数指令：**指令中的地址码 Ad(IR)**
</details>
