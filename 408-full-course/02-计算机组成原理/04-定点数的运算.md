## 一、移位运算（⭐⭐）

### 📐 逻辑移位（无符号数）
把操作数看作**纯二进制数**（无符号），不管符号位：
- **逻辑左移**：高位移出丢弃，**低位补 0**
- **逻辑右移**：低位移出丢弃，**高位补 0**

例：1010 0110 逻辑左移 1 位 → 0100 1100；逻辑右移 1 位 → 0101 0011

### 📐 算术移位（有符号数）
**符号位不变**（或者说，保证符号不变），只移数值位：
| 码制 | 左移补 | 右移补 |
|---|---|---|
| 正数（三种码都一样） | 0 | 0 |
| 负数原码 | 0 | 0 |
| 负数反码 | 1 | 1 |
| **负数补码** | **0** | **1**（补符号位） |

🧒 **补码算术移位最常用，记住**：**左移低位补 0，右移高位补符号位**。
- 例：[−12]补 = 1111 0100
  - 算术右移 1 位：**1**111 1010 = −6 ✓（相当于 ÷2）
  - 算术左移 1 位：1110 1000 = −24 ✓（相当于 ×2）

### 📐 移位与乘除
- 左移 1 位 ≈ **× 2**，右移 1 位 ≈ **÷ 2**
- **左移可能溢出**：补码算术左移时，若移出的位与新的符号位不同，就溢出了
  - 例：0100 0000（64）左移 → 1000 0000（−128）✗ 溢出
- **右移可能丢失精度**：移出的是 1 时，结果不精确（补码右移相当于**向下取整**：−5 >> 1 = −3）

### 📐 循环移位
移出的位**移回另一端**。带进位循环时，还要把 CF 加入循环。

## 二、补码加减运算（⭐⭐⭐）

### 📐 公式
$$[A + B]_补 = [A]_补 + [B]_补 \pmod{2^{n+1}}$$
$$[A - B]_补 = [A]_补 + [-B]_补 \pmod{2^{n+1}}$$
- **符号位和数值位一起参加运算**，符号位产生的进位**丢掉**
- 减法转化为加法：[−B]补 = [B]补 **连同符号位全部取反，末位加 1**

✏️ **例 1**（8 位）：A = 15，B = −24，求 A + B 和 A − B
- [A]补 = 0000 1111，[B]补 = 1110 1000，[−B]补 = 0001 1000
- A + B：0000 1111 + 1110 1000 = **1111 0111** = −9 ✓
- A − B：0000 1111 + 0001 1000 = **0010 0111** = 39 ✓

✏️ **例 2**：A = 100，B = 50，求 A + B（8 位）
- 0110 0100 + 0011 0010 = **1001 0110** = −106 ✗ 正 + 正 = 负，**溢出**！（150 超出 127）

### 📐 加减法器的硬件
一个**加法器** + 对 B 的“**可控求反**”：
- 减法时，控制信号 **Sub = 1**：B 的每一位与 1 异或（取反），同时最低位进位 **Cin = 1**（相当于加 1）
- 加法时 Sub = 0：B 不变，Cin = 0
```
A ─────────────────────┐
                        ├→ [ n 位加法器 ] → F（结果）
B ─→ [⊕ Sub] ──────────┘         ↑
                                Cin = Sub
```
🧒 **同一个电路**既能做有符号数运算，也能做无符号数运算！加法器本身不区分，区别只在于**怎么解释结果**和**看哪个标志位**。

## 三、溢出判断（⭐⭐⭐）

### 📐 什么是溢出
运算结果**超出了机器数能表示的范围**。
- **只有两个同号数相加**（或异号数相减）**才可能溢出**
- **正溢出**：两个正数相加，结果超过最大正数
- **负溢出**：两个负数相加，结果小于最小负数

### 📐 方法一：一位符号位判断（看操作数和结果的符号）
设 A、B 的符号位为 Aₛ、Bₛ，结果符号位为 Sₛ：
**加法**：同号相加，结果符号与操作数不同 → 溢出
$$V = A_s B_s \overline{S_s} + \overline{A_s}\,\overline{B_s} S_s$$
**减法**（A − B）：异号相减（正 − 负 或 负 − 正），结果符号与被减数 A 不同 → 溢出
$$V = A_s \overline{B_s}\,\overline{S_s} + \overline{A_s} B_s S_s$$

📝 **真题（2022 年第 43 题第 1 问）**：设 ALU 的输入端 A、B 及输出端 F 的最高位分别为 A₁₅、B₁₅ 及 F₁₅，FR 中的符号标志和溢出标志分别为 SF 和 OF，则 SF 的逻辑表达式是什么？A 加 B、A 减 B 时 OF 的逻辑表达式分别是什么？
- **SF = F₁₅**
- **加法 OF = A₁₅·B₁₅·F̄₁₅ + Ā₁₅·B̄₁₅·F₁₅**（两个负数相加得正数，或两个正数相加得负数）
- **减法 OF = A₁₅·B̄₁₅·F̄₁₅ + Ā₁₅·B₁₅·F₁₅**（负 − 正 = 正，或 正 − 负 = 负）

### 📐 方法二：双符号位（变形补码）
用两个符号位（正数 00、负数 11）计算，看结果的两个符号位：
| 结果符号位 | 含义 |
|---|---|
| 00 | 正数，无溢出 |
| 11 | 负数，无溢出 |
| **01** | **正溢出** |
| **10** | **负溢出** |
**规律**：两个符号位不同就溢出；**最高符号位代表真正的符号**。
例：100 + 50：00 110 0100 + 00 011 0010 = **01** 001 0110 → 正溢出

### 📐 方法三：进位判断（⭐ 硬件最常用）
设 **Cₙ** 为**符号位向更高位的进位**，**Cₙ₋₁** 为**最高数值位向符号位的进位**：
$$V = C_n \oplus C_{n-1}$$
两个进位**不同**就溢出。
例：0110 0100 + 0011 0010：最高数值位向符号位有进位（C₆ = 1），符号位没有向外进位（C₇ = 0）→ 1 ⊕ 0 = 1 → 溢出 ✓

📝 **真题（2025 年第 14 题）**：假设 8 位字长的计算机中，两个带符号整数 x 和 y 的补码表示分别为 [x]补 = A3H，[y]补 = 75H，则通过补码加减运算器得到的 x − y 的值及 OF 标志分别为：A. 24, 0 B. 24, 1 C. 46, 0 D. 46, 1
1. x = A3H = 1010 0011 = −128 + 32 + 2 + 1 = **−93**；y = 75H = 0111 0101 = **117**
2. 真实结果 x − y = −210，超出 [−128, 127] → **溢出**
3. 机器怎么算：[−y]补 = 75H 全部取反加 1 = 1000 1011 = 8BH
   A3H + 8BH = 1010 0011 + 1000 1011 = **1** 0010 1110，丢掉最高位的进位 → **2EH = 46**
4. OF：负数 − 正数 = 正数 → **OF = 1**
→ 选 **D（46, 1）**

## 四、标志位（⭐⭐⭐）

### 📐 四个常用标志
| 标志 | 名称 | 含义 | 求法 | 对谁有意义 |
|---|---|---|---|---|
| **ZF** | 零标志 | 结果为 0 | 结果全 0 时 ZF = 1 | 都有 |
| **SF** | 符号标志 | 结果为负 | **SF = 结果的最高位** | **有符号数** |
| **OF** | 溢出标志 | 有符号数溢出 | OF = Cₙ ⊕ Cₙ₋₁ | **有符号数** |
| **CF** | 进/借位标志 | 无符号数溢出（进位或借位） | **CF = Cout ⊕ Sub** | **无符号数** |

### 📐 CF 的求法（⭐⭐ 易错）
- **加法**（Sub = 0）：**CF = Cout**（最高位有进位就是无符号溢出）
- **减法**（Sub = 1）：**CF = Cout ⊕ 1 = C̄out**
  - 🧒 减法用“加补码”实现，**有借位时反而没有进位**。例如 3 − 5（无符号）：0011 + 1011（−5 的补码）= 1110，Cout = 0 → CF = 1，表示有借位（3 < 5，不够减）
  - **无符号减法：被减数 < 减数时 CF = 1**

⚠️ **OF 和 CF 的区别**：OF 管**有符号**数是否溢出；CF 管**无符号**数是否溢出（进位/借位）。同一次运算，两个标志都会被设置，程序员根据数据类型看对应的标志。

✏️ **例**：8 位运算 0111 1111 + 0000 0001 = 1000 0000
- ZF = 0，SF = 1
- OF = 1（正 + 正 = 负，127 + 1 有符号溢出）
- CF = 0（无符号 127 + 1 = 128 没有溢出，最高位没有进位）

✏️ **例**：8 位运算 1111 1111 + 0000 0001 = (1)0000 0000
- ZF = 1，SF = 0
- OF = 0（−1 + 1 = 0，有符号正确）
- CF = 1（无符号 255 + 1 = 256，溢出）

📝 **真题（2023 年第 16 题）**：已知 x、y 为 int 类型，当 x = 100、y = 200 时，执行 x − y 得到的溢出标志 OF 和借位标志 CF 分别为 0、1，那么当 x = 10、y = −20 时，执行该指令得到的 OF 和 CF 分别是：A. OF=0, CF=0 B. OF=0, CF=1 C. OF=1, CF=0 D. OF=1, CF=1
1. 有符号：10 − (−20) = 30，没有超出 int 范围 → **OF = 0**
2. CF：按无符号看，x = 10，y = −20 的机器数是 FFFF FFECH（很大的无符号数 2³² − 20）。**10 < 2³² − 20**，不够减，有借位 → **CF = 1**
   （硬件角度：x + ȳ + 1 = 0000 000AH + 0000 0013H + 1 = 0000 001EH，Cout = 0 → CF = Cout ⊕ 1 = 1）
→ 选 **B**

## 五、加法器与 ALU（⭐）

### 📐 一位全加器（FA）
输入：Aᵢ、Bᵢ、低位进位 Cᵢ；输出：本位和 Sᵢ、向高位的进位 Cᵢ₊₁
$$S_i = A_i \oplus B_i \oplus C_i$$
$$C_{i+1} = A_i B_i + (A_i \oplus B_i) C_i$$

### 📐 串行进位加法器（行波进位）
n 个全加器串联，每一位的进位要等低位算完才能得到 → **进位逐级传递，速度慢**，延迟与位数 n 成正比。

### 📐 并行进位加法器（先行进位，CLA）
定义：
- **进位产生函数 Gᵢ = AᵢBᵢ**（本位自己就能产生进位）
- **进位传递函数 Pᵢ = Aᵢ ⊕ Bᵢ**（或 Aᵢ + Bᵢ）（本位能把低位的进位传上去）

则 Cᵢ₊₁ = Gᵢ + PᵢCᵢ，展开：
- C₁ = G₀ + P₀C₀
- C₂ = G₁ + P₁G₀ + P₁P₀C₀
- C₃ = G₂ + P₂G₁ + P₂P₁G₀ + P₂P₁P₀C₀
- ……

**所有进位都直接由 A、B、C₀ 算出，同时得到**，不用等待，速度快。
实际中常用**组内并行、组间串行**或**组内并行、组间并行**（多级先行进位）的折中方案。

### 📐 ALU
**算术逻辑单元**：核心是加法器，再加上逻辑运算电路和多路选择器，由**控制信号（ALUop）**选择做哪种运算。
- **ALU 是组合逻辑电路**（没有记忆功能），输出只取决于当前输入
- 所以 ALU 的输入端、输出端需要寄存器暂存数据（见第 17 课数据通路）

## 六、乘法运算（⭐⭐）

### 🧒 乘法就是“移位 + 加法”
手算 1101 × 1011：
```
        1 1 0 1
      × 1 0 1 1
      ─────────
        1 1 0 1      ← 乘数最低位是 1：加 1101
      1 1 0 1        ← 乘数第 1 位是 1：加 1101 左移 1 位
    0 0 0 0          ← 乘数第 2 位是 0：加 0
  1 1 0 1            ← 乘数第 3 位是 1：加 1101 左移 3 位
  ─────────────
  1 0 0 0 1 1 1 1    = 143 = 13 × 11 ✓
```
计算机中用“**部分积右移**”代替“被乘数左移”：每一步根据乘数的最低位决定加被乘数还是加 0，然后把部分积和乘数**一起右移一位**。

### 📐 原码一位乘法
- **符号位单独处理**：积的符号 = 两个数的符号**异或**
- **数值部分用绝对值相乘**（无符号乘法）
- 每一步：看乘数当前最低位 yᵢ，**yᵢ = 1 则部分积 + |x|**，**yᵢ = 0 则 + 0**；然后部分积与乘数一起**逻辑右移**一位
- n 位数值需要 **n 次“加 + 移位”**

✏️ **例**：|x| = 1101（13），|y| = 1011（11）。寄存器：C（进位）| P（部分积）| Y（乘数）
| 步骤 | 操作 | C P | Y | 说明 |
|---|---|---|---|---|
| 初始 | | 0 0000 | 1011 | |
| 1 | y₀=1，+\|x\| | 0 1101 | 1011 | |
| | 右移 | 0 0110 | 1101 | P 的最低位 1 移入 Y 的最高位 |
| 2 | y=1，+\|x\| | 1 0011 | 1101 | 0110 + 1101 = 1 0011 |
| | 右移 | 0 1001 | 1110 | |
| 3 | y=0，+0 | 0 1001 | 1110 | |
| | 右移 | 0 0100 | 1111 | |
| 4 | y=1，+\|x\| | 1 0001 | 1111 | 0100 + 1101 = 1 0001 |
| | 右移 | 0 1000 | 1111 | |
积 = P Y = **1000 1111** = 143 ✓

### 📐 补码一位乘法（Booth 算法）
直接用补码相乘，符号位也参加运算。在乘数末尾添加一位 y₋₁ = 0，每次看**乘数最低两位 yᵢyᵢ₋₁**：
| yᵢ yᵢ₋₁ | 操作 |
|---|---|
| 0 0 | 部分积 + 0，右移 |
| 0 1 | 部分积 **+ [x]补**，右移 |
| 1 0 | 部分积 **+ [−x]补**（即减 x），右移 |
| 1 1 | 部分积 + 0，右移 |
- 右移是**算术右移**（补码）
- n 位数值（n+1 位补码）需要 n+1 次加法、n 次移位（最后一步不移位）——细节因教材而异，理解思想即可

✏️ 简例：x = 3（0011），y = −2（1110），4 位补码，结果应为 −6
| 步骤 | yᵢyᵢ₋₁ | 操作 | A（部分积） | Q（乘数） | Q₋₁ |
|---|---|---|---|---|---|
| 初始 | | | 0000 | 1110 | 0 |
| 1 | 00 | 无，算术右移 | 0000 | 0111 | 0 |
| 2 | 10 | A − x = 1101，右移 | 1110 | 1011 | 1 |
| 3 | 11 | 无，右移 | 1111 | 0101 | 1 |
| 4 | 11 | 无，右移 | 1111 | 1010 | 1 |
积 = A Q = 1111 1010 = **−6** ✓

### 📐 乘法器的实现方式（⭐ 2020 年第 43 题）
1. **软件实现**：没有乘法指令，用加法和移位指令编程实现（循环）
2. **硬件实现（ALU + 移位器 + 寄存器 + 控制逻辑）**：乘法指令由硬件循环完成，控制逻辑用**计数器**控制循环次数，根据乘数最低位决定加法，控制移位
3. **阵列乘法器**：用大量加法器组成阵列，**所有部分积同时产生、并行相加**，一个周期左右就能出结果

速度：**软件最慢，阵列乘法器最快**。

### 📐 乘法溢出判断（⭐⭐）
n 位 × n 位，乘积需要 **2n 位**才能完整保存。若只保留低 n 位（如 C 语言 int × int 结果还是 int），可能溢出：
- **无符号乘法**：2n 位乘积的**高 n 位全为 0**，才不溢出
- **有符号乘法**：2n 位乘积的**高 n 位每一位都等于低 n 位的最高位（符号位）**，才不溢出（即高 n 位是低 n 位的符号扩展）

📝 **真题（2020 年第 43 题，13 分）**：有实现 x × y 的两个 C 语言函数如下：
```c
unsigned umul(unsigned x, unsigned y) { return x * y; }
int imul(int x, int y) { return x * y; }
```
假定某计算机 M 中 ALU 只能进行加减运算和逻辑运算。请回答：
(1) 若 M 的指令系统中没有乘法指令，但有加法、减法和移位等指令，则在 M 上也能实现上述两个函数中的乘法运算，为什么？
(2) 若 M 的指令系统中有乘法指令，则基于 ALU、移位器、寄存器以及相应控制逻辑实现乘法指令时，控制逻辑的作用是什么？
(3) 针对以下三种情况：① 没有乘法指令；② 有使用 ALU 和移位器实现的乘法指令；③ 有使用阵列乘法器实现的乘法指令，函数 umul() 在哪种情况下执行时间最长？哪种情况下执行的时间最短？说明理由。
(4) n 位整数乘法指令可保存 2n 位乘积，当仅取低 n 位作为乘积时，其结果可能会发生溢出。当 n = 32、x = 2³¹ − 1、y = 2 时，带符号整数乘法指令和无符号整数乘法指令得到的 x × y 的 2n 位乘积分别是什么（用十六进制表示）？此时函数 umul() 和 imul() 的返回结果是否溢出？对于无符号整数乘法运算，当仅取乘积的低 n 位作为乘法结果时，如何用 2n 位乘积进行溢出判断？

**答**：
(1) 乘法运算可以通过**加法和移位**实现（软件编程用循环：根据乘数的每一位决定是否把被乘数的移位结果累加到部分积上）。**硬件能实现的功能，软件也能实现**（软硬件功能的逻辑等价性）。
(2) 控制逻辑的作用：控制循环次数（用计数器，n 位乘法循环 n 次）；根据乘数当前位决定是否将被乘数（部分积）送 ALU 做加法；控制部分积与乘数的移位；控制寄存器的写入等。
(3) **情况 ① 最长**：每一步加法、移位、判断都要执行若干条指令，总共要执行几十上百条指令；**情况 ③ 最短**：阵列乘法器用组合逻辑并行完成，只需一条指令、很短的时间；情况 ② 居中，一条指令但内部要循环 n 次。
(4) x = 2³¹ − 1 = 7FFF FFFFH，y = 2，x × y = 2³² − 2
- **带符号乘法**：2n 位乘积 = **0000 0000 FFFF FFFEH**
- **无符号乘法**：2n 位乘积 = **0000 0000 FFFF FFFEH**（x、y 都是正数，两者相同）
- **umul() 不溢出**：高 32 位全 0，返回的 FFFF FFFEH 就是 2³² − 2
- **imul() 溢出**：返回的低 32 位 FFFF FFFEH 按补码是 −2，而高 32 位是全 0，不是低 32 位最高位（1）的符号扩展 → 溢出
- 无符号乘法溢出判断：**若 2n 位乘积的高 n 位全为 0，则不溢出；否则溢出**

## 七、除法运算（⭐）

### 📐 原理
除法 = **减法 + 移位**。手算时：够减就商 1 并减去除数，不够减就商 0。

### 📐 原码除法：恢复余数法与不恢复余数法（加减交替法）
- 符号单独处理（异或），数值用绝对值
- **恢复余数法**：每次先减除数；余数为负说明不够减，商 0，**再加回除数恢复余数**；余数为正商 1。然后余数左移一位，继续
- **不恢复余数法（加减交替法）**：余数为负时**不恢复**，而是商 0，左移后**下一步加除数**；余数为正时商 1，左移后下一步**减除数**
  - 规则：**余数为正 → 商 1，左移，减 y；余数为负 → 商 0，左移，加 y**
  - 运算次数固定，速度快，硬件常用
- n 位除法需要 n 次（或 n+1 次）加/减和移位

### 📐 除法器的硬件（2025 年第 44 题）
- 被除数（2n 位）放在 **余数寄存器 R（高 n 位）+ 余数/商寄存器 Q（低 n 位）**，除数放在**除数寄存器 Y**
- 每一步 ALU 做**加法或减法**（由 ALUop 控制），余数和商一起左移，新的商位从 Q 的最低位移入
- **控制逻辑**中有**计数器 Cn**，控制循环次数
- 做 32 位补码除法前，要把 32 位被除数**符号扩展**成 64 位

📝 **真题（2025 年第 44 题）**：机器级代码
```
mov  R1, (R3 + R4*4)     // R1 ← d[i]
scov R1                  // {R0, R1} ← SEXT(R1)，把 R1 符号扩展成 64 位放入 R0:R1
idiv R1, R2              // R1 ← ({R0, R1} / R2)
```
(1) 若执行 idiv 时 d[i] = 0x87654321，x = 0xff，则补码除法器中寄存器 R、Q 和 Y 的初始内容分别是什么？哪个部件包含计数器？由 ALUop 所控制的 ALU 运算有哪几种？
- 被除数 d[i] = 8765 4321H 是负数，符号扩展成 64 位：**FFFF FFFF 8765 4321H**
- **R = FFFF FFFFH**（高 32 位），**Q = 8765 4321H**（低 32 位），**Y = 0000 00FFH**（除数 x）
- **控制逻辑**包含计数器 Cn
- ALU 运算有**加法和减法**两种（不恢复余数法中根据余数符号选择加除数或减除数）

(2) 假设 idiv 指令执行过程中会检测并触发除法异常，哪些情况下会发生除法异常（给出 d 和 x 的十六进制机器数）？发生除法异常时，在异常响应过程中 CPU 需要完成哪些操作？
- **除数为 0**：x = **0000 0000H**（d 任意）
- **结果溢出**：d = **8000 0000H**（−2³¹），x = **FFFF FFFFH**（−1）——商 2³¹ 超出 32 位补码范围
- CPU 的异常响应：**关中断**（或屏蔽后续中断）、**保存断点**（发生异常的指令地址）和**程序状态**（PSW），**识别异常类型**（除法异常的类型号/向量），**转去执行**操作系统中对应的**异常处理程序**（同时切换到内核态）

## ⚠️ 易错点
1. 补码算术右移**高位补符号位**，左移低位补 0
2. **只有同号相加（异号相减）才可能溢出**
3. OF = Cₙ ⊕ Cₙ₋₁；双符号位 01 正溢出、10 负溢出
4. **SF = 结果最高位**；**CF 减法时要取反**（CF = Cout ⊕ Sub）
5. OF 看有符号，CF 看无符号
6. 乘法：原码一位乘符号单独异或；Booth 看 yᵢyᵢ₋₁（10 减、01 加）
7. 乘法溢出：无符号看高 n 位全 0；有符号看高 n 位是否为低 n 位的符号扩展
8. 除法异常：除数为 0；−2ⁿ⁻¹ ÷ (−1)

1. 1011 0100（−76）：算术右移 2 位 → 1110 1101 = **EDH**（−19）；算术左移 1 位 → 0110 1000，符号位从 1 变 0，**溢出**（−152 超范围）；逻辑右移 1 位 → 0101 1010 = **5AH**

3. 1000 0000 + 1111 1111 = (1) 0111 1111 → 结果 **7FH**；ZF = 0；SF = 0；OF = 1（负 − 正 = 正，−128 − 1 溢出）；Cout = 1 → CF = 1 ⊕ 1 = **0**（无符号 128 − 1 = 127，够减，无借位）
4. |x| = 101，|y| = 111，寄存器 C P | Y：初始 0 000 | 111；① y₀=1，P+101 → 0 101，右移 → 0 010 | 111；② y=1，P+101 → 0 111，右移 → 0 011 | 111；③ y=1，P+101 → 1 000，右移 → 0 100 | 011。积 = P Y = 100 011，即 **0.100011**（0.625 × 0.875 = 0.546875 ✓），符号位 0 ⊕ 0 = 0
5. 4000H × 4 = 1 0000H → 32 位乘积 **0001 0000H**；低 16 位 0000H，高 16 位 0001H 不是低 16 位符号位（0）的扩展（应为 0000H）→ **溢出**
6. **(b) 和 (d)**。(a) 7FFF FFFFH ÷ (−1) = −(2³¹ − 1)，能用 32 位补码表示，不溢出；(c) 结果为 0，正常；(b) 商为 2³¹，超出范围；(d) 除数为 0
