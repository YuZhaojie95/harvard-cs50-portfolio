你在学习时：

- **书架上**放这学期要用的书，走两步就拿到（**主存**，较快、较大）

计算机的存储器也是这样分层的：**越靠近 CPU 越快、越小、越贵**。通过把“马上要用”的数据提前搬到上层，让整个系统**既快又大又便宜**。

## 一、存储器的层次结构（⭐⭐）

```
             ┌─────────┐
             │  寄存器  │   ← CPU 内部，最快
             ├─────────┤
             │  Cache  │   ← SRAM
             ├─────────┤
             │   主存   │   ← DRAM
             ├─────────┤
             │  辅存    │   ← 磁盘、SSD
             ├─────────┤
             │ 离线存储 │   ← 磁带、光盘
             └─────────┘
    越往上：速度越快、容量越小、每位价格越高
```

### 📐 两个主要层次
| 层次 | 解决什么问题 | 由谁实现 | 对谁透明 |
|---|---|---|---|
| **Cache — 主存** | CPU 与主存**速度不匹配** | **全部由硬件**自动完成 | 对**所有程序员**透明 |
| **主存 — 辅存** | 主存**容量不足** | **硬件 + 操作系统**（虚拟存储系统） | 对**应用程序员**透明（系统程序员可见） |

- 上一层的内容是下一层内容的**副本**（Cache 中的数据主存里都有，主存中的数据辅存里都有）
- **主存与 CPU 直接交换信息**；辅存**不能**与 CPU 直接交换信息，必须先调入主存
- 🧒 “**CPU 只和主存打交道**”：CPU 要用的指令和数据必须在主存（或 Cache）中

## 二、存储器的分类

### 📐 按在计算机中的作用（层次）
- **主存储器（主存、内存）**：存放当前运行的程序和数据，CPU 可直接访问
- **辅助存储器（辅存、外存）**：存放暂时不用的程序和数据，容量大
- **高速缓冲存储器（Cache）**：位于 CPU 和主存之间，存放主存中最常用的部分

### 📐 按存储介质
- 半导体存储器（主存、Cache、Flash）
- 磁表面存储器（磁盘、磁带）
- 光存储器（光盘）

### 📐 按存取方式（⭐）
| 类型 | 特点 | 例子 |
|---|---|---|
| **随机存取存储器（RAM）** | 任何一个存储单元的存取时间**都相同**，与位置无关 | 主存、Cache |
| **只读存储器（ROM）** | 只能读、不能写（或很难写）；**也是随机存取的** | BIOS |
| **顺序存取存储器（SAM）** | 只能按顺序存取，存取时间与位置有关 | 磁带 |
| **直接存取存储器（DAM）** | 先直接找到一个区域，再在区域内顺序查找 | **磁盘** |
| **相联存储器（CAM）** | **按内容**检索，而不是按地址 | **TLB**、Cache 的标记比较 |

### 📐 按信息的可保存性
- **易失性**：断电后信息消失（**RAM**：SRAM、DRAM）
- **非易失性**：断电后信息仍然保存（**ROM**、Flash、磁盘、光盘）
- **破坏性读出**：读出后原信息被破坏，需要**再生**（DRAM）
- **非破坏性读出**：读出不影响原信息（SRAM）

## 三、存储器的性能指标（⭐）

| 指标 | 含义 |
|---|---|
| **存储容量** | = 存储字数 × 字长，如 1M × 8 位 |
| **单位成本** | 每位价格 = 总成本 / 总容量 |
| **存取时间 Tₐ** | 从启动一次读（写）操作到完成该操作所经历的时间 |
| **存取周期 Tₘ**（读写周期） | 连续两次**独立**的读（写）操作之间的**最小时间间隔** |
| **主存带宽 Bₘ** | 单位时间内存储器能读写的数据量 = 数据宽度 / 存取周期 |

⭐ **存取周期 > 存取时间**：存取周期 = 存取时间 + **恢复时间**（读完后，存储器还需要一段时间恢复内部状态，比如 DRAM 要再生）
🧒 就像饭店的厨师：“存取时间”是做一道菜的时间，“存取周期”是做完一道菜到可以开始做下一道菜的时间（中间还要洗锅）。

✏️ 例：存储器存取周期 50 ns，数据宽度 32 位 → 带宽 = 4 B / 50 ns = **80 MB/s**（M = 10⁶）

## 四、主存储器的基本组成

### 📐 结构
```
   地址线 ──→ MAR ──→ 地址译码器 ──→ 存储体（存储矩阵）──→ 读写电路 ──→ MDR ←──→ 数据线
                                           ↑
                                       控制电路 ← 片选(CS)、读/写(WE)
```
- **存储体**：由大量存储元组成的矩阵
- **地址译码器**：把地址转换为对应存储单元的选通信号
- **读写电路**、**控制电路**

### 📐 地址译码方式
- **单译码（一维）**：n 位地址 → 2ⁿ 根选择线，一根选中一个单元。地址多时选择线太多
- **双译码（二维，重合法）**：把地址分为**行地址**和**列地址**，分别译码，**行选择线和列选择线交叉**的单元被选中
  - n 位地址（行列各 n/2 位）只需要 2^(n/2) + 2^(n/2) 根选择线，大大减少
  - ✏️ 例：1M 个单元，单译码需要 2²⁰ ≈ 100 万根线；双译码只需要 2¹⁰ + 2¹⁰ = 2048 根

### 📐 存储芯片的引脚（⭐ 计算题）
一个存储芯片的引脚包括：
- **地址线**：容量为 2ⁿ 个单元 → n 根（DRAM 用地址复用时减半）
- **数据线**：每个单元 b 位 → b 根
- **片选线 CS**（或 CE）：1 根，低电平有效时选中芯片
- **读写控制线**：WE（写使能）1 根，或者 OE（读）和 WE 各 1 根
- 电源、地线

✏️ 例：一个 **2K × 8 位**的 SRAM 芯片，地址线 **11** 根，数据线 **8** 根，加上片选 1 根、读写控制 1 根，共 **21** 根（不算电源和地）。

## 五、SRAM 与 DRAM（⭐⭐⭐）

### 📐 SRAM（静态随机存储器）
- 存储元是**双稳态触发器**（通常由 **6 个晶体管**组成）
- 只要不断电，信息就**一直保持**，**不需要刷新**
- **非破坏性读出**，读出后不需要再生
- 速度**快**，但集成度**低**（一位要 6 个管子）、功耗大、价格**高**
- 用于 **Cache**

### 📐 DRAM（动态随机存储器）
- 存储元是**电容 + 1 个晶体管**，用电容中是否有电荷表示 1 和 0
- 电容会**漏电**，电荷会逐渐消失 → 必须**定期刷新**
- **破坏性读出**：读出时电容放电，读完后需要**再生**（重新写回）
- 集成度**高**、功耗小、价格**低**，但速度比 SRAM **慢**
- 用于**主存**

### 📊 SRAM vs DRAM（⭐⭐⭐）
| 比较项 | SRAM | DRAM |
|---|---|---|
| 存储信息 | 触发器 | 电容 |
| 破坏性读出 | 否 | **是** |
| 读出后需要再生 | 不需要 | **需要** |
| 需要刷新 | 不需要 | **需要** |
| 送行列地址 | **同时送** | **分两次送（地址复用）** |
| 运行速度 | **快** | 慢 |
| 集成度 | 低 | **高** |
| 发热量 | 大 | 小 |
| 存储成本 | 高 | **低** |
| 用途 | **Cache** | **主存** |

📝 **真题（2020 年第 15 题）**：下列关于 TLB 和 Cache 的叙述中，**错误**的是：
A. 命中率都与程序局部性有关 ✓
B. 缺失后都需要去访问主存 ✓
C. 缺失处理都可以由硬件实现 ✓
D. **都由 DRAM 存储器组成** ✗——TLB 和 Cache 都要求速度快，都用 **SRAM**（TLB 还用相联存储器）
→ 选 **D**

### 📐 DRAM 的刷新（⭐⭐）
- **刷新周期**：对 DRAM 的所有存储单元恢复一次原状态的时间间隔，一般为 **2 ms**
- **以行为单位刷新**：每次刷新一行（该行所有单元同时刷新），所需时间 = 一个存取周期
- 刷新地址由 DRAM 内部的**刷新计数器**产生，**不需要 CPU 控制**，刷新时**不需要选片**（整个存储器所有芯片同时刷新）

**三种刷新方式**（设存取周期 0.5 μs，128 行，刷新周期 2 ms）：
| 方式 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **集中刷新** | 在一个刷新周期内，**集中一段时间**对所有行逐行刷新，此期间停止读写 | 读写时不受刷新影响 | 有 128 × 0.5 = 64 μs 的“**死区**”（不能访存） |
| **分散刷新** | 每个存取周期分成两半：前半读写，**后半刷新一行** | **没有死区** | 存取周期变长为 1 μs，速度减半；刷新过于频繁 |
| **异步刷新** | 把 128 次刷新**均匀分散**在 2 ms 内：每隔 2 ms / 128 ≈ 15.6 μs 刷新一行 | 死区很短（每次只有 0.5 μs） | — |
**异步刷新最常用**。还可以把刷新安排在 CPU 不访存的时间（如指令译码阶段），完全不影响速度。

### 📐 DRAM 的地址复用（⭐⭐ 常考陷阱）
DRAM 容量大，地址位数多。为了**减少芯片引脚数**，把地址分成**行地址**和**列地址**，通过**同一组引脚分两次送入**：
- 先送行地址，配合 **RAS**（行地址选通）信号
- 再送列地址，配合 **CAS**（列地址选通）信号
- **地址引脚数减为原来的一半**

✏️ 例：4M × 8 位的 DRAM 芯片，4M = 2²²，行列各 11 位 → 地址引脚只要 **11 根**（若是 SRAM 需要 22 根）

⚠️ DRAM 行列地址数一般**相等**（或接近），这样刷新的行数（= 2^行地址位数）较少。若行列不等，一般让**行数少**以减少刷新次数。

### 📐 行缓冲器（Row Buffer）
DRAM 芯片内有**行缓冲器**：读出时整行数据先读到行缓冲中（这正好也是对这一行的“再生/刷新”），再从中选出需要的列。连续访问同一行的数据时，只需要改列地址，速度快。

📝 **真题（2022 年第 17 题）**：某内存条包含 **8 个 8192 × 8192 × 8 位**的 DRAM 芯片，按字节编址，支持突发（burst）传送方式，对应存储器总线宽度为 64 位，每个 DRAM 芯片内有一个行缓冲区（row buffer）。下列关于该内存条的叙述中，**不正确**的是：
A. 内存条的容量为 512 MB
B. 采用多模块交叉编址方式
C. 芯片的地址引脚为 26 位
D. 芯片内行缓冲有 8192 × 8 位

逐项分析：
- A：每个芯片 8192 × 8192 = 2¹³ × 2¹³ = 2²⁶ 个单元，每单元 8 位（1 B）→ 64 MB；8 片共 **512 MB** ✓
- B：总线 64 位，8 个芯片**各提供 8 位**组成 64 位；连续的 8 个字节地址分布在 8 个不同芯片中 → 属于**多模块交叉编址** ✓
- C：芯片有 2²⁶ 个单元，但 DRAM 采用**地址复用**，行地址 13 位、列地址 13 位**分两次**送入 → 地址引脚只需 **13 根** ✗
- D：行缓冲存放一整行：一行 8192 个单元 × 8 位 = **8192 × 8 位** ✓
→ 选 **C**

### 📐 SDRAM 与 DDR（了解）
- **SDRAM（同步 DRAM）**：与系统时钟**同步**工作，CPU 发出地址和控制信号后可以去做别的事，不用等待
- **DDR SDRAM**：在时钟的**上升沿和下降沿各传送一次**数据，传输速率翻倍
- 支持**突发传送**：给出首地址后，连续传送多个数据（如一个 Cache 块）

## 六、只读存储器 ROM（⭐）

### 📐 特点
- **非易失性**：断电后信息不丢失
- 结构简单，集成度比 DRAM 还高，**也是随机存取的**
- 用途：存放固定不变的程序和数据，如 **BIOS**（开机自检和引导程序）、**微程序控制器的控制存储器**

### 📐 类型
| 类型 | 全称 | 写入方式 |
|---|---|---|
| MROM | 掩模式 ROM | 制造时写入，**不能修改** |
| PROM | 一次可编程 ROM | 用户可写入**一次** |
| EPROM | 可擦除可编程 ROM | 用**紫外线**擦除（全部擦除），可多次改写 |
| EEPROM（E²PROM） | 电可擦除可编程 ROM | 用**电**擦除，可**局部擦除** |
| **Flash** | 闪速存储器 | 在 EEPROM 基础上发展，**按块擦除**，速度快、集成度高、可多次改写 |

### 📐 Flash 与 SSD
- **Flash** 既有 ROM 的非易失性，又可以在线改写（像 RAM），但**写入比读慢得多**，**写前要擦除**，**擦写次数有限**
- **固态硬盘（SSD）**由 Flash 芯片构成（第 9 课详讲）
- U 盘、手机存储也用 Flash

⚠️ 现在的 ROM 大多**可以改写**（只是写入慢、不方便），名字里的“只读”是历史原因。

## ⚠️ 易错点
1. Cache—主存由**硬件**实现；主存—辅存由**硬件 + OS** 实现
2. **ROM 和 RAM 都是随机存取的**；磁盘是**直接存取**；TLB 是**相联存储器**
3. **存取周期 > 存取时间**
4. SRAM 用于 Cache，DRAM 用于主存；**TLB、Cache 都是 SRAM**
5. DRAM：要刷新、破坏性读出、**地址复用（引脚减半）**
6. 刷新**以行为单位**，不需要 CPU 参与，不需要选片
7. 集中刷新有死区；分散刷新无死区但速度减半；异步刷新最常用

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 层次 | 寄存器 > Cache > 主存 > 辅存；上层是下层的副本 |
| 存取方式 | RAM、ROM 随机；磁盘直接；磁带顺序；TLB 相联 |
| 存取周期 | = 存取时间 + 恢复时间 |
| SRAM | 触发器；不刷新；快；Cache |
| DRAM | 电容；刷新（2 ms，按行）；地址复用；主存 |
| 刷新方式 | 集中（有死区）、分散（无死区、慢）、异步（常用） |
| ROM | 非易失；随机存取；BIOS；Flash 按块擦除 |

## 🏋️ 课后练习

1. 某 SRAM 芯片容量为 16K × 4 位，它有多少根地址线、数据线？若是 DRAM 呢？
2. 某 DRAM 芯片内部是 256 × 256 的存储矩阵，刷新周期 2 ms，采用异步刷新，每隔多久刷新一行？
3. 存储器存取周期 100 ns，每次读 64 位，带宽是多少？
4. 下列存储器中，属于易失性存储器的是：A. EPROM B. Flash C. DRAM D. 磁盘
5. 为什么 DRAM 要采用地址复用技术，而 SRAM 一般不用？

<details>
<summary>📖 答案</summary>

1. 16K = 2¹⁴：SRAM 地址线 **14** 根，数据线 **4** 根；DRAM 地址复用：地址线 **7** 根，数据线 4 根
2. 2 ms / 256 ≈ **7.8 μs**
3. 8 B / 100 ns = **80 MB/s**
4. **C**
5. DRAM 容量大、集成度高，地址位数多，若不复用，芯片引脚太多；地址复用可使地址引脚减半。SRAM 容量较小且追求高速，分两次送地址会降低速度，所以一般不复用
</details>
