## 🚪 课前引入

前面我们学了：数据怎么表示（第 2~6 课）、存在哪里（第 7~12 课）、指令长什么样（第 13~15 课）。现在要揭开最核心的问题：**CPU 是怎么一条一条执行指令的？**

🧒 **把 CPU 想象成一个厨房**：
- **运算器**是“灶台和厨师的手”：负责真正的加工（加减乘除、与或非）
- **控制器**是“主厨的大脑”：看菜谱（取指令）、理解菜谱（译码）、指挥手下按步骤干活（发出控制信号）
- **寄存器**是“手边的小碗”：临时放正在处理的食材
- **主存**是“冰箱”：食材（数据）和菜谱（程序）都放在里面

CPU 做的事就是不断循环：**取指令 → 分析指令 → 执行指令 → 取下一条……**

## 一、CPU 的功能（⭐）

1. **指令控制**：控制程序中指令的执行**顺序**（取指令、确定下一条指令地址）
2. **操作控制**：一条指令要由若干个**操作信号**（微操作）完成，CPU 产生这些信号并送往相应部件
3. **时间控制**：对各种操作加以**时间上的控制**（什么时候做什么）
4. **数据加工**：对数据进行算术和逻辑运算
5. **中断处理**：处理运行过程中出现的异常和中断

其中 1~3 由**控制器**完成，4 由**运算器**完成。

## 二、CPU 的基本结构（⭐⭐）

```
┌──────────────────────── CPU ────────────────────────┐
│  ┌──────── 控制器 ────────┐   ┌──────── 运算器 ────────┐│
│  │ PC  程序计数器          │   │ ALU  算术逻辑单元       ││
│  │ IR  指令寄存器          │   │ 暂存寄存器              ││
│  │ ID  指令译码器          │   │ ACC  累加器             ││
│  │ 时序系统（时钟、节拍）   │   │ 通用寄存器组 GPRs       ││
│  │ 微操作信号发生器        │   │ PSW  程序状态字寄存器    ││
│  │ MAR 存储器地址寄存器    │   │ 移位器、计数器           ││
│  │ MDR 存储器数据寄存器    │   │                        ││
│  └───────────────────────┘   └────────────────────────┘│
└─────────────────────────────────────────────────────┘
               │ 地址总线   │ 数据总线   │ 控制总线
               ▼            ▼            ▼
                           主存
```

### 📐 运算器
**功能：对数据进行加工。**
| 部件 | 作用 |
|---|---|
| **ALU**（算术逻辑单元） | 完成算术运算和逻辑运算（**组合逻辑**电路） |
| **暂存寄存器** | 暂存从主存读来的数据，**对程序员不可见** |
| **ACC**（累加器） | 通用寄存器之一，暂存 ALU 运算的结果 |
| **通用寄存器组（GPRs）** | 如 EAX、EBX……存放操作数和地址，**对程序员可见** |
| **PSW**（程序状态字寄存器） | 保留运算结果的状态（**ZF、SF、OF、CF**）以及中断允许位等控制信息 |
| 移位器 | 移位运算 |
| 计数器 | 控制乘除运算的步数 |

### 📐 控制器
**功能：取指令、分析指令、执行指令（发出控制信号）。**
| 部件 | 作用 |
|---|---|
| **PC**（程序计数器） | 存放**下一条要执行的指令的地址**；有自增功能 |
| **IR**（指令寄存器） | 存放**当前正在执行的指令** |
| **ID**（指令译码器） | 对 IR 中的**操作码**进行译码，确定要做什么 |
| **MAR**（存储器地址寄存器） | 存放**要访问的主存单元的地址**，位数 = 地址线位数 |
| **MDR**（存储器数据寄存器） | 存放**从主存读出或要写入主存的数据**，位数 = 数据线位数（或存储字长） |
| **时序系统** | 产生各种时序信号（时钟、节拍），由统一时钟分频得到 |
| **微操作信号发生器** | 根据 IR 的内容、PSW 的状态和时序信号，产生**控制整个计算机的各种控制信号**；可以是**硬布线**或**微程序**实现 |

（MAR、MDR 在现代 CPU 中位于 CPU 内部，有的教材把它们归到存储器部分，考试中一般认为在 CPU 中。）

### 📐 哪些寄存器对程序员可见？（⭐⭐⭐）
| 可见（汇编程序员能直接或间接使用） | 不可见 |
|---|---|
| **通用寄存器**（含基址、变址寄存器、ACC） | **IR** |
| **PC**（转移指令可以改它） | **MAR、MDR** |
| **PSW / 标志寄存器** | **暂存寄存器** |
| **栈指针 SP** | **微指令寄存器 μIR、微地址寄存器 μAR** |

📝 **真题（2025 年第 19 题）**：下列关于 CPU 中的数据通路和控制器的叙述中，**错误**的是：
A. 通用寄存器组中应该包含程序计数器　B. 控制器中一定包含指令操作码的译码电路　C. 单周期 CPU 中的控制器比多周期 CPU 中的更简单　D. 流水线 CPU 需解决数据相关和控制相关等冒险问题
→ **A**。PC 是**控制器**中的专用寄存器，不属于通用寄存器组（x86 的 EIP 不能像 EAX 那样随便用作运算操作数）。
- C 是对的：单周期 CPU 一条指令一个周期完成，控制信号在整个周期保持不变，只需根据操作码**组合逻辑**产生；多周期 CPU 要按节拍发出不同信号，需要**有限状态机**，更复杂

## 三、指令周期、机器周期、时钟周期（⭐⭐⭐）

### 📐 三个“周期”
1. **时钟周期（节拍、T 周期）**：CPU 中**最小的时间单位**，= 1 / 主频。一个时钟周期内完成一个或几个**微操作**
2. **机器周期（CPU 周期）**：完成一个**基本操作**（如取指令、读一次存储器、执行一次运算）所需的时间，由若干个时钟周期组成。通常以**访问一次主存的时间**为基准
3. **指令周期**：CPU **从主存取出一条指令并执行完这条指令**的全部时间，由若干个机器周期组成

```
指令周期
├── 机器周期 1（取指周期）
│     ├── T1  T2  T3  T4        ← 时钟周期（节拍）
├── 机器周期 2（执行周期）
│     ├── T1  T2  T3  T4
```

### 📐 不同指令的指令周期不同
- **无条件转移指令** JMP X：取指后，执行阶段只需把 X 送 PC（不访存）→ 可能只要 **1 个机器周期**（取指）+ 很短的执行
- **加法指令** ADD X（直接寻址）：取指周期 + 执行周期（取操作数、运算）→ **2 个机器周期**
- **间接寻址的加法指令** ADD @X：取指 + **间址** + 执行 → **3 个机器周期**
- 有中断请求时还要加一个**中断周期**

### 📐 CPI 与性能（复习第 1 课）
- **CPI**：执行一条指令平均需要的**时钟周期数**
- CPU 执行时间 = 指令条数 × CPI × 时钟周期 = 指令条数 × CPI / 主频
- **MIPS** = 主频 / (CPI × 10⁶)

📝 **真题（2022 年第 12 题）**：某计算机主频为 1GHz，程序 P 运行过程中，共执行了 10000 条指令，其中，80% 的指令执行平均需 1 个时钟周期，20% 的指令执行平均需 10 个时钟周期。程序 P 的平均 CPI 和 CPU 执行时间分别是：A. 2.8, 28μs　B. 28, 28μs　C. 2.8, 28ms　D. 28, 28ms
- CPI = 0.8 × 1 + 0.2 × 10 = **2.8**
- 时间 = 10000 × 2.8 × 1ns = 28000ns = **28μs** → 选 **A**

📝 **真题（2023 年第 12 题）**：若机器 M 的主频为 1.5GHz，在 M 上执行程序 P 的指令条数为 5 × 10⁵，P 的平均 CPI 为 1.2，则 P 在 M 上的指令执行速度和用户 CPU 时间分别为：A. 0.8GIPS, 0.4ms　B. 0.8GIPS, 0.4μs　C. 1.25GIPS, 0.4ms　D. 1.25GIPS, 0.4μs
- 速度 = 1.5G / 1.2 = **1.25 GIPS**（每秒 12.5 亿条指令）
- 时间 = 5 × 10⁵ × 1.2 / (1.5 × 10⁹) = 6 × 10⁵ / 1.5 × 10⁹ = 4 × 10⁻⁴ s = **0.4ms** → 选 **C**

## 四、指令周期的 4 个阶段与数据流（⭐⭐⭐）

### 📐 四个工作周期
| 周期 | 做什么 | 标志触发器 |
|---|---|---|
| **取指周期** | 从主存取出指令送 IR，PC 指向下一条指令 | FE |
| **间址周期** | 取操作数的**有效地址**（只有间接寻址才需要） | IND |
| **执行周期** | 取操作数、执行运算、存结果 | EX |
| **中断周期** | 保存断点，转入中断服务程序 | INT |

CPU 用 4 个**标志触发器** FE、IND、EX、INT 来区分当前处于哪个周期（同一时刻只有一个为 1）。

🧒 为什么需要区分？**指令和数据都放在主存中**（冯·诺依曼结构），外表看都是 0 和 1。**CPU 就是根据当前所处的周期来区分**：取指周期从主存取出来的是**指令**，执行周期取出来的是**数据**。

```
          ┌──────────┐
     ┌───►│ 取指周期  │
     │    └────┬─────┘
     │         │ 是间接寻址？
     │    是 ┌─┴─┐ 否
     │       ▼   │
     │  ┌────────┐│
     │  │ 间址周期││
     │  └───┬────┘│
     │      ▼     ▼
     │    ┌──────────┐
     │    │ 执行周期  │
     │    └────┬─────┘
     │         │ 有中断请求？
     │    否 ┌─┴─┐ 是
     │       │   ▼
     │       │ ┌──────────┐
     │       │ │ 中断周期  │
     │       │ └────┬─────┘
     └───────┴──────┘
```

### 📐 取指周期的数据流（⭐⭐⭐ 必须会默写）
```
① (PC) → MAR          ; 把指令地址送到 MAR
② MAR → 地址总线 → 主存
③ CU 发出读命令 → 控制总线 → 主存（1 → R）
④ 主存 M(MAR) → 数据总线 → MDR   ; 读出指令
⑤ (MDR) → IR          ; 指令送 IR
⑥ CU 发出控制信号，(PC) + 1 → PC   ; 形成下一条指令地址
```
简写成微操作：
```
PC → MAR
M(MAR) → MDR
MDR → IR
(PC) + 1 → PC
```
（“+1”指的是加一条指令的长度，按字节编址、4 字节指令就是 +4。）

### 📐 间址周期的数据流
取出操作数的**有效地址**：
```
Ad(IR) → MAR          ; 指令中的形式地址送 MAR（或 Ad(MDR) → MAR）
M(MAR) → MDR          ; 读出有效地址
MDR → Ad(IR)          ; 有效地址替换 IR 中的形式地址
```
间址周期结束后，IR 的地址字段里就是**有效地址 EA** 了，执行周期就像直接寻址一样。

### 📐 执行周期
**不同指令的执行周期操作不同**，没有统一的数据流。例：ADD X（ACC + (X) → ACC）：
```
Ad(IR) → MAR
M(MAR) → MDR
(ACC) + (MDR) → ACC
```

### 📐 中断周期的数据流（⭐⭐）
执行完一条指令后，若有中断请求（且允许中断），进入中断周期，由**硬件**完成：
```
① 关中断（中断允许触发器 IF ← 0）
② 保存断点：
   (SP) − 1 → SP          ; 栈顶指针减 1（若按字节编址、32 位则减 4）
   SP → MAR
   PC → MDR               ; 断点（返回地址）
   MDR → M(MAR)           ; 写入栈
③ 中断服务程序入口地址（向量地址）→ PC
```
这三件事由**硬件**完成，叫**中断隐指令**（不是真正的指令，指令系统里没有它）。第 19 课会详细讲。

## 五、指令执行方案（⭐）

### 📐 单周期处理器
- **每条指令都在一个时钟周期内完成**，CPI = 1
- 时钟周期**以最慢的指令为准**（如 Load 指令），所以时钟周期很长
- 指令之间**串行**执行
- 同一个部件在一条指令中不能用两次（比如要同时取指和访问数据 → 需要分离的指令存储器和数据存储器）

### 📐 多周期处理器
- 一条指令分成**多个阶段**，每个阶段一个时钟周期，**不同指令用不同的周期数**
- 时钟周期以**最复杂的阶段**为准，比单周期短
- 部件可以在不同周期被重复使用（如 ALU 既算 PC+4 又算数据）
- 指令之间仍是串行的

### 📐 流水线处理器
- 多条指令**重叠执行**，理想情况下 CPI ≈ 1，时钟周期短
- 第 18 课详细讲

📝 **2025 年第 18 题**考过：“单周期 CPU 的时钟周期以最耗时指令所用的时间为准”——**正确**；“流水线 CPU 的时钟周期以最长流水段所用时间为准”——**正确**；“不同类型指令的 CPI 可能不一样”——正确；“程序的 CPI 与 Cache 缺失率无关”——**错误**（选 B）。

## 六、控制方式（了解）

| 方式 | 说明 |
|---|---|
| **同步控制** | 所有操作由**统一的时钟**控制，每个操作时间固定。简单，但以最慢操作为准，浪费时间 |
| **异步控制** | 不用统一时钟，各操作按需要的时间进行，用**应答（握手）**信号联系。效率高但控制复杂 |
| **联合控制** | 大部分操作同步，少数时间不定的操作（如 I/O）异步 |

## ⚠️ 易错点

1. **PC 存的是下一条指令的地址**；IR 存的是当前指令
2. **PC 不属于通用寄存器组**（2025 年第 19 题）
3. MAR、MDR、IR、暂存寄存器**对程序员不可见**；PSW、通用寄存器、PC 可见
4. **时钟周期 < 机器周期 < 指令周期**
5. 取指周期数据流：PC → MAR → 读 → MDR → IR，PC + 1
6. 间址周期只有**间接寻址**的指令才有
7. CPU 区分指令和数据的依据是**所处的指令周期阶段**（取指周期取出的是指令）
8. 中断周期的操作由**硬件**（中断隐指令）完成：关中断、保存断点、送入口地址
9. 单周期 CPU 的 CPI = 1，时钟周期最长

## 🏋️ 课后练习

1. 下列哪些寄存器对汇编程序员透明（不可见）：PC、IR、MAR、MDR、PSW、ACC、通用寄存器、暂存寄存器？
2. 冯·诺依曼计算机中，指令和数据都以二进制形式存放在存储器中，CPU 区分它们的依据是什么？
3. 写出指令 `ADD @X`（(ACC) + ((X)) → ACC，一次间接寻址）的完整执行过程（取指、间址、执行三个周期的微操作）。
4. 某 CPU 主频 2GHz，一个机器周期含 4 个时钟周期，某指令需要 3 个机器周期。求该指令的执行时间。
5. 若程序 A 的指令条数是程序 B 的 1.2 倍，但 A 的 CPI 是 B 的 0.75 倍，在同一台机器上谁更快？

<details>
<summary>📖 答案</summary>

1. 不可见：**IR、MAR、MDR、暂存寄存器**
2. **根据指令周期的不同阶段**：取指周期从主存取出的是指令，执行周期（或间址周期）取出的是数据（或地址）
3. 取指：PC→MAR；M(MAR)→MDR；MDR→IR；(PC)+1→PC。间址：Ad(IR)→MAR；M(MAR)→MDR；MDR→Ad(IR)。执行：Ad(IR)→MAR；M(MAR)→MDR；(ACC)+(MDR)→ACC
4. 时钟周期 0.5ns，机器周期 2ns，指令 **6ns**
5. 时间比 A/B = 1.2 × 0.75 = 0.9 < 1，**A 更快**
</details>
