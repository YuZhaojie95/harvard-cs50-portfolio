> 3. 会求**有效地址 EA**、操作数、**访存次数**

>
> 真题：2023 年第 17 题、2023 年第 44 题第 2、3 问、2020 年第 16 题、2021 年第 17 题、2009 年真题、2011 年真题、2013 年真题……

## 🚪 课前引入

上节课我们说，指令里的“地址码”告诉 CPU 操作数在哪里。但**地址码可能只有 6 位、8 位**，而主存有 4GB（32 位地址），怎么用 8 位去表示 32 位的地址？

答案是：**地址码里放的不一定是“最终地址”**，而是“**找到最终地址的线索**”。

🧒 **寻宝游戏**：
- 纸条上直接写着宝藏：“**宝藏就是 100 元**” → **立即寻址**（操作数就在指令里）
- 纸条上写“**宝藏在 3 号柜子**” → **直接寻址**
- 纸条上写“**去 3 号柜子，里面有另一张纸条告诉你宝藏在哪**” → **间接寻址**
- 纸条上写“**从你现在站的位置往前走 5 步**” → **相对寻址**
- 纸条上写“**从 A 同学手里的号码开始数，往后第 5 个柜子**” → **基址 / 变址寻址**

这些“找东西的方法”就是**寻址方式**。

## 一、基本概念

### 📐 形式地址与有效地址
- **形式地址 A**：指令地址码字段中给出的地址（“线索”）
- **有效地址 EA**（Effective Address）：操作数在主存中的**真实地址**（此处指逻辑地址，还要经过虚实转换）
- 用 **(X)** 表示“X 中的内容”：(A) 是主存地址 A 单元的内容，(R) 是寄存器 R 的内容

### 📐 两大类寻址
1. **指令寻址**：找**下一条要执行的指令**的地址
2. **数据寻址**：找**本条指令的操作数**的地址

### 📐 指令格式中怎么知道用哪种寻址方式？
- 在指令中设一个**寻址特征（寻址方式）字段**，如 2 位可表示 4 种方式
- 或者由**操作码隐含**（如某些操作码固定使用某种寻址）

📝 **真题（2023 年第 17 题）**：某运算类型指令中有一个地址码为通用寄存器编号，对应通用寄存器中存放的是操作数或操作数地址，CPU 区分两者的依据是：
A. 操作数的寻址方式　B. 操作数的编码方式　C. 通用寄存器的编号　D. 通用寄存器的内容
→ **A**。寄存器里放的是操作数（**寄存器寻址**）还是操作数地址（**寄存器间接寻址**），CPU 是根据指令中的**寻址方式**来区分的。寄存器里的 0 和 1 本身看不出是数据还是地址。

## 二、指令寻址

### 📐 顺序寻址
**PC 自动增加**，指向下一条指令：
- 按字节编址、指令长 4 字节：PC ← PC + 4
- 按字节编址、变长指令：PC ← PC + 当前指令的长度
- 按字编址、单字长指令：PC ← PC + 1

### 📐 跳跃寻址
由**转移指令**给出下一条指令地址：
- **直接给出目标地址**（绝对转移）：PC ← A
- **相对转移**：PC ← PC + 偏移量（见“相对寻址”）
- PC 可以被**部分替换**（如 2021 年第 43 题的 J 型：PC 的低 10 位 ← target）

## 三、数据寻址（⭐⭐⭐）

下面逐个讲解。为了统一，假设主存和寄存器的内容如下：

| 位置 | 内容 |
|---|---|
| 主存地址 100 | 200 |
| 主存地址 200 | 300 |
| 主存地址 300 | 400 |
| 主存地址 1100 | 500 |
| 寄存器 R1 | 100 |
| 变址寄存器 IX | 1000 |
| 基址寄存器 BR | 1000 |
| PC（已指向下一条指令） | 1000 |

指令中形式地址 **A = 100**。

### 1. 立即寻址
```
| OP | 立即数方式 | 操作数 |
```
- **地址码字段就是操作数本身**，叫**立即数**（通常用补码）
- 操作数 = **A = 100**
- 访存次数（取指后）：**0 次**
- ✅ 最快；❌ 立即数的范围受地址码位数限制，只能是常数
- 例：`mov eax, 10`；2023 年第 44 题中 `mov [...], 0Ah` 的**源操作数 0Ah** 就是立即寻址

### 2. 直接寻址
- **EA = A**，操作数 = (A)
- EA = 100，操作数 = (100) = **200**
- 访存 **1 次**
- ❌ 寻址范围受 A 的位数限制（2020 年第 16 题：8 位地址码 → 0~255）

### 3. 间接寻址（一次间接）
- **EA = (A)**，操作数 = ((A))
- EA = (100) = 200，操作数 = (200) = **300**
- 访存 **2 次**（一次取地址，一次取操作数）；多次间接则更多
- ✅ 扩大寻址范围（主存单元的字长比地址码长）；便于子程序返回
- ❌ 慢

### 4. 寄存器寻址
- 地址码是**寄存器编号 Ri**，**操作数 = (Ri)**
- 操作数 = (R1) = **100**
- 访存 **0 次**
- ✅ **快**（寄存器在 CPU 内部），**地址码位数少**（8 个寄存器只要 3 位）
- RISC 的运算指令都用寄存器寻址

### 5. 寄存器间接寻址
- **EA = (Ri)**，操作数 = ((Ri))
- EA = (R1) = 100，操作数 = (100) = **200**
- 访存 **1 次**（比一般间接寻址少一次）
- 例：x86 的 `mov eax, [ebx]`；C 语言中通过指针访问 `*p`

### 6. 相对寻址（⭐⭐⭐）
- **EA = (PC) + A**，A 是**有符号的偏移量**（补码），可正可负
- EA = 1000 + 100 = 1100，操作数 = (1100) = **500**
- 主要用于**转移指令**：转移目标地址 = (PC) + 偏移量
- ✅ 程序在主存中**浮动**（整体搬到别的地址）时，相对位置不变，指令不用修改 → 便于**程序浮动/可重定位**
- ⚠️ **关键：(PC) 是“已经指向下一条指令”的值**，即当前指令地址 + 当前指令长度

### 7. 基址寻址
- **EA = (BR) + A**，BR 是**基址寄存器**
- EA = 1000 + 100 = 1100，操作数 = **500**
- 特点：**BR 的内容由操作系统（或管理程序）确定**，程序执行过程中**不变**；**A 是偏移量**，可变
- 🧒 “基址”就是一个“起点”，由系统安排；程序里写的是相对起点的偏移
- 用途：**多道程序**中实现程序重定位；**扩大寻址范围**（BR 位数多）
- x86 中用 **EBP**（栈帧基址）+ 偏移访问局部变量：`mov eax, [ebp - 8]`（2023 年第 44 题第 1 条指令 `mov [ebp-8], 0` 就是给局部变量 i 赋 0）

### 8. 变址寻址
- **EA = (IX) + A**，IX 是**变址寄存器**
- EA = 1000 + 100 = 1100，操作数 = **500**
- 特点：**A 是基准地址（不变）**，**IX 的内容由用户（程序）改变**（如每次循环 +1）
- 用途：**处理数组**！A 是数组首地址，IX 是下标（或下标 × 元素大小）
- 🧒 和基址寻址公式一模一样，区别在于**谁变谁不变**：
  - 基址：寄存器（起点）不变，A（偏移）变
  - 变址：A（数组首地址）不变，寄存器（下标）变

### 9. 堆栈寻址
- 操作数在**栈**中，由**栈指针 SP** 隐含指出
- **硬堆栈**：用一组寄存器做栈；**软堆栈**：在主存中划一块区域做栈（常用）
- x86 中栈**从高地址向低地址增长**：
  - **PUSH**：先 SP ← SP − 4，再 (SP) ← 数据
  - **POP**：先 数据 ← (SP)，再 SP ← SP + 4
- 零地址指令的操作数就在栈中

### 10. 基址加比例变址寻址（x86，⭐⭐）
- **EA = (基址寄存器) + (变址寄存器) × 比例因子 + 偏移量**
- 比例因子 = 1、2、4、8（对应 char、short、int、double 数组）
- 例：`mov eax, [ebx + esi*4 + 8]`

### 📐 汇总表（⭐⭐⭐ 背下来）

| 寻址方式 | 有效地址 EA | 访存次数（取操作数） | 用途/特点 |
|---|---|---|---|
| 立即 | 无（操作数 = A） | 0 | 常数，最快 |
| 直接 | A | 1 | 简单，范围小 |
| 一次间接 | (A) | 2 | 扩大范围，慢 |
| 寄存器 | 无（操作数 = (R)） | 0 | 快，地址码短 |
| 寄存器间接 | (R) | 1 | 指针 |
| 相对 | (PC) + A | 1 | 转移指令，程序浮动 |
| 基址 | (BR) + A | 1 | 多道程序重定位，BR 由 OS 定 |
| 变址 | (IX) + A | 1 | 数组，IX 由用户改 |
| 堆栈 | (SP) | 1（软堆栈） | 子程序调用、零地址指令 |

📐 **偏移寻址**：相对、基址、变址三种都是“**寄存器内容 + 形式地址**”，统称**偏移寻址**。

📝 **真题（2011 年真题）**：偏移寻址通过将某个寄存器内容与一个形式地址相加而生成有效地址。下列寻址方式中，**不属于**偏移寻址方式的是：A. 间接寻址　B. 基址寻址　C. 相对寻址　D. 变址寻址
→ **A**

📝 **真题（2013 年真题）**：假设变址寄存器 R 的内容为 1000H，指令中的形式地址为 2000H；地址 1000H 中的内容为 2000H，地址 2000H 中的内容为 3000H，地址 3000H 中的内容为 4000H，则**变址寻址**方式下访问到的操作数是：A. 1000H　B. 2000H　C. 3000H　D. 4000H
- EA = (R) + A = 1000H + 2000H = **3000H**
- 操作数 = (3000H) = **4000H** → 选 **D**

## 四、相对寻址专题（⭐⭐⭐）

### 📐 关键：PC 什么时候加？
CPU 执行一条指令时，**取指令结束后 PC 就已经指向下一条指令**了。所以相对寻址计算时用的 (PC) 是：
```
(PC) = 当前指令地址 + 当前指令长度
```
**转移目标地址 = 当前指令地址 + 当前指令长度 + 偏移量**

📝 **真题（2009 年真题）**：某机器字长 16 位，主存按字节编址，转移指令采用相对寻址，由两个字节组成，第一字节为操作码字段，第二字节为相对位移量字段。假定取指令时，每取一个字节 PC 自动加 1。若某转移指令所在主存地址为 **2000H**，相对位移量字段的内容为 **06H**，则该转移指令成功转移后的目标地址是：A. 2006H　B. 2007H　C. 2008H　D. 2009H
- 取完这条 2 字节指令后，PC = 2000H + 2 = 2002H
- 目标 = 2002H + 06H = **2008H** → 选 **C**

### 📐 偏移量为负数
偏移量用**补码**表示，往回跳（如循环）时是负数。
✏️ 某 2 字节转移指令地址 3008H，偏移量为 **F0H**（8 位补码），目标地址？
- F0H = −16（1111 0000 → 取反加 1 → 0001 0000 = 16）
- 目标 = 3008H + 2 − 16 = 300AH − 10H = **2FFAH**

### 📝 真题（2023 年第 44 题第 2 问）
部分机器级代码（每行依次为：指令序号、虚拟地址、机器指令、汇编指令）：
```
1   00401072  C7 45 F8 00 00 00 00   mov  [ebp-8], 0
2   00401079  EB 09                  jmp  00401084h
3   0040107B  8B 55 F8               mov  eax, [ebp-8]
    ......
7   00401088  7D 32                  jge  004010bch
8   0040108A  C7 45 FC 00 00 00 00   mov  [ebp-4], 0
    ......
19  004010AE  C7 84 82 00 20 42 00 0A 00 00 00   mov [ecx+edx*4+00422000h], 0Ah
20  ......
```
> 已知第 2 条 jmp 和第 7 条 jge 都是跳转指令，其操作码分别是 EBH 和 7DH，跳转目标地址分别为 0040 1084H 和 0040 10BCH，这两条指令采用什么寻址方式？请给出第 2 条指令 jmp 的跳转目标地址计算过程。

- jmp 指令：机器码 **EB 09**，2 字节，操作码 EBH，偏移量 **09H**
- 如果是直接寻址，目标地址应该出现在机器码中，但机器码里只有 09H → 说明是**相对寻址**
- 计算：jmp 的地址 0040 1079H，长 2 字节 → (PC) = 0040 107BH；目标 = 0040 107BH + 09H = **0040 1084H** ✓
- jge 同理：0040 1088H + 2 + 32H = 0040 108AH + 32H = **0040 10BCH** ✓
- **两条指令都采用相对寻址**

### 📝 真题（2023 年第 44 题第 1、3 问）
> (1) 第 20 条指令的虚拟地址是多少？
- 第 19 条指令地址 0040 10AEH，机器码 C7 84 82 00 20 42 00 0A 00 00 00 共 **11 字节**
- 第 20 条地址 = 0040 10AEH + 0BH = **0040 10B9H**

> (3) 已知第 19 条 mov 指令的功能是“a[i][j] ← 10”，其中 ecx 和 edx 为寄存器名，0042 2000H 是数组 a 的首地址，指令中源操作数采用什么寻址方式？已知 edx 中存放的是变量 j，ecx 中存放的是什么？根据该指令的机器码判断计算机 M 采用的是大端还是小端方式？
- **源操作数 0Ah：立即寻址**
- 目的操作数：EA = (ecx) + (edx) × 4 + 0042 2000H，是**基址加比例变址寻址**
- a[i][j] 的地址 = 首地址 + (i × 64 + j) × 4 = 0042 2000H + **i × 256** + j × 4
  - edx = j，比例因子 4 → j × 4 ✓
  - 所以 **ecx 中存放的是 i × 256**（即 i × 64 × 4，第 i 行的起始偏移）
- 机器码中位移量 0042 2000H 存为 00 20 42 00、立即数 0000 000AH 存为 0A 00 00 00 → 低位字节在低地址 → **小端方式**

## 五、哪些寄存器对程序员可见？（⭐⭐）

- **汇编程序员可见**：通用寄存器、**基址寄存器、变址寄存器**、**标志寄存器（程序状态字 PSW）**、PC（通过转移指令间接修改）、栈指针 SP
- **不可见**：**指令寄存器 IR**、**MAR、MDR**、**微指令寄存器**、暂存寄存器

📝 **真题（2021 年第 17 题）**：下列寄存器中，汇编语言程序员可见的是：I. 指令寄存器　II. 微指令寄存器　III. 基址寄存器　IV. 标志/状态寄存器
A. 仅 I、II　B. 仅 I、IV　C. 仅 II、IV　D. 仅 III、IV
→ **D**

## ⚠️ 易错点

1. **立即寻址和寄存器寻址不访存**（取指令之外）
2. 一次间接寻址访存 **2 次**；寄存器间接只访存 **1 次**
3. 相对寻址：**(PC) 已经是下一条指令的地址**；偏移量是**补码**
4. 基址 vs 变址：公式相同；**基址寄存器由 OS 设定不变，面向系统**；**变址寄存器由用户改变，面向用户（数组）**
5. 寄存器中是操作数还是地址，由**寻址方式**区分
6. IR、MAR、MDR 对程序员**不可见**
7. 变长指令：下一条指令地址 = 当前地址 + 当前指令长度（要数字节数）
8. 按字编址时，PC + 1 表示下一个字；按字节编址时 PC + 指令字节数

## 📋 本课小结

| 寻址 | 公式 | 一句话 |
|---|---|---|
| 立即 | 操作数 = A | 数就在指令里 |
| 直接 | EA = A | 地址在指令里 |
| 间接 | EA = (A) | 地址的地址 |
| 寄存器 | 操作数 = (R) | 数在寄存器 |
| 寄存器间接 | EA = (R) | 地址在寄存器（指针） |
| 相对 | EA = (PC) + A | 转移，程序浮动 |
| 基址 | EA = (BR) + A | 起点由 OS 定 |
| 变址 | EA = (IX) + A | 数组下标 |
| 堆栈 | EA = (SP) | 后进先出 |

## 🏋️ 课后练习

1. 设 (R1) = 2000H，主存 (2000H) = 3000H，(3000H) = 4000H，(4000H) = 5000H，形式地址 A = 3000H。求下列寻址方式的操作数：(a) 立即；(b) 直接；(c) 间接；(d) 寄存器（R1）；(e) 寄存器间接（R1）；(f) 变址（变址寄存器 R1）。
2. 某计算机按字节编址，转移指令 3 字节（1 字节操作码 + 2 字节偏移量），相对寻址。指令地址 1000H，偏移量 FFF0H，求转移目标地址。
3. 某相对转移指令位于地址 2468H，长 4 字节，要转移到 2400H，偏移量应为多少（用 16 位补码十六进制表示）？
4. 下列哪种寻址方式最适合访问数组元素？哪种最适合实现程序重定位？哪种最适合转移指令？
5. 分析：`for (i = 0; i < n; i++) sum += a[i];` 编译后，访问 a[i] 通常用什么寻址方式？sum 在寄存器中，`sum += ...` 这条指令的目的操作数用什么寻址方式？

<details>
<summary>📖 答案</summary>

1. (a) **3000H**；(b) (3000H) = **4000H**；(c) EA = (3000H) = 4000H，操作数 = **5000H**；(d) **2000H**；(e) (2000H) = **3000H**；(f) EA = 2000H + 3000H = 5000H，操作数 = (5000H)，题中未给出（需要该单元内容）
2. (PC) = 1000H + 3 = 1003H；FFF0H = −16；目标 = 1003H − 10H = **0FF3H**
3. 偏移量 = 2400H − (2468H + 4) = 2400H − 246CH = −6CH；16 位补码：10000H − 6CH = **FF94H**
4. 数组：**变址寻址**（或基址加比例变址）；重定位：**基址寻址**（相对寻址也便于程序浮动）；转移指令：**相对寻址**
5. a[i]：**变址寻址**（首地址为形式地址 A，下标×4 在变址寄存器）或基址加比例变址；sum：**寄存器寻址**
</details>
