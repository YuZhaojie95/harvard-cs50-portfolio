# 408 计算机学科专业基础 · 零基础完整版课程

> 这是一套**像老师上课一样**、从零讲起的 408 完整课程：每一课都包含 🎯 本课目标、🚪 课前引入、🧒 大白话讲解、📐 正式定义、✏️ 例题、📝 **真题精讲**、⚠️ 易错点、📋 小结和 🏋️ 课后练习（附答案）。
> 你上传的 **2020、2021、2022、2023、2025 年** 五套真题的**每一道题**（选择题 + 大题）都在课程中讲到了，见 [真题考点索引](05-真题与冲刺/01-真题考点索引.md)。

## 📖 怎么使用

1. **第一次学**：从 [课程导学](00-导学与预备/00-课程导学.md) 开始，按顺序一课一课往下学（每课末尾都有“下一课”链接）
2. **做真题**：学完后按 [复习计划](05-真题与冲刺/03-复习计划.md) 做五套真题，用 [真题考点索引](05-真题与冲刺/01-真题考点索引.md) 批改并回到对应课程
3. **考前**：看 [考前速记](05-真题与冲刺/04-考前速记.md) 和 [大题答题模板](05-真题与冲刺/02-大题答题模板.md)
4. 仓库中的 [`408-tutorial/`](../408-tutorial/) 是**精简版**，适合学完完整版后快速复习
