## 🚪 课前引入：程序就是“菜谱”

计算机很笨，你必须**一步一步**告诉它做什么。程序就是写给计算机的**菜谱**：
```
1. 准备 2 个碗，分别叫 a 和 b
2. 在 a 里放 3 个鸡蛋，b 里放 5 个鸡蛋
3. 准备一个大碗 sum，把 a 和 b 的鸡蛋都倒进去
4. 告诉我 sum 里有几个鸡蛋
```
写成 C 语言就是：
```c
#include <stdio.h>          // 引入“输入输出工具箱”

int main() {                // 程序从 main 开始执行
    int a = 3, b = 5;       // 准备两个装整数的“碗”
    int sum = a + b;        // 相加
    printf("%d\n", sum);    // 输出：8
    return 0;               // 程序结束
}
```

## 一、程序的基本结构

```c
#include <stdio.h>     // ① 预处理指令：引入头文件（别人写好的工具）
#include <stdlib.h>    //    malloc、free 在这里

#define MAX 100        // ② 宏定义：以后程序里的 MAX 都会被替换成 100

int g = 0;             // ③ 全局变量：整个程序都能用

int add(int x, int y) { // ④ 自己定义的函数
    return x + y;
}

int main() {           // ⑤ 主函数：程序的入口，一定从这里开始执行
    int s = add(1, 2); //    局部变量：只在 main 里能用
    printf("%d\n", s);
    return 0;
}
```

几个规则：
- 每条语句以**分号 `;`** 结尾
- `{ }` 包起来的是一个**代码块**
- `//` 是单行注释，`/* ... */` 是多行注释（注释不会执行，是写给人看的）
- C 语言**区分大小写**：`sum` 和 `Sum` 是两个不同的名字

## 二、变量和数据类型

### 🧒 大白话
**变量**就是一个**贴了名字标签的盒子**，里面可以放东西，东西可以换。
**数据类型**规定了盒子**能装什么、有多大**。

### 📐 基本数据类型（32 位/64 位机常见大小）
| 类型 | 装什么 | 常见大小 | 范围（有符号时） |
|---|---|---|---|
| `char` | 一个字符（本质是小整数） | 1 字节 | −128 ~ 127 |
| `short` | 短整数 | 2 字节 | −32768 ~ 32767 |
| `int` | 整数 | 4 字节 | −2³¹ ~ 2³¹ − 1 |
| `long` | 长整数 | 4 或 8 字节 | |
| `long long` | 更长的整数 | 8 字节 | −2⁶³ ~ 2⁶³ − 1 |
| `float` | 单精度小数 | 4 字节 | 约 7 位有效数字 |
| `double` | 双精度小数 | 8 字节 | 约 16 位有效数字 |

加 `unsigned` 就变成**无符号**（只能表示非负数）：`unsigned int` 范围 0 ~ 2³² − 1。

> 🔗 **和组成原理的联系**：int 用**补码**存（组成原理第 3 课），float 用 **IEEE 754** 存（第 5 课），`short → int` 会发生**符号扩展**（第 6 课）。2025 年第 12 题（`short si = -32767; unsigned int ui = si;`）就考这个。

### 变量的定义和初始化
```c
int a;            // 定义，没有初始化：局部变量里面是“垃圾值”（随机的）
int b = 10;       // 定义并初始化
int x = 1, y = 2; // 一次定义多个
const int N = 5;  // 常量，不能再修改
char c = 'A';     // 字符用单引号，本质存的是 65
```

### `sizeof`：看看盒子多大
```c
sizeof(int)     // 4
sizeof(char)    // 1
sizeof(double)  // 8
```

## 三、运算符（⭐ 细节很多）

### 3.1 算术运算符：`+ - * / %`

**⚠️ 整数除法会截断小数部分（向 0 取整）**：
```c
7 / 2     // 3，不是 3.5！
-7 / 2    // -3
7.0 / 2   // 3.5（有一个是小数，结果就是小数）
```
**`%` 取余数**（只能用于整数）：
```c
7 % 2     // 1  → 判断奇偶：x % 2 == 0 是偶数
17 % 5    // 2
-7 % 2    // -1（C 语言里余数的符号和被除数相同）
```
**两个超级常用的技巧**：
```c
x % 10      // 取 x 的个位数字
x / 10      // 去掉 x 的个位数字
// 循环队列：rear = (rear + 1) % MaxSize;  到了末尾就绕回 0
// 散列函数：H(key) = key % p;
```

### 3.2 赋值与自增自减
```c
a = 5;       // 把 5 放进 a（注意：= 是“放进去”，不是“相等”）
a += 3;      // a = a + 3
a -= 3;  a *= 2;  a /= 2;  a %= 3;

i++;         // i 加 1
++i;         // i 加 1
```
**`i++` 和 `++i` 的区别**（单独一行时没区别，放在表达式里才有区别）：
```c
int i = 5;
int x = i++;   // 先用后加：x = 5，然后 i 变成 6
int j = 5;
int y = ++j;   // 先加后用：j 先变成 6，y = 6
```
🧒 记忆：**`i++` 是“先拿走再补货”，`++i` 是“先补货再拿走”**。
栈的代码经常这样写：`S.data[++S.top] = x;`（top 先加 1 再放入）和 `x = S.data[S.top--];`（先取出再减 1）。

### 3.3 关系运算符和逻辑运算符
```c
==  !=  >  <  >=  <=     // 结果是 1（真）或 0（假）
&&   // 逻辑与：两个都真才真
||   // 逻辑或：有一个真就真
!    // 逻辑非
```
⚠️ **最常见错误**：`if (a = 5)` 是把 5 赋给 a（结果永远为真），判断相等要写 `if (a == 5)`。

**短路求值**（很重要，写算法时经常利用）：
- `A && B`：如果 A 为假，**B 根本不会计算**
- `A || B`：如果 A 为真，B 不会计算
```c
while (j >= 0 && a[j] > temp)   // 如果 j 已经是 -1，就不会去访问 a[-1]，避免越界
```
C 语言里，**0 表示假，非 0 都表示真**。

### 3.4 位运算（⭐ 组成原理、操作系统会用到）
| 运算 | 符号 | 规则 | 例（a = 1100，b = 1010） |
|---|---|---|---|
| 按位与 | `&` | 都为 1 才为 1 | a & b = 1000 |
| 按位或 | `\|` | 有 1 就为 1 | a \| b = 1110 |
| 按位异或 | `^` | 不同为 1 | a ^ b = 0110 |
| 按位取反 | `~` | 0 变 1，1 变 0 | ~a = …0011 |
| 左移 | `<<` | 整体左移，低位补 0 | a << 1 = 11000 |
| 右移 | `>>` | 整体右移 | a >> 2 = 0011 |

**常用技巧**：
```c
x << k        // x × 2^k
x >> k        // x ÷ 2^k（向下取整，对非负数）
x & 1         // 取最低位 → 判断奇偶
x & 0xFF      // 取低 8 位
x & (x - 1)   // 把最低位的 1 清零
addr >> 12    // 地址右移 12 位 = 页号（页大小 4KB 时）
addr & 0xFFF  // 取低 12 位 = 页内偏移
```
⚠️ 右移：**无符号数高位补 0（逻辑右移）；有符号数一般高位补符号位（算术右移）**。组成原理第 4 课会详细讲。

### 3.5 条件运算符
```c
max = (a > b) ? a : b;   // 如果 a > b，max = a，否则 max = b
```

### 3.6 类型转换
```c
int a = 7, b = 2;
double d = a / b;           // 3.0！因为 a/b 先按整数算成 3，再转成 double
double e = (double)a / b;   // 3.5，先把 a 强制转成 double
int f = (int)3.9;           // 3，直接截掉小数部分
```

### 3.7 优先级（记几个关键的）
从高到低大致是：`()` `[]` `->` `.` > `!` `~` `++` `--` 单目 `*` `&` > `* / %` > `+ -` > `<< >>` > `< <= > >=` > `== !=` > `&` > `^` > `|` > `&&` > `||` > `?:` > `=` `+=`…
**不确定就加括号**！考试写代码时括号多一点绝不扣分。

## 四、输入输出

```c
int a; double d; char s[100];
scanf("%d", &a);        // 读一个整数，注意变量前要加 &（取地址）
scanf("%lf", &d);       // 读 double
scanf("%s", s);         // 读字符串，数组名本身就是地址，不加 &
printf("a = %d\n", a);  // %d 整数，%f 小数，%c 字符，%s 字符串，%x 十六进制
printf("%.2f\n", d);    // 保留两位小数
```
`\n` 是换行。408 写算法题时一般**不需要写输入输出**，只写函数。

## 五、分支结构

### 5.1 if-else
```c
if (score >= 90) {
    printf("优秀");
} else if (score >= 60) {
    printf("及格");
} else {
    printf("不及格");
}
```
执行过程：从上往下判断，**第一个成立的分支执行后，后面的都跳过**。

### 5.2 switch
```c
switch (op) {
    case '+': r = a + b; break;
    case '-': r = a - b; break;
    default:  r = 0;
}
```
⚠️ 每个 case 结尾要写 `break`，否则会“**贯穿**”执行下一个 case。

## 六、循环结构（⭐⭐⭐ 算法的核心）

### 6.1 for 循环
```c
for (初始化; 条件; 更新) {
    循环体;
}
```
执行顺序：初始化（只执行一次）→ 判断条件 → 成立则执行循环体 → 更新 → 再判断条件 → …… → 条件不成立时退出。

```c
int sum = 0;
for (int i = 1; i <= 100; i++) {   // i = 1, 2, ..., 100
    sum += i;
}
// sum = 5050
```

**数一数循环体执行了几次**（⭐ 算复杂度的基础）：
| 写法 | i 的取值 | 次数 |
|---|---|---|
| `for (i = 0; i < n; i++)` | 0 ~ n−1 | n |
| `for (i = 1; i <= n; i++)` | 1 ~ n | n |
| `for (i = 0; i <= n; i++)` | 0 ~ n | n + 1 |
| `for (i = n - 1; i >= 0; i--)` | n−1 ~ 0 | n |
| `for (i = 1; i < n; i *= 2)` | 1, 2, 4, …, < n | ⌈log₂n⌉ |
| `for (i = 0; i < n; i += 2)` | 0, 2, 4, … | ⌈n/2⌉ |

### 6.2 while 和 do-while
```c
while (条件) {      // 先判断，再执行；可能一次都不执行
    循环体;
}

do {                // 先执行一次，再判断；至少执行一次
    循环体;
} while (条件);
```
**例**：求一个正整数的各位数字之和
```c
int n = 1234, sum = 0;
while (n > 0) {
    sum += n % 10;   // 取个位
    n /= 10;         // 去掉个位
}
// sum = 1 + 2 + 3 + 4 = 10
```

### 6.3 break 和 continue
- `break`：**立即跳出**整个循环
- `continue`：**跳过本次**循环剩下的语句，直接进入下一次

```c
for (int i = 0; i < n; i++) {
    if (a[i] == key) {
        pos = i;
        break;         // 找到了就不用再找了
    }
}
```

### 6.4 嵌套循环
```c
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 4; j++) {
        printf("(%d,%d) ", i, j);
    }
    printf("\n");
}
```
外层每转一圈，内层转完整的 4 圈 → 总共 3 × 4 = 12 次。

### 6.5 手动模拟程序（⭐ 考试必备技能）
面对一段程序，最稳的办法是**画表格，一步一步记下每个变量的值**。
```c
int x = 0;
for (int i = 1; i <= 4; i++)
    for (int j = i; j <= 4; j++)
        x++;
```
| i | j 的取值 | 本轮 x++ 次数 |
|---|---|---|
| 1 | 1,2,3,4 | 4 |
| 2 | 2,3,4 | 3 |
| 3 | 3,4 | 2 |
| 4 | 4 | 1 |
x = 4 + 3 + 2 + 1 = **10**。推广到 n：x = n(n+1)/2。

## 七、数组（⭐⭐⭐）

### 7.1 一维数组
🧒 数组就是**一排连在一起的、同类型的盒子**，用**下标**编号，**下标从 0 开始**。

```c
int a[5];                  // 5 个 int：a[0] a[1] a[2] a[3] a[4]
int b[5] = {1, 2, 3};      // 没写的自动补 0：{1,2,3,0,0}
int c[] = {4, 5, 6};       // 自动推断长度为 3
```
⚠️ **越界访问**：`a[5]` 不存在！C 语言**不检查越界**，会读写到别的内存，产生奇怪的错误。

**内存布局**：数组元素在内存中**连续存放**。
若 a 的首地址是 1000，int 占 4 字节，则 a[i] 的地址 = **1000 + 4i**。
（这就是为什么数组能 O(1) “随机访问”：地址一算就出来了。）

**常见操作模板**：
```c
// 求和、求最大值
int sum = 0, max = a[0];
for (int i = 0; i < n; i++) {
    sum += a[i];
    if (a[i] > max) max = a[i];
}

// 逆置数组（双指针）
for (int i = 0, j = n - 1; i < j; i++, j--) {
    int t = a[i]; a[i] = a[j]; a[j] = t;   // 交换
}

// 在数组中查找
int pos = -1;
for (int i = 0; i < n; i++)
    if (a[i] == key) { pos = i; break; }
```

**交换两个变量**（记住这个“三步走”，一定要借助临时变量 t）：
```c
int t = x;   // ① 把 x 先存到 t
x = y;       // ② y 放进 x
y = t;       // ③ 原来的 x 放进 y
```

### 7.2 二维数组
```c
int m[3][4];   // 3 行 4 列
m[1][2] = 7;   // 第 1 行第 2 列（都从 0 数）
```
🧒 二维数组就像一个**表格**。但内存是一维的一条长街，所以要“铺平”：C 语言用**行优先**——先存第 0 行的全部，再存第 1 行……

```
m[0][0] m[0][1] m[0][2] m[0][3] | m[1][0] m[1][1] ... | m[2][0] ...
```
**地址公式**：`m[i][j]` 的地址 = 首地址 + **(i × 列数 + j)** × 元素大小

**遍历**：
```c
for (int i = 0; i < 3; i++)        // 按行遍历：访问地址连续，局部性好
    for (int j = 0; j < 4; j++)
        sum += m[i][j];

for (int j = 0; j < 4; j++)        // 按列遍历：每次跳过一整行，局部性差
    for (int i = 0; i < 3; i++)
        sum += m[i][j];
```
> 🔗 “按行遍历比按列遍历快”是组成原理 **Cache** 的必考点（2020 年 46 题、2023 年 43 题）。现在先记住这个现象，学 Cache 时你就明白原因了。

### 7.3 字符串
C 语言的字符串就是**以 `'\0'`（值为 0 的字符）结尾的 char 数组**。
```c
char s[] = "hello";   // 实际占 6 个字节：h e l l o \0
int len = 0;
while (s[len] != '\0') len++;   // 自己求长度，len = 5
```
常用库函数（`#include <string.h>`）：`strlen(s)` 长度、`strcpy(a, b)` 复制、`strcmp(a, b)` 比较、`strcat(a, b)` 拼接。

## 📝 真题中的 C 代码片段（感受一下）

**2022 年第 1 题**：
```c
int sum = 0;
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < i; j++)
        sum++;
```
问时间复杂度。学完第 4 课你就会算：总次数 1 + 2 + 4 + … < 2n，所以是 **O(n)**。

**2023 年第 43 题**：
```c
int a[24][64];
for (i = 0; i < 24; i++)
    for (j = 0; j < 64; j++)
        a[i][j] = 10;
```
（你手里的扫描件把数组印成了 `a[24][24]`，但循环 j 到 64，原题应为 `a[24][64]`。）考 Cache 和缺页——关键是看懂“按行访问、地址连续”。

## ⚠️ 易错点汇总

   int last = a[n - 1];
   for (int i = n - 1; i > 0; i--) a[i] = a[i - 1];   // 从后往前挪，避免覆盖
   a[0] = last;
   ```
5. 2000 + (3 × 20 + 5) × 4 = 2000 + 260 = **2260**
6. i = 100, 50, 25, 12, 6, 3, 1 → **7 次**（⌊log₂100⌋ + 1 = 7）
7. `0x3C` = 0011 1100。`& 0x0F` → 0000 1100 = **0x0C**；`| 0x0F` → 0011 1111 = **0x3F**；`^ 0xFF` → 1100 0011 = **0xC3**；`>> 2` → 0000 1111 = **0x0F**
</details>
