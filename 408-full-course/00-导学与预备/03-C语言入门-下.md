## 一、函数

### 🧒 大白话
函数就是一台**加工机器**：从入口放进原料（**参数**），机器加工，从出口吐出成品（**返回值**）。
写好一次，可以反复使用。

### 📐 定义与调用
```c
// 返回值类型  函数名(参数列表)
int max(int x, int y) {
    if (x > y) return x;   // return：交出结果，并立即结束函数
    return y;
}

void printLine(int n) {    // void：不返回任何东西
    for (int i = 0; i < n; i++) printf("-");
    printf("\n");
}

int main() {
    int m = max(3, 7);     // 调用：x 得到 3，y 得到 7，m = 7
    printLine(10);
    return 0;
}
```
- **形参**：定义函数时括号里的 x、y
- **实参**：调用时传进去的 3、7
- 函数要**先声明后使用**：如果 max 写在 main 后面，要在 main 前写一句 `int max(int x, int y);`

### 📐 值传递（⭐ 重要陷阱）
**C 语言的参数传递是“值传递”：形参是实参的一份复印件，改复印件不影响原件。**

```c
void swap(int a, int b) {   // 错误的交换
    int t = a; a = b; b = t;
}
int main() {
    int x = 1, y = 2;
    swap(x, y);
    printf("%d %d", x, y);  // 输出 1 2 —— 没换过来！
}
```
🧒 这就像你把作业**复印**一份给同学，同学在复印件上改了答案，你的原件并没有变。

**怎么才能在函数里改掉外面的变量？** → 把变量的**地址**传进去（下面的指针），或者用 C++ 的**引用**。

### 📐 变量的作用域和生命周期
| 变量 | 定义在哪 | 在哪能用 | 什么时候存在 | 存在内存哪里 |
|---|---|---|---|---|
| **局部变量** | 函数/代码块内 | 只在该函数内 | 函数调用时创建，返回时销毁 | **栈** |
| **全局变量** | 所有函数外 | 整个程序 | 程序运行全程 | **数据段** |
| **static 局部变量** | 函数内加 static | 只在该函数内 | 程序运行全程（只初始化一次） | **数据段** |
| **malloc 申请的** | — | 通过指针访问 | 直到 free | **堆** |

> 🔗 这张表在操作系统“进程内存映像”中会再考（2025 年第 46 题：全局变量 ptr 在“可读写数据区”，局部变量 length 在“用户栈”，malloc 的空间在“堆”）。

## 二、指针（⭐⭐⭐ 重中之重）

### 🧒 大白话：门牌号与房间
- 内存就像一条长长的街，每个**房间**（字节）都有一个**门牌号**（地址）。
- 变量 `int a = 5;` 就是占了 4 个房间，里面放着 5。
- **指针变量**是一种特殊的变量，它里面放的不是普通数字，而是**另一个变量的门牌号**。

```
地址:     1000       1004            2000
       ┌────────┐              ┌────────┐
       │   5    │  ←──────────  │  1000  │
       └────────┘              └────────┘
        变量 a                  指针 p（里面存着 a 的地址）
```

### 📐 两个运算符
| 运算符 | 读法 | 作用 |
|---|---|---|
| `&a` | “a 的地址” | 取门牌号 |
| `*p` | “p 指向的东西” | 按门牌号进门，拿到/修改房间里的东西 |

```c
int a = 5;
int *p;        // 定义一个指针 p，它将来指向一个 int
p = &a;        // p 里存 a 的地址
printf("%d", *p);   // 5：通过 p 读 a 的值
*p = 10;       // 通过 p 修改 a 的值
printf("%d", a);    // 10
```
⚠️ **星号 `*` 的两种含义**：
- 在**定义**里（`int *p;`）：表示“p 是一个指针”
- 在**使用**里（`*p = 10;`）：表示“p 指向的那个东西”

### 📐 用指针实现真正的交换
```c
void swap(int *a, int *b) {   // 参数是两个地址
    int t = *a;               // t = a 指向的值
    *a = *b;                  // 把 b 指向的值放进 a 指向的房间
    *b = t;
}
int main() {
    int x = 1, y = 2;
    swap(&x, &y);             // 把 x、y 的地址传进去
    printf("%d %d", x, y);    // 2 1 —— 成功！
}
```
🧒 这次你给同学的不是作业复印件，而是**你家的钥匙和地址**，他直接去你家改了原件。

### 📐 空指针和野指针
```c
int *p = NULL;   // 空指针：不指向任何东西（地址 0）
if (p != NULL) { ... }   // 使用前先判断，链表代码里到处都是
```
- **野指针**：没初始化或者指向已释放内存的指针，非常危险。好习惯：`free(p); p = NULL;`

### 📐 指针与数组（⭐）
**数组名就是数组首元素的地址**：`a` 等价于 `&a[0]`。
```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;         // p 指向 a[0]
*(p + 2)            // 30，等价于 a[2]、p[2]
p++;                // p 指向 a[1]
```
**指针加 1，不是地址加 1 字节，而是加“一个元素的大小”**：int 指针加 1，地址加 4。
所以 `a[i]` 本质上就是 `*(a + i)`：从首地址往后跳 i 个元素。

**数组作为函数参数时，传的是首地址**：
```c
void setZero(int arr[], int n) {    // 等价于 int *arr
    for (int i = 0; i < n; i++) arr[i] = 0;   // 会修改外面的数组！
}
```
所以函数里改数组元素，外面能看到（因为传的是地址）。同时函数内部**不知道数组多长**，必须另外传 n。

### 📐 指向指针的指针（了解）
```c
int a = 5;
int *p = &a;
int **pp = &p;   // pp 存着 p 的地址
**pp = 7;        // a 变成 7
```
在数据结构里，要在函数中**修改一个指针本身**（比如让链表头指针指向新结点），就要传指针的地址（`LNode **L`），或者用 C++ 引用（`LinkList &L`，更简单，下面讲）。

## 三、结构体（⭐⭐⭐）

### 🧒 大白话
数组只能装**同一种**东西。现实中一个“学生”有学号（整数）、姓名（字符串）、成绩（小数）……
**结构体**就是一个**多格收纳盒**，每一格可以放不同类型的东西。

### 📐 定义和使用
```c
struct Student {
    int id;
    char name[20];
    float score;
};                          // 注意结尾的分号！

struct Student s1;          // 定义一个结构体变量
s1.id = 1001;               // 用 . 访问成员
s1.score = 95.5;

struct Student *ps = &s1;   // 指向结构体的指针
ps->score = 98;             // 用 -> 访问（等价于 (*ps).score）
```
🧒 记忆：**手里拿的是“东西本身”用点 `.`；手里拿的是“门牌号（指针）”用箭头 `->`**。

### 📐 typedef：起别名
```c
typedef struct Student {
    int id;
    float score;
} Student, *PStudent;
// 以后 Student 就代表 struct Student，PStudent 就代表 struct Student *
Student s;      // 比 struct Student s; 简洁
PStudent p;     // 等价于 Student *p;
```

### 📐 数据结构里的经典定义（现在就要看懂）

**顺序表**：
```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];   // 存元素的数组
    int length;          // 当前长度
} SqList;
```

**单链表结点**：
```c
typedef struct LNode {
    int data;               // 数据域
    struct LNode *next;     // 指针域：指向下一个结点（自己类型的指针）
} LNode, *LinkList;
// LNode *p 强调“p 是一个结点的指针”；LinkList L 强调“L 代表一个链表”（头指针）
```

**二叉树结点**：
```c
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;   // 左右孩子
} BiTNode, *BiTree;
```

**图的邻接矩阵**（2021、2023 年第 41 题原题定义）：
```c
typedef struct {
    int numVertices, numEdges;      // 顶点数、边数
    char VerticesList[MAXV];        // 顶点表
    int Edge[MAXV][MAXV];           // 邻接矩阵
} MGraph;
// 使用：G.numVertices、G.Edge[i][j]
```

### 📐 结构体的大小与对齐（组成原理会考）
```c
struct record { short x1; int x2; };
```
sizeof 并不是 2 + 4 = 6，而是 **8**：因为 int 要放在 4 的倍数地址上，x1 后面会填充 2 字节。
这叫**边界对齐**，组成原理第 6 课详细讲（2020 年第 14 题、2025 年第 15 题都考了）。

## 四、动态内存分配

### 🧒 大白话
数组的大小要在写程序时就定死（`int a[100]`）。如果运行时才知道要多少呢？就要**临时向系统“借地”**：`malloc`。用完要**还**：`free`。

### 📐 用法（`#include <stdlib.h>`）
```c
int n = 10;
int *arr = (int *)malloc(sizeof(int) * n);   // 借 n 个 int 的空间
if (arr == NULL) { /* 借失败了 */ }
for (int i = 0; i < n; i++) arr[i] = i;      // 当数组用
free(arr);                                    // 还回去
```
- `malloc(字节数)` 返回一个 `void *`（通用指针），要**强制转换**成需要的类型
- `sizeof(int) * n` 是字节数
- 借来的内存在**堆（heap）**里，不会随函数返回而消失，必须手动 free，否则**内存泄漏**

**申请一个链表结点**：
```c
LNode *s = (LNode *)malloc(sizeof(LNode));
s->data = 5;
s->next = NULL;
```
**C++ 写法（考试可用，更简洁）**：
```cpp
LNode *s = new LNode;      // 申请
delete s;                  // 释放
int *arr = new int[n];     // 申请数组
delete[] arr;              // 释放数组
```

📝 **2021 年第 42 题**里就有：`count = (int *)malloc(sizeof(int) * n);` ... `free(count);`
📝 **2025 年第 46 题**：`ptr = (char *)malloc(sizeof(char)); ... free(ptr);` 问 ptr 指向的内容在哪个内存区域 → **堆**。

## 五、递归（⭐⭐）

### 🧒 大白话：俄罗斯套娃
**递归**就是函数**自己调用自己**。
想象你要知道一排人中你是第几个，你问前面的人：“你是第几个？”他也不知道，又问更前面的……一直问到第一个人，他说“我是第 1 个”。然后答案一个个传回来：“我是第 2 个”“我是第 3 个”……

递归必须有两样东西：
1. **递归出口（终止条件）**：什么时候不再调用自己（第一个人直接知道答案）
2. **递归体**：把大问题变成**同样形式的小问题**

### 📐 例 1：阶乘
n! = n × (n−1)!，且 1! = 1
```c
int fact(int n) {
    if (n == 1) return 1;           // 出口
    return n * fact(n - 1);         // 递归体
}
```
**执行过程**（fact(4)）：
```
fact(4) = 4 * fact(3)
              fact(3) = 3 * fact(2)
                            fact(2) = 2 * fact(1)
                                          fact(1) = 1    ← 到底了，开始返回
                            fact(2) = 2 * 1 = 2
              fact(3) = 3 * 2 = 6
fact(4) = 4 * 6 = 24
```

### 📐 递归与系统栈（⭐ 408 常考）
每调用一次函数，系统就在**栈**里压入一个“**栈帧**”（存放这次调用的参数、局部变量、返回地址）。函数返回时弹出。
```
调用 fact(4) 过程中栈的最深状态：
┌──────────┐ ← 栈顶
│ fact(1)  │
│ fact(2)  │
│ fact(3)  │
│ fact(4)  │
│ main     │
└──────────┘
```
- **递归深度为 d，空间复杂度就是 O(d)**
- 递归太深会**栈溢出**
- 任何递归都可以借助一个**栈**改写成非递归（循环）

### 📐 例 2：斐波那契数列
F(1) = F(2) = 1，F(n) = F(n−1) + F(n−2)
```c
int fib(int n) {
    if (n <= 2) return 1;
    return fib(n - 1) + fib(n - 2);
}
```
⚠️ 这个递归**重复计算**非常多（fib(5) 会算两次 fib(3)），时间复杂度是 O(2ⁿ)。用循环只需 O(n)：
```c
int fib(int n) {
    int a = 1, b = 1;
    for (int i = 3; i <= n; i++) { int c = a + b; a = b; b = c; }
    return b;
}
```

### 📐 例 3：递归求数组最大值（分治思想）
```c
int maxOf(int a[], int low, int high) {
    if (low == high) return a[low];            // 只有一个元素
    int mid = (low + high) / 2;
    int m1 = maxOf(a, low, mid);               // 左半边最大
    int m2 = maxOf(a, mid + 1, high);          // 右半边最大
    return m1 > m2 ? m1 : m2;
}
```
这种“拆成两半各自解决，再合并”的思想叫**分治**，归并排序、快速排序、二叉树算法都用它。

### 📐 例 4：二叉树的递归（预告）
```c
int height(BiTree T) {                     // 求树高
    if (T == NULL) return 0;               // 空树高度为 0
    int hl = height(T->lchild);
    int hr = height(T->rchild);
    return (hl > hr ? hl : hr) + 1;
}
```
树天然就是递归结构（一棵树 = 根 + 左子树 + 右子树），所以树的算法几乎都用递归写。

## 六、考试可以用的 C++ 便利语法

408 允许用 C 或 C++ 写算法，C++ 有几个特别方便的地方：

### 6.1 引用 `&`（⭐ 教材代码里大量使用）
```cpp
void swap(int &a, int &b) {   // a、b 是实参的“别名”
    int t = a; a = b; b = t;  // 直接改，不用 *
}
int x = 1, y = 2;
swap(x, y);                   // 调用时也不用 &，x、y 真的交换了
```
🧒 引用就是给变量**起个外号**：同一个人，两个名字，改了一个就是改了另一个。

教材里常见：
```cpp
bool InitList(LinkList &L) {                // 要修改头指针 L 本身，所以用引用
    L = (LNode *)malloc(sizeof(LNode));     // 创建头结点
    L->next = NULL;
    return true;
}
bool ListInsert(SqList &L, int i, int e);   // 要修改顺序表，所以用引用
int GetElem(SqList L, int i);               // 只读取，不用引用也行
```
**判断要不要加 `&` 的规则**：函数**需要修改**这个参数、并且希望修改结果带回给调用者 → 加 `&`。

### 6.2 bool 类型
```cpp
bool found = false;
if (...) found = true;
```
（C99 中需要 `#include <stdbool.h>`）

### 6.3 其他
- `new` / `delete`
- `swap(a, b)`（`#include <algorithm>`）
- `sort(a, a + n)`：排序，时间 O(n log n)
- `min(a, b)`、`max(a, b)`

## 七、综合示例：读懂一段完整的数据结构代码

```cpp
// 在带头结点的单链表 L 的第 i 个位置插入元素 e
bool ListInsert(LinkList &L, int i, int e) {
    if (i < 1) return false;            // 位置不合法
    LNode *p = L;                        // p 从头结点出发
    int j = 0;                           // p 当前指向第 j 个结点（头结点算第 0 个）
    while (p != NULL && j < i - 1) {     // 找第 i-1 个结点
        p = p->next;
        j++;
    }
    if (p == NULL) return false;         // i 太大，不存在第 i-1 个结点
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;                   // ① 新结点先连上后继
    p->next = s;                         // ② 再让前驱指向新结点
    return true;
}
```
逐行读懂了吗？数据结构第 3 课会一行一行地讲它。

## ⚠️ 易错点汇总
1. 值传递：函数里改形参不影响实参；要改就传地址或用引用
2. `*` 在定义和使用中含义不同
3. 指针用之前要确认不是 NULL
4. 结构体变量用 `.`，结构体指针用 `->`
5. 指针加 1 是加“一个元素的大小”
6. malloc 后要强转类型，用完要 free
7. 递归必须有出口，否则无限递归导致栈溢出
8. 递归空间复杂度 = 递归深度

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 函数 | 返回值类型 函数名(参数)；return 结束函数 |
| 值传递 | 形参是复印件 |
| 指针 | `&` 取地址，`*` 解引用；`int *p = &a; *p = 10;` |
| 数组与指针 | 数组名 = 首地址；`a[i]` = `*(a+i)` |
| 结构体 | `.` 访问成员；指针用 `->` |
| typedef | 起别名：`LNode, *LinkList` |
| malloc/free | `(T*)malloc(sizeof(T)*n)`，空间在堆上 |
| 递归 | 出口 + 递归体；每层一个栈帧；空间 O(深度) |
| C++ 引用 | `int &a` 是别名，函数里改了外面也改 |
