## 🚪 课前引入：为什么计算机只认 0 和 1？

计算机是用**电路**做的。电路里最容易、最可靠区分的状态是什么？
- 开关：**开 / 关**
- 电压：**高 / 低**
- 磁性：**N 极 / S 极**
- 光：**有光 / 没光**

都是**两种状态**！如果非要让电路区分十种电压（0V、0.5V、1V……4.5V），稍微有点干扰（比如电压抖动了 0.3V）就会认错。而区分“高”和“低”两种，抗干扰能力强得多。

所以计算机选择了**二进制**：用 1 表示一种状态，0 表示另一种状态。所有的数字、文字、图片、声音、视频，在计算机里最终都是一长串 0 和 1。

## 一、进制的本质

### 🧒 大白话：数糖果
假设你有一堆糖果要数。
- **十进制**：你有一种盒子，一个盒子装 **10** 颗。装满 10 个小盒子，再放进一个大盒子（100 颗）……
  比如 **345** 颗 = 3 个大盒子（每个 100）+ 4 个小盒子（每个 10）+ 5 颗散的
- **二进制**：盒子一个只装 **2** 颗。满 2 颗就放进上一级盒子。
  比如 **1011**（二进制）= 1 个“8 颗盒” + 0 个“4 颗盒” + 1 个“2 颗盒” + 1 颗散的 = 11 颗

所以进制就是“**满几进一**”：
- 十进制：满 10 进 1，用 0~9 这 10 个数字
- 二进制：满 2 进 1，用 0、1 这 2 个数字
- 八进制：满 8 进 1，用 0~7
- 十六进制：满 16 进 1，用 0~9 和 A~F

### 📐 正式定义：位权展开

一个 R 进制数（R 叫**基数**）：

$$
(a_{n-1}a_{n-2}\cdots a_1a_0.a_{-1}a_{-2}\cdots a_{-m})_R = \sum_{i=-m}^{n-1} a_i \times R^i
$$

- 第 i 位的“**位权**”是 Rⁱ
- 整数部分从右往左，位权依次是 R⁰、R¹、R²……
- 小数部分从左往右，位权依次是 R⁻¹、R⁻²……

**例**：(345.6)₁₀ = 3×10² + 4×10¹ + 5×10⁰ + 6×10⁻¹
**例**：(1011.01)₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ + 0×2⁻¹ + 1×2⁻² = 8 + 2 + 1 + 0.25 = 11.25

### 书写约定（考试中常见）
| 写法 | 含义 |
|---|---|
| (1011)₂、1011B | 二进制（B = Binary） |
| (17)₈、17O、17Q | 八进制 |
| (99)₁₀、99D | 十进制 |
| (7F)₁₆、7FH、0x7F | 十六进制（H = Hex） |

⚠️ 408 题目里最常见的是 **H 后缀**（如 `C800 0000H`）和 **0x 前缀**（如 `0x1A2F`）。

| 0 | 1 | 8 | 256 | 16 | 65536 (64K) |
| 1 | 2 | 9 | 512 | 20 | 1048576 (1M) |
| 2 | 4 | 10 | 1024 (1K) | 24 | 16M |
| 3 | 8 | 11 | 2048 (2K) | 30 | 1G |
| 4 | 16 | 12 | 4096 (4K) | 32 | 4G |
| 5 | 32 | 13 | 8192 (8K) | 40 | 1T |
| 6 | 64 | 14 | 16384 (16K) | | |
| 7 | 128 | 15 | 32768 (32K) | | |

**记忆技巧**：2¹⁰ = 1K，所以 2¹² = 2² × 2¹⁰ = 4K，2²³ = 2³ × 2²⁰ = 8M，2³² = 2² × 2³⁰ = 4G。
反过来：**4KB = 2¹² B，32KB = 2¹⁵ B，64B = 2⁶ B，512MB = 2²⁹ B**。考试时看到容量，第一反应就是把它写成 2 的幂。

|---|---|---|---|---|
| 0.5 | 0.25 | 0.125 | 0.0625 | 0.03125 |

## 三、进制转换（⭐⭐⭐）

### 3.1 任意进制 → 十进制：按权展开相加
就是上面的位权公式。

**例 1**：(2A.8)₁₆ = 2×16 + 10×1 + 8×16⁻¹ = 32 + 10 + 0.5 = **42.5**
**例 2**：(157)₈ = 1×64 + 5×8 + 7 = **111**

### 3.2 十进制整数 → R 进制：除 R 取余，逆序排列

🧒 **为什么这样做？** 想想十进制：345 ÷ 10 = 34 余 **5**，余数就是个位；34 ÷ 10 = 3 余 **4**，是十位……每除一次，就“剥”出最低的一位。二进制也一样，每除以 2，余数就是当前最低位。先剥出来的是低位，所以要**倒着读**。

**例**：100 转二进制
```
100 ÷ 2 = 50 …… 0   ← 最低位
 50 ÷ 2 = 25 …… 0
 25 ÷ 2 = 12 …… 1
 12 ÷ 2 =  6 …… 0
  6 ÷ 2 =  3 …… 0
  3 ÷ 2 =  1 …… 1
  1 ÷ 2 =  0 …… 1   ← 最高位
从下往上读：1100100
```
验算：64 + 32 + 4 = 100 ✓

**考场快速法：减 2 的幂**
100 里最大的 2 的幂是 64 → 100 − 64 = 36 → 最大 32 → 36 − 32 = 4 → 4。
所以 100 = 64 + 32 + 4 = 2⁶ + 2⁵ + 2²，第 6、5、2 位是 1：**1100100**。

### 3.3 十进制小数 → R 进制：乘 R 取整，顺序排列

🧒 **为什么？** 0.375 × 2 = 0.75，整数部分 0 就是二进制小数点后第 1 位；把小数部分继续乘 2……每乘一次，就把小数点后的下一位“挪”到整数部分来。先得到的是高位，所以**正着读**。

**例**：0.6875 转二进制
```
0.6875 × 2 = 1.375  → 1
0.375  × 2 = 0.75   → 0
0.75   × 2 = 1.5    → 1
0.5    × 2 = 1.0    → 1   （小数部分为 0，结束）
正着读：0.1011
```
验算：0.5 + 0.125 + 0.0625 = 0.6875 ✓

**考场快速法**：0.6875 = 0.5 + 0.125 + 0.0625 = 2⁻¹ + 2⁻³ + 2⁻⁴ → 0.1011

**无限循环的情况**：0.1 转二进制
```
0.1 × 2 = 0.2 → 0
0.2 × 2 = 0.4 → 0
0.4 × 2 = 0.8 → 0
0.8 × 2 = 1.6 → 1
0.6 × 2 = 1.2 → 1
0.2 × 2 = 0.4 → 0   ← 又回到 0.2 了，开始循环！
结果：0.0 0011 0011 0011 ……
```
⚠️ **重要结论**：一个十进制小数能用有限位二进制表示，**当且仅当它能写成“整数 / 2ᵏ”的形式**。0.5、0.25、0.375、0.6875 可以；0.1、0.2、1.2 不可以。
这就是为什么计算机里 `0.1 + 0.2 != 0.3`！

📝 **真题（2021 年第 14 题）**：下列数值中，不能用 IEEE 754 浮点格式精确表示的是：A. 1.2  B. 1.25  C. 2.0  D. 2.5
→ 1.25 = 5/4 ✓，2.0 ✓，2.5 = 5/2 ✓，1.2 = 6/5，分母不是 2 的幂 ✗。选 **A**。

### 3.4 二进制 ↔ 八进制、十六进制：分组法

因为 8 = 2³，16 = 2⁴，所以：
- **3 位二进制 = 1 位八进制**
- **4 位二进制 = 1 位十六进制**

**分组规则**：以**小数点为中心**，整数部分**向左**、小数部分**向右**分组，不够的**补 0**（整数在最左边补，小数在最右边补）。

**例**：(1101101.101)₂ 转十六进制
```
整数部分：110 1101 → 0110 1101 → 6 D
小数部分：101 → 1010 → A
结果：6D.AH
```
**例**：(1101101.101)₂ 转八进制
```
整数：1 101 101 → 001 101 101 → 1 5 5
小数：101 → 5
结果：(155.5)₈
```
**反过来**：十六进制转二进制，每一位直接展开成 4 位。
(3F.C)₁₆ = 0011 1111 . 1100 = (111111.11)₂

### 3.5 十六进制 ↔ 十进制（考场常用）
- 十六 → 十：按权展开。(1F4)₁₆ = 1×256 + 15×16 + 4 = 500
- 十 → 十六：可以先转二进制再分组；或者除 16 取余。
  500 ÷ 16 = 31 余 4；31 ÷ 16 = 1 余 15(F)；1 ÷ 16 = 0 余 1 → **1F4H**

## 四、“n 位能表示多少种” 与 “编号需要几位”（⭐⭐⭐ 万能工具）

### 🧒 大白话
- 1 个开关：2 种状态（开、关）
- 2 个开关：4 种（开开、开关、关开、关关）
- n 个开关：**2ⁿ 种状态**

反过来，要给 N 个东西各分配一个不同的编号，用二进制编号，至少需要 **⌈log₂N⌉ 位**（找最小的 n 使 2ⁿ ≥ N）。

### 这个工具在 408 里到处用
| 场景 | 例子 |
|---|---|
| 指令操作码位数 | 48 条指令 → 2⁵ = 32 < 48 ≤ 64 = 2⁶ → 需要 **6 位** |
| 寄存器编号位数 | 16 个通用寄存器 → **4 位** |
| 地址位数 ↔ 容量 | 32 位地址 → 能访问 2³² 个单元；按字节编址就是 4GB |
| Cache 组号位数 | 64 组 → **6 位** |
| 页内偏移位数 | 页大小 4KB = 2¹² → **12 位** |
| 磁盘地址 | 20000 个磁道 → 2¹⁴ = 16384 < 20000 ≤ 32768 = 2¹⁵ → **15 位** |
| 子网划分 | 要 6 个子网 → 借 **3 位** |

**无符号 n 位二进制能表示的范围**：0 ~ 2ⁿ − 1。
例：8 位 → 0~255；16 位 → 0~65535。

## 五、存储单位与速率单位（⭐⭐⭐ 最容易丢分的地方）

### 5.1 存储容量单位（二进制前缀）
| 单位 | 含义 |
|---|---|
| **b（bit，位）** | 一个 0 或 1，最小单位 |
| **B（Byte，字节）** | 8 位 |
| KB | 2¹⁰ B = 1024 B |
| MB | 2²⁰ B |
| GB | 2³⁰ B |
| TB | 2⁴⁰ B |

> 严格来说，国际标准把 2¹⁰ 写作 KiB、2²⁰ 写作 MiB，但**408 题目里说存储容量时，K/M/G 就是 2¹⁰/2²⁰/2³⁰**。

### 5.2 速率、频率单位（十进制前缀）
| 单位 | 含义 |
|---|---|
| k | 10³ |
| M | 10⁶ |
| G | 10⁹ |
| T | 10¹² |

**用在**：网络带宽（Mbps）、时钟频率（GHz）、总线传输率（MB/s 中的 M 通常取 10⁶，题目有时会特别说明）、MIPS、FLOPS。

### 5.3 时间单位
1 s = 10³ ms（毫秒）= 10⁶ μs（微秒）= 10⁹ ns（纳秒）= 10¹² ps（皮秒）

**频率和周期互为倒数**：
- 1 GHz → 周期 1 ns
- 2 GHz → 0.5 ns
- 500 MHz → 2 ns
- 100 MHz → 10 ns

### ⚠️ 易错点汇总
1. **b 和 B 不要搞混**：100 Mbps 是每秒 100 兆**位**，每秒只能传 12.5 MB（M=10⁶）
2. **容量用 2 的幂，速率用 10 的幂**。传一个 1MB（2²⁰ B）的文件，速率 1 MB/s（10⁶ B/s）→ 时间 ≈ 1.048576 s。408 的计算题大部分会给你约定，或者两者差别不影响答案；题目明确写“1M = 10⁶”时就按题目来（2025 年第 33 题就写了）。
3. 看到“**按字编址**”要警惕：一个地址对应一个**字**，不是一个字节

## 六、字符编码

### 6.1 ASCII 码
用 **7 位**二进制表示 128 个字符（通常占 1 个字节，最高位为 0）。

| 字符 | 十进制 | 十六进制 | 二进制 |
|---|---|---|---|
| 空格 | 32 | 20H | 010 0000 |
| '0' | 48 | 30H | 011 0000 |
| '9' | 57 | 39H | 011 1001 |
| 'A' | 65 | 41H | 100 0001 |
| 'Z' | 90 | 5AH | 101 1010 |
| 'a' | 97 | 61H | 110 0001 |
| 'z' | 122 | 7AH | 111 1010 |

**规律**：
- 数字 '0'~'9' 的低 4 位正好是 0~9 → `'7' - '0' = 7`（C 语言里把字符数字变整数的经典写法）
- 大写字母 + 32 = 小写字母（二进制中是第 5 位不同）
- 控制字符 0~31 和 127（如换行 LF = 10，回车 CR = 13）

### 6.2 汉字编码（了解）
- **输入码**：拼音、五笔（你敲键盘用的）
- **国标码 GB2312**：每个汉字 2 个字节
- **机内码**：国标码每个字节最高位置 1（以便和 ASCII 区分）
- **字形码**：显示时用的点阵或矢量信息
- **Unicode / UTF-8**：全世界统一的编码。UTF-8 是变长编码，英文 1 字节，常用汉字 3 字节

### 6.3 BCD 码（了解）
用 4 位二进制表示 1 位十进制数。最常用 **8421 码**：每位权值 8、4、2、1。
例：十进制 **93** 的 8421 BCD 码 = **1001 0011**（9 → 1001，3 → 0011）
⚠️ 注意 BCD 和二进制不同：93 的纯二进制是 1011101。
- 8421 码中 1010~1111 这 6 个编码不用
- BCD 加法：两位相加若结果 > 9 或产生进位，要 **加 6（0110）修正**
  例：8 + 7：1000 + 0111 = 1111（>9）→ 1111 + 0110 = 1 0101 → 进位 1、本位 5 → 15 ✓

## 七、真值与机器数（下一步的铺垫）

- **真值**：我们平时写的带正负号的数，如 +5、−13、0.375
- **机器数**：这个数在计算机里的**二进制表示**（符号也要用 0/1 表示）

怎么用 0 和 1 表示负号？这就引出了原码、反码、补码、移码——组成原理第 3 课会详细讲。现在只需要知道：**同一串二进制，按不同的规则“解释”，代表的真值可能完全不同**。
例如 1111 1111：
- 当作无符号数 → 255
- 当作补码 → −1
- 当作原码 → −127

这个思想非常重要，408 有大量题目就是考“同一串位，不同解释”。
