# 预备第 4 课 · 算法与复杂度分析

> 🎯 **本课目标**
> 1. 知道什么是算法、算法的 5 个特性、好算法的标准
> 2. 理解时间复杂度和空间复杂度的含义，会用大 O 记号
> 3. **掌握 5 种求时间复杂度的方法**（408 第 1 题几乎每年考）
> 4. 区分最好、最坏、平均复杂度
>
> 408 数据结构**第 1 题**几乎年年是“求这段代码的时间复杂度”（2022、2025 年都是），第 41 题还要求你写出自己算法的复杂度（2 分）。

---

## 🚪 课前引入：两种找书的方法

书架上有 1000 本书，你要找《数据结构》。
- **方法 A**：从第一本开始一本本看书名。最坏要看 1000 本。
- **方法 B**：书是按书名拼音排好序的，你每次翻到中间，看看目标在左半还是右半，扔掉一半。最多看 10 本（2¹⁰ = 1024）。

如果书架有 100 万本书呢？方法 A 最坏看 100 万次，方法 B 只要 20 次。
**书越多，差距越大**。复杂度分析研究的就是：**当问题规模 n 变大时，算法的工作量怎样增长**。

## 一、算法的基本概念

### 📐 定义
**算法**是对特定问题求解步骤的一种描述，是**指令的有限序列**。

### 📐 五个特性（⭐ 选择题）
| 特性 | 含义 | 大白话 |
|---|---|---|
| **有穷性** | 执行有限步后结束，每步在有限时间内完成 | 菜谱不能无限长，做菜总会做完 |
| **确定性** | 每条指令含义明确，相同输入得到相同输出 | “放适量盐”不行，要“放 5 克盐” |
| **可行性** | 每一步都能通过有限次基本运算实现 | 不能写“一步把宇宙所有原子数一遍” |
| **输入** | 有零个或多个输入 | |
| **输出** | 有一个或多个输出 | 算法总要给出结果 |

⚠️ **程序 ≠ 算法**：程序可以不满足有穷性（例如操作系统，开机后一直运行，不会自己结束）。

### 📐 好算法的目标
**正确性、可读性、健壮性**（输入非法数据时能合理处理，不会崩溃）、**高效率与低存储量需求**。

## 二、时间复杂度

### 🧒 大白话
我们不去测“算法跑了几秒”（那和电脑快慢有关），而是数“**基本操作执行了多少次**”，再看这个次数**随 n 增长的趋势**。

### 📐 定义
- 设算法中**基本操作**（通常是最深层循环里的语句）的执行次数为 **T(n)**，n 是问题规模
- 若存在常数 C 和 n₀，使得 n ≥ n₀ 时 T(n) ≤ C·f(n)，就记 **T(n) = O(f(n))**
- 意思是：**T(n) 的增长速度不超过 f(n)**（“同阶”或“更低”）

### 📐 两条规则
1. **加法规则**：T(n) = T₁(n) + T₂(n) = O(max(f(n), g(n)))
   → **顺序执行的几段代码，取最大的那一段**
   例：3n² + 100n + 1000 = O(n²)
2. **乘法规则**：T(n) = T₁(n) × T₂(n) = O(f(n) × g(n))
   → **嵌套的循环，相乘**

简化方法：**只保留最高阶项，去掉系数**。

### 📐 常见复杂度大小（⭐⭐⭐ 必背）
$$
O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)
$$
**口诀：常 对 幂 指 阶**（常数 < 对数 < 幂函数 < 指数 < 阶乘）

感受一下 n = 1000 时的数量级：
| 复杂度 | 大约次数 |
|---|---|
| O(1) | 1 |
| O(log n) | 10 |
| O(√n) | 32 |
| O(n) | 1000 |
| O(n log n) | 10000 |
| O(n²) | 10⁶ |
| O(n³) | 10⁹ |
| O(2ⁿ) | 10³⁰¹（宇宙毁灭也算不完） |

> 💡 复杂度里的 log n 一般指 log₂n，但**底数不影响阶**（log₂n = log₁₀n / log₁₀2，只差常数倍）。另外 √n = n^0.5，介于 log n 和 n 之间。

## 三、求时间复杂度的 5 种方法（⭐⭐⭐）

### 方法 1：独立的循环嵌套 → 直接相乘
```c
for (i = 0; i < n; i++)          // n 次
    for (j = 0; j < n; j++)      // 每次 n 次
        x++;
```
T(n) = n × n → **O(n²)**

```c
for (i = 0; i < n; i++)
    for (j = 0; j < m; j++)
        x++;
```
→ **O(n × m)**（两个规模不同就都保留）

### 方法 2：循环变量“乘/除”变化 → 设执行 k 次，解方程

**步骤**：
1. 写出第 k 次循环时循环变量的值
2. 令它等于循环结束的边界，解出 k

**例 1**：
```c
i = 1;
while (i <= n)
    i = i * 2;
```
第 1 次 i = 1，第 2 次 i = 2，……，第 k 次 i = 2ᵏ⁻¹。循环结束时 2ᵏ⁻¹ > n → k ≈ log₂n → **O(log n)**

**例 2（2011 年真题）**：
```c
x = 2;
while (x < n / 2)
    x = 2 * x;
```
执行 k 次后 x = 2ᵏ⁺¹，结束时 2ᵏ⁺¹ ≥ n/2 → k ≈ log₂n − 2 → **O(log₂n)**

**例 3**（逆向）：
```c
for (i = n; i > 1; i = i / 3) x++;
```
k 次后 i = n/3ᵏ ≤ 1 → k = log₃n → **O(log n)**

### 方法 3：循环条件里有“平方”或“累加” → 同样设 k 次解方程

**例 1（2019 年真题）**：
```c
x = 0;
while (n >= (x + 1) * (x + 1))
    x = x + 1;
```
x 从 0 一步步加 1，循环结束时 (x+1)² > n，即 x ≈ √n → 执行约 √n 次 → **O(√n)**

**例 2（2017 年真题）**：
```c
int func(int n) {
    int i = 0, sum = 0;
    while (sum < n) sum += ++i;
    return i;
}
```
i 依次是 1, 2, 3, …，sum = 1 + 2 + … + k = k(k+1)/2。结束时 k(k+1)/2 ≥ n → k ≈ √(2n) → **O(√n)**

### 方法 4：内层循环依赖外层变量 → 逐层求和（⭐ 最重要，最容易错）

**不能直接相乘！要把每一轮的次数加起来。**

**例 1**：
```c
for (i = 1; i <= n; i++)
    for (j = 1; j <= i; j++)
        x++;
```
i = 1 时内层 1 次，i = 2 时 2 次，…… i = n 时 n 次
T(n) = 1 + 2 + … + n = n(n+1)/2 → **O(n²)**

**例 2（2022 年第 1 题）**：
```c
int sum = 0;
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < i; j++)
        sum++;
```
- 外层 i 取值：1, 2, 4, 8, …, 2ᵏ（最后一个小于 n 的 2 的幂）
- 内层执行次数就等于 i
- T(n) = 1 + 2 + 4 + … + 2ᵏ = 2ᵏ⁺¹ − 1 < 2n
→ **O(n)**，选 B

⚠️ **常见错误**：看到外层 log n 次、内层最多 n 次，就乘起来得 O(n log n)——**错**！内层并不是每次都 n 次。

**例 3（2025 年第 1 题）**：
```c
int count = 0, i, j;
for (i = 1; i * i <= n; i++)
    for (j = 1; j <= i; j++)
        count++;
```
- 外层 i 从 1 到 √n
- 内层 i 次
- T(n) = 1 + 2 + … + √n = √n(√n + 1)/2 ≈ n/2
→ **O(n)**，选 B

**例 4（2014 年真题）**：
```c
count = 0;
for (k = 1; k <= n; k *= 2)
    for (j = 1; j <= n; j++)
        count++;
```
这次内层**与外层无关**，每次都是 n 次；外层 log₂n + 1 次 → **O(n log n)**

对比例 2 和例 4，一定要看清**内层循环的边界是 n 还是 i**！

**例 5**：三重循环
```c
for (i = 1; i <= n; i++)
    for (j = 1; j <= i; j++)
        for (k = 1; k <= j; k++)
            x++;
```
T = Σᵢ Σⱼ≤ᵢ j = Σᵢ i(i+1)/2 ≈ n³/6 → **O(n³)**

### 方法 5：递归算法 → 写递推式，展开求解

**例 1（2012 年真题）**：求 n! 的递归
```c
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
```
T(n) = T(n−1) + 1 = T(n−2) + 2 = … = T(1) + (n−1) → **O(n)**（空间复杂度也是 O(n)，递归深度 n）

**例 2**：二分递归
T(n) = T(n/2) + 1 → 每次规模减半，展开 log₂n 层 → **O(log n)**（折半查找）

**例 3**：归并排序
T(n) = 2T(n/2) + n
展开：
```
第 0 层：1 个规模 n 的问题，合并花 n
第 1 层：2 个规模 n/2 的问题，合并共花 2 × n/2 = n
第 2 层：4 个规模 n/4 的问题，合并共花 n
……
共 log₂n 层，每层 n
```
→ **O(n log n)**

**例 4**：T(n) = 2T(n−1) + 1（如汉诺塔、朴素的斐波那契）→ 每层问题数翻倍，共 n 层 → **O(2ⁿ)**

**常用递推式速查**：
| 递推式 | 结果 | 典型算法 |
|---|---|---|
| T(n) = T(n−1) + O(1) | O(n) | 递归求阶乘、遍历链表 |
| T(n) = T(n−1) + O(n) | O(n²) | 简单选择排序的递归版 |
| T(n) = T(n/2) + O(1) | O(log n) | 折半查找 |
| T(n) = T(n/2) + O(n) | O(n) | （每次处理一半）|
| T(n) = 2T(n/2) + O(1) | O(n) | 二叉树遍历 |
| T(n) = 2T(n/2) + O(n) | O(n log n) | 归并排序、快排最好情况 |
| T(n) = 2T(n−1) + O(1) | O(2ⁿ) | 汉诺塔 |

## 四、最好、最坏、平均时间复杂度

同一个算法，输入不同，执行次数可能不同。以“在数组中顺序查找 key”为例：
```c
for (i = 0; i < n; i++)
    if (a[i] == key) return i;
return -1;
```
- **最好**：key 在第一个 → 比较 1 次 → O(1)
- **最坏**：key 在最后或不存在 → 比较 n 次 → O(n)
- **平均**：假设 key 在每个位置概率相同 → (1 + 2 + … + n)/n = (n+1)/2 → O(n)

⚠️ **一般说“时间复杂度”，指的是最坏情况**（因为它给出了一个保证：再差也不会超过这个）。

其他例子：
| 算法 | 最好 | 最坏 | 平均 |
|---|---|---|---|
| 直接插入排序 | O(n)（已有序） | O(n²)（逆序） | O(n²) |
| 快速排序 | O(n log n) | O(n²)（已有序） | O(n log n) |
| 冒泡排序（带标志） | O(n) | O(n²) | O(n²) |

## 五、空间复杂度

### 📐 定义
算法**额外**使用的存储空间随 n 增长的趋势，记作 S(n) = O(g(n))。
- **不算**输入数据本身占的空间，只算**辅助空间**
- 只用了几个变量 → **O(1)**，称为“**原地工作**”
- 开了一个长度为 n 的辅助数组 → O(n)
- 开了 n×n 的二维数组 → O(n²)
- **递归**：空间 = 递归深度 × 每层所需空间

| 算法 | 空间复杂度 | 原因 |
|---|---|---|
| 顺序查找、冒泡排序 | O(1) | 只用几个变量 |
| 归并排序 | O(n) | 需要辅助数组 |
| 快速排序 | O(log n) ~ O(n) | 递归栈深度 |
| 递归求阶乘 | O(n) | 递归深度 n |
| 二叉树递归遍历 | O(h) | h 是树高 |

> 💡 第 41 题写复杂度时，**空间复杂度 O(1) 往往是加分项**。“用辅助数组换时间”的算法空间是 O(n)，也完全可以（大部分题只要求“尽可能高效”）。

## 📝 真题集中训练

**1.（2022 年第 1 题）** 见上文方法 4 例 2 → O(n)

**2.（2025 年第 1 题）** 见上文方法 4 例 3 → O(n)

**3.（2013 年第 1 题）** 已知两个长度分别为 m 和 n 的升序链表，合并为一个长度为 m+n 的降序链表，最坏情况下的时间复杂度是？
→ 合并时每比较一次就取走一个结点，最坏要把两个链表都走完，共 m+n 次，即 **O(max(m, n))**（O(m+n) 与 O(max(m,n)) 同阶）

**4.** 下面程序段的时间复杂度？
```c
for (i = 0; i < n; i++)
    for (j = i; j < n; j++)
        for (k = 0; k < 10; k++)
            x++;
```
→ 最内层固定 10 次（常数），中间两层共 n + (n−1) + … + 1 = n(n+1)/2 → **O(n²)**

**5.** 下面递归函数的时间复杂度？
```c
void f(int n) {
    if (n <= 1) return;
    for (int i = 0; i < n; i++) x++;
    f(n / 2);
}
```
→ T(n) = T(n/2) + n = n + n/2 + n/4 + … < 2n → **O(n)**

## ⚠️ 易错点汇总
1. 内层边界依赖外层变量时，**必须逐层求和**，不能直接相乘
2. 看清是 `i *= 2`（对数）还是 `i++`（线性）
3. `i * i <= n` 意味着 i 最多到 √n
4. 时间复杂度默认指**最坏**情况
5. 空间复杂度**不含输入数据本身**，递归要算栈空间
6. O(log n) 不写底数

## 📋 本课小结

| 方法 | 适用 | 做法 |
|---|---|---|
| 1 独立嵌套 | 各层边界互不相关 | 相乘 |
| 2 乘除变化 | `i *= 2`、`i /= 3` | 设 k 次，解 2ᵏ = n → log n |
| 3 平方/累加条件 | `i*i <= n`、`sum += i` | 设 k 次，解 k² = n → √n |
| 4 依赖嵌套 | 内层边界含外层变量 | 逐层求和（等差、等比） |
| 5 递归 | 递归函数 | 写递推式，展开 |

常见阶：**常 < 对 < 幂 < 指 < 阶**

## 🏋️ 课后练习

求下列程序段的时间复杂度：
1. ```c
   for (i = 1; i <= n; i = i * 2)
       for (j = 1; j <= i; j++) x++;
   ```
2. ```c
   i = n * n;
   while (i != 1) i = i / 2;
   ```
3. ```c
   for (i = 1; i <= n; i++)
       for (j = 1; j <= n; j = j * 2) x++;
   ```
4. ```c
   y = 0;
   while ((y + 1) * (y + 1) * (y + 1) <= n) y++;
   ```
5. ```c
   int f(int n) { if (n == 0) return 1; return f(n - 1) + f(n - 1); }
   ```
6. 在一个长度为 n 的有序数组中，先用折半查找找到 key 的位置，再把 key 之后的元素全部后移一位。整个过程的时间复杂度？

<details>
<summary>📖 答案</summary>

1. 1 + 2 + 4 + … + n ≈ 2n → **O(n)**
2. i 从 n² 每次减半到 1，次数 log₂(n²) = 2log₂n → **O(log n)**
3. 外层 n 次，内层 log₂n 次（与 i 无关）→ **O(n log n)**
4. y³ ≤ n → y ≈ ∛n → **O(n^(1/3))**
5. T(n) = 2T(n−1) + 1 → **O(2ⁿ)**
6. 折半 O(log n) + 移动 O(n) → 加法规则取大者 **O(n)**
</details>
