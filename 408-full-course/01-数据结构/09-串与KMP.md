## 一、串的基本概念

### 📐 定义
**串（字符串）**是由零个或多个字符组成的**有限序列**。记作 S = 'a₁a₂…aₙ'。
- **串长**：字符个数 n；n = 0 时为**空串**（注意：空格串 ' ' 不是空串，它的长度是 1）
- **子串**：串中任意多个**连续**字符组成的子序列（空串也是子串）
- **主串**：包含子串的串
- **字符在串中的位置**：字符的序号（从 1 开始）
- **子串在主串中的位置**：子串**第一个字符**在主串中的位置

📐 **子串个数**（⭐ 小计算）：长度为 n 的串（字符互不相同），
- 非空子串个数 = n + (n−1) + … + 1 = **n(n+1)/2**
- 加上空串共 **n(n+1)/2 + 1** 个
- 例：'abc' 的子串：a, b, c, ab, bc, abc + 空串 = 7 个

### 📐 串 vs 线性表
- 串的逻辑结构和线性表**极其相似**，区别是：串的数据对象**限定为字符集**
- 线性表的操作以**单个元素**为对象；串的操作通常以**子串**为对象（查找子串、插入子串、删除子串）

### 📐 基本操作
StrAssign（赋值）、StrCopy（复制）、StrEmpty、StrLength、**StrCompare**（比较）、Concat（连接）、SubString（求子串）、**Index（定位/模式匹配）**、ClearString、DestroyString

**串比较规则**：从第一个字符开始逐个比较，第一个不同的字符决定大小（按字符编码）；若一个是另一个的前缀，则**长的大**。
例：'abc' < 'abd'；'ab' < 'abc'；'b' > 'abcdef'

### 📐 存储结构
1. **定长顺序存储**：用固定长度的字符数组，超出部分被截断
   ```c
   #define MAXLEN 255
   typedef struct {
       char ch[MAXLEN];   // 教材常让 ch[0] 空着不用，使字符位序与下标一致
       int length;
   } SString;
   ```
2. **堆分配存储**：用 malloc 动态分配，长度可变
3. **块链存储**：用链表，每个结点存**多个字符**（每个结点存 1 个字符时存储密度太低）

## 二、朴素模式匹配算法（暴力法）

### 📐 问题
**模式匹配**：在主串 S 中找到与模式串 T 相同的子串，返回其位置。

### 📐 思想
从主串的第 1 个字符开始，和模式串逐个比较：
- 全部相同 → 匹配成功
- 遇到不同 → 主串回到**本趟起点的下一个位置**，模式串回到第 1 个字符，重新比较

```c
int Index(SString S, SString T) {          // 串下标从 1 开始
    int i = 1, j = 1;
    while (i <= S.length && j <= T.length) {
        if (S.ch[i] == T.ch[j]) { i++; j++; }  // 继续比较后继字符
        else { i = i - j + 2; j = 1; }         // 指针回退，重新开始
    }
    if (j > T.length) return i - T.length;     // 匹配成功
    return 0;
}
```
🧒 **i = i − j + 2 是什么意思？** 本趟从主串的 i − j + 1 位置开始（已经比较了 j − 1 个），下一趟从它的下一个位置开始，即 i − j + 2。

### 📐 例子
S = 'ababcabcacbab'，T = 'abcac'
```
第1趟：a b a b c ...        第 3 个字符失配（a≠c）
       a b c
第2趟：  b ...              第 1 个就失配
         a
第3趟：    a b c a b ...    第 5 个字符失配（b≠c）
           a b c a c
第4趟：      b              失配
第5趟：        c            失配
第6趟：          a b c a c  成功！位置 6
```

### 📐 复杂度
设主串长 n，模式串长 m：
- **最好**：第一趟就成功，比较 m 次，O(m)
- **最坏**：每趟都比较到模式串最后一个字符才失配，O(nm)
  - 例：S = 'aaa…ab'，T = 'aa…ab'
- **缺点**：**主串指针 i 经常回退**，已经比较过的信息被浪费了

## 三、KMP 算法（⭐⭐⭐）

### 🚪 引入：一个聪明的发现

S = 'abaab**x**...'，T = 'abaab**c**'，比到第 6 个字符时失配（x ≠ c）。
朴素算法：主串退回第 2 个字符，模式串从头开始。

但是！我们**已经知道**主串的前 5 个字符是 'abaab'（因为和模式串匹配成功了）。
观察 'abaab'：
- 它的**开头** 'ab' 和**结尾** 'ab' 一样！
- 所以可以直接把模式串的开头 'ab' 对准主串中刚才那段的结尾 'ab'，**从模式串第 3 个字符开始**和主串的 x 比较

```
主串：    a b a a b x ...
模式串：  a b a a b c           ← 第 6 位失配
                ↓ 直接滑动
主串：    a b a a b x ...
模式串：        a b a a b c     ← 前两个 ab 已知相等，从 T[3] 与 x 比较
```
**主串指针 i 不动**（还是指着 x），只有模式串的 j 从 6 变成 3。

KMP 的核心就是：**失配时，主串指针不回退，模式串根据自身的结构“聪明地”滑动。** 而滑动多少，**只和模式串自己有关**，和主串无关，所以可以**提前算好**。

### 3.1 前缀、后缀、部分匹配值（PM）

- **前缀**：除最后一个字符外，字符串的所有**头部**子串
- **后缀**：除第一个字符外，字符串的所有**尾部**子串
- **部分匹配值（PM）**：字符串的**最长相等前后缀**的长度

以 'ababa' 为例：
- 前缀：a, ab, aba, abab
- 后缀：a, ba, aba, baba
- 相等的：a、aba，最长是 'aba'，长度 **3**

**求模式串每个前缀子串的 PM 值**：T = 'abaabc'
| 子串 | 前缀集合 | 后缀集合 | 最长相等 | PM |
|---|---|---|---|---|
| a | ∅ | ∅ | — | **0** |
| ab | {a} | {b} | — | **0** |
| aba | {a, ab} | {a, ba} | a | **1** |
| abaa | {a, ab, aba} | {a, aa, baa} | a | **1** |
| abaab | {a, ab, aba, abaa} | {b, ab, aab, baab} | ab | **2** |
| abaabc | {a, …, abaab} | {c, bc, …} | — | **0** |

| j | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| T | a | b | a | a | b | c |
| PM | 0 | 0 | 1 | 1 | 2 | 0 |

### 3.2 利用 PM 求滑动距离
在第 j 个字符失配时，已经匹配成功了前 j − 1 个字符，查看**前 j − 1 个字符的 PM 值**（即 PM[j−1]）：
$$\text{模式串右移位数} = \text{已匹配字符数} - \text{对应的部分匹配值} = (j - 1) - PM[j-1]$$
上例：第 6 个字符失配，已匹配 5 个，PM[5] = 2 → 右移 5 − 2 = 3 位，模式串的第 3 个字符对准主串当前字符。

### 3.3 next 数组（⭐⭐⭐）
为了写程序方便，我们直接记录“**第 j 个字符失配时，下一步用模式串的第几个字符和主串当前字符比较**”，这就是 **next[j]**。

**由 PM 得到 next（串下标从 1 开始，王道/严蔚敏教材写法）**：
1. 把 PM 数组**整体右移一位**，最左边空出来的补 −1，最右边溢出的丢掉
2. 整体 **+1**

| j | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| T | a | b | a | a | b | c |
| PM | 0 | 0 | 1 | 1 | 2 | 0 |
| 右移（补 −1） | −1 | 0 | 0 | 1 | 1 | 2 |
| **next** | **0** | **1** | **1** | **2** | **2** | **3** |

**直接求 next 的规则**（更快）：
- **next[1] = 0**（第 1 个就失配：模式串无法再滑，主串指针后移一位，模式串从头比）
- **next[2] = 1**
- j ≥ 3 时：**next[j] = (前 j − 1 个字符的最长相等前后缀长度) + 1**

🧒 **next[j] 的含义**：在第 j 个字符失配时，前面已知有 PM 个字符匹配好了，下一步就比第 PM + 1 个。

> ⚠️ **两种写法要分清**：若串的下标从 **0** 开始（很多 C 程序这么写），next 就是“PM 右移一位、首位补 −1”，**不加 1**：next = [−1, 0, 0, 1, 1, 2]。题目会说明，或者从选项里的数字判断。

### 3.4 KMP 匹配算法代码
```c
int Index_KMP(SString S, SString T, int next[]) {
    int i = 1, j = 1;
    while (i <= S.length && j <= T.length) {
        if (j == 0 || S.ch[i] == T.ch[j]) {   // j==0 表示第 1 个字符就失配
            i++; j++;                          // 继续比较后继字符
        } else {
            j = next[j];                       // 模式串滑动，i 不变！
        }
    }
    if (j > T.length) return i - T.length;
    return 0;
}
```
对比朴素算法：失配时只有一句 `j = next[j]`，**i 永远不回退**。

### 3.5 求 next 数组的代码（了解，理解思路即可）
```c
void get_next(SString T, int next[]) {
    int i = 1, j = 0;
    next[1] = 0;
    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            i++; j++;
            next[i] = j;            // 若 T[i]==T[j]，则 next[i+1] = next[i] + 1
        } else {
            j = next[j];            // 否则 j 回溯（本质上是“模式串自己和自己做 KMP”）
        }
    }
}
```
🧒 这段代码的思想是：已知 next[i] = j（前 j−1 个字符是相等前后缀），看 T[i] 和 T[j]：相等，则前后缀可以再延长一个，next[i+1] = j + 1；不等，就退而求其次，看更短的前后缀 next[j]。

### 3.6 完整模拟一次 KMP 匹配（⭐⭐ 考比较次数）

📝 **真题（2019 年真题）**：主串 T = 'abaabaabcabaabc'，模式串 S = 'abaabc'，采用 KMP 算法，到匹配成功时为止，**单个字符之间的比较次数**是？

模式串 next = [0, 1, 1, 2, 2, 3]（上面算过）

| 比较次数 | 主串位置 i | 主串字符 | 模式串位置 j | 模式串字符 | 结果 |
|---|---|---|---|---|---|
| 1 | 1 | a | 1 | a | ✓ |
| 2 | 2 | b | 2 | b | ✓ |
| 3 | 3 | a | 3 | a | ✓ |
| 4 | 4 | a | 4 | a | ✓ |
| 5 | 5 | b | 5 | b | ✓ |
| 6 | 6 | a | 6 | c | ✗ → j = next[6] = 3 |
| 7 | 6 | a | 3 | a | ✓（i 没有回退！） |
| 8 | 7 | a | 4 | a | ✓ |
| 9 | 8 | b | 5 | b | ✓ |
| 10 | 9 | c | 6 | c | ✓ 匹配成功 |

共 **10 次**，选 B。（匹配位置在主串第 4 个字符。朴素算法需要 15 次。）

📝 **真题（2015 年真题）**：字符串 S = 'abaabaabacacaabaabcc'，模式串 t = 'abaabc'。采用 KMP 算法匹配，第一次出现“失配”（s[i] ≠ t[j]）时，**i = j = 5**，则下次开始匹配时，i 和 j 的值分别是？
- 这里 i = j = 5 说明**下标从 0 开始**（第 6 个字符失配）
- 下标从 0 开始的 next = PM 右移补 −1：[−1, 0, 0, 1, 1, 2]
- i 不变 = **5**；j = next[5] = **2**
- 答案 **i = 5，j = 2**
（换成下标从 1 的写法：第 6 个字符失配，j = next[6] = 3，即模式串第 3 个字符——下标 2，是同一个意思。）

### 3.7 KMP 的复杂度
- 求 next 数组：O(m)
- 匹配过程：O(n)（主串指针只进不退）
- **总计 O(n + m)**

⚠️ KMP 的优势在于**主串与模式串有很多“部分匹配”**时。一般情况下朴素算法的实际执行时间也接近 O(n + m)，所以朴素算法至今仍被广泛使用。

## 四、nextval 数组（KMP 的进一步优化，⭐⭐）

### 🚪 问题
T = 'aaaab'，next = [0, 1, 2, 3, 4]。
主串 'aaabaaaab'，在第 4 个字符失配（主串 b ≠ 模式串 a）：
- j = next[4] = 3，比较 T[3] = 'a' 和 'b' → 失配
- j = next[3] = 2，比较 T[2] = 'a' → 失配
- j = next[2] = 1，比较 T[1] = 'a' → 失配
- j = next[1] = 0 → 主串后移

明明 T[4] = T[3] = T[2] = T[1] = 'a'，T[4] 和 'b' 不等，那 T[3]、T[2]、T[1] **必然也不等**，这些比较都是白费的！

### 📐 优化规则
若 **T[j] == T[next[j]]**，说明跳过去之后还会失配，干脆继续跳：
$$\text{nextval}[j] = \begin{cases} \text{nextval}[\text{next}[j]], & T[j] = T[\text{next}[j]] \\ \text{next}[j], & T[j] \ne T[\text{next}[j]] \end{cases}$$
nextval[1] = 0。**从左往右**依次计算（因为要用到前面已算好的 nextval）。

### ✏️ 例：求 'aaaab' 的 nextval
| j | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| T | a | a | a | a | b |
| next | 0 | 1 | 2 | 3 | 4 |
| T[next[j]] | — | T[1]=a | T[2]=a | T[3]=a | T[4]=a |
| 相等？ | — | 是 | 是 | 是 | 否（b≠a） |
| **nextval** | **0** | nextval[1]=**0** | nextval[2]=**0** | nextval[3]=**0** | next[5]=**4** |

### ✏️ 例：求 'abaabc' 的 nextval
| j | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| T | a | b | a | a | b | c |
| next | 0 | 1 | 1 | 2 | 2 | 3 |
| T[next[j]] | — | a | a | b | b | a |
| 相等？ | — | 否 | 是 | 否 | 是 | 否 |
| **nextval** | **0** | **1** | nextval[1]=**0** | **2** | nextval[2]=**1** | **3** |

### ✏️ 例：求 'ababaa' 的 next 和 nextval
PM：a 0，ab 0，aba 1，abab 2，ababa 3，ababaa 1
| j | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| T | a | b | a | b | a | a |
| next | 0 | 1 | 1 | 2 | 3 | 4 |
| nextval | 0 | 1 | 0 | 1 | 0 | 4 |
（j = 3：T[3]=a，T[next[3]]=T[1]=a，相等 → nextval[1] = 0；j = 4：T[4]=b，T[2]=b，相等 → nextval[2] = 1；j = 5：T[5]=a，T[3]=a，相等 → nextval[3] = 0；j = 6：T[6]=a，T[4]=b，不等 → next[6] = 4）

## 五、考试答题技巧总结

1. **求 next**：先写 PM 表（逐个前缀子串求最长相等前后缀），再“右移一位、补 −1、全部 +1”
2. **看清下标从 0 还是 1**：从 0 开始的 next 不加 1（首项 −1）
3. **模拟匹配**：画表格，列出每次比较的 i、j；失配时 **i 不变**，j = next[j]；j = 0 时 i、j 都加 1
4. **比较次数**：每次“字符与字符的比较”算一次，j = 0 的情况不算比较
5. **nextval**：从左往右，T[j] 和 T[next[j]] 相等就“继承” nextval[next[j]]

---

## ⚠️ 易错点
1. 空串 ≠ 空格串
2. 子串要求**连续**
3. 前后缀都**不能是整个串本身**
4. KMP 失配时**主串指针不回退**
5. next 数组有两种写法（下标从 0 或 1）
6. nextval 计算要从左往右，用已算出的 nextval

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 子串个数 | n(n+1)/2 + 1（含空串，字符互不相同时） |
| 朴素匹配 | 失配时 i = i − j + 2，j = 1；最坏 O(nm) |
| PM | 最长相等前后缀长度 |
| next（下标从 1） | next[1]=0，next[2]=1，next[j] = PM[j−1] + 1 |
| KMP 失配 | i 不动，j = next[j]；j=0 时 i++、j++ |
| 复杂度 | O(n + m) |
| nextval | T[j]==T[next[j]] ? nextval[next[j]] : next[j] |
