## 一、归并排序（⭐⭐⭐）

### 📐 “归并”的含义
把**两个或多个已经有序的表**合并成**一个新的有序表**。

📝 **真题（2022 年第 10 题）**：使用二路归并排序对含 n 个元素的数组 M 进行排序时，二路归并操作的功能是：
A. **将两个有序表合并为一个新的有序表** ✓
B. 将 M 划分为两部分，两部分的元素个数大致相等 ✗（这是“分解”，不是“归并”）
C. 将 M 划分为 n 个部分，每个部分中仅含有一个元素 ✗
D. 将 M 划分为两部分，一部分元素的值均小于另一部分元素的值 ✗（这是快排的划分）

### 📐 Merge 代码（⭐⭐）
```c
ElemType *B = (ElemType *)malloc((n + 1) * sizeof(ElemType));   // 辅助数组

// 把 A[low..mid] 和 A[mid+1..high] 两个有序段归并成一个有序段
void Merge(ElemType A[], int low, int mid, int high) {
    int i, j, k;
    for (k = low; k <= high; k++) B[k] = A[k];        // 先复制到 B
    for (i = low, j = mid + 1, k = i; i <= mid && j <= high; k++) {
        if (B[i] <= B[j]) A[k] = B[i++];              // 相等时取前一段的 → 稳定
        else A[k] = B[j++];
    }
    while (i <= mid) A[k++] = B[i++];                 // 前一段剩余
    while (j <= high) A[k++] = B[j++];                // 后一段剩余
}

void MergeSort(ElemType A[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        MergeSort(A, low, mid);                        // 左半部分排序
        MergeSort(A, mid + 1, high);                   // 右半部分排序
        Merge(A, low, mid, high);                      // 归并
    }
}
```

### ✏️ 过程演示（自底向上看“趟”）
初始：**49 38 65 97 76 13 27**
```
初始:        [49] [38] [65] [97] [76] [13] [27]       每个元素看成一个有序段
第 1 趟:     [38 49] [65 97] [13 76] [27]              两两归并
第 2 趟:     [38 49 65 97] [13 27 76]
第 3 趟:     [13 27 38 49 65 76 97]
```
- 二路归并的**趟数 = ⌈log₂n⌉**
- **判断是否是归并排序的某趟结果**：第 1 趟后每 2 个一组有序，第 2 趟后每 4 个一组有序……

### 📐 性能
- 每趟归并 O(n)，共 ⌈log₂n⌉ 趟 → 时间 **O(n log n)**（最好、最坏、平均**都一样**，与初始状态无关）
- 空间 **O(n)**（辅助数组 B），这是它的主要缺点
- **稳定**（相等时先取前一段的）
- 递归形式的归并排序，还需要 O(log n) 的栈空间，但 O(n) 占主导

### 📐 k 路归并
一般地，对 n 个元素进行 **k 路归并**排序，趟数 **m = ⌈log_k n⌉**。k 路归并主要用于**外部排序**（下一课）。

## 二、基数排序（⭐⭐）

### 📐 思想
**不基于比较**，而是按关键字的**各个位**来排序。借助“**分配**”和“**收集**”两种操作。
设关键字是 d 位数，每位有 r 种取值（**基数** r，十进制 r = 10）：
- **最低位优先（LSD）**：先按**个位**分配、收集；再按十位；……最后按最高位。每一趟必须**稳定**
- **最高位优先（MSD）**：先按最高位分成若干组，每组再递归按次高位分……

LSD 最常用。**分配**：按当前位的值，把元素依次放入 r 个队列（Q₀~Q₉）；**收集**：把 r 个队列**首尾相接**，按 Q₀、Q₁、…、Q₉ 的顺序连成一个序列。

### ✏️ 真题（2021 年第 10 题）
> 设数组 S[] = {93, 946, 372, 9, 146, 151, 301, 485, 236, 327, 43, 892}，采用 LSD 基数排序将 S 排列成升序序列。第 1 趟分配、收集后，元素 372 之前、之后紧邻的元素分别是：A. 43, 892 B. 236, 301 C. 301, 892 D. 485, 301

**第 1 趟（按个位分配）**：按原序列顺序依次放入队列
```
Q0: 
Q1: 151 → 301
Q2: 372 → 892
Q3: 93 → 43
Q4:
Q5: 485
Q6: 946 → 146 → 236
Q7: 327
Q8:
Q9: 9
```
**收集**：151 301 **372** 892 93 43 485 946 146 236 327 9
→ 372 前面是 **301**，后面是 **892**，选 C

**继续完成排序**（理解全过程）：
**第 2 趟（按十位）**：
```
Q0: 301 → 9（9 的十位是 0）
Q2: 327
Q3: 236
Q4: 43 → 946 → 146
Q5: 151
Q7: 372
Q8: 485
Q9: 892 → 93
```
收集：301 9 327 236 43 946 146 151 372 485 892 93

**第 3 趟（按百位）**：
```
Q0: 9 → 43 → 93
Q1: 146 → 151
Q2: 236
Q3: 301 → 327 → 372
Q4: 485
Q8: 892
Q9: 946
```
收集：**9 43 93 146 151 236 301 327 372 485 892 946** ✓ 有序

🧒 **为什么 LSD 能排对？** 每一趟分配时，**同一个队列里的元素保持上一趟的相对顺序**（稳定）。按百位分到同一个队列的元素（如 301、327、372），它们的相对顺序是上一趟（按十位）排好的，而上一趟又保持了按个位排好的顺序……所以最终整体有序。

### 📐 性能
- 一趟分配 O(n)，一趟收集 O(r)，共 d 趟 → 时间 **O(d(n + r))**，**与初始状态无关**
- 空间 **O(r)**（r 个队列的头尾指针；通常用链式存储，元素本身不需要额外空间）
- **稳定**
- 适用：关键字可以方便地拆分成 d 位、d 和 r 不太大、n 很大的情况（如 10000 个学生按生日排序）

## 三、计数排序（⭐ 2021 年第 42 题原题）

📝 **真题（2021 年第 42 题，8 分）**：已知某排序算法如下：
```c
void cmpCountSort(int a[], int b[], int n) {
    int i, j, *count;
    count = (int *)malloc(sizeof(int) * n);
    for (i = 0; i < n; i++) count[i] = 0;
    for (i = 0; i < n - 1; i++)
        for (j = i + 1; j < n; j++)
            if (a[i] < a[j]) count[j]++;
            else count[i]++;
    for (i = 0; i < n; i++) b[count[i]] = a[i];
    free(count);
}
```
(1) 若有 `int a[] = {25, -10, 25, 10, 11, 19}, b[6];`，则调用 cmpCountSort(a, b, 6) 后数组 b 中的内容是什么？
(2) 若 a 中含有 n 个元素，则算法执行过程中，元素之间的比较次数是多少？
(3) 该算法是稳定的吗？若是，则阐述理由；否则，修改为稳定排序算法。

**理解算法**：对每一对 (i, j)，i < j，比较 a[i] 和 a[j]，**较大的那个 count 加 1**（相等时 count[i] 加 1）。最终 **count[i] = 比 a[i] 小的元素个数**（再加上相等且排在它后面的个数），这正是 a[i] 在有序数组中的**下标**！

**(1)** 计算 count：
| i | a[i] | 比它小的 | 相等的影响 | count[i] |
|---|---|---|---|---|
| 0 | 25 | −10, 10, 11, 19 → 4 | 与 a[2]=25 相等，i=0 < 2，count[0]++ → 5 | **5** |
| 1 | −10 | 0 | | **0** |
| 2 | 25 | 4 | 与 a[0] 相等时加的是 count[0] | **4** |
| 3 | 10 | −10 → 1 | | **1** |
| 4 | 11 | −10, 10 → 2 | | **2** |
| 5 | 19 | −10, 10, 11 → 3 | | **3** |
b[5] = 25（a[0]），b[0] = −10，b[4] = 25（a[2]），b[1] = 10，b[2] = 11，b[3] = 19
→ **b = {−10, 10, 11, 19, 25, 25}**

**(2)** 比较次数：每对 (i, j) 比较一次，共 C(n, 2) = **n(n − 1)/2** 次

**(3)** **不稳定**。当 a[i] == a[j] 且 i < j 时，执行 else 分支 count[i]++，使**前面的**元素排到了**后面**（上例中 a[0] 的 25 放到了 b[5]，a[2] 的 25 放到了 b[4]，顺序颠倒）。
**修改**：把 `if (a[i] < a[j])` 改为 **`if (a[i] <= a[j])`**，相等时让后面的元素 count[j]++，排在后面，就稳定了。

## 四、内部排序算法的比较（⭐⭐⭐ 考前必背）

### 📊 总表
| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 | 一趟后能确定一个元素的最终位置？ |
|---|---|---|---|---|---|---|
| 直接插入 | **O(n)** | O(n²) | O(n²) | O(1) | ✓ | ✗ |
| 折半插入 | O(n log n)* | O(n²) | O(n²) | O(1) | ✓ | ✗ |
| 希尔 | — | ≈O(n^1.3) | O(n²) | O(1) | ✗ | ✗ |
| 冒泡 | **O(n)** | O(n²) | O(n²) | O(1) | ✓ | ✓ |
| 快速 | O(n log n) | **O(n log n)** | **O(n²)** | **O(log n)** | ✗ | ✓（枢轴） |
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | ✗ | ✓ |
| 堆 | O(n log n) | O(n log n) | O(n log n) | O(1) | ✗ | ✓（堆顶） |
| 二路归并 | O(n log n) | O(n log n) | O(n log n) | **O(n)** | ✓ | ✗ |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(r) | ✓ | ✗ |
\* 指比较次数

### 🧒 记忆口诀
- **不稳定**：“**快些选堆**”（**快**速、希尔（**些**）、**选**择、**堆**）——“心情不稳定，快些选一堆朋友来聊天”
- **平均 O(n log n)**：“**快归堆**”（快速、归并、堆）
- **空间不是 O(1)**：快速 O(log n)、归并 O(n)、基数 O(r)
- **最好 O(n)**：直接插入、冒泡（初始有序时）
- **与初始状态无关**：
  - **时间复杂度**与初始状态无关：简单选择、堆排序、归并排序、基数排序
  - **比较次数**与初始状态无关：简单选择（n(n−1)/2）、折半插入
  - **趟数**与初始状态无关：直接插入（n−1 趟）、简单选择、归并、基数；**冒泡和快排的趟数与初始状态有关**
- **每趟能确定一个元素最终位置**：冒泡、快速、简单选择、堆

📝 **真题（2023 年第 10 题）**：下列排序算法中，不稳定的是：I. 希尔排序 II. 归并排序 III. 快速排序 IV. 堆排序 V. 基数排序
→ **I、III、IV**（快些选堆），选 C

### 📐 如何选择排序算法（⭐⭐）
| 情况 | 推荐 |
|---|---|
| n 较小（如 n ≤ 50） | 直接插入 或 简单选择（记录本身很大时选简单选择，移动少） |
| **基本有序** | 直接插入、冒泡 |
| n 较大，追求平均最快 | **快速排序** |
| n 较大，要求**最坏也快**、空间 O(1) | **堆排序** |
| n 较大，要求**稳定** | **归并排序** |
| n 很大，关键字位数少、可分解 | **基数排序** |
| 链表存储 | 直接插入、冒泡、简单选择、归并、基数（**不能用**希尔、快排（一般说法）、堆、折半插入） |
| 要求稳定 + O(1) 空间 | 直接插入、冒泡（O(n²)） |

📝 **真题（2022 年第 11 题）**：采用直接插入而不采用快速排序，可能的原因：大部分元素已有序、元素很少、要求 O(1) 空间、要求稳定 → **全部**。（详见第 27 课）

---

## ⚠️ 易错点
1. 归并排序的空间是 **O(n)**，这是它唯一的缺点
2. 归并的“归并操作”是**合并两个有序表**，不是划分
3. 基数排序每趟必须稳定；LSD 从**个位**开始
4. 基数排序时间 O(d(n + r))，**不基于比较**，不受 Ω(n log n) 下界限制
5. 计数排序 count[i] = 比 a[i] 小的元素个数（+ 相等时的调整）
6. 冒泡、快排的趟数与初始状态有关

---

## 📋 本课小结

| 算法 | 时间 | 空间 | 稳定 | 要点 |
|---|---|---|---|---|
| 二路归并 | O(n log n) | O(n) | ✓ | 趟数 ⌈log₂n⌉；与初始状态无关 |
| 基数（LSD） | O(d(n+r)) | O(r) | ✓ | 分配 + 收集；从低位到高位 |
| 计数（比较型） | O(n²) | O(n) | 改 ≤ 后稳定 | count[i] 即最终下标 |
