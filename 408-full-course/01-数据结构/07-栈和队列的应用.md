## 一、括号匹配（⭐⭐）

### 🚪 引入
写代码时，编辑器会检查 `{ [ ( ) ] }` 是否配对。规则是：**最后出现的左括号，最先被匹配**——这正是栈的“后进先出”！

### 📐 算法
从左到右扫描：
1. 遇到**左括号**：入栈
2. 遇到**右括号**：
   - 栈空 → 失败（右括号多了）
   - 栈顶是**配对**的左括号 → 出栈
   - 栈顶**不配对** → 失败（类型不匹配）
3. 扫描结束：栈**空**则成功；**非空**则失败（左括号多了）

```c
bool BracketCheck(char str[], int length) {
    SqStack S;
    InitStack(S);
    for (int i = 0; i < length; i++) {
        if (str[i] == '(' || str[i] == '[' || str[i] == '{') {
            Push(S, str[i]);
        } else if (str[i] == ')' || str[i] == ']' || str[i] == '}') {
            if (StackEmpty(S)) return false;        // 右括号单身
            char top;
            Pop(S, top);
            if (str[i] == ')' && top != '(') return false;
            if (str[i] == ']' && top != '[') return false;
            if (str[i] == '}' && top != '{') return false;
        }
        // 其他字符（字母、运算符）直接跳过
    }
    return StackEmpty(S);                           // 左括号单身则失败
}
```

**演示**：`{ [ ( ) ( ) ] }`
| 字符 | 操作 | 栈（左为底） |
|---|---|---|
| { | 入栈 | { |
| [ | 入栈 | { [ |
| ( | 入栈 | { [ ( |
| ) | 与 ( 匹配，出栈 | { [ |
| ( | 入栈 | { [ ( |
| ) | 匹配，出栈 | { [ |
| ] | 匹配，出栈 | { |
| } | 匹配，出栈 | 空 → **成功** |

### 📝 真题（2025 年第 2 题）
> 算法 A 检查字符串中各类括号是否匹配，执行时使用初始为空的栈保存遇到的括号。若栈的容量是 3，则 A **不能处理**的是：
> A. （选项 A 的表达式，括号最多嵌套 3 层，此处从略）
> B. `[(a*(b+c)/(d−e)+/g−h]`
> C. `(a*[b−(c−d)*e/(f+g)]−h)`
> D. `[a−(b+[c*(d+e)−f]+g+h)]`

🧒 “栈容量 3 不能处理”= **某一时刻栈里需要超过 3 个括号** = 括号**嵌套深度 > 3**。
逐个数最大嵌套层数：
- B：`[ ( (` 最多 3 层
- C：`( [ (` 最多 3 层（`(f+g)` 时是 `( [ (`，也是 3 层）
- D：`[ ( [ (` —— 在 `(d+e)` 处，栈中有 `[ ( [ (` **4 个** ✗
- A 最多也是 3 层
答案 **D**。

## 二、表达式求值（⭐⭐⭐）

### 🚪 引入
我们平时写 `3 + 4 * 2`，知道要先算乘法。但计算机从左往右读，怎么知道谁先算？括号又怎么处理？
波兰数学家发明了一种**不需要括号**、**不需要优先级**的写法。

### 📐 三种表达式
| 名称 | 运算符位置 | 例子（a + b × c） | 别名 |
|---|---|---|---|
| **中缀表达式** | 在两个操作数**中间** | a + b * c | 人类习惯 |
| **前缀表达式** | 在两个操作数**前面** | + a * b c | 波兰式 |
| **后缀表达式** | 在两个操作数**后面** | a b c * + | **逆波兰式** |

前缀和后缀表达式**没有括号**，而且运算顺序是唯一确定的！

### 📐 手工转换：加括号法（⭐ 考场最快）
**中缀 → 后缀**：
1. 按运算顺序给**每一次运算**加上括号
2. 把每个运算符**移到它所在括号的右括号后面**
3. 去掉所有括号

**中缀 → 前缀**：第 2 步改成**移到左括号前面**。

**例 1**：`a + b * (c - d) - e / f`
```
1. 加括号：((a + (b * (c - d))) - (e / f))
2. 后缀：运算符挪到右括号后
   ((a (b (c d)-)*)+ (e f)/)-
3. 去括号：a b c d - * + e f / -

前缀：运算符挪到左括号前
   -(+(a *(b -(c d))) /(e f))
   → - + a * b - c d / e f
```

**例 2**：`(a + b) * (c - d / e)`
```
加括号：((a + b) * (c - (d / e)))
后缀：a b + c d e / - *
前缀：* + a b - c / d e
```

### 📐 后缀表达式求值（用**操作数栈**，⭐⭐）
从左到右扫描：
1. 遇到**操作数** → 入栈
2. 遇到**运算符** → 弹出两个操作数，**先弹出的是右操作数**，后弹出的是左操作数，计算 `左 op 右`，结果入栈
3. 扫描结束，栈中唯一的元素就是结果

**例**：计算后缀表达式 `6 2 / 3 1 - 2 * +`（即中缀 6/2 + (3−1)*2）
| 扫描 | 操作 | 栈 |
|---|---|---|
| 6 | 入栈 | 6 |
| 2 | 入栈 | 6 2 |
| / | 弹出 2（右）、6（左），6/2 = 3 | 3 |
| 3 | 入栈 | 3 3 |
| 1 | 入栈 | 3 3 1 |
| − | 弹出 1、3，3−1 = 2 | 3 2 |
| 2 | 入栈 | 3 2 2 |
| * | 弹出 2、2，2*2 = 4 | 3 4 |
| + | 弹出 4、3，3+4 = 7 | **7** |

⚠️ **减法和除法要注意顺序**：先弹出的是**右**操作数。弹出 2 再弹出 6，是 6 / 2 而不是 2 / 6。

**前缀表达式求值**：**从右往左**扫描，遇到运算符时先弹出的是**左**操作数。

### 📐 用栈把中缀转后缀（用**运算符栈**，⭐⭐⭐ 选择题考“栈中内容”）
从左到右扫描中缀表达式，用一个栈存**暂时还不能确定运算顺序的运算符**：
1. **操作数**：直接输出
2. **左括号 `(`**：直接入栈
3. **右括号 `)`**：依次弹出栈顶运算符并输出，直到弹出 `(` 为止（`(` 只弹出、不输出）
4. **运算符**：依次弹出栈中**优先级高于或等于**当前运算符的所有运算符并输出，**遇到 `(` 或栈空就停止**；然后把当前运算符入栈
5. 扫描结束：把栈中剩余运算符依次弹出输出

🧒 **为什么“优先级高于或等于”就要弹出？** 栈里的运算符更早出现。如果它的优先级 ≥ 当前的，说明它应该**先算**，所以现在就可以把它输出了。等于也要弹出，是因为同级运算“从左到右”算，左边的先算。

**例**：`a + b * (c - d) - e / f`
| 扫描 | 操作 | 栈（左为底） | 输出 |
|---|---|---|---|
| a | 输出 | | a |
| + | 栈空，入栈 | + | a |
| b | 输出 | + | a b |
| * | 栈顶 + 优先级低，不弹；入栈 | + * | a b |
| ( | 入栈 | + * ( | a b |
| c | 输出 | + * ( | a b c |
| − | 栈顶是 (，停；入栈 | + * ( − | a b c |
| d | 输出 | + * ( − | a b c d |
| ) | 弹出 −，遇到 ( 停并丢弃 | + * | a b c d − |
| − | 弹出 *（高）、+（相等），再入栈 − | − | a b c d − * + |
| e | 输出 | − | a b c d − * + e |
| / | 栈顶 − 优先级低，入栈 | − / | a b c d − * + e |
| f | 输出 | − / | a b c d − * + e f |
| 结束 | 依次弹出 /、− | | a b c d − * + e f / − |

结果：`a b c d - * + e f / -`（与手工法一致 ✓）

📝 **真题（2014 年第 2 题）**：栈初始为空，将中缀表达式 `a/b+(c*d-e*f)/g` 转换为后缀表达式，**当扫描到 f 时**，栈中的元素依次是？
按规则模拟：
| 扫描 | 栈 |
|---|---|
| a | |
| / | / |
| b | / |
| + | 弹出 /（优先级高），入 + → + |
| ( | + ( |
| c | + ( |
| * | + ( * |
| d | + ( * |
| − | 弹出 *，入 − → + ( − |
| e | + ( − |
| * | − 优先级低，入 * → + ( − * |
| **f** | **+ ( − *** |
答案：`+ ( - *`

📝 **真题（2012 年第 2 题）**：将中缀表达式 `a+b-a*((c+d)/e-f)+g` 转换为后缀表达式 `ab+acd+e/f-*-g+` 时，用栈存放暂时还不能确定运算次序的操作符。栈初始为空，转换过程中**同时保存在栈中的操作符的最大个数**是？
关键时刻：扫描到 `(c+d` 的 `+` 时，栈中是 `- * ( ( +` → **5 个**。答案 **5**。

### 📐 用栈直接计算中缀表达式（了解）
需要**两个栈**：操作数栈 + 运算符栈。
相当于把“中缀转后缀”和“后缀求值”合在一起：每当运算符栈弹出一个运算符，就从操作数栈弹出两个数计算，结果压回操作数栈。

## 三、递归与栈（⭐）

### 📐 函数调用的本质
每次函数调用，系统都会在**系统栈（函数调用栈）**中压入一个**栈帧**，保存：
1. **调用返回地址**（执行完后回到哪里）
2. **实参**
3. **局部变量**

函数返回时，栈帧弹出。**“最后调用的函数最先返回”**——后进先出，所以用栈！

### 📐 递归的代价
- 递归深度越大，栈帧越多 → 空间复杂度 = O(递归深度)
- 可能**栈溢出**
- 可能包含大量**重复计算**（如斐波那契数列的朴素递归）

### 📐 递归转非递归
任何递归算法都可以借助一个**栈**改写成非递归算法（手动模拟系统栈）。
例如：二叉树的非递归中序遍历就用栈（第 12 课详细讲）。

📝 **经典选择题**：执行（ ）操作时，需要使用队列作为辅助存储空间。
A. 查找散列表 B. 广度优先搜索图 C. 前序遍历二叉树 D. 深度优先搜索图
→ **B**（BFS 用队列；前序遍历、DFS 用栈/递归）

📝 **经典选择题**：函数调用时，系统使用的数据结构是？→ **栈**

## 四、队列的应用

### 4.1 层次遍历
二叉树按层从上到下、从左到右访问：
1. 根结点入队
2. 队头出队并访问，把它的左孩子、右孩子（如果有）依次入队
3. 重复直到队空

```
        A
       / \
      B   C
     / \   \
    D   E   F

队列变化：[A] → 访问A,入B C → [B C] → 访问B,入D E → [C D E]
         → 访问C,入F → [D E F] → 访问D → 访问E → 访问F
层序：A B C D E F
```

### 4.2 图的广度优先搜索（BFS）
同层次遍历，但要标记已访问的顶点（第 18 课讲）。

### 4.3 在计算机系统中的应用
- **缓冲区**：主机和打印机速度不匹配，主机把要打印的数据放进缓冲队列，打印机从队列中依次取出打印
- **CPU 资源竞争**：多个进程排队等待 CPU，先来先服务（操作系统的就绪队列）
- **页面置换 FIFO 算法**：最先调入的页面最先被淘汰

## ⚠️ 易错点
1. 括号匹配三种失败：类型不配、右括号多、左括号多（结束时栈非空）
2. 后缀求值：**先弹出的是右操作数**
3. 中缀转后缀：弹出**优先级高于或等于**当前运算符的，遇到 `(` 停
4. `(` 入栈，遇 `)` 才出栈，`(` 不输出
5. 函数调用、递归用**栈**；层次遍历、BFS 用**队列**

## 📋 本课小结

| 应用 | 数据结构 | 要点 |
|---|---|---|
| 括号匹配 | 栈 | 左括号入栈，右括号比栈顶 |
| 后缀求值 | 操作数栈 | 遇运算符弹两个，先弹的是右操作数 |
| 中缀转后缀 | 运算符栈 | 弹出 ≥ 当前优先级的；( 入栈；) 弹到 ( |
| 手工转换 | — | 加括号，运算符挪到右括号后（后缀）/左括号前（前缀） |
| 递归 | 系统栈 | 栈帧：返回地址、实参、局部变量 |
| 层次遍历、BFS | 队列 | 出队一个，入队其孩子/邻居 |
| 缓冲区、FCFS | 队列 | 先来先服务 |

## 🏋️ 课后练习

1. 把中缀表达式 `a * (b + c) - d` 转换为后缀和前缀表达式。
2. 计算后缀表达式 `5 3 2 * + 4 -` 的值。
3. 用栈将 `a + b * c - d / e` 转换为后缀，扫描到 d 时栈中有哪些运算符？整个过程中栈最多同时有几个运算符？
4. 前缀表达式 `- * + 1 2 3 4` 的值是多少？
5. 判断括号序列 `( [ ) ]` 是否匹配，并说明是在哪一步失败的。

<details>
<summary>📖 答案</summary>

1. 加括号 `((a * (b + c)) - d)` → 后缀 `a b c + * d -`；前缀 `- * a + b c d`
2. 5 入；3 入；2 入；* → 3*2=6；+ → 5+6=11；4 入；− → 11−4 = **7**
3. 过程：a 出；+ 入；b 出；* 入（+ *）；c 出；− 来：弹出 *、+，入 −（−）；d 出——**扫描到 d 时栈中为 `−`**；/ 入（− /）；e 出；结束弹出。最多同时 **2** 个。后缀：`a b c * + d e / -`
4. 从右往左：4、3、2、1 入栈；遇 +：弹出 1（左）、2（右）→ 3；遇 *：弹出 3（左）、3（右）→ 9；遇 −：弹出 9（左）、4（右）→ **5**。即 (1+2)*3−4 = 5
5. 不匹配。扫描到 `)` 时栈顶是 `[`，类型不配，失败
</details>
