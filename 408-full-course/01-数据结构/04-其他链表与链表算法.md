## 🚪 课前引入
单链表有两个遗憾：
1. **只能往后走**，找前驱要从头来（删除某结点、前插时很麻烦）
2. **走到尾就断了**，想从尾回到头要重新开始

双链表解决第一个问题（加一根往回指的指针），循环链表解决第二个问题（尾巴连回头）。

## 一、双链表

### 📐 结点结构
```
┌───────┬──────┬──────┐
│ prior │ data │ next │
└───────┴──────┴──────┘
```
```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;   // 前驱指针、后继指针
} DNode, *DLinklist;
```
带头结点的双链表：
```
L → [^| |●] ⇄ [●|a1|●] ⇄ [●|a2|●] ⇄ [●|a3|^]
    头结点
```
初始化：`L->prior = NULL; L->next = NULL;`

### 📐 插入：在 p 之后插入 s（⭐⭐ 顺序很重要）
```
插入前：   p ⇄ q（q = p->next）
插入后：   p ⇄ s ⇄ q
```
需要修改 **4 根指针**：
```c
s->next = p->next;      // ① s 的后继 → q
p->next->prior = s;     // ② q 的前驱 → s   （若 p 是尾结点，p->next 为 NULL，这句要跳过）
s->prior = p;           // ③ s 的前驱 → p
p->next = s;            // ④ p 的后继 → s
```
**顺序原则**：④ `p->next = s` **必须在 ①② 之后**——因为 ①② 需要通过 `p->next` 找到 q，④ 一执行，q 就找不到了。
①②③ 之间的顺序可以调换。

🧒 **记忆**：“**先搞定新结点和后面的，最后才动 p 的 next**”。

完整代码（考虑 p 是尾结点）：
```c
bool InsertNextDNode(DNode *p, DNode *s) {
    if (p == NULL || s == NULL) return false;
    s->next = p->next;
    if (p->next != NULL)          // p 不是尾结点
        p->next->prior = s;
    s->prior = p;
    p->next = s;
    return true;
}
```

### 📐 删除：删除 p 的后继结点 q
```c
q = p->next;
p->next = q->next;              // p 的后继 → q 的后继
if (q->next != NULL)
    q->next->prior = p;         // q 后继的前驱 → p
free(q);
```

### 📐 删除 p 本身（双链表可以直接找到前驱）
```c
p->prior->next = p->next;
p->next->prior = p->prior;      // （p 非尾结点时）
free(p);
```
📝 **真题（2016 年）**：带头结点的双向循环链表 L，结点结构为 (prev, data, next)。删除 p 所指结点，正确的语句序列是：
`p->next->prev = p->prev; p->prev->next = p->next; free(p);` ✓（两句顺序可换，但 free 必须最后）

### 📐 双链表的特点
- 找前驱 O(1)，所以**前插、删除给定结点都是 O(1)**
- 按位查找、按值查找仍是 O(n)（没有随机存取）
- 每个结点多一个指针，存储密度更低

## 二、循环链表

### 2.1 循环单链表
最后一个结点的 next **指回头结点**，形成一个环。
```
L → [头|●] → [a1|●] → [a2|●] → [a3|●] ─┐
     ↑                                   │
     └───────────────────────────────────┘
```
| 条件 | 带头结点的循环单链表 |
|---|---|
| 判空 | `L->next == L` |
| 判断 p 是否是尾结点 | `p->next == L` |
| 遍历结束条件 | `p != L`（而不是 `p != NULL`） |

**从任意结点出发都能遍历整个链表**。

### 📐 用尾指针代替头指针（⭐⭐ 选择题常考）
循环单链表常常**只设尾指针 r**，因为：
- 尾结点：r，O(1)
- 头结点：`r->next`，O(1)
- 第一个元素：`r->next->next`，O(1)

所以**在表头、表尾插入都是 O(1)**。但**删除表尾**仍需找到尾结点的前驱，O(n)。

### 2.2 循环双链表
头结点的 prior 指向尾结点，尾结点的 next 指向头结点。
```
判空：L->next == L && L->prior == L
```
**首尾操作全部 O(1)**（头结点既能找到头，也能通过 prior 直接找到尾，尾结点的前驱也能直接找到）。

### 📊 各种链表的操作复杂度（⭐⭐⭐ 必考表格）
| 链表类型 | 表头插入 | 表头删除 | 表尾插入 | 表尾删除 |
|---|---|---|---|---|
| 单链表（只有头指针） | O(1) | O(1) | O(n) | O(n) |
| 单链表（头指针 + 尾指针） | O(1) | O(1) | O(1) | **O(n)**（要找尾的前驱） |
| 循环单链表（只有头指针） | O(1) | O(1) | O(n) | O(n) |
| 循环单链表（**只有尾指针**） | O(1) | O(1) | O(1) | **O(n)** |
| 双链表（头 + 尾指针） | O(1) | O(1) | O(1) | O(1) |
| **循环双链表（只有头指针）** | O(1) | O(1) | O(1) | O(1) |

📝 **经典选择题**：某线性表常用操作是“在最后一个元素之后插入”和“删除第一个元素”，最节省时间的存储方式是？
→ **仅有尾指针的循环单链表**（尾插 O(1)，删头 O(1)）

📝 **经典选择题**：某线性表常用操作是“在最后一个元素之后插入”和“删除最后一个元素”，最节省时间的是？
→ **带头结点的循环双链表**（删尾需要找前驱，只有双链表能 O(1)）

📝 **真题（2021 年第 1 题）**：带头结点的非空**单循环链表**，头指针 h，**尾指针 p**，临时指针 q。删除链表**第一个元素**，正确的是：
A. `h->next = h->next->next; q = h->next; free(q);`
B. `q = h->next; h->next = h->next->next; free(q);`
C. `q = h->next; h->next = q->next; if (p != q) p = h; free(q);`
D. `q = h->next; h->next = q->next; if (p == q) p = h; free(q);`

**逐项分析**：
- A：先改 h->next，再令 q = h->next → q 指向的是**第二个**元素，删错了 ✗
- B：删除正确，但忽略了**表中只有一个元素**的情况：这个元素既是第一个也是尾结点（p == q），删掉后尾指针 p 成了“野指针” ✗
- C：条件写反了 ✗
- D：只有当被删的恰好是尾结点时，才把尾指针指回头结点（此时链表变空，循环单链表空表的尾就是头结点）✓

答案 **D**。
> 🎯 **链表题检查清单**：空表？只有 1 个元素？删的是第一个？删的是最后一个？头/尾指针需要更新吗？

## 三、静态链表

### 📐 定义
用**数组**来模拟链表：每个数组元素包含 data 和 **next（下一个元素的数组下标）**，用 −1 表示结束。
```c
#define MaxSize 50
typedef struct {
    ElemType data;
    int next;          // 下一个元素的数组下标（“游标”）
} SLinkList[MaxSize];
```
```
下标:   0      1      2      3      4
data:  头    b      a      d      c
next:   2     4      1      -1     3
遍历：0 → 2(a) → 1(b) → 4(c) → 3(d) → 结束
```
- 插入删除只需修改游标，**不需移动元素**
- 需要预先分配一块连续空间，容量固定
- **不能随机存取**
- 适用于不支持指针的语言，或数据元素数量固定的场景（如操作系统的**文件分配表 FAT**）

## 四、链表经典算法题（⭐⭐⭐）

### 🛠️ 三大武器
1. **头插法**：可以把链表**逆置**
2. **快慢指针**：慢指针走 1 步，快指针走 2 步 → 找**中间结点**、判断**有环**
3. **前后指针（间隔 k）**：前指针先走 k 步，然后两个一起走 → 找**倒数第 k 个**

---

### 题 1：就地逆置单链表（O(1) 空间）
**方法一：头插法**。把头结点摘下来当新表，原链表的结点依次摘下，用头插法插入新表。
```c
LinkList Reverse(LinkList L) {
    LNode *p = L->next, *r;     // p 是当前要摘的结点，r 暂存 p 的后继（防止断链）
    L->next = NULL;             // 头结点摘下，作为空表
    while (p != NULL) {
        r = p->next;            // 先记住下一个
        p->next = L->next;      // 头插
        L->next = p;
        p = r;                  // 继续处理下一个
    }
    return L;
}
```
**过程**：L → 1 → 2 → 3
```
初始：新表 L → ∅，待处理 1 → 2 → 3
摘 1：L → 1
摘 2：L → 2 → 1
摘 3：L → 3 → 2 → 1   ✓
```
**方法二：三指针原地反转指向**（pre、p、r），把每个结点的 next 反过来指向前驱。
时间 O(n)，空间 O(1)。

### 题 2：删除所有值为 x 的结点
```c
void Del_X(LinkList &L, ElemType x) {
    LNode *pre = L, *p = L->next, *q;   // pre 始终是 p 的前驱
    while (p != NULL) {
        if (p->data == x) {
            q = p;
            p = p->next;
            pre->next = p;              // 跳过 q
            free(q);
        } else {
            pre = p;                    // 两个指针一起后移
            p = p->next;
        }
    }
}
```
🧒 链表删除一定要握着**前驱**，所以用 pre 和 p 两个指针“一前一后”走。

### 题 3：查找倒数第 k 个结点（⭐ 2009 年第 42 题原题，15 分）
> 带头结点的单链表，结点为 (data, link)，头指针 list。在**不改变链表**的前提下，尽可能高效地找到倒数第 k 个位置上的结点（k 为正整数）。成功则输出 data 并返回 1，否则返回 0。

**设计思想**：定义两个指针 p、q，初始都指向第一个结点。**p 先走 k 步**，然后 p、q **同步**后移；当 p 走到 NULL（走出链表）时，q 恰好指向倒数第 k 个结点。只需**一趟扫描**。

🧒 **比喻**：两个人拿着一根长 k 米的绳子在跑道上走，前面的人到终点时，后面的人离终点正好 k 米。

```c
int Search_k(LinkList list, int k) {
    LNode *p = list->link, *q = list->link;
    int count = 0;
    while (p != NULL) {
        if (count < k) count++;     // p 先走 k 步
        else q = q->link;           // 之后 q 也开始走
        p = p->link;
    }
    if (count < k) return 0;        // 链表长度小于 k，查找失败
    printf("%d", q->data);
    return 1;
}
```
**验证**：链表 1 → 2 → 3 → 4 → 5，k = 2
| p 指向 | count | q 指向 |
|---|---|---|
| 1 | 0→1 | 1 |
| 2 | 1→2 | 1 |
| 3 | 2 | 1→2 |
| 4 | 2 | 2→3 |
| 5 | 2 | 3→4 |
| NULL | 结束 | **4**（倒数第 2 个）✓ |

时间 O(n)，空间 O(1)。

### 题 4：两个链表的公共后缀起点（⭐ 2012 年第 42 题原题）
> 用带头结点的单链表存储单词，当两个单词有相同后缀时可共享后缀空间，例如 “loading” 和 “being” 共享 “ing”。str1、str2 分别指向两个单词的头结点，找出公共后缀的**起始位置**（即 i 所在的结点）。

```
str1 → l → o → a → d ┐
                      ├→ i → n → g
str2 → b → e ────────┘
```
**设计思想**：
1. 分别求出两个链表的长度 m、n
2. 让**较长的链表**的指针先走 |m − n| 步，使两个指针到表尾的距离相等
3. 两个指针同步后移，**第一次指向同一个结点（地址相同，不是数据相同）**时，就是公共后缀的起点

🧒 **比喻**：两个人要在路口会合，一个离路口远一些，就让他**先出发几步**，然后两人同速走，就会同时到达路口。

```c
int Length(LinkList L) {
    int len = 0;
    for (LNode *p = L->next; p != NULL; p = p->next) len++;
    return len;
}
LNode *FindCommon(LinkList str1, LinkList str2) {
    int m = Length(str1), n = Length(str2);
    LNode *p = str1->next, *q = str2->next;
    for (; m > n; m--) p = p->next;     // 长的先走
    for (; n > m; n--) q = q->next;
    while (p != NULL && p != q) {       // 比较的是指针（地址）
        p = p->next;
        q = q->next;
    }
    return p;                           // 没有公共后缀时返回 NULL
}
```
时间 O(m + n)，空间 O(1)。

⚠️ 比较的是 `p != q`（**是不是同一个结点**），不是 `p->data != q->data`。

### 题 5：删除绝对值重复的结点（⭐ 2015 年第 41 题原题）
> 带头结点单链表 head，结点 (data, link)，|data| ≤ n（n 为正整数）。对于 data 的**绝对值相等**的结点，**仅保留第一次出现的结点**，删除其余结点。要求时间复杂度尽可能高效。
> 例：21 → −15 → −15 → −7 → 15 变成 21 → −15 → −7

**设计思想（空间换时间）**：因为 |data| ≤ n，开一个长度 n+1 的辅助数组 q，初值全为 0。遍历链表，对每个结点看 q[|data|]：
- 若为 0：第一次出现，保留，并令 q[|data|] = 1
- 若为 1：已经出现过，删除该结点

```c
void func(PNODE h, int n) {
    PNODE p = h, r;
    int *q = (int *)malloc(sizeof(int) * (n + 1));
    for (int i = 0; i <= n; i++) q[i] = 0;
    while (p->link != NULL) {                 // 考察 p 的后继
        int m = p->link->data > 0 ? p->link->data : -p->link->data;
        if (q[m] == 0) {                      // 第一次出现，保留
            q[m] = 1;
            p = p->link;
        } else {                              // 重复，删除 p 的后继
            r = p->link;
            p->link = r->link;
            free(r);
        }
    }
    free(q);
}
```
🧒 注意这里的写法：**p 始终停在“待考察结点的前驱”**，这样删除时很方便。
时间 O(m)（m 为链表长度），空间 O(n)。

### 题 6：链表重排（⭐ 2019 年第 41 题原题）
> 带头结点单链表 L = (a₁, a₂, a₃, …, aₙ)，要求**空间复杂度 O(1)**，重新排列为 L' = (a₁, aₙ, a₂, aₙ₋₁, a₃, aₙ₋₂, …)。

**设计思想（三步走，三大武器全用上）**：
1. **快慢指针找中间结点**：p 走一步、q 走两步，q 到尾时 p 在中间
2. **头插法逆置后半段**：aₙ, aₙ₋₁, …
3. **交替合并**：把后半段的结点依次插入前半段的每个结点之后

```
L:        1 → 2 → 3 → 4 → 5
第1步：    前半 1 → 2 → 3 ｜ 后半 4 → 5
第2步：    前半 1 → 2 → 3 ｜ 后半 5 → 4
第3步：    1 → 5 → 2 → 4 → 3    ✓
```
```c
void change_list(NODE *h) {
    NODE *p, *q, *r, *s;
    p = q = h;
    while (q->next != NULL) {            // ① 找中间结点
        p = p->next;                     //   p 走一步
        q = q->next;
        if (q->next != NULL) q = q->next;//   q 走两步
    }
    q = p->next;                         // q 指向后半段第一个结点
    p->next = NULL;
    while (q != NULL) {                  // ② 后半段头插到 p 之后（逆置）
        r = q->next;
        q->next = p->next;
        p->next = q;
        q = r;
    }
    s = h->next;                         // s 指向前半段第一个结点
    q = p->next;                         // q 指向逆置后的后半段第一个结点
    p->next = NULL;                      // 前半段结尾断开
    while (q != NULL) {                  // ③ 交替插入
        r = q->next;                     //   记住后半段下一个
        q->next = s->next;               //   q 插到 s 之后
        s->next = q;
        s = q->next;                     //   s 移到前半段下一个
        q = r;
    }
}
```
**验证** n = 5：找中间 p 停在 3；后半 4、5 逆置后接在 3 后面：1→2→3→5→4；断开得前半 1→2→3、后半 5→4；交替：1→5→2→4→3 ✓
**验证** n = 4：p 停在 2；后半 4→3；交替：1→4→2→3 ✓

时间 O(n)，空间 O(1)。

### 题 7（补充）：判断链表是否有环，并找环的入口
**快慢指针**：slow 每次走 1 步，fast 每次走 2 步。若有环，fast 一定会在环里追上 slow（相遇）；若 fast 走到 NULL，则无环。
**找入口**：相遇后，让一个指针回到链表头，另一个留在相遇点，两者都**每次走 1 步**，再次相遇的结点就是**环的入口**。
（证明：设头到入口距离 a，入口到相遇点 b，环长 r。相遇时 slow 走了 a + b，fast 走了 2(a + b) = a + b + kr → a = kr − b，即从相遇点再走 a 步正好到入口。）
```c
LNode *FindLoopStart(LNode *head) {
    LNode *slow = head, *fast = head;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) break;             // 相遇
    }
    if (fast == NULL || fast->next == NULL) return NULL;   // 无环
    LNode *p1 = head, *p2 = slow;
    while (p1 != p2) { p1 = p1->next; p2 = p2->next; }
    return p1;                               // 环的入口
}
```
时间 O(n)，空间 O(1)。

### 题 8（补充）：合并两个递增链表为一个递减链表
思路：两个指针比较，每次把较小的结点**头插**到结果链表中（头插法天然得到逆序）。一个链表用完后，另一个剩下的也逐个头插。时间 O(m + n)。
（这正是 2013 年真题的背景：合并长度 m、n 的两个升序链表为降序链表，最坏时间复杂度 O(max(m, n))。）

## ⚠️ 易错点
1. 双链表插入：`p->next = s` 要放在最后
2. 双链表操作要考虑 p 是尾结点（`p->next == NULL`）的情况
3. 循环链表遍历的结束条件是 `p != L`，不是 `p != NULL`
4. 循环单链表只有尾指针时：删尾仍是 O(n)
5. 公共后缀比较的是**地址**
6. 链表删除要握住**前驱**

---

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 双链表插入 | ①s->next=p->next ②p->next->prior=s ③s->prior=p ④p->next=s（④最后） |
| 双链表删除 p | p->prior->next = p->next; p->next->prior = p->prior; free(p) |
| 循环单链表 | 判空 L->next == L；常只设尾指针，首尾插入 O(1) |
| 循环双链表 | 首尾插删全 O(1) |
| 静态链表 | 数组 + 游标；不能随机存取；FAT 用它 |
| 逆置 | 头插法 |
| 倒数第 k 个 | 前指针先走 k 步 |
| 公共后缀 | 长的先走差值步，再同步走，比较地址 |
| 找中间 | 快慢指针 |
| 重排 | 找中间 + 逆置后半 + 交替合并 |

## 🏋️ 课后练习

1. 双链表中，在 p 所指结点**之前**插入 s，写出语句序列。
2. 设有一个仅设尾指针 r 的循环单链表（带头结点），写出在表头插入结点 s 的语句。
3. 写一个算法，判断带头结点的**循环双链表**是否对称（如 1,2,3,2,1 对称）。
4. 写算法：删除带头结点单链表中**最小值**结点（假设唯一）。
5. 为什么查找倒数第 k 个结点只需扫描一遍？如果先求表长 n 再找第 n−k+1 个，时间复杂度是多少？两种方法考试都能得分吗？

<details>
<summary>📖 答案</summary>

1. ```c
   s->prior = p->prior;
   p->prior->next = s;
   s->next = p;
   p->prior = s;      // 必须在前两句之后
   ```
2. `s->next = r->next->next; r->next->next = s;`（r->next 是头结点；若原表为空，s 成为尾结点，还需令 `r = s`）
3. 两个指针 p 从头往后、q 从尾往前（`p = L->next; q = L->prior;`），比较 data；直到 `p == q`（奇数个）或 `p->next == q`（偶数个，比较完这一对后）停止，途中有不等就返回 false
   ```c
   bool Symmetry(DLinklist L) {
       DNode *p = L->next, *q = L->prior;
       while (p != q && q->next != p) {     // 两指针未相遇且未交错
           if (p->data != q->data) return false;
           p = p->next; q = q->prior;
       }
       return true;
   }
   ```
4. ```c
   void DelMin(LinkList &L) {
       LNode *pre = L, *p = L->next;          // 工作指针
       LNode *minpre = L, *minp = L->next;    // 最小值结点及其前驱
       while (p != NULL) {
           if (p->data < minp->data) { minp = p; minpre = pre; }
           pre = p; p = p->next;
       }
       minpre->next = minp->next;
       free(minp);
   }
   ```
5. 前后指针保持 k 的间距，前指针到尾时后指针就在倒数第 k 个。先求表长再找需要扫描约两遍，时间也是 O(n)。**两种方法复杂度相同，都能得满分或接近满分**；题目要求“尽可能高效”时，一趟扫描的更好
</details>
