# 数据结构 第 6 课 · 队列

> 🎯 **本课目标**
> 1. 理解队列“先进先出”的特性
> 2. **彻底搞懂循环队列**：为什么要循环、怎么取余、怎么判空判满、怎么求元素个数（三种判满方法 + 各种 front/rear 约定）
> 3. 掌握链队列（尤其是删除最后一个元素时的特殊处理）
> 4. 掌握双端队列、输入受限/输出受限队列的**出队序列判断**
>
> 循环队列的公式是 408 的高频考点，而且题目经常**故意改约定**（比如 rear 指向队尾元素本身），死记公式会翻车，本课教你**自己推公式**。

## 🚪 课前引入：排队买奶茶

奶茶店门口排队：
- 新来的人站到**队尾**（入队）
- 买完的人从**队头**离开（出队）
- **先来的先买**：先进先出（FIFO, First In First Out）

生活中的队列：打印机的打印任务、银行叫号、操作系统里等 CPU 的进程……

## 一、队列的定义

### 📐 定义
队列是**只允许在一端插入、在另一端删除**的线性表。
- **队尾（rear）**：允许插入的一端
- **队头（front）**：允许删除的一端

```
出队 ←  [ a1 | a2 | a3 | a4 | a5 ]  ← 入队
        队头                  队尾
```

### 📐 基本操作
InitQueue(&Q)、QueueEmpty(Q)、**EnQueue(&Q, x)** 入队、**DeQueue(&Q, &x)** 出队、GetHead(Q, &x) 读队头。

⚠️ 队列和栈一样，是**操作受限的线性表**，**不能**随便读取中间的元素。

## 二、顺序队列与“假溢出”

### 📐 最朴素的想法
用数组存，front 指向队头元素，rear 指向**队尾元素的下一个位置**。
```c
typedef struct {
    ElemType data[MaxSize];
    int front, rear;
} SqQueue;
// 初始：front = rear = 0
// 入队：data[rear] = x; rear++;
// 出队：x = data[front]; front++;
```

### 📐 问题：假溢出
```
MaxSize = 5
入队 a,b,c,d,e：  [a][b][c][d][e]   front=0, rear=5
出队 a,b,c：      [ ][ ][ ][d][e]   front=3, rear=5
再入队 f？        rear == MaxSize，“满了”！
```
可是数组前面明明**空着 3 个位置**！这叫“**假溢出**”。

🧒 就像排队时前面的人买完走了，后面的人却不往前走，新来的人以为队伍已经排到马路上了，没地方站。

## 三、循环队列（⭐⭐⭐）

### 📐 思想：把数组首尾相接，看成一个环
走到数组末尾后，**绕回到下标 0** 继续用。实现方法：**取余**。
```c
rear = (rear + 1) % MaxSize;    // 到 MaxSize-1 后，再加 1 就变成 0
front = (front + 1) % MaxSize;
```
```
          [0]
     [4]       [1]          front、rear 在环上顺时针移动
     [3]       [2]
```

### 📐 标准约定：front 指向队头元素，rear 指向队尾元素的**下一个位置**
```c
void InitQueue(SqQueue &Q) {
    Q.front = Q.rear = 0;
}
bool EnQueue(SqQueue &Q, ElemType x) {
    if ((Q.rear + 1) % MaxSize == Q.front) return false;   // 队满
    Q.data[Q.rear] = x;
    Q.rear = (Q.rear + 1) % MaxSize;
    return true;
}
bool DeQueue(SqQueue &Q, ElemType &x) {
    if (Q.rear == Q.front) return false;                   // 队空
    x = Q.data[Q.front];
    Q.front = (Q.front + 1) % MaxSize;
    return true;
}
```

### 📐 判空和判满的矛盾
- 初始时 front == rear，是**空**
- 如果一直入队，把所有格子都填满，rear 绕一圈追上 front，又变成 front == rear——是**满**！
- **空和满的条件一样，区分不了**！

### 📐 三种解决方法（⭐⭐）

**方法一：牺牲一个存储单元（最常用，考试默认）**
规定：**rear 的下一个位置是 front 时就算满**（故意留一个空格不用）。
| 状态 | 条件 |
|---|---|
| **队空** | `Q.front == Q.rear` |
| **队满** | `(Q.rear + 1) % MaxSize == Q.front` |
| **元素个数** | `(Q.rear - Q.front + MaxSize) % MaxSize` |
| 最多能存 | MaxSize − 1 个元素 |

🧒 **元素个数公式为什么要 + MaxSize 再取余？**
- 正常情况 rear 在 front 后面：个数 = rear − front
- rear 绕回来了，在 front 前面：rear − front 是负数，要加一圈 MaxSize
- 统一写成 (rear − front + MaxSize) % MaxSize，两种情况都对

**例**：MaxSize = 10，front = 7，rear = 3 → 个数 = (3 − 7 + 10) % 10 = **6**（下标 7, 8, 9, 0, 1, 2）

**方法二：增设 size 变量记录元素个数**
- 队空：size == 0；队满：size == MaxSize
- 入队 size++，出队 size−−
- 所有格子都能用

**方法三：增设 tag 标志**
- tag = 0 表示最近一次是**出队**，tag = 1 表示最近一次是**入队**
- 只有出队才可能导致空，只有入队才可能导致满：
  - 队空：`front == rear && tag == 0`
  - 队满：`front == rear && tag == 1`

### 📐 其他约定：rear 指向队尾元素本身（⭐ 考试陷阱）
有的题目规定 **rear 指向队尾元素**（而不是下一个位置）。这时：
- 初始：`front = 0, rear = MaxSize − 1`（让第一次入队后 rear 变成 0）
- 入队：**先移动 rear**，再放入：`rear = (rear + 1) % MaxSize; data[rear] = x;`
- 队空：`(rear + 1) % MaxSize == front`
- 队满（牺牲一个单元）：`(rear + 2) % MaxSize == front`
- 元素个数：`(rear − front + 1 + MaxSize) % MaxSize`

🎯 **万能方法：不要背，现场推！**
1. 先画一个空队列，确定 front、rear 的初值
2. 入队一个元素，看 front、rear 变成什么
3. 写出“队空”时 front 和 rear 的关系
4. 写出“再入队一个就会冲突”时的关系 → 队满

📝 **经典题**：循环队列存在数组 A[0..n−1] 中，入队时先改 rear 再存元素。初始队列为空，**第一个元素存在 A[0]**，则 front 和 rear 的初值分别是？
→ 第一个元素存入 A[0]，入队“先改 rear”，说明 rear 从 n−1 变为 0。front 指向队头元素，第一个元素在 A[0]，front = 0。答案：**front = 0，rear = n − 1**。

## 四、链队列

### 📐 定义
用单链表实现队列，设**队头指针 front** 和**队尾指针 rear**。
```c
typedef struct LinkNode {
    ElemType data;
    struct LinkNode *next;
} LinkNode;
typedef struct {
    LinkNode *front, *rear;
} LinkQueue;
```
**带头结点**的链队列：
```
front → [头结点] → [a1] → [a2] → [a3|^]
                                   ↑
                                  rear
空队列：front == rear（都指向头结点）
```

### 📐 入队（在表尾插入）
```c
void EnQueue(LinkQueue &Q, ElemType x) {
    LinkNode *s = (LinkNode *)malloc(sizeof(LinkNode));
    s->data = x;
    s->next = NULL;
    Q.rear->next = s;      // 接在队尾
    Q.rear = s;            // 更新队尾指针
}
```

### 📐 出队（删除表头的第一个数据结点）
```c
bool DeQueue(LinkQueue &Q, ElemType &x) {
    if (Q.front == Q.rear) return false;      // 空队
    LinkNode *p = Q.front->next;              // 第一个数据结点
    x = p->data;
    Q.front->next = p->next;
    if (Q.rear == p)                          // ⚠️ 如果删的是最后一个结点
        Q.rear = Q.front;                     //    队尾指针要指回头结点
    free(p);
    return true;
}
```
⚠️ **最容易忘的一步**：队列中只剩一个元素时，删除它后 rear 仍指向被释放的结点。必须把 rear 改回 front（队列变空）。这和 2021 年第 1 题（循环单链表删第一个元素要维护尾指针）是同一个坑！

### 📐 链队列的特点
- 不存在队满（除非内存耗尽），适合**元素个数变化大**的场景
- 入队、出队都是 O(1)

📝 **经典题**：用链表表示队列，**只设尾指针**，最适合的是哪种链表？
→ **循环单链表**（尾指针 rear，队头就是 rear->next->next（带头结点）或 rear->next（不带头结点），入队出队都 O(1)）

## 五、双端队列（⭐⭐）

### 📐 定义
**两端都允许**入队和出队的队列。
```
     ⇄ [ a | b | c | d ] ⇄
    前端              后端
```
两种受限的双端队列：
- **输入受限**：一端**只能出**，另一端能入能出（**只有一个入口**，有两个出口）
- **输出受限**：一端**只能入**，另一端能入能出（**只有一个出口**，有两个入口）

> 🧒 记忆：“输入受限”就是**输入口受到限制**（只剩一个入口）；“输出受限”就是**输出口受到限制**（只剩一个出口）。

### 📐 判断出队序列是否可能（⭐⭐）
**一般方法**：根据出队序列，**倒推**每个元素出队时队列中元素的排列，检查能否通过合法的入队操作得到。

对于**输出受限**的双端队列（只有一个出口），思路最清晰：
- 所有元素都从**同一个出口**离开
- 第一个出队的元素 x 出队时，所有在它之前入队的元素都在队中
- 出队顺序 = 队列中从出口往里的顺序
- 检查：这个排列能否通过“每个新元素要么放左端、要么放右端”得到？

**关键规律**：按入队顺序 1, 2, 3, … 依次放入，**每个新来的元素只能放在两端**，所以任何时刻队列里的元素，**越靠近两端的越晚进来**，**先进来的一定被夹在中间**（比如 1、2 进队后是紧挨着的，3 只能放在它们两边，不能插进 1 和 2 之间）。

📝 **真题（2021 年第 2 题）**：初始为空的队列 Q，**一端只能入队，另一端既能入队又能出队**（输出受限）。入队序列 1, 2, 3, 4, 5，**不能**得到的出队序列是？
A. 5, 4, 3, 1, 2 &nbsp; B. 5, 3, 1, 2, 4 &nbsp; C. 4, 2, 1, 3, 5 &nbsp; D. 4, 1, 3, 2, 5

设右端是出口（能进能出），左端只能进。出队顺序就是“当时队列从右往左读”。

**A. 5, 4, 3, 1, 2**：5 最先出，所以 5 出队前 1~5 全在队中，从右往左是 5, 4, 3, 1, 2，即从左到右是 **2, 1, 3, 4, 5**。
能构造吗？1 入；2 从左入 → [2, 1]；3 从右入 → [2, 1, 3]；4 右入；5 右入 → [2, 1, 3, 4, 5] ✓

**B. 5, 3, 1, 2, 4**：从左到右应为 **4, 2, 1, 3, 5**。
1；2 左 → [2,1]；3 右 → [2,1,3]；4 左 → [4,2,1,3]；5 右 → [4,2,1,3,5] ✓

**C. 4, 2, 1, 3, 5**：4 最先出，此时队中有 1~4，从右往左 4, 2, 1, 3，从左到右 **3, 1, 2, 4**。
1；2 右 → [1,2]；3 左 → [3,1,2]；4 右 → [3,1,2,4]。出 4、2、1、3，然后 5 入队再出 ✓

**D. 4, 1, 3, 2, 5**：4 最先出，从左到右应为 **2, 3, 1, 4**：3 夹在 2 和 1 中间。
但 1、2 先进队，它们一定**紧挨着**（[1,2] 或 [2,1]），3 只能放两端，不可能插到 1 和 2 之间 ✗

答案 **D**。

📝 **经典题**：输入受限的双端队列（只有一端能入，两端都能出），入队 1, 2, 3, 4，能否得到出队序列 4, 2, 1, 3？
→ 入口只有一个，所以队列里的顺序和入队顺序相同：[1, 2, 3, 4]（从入口端数）。4 最先出：1~4 全进来，队列 1, 2, 3, 4（左端是 1，右端是 4，假设右端为入口）。出 4（右端）→ [1, 2, 3]；要出 2，但两端是 1 和 3 → ✗ **不能**。

> 💡 **小技巧**：对于 4 个元素，栈能得到 14 种序列；输入受限双端队列能得到 22 种；输出受限双端队列能得到 22 种；普通双端队列能得到更多。能被栈得到的序列，两种受限双端队列都能得到。

## 六、队列的应用（预告）
- **层次遍历**：二叉树的层序遍历、图的广度优先搜索（BFS）
- **操作系统**：进程就绪队列、打印缓冲区、FCFS 调度
- **计算机网络**：路由器的分组缓冲队列

## ⚠️ 易错点
1. 循环队列要取余：`(rear + 1) % MaxSize`
2. 牺牲一个单元：最多存 MaxSize − 1 个
3. 元素个数：`(rear − front + MaxSize) % MaxSize`
4. **题目改了 front/rear 的约定时，公式要自己重新推**
5. 链队列删除最后一个元素时要修改 rear
6. 输入受限 = 一个入口；输出受限 = 一个出口

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 特性 | 先进先出；队尾入、队头出 |
| 假溢出 | 顺序队列前面有空位却“满”了 → 用循环队列 |
| 循环队列（标准） | 空 f==r；满 (r+1)%M==f；个数 (r−f+M)%M |
| 区分空满 | 牺牲单元 / size 计数 / tag 标志 |
| 链队列 | front 指头结点，rear 指尾；删最后一个时 rear=front |
| 双端队列 | 输入受限（一个入口）、输出受限（一个出口） |
| 判断出队序列 | 倒推队内排列；先入的元素紧挨在中间 |

## 🏋️ 课后练习

1. 循环队列 MaxSize = 20，front = 15，rear = 5（标准约定），元素个数？
2. 循环队列用数组 A[0..m]（共 m+1 个单元）存储，front 指向队头元素，rear 指向队尾元素的下一个位置，求元素个数的公式。
3. 循环队列用 A[0..5] 存储，当前 rear = 0、front = 3，删除一个元素后再加入两个元素，rear 和 front 分别是多少？
4. 链队列（带头结点）只剩一个元素时出队，要修改哪些指针？
5. 输出受限的双端队列（右端能进能出，左端只能进），入队 1, 2, 3, 4，能否得到出队序列 4, 1, 3, 2？ 3, 1, 4, 2 呢？

<details>
<summary>📖 答案</summary>

1. (5 − 15 + 20) % 20 = **10**
2. (rear − front + m + 1) % (m + 1)（数组长度是 m+1）
3. 删除：front = (3+1) % 6 = **4**；加入两个：rear = (0+2) % 6 = **2**
4. 头结点的 next（置为 NULL）和 **rear**（改为指向头结点）
5. 4, 1, 3, 2：4 先出，从左到右应为 2, 3, 1, 4，3 夹在 1、2 之间 → **不能**。
   3, 1, 4, 2：3 出队时队中有 1、2、3，从右往左 3, 1, … 队列从左到右为 2, 1, 3（剩下的 2 在最左）→ 1；2 左入 [2,1]；3 右入 [2,1,3]；出 3、出 1 → [2]；4 右入 [2,4]；出 4、出 2 ✓ **能**
</details>
