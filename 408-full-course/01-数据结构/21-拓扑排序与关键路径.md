## 一、有向无环图（DAG）

### 📐 定义
**有向无环图**：一个**不存在环**的有向图，简称 **DAG**（Directed Acyclic Graph）。

### 📐 DAG 描述表达式（了解）
表达式中的**公共子式**可以共享，用 DAG 表示比用二叉树节省结点。
例：`((a+b)*(b*(c+d))+(c+d)*e)*((c+d)*e)` 中，`(c+d)` 和 `(c+d)*e` 都出现多次，DAG 中只画一次。
**求 DAG 最少顶点数的方法**：把表达式中的操作数去重（每个变量只出现一次），再从下往上，把运算符和操作数都相同的结点合并。

## 二、拓扑排序（⭐⭐⭐）

### 📐 AOV 网
用 **DAG** 表示一个工程，**顶点表示活动**，有向边 <Vᵢ, Vⱼ> 表示“**活动 Vᵢ 必须先于 Vⱼ 进行**”。这种网叫 **AOV 网**（Activity On Vertex）。
- AOV 网中**不能有环**（否则活动自己要先于自己，矛盾）

### 📐 拓扑排序的定义
由 DAG 的所有顶点组成的一个序列，满足：
1. 每个顶点**出现且只出现一次**
2. 若顶点 A 在序列中排在 B 之前，则图中**不存在从 B 到 A 的路径**

🧒 **大白话**：把所有课程排成一排，**每门课的先修课都排在它前面**。

### 📐 算法（每次删一个入度为 0 的顶点）
1. 从 DAG 中选择一个**入度为 0**（没有前驱）的顶点并输出
2. 从图中**删除**该顶点和所有以它为起点的有向边（它的后继的入度减 1）
3. 重复 1、2，直到：
   - 所有顶点都输出了 → 成功
   - 图中还有顶点，但**找不到入度为 0 的顶点** → 说明图中**有环**

### ✏️ 例题
```
     1 ──→ 2 ──→ 4
     │     ↑     │
     ↓     │     ↓
     3 ────┘     5
（边：1→2, 1→3, 3→2, 2→4, 4→5）
```
| 步骤 | 入度为 0 的顶点 | 输出 | 删除后各顶点入度 |
|---|---|---|---|
| 初始 | 1 | — | 1:0, 2:2, 3:1, 4:1, 5:1 |
| 1 | {1} | **1** | 2:1, 3:0 |
| 2 | {3} | **3** | 2:0 |
| 3 | {2} | **2** | 4:0 |
| 4 | {4} | **4** | 5:0 |
| 5 | {5} | **5** | — |
拓扑序列：**1, 3, 2, 4, 5**（这个图只有这一种）

### 📐 代码（邻接表 + 栈/队列存放入度为 0 的顶点）
```c
bool TopologicalSort(ALGraph G) {
    int indegree[MAX], print[MAX], count = 0;
    // ① 求所有顶点的入度（此处省略：遍历邻接表统计）
    SqStack S; InitStack(S);
    for (int i = 0; i < G.vexnum; i++)
        if (indegree[i] == 0) Push(S, i);        // 入度为 0 的顶点入栈
    while (!StackEmpty(S)) {
        int i; Pop(S, i);
        print[count++] = i;                       // 输出
        for (ArcNode *p = G.vertices[i].first; p != NULL; p = p->next) {
            int v = p->adjvex;
            if (--indegree[v] == 0)               // 后继入度减 1，减到 0 就入栈
                Push(S, v);
        }
    }
    return count == G.vexnum;                     // 输出顶点数 < 总数，说明有环
}
```
- 用栈或队列都可以（得到的序列可能不同，但都是合法的拓扑序列）

### 📐 复杂度
- 邻接表：每个顶点输出一次，每条边处理一次 → **O(|V| + |E|)**
- 邻接矩阵：**O(|V|²)**

### 📐 拓扑序列的唯一性与个数（⭐⭐）
- 某一步如果有**多个**入度为 0 的顶点，选哪个都行 → 拓扑序列**不唯一**
- 若每一步都**只有一个**入度为 0 的顶点，序列唯一（此时各顶点排成一条链，存在一条经过所有顶点的路径）
- **求拓扑序列的个数**：画出每一步的选择，用树形分支数一数

✏️ **例**：边 A→C，B→C，C→D，C→E
- 开始时 A、B 入度都为 0，先 A 或先 B（2 种）
- 然后 C
- 然后 D、E 入度都为 0，先 D 或先 E（2 种）
- 共 2 × 2 = **4 种**：ABCDE、ABCED、BACDE、BACED

📝 **真题（2021 年第 7 题）**：给定如下有向图，该图的拓扑有序序列的个数是：A. 1 B. 2 C. 3 D. 4
图中的弧（据原卷图）：A→B、A→F、B→C、B→D、B→F、C→D、D→E、D→F、E→F
| 步骤 | 入度为 0 的顶点 | 输出 |
|---|---|---|
| 1 | {A} | A |
| 2 | {B} | B |
| 3 | {C}（D 还要等 C） | C |
| 4 | {D} | D |
| 5 | {E}（F 还要等 E） | E |
| 6 | {F} | F |
每一步都只有一个选择 → 只有 **1** 个拓扑序列 A B C D E F，选 **A**。

### 📐 拓扑排序的其他性质（⭐ 选择题）
1. **有向图能拓扑排序 ⟺ 图中无环**。所以拓扑排序可以用来**判断有向图是否有环**（DFS 也可以）
2. 若一个有向图的顶点能排成一个拓扑序列，则其**邻接矩阵可以化为三角矩阵**（按拓扑序重新编号顶点后，所有边都从小编号指向大编号 → 上三角矩阵）
3. 反过来：若邻接矩阵是**三角矩阵**（对角线以下全为 0），则一定存在拓扑序列（但不一定唯一）
4. **有向无环图的拓扑序列存在但不一定唯一**（2025 年第 6 题 B 选项 ✗）

### 📐 用 DFS 求拓扑序列（⭐）
📝 **真题（2020 年第 6 题）**：DFS 中把输出语句**移到退出递归前**，遍历 DAG，输出的是**逆拓扑有序序列**。
🧒 **原因**：一个顶点要等它**能到达的所有顶点**都输出后才输出（后序）。所以若有边 u → v，v 一定先输出。这恰好是拓扑序列**反过来**。
→ 把这个输出序列**逆置**，就得到一个拓扑序列。
（也可以理解为：按 DFS **结束时间从大到小**排列顶点，就是拓扑序列。）

### 📐 逆拓扑排序
每次选**出度为 0** 的顶点输出，删除它和所有指向它的边。

## 三、关键路径（⭐⭐⭐）

### 📐 AOE 网
用**带权 DAG** 表示工程：**顶点表示事件**，**有向边表示活动**，**边上的权值表示活动持续的时间**。这种网叫 **AOE 网**（Activity On Edge）。
- **事件**：某些活动已经完成、另一些活动可以开始的“**时间点**”
- **活动**：需要花费时间的“**工作**”

**AOE 网的两个性质**：
1. 只有在某顶点代表的事件**发生后**，从该顶点出发的各活动**才能开始**
2. 只有在进入某顶点的**所有**活动都**结束**时，该顶点代表的事件**才能发生**

**源点**：唯一的入度为 0 的顶点（工程开始）；**汇点**：唯一的出度为 0 的顶点（工程结束）

### 📐 关键路径
- 从源点到汇点的所有路径中，**路径长度（权值和）最大**的路径叫**关键路径**
- 关键路径上的活动叫**关键活动**
- **完成整个工程的最短时间 = 关键路径的长度**

🧒 **为什么是“最长”的路径决定“最短”的工期？** 因为所有路线上的活动都要干完工程才算结束，而最长的那条线是“**瓶颈**”——就像一群人一起出发去一个地方，大家都到齐了才算到，**最慢的人**决定了什么时候到齐。

### 📐 四个参量（⭐⭐⭐ 必须会算）

**① 事件 vₖ 的最早发生时间 ve(k)**：从源点到 vₖ 的**最长**路径长度
$$ve(源点) = 0, \quad ve(k) = \max_{\langle j,k\rangle}\{ve(j) + \text{Weight}(j, k)\}$$
**从前往后**按拓扑序计算，**取最大**。
🧒 事件 k 要等**所有**进入它的活动都完成，所以取最慢的那个。

**② 事件 vₖ 的最迟发生时间 vl(k)**：在不推迟整个工程的前提下，事件最迟必须发生的时间
$$vl(汇点) = ve(汇点), \quad vl(j) = \min_{\langle j,k\rangle}\{vl(k) - \text{Weight}(j, k)\}$$
**从后往前**按逆拓扑序计算，**取最小**。
🧒 事件 j 发生后，**所有**从它出发的活动都要来得及，所以要照顾最紧的那个。

**③ 活动 aᵢ 的最早开始时间 e(i)**：= 该活动**起点事件**的最早发生时间
$$\text{若活动 } a_i = \langle j, k\rangle, \quad e(i) = ve(j)$$

**④ 活动 aᵢ 的最迟开始时间 l(i)**：= 该活动**终点事件**的最迟发生时间 − 活动持续时间
$$l(i) = vl(k) - \text{Weight}(j, k)$$

**时间余量 d(i) = l(i) − e(i)**：活动可以**推迟**多久而不影响工期。
**d(i) = 0 的活动就是关键活动**。

### ✏️ 基础例题
```
活动:  a1: V1→V2 (3)    a2: V1→V3 (2)
       a3: V2→V4 (2)    a4: V2→V5 (3)
       a5: V3→V4 (4)    a6: V3→V6 (3)
       a7: V4→V6 (2)    a8: V5→V6 (1)
```
**第 1 步：从前往后求 ve（取最大）**
| 事件 | V1 | V2 | V3 | V4 | V5 | V6 |
|---|---|---|---|---|---|---|
| ve | 0 | 0+3 = 3 | 0+2 = 2 | max(3+2, 2+4) = **6** | 3+3 = 6 | max(6+2, 6+1, 2+3) = **8** |

**第 2 步：从后往前求 vl（取最小）**
| 事件 | V6 | V5 | V4 | V3 | V2 | V1 |
|---|---|---|---|---|---|---|
| vl | 8 | 8−1 = 7 | 8−2 = 6 | min(6−4, 8−3) = **2** | min(6−2, 7−3) = **4** | min(4−3, 2−2) = **0** |

**第 3 步：求各活动的 e、l、d**
| 活动 | a1 | a2 | a3 | a4 | a5 | a6 | a7 | a8 |
|---|---|---|---|---|---|---|---|---|
| 起点→终点 | V1→V2 | V1→V3 | V2→V4 | V2→V5 | V3→V4 | V3→V6 | V4→V6 | V5→V6 |
| e = ve(起点) | 0 | 0 | 3 | 3 | 2 | 2 | 6 | 6 |
| l = vl(终点) − 权 | 4−3=1 | 2−2=**0** | 6−2=4 | 7−3=4 | 6−4=**2** | 8−3=5 | 8−2=**6** | 8−1=7 |
| d = l − e | 1 | **0** | 1 | 1 | **0** | 3 | **0** | 1 |

**结论**：关键活动 a2、a5、a7；关键路径 **V1 → V3 → V4 → V6**；工期 **8**。

🧒 **检查技巧**：关键路径上的事件一定满足 **ve = vl**（V1、V3、V4、V6）。

### 📐 关键路径的性质（⭐⭐ 选择题）
1. 关键路径上的活动时间**增加** → 工期**一定延长**
2. 关键活动时间**缩短** → 工期**可能缩短**，但：
   - 缩短到一定程度，它可能**不再是关键活动**（别的路径变成了最长的），再缩短就没用了
   - 若有**多条关键路径**，只缩短其中一条上的某个活动，工期**不会缩短**；必须缩短**所有关键路径共有的**活动，或者同时缩短每条关键路径上的活动
3. 关键路径**不一定唯一**

📝 **真题（2020 年第 8 题）**：若使用 AOE 网估算工程进度，下列叙述中正确的是：
- A. 关键路径是从源点到汇点**边数最多**的一条路径 ✗（是**长度**最长，不是边数）
- B. **关键路径是从源点到汇点路径长度最长的路径** ✓
- C. 增加任一关键活动的时间不会延长工程的工期 ✗（一定会延长）
- D. 缩短任一关键活动的时间将会缩短工程的工期 ✗（多条关键路径时不一定）
答案 **B**。

📝 **真题（2022 年第 7 题）**：下图是一个有 10 个活动的 AOE 网，时间余量最大的活动是：A. c B. g C. h D. j
活动（据原卷图）：a: 1→2 (2)、b: 1→3 (5)、c: 2→3 (1)、d: 2→4 (3)、e: 3→4 (3)、f: 3→5 (4)、g: 3→6 (1)、h: 4→5 (1)、i: 4→6 (4)、j: 5→6 (1)
- ve：1:0，2:2，3:max(5, 2+1)=5，4:max(2+3, 5+3)=8，5:max(5+4, 8+1)=9，6:max(8+4, 5+1, 9+1)=**12**
- vl：6:12，5:11，4:min(12−4, 11−1)=8，3:min(8−3, 11−4, 12−1)=5，2:min(8−3, 5−1)=4，1:0
- 四个选项的余量：c：l = 5−1 = 4，e = 2 → **2**；g：l = 12−1 = 11，e = 5 → **6**；h：l = 11−1 = 10，e = 8 → **2**；j：l = 12−1 = 11，e = 9 → **2**
- 时间余量最大的是 **g**，选 B（关键路径 1→3→4→6：b、e、i）

## 四、2025 年第 42 题完整解答（⭐⭐⭐ 最新大题）

> 某工程包含 12 个活动，使用题 42 图所示的 AOE 网描述，图中各边上标注了活动及其持续时间。请回答（活动均用活动名表示）：
> (1) 完成该工程的最短时间是多少？哪些活动是关键活动？（3 分）
> (2) 若按照最短时间完成工程，则与活动 e 同时进行的活动可能有哪些？（3 分）
> (3) 时间余量最大的活动是哪个？其时间余量是多少？（2 分）
> (4) 假设工程从时刻 0 启动，因某种原因，活动 b 在时刻 6 开始，为保证工程不延期，在其他活动持续时间不变的情况下，b 的持续时间最多是多少？若不改变 b 的持续时间，则压缩哪个活动的持续时间也能保证工程不延期？（2 分）

根据你上传的扫描件辨认出的数据如下（扫描件较模糊，个别数字可能与原卷有出入，**重点学方法**）：
| 活动 | a | b | c | d | e | f | g | h | j | k | m | n |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 起点→终点 | 1→3 | 1→2 | 3→4 | 1→4 | 3→6 | 4→2 | 4→6 | 6→7 | 4→5 | 2→5 | 4→7 | 7→5 |
| 持续时间 | 2 | 6 | 3 | 3 | 1 | 4 | 1 | 1 | 1 | 2 | 4 | 3 |
源点 1，汇点 5。拓扑序：1, 3, 4, 6, 2, 7, 5

**求 ve（从前往后，取大）**：
| 事件 | 1 | 3 | 4 | 6 | 2 | 7 | 5 |
|---|---|---|---|---|---|---|---|
| ve | 0 | 2 | max(0+3, 2+3) = 5 | max(2+1, 5+1) = 6 | max(0+6, 5+4) = 9 | max(5+4, 6+1) = 9 | max(9+2, 5+1, 9+3) = **12** |

**求 vl（从后往前，取小）**：
| 事件 | 5 | 7 | 2 | 6 | 4 | 3 | 1 |
|---|---|---|---|---|---|---|---|
| vl | 12 | 12−3 = 9 | 12−2 = 10 | 9−1 = 8 | min(10−4, 12−1, 8−1, 9−4) = 5 | min(5−3, 8−1) = 2 | min(10−6, 2−2, 5−3) = 0 |

**求 e、l、d**：
| 活动 | a | b | c | d | e | f | g | h | j | k | m | n |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| e | 0 | 0 | 2 | 0 | 2 | 5 | 5 | 6 | 5 | 9 | 5 | 9 |
| l | 0 | 4 | 2 | 2 | 7 | 6 | 7 | 8 | 11 | 10 | 5 | 9 |
| d | **0** | 4 | **0** | 2 | 5 | 1 | 2 | 2 | **6** | 1 | **0** | **0** |

**(1)** 最短时间 **12**；关键活动 **a、c、m、n**（关键路径 1 → 3 → 4 → 7 → 5）

**(2)** 活动 e 可能进行的时间段：最早 2 开始，最迟 7 开始，持续 1 → 在 **[2, 8]** 区间内。
能与 e 同时进行的活动，要满足：① 时间区间可能与 [2, 8] 重叠；② **不是 e 的前驱或后继**（a 必须在 e 之前完成，h 必须在 e 之后开始）。
各活动可能的时间区间 [e, l + 持续时间]：b [0,10]、c [2,5]、d [0,5]、f [5,10]、g [5,8]、j [5,12]、m [5,9]、k [9,12]、n [9,12]
→ 可能与 e 同时进行：**b、c、d、f、g、j、m**

**(3)** 时间余量最大的活动是 **j**，余量为 **6**

**(4)** 活动 b（1 → 2）的终点事件 2 最迟发生时间 vl(2) = 10。b 在时刻 6 开始，要保证不延期，b 最多持续 10 − 6 = **4**。
若不改变 b 的持续时间，事件 2 最早发生在“6 + b 的持续时间”，推迟了；事件 2 之后只有活动 k（2 → 5），所以要**压缩活动 k** 的持续时间，使事件 2 的发生时间 + k ≤ 12。

## ⚠️ 易错点
1. 拓扑排序每次选**入度为 0** 的顶点；逆拓扑排序选**出度为 0** 的
2. 拓扑序列不唯一；无环 ⟺ 存在拓扑序列
3. ve 从前往后**取最大**，vl 从后往前**取最小**
4. e(活动) = ve(**起点**)，l(活动) = vl(**终点**) − 权值
5. 关键路径是**长度最长**，不是边数最多
6. 缩短关键活动**不一定**缩短工期（多条关键路径时）

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| AOV 网 | 顶点 = 活动，边 = 先后关系 |
| 拓扑排序 | 反复删入度为 0 的顶点；O(V+E)；可判环 |
| DFS 退出时输出 | 逆拓扑序列 |
| AOE 网 | 边 = 活动（带时间），顶点 = 事件 |
| ve | 前推取大 |
| vl | 后推取小 |
| e / l | e = ve(起点)；l = vl(终点) − 权 |
| 关键活动 | d = l − e = 0 |
| 工期 | 关键路径长度 = ve(汇点) |

2. 某 AOE 网：a1: 1→2 (6)、a2: 1→3 (4)、a3: 1→4 (5)、a4: 2→5 (1)、a5: 3→5 (1)、a6: 4→6 (2)、a7: 5→7 (9)、a8: 5→8 (7)、a9: 6→8 (4)、a10: 7→9 (2)、a11: 8→9 (4)。求工期、关键活动、关键路径。
3. 上题中，如果把 a1 缩短 1，工期变为多少？如果把 a1 缩短 3 呢？
4. 判断：若有向图的邻接矩阵中，主对角线以下的元素全为 0，则该图的拓扑序列唯一。

<details>
<summary>📖 答案</summary>

1. 开始只有 1；之后 2、3 入度为 0。
   - 选 2：剩 3 可选 → 3 → 4、5 都可选：1 2 3 4 5、1 2 3 5 4
   - 选 3：2、5 可选 → 选 2 → 4、5：1 3 2 4 5、1 3 2 5 4；选 5 → 2 → 4：1 3 5 2 4
   共 **5 种**
2. ve：1:0，2:6，3:4，4:5，5:max(7,5)=7，6:7，7:16，8:max(14,11)=14，9:max(18,18)=**18**
   vl：9:18，8:14，7:16，6:10，5:min(16−9, 14−7)=7，4:8，3:6，2:6，1:0
   关键活动（d=0）：a1(0/0)、a4(6/6)、a7(7/7)、a8(7/7)、a10(16/16)、a11(14/14)
   关键路径**两条**：1→2→5→7→9 和 1→2→5→8→9，工期 **18**
3. a1 是两条关键路径共有的活动：缩短 1 → 工期 **17**；缩短 3 → a1 = 3，1→2→5 = 4，但 1→3→5 = 5 成了更长的，ve(5) = 5，工期 = 5 + 11 = **16**（只缩短了 2，因为关键路径变了）
4. **错**。三角矩阵说明**存在**拓扑序列，但不一定唯一（例如没有任何边的图，邻接矩阵全 0 也是三角矩阵，拓扑序列有 n! 种）
