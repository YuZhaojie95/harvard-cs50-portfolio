## 🚪 课前引入：寻宝游戏

老师把全班同学的名字分散藏在教室各处。每张纸条上除了名字，还写着“**下一张纸条藏在哪**”。
- 你只知道第一张纸条在哪（**头指针**）
- 要找第 5 个名字，必须从第 1 张开始，一张一张顺着找过去 → **不能随机访问**
- 要在第 2 张和第 3 张之间加一张新纸条？只要**改第 2 张纸条上的“下一张在哪”**，让它指向新纸条，新纸条再指向原来的第 3 张 → **插入很方便，不用挪动任何纸条**

这就是**链表**。

## 一、单链表的定义

### 📐 结点结构
```
┌──────┬──────┐
│ data │ next │     data：数据域，存元素
└──────┴──────┘     next：指针域，存下一个结点的地址
```
```c
typedef struct LNode {
    ElemType data;           // 数据域
    struct LNode *next;      // 指针域
} LNode, *LinkList;
```
- `LNode *p`：强调 p 指向**一个结点**
- `LinkList L`：强调 L 代表**一整个链表**（其实就是头指针）
- 两者本质相同，都是“指向 LNode 的指针”

### 📐 头指针、头结点、首元结点（⭐ 概念辨析）
```
不带头结点：
  L ──→ [a1|●]──→[a2|●]──→[a3|^]
头指针     首元结点

带头结点：
  L ──→ [   |●]──→[a1|●]──→[a2|●]──→[a3|^]
头指针    头结点     首元结点
```
| 名称 | 含义 |
|---|---|
| **头指针** | 指向链表第一个结点的指针（不管这个结点是头结点还是首元结点）。**链表一定有头指针** |
| **头结点** | 在第一个数据结点**之前额外附加**的一个结点，**数据域一般不存东西**（也可以存表长），指针域指向首元结点 |
| **首元结点** | 存放第一个数据元素 a₁ 的结点 |

**为什么要有头结点？**（⭐ 选择题）
1. **统一操作**：在第 1 个位置插入/删除时，不用特殊处理（否则要修改头指针本身）
2. **统一空表和非空表**：带头结点时，无论表是否为空，头指针都指向头结点（非空）
   - 带头结点的空表：`L->next == NULL`
   - 不带头结点的空表：`L == NULL`

> 💡 考试中如果题目没说，一般默认**带头结点**。下面的代码都是带头结点的版本。

### 📐 单链表的特点
- ✅ 不需要连续空间；插入删除不需要移动元素，只改指针
- ❌ 每个结点要多存一个指针，存储密度低
- ❌ **不能随机存取**，找第 i 个元素要从头遍历，O(n)

## 二、基本操作（⭐⭐⭐ 每个都要能默写）

### 2.1 初始化（带头结点）
```c
bool InitList(LinkList &L) {
    L = (LNode *)malloc(sizeof(LNode));   // 创建头结点
    if (L == NULL) return false;          // 内存不足
    L->next = NULL;                       // 头结点之后暂时没有结点
    return true;
}
```

### 2.2 求表长
```c
int Length(LinkList L) {
    int len = 0;
    LNode *p = L;               // p 从头结点出发
    while (p->next != NULL) {   // 只要后面还有结点
        p = p->next;
        len++;
    }
    return len;
}
```
O(n)。（有的实现把表长存在头结点的 data 里，就是 O(1)。）

### 2.3 按序号查找：找第 i 个结点
```c
LNode *GetElem(LinkList L, int i) {
    if (i < 0) return NULL;
    LNode *p = L;               // 头结点看作第 0 个结点
    int j = 0;                  // p 当前指向第 j 个结点
    while (p != NULL && j < i) {
        p = p->next;
        j++;
    }
    return p;                   // i 大于表长时返回 NULL
}
```
🧒 **理解关键**：变量 `j` 始终记录“p 现在指着第几个”。循环结束时 j == i，p 就指向第 i 个。
平均 O(n)。

### 2.4 按值查找
```c
LNode *LocateElem(LinkList L, ElemType e) {
    LNode *p = L->next;         // 从第 1 个数据结点开始
    while (p != NULL && p->data != e)
        p = p->next;
    return p;                   // 找不到返回 NULL
}
```
O(n)。

### 2.5 插入（⭐⭐⭐）

#### (1) 按位序插入：在第 i 个位置插入 e
**思路**：找到第 i−1 个结点 p，在 p 后面插入新结点。

```
插入前：  p ──→ [ai-1|●]──────────→[ai|●]
插入后：  p ──→ [ai-1|●]   [e|●]   [ai|●]
                     ╲    ↗    ╲  ↗
                      ②         ①
① s->next = p->next    （新结点先拉住原来的第 i 个）
② p->next = s          （第 i-1 个再拉住新结点）
```
```c
bool ListInsert(LinkList &L, int i, ElemType e) {
    if (i < 1) return false;
    LNode *p = GetElem(L, i - 1);     // 找第 i-1 个结点
    if (p == NULL) return false;      // i 不合法（太大）
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;                // ①
    p->next = s;                      // ②
    return true;
}
```
⚠️ **①② 顺序不能反**！如果先执行 `p->next = s`，原来 p 后面的结点（aᵢ）的地址就丢了，再也找不到了。
🧒 **口诀：先连后断**——新人先抓住后面的人，前面的人再松手去抓新人。

**复杂度**：查找第 i−1 个 O(n) + 插入本身 O(1) → 总 O(n)。
⚠️ 如果**已经给了结点 p**，要在 p 后面插入，就是 **O(1)**。

#### (2) 后插操作：在给定结点 p 之后插入
```c
bool InsertNextNode(LNode *p, ElemType e) {
    if (p == NULL) return false;
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;
    p->next = s;
    return true;
}
```
O(1)。

#### (3) 前插操作：在给定结点 p **之前**插入（⭐ 技巧）
问题：单链表只能往后走，p 的前驱找不到（除非从头遍历，O(n)）。
**偷天换日法**：在 p **后面**插入新结点 s，然后**交换 p 和 s 的数据**。这样看起来就像在 p 前面插入了。
```
想在 p 前面插入 e：
原：   ... → [x|●]p → [y] ...
后插：  ... → [x|●]p → [e|●]s → [y] ...
交换：  ... → [e|●]p → [x|●]s → [y] ...     ← e 就在 x 前面了 ✓
```
```c
bool InsertPriorNode(LNode *p, ElemType e) {
    if (p == NULL) return false;
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->next = p->next;
    p->next = s;            // s 接在 p 后面
    s->data = p->data;      // p 的数据搬到 s
    p->data = e;            // p 里放新数据
    return true;
}
```
O(1)。

### 2.6 删除（⭐⭐⭐）

#### (1) 按位序删除：删除第 i 个结点
**思路**：找到第 i−1 个结点 p，让 p 直接指向第 i+1 个，释放第 i 个。
```
删除前：  p → [ai-1|●] → [ai|●]q → [ai+1|●]
删除后：  p → [ai-1|●] ─────────→ [ai+1|●]     free(q)
```
```c
bool ListDelete(LinkList &L, int i, ElemType &e) {
    if (i < 1) return false;
    LNode *p = GetElem(L, i - 1);           // 找第 i-1 个
    if (p == NULL || p->next == NULL)       // i-1 不存在，或第 i 个不存在
        return false;
    LNode *q = p->next;                     // q 是要删的结点
    e = q->data;
    p->next = q->next;                      // 跳过 q
    free(q);
    return true;
}
```
O(n)（主要花在查找上）。

#### (2) 删除给定结点 p（⭐ 技巧）
同样的问题：找不到 p 的前驱。
**偷天换日法**：把 p 的**后继**结点的数据复制到 p 中，然后删掉后继结点。
```c
bool DeleteNode(LNode *p) {
    if (p == NULL) return false;
    LNode *q = p->next;         // q 是 p 的后继
    p->data = q->data;          // 后继的数据搬过来
    p->next = q->next;          // 删掉后继
    free(q);
    return true;
}
```
O(1)。⚠️ **局限**：如果 p 是**最后一个结点**（q == NULL），这个方法不行，只能从头找前驱，O(n)。

### 2.7 建立单链表（⭐⭐）

#### (1) 头插法：每次把新结点插到**头结点之后**
```c
LinkList List_HeadInsert(LinkList &L) {
    L = (LNode *)malloc(sizeof(LNode));
    L->next = NULL;                         // 空表（这句很重要！）
    int x;
    scanf("%d", &x);
    while (x != 9999) {                     // 输入 9999 表示结束
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = x;
        s->next = L->next;                  // 新结点指向原来的第一个
        L->next = s;                        // 头结点指向新结点
        scanf("%d", &x);
    }
    return L;
}
```
**过程**：依次输入 1, 2, 3
```
输入 1：L → [1]
输入 2：L → [2] → [1]
输入 3：L → [3] → [2] → [1]
```
⚠️ **头插法得到的链表顺序与输入顺序相反**！
💡 **重要应用：链表逆置**。把原链表的结点依次摘下来，用头插法插回去，就逆置了（下一课讲）。

#### (2) 尾插法：每次把新结点插到**表尾**，需要一个**尾指针 r**
```c
LinkList List_TailInsert(LinkList &L) {
    L = (LNode *)malloc(sizeof(LNode));
    LNode *r = L;                           // r 始终指向表尾
    int x;
    scanf("%d", &x);
    while (x != 9999) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = x;
        r->next = s;                        // 接在表尾后面
        r = s;                              // r 移到新的表尾
        scanf("%d", &x);
    }
    r->next = NULL;                         // 表尾指针置空（别忘了！）
    return L;
}
```
**过程**：依次输入 1, 2, 3 → L → [1] → [2] → [3]，**顺序与输入相同**。

两种建表方法都是 **O(n)**。

## 三、不带头结点的情况（了解区别）

不带头结点时，在第 1 个位置插入要**特殊处理**：
```c
if (i == 1) {
    LNode *s = (LNode *)malloc(sizeof(LNode));
    s->data = e;
    s->next = L;
    L = s;              // 头指针要指向新结点！（所以 L 必须用引用传入）
    return true;
}
// i > 1 时和带头结点的一样
```
删除第 1 个结点也要修改头指针 L。这就是头结点的价值：**让所有位置的操作都一样**。

## 四、顺序表 vs 链表（⭐⭐⭐ 必考比较）

| 比较项 | 顺序表 | 链表 |
|---|---|---|
| 存取方式 | **随机存取** | **顺序存取** |
| 逻辑与物理 | 逻辑相邻 = 物理相邻 | 逻辑相邻，物理不一定相邻 |
| 按位查找 | **O(1)** | O(n) |
| 按值查找 | O(n)；有序时可折半 O(log n) | O(n)（有序也不能折半） |
| 插入/删除 | O(n)，**主要花在移动元素** | O(n)，**主要花在查找位置**；已知位置则 O(1) |
| 存储密度 | 高（= 1） | 低（< 1） |
| 空间分配 | 预分配，大了浪费，小了溢出 | 按需分配，灵活 |
| 碎片 | 需要连续空间，可能有外部碎片 | 无 |

**怎么选？**
- 经常**按位置查找**、很少插入删除、表长能预估 → **顺序表**
- 经常**插入删除**、表长变化大 → **链表**

📝 **经典选择题**：某线性表最常用的操作是“存取任一指定序号的元素”和“在最后进行插入和删除”，用哪种存储最省时间？
→ **顺序表**（按序号存取 O(1)，在表尾插删也不用移动元素）

---

## ⚠️ 易错点
1. 带头结点空表：`L->next == NULL`；不带头结点空表：`L == NULL`
2. 插入：**先连后断**（`s->next = p->next;` 在 `p->next = s;` 之前）
3. 删除后要 `free`
4. 尾插法结束后要把 `r->next = NULL`
5. 头插法得到**逆序**链表
6. 删除给定结点 p 的“复制后继”技巧，**p 是尾结点时不能用**
7. 链表有序也**不能用折半查找**

## 📋 本课小结

| 操作 | 核心代码 | 时间 |
|---|---|---|
| 按位查找 | `while (p && j < i) { p = p->next; j++; }` | O(n) |
| 后插 s | `s->next = p->next; p->next = s;` | O(1) |
| 前插 | 后插 + 交换数据 | O(1) |
| 删除 p 的后继 q | `q = p->next; p->next = q->next; free(q);` | O(1) |
| 删除 p 本身 | 复制后继数据 + 删后继 | O(1)（p 非尾） |
| 头插法 | `s->next = L->next; L->next = s;` | 逆序 |
| 尾插法 | `r->next = s; r = s;` 最后 `r->next = NULL` | 正序 |

## 🏋️ 课后练习

1. 在单链表中，p 指向某结点，要删除 p 的后继结点，正确的语句是？
2. 带头结点的单链表 L，判断其为空的条件是？若不带头结点呢？
3. 已知 p 指向单链表中某结点（非尾结点），在 O(1) 时间内删除 p 所指结点，写出代码。
4. 依次输入 5, 8, 2, 7，分别用头插法、尾插法建表，写出结果。
5. 下列关于头结点的说法错误的是：
   A. 头结点的数据域可以不存储信息
   B. 有了头结点，插入第一个位置不需特殊处理
   C. 头指针一定指向头结点
   D. 带头结点的空表中，头结点的指针域为空

<details>
<summary>📖 答案</summary>

1. `q = p->next; p->next = q->next; free(q);`
2. 带头结点：`L->next == NULL`；不带头结点：`L == NULL`
3. `q = p->next; p->data = q->data; p->next = q->next; free(q);`
4. 头插法：L → 7 → 2 → 8 → 5；尾插法：L → 5 → 8 → 2 → 7
5. **C**。头指针指向链表的第一个结点，不带头结点时指向首元结点
</details>
