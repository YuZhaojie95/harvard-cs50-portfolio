## 🚪 课前引入：图书馆的故事

一个图书馆有 10 万本书。
- 书与书之间有什么**关系**？（按类别分？按作者分？按编号排成一排？）——这是**逻辑结构**
- 书**放在哪里**？（一排书架挨着放？还是散放在各处，每本书里夹张纸条写着下一本在哪？）——这是**存储结构**
- 要对书**做什么**？（借书、还书、查找、上新书）——这是**数据的运算**

数据结构这门课，就是研究这三件事。

## 一、基本概念和术语

| 术语 | 定义 | 例子（学生成绩管理） |
|---|---|---|
| **数据** | 信息的载体，能输入计算机并被程序处理的符号的集合 | 整个成绩系统里的所有东西 |
| **数据元素** | 数据的**基本单位**，通常作为一个整体处理（也叫记录、结点） | 一个学生的记录 |
| **数据项** | 构成数据元素的**不可分割的最小单位** | 学号、姓名、成绩 |
| **数据对象** | 具有**相同性质**的数据元素的集合，是数据的子集 | 所有学生记录的集合 |
| **数据类型** | 一个值的集合 + 定义在这个集合上的一组操作 | int：整数集合 + 加减乘除 |
| **抽象数据类型（ADT）** | 一个数学模型 + 定义在其上的一组操作；**只描述逻辑特性，与计算机内部如何表示无关** | “栈”：只规定能 push、pop，不管用数组还是链表实现 |
| **数据结构** | 相互之间存在一种或多种特定**关系**的数据元素的集合 | |

🧒 **层次关系**：数据 ⊃ 数据对象 ⊃ 数据元素 ⊃ 数据项
就像：学校所有档案 ⊃ 学生档案 ⊃ 一个学生的档案 ⊃ 档案里的“姓名”一栏

⚠️ **易混点**：数据元素是“基本单位”，数据项是“最小单位”。

**数据类型分三种**：
- 原子类型：值不可再分（int、char）
- 结构类型：值可以再分（结构体、数组）
- 抽象数据类型

## 二、数据结构的三要素（⭐⭐）

```
            数据结构
   ┌───────────┼───────────┐
逻辑结构      存储结构      数据的运算
（关系是什么）（在内存怎么放）（能做什么操作）
```

### 2.1 逻辑结构（⭐）
**逻辑结构 = 数据元素之间的逻辑关系，与存储无关，独立于计算机。**

四种基本逻辑结构：

```
① 集合            ② 线性结构         ③ 树形结构           ④ 图状/网状结构
 ┌─────────┐                             A                    A ── B
 │ ●  ●    │      ● → ● → ● → ●        / | \                 │ ╲  │
 │   ●   ● │                           B  C  D                C ── D
 └─────────┘                          / \
 同属一个集合，    一对一               E   F                   多对多
 别无其他关系                          一对多
```

| 逻辑结构 | 关系 | 例子 |
|---|---|---|
| 集合 | 同属一个集合，**没有其他关系** | 一袋弹珠 |
| **线性结构** | **一对一**：除第一个外每个都有唯一前驱，除最后一个外每个都有唯一后继 | 排队、线性表、栈、队列、串 |
| **树形结构** | **一对多** | 家谱、文件夹目录 |
| **图状结构** | **多对多** | 地铁线路、社交网络 |

**分类**：
- **线性结构**：线性表、栈、队列、串、数组（一维）、广义表（有争议，一般不讨论）
- **非线性结构**：集合、树、二叉树、图

⚠️ **栈和队列是线性结构**（逻辑上一对一），只是操作受限。

### 2.2 存储结构（物理结构，⭐⭐）
**存储结构 = 数据结构在计算机中的表示（映像），依赖于计算机语言。**

四种基本存储结构：

**① 顺序存储**：逻辑上相邻的元素，物理位置上也相邻
```
内存：| a1 | a2 | a3 | a4 | a5 |
```
- ✅ 可以**随机存取**（知道第 i 个在哪，直接算地址）；每个元素占用空间最少（存储密度 = 1）
- ❌ 只能用一整块连续空间，可能产生**外部碎片**；插入删除要移动大量元素

**② 链式存储**：不要求物理上相邻，借助**指针**表示元素之间的逻辑关系
```
[a1|●]→[a3|●]→[a2|●]→[a4|^]      （物理顺序任意，靠指针串起来）
```
- ✅ 不会出现碎片，能充分利用所有存储单元；插入删除只改指针
- ❌ 每个元素要额外存指针，**存储密度 < 1**；只能**顺序存取**

**③ 索引存储**：存储元素的同时，建一张**索引表**（关键字, 地址）
- ✅ 检索快
- ❌ 索引表占额外空间；增删数据时也要修改索引表

**④ 散列存储（哈希存储）**：根据元素的关键字，用**散列函数**直接算出存储地址
- ✅ 检索、增加、删除都很快
- ❌ 散列函数不好时会出现**冲突**，解决冲突要额外开销

### 2.3 数据的运算
- **运算的定义**针对**逻辑结构**，指出运算的功能（比如“插入”：把元素放到第 i 个位置）
- **运算的实现**针对**存储结构**，指出具体步骤（顺序表插入要移动元素，链表插入要改指针）

### 2.4 三者关系（⭐ 选择题陷阱）
- 同一个**逻辑结构**可以用不同的**存储结构**实现（线性表可以用顺序表或链表）
- **存储结构影响运算的效率**（顺序表按位置查找 O(1)，链表 O(n)）
- 一个名词到底表示逻辑结构还是“逻辑 + 存储”？

| 名词 | 性质 |
|---|---|
| 线性表、栈、队列、树、图 | **只是逻辑结构**（没说怎么存） |
| 顺序表 | 线性表 + **顺序存储** |
| 链表（单链表、双链表） | 线性表 + **链式存储** |
| 循环队列 | 队列 + **顺序存储** |
| 链栈 | 栈 + 链式存储 |
| 散列表（哈希表） | 同时定义了逻辑结构和存储结构 |
| 线索二叉树 | 是一种**物理结构**（在二叉链表上加线索） |
| 有序表 | **逻辑结构**（只说元素有序，没说怎么存；可以顺序存也可以链式存） |

📝 **经典真题（2010 年）**：下列选项中，与数据的**存储结构无关**的术语是（ ）
A. 循环队列  B. 链表  C. 哈希表  D. 栈
→ 循环队列（顺序存储的队列）、链表（链式）、哈希表（散列存储）都和存储有关；**栈**只是逻辑结构。选 **D**。

📝 **经典题**：以下属于逻辑结构的是（ ）A. 顺序表 B. 哈希表 C. 有序表 D. 单链表 → 选 **C**。

## 三、复杂度真题巩固

复杂度的完整讲解在[预备第 4 课](../00-导学与预备/04-算法与复杂度.md)。这里再列一次 408 历年第 1 题的常见考法，确认你全部会做：

| 年份 | 代码核心 | 答案 | 方法 |
|---|---|---|---|
| 2011 | `x=2; while(x<n/2) x=2*x;` | O(log n) | 乘法变化 |
| 2012 | 递归求 n! | O(n) | 递推 T(n)=T(n−1)+1 |
| 2014 | 外层 `k*=2`，内层 `j<=n` | O(n log n) | 内外独立，相乘 |
| 2017 | `while(sum<n) sum+=++i;` | O(√n) | 累加到 n |
| 2019 | `while(n>=(x+1)*(x+1)) x++;` | O(√n) | 平方 |
| 2022 | 外层 `i*=2`，内层 `j<i` | O(n) | 依赖嵌套，等比求和 |
| 2025 | 外层 `i*i<=n`，内层 `j<=i` | O(n) | 依赖嵌套，等差求和 |

## ⚠️ 易错点
1. 数据元素是**基本单位**，数据项是**最小单位**
2. 栈、队列是**线性结构**；树、图是非线性结构
3. “有序表”是逻辑结构；“顺序表”是存储结构（含逻辑）
4. 逻辑结构独立于计算机；存储结构依赖于计算机语言
5. 链式存储：存储密度 < 1，**不能随机存取**
6. 算法的“运算定义”看逻辑结构，“运算实现”看存储结构

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 层次 | 数据 ⊃ 数据对象 ⊃ 数据元素（基本单位）⊃ 数据项（最小单位） |
| ADT | 只管逻辑特性，与实现无关 |
| 三要素 | 逻辑结构、存储结构、数据的运算 |
| 逻辑结构 | 集合、线性（一对一）、树（一对多）、图（多对多） |
| 存储结构 | 顺序（随机存取）、链式（顺序存取）、索引、散列 |
| 名词判断 | 栈/队列/树/有序表 = 逻辑；顺序表/链表/循环队列/哈希表 = 含存储 |

## 🏋️ 课后练习

1. 以下与数据存储结构无关的是：A. 顺序栈 B. 线性表 C. 散列表 D. 双链表
2. 以下关于数据结构的说法正确的是：
   A. 逻辑结构与数据元素本身的内容和形式无关
   B. 数据元素是数据的最小单位
   C. 链式存储结构的存储密度等于 1
   D. 同一逻辑结构只能用一种存储结构实现
3. 链式存储相比顺序存储的优点是？缺点是？
4. 下列属于非线性结构的是：A. 串 B. 队列 C. 二叉树 D. 栈

<details>
<summary>📖 答案</summary>

1. **B**（线性表只是逻辑结构）
2. **A**。B 错：最小单位是数据项；C 错：链式存储要存指针，密度 < 1；D 错：可以有多种
3. 优点：不要求连续空间，插入删除只需修改指针、不需移动元素，空间利用灵活；缺点：存储密度低（要存指针），不支持随机存取
4. **C**
</details>
