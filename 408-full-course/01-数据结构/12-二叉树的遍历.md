# 数据结构 第 12 课 · 二叉树的遍历与构造

> 🎯 **本课目标**
> 1. **熟练写出**任意二叉树的先序、中序、后序、层序序列

>
> 遍历是二叉树**所有算法的基础**。二叉树的算法题，几乎都是“在遍历的框架里加几行代码”。

## 🚪 课前引入：怎么“拜访”每一个家族成员

你要给家族里的每个人送一份礼物，每人只送一次。按什么顺序送？
- 先送给自己家长，再送左边这一支，再送右边这一支 → **先序**
- 先送左边这一支，再送家长，再送右边这一支 → **中序**
- 先送左边这一支，再送右边这一支，最后送家长 → **后序**
- 按辈分，一代一代地送，同一代从左到右 → **层序**

## 一、三种递归遍历（⭐⭐⭐）

### 📐 定义（“序”指的是**根**什么时候被访问）
| 遍历 | 顺序 | 口诀 |
|---|---|---|
| **先序（前序）PreOrder** | 根 → 左子树 → 右子树 | **根左右** |
| **中序 InOrder** | 左子树 → 根 → 右子树 | **左根右** |
| **后序 PostOrder** | 左子树 → 右子树 → 根 | **左右根** |

左子树永远在右子树前面，只是根的位置不同。

### 📐 代码
```c
void PreOrder(BiTree T) {
    if (T != NULL) {
        visit(T);                // 访问根
        PreOrder(T->lchild);     // 先序遍历左子树
        PreOrder(T->rchild);     // 先序遍历右子树
    }
}
void InOrder(BiTree T) {
    if (T != NULL) {
        InOrder(T->lchild);
        visit(T);
        InOrder(T->rchild);
    }
}
void PostOrder(BiTree T) {
    if (T != NULL) {
        PostOrder(T->lchild);
        PostOrder(T->rchild);
        visit(T);
    }
}
```
三段代码**只有 visit 的位置不同**！

### ✏️ 手工求遍历序列
```
            A
          /   \
         B     C
        / \     \
       D   E     F
          /     / \
         G     H   I
```
**方法：递归展开**（把子树当成一个整体，一层层展开）
- 先序：A [B 的子树] [C 的子树] = A B D E G C F H I
- 中序：[B 的子树] A [C 的子树] = D B G E A C H F I
- 后序：[B 的子树] [C 的子树] A = D G E B H I F C A

**快速技巧 1：中序的“投影法”**
把每个结点**垂直往下投影**到一条水平线上，从左到右读就是中序。（前提：画树时左孩子严格在左下、右孩子严格在右下）

**快速技巧 2：“绕圈法”**
从根的左边出发，沿着树的外轮廓**逆时针**绕一圈（像描边一样），每个结点会被经过 3 次：
- 第 1 次经过（从结点**左边**经过）时访问 → 先序
- 第 2 次经过（从结点**下边**经过）时访问 → 中序
- 第 3 次经过（从结点**右边**经过）时访问 → 后序

### 📐 复杂度
- 时间：每个结点访问一次，**O(n)**
- 空间：递归栈深度 = 树高 h，**O(h)**；最坏（单支树）O(n)，最好（完全二叉树）O(log n)

### 📐 递归执行过程（理解栈的作用）
中序遍历上图时，系统栈的变化：
```
访问 A → 先进入 A 的左子树（A 压栈）
  访问 B → 进入 B 的左子树（B 压栈）
    访问 D → D 的左子树空 → 输出 D → D 的右子树空 → 返回
  输出 B（B 出栈）→ 进入 B 的右子树
    E 压栈 → G 压栈 → G 左空 → 输出 G → G 右空 → 返回
    输出 E → E 右空 → 返回
输出 A → 进入 A 的右子树 ……
```
🧒 “**一路往左走到底，边走边把结点压栈；走不动了就弹出一个访问，然后转向它的右子树**”——这就是非递归中序遍历的思路。

## 二、非递归遍历（用栈，⭐⭐）

### 2.1 中序非递归
```c
void InOrder2(BiTree T) {
    SqStack S; InitStack(S);
    BiTNode *p = T;
    while (p != NULL || !StackEmpty(S)) {
        if (p != NULL) {             // 一路向左
            Push(S, p);
            p = p->lchild;
        } else {                     // 左边走到头了
            Pop(S, p);
            visit(p);                // 访问
            p = p->rchild;           // 转向右子树
        }
    }
}
```

### 2.2 先序非递归
和中序几乎一样，只是**在压栈时就访问**：
```c
if (p != NULL) {
    visit(p);                        // 入栈前访问
    Push(S, p);
    p = p->lchild;
} else {
    Pop(S, p);
    p = p->rchild;
}
```

### 2.3 后序非递归（⭐ 难点）
难点：一个结点从栈顶被看到时，要判断它的**右子树是否已经访问过**。只有左右子树都访问完了才能访问它。
用一个指针 r 记录**最近访问过的结点**：
```c
void PostOrder2(BiTree T) {
    SqStack S; InitStack(S);
    BiTNode *p = T, *r = NULL;          // r 指向最近访问过的结点
    while (p != NULL || !StackEmpty(S)) {
        if (p != NULL) {                // 一路向左
            Push(S, p);
            p = p->lchild;
        } else {
            GetTop(S, p);               // 看栈顶（先不弹出）
            if (p->rchild != NULL && p->rchild != r) {
                p = p->rchild;          // 右子树存在且没访问过 → 去右子树
            } else {
                Pop(S, p);              // 右子树为空或已访问 → 访问它
                visit(p);
                r = p;                  // 记录最近访问的结点
                p = NULL;               // 重置 p，下一轮继续看栈顶
            }
        }
    }
}
```
📐 **后序非递归的重要性质**：访问某个结点时，**栈中的元素恰好是从根到该结点的路径上的所有祖先**。
→ 可用于：求根到某结点的路径、求两个结点的**最近公共祖先**。

## 三、层序遍历（用队列，⭐⭐）

```c
void LevelOrder(BiTree T) {
    SqQueue Q; InitQueue(Q);
    BiTNode *p;
    EnQueue(Q, T);                      // 根入队
    while (!QueueEmpty(Q)) {
        DeQueue(Q, p);                  // 队头出队
        visit(p);
        if (p->lchild != NULL) EnQueue(Q, p->lchild);   // 左孩子入队
        if (p->rchild != NULL) EnQueue(Q, p->rchild);   // 右孩子入队
    }
}
```
上图的层序：**A B C D E F G H I**

**队列变化**：
```
[A] → 出A,入B C → [B C] → 出B,入D E → [C D E] → 出C,入F → [D E F]
→ 出D → [E F] → 出E,入G → [F G] → 出F,入H I → [G H I] → 出G,H,I
```
**应用**：求树的**宽度**（结点最多的那层的结点数）、判断**完全二叉树**、按层输出、求高度（非递归）。

## 四、由遍历序列构造二叉树（⭐⭐⭐）

### 📐 结论
| 已知序列 | 能否唯一确定二叉树 |
|---|---|
| 先序 + 中序 | ✓ |
| 后序 + 中序 | ✓ |
| 层序 + 中序 | ✓ |
| 先序 + 后序 | ✗ |
| 只有一种序列 | ✗ |

🧒 **为什么必须有中序？** 先序/后序/层序只能告诉你“**谁是根**”，但分不清剩下的结点**哪些在左子树、哪些在右子树**。中序正好可以：**根的左边全是左子树，右边全是右子树**。

**先序 + 后序为什么不行？** 例：先序 AB、后序 BA，B 可能是 A 的左孩子，也可能是右孩子。

### 📐 先序 + 中序 → 二叉树
**步骤**：
1. **先序的第一个**是根
2. 在**中序**中找到根，**左边是左子树的中序，右边是右子树的中序**
3. 根据左子树的结点个数 k，在先序中取根后面的 k 个作为左子树的先序，剩下的是右子树的先序
4. 对左右子树**递归**

✏️ **例**：先序 `A B D E G C F H I`，中序 `D B G E A C H F I`
```
第 1 步：根 = A；中序中 A 左边 [D B G E]（4 个），右边 [C H F I]
         先序中 A 后面 4 个 [B D E G] 是左子树，后面 [C F H I] 是右子树
第 2 步：左子树：先序 B D E G，中序 D B G E → 根 B，左 [D]，右 [G E]
         B 的右子树：先序 E G，中序 G E → 根 E，G 在 E 左边 → G 是 E 的左孩子
第 3 步：右子树：先序 C F H I，中序 C H F I → 根 C，C 左边没有 → 无左子树；右 [H F I]
         C 的右子树：先序 F H I，中序 H F I → 根 F，左 H，右 I
```
还原出的就是本课开头那棵树 ✓

### 📐 后序 + 中序 → 二叉树
**后序的最后一个**是根，其余同上（在后序中，左子树的 k 个在前，右子树的在后，根在最后）。

✏️ **例**：后序 `D G E B H I F C A`，中序 `D B G E A C H F I` → 根 A（后序最后），中序分左右……同样还原出上面的树。

### 📐 层序 + 中序 → 二叉树
层序第一个是根；在中序中划分左右子树；然后在**层序序列中按顺序**找出属于左子树的结点（它们在层序中的相对顺序就是左子树的层序），右子树同理。

### 📐 由序列关系推断形态（⭐ 选择题）
| 条件 | 结论 |
|---|---|
| 先序 = 中序 | 每个结点**都没有左孩子**（右单支） |
| 中序 = 后序 | 每个结点**都没有右孩子**（左单支） |
| 先序 = 后序 | 只有**一个结点**（或空树） |
| 先序与后序**相反** | 每个结点**只有一个孩子**（每层一个结点，高度 = 结点数） |
| 先序与中序**相反** | 每个结点都没有右孩子 |
| 中序与后序相反 | 每个结点都没有左孩子 |

🧒 推导例子：先序“根左右”，中序“左根右”，要相同 → 左子树必须为空。

📝 **真题（2022 年第 3 题）**：若结点 p 与 q 在二叉树 T 的**中序**遍历序列中相邻，且 p 在 q 之前，则下列 p 与 q 的关系中，**不可能**的是：
I. q 是 p 的双亲 &nbsp; II. q 是 p 的右孩子 &nbsp; III. q 是 p 的右兄弟 &nbsp; IV. q 是 p 的双亲的双亲

逐个分析（中序是“左根右”）：
- I 可能：p 是 q 的**左孩子**，且 p 没有右子树 → 中序 … p q …
- II 可能：q 是 p 的右孩子，且 q **没有左子树** → 中序 … p q …
- III **不可能**：p、q 是兄弟（p 左 q 右），中序中它们之间**一定隔着双亲**（左子树 … 双亲 … 右子树）
- IV 可能：q 的左孩子是 x，x 的右孩子是 p，且 p 没有右子树 → 中序 … x p q …
答案：**仅 III**，选 B。

📝 **经典题**：一棵二叉树的先序为 1, 2, 3, 4，其中序**不可能**是？A. 1,2,3,4 B. 2,3,4,1 C. 3,2,4,1 D. 4,1,2,3 … 方法：先序固定时，中序合法 ⟺ 把先序当入栈序列、中序当出栈序列时合法（卡特兰数对应关系）。例如“4, 1, 2, 3”：4 先出栈时 1、2、3 在栈中，下一个只能是 3 → 不合法。

## 五、遍历的应用：递归算法题（⭐⭐⭐ 41 题常客）

🎯 **万能思路**：把问题分解为“**根 + 左子树的结果 + 右子树的结果**”，用递归解决。写代码时先写**递归出口**（空树返回什么），再写**如何组合**左右子树的结果。

### 题 1：求结点总数
```c
int CountNodes(BiTree T) {
    if (T == NULL) return 0;
    return CountNodes(T->lchild) + CountNodes(T->rchild) + 1;
}
```

### 题 2：求叶子数
```c
int CountLeaves(BiTree T) {
    if (T == NULL) return 0;
    if (T->lchild == NULL && T->rchild == NULL) return 1;   // 是叶子
    return CountLeaves(T->lchild) + CountLeaves(T->rchild);
}
```

### 题 3：求度为 2 的结点数、度为 1 的结点数
```c
int CountDegree2(BiTree T) {
    if (T == NULL) return 0;
    int self = (T->lchild != NULL && T->rchild != NULL) ? 1 : 0;
    return self + CountDegree2(T->lchild) + CountDegree2(T->rchild);
}
```

### 题 4：求高度
```c
int Height(BiTree T) {
    if (T == NULL) return 0;
    int hl = Height(T->lchild), hr = Height(T->rchild);
    return (hl > hr ? hl : hr) + 1;
}
```

### 题 5：交换所有结点的左右子树（镜像）
```c
void Swap(BiTree T) {
    if (T == NULL) return;
    BiTNode *t = T->lchild; T->lchild = T->rchild; T->rchild = t;
    Swap(T->lchild);
    Swap(T->rchild);
}
```

### 题 6：求第 k 层的结点数
```c
int CountLevelK(BiTree T, int k) {
    if (T == NULL) return 0;
    if (k == 1) return 1;                       // 当前子树的根就在第 k 层
    return CountLevelK(T->lchild, k - 1) + CountLevelK(T->rchild, k - 1);
}
```

### 题 7：二叉树的带权路径长度 WPL（⭐ 2014 年第 41 题原题，13 分）
> 二叉树的 WPL 是所有**叶结点**的带权路径长度之和（权值 × 该叶子的深度，深度指从根到它的路径长度，即边数）。二叉链表结点为 (left, weight, right)，root 为根指针，设计求 WPL 的算法。

**设计思想**：先序遍历，用参数 deep 记录当前结点的深度（根为 0）。遇到叶子时，把 weight × deep 累加到结果中。
```c
typedef struct BiTNode {
    int weight;
    struct BiTNode *left, *right;
} BiTNode, *BiTree;

int wpl_PreOrder(BiTree root, int deep) {
    if (root == NULL) return 0;
    if (root->left == NULL && root->right == NULL)       // 叶结点
        return root->weight * deep;
    return wpl_PreOrder(root->left, deep + 1)            // 左右子树深度 +1
         + wpl_PreOrder(root->right, deep + 1);
}
int WPL(BiTree root) {
    return wpl_PreOrder(root, 0);
}
```
也可以用**层序遍历**：记录当前层数，出队遇到叶子就累加。
时间 O(n)，空间 O(h)。

### 题 8：表达式树转中缀表达式（⭐ 2017 年第 41 题原题，15 分）
> 将给定的表达式树（二叉树）转换为等价的中缀表达式（通过括号反映操作符的计算次序）并输出。例如，树 `*(+(a, b), *(c, −(d)))` 输出 `(a+b)*(c*(-d))`。结点：(left, data[10], right)。

```
         *                   *
       /   \               /   \
      +     *             +     -
     / \   / \           / \     \
    a   b c   -         a   b     -
               \                   \
                d                   d
```
**设计思想**：中序遍历即可得到中缀表达式，关键是**加括号**：
- **根结点**外面不加括号（最外层不需要）
- **叶结点**（操作数）不加括号
- 其他**分支结点**（运算符），在遍历它的左子树之前加 `(`，遍历完右子树之后加 `)`

用参数 deep 表示当前深度，根的 deep = 1。
```c
void BtreeToExp(BTree *root, int deep) {
    if (root == NULL) return;
    if (root->left == NULL && root->right == NULL) {
        printf("%s", root->data);                // 叶结点：直接输出操作数
    } else {
        if (deep > 1) printf("(");               // 非根的分支结点：加左括号
        BtreeToExp(root->left, deep + 1);
        printf("%s", root->data);                // 输出运算符
        BtreeToExp(root->right, deep + 1);
        if (deep > 1) printf(")");               // 加右括号
    }
}
void BtreeToE(BTree *root) {
    BtreeToExp(root, 1);
}
```
🧒 注意 `-(d)` 这种**一元运算符**：它只有右孩子，左子树为空，所以输出 `(-d)`，正好符合要求。

### 题 9：判断是否为完全二叉树（用层序遍历）
**思想**：层序遍历，**空结点也入队**。一旦遇到空结点，检查队列中后面的是否**全是空结点**；若后面还有非空结点，就不是完全二叉树。
```c
bool IsComplete(BiTree T) {
    if (T == NULL) return true;
    SqQueue Q; InitQueue(Q);
    BiTNode *p;
    EnQueue(Q, T);
    while (!QueueEmpty(Q)) {
        DeQueue(Q, p);
        if (p != NULL) {
            EnQueue(Q, p->lchild);              // 空孩子也入队
            EnQueue(Q, p->rchild);
        } else {
            while (!QueueEmpty(Q)) {            // 遇到空结点，检查后面
                DeQueue(Q, p);
                if (p != NULL) return false;     // 空结点之后还有非空结点
            }
        }
    }
    return true;
}
```

### 题 10：判断两棵二叉树是否相似/相等、求宽度等
思路都一样：**根的情况 + 递归左右子树**。宽度用层序遍历，记录每层结点数取最大。

## ⚠️ 易错点
1. 三种遍历中，**叶子的相对顺序完全相同**（都是从左到右）
2. 还原二叉树必须有**中序**
3. 后序的**最后一个**是根
4. 非递归后序要判断“右子树是否访问过”
5. 层序遍历用**队列**，其余用**栈**（或递归）
6. WPL 中路径长度是**边数**，根的深度为 0

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 先中后序 | 根左右 / 左根右 / 左右根；代码只差 visit 位置 |
| 复杂度 | 时间 O(n)，空间 O(h) |
| 非递归中序 | 一路向左压栈，弹出访问，转向右 |
| 非递归后序 | 用 r 记录最近访问；栈中是当前结点的所有祖先 |
| 层序 | 队列：出一个，入其左右孩子 |
| 还原 | 必须有中序；先/后/层序确定根 |
| 先序 = 中序 | 无左孩子 |
| 先序、后序相反 | 每个结点只有一个孩子 |
| 递归算法模板 | 空树出口 + 组合左右子树结果 |

4. 若一棵二叉树的先序和后序序列正好相反，这棵树有什么特点？
5. 写递归算法：求二叉树中值为 x 的结点所在的层号（不存在返回 0）。

1. 先序：1 2 4 7 3 5 6 8；中序：4 7 2 1 5 3 8 6；后序：7 4 2 5 8 6 3 1；层序：1 2 3 4 5 6 7 8
2. 根 E；左子树中序 A B C D，先序 B A D C → 根 B，左 A，右子树（中序 C D，先序 D C）根 D 左 C；右子树中序 F G H I J K，先序 F H G I K J → 根 F，无左，右子树（中序 G H I J K，先序 H G I K J）根 H，左 G，右子树（中序 I J K，先序 I K J）根 I，右子树（中序 J K，先序 K J）根 K，左 J。
   后序：**A C D B G J K I H F E**
3. 根 C；中序 C 左边 D E B A 是左子树，右边空。左子树后序 D A B E → 根 E，中序 D | E | B A → 左 D，右子树（中序 B A，后序 A B）根 B，右孩子 A。先序：**C E D B A**
4. 每个结点**只有一个孩子**（没有度为 2 的结点），树的高度等于结点数
5. ```c
   int Level(BiTree T, ElemType x, int depth) {   // 调用：Level(T, x, 1)
       if (T == NULL) return 0;
       if (T->data == x) return depth;
       int l = Level(T->lchild, x, depth + 1);
       if (l != 0) return l;
       return Level(T->rchild, x, depth + 1);
   }
