# 数据结构 第 11 课 · 二叉树的概念、性质与存储结构

> 🎯 **本课目标**
> 1. 理解二叉树的定义和 5 种基本形态，分清二叉树和度为 2 的树
> 2. 掌握满二叉树、完全二叉树的定义和**编号性质**
> 3. **掌握二叉树的 5 条性质**（尤其 n₀ = n₂ + 1 和完全二叉树的计算），会做各类计数题
> 4. 掌握顺序存储和链式存储，知道二叉链表中空指针的个数
>
> 二叉树的性质题几乎每年都有（2009、2011、2020 年第 3 题、2025 年第 3、4 题……）。

---

## 🚪 课前引入

普通的树，一个结点可能有 100 个孩子，存储和操作都很麻烦。
如果**规定每个结点最多只有两个孩子**，并且分清“左孩子”和“右孩子”，问题就简单多了。这就是二叉树。
而且后面会学到：**任何一棵树都能转换成二叉树**！所以学好二叉树就等于学好了所有的树。

## 一、二叉树的定义

### 📐 递归定义
二叉树是 n（n ≥ 0）个结点的有限集合：
1. 或者为**空二叉树**（n = 0）
2. 或者由一个**根结点**和两个**互不相交**的、分别称为**左子树**和**右子树**的二叉树组成

### 📐 特点
- 每个结点**至多有两棵子树**（不存在度大于 2 的结点）
- 子树**有左右之分，次序不能颠倒**（二叉树是**有序树**）
- 即使只有一棵子树，也要区分是左子树还是右子树

### 📐 五种基本形态
```
① 空树      ② 只有根     ③ 只有左子树   ④ 只有右子树   ⑤ 左右子树都有
   ∅           ○              ○              ○              ○
                             /                \            /   \
                            ○                  ○          ○     ○
```
③ 和 ④ 是**两棵不同的二叉树**！但如果看作普通的树，它们是同一棵。

### 📐 二叉树 vs 度为 2 的有序树（⭐ 选择题）
| | 二叉树 | 度为 2 的有序树 |
|---|---|---|
| 能否为空 | 能 | 不能（至少 3 个结点） |
| 只有一个孩子时 | **区分左右** | 不区分（无所谓左右，只是“第一个孩子”） |
| 是否必须有度为 2 的结点 | 不必 | 必须至少一个 |

### 📐 n 个结点能构成多少种不同的二叉树？
**卡特兰数**：$\frac{1}{n+1}C_{2n}^{n}$。n = 3 时 5 种，n = 4 时 14 种。（和栈的出栈序列个数一样！因为“先序序列固定时，二叉树形态”与“入栈序列固定时，出栈序列”一一对应。）

## 二、几种特殊的二叉树（⭐⭐）

### 2.1 满二叉树
**定义**：高度为 h，且含有 **2ʰ − 1** 个结点的二叉树（每层都塞满了）。
```
            1
        /       \
       2         3
     /   \     /   \
    4     5   6     7
```
特点：
- 叶子**只在最下面一层**
- 除叶子外，每个结点的度**都是 2**
- 按层序编号（从 1 开始）：结点 i 的双亲是 ⌊i/2⌋，左孩子 2i，右孩子 2i + 1

### 2.2 完全二叉树（⭐⭐⭐）
**定义**：高度为 h、有 n 个结点的二叉树，当且仅当它的**每个结点都与高度为 h 的满二叉树中编号 1 ~ n 的结点一一对应**时，称为完全二叉树。

🧒 **大白话**：按“**从上到下、从左到右**”的顺序一个挨一个地放结点，**中间不能有空位**，最后一层可以不满，但只能缺右边的。
```
是完全二叉树：          不是完全二叉树：        不是完全二叉树：
        1                     1                      1
      /   \                 /   \                  /   \
     2     3               2     3                2     3
    / \   /               / \     \                    / \
   4   5 6               4   5     7    ← 6空了        6   7   ← 4、5空了
```

**完全二叉树的性质（⭐⭐⭐ 必背）**，n 个结点，按层序从 1 编号：
1. 叶子只可能出现在**最下面两层**
2. 最下面一层的叶子都集中在**最左边**
3. **度为 1 的结点最多只有 1 个**，而且它只有**左孩子**
   - n 为**偶数**时，有 1 个度为 1 的结点（编号 n/2）
   - n 为**奇数**时，没有度为 1 的结点
4. 若某结点是叶子或只有左孩子，则编号比它大的结点**都是叶子**
5. **i ≤ ⌊n/2⌋ 的结点是分支结点，i > ⌊n/2⌋ 的结点是叶子**
6. **叶子数 = n − ⌊n/2⌋ = ⌈n/2⌉**
7. 编号关系：
   - 结点 i 的**双亲**：⌊i/2⌋（i > 1）
   - 结点 i 的**左孩子**：2i（若 2i ≤ n，否则无左孩子）
   - 结点 i 的**右孩子**：2i + 1（若 2i + 1 ≤ n，否则无右孩子）
   - 结点 i 所在的**层次**：⌊log₂i⌋ + 1
8. 高度：**⌊log₂n⌋ + 1** 或 **⌈log₂(n + 1)⌉**

> ⚠️ 若编号从 **0** 开始（数组下标）：双亲 ⌊(i−1)/2⌋，左孩子 2i + 1，右孩子 2i + 2。（2022 年第 41 题就是这种）

### 2.3 二叉排序树（BST）与平衡二叉树（AVL）
- **二叉排序树**：左子树上所有结点 < 根 < 右子树上所有结点（第 23 课详讲）
- **平衡二叉树**：任一结点左右子树的高度差不超过 1（第 23 课详讲）

## 三、二叉树的性质（⭐⭐⭐）

### 性质 1：非空二叉树的叶子数 = 度为 2 的结点数 + 1，即 **n₀ = n₂ + 1**

**推导**：
- 按度数分：n = n₀ + n₁ + n₂
- 按边数分：n = 1 + n₁ + 2n₂（每个度为 1 的结点贡献 1 条边，度为 2 的贡献 2 条）
- 两式相减：n₀ = n₂ + 1 ✓

🧒 这条性质超级常用，它说明：**叶子数只和度为 2 的结点数有关，和度为 1 的结点数无关！**

### 性质 2：第 i 层至多有 2ⁱ⁻¹ 个结点（i ≥ 1）

### 性质 3：高度为 h 的二叉树至多有 2ʰ − 1 个结点（h ≥ 1）

### 性质 4：n 个结点的完全二叉树的高度为 ⌊log₂n⌋ + 1 = ⌈log₂(n+1)⌉
**推导**：高度为 h 的完全二叉树，结点数在 [2ʰ⁻¹, 2ʰ − 1] 之间（前 h−1 层满 + 最后一层至少 1 个）：
2ʰ⁻¹ ≤ n < 2ʰ → h − 1 ≤ log₂n < h → h = ⌊log₂n⌋ + 1

**例**：n = 1000 → log₂1000 ≈ 9.97 → h = 10；n = 1024 → h = 11。

## 四、计数题大全（⭐⭐⭐）

### 类型 1：已知部分结点数，求叶子数
**例**：二叉树有 20 个叶子，10 个度为 1 的结点，总结点数？
→ n₂ = n₀ − 1 = 19，n = 20 + 10 + 19 = **49**

### 类型 2：完全二叉树已知总结点数 n，求叶子数/各度结点数
**方法**：n 偶数 → n₁ = 1；n 奇数 → n₁ = 0。再用 n₀ = n₂ + 1。

📝 **真题（2011 年第 4 题）**：若一棵完全二叉树有 **768** 个结点，则该二叉树中叶结点的个数是？
- 768 是偶数 → n₁ = 1
- n₀ + n₂ = 767，n₀ = n₂ + 1 → 2n₂ + 1 = 767 → n₂ = 383，**n₀ = 384**
- 更快：叶子数 = ⌈768/2⌉ = **384**

### 类型 3：完全二叉树第 k 层有 x 个叶子，求结点数的最大/最小值

📝 **真题（2009 年第 6 题）**：已知一棵完全二叉树的**第 6 层**（设根为第 1 层）有 **8 个叶结点**，则该完全二叉树的结点个数**最多**是？
🧒 思路：第 6 层有叶子，说明这棵树高度是 6 或 7。
- **结点最多** → 高度为 7：第 6 层满的话有 2⁵ = 32 个结点，其中 8 个是叶子，剩下 **24 个都有两个孩子**
  - 前 6 层：2⁶ − 1 = 63 个
  - 第 7 层：24 × 2 = 48 个
  - 总共 63 + 48 = **111**
- （若问**最少**：高度为 6，第 6 层只有 8 个结点：前 5 层 31 + 8 = **39**）

### 类型 4：已知叶子数，完全二叉树结点数的范围
**例**：完全二叉树有 124 个叶子，最多多少个结点？
- n₀ = 124 → n₂ = 123，n₁ 为 0 或 1
- 最多：n = 124 + 1 + 123 = **248**；最少 247

### 类型 5：一般二叉树的最大、最小高度
- n 个结点的二叉树：**最小高度 ⌈log₂(n+1)⌉**（完全二叉树），**最大高度 n**（单支树，每层一个）

## 五、二叉树的存储结构

### 5.1 顺序存储（⭐）
**方法**：用一组地址连续的存储单元，**按完全二叉树的编号**，把编号为 i 的结点存在数组第 i 个位置（或下标 i−1）。
```
完全二叉树：                 数组（下标从 1）：
        A                    [ _ | A | B | C | D | E | F ]
      /   \                     0   1   2   3   4   5   6
     B     C
    / \   /
   D   E F
```
- **完全二叉树和满二叉树**用顺序存储最合适：既节省空间，又能用编号直接找双亲孩子
- **一般二叉树**：要补上“空结点”凑成完全二叉树的形状，**可能浪费大量空间**
  - 最坏情况：高度为 h、只有 h 个结点的**右单支树**，也需要 2ʰ − 1 个存储单元

```
右单支树（3 个结点）：          顺序存储（下标从 1）：
  A                           [ _ | A | ∅ | B | ∅ | ∅ | ∅ | C ]
   \                              1   2   3   4   5   6   7
    B
     \
      C
```

📝 **真题（2020 年第 3 题）**：对于**任意一棵**高度为 5 且有 10 个结点的二叉树，若采用顺序存储结构保存，每个结点占 1 个存储单元（仅存放结点的数据信息），则存放该二叉树需要的存储单元数量**至少**是？
- “**任意一棵**”：要保证所有可能的形态都能存下
- 高度为 5，某个结点可能在第 5 层的**最右边**，编号为 2⁵ − 1 = **31**
- 所以至少需要 **31** 个存储单元，选 A
🧒 注意“至少”是对“**能存下任意一棵**”而言的，所以要按最坏形态算。

📝 **真题（2025 年第 3 题）** 的考法：用数组（−1 表示结点不存在）顺序存储二叉树，判断哪个数组**不能表示**一棵二叉树。
**判断方法**：若某个位置有结点（不是 −1），但它的**双亲位置是 −1**，就不合法（一个结点不可能没有双亲而悬空）。例如下标从 1 开始时，第 8 个位置有结点，但第 4 个位置是 −1，就不合法。

### 5.2 链式存储（⭐⭐⭐）
**二叉链表**：每个结点包含数据域和左、右两个指针域。
```
┌────────┬──────┬────────┐
│ lchild │ data │ rchild │
└────────┴──────┴────────┘
```
```c
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;   // 左、右孩子指针
} BiTNode, *BiTree;
```
**重要性质**：n 个结点的二叉链表中，共有 2n 个指针域，其中**非空指针 n − 1 个**（每个非根结点被一个指针指向），**空指针 n + 1 个**。
🧒 这 n + 1 个空指针被浪费了，下一课的“**线索二叉树**”就是利用它们来存前驱后继信息。

**三叉链表**：再加一个指向双亲的指针 parent，方便找双亲。

## ⚠️ 易错点
1. 二叉树**区分左右**，可以为空
2. 完全二叉树中度为 1 的结点**最多 1 个**，且只有左孩子
3. n₀ = n₂ + 1 **与 n₁ 无关**
4. 顺序存储时编号从 1 还是 0 开始，公式不同
5. “任意二叉树”顺序存储要按最坏情况（右下角）考虑
6. 二叉链表空指针数 n + 1

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 核心性质 | n₀ = n₂ + 1 |
| 第 i 层最多 | 2ⁱ⁻¹ |
| 高度 h 最多 | 2ʰ − 1 |
| 完全二叉树高度 | ⌊log₂n⌋ + 1 = ⌈log₂(n+1)⌉ |
| 完全二叉树编号（从 1） | 双亲 ⌊i/2⌋，左 2i，右 2i+1 |
| 完全二叉树叶子数 | ⌈n/2⌉；n 偶则 n₁=1，n 奇则 n₁=0 |
| 分支/叶子分界 | i ≤ ⌊n/2⌋ 为分支结点 |
| 顺序存储 | 适合完全二叉树；一般树最坏需 2ʰ−1 |
| 二叉链表 | 空指针 n+1 个 |
| 不同形态数 | 卡特兰数 |

## 🏋️ 课后练习

1. 一棵二叉树有 50 个度为 2 的结点、30 个度为 1 的结点，叶子有多少？总结点数？
2. 完全二叉树有 1001 个结点，叶子有多少？度为 1 的结点有多少？高度是多少？
3. 完全二叉树中编号为 37 的结点（从 1 开始编号），其双亲、左孩子、右孩子的编号（假设 n 足够大）？它在第几层？
4. 一棵完全二叉树第 5 层有 6 个叶子，结点数最多、最少各是多少？
5. 含有 100 个结点的二叉链表中，有多少个空指针域？
6. 高度为 4 的二叉树，最少、最多有多少个结点？
7. 3 个结点能构成多少种不同形态的二叉树？画出来。

<details>
<summary>📖 答案</summary>

1. n₀ = 51；n = 51 + 30 + 50 = **131**
2. 1001 是奇数 → n₁ = **0**；n₀ = ⌈1001/2⌉ = **501**，n₂ = 500；高度 ⌊log₂1001⌋ + 1 = 9 + 1 = **10**
3. 双亲 18，左孩子 74，右孩子 75；层次 ⌊log₂37⌋ + 1 = 5 + 1 = **6**
4. 最多（高度 6）：第 5 层满 16 个，6 个叶子，10 个各有 2 个孩子 → 前 5 层 31 + 20 = **51**；最少（高度 5）：前 4 层 15 + 6 = **21**
5. **101**
6. 最少 **4**（单支），最多 **15**
7. **5 种**：左左链、左右折线、满（根带左右）、右左折线、右右链
