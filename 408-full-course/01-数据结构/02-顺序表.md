## 🚪 课前引入：电影院的一排座位

一排电影院座位，观众按票号**一个挨一个**坐好：1 号坐第 1 个座位，2 号坐第 2 个……
- 想找 5 号观众？直接去第 5 个座位，**一步到位**。
- 现在要在 3 号和 4 号之间**插进**一个人？那 4 号及后面所有人都得**往后挪一个座位**。
- 3 号走了？后面所有人都得**往前挪一个**，不能留空位。

这就是**顺序表**：找人快，插人删人慢。

## 一、线性表的定义

### 📐 定义
**线性表**是具有**相同数据类型**的 n（n ≥ 0）个数据元素的**有限序列**。
$$L = (a_1, a_2, \ldots, a_i, a_{i+1}, \ldots, a_n)$$
- n 是**表长**，n = 0 时是**空表**
- a₁ 叫**表头元素**，aₙ 叫**表尾元素**
- 除表头外，每个元素**有且仅有一个直接前驱**；除表尾外，每个元素**有且仅有一个直接后继**

**特点**：
- 元素个数**有限**
- 元素有**先后次序**（逻辑上的顺序性）
- 每个元素都是**单个**数据元素，**类型相同**（占用相同大小的空间）
- 线性表是**逻辑结构**，顺序表和链表是它的两种**存储结构**

⚠️ **位序从 1 开始**，而 C 语言数组下标从 0 开始。第 i 个元素存在 `data[i-1]` 里。这是写代码时最容易错的地方！

### 📐 基本操作（ADT）
| 操作 | 功能 |
|---|---|
| InitList(&L) | 初始化，构造空表 |
| Length(L) | 求表长 |
| LocateElem(L, e) | **按值查找**：返回值为 e 的元素位序 |
| GetElem(L, i) | **按位查找**：返回第 i 个元素 |
| ListInsert(&L, i, e) | 在第 i 个位置**插入** e |
| ListDelete(&L, i, &e) | **删除**第 i 个元素，用 e 带回它的值 |
| PrintList(L)、Empty(L)、DestroyList(&L) | 输出、判空、销毁 |

（参数带 `&` 表示这个参数会被修改，这是 C++ 引用。）

## 二、顺序表的定义

### 📐 定义
用一组**地址连续**的存储单元依次存放线性表的元素。**逻辑上相邻的元素，物理位置也相邻。**

**地址公式**：若第 1 个元素地址为 LOC(A)，每个元素占 sizeof(ElemType) 字节：
$$\text{LOC}(a_i) = \text{LOC}(A) + (i - 1) \times \text{sizeof(ElemType)}$$

### 📐 静态分配
```c
#define MaxSize 50            // 最大长度
typedef struct {
    ElemType data[MaxSize];   // 用静态数组存放元素
    int length;               // 当前长度
} SqList;
```
缺点：数组大小一开始就固定，满了就没办法了。

### 📐 动态分配
```c
#define InitSize 100
typedef struct {
    ElemType *data;           // 指向动态分配的数组
    int MaxSize, length;
} SeqList;

// 初始化
L.data = (ElemType *)malloc(sizeof(ElemType) * InitSize);
// 空间不够时：申请一块更大的新空间，把旧数据全部复制过去，再释放旧空间
```
⚠️ 动态分配**仍然是顺序存储**，仍然支持随机存取，只是大小可以在运行时决定。

### 📐 顺序表的特点（⭐ 选择题）
1. **随机访问**：通过首地址和位序，O(1) 找到第 i 个元素（最大的优点）
2. **存储密度高**：每个结点只存数据，没有指针
3. 逻辑相邻的元素物理也相邻 → **插入、删除要移动大量元素**
4. 需要**连续**的存储空间，拓展容量不方便

## 三、顺序表的基本操作（⭐⭐⭐ 必须能默写）

### 3.1 插入：在第 i 个位置插入 e

🧒 **想法**：把第 i 个到第 n 个元素**全部往后挪一格**，空出第 i 个位置，放入 e。
⚠️ **必须从最后一个元素开始往后挪**！如果从前往后挪，前面的会覆盖后面的。

```
插入前（在第 3 个位置插入 X）：
位序:   1    2    3    4    5
       [a1] [a2] [a3] [a4] [a5] [  ]
第 1 步：a5 后移   [a1] [a2] [a3] [a4] [  ] [a5]
第 2 步：a4 后移   [a1] [a2] [a3] [  ] [a4] [a5]
第 3 步：a3 后移   [a1] [a2] [  ] [a3] [a4] [a5]
第 4 步：放入 X    [a1] [a2] [X ] [a3] [a4] [a5]
```

```c
bool ListInsert(SqList &L, int i, ElemType e) {
    if (i < 1 || i > L.length + 1)     // 合法位置是 1 ~ length+1
        return false;
    if (L.length >= MaxSize)           // 表满了
        return false;
    for (int j = L.length; j >= i; j--)   // 从最后一个元素开始，依次后移
        L.data[j] = L.data[j - 1];        // 第 j 个元素（下标 j-1）移到下标 j
    L.data[i - 1] = e;                 // 第 i 个位置的下标是 i-1
    L.length++;
    return true;
}
```
**逐行解读**：
- `i` 的合法范围是 `[1, length+1]`：可以插在最前面（i = 1），也可以插在最后面（i = length + 1，即表尾之后）
- 循环中 `j` 是**下标**：把下标 j−1 的元素搬到下标 j
- 最后一步 `length++` 别忘了

### 📐 插入的时间复杂度（⭐ 推导）
- **最好**：插在表尾（i = n+1），不用移动 → O(1)
- **最坏**：插在表头（i = 1），移动 n 个 → O(n)
- **平均**：设在每个位置插入的概率相等，pᵢ = 1/(n+1)。在第 i 个位置插入需要移动 n − i + 1 个元素：
$$\sum_{i=1}^{n+1} \frac{1}{n+1}(n - i + 1) = \frac{1}{n+1} \cdot \frac{n(n+1)}{2} = \frac{n}{2}$$
所以**平均移动 n/2 个元素**，时间复杂度 **O(n)**。

### 3.2 删除：删除第 i 个元素，用 e 返回

🧒 **想法**：先把第 i 个元素的值保存下来，然后把第 i+1 到第 n 个元素**依次往前挪一格**。
⚠️ 这次要**从前往后**挪（先挪第 i+1 个）。

```c
bool ListDelete(SqList &L, int i, ElemType &e) {
    if (i < 1 || i > L.length)         // 合法位置 1 ~ length
        return false;
    e = L.data[i - 1];                 // 保存被删元素
    for (int j = i; j < L.length; j++) // 从第 i+1 个元素（下标 i）开始前移
        L.data[j - 1] = L.data[j];
    L.length--;
    return true;
}
```
**平均移动次数**：删除第 i 个要移动 n − i 个，pᵢ = 1/n：
$$\sum_{i=1}^{n} \frac{1}{n}(n - i) = \frac{1}{n} \cdot \frac{n(n-1)}{2} = \frac{n-1}{2}$$
时间复杂度 **O(n)**。

### 3.3 按值查找
```c
int LocateElem(SqList L, ElemType e) {
    for (int i = 0; i < L.length; i++)
        if (L.data[i] == e)
            return i + 1;              // 返回位序（下标 + 1）
    return 0;                          // 没找到
}
```
- 最好 O(1)，最坏 O(n)，平均比较 (n+1)/2 次 → **O(n)**

### 3.4 按位查找
```c
ElemType GetElem(SqList L, int i) {
    return L.data[i - 1];              // O(1)，这就是“随机存取”
}
```

### 📊 顺序表操作复杂度总结
| 操作 | 时间 | 平均移动/比较次数 |
|---|---|---|
| 按位查找 | **O(1)** | — |
| 按值查找 | O(n) | 比较 (n+1)/2 |
| 插入 | O(n) | 移动 **n/2** |
| 删除 | O(n) | 移动 **(n−1)/2** |

## 四、顺序表经典算法题（⭐⭐⭐ 41 题高频）

> 下面每道题都按考试的标准格式来讲：**设计思想 → 代码 → 复杂度**。强烈建议你**先自己想 10 分钟**，再看答案。

### 题 1：删除顺序表中所有值为 x 的元素（要求 O(n) 时间、O(1) 空间）

**错误思路**：每找到一个 x 就调用一次删除（每次移动 O(n)）→ 总共 O(n²)。

**正确思路（“留下来的元素往前放”）**：
用 k 记录“**到目前为止，不等于 x 的元素有几个**”。扫描时，遇到不等于 x 的元素，就把它放到下标 k 的位置，然后 k++。扫描结束，表长设为 k。

🧒 就像排队时把“不需要的人”踢掉：从前往后走，留下来的人依次往前补位。

```c
void DeleteX(SqList &L, ElemType x) {
    int k = 0;                              // 保留下来的元素个数
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] != x) {
            L.data[k] = L.data[i];          // 放到第 k 个位置
            k++;
        }
    }
    L.length = k;
}
```
**过程演示**：L = [3, 5, 3, 7, 3, 9]，x = 3
| i | data[i] | 操作 | 表前 k 个元素 | k |
|---|---|---|---|---|
| 0 | 3 | 跳过 | [] | 0 |
| 1 | 5 | data[0] = 5 | [5] | 1 |
| 2 | 3 | 跳过 | [5] | 1 |
| 3 | 7 | data[1] = 7 | [5, 7] | 2 |
| 4 | 3 | 跳过 | [5, 7] | 2 |
| 5 | 9 | data[2] = 9 | [5, 7, 9] | 3 |
结果 length = 3：[5, 7, 9] ✓

时间 O(n)，空间 O(1)。
**变形**：删除值在 [s, t] 之间的所有元素——把判断条件改成 `if (L.data[i] < s || L.data[i] > t)` 即可。

### 题 2：逆置顺序表（O(1) 空间）
**思路**：第一个和最后一个交换，第二个和倒数第二个交换……交换到中间为止。
```c
void Reverse(ElemType A[], int left, int right) {   // 逆置 A[left..right]
    while (left < right) {
        ElemType t = A[left];
        A[left] = A[right];
        A[right] = t;
        left++; right--;
    }
}
```
交换次数 ⌊n/2⌋，时间 O(n)，空间 O(1)。

### 题 3：合并两个有序顺序表（⭐ 归并思想的基础）
**问题**：A、B 都是递增有序的，合并成一个新的递增有序表 C。
**思路**：两个指针 i、j 分别指向 A、B 的开头，**每次比较两者，把小的放进 C**，对应指针后移；某一个表用完后，把另一个表剩下的全部接到 C 后面。

🧒 两队小朋友都按身高排好了，要合成一队：每次看两队排头，**矮的先出列**。

```c
bool Merge(SqList A, SqList B, SqList &C) {
    if (A.length + B.length > MaxSize) return false;
    int i = 0, j = 0, k = 0;
    while (i < A.length && j < B.length) {
        if (A.data[i] <= B.data[j])
            C.data[k++] = A.data[i++];     // 先赋值再加 1
        else
            C.data[k++] = B.data[j++];
    }
    while (i < A.length) C.data[k++] = A.data[i++];   // A 剩下的
    while (j < B.length) C.data[k++] = B.data[j++];   // B 剩下的
    C.length = k;
    return true;
}
```
时间 O(m + n)，空间 O(m + n)（新表 C）。

### 题 4：有序表去重
**问题**：从**有序**顺序表中删除所有值重复的元素，使表中元素各不相同。
**思路**：有序 → 相同的元素一定**挨在一起**。用 k 指向“去重后表的最后一个元素”，扫描到与 data[k] 不同的元素就放到 k+1 位置。
```c
void DeleteSame(SqList &L) {
    if (L.length == 0) return;
    int k = 0;                               // data[0..k] 是去重后的结果
    for (int i = 1; i < L.length; i++)
        if (L.data[i] != L.data[k])
            L.data[++k] = L.data[i];         // 先 k+1，再放入
    L.length = k + 1;
}
```
[1, 2, 2, 2, 3, 3, 5] → [1, 2, 3, 5]。时间 O(n)，空间 O(1)。

### 题 5：循环左移 p 位（⭐ 2010 年第 42 题原题）
**问题**：把数组 R 中的 n 个数**循环左移 p 位**（0 < p < n），即 (X₀, X₁, …, Xₙ₋₁) 变成 (Xₚ, Xₚ₊₁, …, Xₙ₋₁, X₀, X₁, …, Xₚ₋₁)。要求时间和空间都尽可能高效。

**思路（三次逆置法，非常巧妙）**：
设前 p 个元素为 a，后 n−p 个为 b，原数组是 **ab**，目标是 **ba**。
- 先把 a 逆置得到 a⁻¹b
- 再把 b 逆置得到 a⁻¹b⁻¹
- 最后把整个数组逆置：(a⁻¹b⁻¹)⁻¹ = **ba** ✓

**例**：abcdefgh，p = 3
```
原数组：   a b c | d e f g h
逆置前 3： c b a | d e f g h
逆置后 5： c b a | h g f e d
整体逆置： d e f g h a b c    ✓
```
```c
void Converse(int R[], int n, int p) {
    Reverse(R, 0, p - 1);      // 逆置前 p 个
    Reverse(R, p, n - 1);      // 逆置后 n-p 个
    Reverse(R, 0, n - 1);      // 整体逆置
}
```
时间 O(n)（三次逆置分别交换 p/2、(n−p)/2、n/2 次），空间 O(1)。

> 另一种方法：借助一个长度为 p 的辅助数组，先把前 p 个存起来，其余前移，再放回。时间 O(n)，空间 O(p)。也能拿到大部分分数。

### 题 6：两个等长升序序列的中位数（⭐ 2011 年第 42 题原题）
**问题**：长度为 L 的升序序列，第 ⌈L/2⌉ 个位置的数称为中位数。两个等长（都是 L）升序序列 A、B，求合并后（长 2L）的中位数，即第 L 小的数。例如 A = (11, 13, 15, 17, 19)，B = (2, 4, 6, 8, 20)，中位数是 11。

**方法一（O(n)，容易想到，推荐考场使用）**：模仿归并，只数到第 L 个。
```c
int FindMedian(int A[], int B[], int L) {
    int i = 0, j = 0, cur;
    for (int k = 1; k <= L; k++) {          // 取出前 L 小的数，最后一个就是中位数
        if (A[i] <= B[j]) cur = A[i++];
        else cur = B[j++];
    }
    return cur;
}
```
时间 O(L)，空间 O(1)。（为什么 i、j 不会越界？一共只取 L 个数，某个数组的下标要走到 L，就必须从它身上取满 L 个，那时循环恰好结束，不会再访问 A[L] 或 B[L]。）

**方法二（O(log n)，最优解，了解思想）**：分别求 A、B 的中位数 a、b：
- a = b：a 就是答案
- a < b：舍弃 A 中较小的一半和 B 中较大的一半（两边舍弃的个数要相等）
- a > b：舍弃 A 中较大的一半和 B 中较小的一半
- 重复直到两个序列都只剩一个元素，较小者为答案
每次规模减半，O(log n)。

> 💡 **考场策略**：想不到最优解就写方法一，方法一的思路 + 代码正确一般能拿到 13 分中的 10~11 分。

### 题 7：找主元素（⭐ 2013 年第 41 题原题）
**问题**：整数序列 A 中，若某个元素出现次数**大于 n/2**，称为主元素。找出主元素，没有则返回 −1。
例：A = (0, 5, 5, 3, 5, 7, 5, 5) 主元素是 5；A = (0, 5, 5, 3, 5, 1, 5, 7) 没有主元素。

**方法一（计数数组，O(n) 时间 O(n) 空间）**：题目限定元素值在 0 ~ n−1，开一个计数数组 count[n]，统计每个值出现次数，找出次数 > n/2 的。

**方法二（摩尔投票法，O(n) 时间 O(1) 空间，最优）**：
🧒 **打擂台**：主元素比其他所有元素加起来还多。让不同的元素**两两“同归于尽”**，最后剩下的一定是主元素（如果存在的话）。
1. 选第一个数为候选 c，计数 count = 1
2. 往后扫：遇到和 c 相同的，count++；不同的，count−−；count 减到 0 时，把下一个数设为新候选，count = 1
3. 扫完后，c 是**可能的**主元素；再扫一遍统计 c 的真实出现次数，确认是否 > n/2

```c
int Majority(int A[], int n) {
    int c = A[0], count = 1;
    for (int i = 1; i < n; i++) {
        if (A[i] == c) count++;
        else if (count > 0) count--;
        else { c = A[i]; count = 1; }      // 换新候选
    }
    count = 0;                              // 第二遍：验证
    for (int i = 0; i < n; i++)
        if (A[i] == c) count++;
    return count > n / 2 ? c : -1;
}
```
**演示** A = (0, 5, 5, 3, 5, 7, 5, 5)：
| i | A[i] | c | count |
|---|---|---|---|
| 0 | 0 | 0 | 1 |
| 1 | 5 | 0 | 0 |
| 2 | 5 | 5 | 1（count 为 0，换候选） |
| 3 | 3 | 5 | 0 |
| 4 | 5 | 5 | 1（与候选相同，count + 1） |
| 5 | 7 | 5 | 0 |
| 6 | 5 | 5 | 1 |
| 7 | 5 | 5 | 2 |
候选 5，验证出现 5 次 > 4 ✓

### 题 8：未出现的最小正整数（⭐ 2018 年第 41 题原题）
**问题**：n 个整数的数组，找出**未出现的最小正整数**。例：{−5, 3, 2, 3} → 1；{1, 2, 3} → 4。要求时间尽可能高效。

**思路（空间换时间）**：答案一定在 1 ~ n+1 之间（n 个数最多占满 1~n）。开一个标记数组 B[n]（初始全 0），对每个 A[i]，若 1 ≤ A[i] ≤ n，就令 B[A[i]−1] = 1。最后从头找第一个 B[i] == 0 的，答案是 i+1；全都是 1 则答案 n+1。
```c
int FindMissMin(int A[], int n) {
    int *B = (int *)malloc(sizeof(int) * n);
    memset(B, 0, sizeof(int) * n);           // 全部置 0
    for (int i = 0; i < n; i++)
        if (A[i] > 0 && A[i] <= n)
            B[A[i] - 1] = 1;                 // 标记 A[i] 出现过
    int i;
    for (i = 0; i < n; i++)
        if (B[i] == 0) break;                // 第一个没出现的
    free(B);
    return i + 1;
}
```
时间 O(n)，空间 O(n)。

## 📌 补充真题

📝 **补充真题（2023 年第 1 题）**：下列对顺序存储的有序表（长度为 n）实现给定操作的算法中，平均时间复杂度为 O(1) 的是：A. 查找包含指定值元素的算法　B. 插入包含指定值元素的算法　C. 删除第 i（1 ≤ i ≤ n）个元素的算法　D. 获取第 i（1 ≤ i ≤ n）个元素的算法
→ **D**（顺序表**随机存取**，按位置取元素 O(1)；A 顺序查找 O(n)（折半也要 O(log n)）；B、C 要移动元素，O(n)）

## ⚠️ 易错点
1. **位序从 1 开始，下标从 0 开始**：第 i 个元素是 `data[i-1]`
2. 插入合法位置 1 ~ n+1，删除合法位置 1 ~ n
3. 插入**从后往前**移，删除**从前往后**移
4. 插入平均移动 n/2，删除平均移动 (n−1)/2
5. 动态分配的顺序表**仍然是随机存取**
6. 别忘了修改 length

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 线性表 | 相同类型、有限、有序；逻辑结构 |
| 顺序表 | 连续存储；LOC(aᵢ) = LOC(a₁) + (i−1)×size |
| 特点 | 随机存取 O(1)；存储密度高；插删要移动 |
| 插入 | 从后往前移；平均 n/2；O(n) |
| 删除 | 从前往后移；平均 (n−1)/2；O(n) |
| 删除所有 x | k 计数，留下的往前放，O(n)/O(1) |
| 合并有序表 | 双指针，小的先出，O(m+n) |
| 循环左移 | 三次逆置，O(n)/O(1) |
| 主元素 | 摩尔投票 + 验证，O(n)/O(1) |
| 最小未出现正整数 | 标记数组，O(n)/O(n) |

## 🏋️ 课后练习

1. 顺序表有 100 个元素，在第 30 个位置插入一个元素需要移动几个元素？删除第 30 个元素呢？
2. 写一个算法：从顺序表中删除**最小值**元素（假设唯一），空出的位置由最后一个元素填补，返回被删元素的值。
3. 写一个算法：把顺序表中所有**负数移到正数前面**，要求 O(n) 时间、O(1) 空间。
4. 用三次逆置法把 [1, 2, 3, 4, 5, 6, 7] 循环左移 2 位，写出每一步的结果。
5. 用摩尔投票法分析 A = (2, 2, 1, 1, 1, 2, 2)，候选是什么？是主元素吗？

<details>
<summary>📖 答案</summary>

1. 插入：移动 100 − 30 + 1 = **71** 个；删除：移动 100 − 30 = **70** 个
2. ```c
   bool DelMin(SqList &L, ElemType &value) {
       if (L.length == 0) return false;
       int pos = 0;
       for (int i = 1; i < L.length; i++)
           if (L.data[i] < L.data[pos]) pos = i;
       value = L.data[pos];
       L.data[pos] = L.data[L.length - 1];   // 最后一个元素填补
       L.length--;
       return true;
   }
   ```
3. 双指针：i 从左找正数，j 从右找负数，交换（类似快排划分）
   ```c
   void Move(int A[], int n) {
       int i = 0, j = n - 1;
       while (i < j) {
           while (i < j && A[i] < 0) i++;     // 左边跳过负数
           while (i < j && A[j] >= 0) j--;    // 右边跳过非负数
           if (i < j) { int t = A[i]; A[i] = A[j]; A[j] = t; }
       }
   }
   ```
4. 逆置前 2 个：[2, 1, 3, 4, 5, 6, 7]；逆置后 5 个：[2, 1, 7, 6, 5, 4, 3]；整体逆置：**[3, 4, 5, 6, 7, 1, 2]**
5. 过程：c=2,cnt=1 → 2:cnt=2 → 1:cnt=1 → 1:cnt=0 → 1:c=1,cnt=1 → 2:cnt=0 → 2:c=2,cnt=1。候选 **2**，验证：2 出现 4 次 > 7/2 = 3，**是主元素**
</details>
