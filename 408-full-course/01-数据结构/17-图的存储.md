## 🚪 课前引入

一张地铁图，怎么存进电脑？
- 方法 1：做一张**表格**，行和列都是所有站点，两站之间有线路就在格子里打 ✓ → **邻接矩阵**
- 方法 2：给每个站点列一个**清单**，写上它能直达哪些站 → **邻接表**

两种方法各有优劣：表格一目了然，查两站之间有没有线路很快，但站很多、线路很少时，表格里大部分是空格，很浪费；清单节省空间，但查“A 到 B 有没有线路”要翻 A 的整个清单。

## 一、邻接矩阵（⭐⭐⭐）

### 📐 定义
用一个**一维数组**存顶点信息，用一个**二维数组**存边的信息（各顶点之间的邻接关系）。这个二维数组叫**邻接矩阵**。

**不带权的图**：
$$A[i][j] = \begin{cases} 1, & (v_i, v_j) \text{ 或 } \langle v_i, v_j\rangle \text{ 是边} \\ 0, & \text{否则} \end{cases}$$

**带权图（网）**：
$$A[i][j] = \begin{cases} w_{ij}, & \text{有边，权值为 } w_{ij} \\ 0 \text{ 或 } \infty, & i = j \text{ 或无边} \end{cases}$$
（对角线通常为 0，无边为 ∞）

### ✏️ 例
**无向图**：
```
   A ─── B
   │   ╱ │           A  B  C  D
   │ ╱   │        A [0  1  1  0]
   C     D        B [1  0  1  1]
                  C [1  1  0  0]
                  D [0  1  0  0]
```
**有向图**：
```
   A ──→ B           A  B  C
    ↖   ↙         A [0  1  0]
      C           B [0  0  1]
                  C [1  0  0]
```
**带权有向图**：
```
   A ─5→ B           A  B  C
    ↖   ↙3        A [0  5  ∞]
     2  C         B [∞  0  3]
                  C [2  ∞  0]
```

### 📐 结构定义
```c
#define MaxVertexNum 100
typedef char VertexType;           // 顶点的数据类型
typedef int EdgeType;              // 边上权值的数据类型
typedef struct {
    VertexType Vex[MaxVertexNum];               // 顶点表
    EdgeType Edge[MaxVertexNum][MaxVertexNum];  // 邻接矩阵（边表）
    int vexnum, arcnum;                         // 当前顶点数、弧数
} MGraph;
```
（2021、2023 年第 41 题中的定义几乎一样：`numVertices, numEdges; VerticesList[]; Edge[][]`）

### 📐 邻接矩阵的性质（⭐⭐）
1. **无向图的邻接矩阵是对称矩阵**，可以只存上（或下）三角 → 压缩存储（第 8 课）
2. **无向图**：第 i 行（或第 i 列）非零元素的个数 = 顶点 i 的**度**
3. **有向图**：
   - 第 i **行**非零元素个数 = 顶点 i 的**出度**
   - 第 i **列**非零元素个数 = 顶点 i 的**入度**
4. **判断两个顶点间是否有边**：直接看 A[i][j]，**O(1)**
5. **找一个顶点的所有邻居**：扫描一整行，**O(n)**
6. **统计边数**：扫描整个矩阵，**O(n²)**
7. **空间复杂度 O(n²)**，只和顶点数有关，与边数无关 → 适合**稠密图**
8. 邻接矩阵表示是**唯一的**（顶点编号确定后）
9. ⭐ **设 A 是（不带权）邻接矩阵，Aⁿ[i][j] 等于从顶点 i 到顶点 j 的长度为 n 的路径数目**

✏️ **性质 9 的例子**：上面的无向图，求 A² 中 A²[A][D]（A 到 D 长度为 2 的路径数）：
A²[A][D] = Σₖ A[A][k] × A[k][D] = A[A][A]·A[A][D] + A[A][B]·A[B][D] + A[A][C]·A[C][D] + A[A][D]·A[D][D] = 0 + 1×1 + 0 + 0 = **1**（路径 A→B→D）

### 📐 真题风格的算法（邻接矩阵上）
📝 **2021 年第 41 题**：判断无向连通图是否存在 EL 路径（度为奇数的顶点个数为 0 或 2）→ 求每行之和得度数，统计奇数度顶点个数。
📝 **2023 年第 41 题**：输出有向图中出度大于入度的顶点 → 第 i 行之和是出度，第 i 列之和是入度。
（完整代码见[第 32 课 · 算法题专题](32-算法题专题.md)）

## 二、邻接表（⭐⭐⭐）

### 📐 定义
对每个顶点 vᵢ 建一个**单链表**，链表中的结点表示**依附于 vᵢ 的边**（有向图是以 vᵢ 为**尾**的弧）。
- **顶点表**：用数组存放每个顶点的信息和**指向第一条边的指针**
- **边表**：每个边结点存放**邻接点的下标**、指向下一条边的指针（带权图再加权值）

```
顶点表结点：         边表结点：
┌──────┬──────────┐   ┌────────┬──────┐
│ data │ firstarc │   │ adjvex │ next │
└──────┴──────────┘   └────────┴──────┘
```

### ✏️ 例（上面的无向图，A=0, B=1, C=2, D=3）
```
0 A → [1] → [2] → ^
1 B → [0] → [2] → [3] → ^
2 C → [0] → [1] → ^
3 D → [1] → ^
```
**有向图**（A→B, B→C, C→A）：
```
0 A → [1] → ^        （A 的出边）
1 B → [2] → ^
2 C → [0] → ^
```

### 📐 结构定义
```c
typedef struct ArcNode {           // 边表结点
    int adjvex;                    // 该弧指向的顶点的位置
    struct ArcNode *next;          // 指向下一条弧
    // InfoType info;              // 权值（带权图时）
} ArcNode;

typedef struct VNode {             // 顶点表结点
    VertexType data;               // 顶点信息
    ArcNode *first;                // 指向第一条依附于该顶点的弧
} VNode, AdjList[MaxVertexNum];

typedef struct {
    AdjList vertices;              // 邻接表
    int vexnum, arcnum;            // 顶点数、弧数
} ALGraph;
```

### 📐 邻接表的性质（⭐⭐）
1. **空间复杂度**：
   - 无向图：每条边在两个顶点的链表中各出现一次 → **O(|V| + 2|E|)**
   - 有向图：**O(|V| + |E|)**
   - 适合**稀疏图**
2. **无向图**：顶点 vᵢ 的度 = 第 i 个链表的结点数
3. **有向图**：
   - 出度 = 第 i 个链表的结点数，O(出度)，**容易**
   - 入度 = 所有链表中 adjvex == i 的结点个数，要**遍历整个邻接表**，O(|V| + |E|)，**困难**
   - 解决：建立**逆邻接表**（每个顶点的链表存以它为**头**的弧），入度就容易求了
4. **判断两个顶点间是否有边**：要在一个链表中查找，O(度)，比邻接矩阵慢
5. **找一个顶点的所有邻居**：直接遍历它的链表，快
6. 邻接表表示**不唯一**（链表中结点的顺序可以不同，取决于建立时边的输入顺序）

## 三、十字链表（有向图，了解）

### 📐 思想
有向图的邻接表**找入边**很麻烦。十字链表把**邻接表和逆邻接表合在一起**：每条弧用一个结点表示，这个结点**同时**挂在“弧尾的出边链表”和“弧头的入边链表”上。
```
弧结点：
┌─────────┬─────────┬───────┬───────┬──────┐
│ tailvex │ headvex │ hlink │ tlink │ info │
└─────────┴─────────┴───────┴───────┴──────┘
tailvex/headvex：弧尾、弧头的编号
hlink：指向弧头相同的下一条弧（入边链）
tlink：指向弧尾相同的下一条弧（出边链）

顶点结点：
┌──────┬─────────┬──────────┐
│ data │ firstin │ firstout │
└──────┴─────────┴──────────┘
```
- 求**出度和入度都方便**
- 空间 O(|V| + |E|)
- 表示**不唯一**，但一个十字链表确定一个图

## 四、邻接多重表（无向图，了解）

### 📐 思想
无向图的邻接表中，**每条边存了两次**（在两个端点的链表里各一个），删除一条边要删两个结点。邻接多重表让**每条边只用一个结点表示**，这个结点同时挂在两个端点的链表上。
```
边结点：
┌──────┬───────┬──────┬───────┬──────┐
│ ivex │ ilink │ jvex │ jlink │ info │
└──────┴───────┴──────┴───────┴──────┘
ivex、jvex：边的两个端点
ilink：指向下一条依附于 ivex 的边
jlink：指向下一条依附于 jvex 的边
```
- 删除边、标记已访问的边更方便
- 空间 O(|V| + |E|)

## 五、四种存储结构对比（⭐⭐⭐）

| | 邻接矩阵 | 邻接表 | 十字链表 | 邻接多重表 |
|---|---|---|---|---|
| 空间复杂度 | O(\|V\|²) | 无向 O(\|V\|+2\|E\|)；有向 O(\|V\|+\|E\|) | O(\|V\|+\|E\|) | O(\|V\|+\|E\|) |
| 适用 | **稠密图** | **稀疏图** | 只能存**有向图** | 只能存**无向图** |
| 表示方式 | **唯一** | 不唯一 | 不唯一 | 不唯一 |
| 计算度/出度/入度 | 遍历对应行/列 O(\|V\|) | 出度易、入度难（有向） | 都容易 | 容易 |
| 判断 (i,j) 是否有边 | **O(1)** | O(度) | 容易 | 容易 |
| 找相邻的边 | 遍历一行 O(\|V\|) | 遍历链表 | 容易 | 容易 |
| 删除边或顶点 | 删边容易，删顶点需大量移动 | 无向图中删边、删顶点都麻烦 | 容易 | 容易 |

### 📐 基于两种结构的操作复杂度（⭐ 为遍历算法做准备）
| 操作 | 邻接矩阵 | 邻接表 |
|---|---|---|
| 判断边 (x, y) 是否存在 | O(1) | O(度) |
| 列出顶点 x 的所有邻接点 | O(\|V\|) | O(度) |
| FirstNeighbor(G, x)：x 的第一个邻接点 | O(\|V\|)（最坏） | O(1) |
| NextNeighbor(G, x, y)：y 之后的下一个邻接点 | O(\|V\|)（最坏） | O(1) |
| 访问所有顶点的所有邻接点（遍历） | **O(\|V\|²)** | **O(\|V\| + \|E\|)** |

## 六、基本操作接口（了解）
```c
Adjacent(G, x, y)        // 判断是否存在边 <x,y> 或 (x,y)
Neighbors(G, x)          // 列出与 x 邻接的边
InsertVertex(G, x)       // 插入顶点
DeleteVertex(G, x)       // 删除顶点
AddEdge(G, x, y)         // 添加边
RemoveEdge(G, x, y)      // 删除边
FirstNeighbor(G, x)      // 求 x 的第一个邻接点，无则返回 -1
NextNeighbor(G, x, y)    // y 是 x 的一个邻接点，返回除 y 外 x 的下一个邻接点，无则 -1
Get_edge_value(G, x, y)、Set_edge_value(G, x, y, v)
```
遍历算法（下一课）就是基于 FirstNeighbor 和 NextNeighbor 写的：
```c
for (w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w)) {
    // 处理 v 的每一个邻接点 w
}
```

## ⚠️ 易错点
1. 有向图邻接矩阵：**行 = 出度，列 = 入度**
2. 无向图邻接表的边结点数 = **2e**
3. 邻接矩阵唯一，邻接表不唯一
4. 邻接表求有向图的入度要遍历整个表（或用逆邻接表）
5. 十字链表只用于有向图，邻接多重表只用于无向图
6. 稠密图用矩阵，稀疏图用邻接表

---

## 📋 本课小结

| 结构 | 空间 | 要点 |
|---|---|---|
| 邻接矩阵 | O(n²) | 唯一；判断边 O(1)；无向对称；Aⁿ[i][j] = 长度 n 的路径数 |
| 邻接表 | O(n + e) | 不唯一；出度易、入度难；无向图 2e 个边结点 |
| 逆邻接表 | O(n + e) | 求入度方便 |
| 十字链表 | O(n + e) | 有向图；出入度都方便 |
| 邻接多重表 | O(n + e) | 无向图；每条边一个结点 |

## 🏋️ 课后练习

1. 一个有向图的邻接矩阵如下，求各顶点的入度和出度：
   ```
       0 1 2 3
   0 [ 0 1 1 0 ]
   1 [ 0 0 0 1 ]
   2 [ 0 1 0 1 ]
   3 [ 1 0 0 0 ]
   ```
2. 画出上题的邻接表（边按顶点编号从小到大排列）。
3. 一个无向图有 n 个顶点、e 条边，用邻接表存储，边表结点共有多少个？用邻接矩阵存储，矩阵中有多少个 1？
4. 对一个 1000 个顶点、2000 条边的图，用邻接矩阵还是邻接表？为什么？
5. 写一个算法：已知有向图的邻接表，求顶点 k 的入度。

<details>
<summary>📖 答案</summary>

1. 出度（行和）：0→2，1→1，2→2，3→1；入度（列和）：0→1，1→2，2→1，3→2
2. `0 → 1 → 2`；`1 → 3`；`2 → 1 → 3`；`3 → 0`
3. 边表结点 **2e** 个；矩阵中 **2e** 个 1
4. **邻接表**。邻接矩阵需要 10⁶ 个单元，而只有 2000 条边（稀疏图），邻接表只需约 1000 + 2000（或 4000）个单元
5. ```c
   int InDegree(ALGraph G, int k) {
       int count = 0;
       for (int i = 0; i < G.vexnum; i++)
           for (ArcNode *p = G.vertices[i].first; p != NULL; p = p->next)
               if (p->adjvex == k) count++;
       return count;
   }
   ```
   时间 O(n + e)
</details>
