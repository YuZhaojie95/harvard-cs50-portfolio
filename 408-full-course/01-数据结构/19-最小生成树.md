## 🚪 课前引入：修路问题

有 6 个村庄，要修路让**所有村庄都连通**（任意两村都能通过道路到达），每条可能的道路都有造价。怎么修**总造价最低**？
- 要连通 n 个村庄，至少修 n − 1 条路（多修一条就会形成环，是浪费）
- 在所有“连通且 n − 1 条边”的方案中，选**总造价最小**的——这就是**最小生成树**

---

## 一、最小生成树的概念

### 📐 定义
对于一个**带权连通无向图** G，它的生成树中，**边的权值之和最小**的那棵，称为**最小生成树（MST, Minimum Spanning Tree）**。

### 📐 性质（⭐⭐）
1. MST 包含图的**所有顶点**，有 **|V| − 1 条边**，**不含回路**
2. 若图中各边**权值互不相同**，则 MST **唯一**
3. 若有权值相同的边，MST **可能不唯一**，但**所有 MST 的权值之和（代价）一定相同且最小**
4. 若图本身就是一棵树（|E| = |V| − 1），MST 就是它自己
5. 只有**连通图**才有生成树；非连通图只有**生成森林**
6. ⚠️ MST 中两个顶点之间的路径**不一定**是图中这两点间的**最短路径**

### 📐 MST 性质（贪心的理论依据）
设 U 是顶点集 V 的一个非空子集。若 (u, v) 是一条**一端在 U 中、另一端在 V − U 中**的边里**权值最小**的，则**必存在**一棵包含边 (u, v) 的最小生成树。
🧒 **大白话**：把村庄分成两组，连接两组的所有道路中最便宜的那条，一定可以出现在某个最优方案里。
Prim 和 Kruskal 都是基于这个性质的**贪心算法**。

---

## 二、Prim 算法（普里姆，⭐⭐⭐）

### 📐 思想：“**加点法**”，从一个顶点开始，一棵树慢慢长大
1. 任选一个顶点加入树 T
2. 在所有“**一端在 T 中、另一端不在 T 中**”的边里，选**权值最小**的一条，把它和它的另一个端点加入 T
3. 重复，直到所有顶点都加入 T（选了 n − 1 条边）

🧒 **比喻**：一个村子先通电，每次从“已通电的村子”向“没通电的村子”拉一条最便宜的线。

### ✏️ 例题
```
6 个村庄 A~F，可修的路（无向带权图）：
A-B 4   A-C 1   B-C 2   B-D 5   C-D 8
C-E 10  D-E 2   D-F 6   E-F 3
```

### 📐 用 lowcost 表模拟（⭐ 考场标准做法）
- **lowcost[v]**：当前树 T 到顶点 v 的**最小边权**（v 还没进树时有意义）
- 每一轮：选 lowcost 最小的顶点加入 T，然后**用新加入的顶点更新**其他顶点的 lowcost

从 A 开始：
| 轮次 | 加入的顶点（边） | lowcost：B | C | D | E | F |
|---|---|---|---|---|---|---|
| 初始 | A | 4 | **1** | ∞ | ∞ | ∞ |
| 1 | C（A-C, 1） | **2** | ✓ | 8 | 10 | ∞ |
| 2 | B（C-B, 2） | ✓ | ✓ | **5** | 10 | ∞ |
| 3 | D（B-D, 5） | ✓ | ✓ | ✓ | **2** | 6 |
| 4 | E（D-E, 2） | ✓ | ✓ | ✓ | ✓ | **3** |
| 5 | F（E-F, 3） | ✓ | ✓ | ✓ | ✓ | ✓ |

**更新过程解释**：
- 第 1 轮加入 C 后：B 通过 C 连接只要 2（比经过 A 的 4 小），更新为 2；D 通过 C 要 8；E 通过 C 要 10
- 第 2 轮加入 B 后：D 通过 B 只要 5（比 8 小），更新
- 第 3 轮加入 D 后：E 通过 D 只要 2，F 通过 D 要 6
- 第 4 轮加入 E 后：F 通过 E 只要 3

依次加入的边：**(A,C)1、(C,B)2、(B,D)5、(D,E)2、(E,F)3**，总权值 **13**。

### 📐 代码框架
```c
void Prim(MGraph G, int v0) {
    int lowcost[MAX], adjvex[MAX];    // adjvex[v]：lowcost[v] 对应的边在树中的那一端
    bool inTree[MAX] = {false};
    inTree[v0] = true;
    for (int v = 0; v < G.vexnum; v++) { lowcost[v] = G.Edge[v0][v]; adjvex[v] = v0; }
    for (int i = 1; i < G.vexnum; i++) {          // 共加入 n-1 个顶点
        int min = INF, k = -1;
        for (int v = 0; v < G.vexnum; v++)        // 选出 lowcost 最小的非树顶点
            if (!inTree[v] && lowcost[v] < min) { min = lowcost[v]; k = v; }
        printf("(%d, %d) ", adjvex[k], k);        // 输出这条边
        inTree[k] = true;
        for (int v = 0; v < G.vexnum; v++)        // 用 k 更新 lowcost
            if (!inTree[v] && G.Edge[k][v] < lowcost[v]) {
                lowcost[v] = G.Edge[k][v];
                adjvex[v] = k;
            }
    }
}
```

### 📐 复杂度
- 外层 n − 1 轮，每轮选最小 O(n) + 更新 O(n) → **O(|V|²)**
- **与边数无关** → 适合**稠密图**（边多）
- （用堆优化可以到 O(|E| log |V|)，了解）

## 三、Kruskal 算法（克鲁斯卡尔，⭐⭐⭐）

### 📐 思想：“**加边法**”，从小到大挑边，不成环就要
1. 初始时，n 个顶点各自是一棵树（森林），**没有边**
2. 把所有边按权值**从小到大排序**
3. 依次考察每条边：若这条边的两个端点**属于不同的树**（加入后不会形成回路），就选它，并把两棵树合并；否则**舍弃**
4. 直到选够 n − 1 条边

🧒 **比喻**：从最便宜的路开始修，每次看这条路修了会不会“绕圈”（两个村子本来就已经连通了），会绕圈就不修。

### ✏️ 同一个例题
边按权值排序：
| 边 | 权 | 两端是否已连通 | 结果 | 已连通的集合 |
|---|---|---|---|---|
| A-C | 1 | 否 | **选** | {A,C} {B} {D} {E} {F} |
| B-C | 2 | 否 | **选** | {A,B,C} {D} {E} {F} |
| D-E | 2 | 否 | **选** | {A,B,C} {D,E} {F} |
| E-F | 3 | 否 | **选** | {A,B,C} {D,E,F} |
| A-B | 4 | **是**（A、B 已通过 C 连通） | 舍弃（会成环） | |
| B-D | 5 | 否 | **选** | {A,B,C,D,E,F} |
已选 5 条边，结束。总权值 1 + 2 + 2 + 3 + 5 = **13**（和 Prim 一样）。

⚠️ 注意 B-C 和 D-E 权值都是 2，谁先谁后都可以——**选边顺序可能不唯一**，但这里最终的 MST 相同。

### 📐 如何判断“是否会形成回路”——并查集
- 每个连通分量是一个集合
- 考察边 (u, v)：若 **Find(u) == Find(v)**，u、v 已在同一集合 → 会成环，舍弃
- 否则选中这条边，**Union** 两个集合

```c
void Kruskal(Edge edges[], int n, int e) {   // edges 已按权值升序排序
    int S[MAX];
    for (int i = 0; i < n; i++) S[i] = -1;   // 并查集初始化
    int count = 0;
    for (int i = 0; i < e && count < n - 1; i++) {
        int r1 = Find(S, edges[i].u), r2 = Find(S, edges[i].v);
        if (r1 != r2) {                       // 不在同一集合，不会成环
            printf("(%d, %d) ", edges[i].u, edges[i].v);
            Union(S, r1, r2);
            count++;
        }
    }
}
```

### 📐 复杂度
- 排序 O(|E| log |E|)，并查集操作近似 O(1)
- 总计 **O(|E| log |E|)**
- **与顶点数关系不大** → 适合**稀疏图**（边少、顶点多）

## 四、Prim vs Kruskal

| | Prim | Kruskal |
|---|---|---|
| 策略 | **加点**：一棵树慢慢长大 | **加边**：森林逐渐合并 |
| 每步选择 | 树与非树顶点之间的最小边 | 全局最小的、不成环的边 |
| 中间过程 | 始终是**一棵树** | 可能是**森林** |
| 时间复杂度 | **O(\|V\|²)** | **O(\|E\| log \|E\|)** |
| 适合 | **稠密图** | **稀疏图** |
| 辅助结构 | lowcost 数组 | 排序 + 并查集 |

## 五、真题与常见考法

📝 **真题（2020 年第 7 题）**：已知无向图 G（题中给出图），使用 Kruskal 算法求 G 的最小生成树，**加到最小生成树中的边依次是**？
**解法**：把所有边按权值从小到大列出，一条一条判断是否成环；选出的边按选择顺序写下来，和选项对照。**权值相同的边，看选项的顺序是否合理**（相同权值的边谁先都可以，但不成环的必须都选）。
⚠️ 常见陷阱：选项中出现了“会导致成环”的边，或者顺序中某条小权值的边排在了大权值的边之后（Kruskal 严格按权值从小到大）。

📝 **常见选择题 1**：下列关于最小生成树的说法，正确的是：
- 最小生成树的代价唯一 ✓
- 所有权值最小的边一定会出现在所有的最小生成树中 ✗（若权值最小的边有多条且会构成环，就不一定都出现）
- 使用 Prim 算法从不同顶点开始得到的 MST 一定相同 ✗（权值有重复时可能不同）
- Prim 和 Kruskal 得到的 MST 总不相同 ✗（权值互不相同时一定相同）

📝 **常见选择题 2**：一个带权连通图中，**权值最小的边**一定在 MST 中吗？
→ 若**唯一**的最小权边，**一定**在所有 MST 中（Kruskal 第一步就选它）。若有多条相同最小权值的边，每一条不一定都在。

📝 **常见选择题 3**：一个带权连通图中，**权值最大的边**一定不在 MST 中吗？
→ **不一定**。若这条边是“**桥**”（去掉它图就不连通），它必须在 MST 中。

---

## ⚠️ 易错点
1. MST 是针对**带权连通无向图**的
2. 权值互不相同 → MST 唯一；有相同权值 → MST 可能不唯一，但代价唯一
3. Prim O(V²) 适合稠密图，Kruskal O(E log E) 适合稀疏图
4. Kruskal 的中间状态可以是森林，Prim 始终是一棵树
5. MST 上的路径不一定是最短路径
6. Prim 更新 lowcost 时用的是**新加入的顶点**到其他顶点的边

---

## 📋 本课小结

| 算法 | 思想 | 复杂度 | 适用 |
|---|---|---|---|
| Prim | 加点：每次选树到非树的最小边 | O(\|V\|²) | 稠密图 |
| Kruskal | 加边：从小到大选不成环的边（并查集） | O(\|E\|log\|E\|) | 稀疏图 |

MST：n − 1 条边；权值互异则唯一；代价总是唯一。
