## 🚪 课前引入：一摞盘子

食堂洗好的盘子一个个**摞起来**：
- 新洗好的盘子只能放在**最上面**
- 取盘子也只能从**最上面**拿
- 所以**最后放上去的，最先被拿走**

这就是栈（Stack）：**后进先出（LIFO, Last In First Out）**。

生活中的栈：浏览器的“后退”按钮（最近访问的页面最先退回）、Word 的“撤销”（最近的操作最先撤销）、叠罗汉……

## 一、栈的定义

### 📐 定义
栈是**只允许在一端进行插入和删除操作**的线性表。
- **栈顶（top）**：允许插入、删除的那一端
- **栈底（bottom）**：固定的、不允许操作的那一端
- **空栈**：不含任何元素

```
        ┌─────┐
入栈 →  │  e  │ ← 栈顶（top）   → 出栈
        ├─────┤
        │  d  │
        ├─────┤
        │  c  │
        ├─────┤
        │  b  │
        ├─────┤
        │  a  │ ← 栈底
        └─────┘
入栈顺序 a, b, c, d, e；出栈顺序 e, d, c, b, a
```

⚠️ 栈是**操作受限的线性表**，逻辑结构仍是**线性结构**（一对一）。

### 📐 基本操作
| 操作 | 功能 |
|---|---|
| InitStack(&S) | 初始化空栈 |
| StackEmpty(S) | 判空 |
| **Push(&S, x)** | **入栈**（进栈）：x 放到栈顶 |
| **Pop(&S, &x)** | **出栈**：删除栈顶元素，用 x 返回 |
| GetTop(S, &x) | 读栈顶元素（不删除） |
| DestroyStack(&S) | 销毁 |

## 二、顺序栈（⭐⭐⭐）

### 📐 定义
```c
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize];   // 存放栈中元素
    int top;                  // 栈顶指针（实际是数组下标）
} SqStack;
```

### 📐 写法一：top 初值为 −1（top 指向**栈顶元素**）
```c
void InitStack(SqStack &S) { S.top = -1; }

bool StackEmpty(SqStack S) { return S.top == -1; }

bool Push(SqStack &S, ElemType x) {
    if (S.top == MaxSize - 1) return false;   // 栈满
    S.data[++S.top] = x;                      // 指针先加 1，再放入
    return true;
}

bool Pop(SqStack &S, ElemType &x) {
    if (S.top == -1) return false;            // 栈空
    x = S.data[S.top--];                      // 先取出，指针再减 1
    return true;
}

bool GetTop(SqStack S, ElemType &x) {
    if (S.top == -1) return false;
    x = S.data[S.top];
    return true;
}
```
| 状态 | 条件 |
|---|---|
| 栈空 | top == −1 |
| 栈满 | top == MaxSize − 1 |
| 栈中元素个数 | top + 1 |

**过程演示**（MaxSize = 5）：
```
初始          top = -1   [ _ _ _ _ _ ]
Push(a)       top = 0    [ a _ _ _ _ ]
Push(b)       top = 1    [ a b _ _ _ ]
Pop → b       top = 0    [ a b _ _ _ ]   ← b 还在数组里，但已经“不在栈中”了
Push(c)       top = 1    [ a c _ _ _ ]   ← c 覆盖了 b
```
🧒 出栈只是移动 top，**数据并没有真的被擦掉**，只是逻辑上删除了，下次入栈会覆盖它。

### 📐 写法二：top 初值为 0（top 指向**栈顶元素的下一个位置**）
```c
S.top = 0;                    // 初始
S.data[S.top++] = x;          // 入栈：先放入，指针再加 1
x = S.data[--S.top];          // 出栈：指针先减 1，再取出
```
| 状态 | 条件 |
|---|---|
| 栈空 | top == 0 |
| 栈满 | top == MaxSize |
| 元素个数 | top |

⚠️ **考试时一定要先看题目规定 top 的初值**，代码的 `++` 位置随之变化。

🧒 **记忆**：
- top 指向“有东西的格子”（初值 −1）→ 入栈时要**先挪到空格子**再放：`++top`
- top 指向“空格子”（初值 0）→ 入栈时**直接放**再挪：`top++`

## 三、共享栈

### 📐 思想
两个栈**共用一个数组**：栈 0 的栈底在数组开头，**向右长**；栈 1 的栈底在数组末尾，**向左长**。
```
下标:  0   1   2   3   4   5   6   7
      [a1][a2][a3][  ][  ][b2][b1]
            ↑top0         ↑top1
栈0 →→→                    ←←← 栈1
```
```c
// 初始：top0 = -1，top1 = MaxSize
// 栈 0 入栈：S.data[++top0] = x;
// 栈 1 入栈：S.data[--top1] = x;
// 栈满条件：top0 + 1 == top1   （两个栈顶“碰头”了）
```
**优点**：更有效地利用空间。两个栈中一个多一个少的时候，可以互相“借”空间。只有整个数组都满了才会溢出。

## 四、链栈

### 📐 定义
用单链表实现栈，**规定在链表头部进行插入和删除**（表头就是栈顶）。
```c
typedef struct Linknode {
    ElemType data;
    struct Linknode *next;
} LiStack;
```
```
top → [e|●] → [d|●] → [c|●] → [b|●] → [a|^]
栈顶                                    栈底
```
- 入栈 = 在表头插入（头插法），O(1)
- 出栈 = 删除表头结点，O(1)
- **一般不带头结点**（栈顶指针直接指向栈顶元素），空栈 `top == NULL`
- **优点**：不存在栈满上溢（只要内存够），便于多个栈共享存储空间

🧒 为什么栈顶放在链表**头部**而不是尾部？因为单链表在头部插删是 O(1)，在尾部删除要 O(n)。

## 五、出栈序列（⭐⭐⭐ 必考）

### 5.1 按操作模拟

📝 **真题（2020 年第 2 题）**：对空栈 S 进行 Push 和 Pop 操作，入栈序列为 a, b, c, d, e，经过 Push, Push, Pop, Push, Pop, Push, Push, Pop 操作后得到的出栈序列是？
```
操作      栈（左为底）    输出
Push a    a
Push b    a b
Pop       a              b
Push c    a c
Pop       a              c
Push d    a d
Push e    a d e
Pop       a d            e
```
出栈序列 **b, c, e**，选 D。

### 5.2 判断出栈序列是否合法（⭐⭐）

**核心规律**：对出栈序列中的任一元素 x，**在 x 之后出栈的、且比 x 先入栈的元素，必须按“逆序”（后入先出）出栈**。
换句话说：如果入栈顺序是 1, 2, 3, …，那么**出栈序列中不能出现“大、小、中”的模式**（即 i < j < k，出栈顺序是 k, i, j 是非法的）。

🧒 **理由**：k 出栈时，i 和 j 已经在栈里，而且 j 压在 i 上面。之后必须先出 j 再出 i，不可能先出 i。

**方法一：模拟法（最稳）**
依次看出栈序列的每个元素：
- 如果它在栈顶 → 出栈
- 如果它还没入栈 → 把它和它之前的元素依次入栈，再出栈
- 如果它在栈里但不在栈顶 → **非法**

**例**：入栈 1, 2, 3, 4, 5，判断 **3, 2, 5, 4, 1** 和 **4, 1, 3, 2, 5**
```
序列 3,2,5,4,1：
要 3：1,2,3 入栈，3 出             栈：1 2
要 2：栈顶是 2，出                 栈：1
要 5：4,5 入栈，5 出               栈：1 4
要 4：栈顶是 4，出                 栈：1
要 1：栈顶是 1，出                 栈：空        → 合法 ✓

序列 4,1,3,2,5：
要 4：1,2,3,4 入栈，4 出           栈：1 2 3
要 1：1 在栈里，但栈顶是 3          → 非法 ✗
```

**方法二：“大小中”排除法（快速）**
4, 1, 3, 2, 5 中：4 在前，1 和 3 在后，且 1 < 3 < 4，出现“4…1…3”（大、小、中）→ 非法。

### 5.3 出栈序列的个数：卡特兰数（⭐）
n 个**不同**元素依次入栈，可能的出栈序列个数为：
$$\frac{1}{n+1}C_{2n}^{n} = \frac{(2n)!}{(n+1)!\,n!}$$
| n | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 个数 | 1 | 2 | **5** | **14** | 42 |

**n = 3 的 5 种**（入栈 a, b, c）：abc、acb、bac、bca、cba（**只有 cab 不行**，它是“大小中”）

> 🔗 卡特兰数还等于：**n 个结点能构成的不同形态的二叉树个数**、n 对括号的合法匹配数。

### 5.4 相关真题

📝 **真题（2022 年第 2 题）**：给定有限符号集 S，in 和 out 均为 S 中所有元素的任意排列。对于初始为空的栈 ST，下列叙述正确的是：
- A. 若 in 是 ST 的入栈序列，则**不能判断** out 是否为其可能的出栈序列 ✗（用模拟法就能判断）
- B. 若 out 是出栈序列，则不能判断 in 是否为可能的入栈序列 ✗（同理，反向模拟即可）
- C. in 与 out **一定不同** ✗（每个元素入栈后立即出栈，out = in）
- D. in 与 out **可能互为倒序** ✓（全部入栈后再全部出栈）
答案 **D**。

📝 **经典题**：入栈序列 1, 2, 3, …, n，出栈序列第一个元素是 n，则第 i 个出栈的元素是？
→ n 最先出，说明 1 ~ n 全部入栈后才开始出，出栈序列只能是 n, n−1, …, 1，第 i 个是 **n − i + 1**。

📝 **经典题**：入栈序列 1, 2, …, n，出栈序列第一个是 3，则第二个出栈的**不可能**是？
→ 3 出栈时 1、2 在栈里（2 在栈顶）。第二个出栈的可能是 2（栈顶），也可能是 4, 5, …, n（新入栈的）。**不可能是 1**。

📝 **经典题**：入栈 a, b, c, d, e，出栈序列为 b, d, c, e, a，栈的容量至少是？
```
b：a,b 入，b 出            栈中 1 个（最多时 2 个）
d：c,d 入，d 出            栈中 a,c（最多时 3 个：a,c,d）
c：出                      a
e：e 入，e 出              a（最多时 2 个）
a：出
```
栈中同时最多 3 个元素 → 容量至少 **3**。

## ⚠️ 易错点
1. 栈是**线性结构**，只是操作受限
2. top 初值为 −1 还是 0，入栈出栈的写法不同
3. 出栈只是移动指针，数据还在数组里
4. 共享栈满：`top0 + 1 == top1`
5. 链栈在**表头**操作
6. 判断出栈序列：不能出现“大、小、中”

---

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 特性 | 后进先出 LIFO；只在栈顶操作 |
| 顺序栈（top 初值 −1） | 入 `data[++top]=x`，出 `x=data[top--]`；空 top==−1，满 top==MaxSize−1 |
| 顺序栈（top 初值 0） | 入 `data[top++]=x`，出 `x=data[--top]`；空 top==0，满 top==MaxSize |
| 共享栈 | 两端向中间长；满 top0+1==top1 |
| 链栈 | 表头当栈顶；不会上溢 |
| 出栈序列合法性 | 模拟法；禁止“大小中” |
| 卡特兰数 | C(2n,n)/(n+1)：1, 2, 5, 14, 42 |
