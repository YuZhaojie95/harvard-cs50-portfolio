## 一、数组的定义

### 📐 定义
数组是由 n 个**相同类型**的数据元素构成的**有限序列**。
- 一维数组是线性表
- 二维数组可以看成“元素是一维数组”的一维数组（线性表的推广）

### 📐 特点
- 数组一旦定义，**维数和维界就不再改变**
- 除了初始化和销毁，只有**存取元素**和**修改元素**两种操作（**没有插入、删除**）
- 因此数组适合用**顺序存储**

## 二、数组的存储结构与地址计算（⭐⭐）

### 2.1 一维数组
A[0..n−1]，首地址 LOC(A[0])，每个元素占 L 字节：
$$\text{LOC}(A[i]) = \text{LOC}(A[0]) + i \times L$$

### 2.2 二维数组
内存是一维的，二维数组要“**拉直**”存放，有两种方式：

```
矩阵 A[3][4]：
     a00 a01 a02 a03
     a10 a11 a12 a13
     a20 a21 a22 a23

行优先（C 语言）：a00 a01 a02 a03 | a10 a11 a12 a13 | a20 a21 a22 a23
列优先（Fortran）：a00 a10 a20 | a01 a11 a21 | a02 a12 a22 | a03 a13 a23
```

**行优先**：A[0..m−1][0..n−1]（m 行 n 列）
$$\text{LOC}(a_{ij}) = \text{LOC}(a_{00}) + (i \times n + j) \times L$$
🧒 前面有 i 整行（每行 n 个），本行前面还有 j 个。

**列优先**：
$$\text{LOC}(a_{ij}) = \text{LOC}(a_{00}) + (j \times m + i) \times L$$
🧒 前面有 j 整列（每列 m 个），本列前面还有 i 个。

**下标不从 0 开始**：A[l₁..h₁][l₂..h₂]，行优先：
$$\text{LOC}(a_{ij}) = \text{LOC}(a_{l_1 l_2}) + [(i - l_1) \times (h_2 - l_2 + 1) + (j - l_2)] \times L$$
🧒 公式看着复杂，其实还是“前面有几行 × 每行几个 + 本行前面几个”。

### ✏️ 例题
**例 1**：A[1..10][1..20]，按行优先存储，每个元素 2 字节，A[1][1] 的地址是 1000，求 A[5][8] 的地址。
- 前面有 5 − 1 = 4 整行，每行 20 个 → 80 个
- 本行前面有 8 − 1 = 7 个
- 地址 = 1000 + (80 + 7) × 2 = **1174**

**例 2**：同上，改成列优先。
- 前面有 8 − 1 = 7 整列，每列 10 个 → 70 个
- 本列前面有 5 − 1 = 4 个
- 地址 = 1000 + (70 + 4) × 2 = **1148**

📝 **真题（2021 年第 3 题）**：二维数组 A 按行优先存储，每个元素占 1 个存储单元。A[0][0] 的地址是 100，A[3][3] 的地址是 220，则 A[5][5] 的地址是？
- 设每行 n 个元素：220 − 100 = 3n + 3 → **n = 39**
- A[5][5] = 100 + (5 × 39 + 5) × 1 = 100 + 200 = **300**，选 B
🧒 这题的巧妙之处：题目没告诉你每行多少个，要**反推列数**。

## 三、特殊矩阵的压缩存储（⭐⭐⭐）

### 📐 为什么要压缩
- **特殊矩阵**：有许多**相同元素**或**零元素**，且分布**有规律**（对称矩阵、三角矩阵、对角矩阵）
- **压缩存储**：多个值相同的元素只分配**一个**存储空间，零元素**不分配**空间
- 压缩后存在一维数组 B 中，关键是求出矩阵元素 aᵢⱼ 对应的数组下标 k

### 🎯 万能方法（强烈推荐）
**k = aᵢⱼ 前面（在存储顺序中）有多少个元素**（若数组下标从 0 开始）
若数组下标从 1 开始，则 k = 前面的个数 + 1。

然后注意**四个坑**：
1. 矩阵下标从 0 还是 1 开始？（默认从 1）
2. 数组下标从 0 还是 1 开始？（C 语言数组从 0）
3. 行优先还是列优先？
4. 存的是上三角还是下三角？要找的元素在不在被存的那一半？

### 3.1 对称矩阵
**定义**：n 阶方阵，aᵢⱼ = aⱼᵢ。
**压缩**：只存**主对角线 + 下三角**（或上三角），共 **n(n+1)/2** 个元素。

**存下三角（i ≥ j），行优先，矩阵下标从 1，数组下标从 0**：
```
行 1：a11                     1 个
行 2：a21 a22                 2 个
行 3：a31 a32 a33             3 个
...
行 i：ai1 ai2 ... aij ...     i 个
```
aᵢⱼ 前面：第 1 ~ i−1 行共 1 + 2 + … + (i−1) = **i(i−1)/2** 个；本行前面 **j − 1** 个。
$$k = \frac{i(i-1)}{2} + j - 1 \quad (i \ge j)$$
**若要找的元素在上三角（i < j）**：因为对称，aᵢⱼ = aⱼᵢ，把 i、j **交换**再代公式：
$$k = \frac{j(j-1)}{2} + i - 1 \quad (i < j)$$

**存上三角（i ≤ j），行优先**：第 r 行有 n − r + 1 个元素。
aᵢⱼ 前面：前 i−1 行共 n + (n−1) + … + (n−i+2) = (i−1)(2n−i+2)/2 个；本行前面 j − i 个。
$$k = \frac{(i-1)(2n - i + 2)}{2} + (j - i)$$
🧒 公式不用背！考试时现场数就行。

**存上三角，列优先**：第 j 列有 j 个元素（a₁ⱼ ~ aⱼⱼ），和“下三角行优先”对称：
$$k = \frac{j(j-1)}{2} + i - 1$$

📝 **真题（2020 年第 1 题）**：将一个 10 × 10 对称矩阵 M 的**上三角部分**元素 mᵢⱼ（1 ≤ i ≤ j ≤ 10）**按列优先**存入 C 语言的一维数组 N 中，元素 **m₇,₂** 在 N 中的下标是？
1. m₇,₂ 的 i = 7 > j = 2，在**下三角**，没有被存储！由对称性 m₇,₂ = **m₂,₇**
2. 上三角按列存：第 1 列 1 个，第 2 列 2 个，……，第 j 列 j 个
3. m₂,₇ 在第 7 列，前 6 列共 1 + 2 + … + 6 = **21** 个
4. 第 7 列中 m₁,₇ 在它前面，**1** 个
5. 前面共 22 个，C 数组下标从 0 → 下标 **22**，选 C

📝 **真题（2018 年真题）**：12 × 12 的对称矩阵 M，将其**上三角部分**元素 mᵢⱼ（1 ≤ i ≤ j ≤ 12）**按行优先**存入 C 语言一维数组 N 中，m₆,₆ 在 N 中的下标是？
- 上三角行优先：第 1 行 12 个，第 2 行 11 个，……
- m₆,₆ 前面有第 1~5 行：12 + 11 + 10 + 9 + 8 = **50** 个
- m₆,₆ 是第 6 行的第一个（上三角第 6 行从 m₆,₆ 开始），本行前面 0 个
- 下标 **50**

### 3.2 三角矩阵
**下三角矩阵**：上三角区（不含对角线）的所有元素都是**同一个常数 c**。
**压缩**：存下三角（n(n+1)/2 个），**最后再多存一个 c** → 共 **n(n+1)/2 + 1** 个。
$$k = \begin{cases} \dfrac{i(i-1)}{2} + j - 1, & i \ge j \text{（下三角区）}\\[2mm] \dfrac{n(n+1)}{2}, & i < j \text{（上三角区，都对应最后那个 c）}\end{cases}$$

**上三角矩阵**：下三角区是常数 c，存上三角 + 一个 c，同理。

### 3.3 三对角矩阵（带状矩阵）
**定义**：只有**主对角线**及其**上下相邻的两条对角线**上有非零元素，即 |i − j| > 1 时 aᵢⱼ = 0。
```
a11 a12  0   0   0
a21 a22 a23  0   0
 0  a32 a33 a34  0
 0   0  a43 a44 a45
 0   0   0  a54 a55
```
- 第 1 行和第 n 行各 2 个，其余每行 3 个，共 **3n − 2** 个
- **行优先**存储，矩阵下标从 1，数组下标从 0：
  - aᵢⱼ 前面：第 1 行 2 个 + 第 2 ~ i−1 行各 3 个 = 2 + 3(i − 2) = **3i − 4** 个（i ≥ 2）
  - 本行中：第 i 行的第一个元素是 aᵢ,ᵢ₋₁，aᵢⱼ 前面有 **j − i + 1** 个
  - 总计：3i − 4 + j − i + 1 = **2i + j − 3**
$$k = 2i + j - 3$$
（验证：a₁₁ → 2 + 1 − 3 = 0 ✓；a₁₂ → 1 ✓；a₂₁ → 2 ✓）

**反过来：已知下标 k，求 i、j**：
- 前 i − 1 行共 3(i−1) − 1 个元素，第 i 行最后一个元素的下标为 3i − 2
- 所以 i 满足：3(i−1) − 2 < k ≤ 3i − 2 → **i = ⌊(k + 1)/3⌋ + 1**（下标从 0）
- 再由 k = 2i + j − 3 解出 j = k − 2i + 3

📝 **真题（2016 年真题）**：100 阶的三对角矩阵 M，元素 mᵢⱼ 按行优先依次压缩存入**下标从 0 开始**的一维数组 N 中，m₃₀,₃₀ 在 N 中的下标是？
→ k = 2 × 30 + 30 − 3 = **87**

## 四、稀疏矩阵

### 📐 定义
非零元素个数**远远少于**矩阵元素总数，而且分布**没有规律**。
例：1000 × 1000 的矩阵只有 100 个非零元素。

### 📐 三元组表
用一个表，每个非零元素记录 **(行, 列, 值)**：
```
矩阵：                     三元组表：
 0  0  3  0                 行  列  值
 0  0  0  0                 0   2   3
 0  7  0  0                 2   1   7
 0  0  0  5                 3   3   5
```
通常还要记录矩阵的**行数、列数、非零元个数**。
⚠️ 压缩后**失去了随机存取特性**：要找 a[i][j]，得在三元组表里查找。

### 📐 十字链表
每个非零元素用一个结点表示：`(行, 列, 值, 指向同行下一个非零元的指针, 指向同列下一个非零元的指针)`。
每行有一个行链表、每列有一个列链表，像“十字”一样交织。
适合**非零元位置经常变化**（频繁插入删除）的情况。

📝 **真题（2017 年真题）**：适用于压缩存储稀疏矩阵的两种存储结构是：**三元组表和十字链表**（选 A）。

## ⚠️ 易错点汇总
1. 看清矩阵下标起点（一般从 1）和数组下标起点（C 语言从 0）
2. 对称矩阵：要找的元素**不在存储的那一半**时，先交换 i、j
3. 列优先的上三角 ≈ 行优先的下三角（公式形式相同）
4. 三角矩阵要**多存一个常数 c**
5. 三对角矩阵 k = 2i + j − 3（矩阵下标从 1，数组下标从 0）
6. 稀疏矩阵压缩后**不能随机存取**
7. **最保险的方法：数一数前面有几个元素**

## 📋 本课小结

| 类型 | 元素个数 | 下标公式（矩阵从 1、数组从 0、行优先） |
|---|---|---|
| 二维数组 m×n | mn | (i−1)n + (j−1)（从 0 开始则 in + j） |
| 对称矩阵（存下三角） | n(n+1)/2 | i ≥ j：i(i−1)/2 + j − 1；i < j：交换 i、j |
| 对称矩阵（存上三角，列优先） | n(n+1)/2 | i ≤ j：j(j−1)/2 + i − 1 |
| 下三角矩阵 | n(n+1)/2 + 1 | i ≥ j 同上；i < j 为 n(n+1)/2 |
| 三对角矩阵 | 3n − 2 | 2i + j − 3 |
| 稀疏矩阵 | 非零元个数 | 三元组表 / 十字链表，失去随机存取 |

## 🏋️ 课后练习

1. A[0..5][0..7] 按列优先存储，每个元素 4 字节，A[0][0] 地址 2000，求 A[4][6] 的地址。
2. 对称矩阵 A[1..8][1..8]，下三角按行优先存入 B[0..35]，求 a₅,₃ 和 a₃,₅ 在 B 中的下标。
3. 10 阶三对角矩阵按行优先存入 B[0..27]，B[16] 对应的矩阵元素是 aᵢⱼ 中的哪一个？
4. n 阶上三角矩阵（下三角全为 0）按列优先压缩存储（不存 0），数组下标从 1 开始，求 aᵢⱼ（i ≤ j）的下标。
5. 稀疏矩阵用三元组表存储后，还能随机存取吗？为什么？

<details>
<summary>📖 答案</summary>

1. 每列 6 个元素。前面 6 整列 → 36 个；本列前面 4 个。地址 = 2000 + 40 × 4 = **2160**
2. a₅,₃：前 4 行 1+2+3+4 = 10 个，本行前 2 个 → 下标 **12**；a₃,₅ = a₅,₃，下标也是 **12**
3. i = ⌊(16 + 1)/3⌋ + 1 = 5 + 1 = **6**；j = 16 − 12 + 3 = **7** → **a₆,₇**（验证：2×6 + 7 − 3 = 16 ✓）
4. 前 j−1 列共 1 + 2 + … + (j−1) = j(j−1)/2 个，本列前 i−1 个，数组从 1 开始要再 +1：**k = j(j−1)/2 + i**
5. 不能。要访问某个 aᵢⱼ，必须在三元组表中查找（顺序查找或折半查找），不能像二维数组那样直接算出地址
</details>
