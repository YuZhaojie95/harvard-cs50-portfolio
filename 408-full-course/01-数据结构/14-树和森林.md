# 数据结构 第 14 课 · 树和森林：存储、转换与遍历

> 🎯 **本课目标**

> 2. **熟练进行树、森林与二叉树的相互转换**
> 3. 掌握树和森林的遍历，以及与二叉树遍历的**对应关系**

## 🚪 课前引入

普通的树，一个结点可能有 0 个、1 个、10 个孩子，不整齐。怎么存？
- 每个结点留 10 个孩子指针？大多数结点用不上，浪费
- 有没有办法**把任意树变成二叉树**，然后用二叉树的所有方法来处理？

答案是有的：“**左孩子右兄弟**”。

## 一、树的存储结构

### 1.1 双亲表示法
用一组连续空间存储结点，每个结点记录**双亲在数组中的下标**（根的双亲为 −1）。
```
        R                下标  data  parent
      / | \               0     R     -1
     A  B  C              1     A      0
    / \    |              2     B      0
   D   E   F              3     C      0
                          4     D      1
                          5     E      1
                          6     F      3
```
```c
#define MAX_TREE_SIZE 100
typedef struct {
    ElemType data;
    int parent;              // 双亲位置
} PTNode;
typedef struct {
    PTNode nodes[MAX_TREE_SIZE];
    int n;                   // 结点数
} PTree;
```
- ✅ **找双亲很快**，O(1)
- ❌ **找孩子要遍历整个数组**
- 应用：**并查集**（第 15 课）

### 1.2 孩子表示法
每个结点的**所有孩子**用一个**单链表**串起来，所有结点的数据和孩子链表的头指针存在一个数组里。
```
下标 data  firstchild
 0    R  → 1 → 2 → 3 → ^
 1    A  → 4 → 5 → ^
 2    B  → ^
 3    C  → 6 → ^
 4    D  → ^
 ...
```
- ✅ 找孩子方便
- ❌ 找双亲要遍历所有孩子链表
- 应用：图的**邻接表**（第 17 课）就是这种思想

### 1.3 孩子兄弟表示法（⭐⭐⭐ 二叉树表示法）
每个结点有两个指针：
- **firstchild**：指向**第一个孩子**
- **nextsibling**：指向**下一个兄弟**
```c
typedef struct CSNode {
    ElemType data;
    struct CSNode *firstchild, *nextsibling;
} CSNode, *CSTree;
```
🧒 这其实就是一棵**二叉树**：firstchild 当作左指针，nextsibling 当作右指针。**“左孩子，右兄弟”**。
- ✅ 方便地把树转换为二叉树，可以用二叉树的算法
- ✅ 找孩子方便
- ❌ 找双亲麻烦（可以再加一个 parent 指针）

## 二、树 ↔ 二叉树（⭐⭐⭐）

### 📐 树 → 二叉树（“左孩子右兄弟”）
**口诀：兄弟相连，只留长子**
1. **加线**：在所有**兄弟结点**之间加一条连线
2. **抹线**：对每个结点，**只保留它与第一个孩子（长子）的连线**，抹掉与其他孩子的连线
3. **旋转**：以根为轴，顺时针旋转 45°，使长子在左、兄弟在右

✏️ **例**：
```
原树：                   加线+抹线：                二叉树：
        R                    R                       R
      / | \                 /                       /
     A  B  C               A ─ B ─ C               A
    / \    |              /        |              / \
   D   E   F             D ─ E     F             D   B
                                                  \   \
                                                   E   C
                                                      /
                                                     F
```
**转换后的特点**：
- **根没有右孩子**（根没有兄弟）
- 二叉树中结点的**左孩子**是原树中它的**第一个孩子**
- 二叉树中结点的**右孩子**是原树中它的**下一个兄弟**

### 📐 二叉树 → 树（逆操作）
1. **加线**：若某结点是其双亲的**左孩子**，则把该结点的右孩子、右孩子的右孩子……（沿右链走下去的所有结点）都与该结点的**双亲**连起来
2. **抹线**：抹掉所有结点与其右孩子的连线
3. 调整

🧒 简单记：二叉树中，**顺着右链走的一串结点，在原树中是兄弟**，它们的双亲都是这串的第一个结点的双亲。

## 三、森林 ↔ 二叉树（⭐⭐⭐）

### 📐 森林 → 二叉树
1. 把森林中**每棵树**分别转换成二叉树
2. 第 1 棵树的根作为最终二叉树的根；**第 2 棵树（转换后）作为第 1 棵树根的右子树**，第 3 棵作为第 2 棵根的右子树……

🧒 把各棵树的**根看作兄弟**，用“左孩子右兄弟”连起来就行。

✏️ **例**：森林有三棵树 T1（A 有孩子 B、C、D）、T2（E 有孩子 F）、T3（G 有孩子 H、I，H 有孩子 J）
```
T1:   A        T2:  E       T3:   G
    / | \           |            / \
   B  C  D          F           H   I
                                |
                                J

转换后的二叉树：
            A
          /   \
         B     E
          \   / \
           C F   G
            \   /
             D H
              / \
             J   I
```
（B、C、D 是兄弟 → 沿右链；E 是 A 的“兄弟” → A 的右孩子；G 是 E 的“兄弟” → E 的右孩子；H、I 是兄弟；J 是 H 的长子 → H 的左孩子）

### 📐 二叉树 → 森林
1. 把二叉树的根及其**右链**上的结点（根、根的右孩子、右孩子的右孩子……）断开，每个都是一棵树的根
2. 对每棵二叉树按“二叉树 → 树”的方法转换

⭐ **重要推论**：二叉树从根开始**一直沿右指针走**，经过几个结点，森林中就有**几棵树**。

📝 **真题（2021 年第 4 题）**：某森林 F 对应的二叉树为 T，T 的先序序列 a, b, d, c, e, g, f，中序序列 b, d, a, e, g, c, f，则 F 中树的棵数是？
1. 还原 T：根 a；中序中 a 左边 {b, d}，右边 {e, g, c, f}
2. a 的右子树：先序 c, e, g, f → 根 c；中序 e, g, c, f → c 的左 {e, g}，右 {f}
3. c 的右子树只有 f
4. 右链：a → c → f，共 **3** 个结点 → 森林有 **3 棵树**，选 C

## 四、树和森林的遍历（⭐⭐⭐）

### 4.1 树的遍历
- **先根遍历**：先访问根，再**依次先根遍历**每棵子树
- **后根遍历**：先**依次后根遍历**每棵子树，再访问根
- **层次遍历**：按层

（树没有“中根遍历”，因为树的孩子个数不定，没法定义“中间”。）

✏️ 用第二节那棵树（R 的孩子 A、B、C；A 的孩子 D、E；C 的孩子 F）：
- 先根：R A D E B C F
- 后根：D E A B F C R

### 4.2 森林的遍历
- **先序遍历森林**：对**每棵树依次**进行先根遍历
- **中序遍历森林**（有的教材叫**后序遍历森林**）：对**每棵树依次**进行后根遍历

### 4.3 对应关系（⭐⭐⭐ 必背）
| 树 | 森林 | 对应的二叉树 |
|---|---|---|
| **先根遍历** | **先序遍历** | **先序遍历** |
| **后根遍历** | **中序遍历**（后序遍历） | **中序遍历** |

🧒 **记忆**：“先对先，后对中”。
为什么树的后根对应二叉树的**中序**？树的后根是“先孩子们，后自己”；在二叉树中，孩子们在**左子树**里，兄弟们在**右子树**里——“左子树（孩子们）→ 自己 → 右子树（兄弟们）”正是中序！

验证：上面的树转成二叉树后，二叉树的中序是 D E A B F C R，和树的后根遍历一样 ✓

📝 **真题（2020 年第 4 题）**：已知森林 F 及与之对应的二叉树 T，若 F 的**先根**遍历序列是 a, b, c, d, e, f，**中根**遍历序列是 b, a, d, f, e, c，则 T 的**后根（后序）**遍历序列是？
1. F 的先根 = T 的先序：a b c d e f
2. F 的中根 = T 的中序：b a d f e c
3. 还原 T：
   - 根 a；中序中 a 左边 {b}，右边 {d, f, e, c}
   - 右子树：先序 c d e f → 根 c；中序 d f e c → c 的左子树 {d, f, e}，无右子树
   - c 的左子树：先序 d e f → 根 d；中序 d f e → d 无左子树，右子树 {f, e}
   - d 的右子树：先序 e f → 根 e；中序 f e → f 是 e 的左孩子
4. T 的后序：b，然后 a 右子树的后序（f e d c），最后 a → **b, f, e, d, c, a**，选 C

## 五、转换相关的计数题（⭐⭐）

### 📐 常用结论
设森林（或树）转换成二叉树 T：
1. T 中结点的**左指针为空** ⟺ 原森林中该结点**没有孩子**（是叶子）
   → **森林的叶结点个数 = T 中左孩子指针为空的结点个数**
2. T 中结点的**右指针为空** ⟺ 原森林中该结点**是最后一个孩子**（没有下一个兄弟），或是最后一棵树的根
   → **T 中无右孩子的结点个数 = 原森林中分支结点个数 + 1**（对一棵树而言：每个分支结点的最后一个孩子无右兄弟，再加上根本身）

📝 **真题（2014 年真题）**：将森林 F 转换为对应的二叉树 T，F 中叶结点的个数等于？
→ **T 中左孩子指针为空的结点个数**

📝 **真题（2011 年真题）**：已知一棵有 2011 个结点的树，其叶结点个数为 116，该树对应的二叉树中**无右孩子**的结点个数是？
- 分支结点数 = 2011 − 116 = 1895
- 每个分支结点有且只有一个“最后的孩子”，它在二叉树中没有右孩子 → 1895 个
- 再加上**根**（树只有一个根，没有兄弟）→ 1895 + 1 = **1896**

📝 **真题（2009 年真题）**：将森林转换为对应的二叉树，若在二叉树中，结点 u 是结点 v 的**父结点的父结点**，则在原来的森林中，u 和 v 可能具有的关系是：
I. 父子关系 II. 兄弟关系 III. u 的父结点与 v 的父结点是兄弟关系
设二叉树中 u → x → v（u 是 x 的双亲，x 是 v 的双亲），分四种情况：
- x 是 u 的左孩子（x 是 u 的长子），v 是 x 的左孩子（v 是 x 的长子）→ u 是 v 的**祖父**
- x 是 u 的左孩子，v 是 x 的右孩子（v 是 x 的弟弟）→ v 也是 u 的孩子 → **父子** ✓
- x 是 u 的右孩子（x 是 u 的弟弟），v 是 x 的左孩子 → v 是 x 的孩子，u 是 v 的**叔伯**
- x 是 u 的右孩子，v 是 x 的右孩子 → u、x、v 都是兄弟 → **兄弟** ✓
所以可能是 I 和 II，III 不可能。选 **B**。

📝 **真题（2025 年第 4 题）**：关于二叉树及森林，正确的是：
- A. 完全二叉树中不存在度为 1 的结点 ✗（可能有 1 个）
- B. **任意一个森林都可以转换为一棵二叉树** ✓
- C. 二叉树的分支结点个数比叶结点个数少 ✗（n₀ = n₂ + 1，但分支结点还包括 n₁ 个度为 1 的，可能比叶子多）
- D. 表达式树（链式树）的根中保存的是最先计算的运算符 ✗（根是**最后**计算的运算符）
答案 **B**。

## ⚠️ 易错点
1. 树转二叉树：**根没有右孩子**；森林转二叉树：根可以有右孩子
2. 树没有中根遍历
3. 森林的“中序遍历”= 每棵树后根遍历
4. **树的后根 = 二叉树的中序**（不是后序！）
5. 二叉树的右链长度 = 森林中树的棵数

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 双亲表示法 | 找双亲 O(1)，找孩子难；并查集用它 |
| 孩子表示法 | 找孩子易；邻接表思想 |
| 孩子兄弟表示法 | 左 = 第一个孩子，右 = 下一个兄弟 |
| 树 → 二叉树 | 兄弟相连，只留长子；根无右孩子 |
| 森林 → 二叉树 | 各树根视为兄弟 |
| 遍历对应 | 树先根 = 森林先序 = 二叉先序；树后根 = 森林中序 = 二叉中序 |
| 计数结论 | 森林叶子数 = T 中左指针为空的结点数；树棵数 = 右链结点数 |

## 🏋️ 课后练习

1. 把下面的树转换成二叉树，并写出二叉树的先序和中序：
   ```
          A
        / | \
       B  C  D
      / \     \
     E   F     G
   ```
2. 一棵二叉树的先序是 A B C D E F，中序是 C B D A F E，它对应的森林有几棵树？每棵树的结点是什么？
3. 一个森林有 3 棵树，结点数分别为 n₁、n₂、n₃，转换成二叉树后，根的右子树有多少个结点？根的左子树呢？
4. 一棵树有 100 个结点，其中 60 个叶子，对应的二叉树中有多少个结点的左指针为空？右指针为空？

<details>
<summary>📖 答案</summary>

1. 二叉树：A 的左孩子 B；B 的左孩子 E、右孩子 C；E 的右孩子 F；C 的右孩子 D；D 的左孩子 G。先序：A B E F C D G；中序：E F B C G D A（= 树的后根遍历 ✓）
2. 根 A；中序中 A 左 {C, B, D}，右 {F, E}；A 的右子树先序 E F → 根 E，F 在 E 左边 → F 是 E 的左孩子。右链：A → E，共 **2 棵树**。左子树先序 B C D、中序 C B D → B 的左孩子 C、右孩子 D。“左孩子 = 长子、右孩子 = 弟弟”，所以 C 是 B 的孩子，D 是 B 的弟弟。第一棵树：根 A，孩子 B、D，B 的孩子 C；第二棵树：根 E，孩子 F
3. 右子树结点数 = **n₂ + n₃**；左子树 = **n₁ − 1**（第一棵树除根外的结点）
4. 左指针为空 = 叶子数 = **60**；右指针为空 = 分支结点数 + 1 = 40 + 1 = **41**
</details>
