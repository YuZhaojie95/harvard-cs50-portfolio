## 一、简单选择排序（⭐）

### 📐 思想
第 i 趟在后面 n − i + 1 个待排序元素中**选出最小的**，和第 i 个元素**交换**。经过 n − 1 趟，排序完成。

### 📐 代码
```c
void SelectSort(ElemType A[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min = i;                               // 记录最小元素的位置
        for (int j = i + 1; j < n; j++)
            if (A[j] < A[min]) min = j;
        if (min != i) swap(A[i], A[min]);          // 交换（移动 3 次）
    }
}
```

### ✏️ 过程演示
初始：**49 38 65 97 76 13 27 49̲**
```
第 1 趟: 13 | 38 65 97 76 49 27 49̲     （选出 13，与 49 交换）
第 2 趟: 13 27 | 65 97 76 49 38 49̲    （选出 27，与 38 交换）
第 3 趟: 13 27 38 | 97 76 49 65 49̲    
第 4 趟: 13 27 38 49 | 76 97 65 49̲    
第 5 趟: 13 27 38 49 49̲ | 97 65 76    
第 6 趟: 13 27 38 49 49̲ 65 | 97 76    
第 7 趟: 13 27 38 49 49̲ 65 76 97
```

### 📐 性能（⭐⭐）
- **比较次数**：永远是 (n−1) + (n−2) + … + 1 = **n(n−1)/2**，**与初始序列无关**
- **移动次数**：最好 0 次（已有序），最坏 **3(n−1)** 次（每趟交换一次，一次交换移动 3 次）——**移动次数是所有排序中最少的**之一
- 时间 **O(n²)**（最好、最坏、平均都是）
- 空间 **O(1)**
- **不稳定**：反例 **2 2̲ 1**，第 1 趟 2 与 1 交换 → 1 2̲ 2，两个 2 的顺序颠倒 ✗
- 适用于顺序表和链表
- 每一趟都能确定一个元素的**最终位置**

📝 **真题（2025 年第 10 题）**：下列排序算法中，**最坏情况下元素移动最少**的是：A. 冒泡排序 B. 直接插入排序 C. 快速排序 D. 简单选择排序
- 冒泡最坏：交换 n(n−1)/2 次
- 直接插入最坏：移动约 n²/2 次
- 快排最坏：O(n²) 次
- **简单选择最坏：3(n−1) 次**，O(n)
答案 **D**

## 二、堆（⭐⭐⭐）

### 📐 定义
n 个关键字序列 L[1..n]（下标从 1）称为**堆**，当且仅当满足：
- **大根堆（大顶堆）**：L(i) ≥ L(2i) 且 L(i) ≥ L(2i+1)（1 ≤ i ≤ n/2）
- **小根堆（小顶堆）**：L(i) ≤ L(2i) 且 L(i) ≤ L(2i+1)

🧒 **把堆看成一棵完全二叉树**（按层序编号，i 的孩子是 2i 和 2i+1）：
- **大根堆**：每个结点都 ≥ 它的孩子 → **根是最大的**
- **小根堆**：每个结点都 ≤ 它的孩子 → **根是最小的**

```
大根堆 [87, 45, 78, 32, 17, 65, 53, 09]：
              87
           /      \
         45        78
        /  \      /  \
      32   17   65    53
      /
    09
```

### 📐 堆的性质（⭐⭐ 选择题）
📝 **真题（2020 年第 9 题）**：下列关于大根堆（至少含 2 个元素）的叙述中，正确的是：
I. 可以将堆视为一棵完全二叉树 ✓
II. 可以采用顺序存储方式保存堆 ✓（完全二叉树最适合顺序存储）
III. 可以将堆视为一棵二叉排序树 ✗（堆只规定“上下”关系，不管“左右”：左孩子可能比右孩子大）
IV. 堆中的**次大值一定在根的下一层** ✓（次大值的双亲必须比它大，只能是最大值——根）
答案 **I、II、IV**，选 C

补充：
- 堆中**最小值**（大根堆）一定在**叶结点**中，但不知道是哪个叶子
- 堆的中序遍历、层序遍历**都不一定有序**

## 三、建堆（⭐⭐⭐）

### 📐 下沉（向下调整，sift down）
对以 k 为根的子树，若它的左右子树都已经是堆，但 k 本身可能比孩子小：
1. 找出 k 的两个孩子中**较大的**那个 j
2. 若 A[k] ≥ A[j]，已经是堆，结束
3. 否则交换 A[k] 和 A[j]，然后对 j 继续下沉

```c
void HeadAdjust(ElemType A[], int k, int len) {   // 将以 k 为根的子树调整为大根堆
    A[0] = A[k];                                  // A[0] 暂存子树的根
    for (int i = 2 * k; i <= len; i *= 2) {       // 沿较大的孩子向下筛选
        if (i < len && A[i] < A[i + 1]) i++;      // 取较大的孩子
        if (A[0] >= A[i]) break;                  // 根已经最大，结束
        A[k] = A[i];                              // 较大的孩子上移
        k = i;                                    // 继续向下
    }
    A[k] = A[0];                                  // 放入最终位置
}
```
**比较次数**：每下沉一层，要比较 **2 次**（两个孩子比一次、较大者与根比一次）；只有一个孩子时比 1 次。

### 📐 建堆（自下而上）
**从最后一个分支结点 ⌊n/2⌋ 开始，往前依次对每个结点做下沉**，直到根。
```c
void BuildMaxHeap(ElemType A[], int len) {
    for (int i = len / 2; i > 0; i--)
        HeadAdjust(A, i, len);
}
```
**建堆的时间复杂度是 O(n)**（⭐ 重要结论，不是 O(n log n)！）
🧒 大多数结点在树的底部，下沉距离很短；只有少数上层结点下沉距离长。仔细求和总比较次数不超过 4n。

### ✏️ 例：将 {53, 17, 78, 09, 45, 65, 87, 32} 建成大根堆（⭐ 一定要跟着做）
n = 8，从 ⌊8/2⌋ = 4 开始：
```
初始（层序）:
              53
           /      \
         17        78
        /  \      /  \
      09   45   65    87
      /
    32
```
| 步骤 | 下沉结点 | 过程 | 序列 |
|---|---|---|---|
| i=4 | 09 | 孩子只有 32 > 09 → 交换 | 53 17 78 **32** 45 65 87 **09** |
| i=3 | 78 | 孩子 65、87 中较大 87 > 78 → 交换 | 53 17 **87** 32 45 65 **78** 09 |
| i=2 | 17 | 孩子 32、45 中较大 45 > 17 → 交换；17 到了位置 5，无孩子 | 53 **45** 87 32 **17** 65 78 09 |
| i=1 | 53 | 孩子 45、87 中较大 87 → 交换；53 到位置 3，孩子 65、78 中较大 78 > 53 → 交换 | **87** 45 **78** 32 17 65 **53** 09 |

建好的大根堆：**87 45 78 32 17 65 53 09**（就是上面“定义”里画的那棵）

📝 **经典真题（2018 年真题）**：在将数据序列 (6, 1, 5, 9, 8, 4, 7) 建成大根堆时，正确的序列变化过程是？
- i = 3（5）：孩子 4、7，较大 7 > 5 → 交换 → **6, 1, 7, 9, 8, 4, 5**
- i = 2（1）：孩子 9、8，较大 9 → 交换 → **6, 9, 7, 1, 8, 4, 5**（1 到了位置 4，无孩子）
- i = 1（6）：孩子 9、7，较大 9 → 交换；6 到位置 2，孩子 1、8，较大 8 > 6 → 交换 → **9, 8, 7, 1, 6, 4, 5**
变化过程：6,1,7,9,8,4,5 → 6,9,7,1,8,4,5 → 9,8,7,1,6,4,5

## 四、堆的插入与删除（⭐⭐）

### 📐 插入（上浮，sift up）
1. 把新元素放在**堆的末尾**（完全二叉树最后一个位置的下一个）
2. 与**双亲**（⌊i/2⌋）比较，若比双亲大（大根堆），交换
3. 继续向上，直到不比双亲大或到达根
- 每上浮一层比较 **1 次**，时间 O(log n)

📝 **真题（2021 年第 11 题）**：将关键字 6, 9, 1, 5, 8, 4, 7 **依次插入**到初始为空的大根堆 H 中，得到的 H 是？
```
插 6:  [6]
插 9:  [6, 9]          9 > 6（双亲）→ 交换 → [9, 6]
插 1:  [9, 6, 1]       1 < 9，不动
插 5:  [9, 6, 1, 5]    5 的双亲是位置 2 的 6，5 < 6，不动
插 8:  [9, 6, 1, 5, 8] 8 的双亲是位置 2 的 6，8 > 6 → 交换 → [9, 8, 1, 5, 6]；8 的双亲 9，不动
插 4:  [9, 8, 1, 5, 6, 4]  4 的双亲是位置 3 的 1，4 > 1 → 交换 → [9, 8, 4, 5, 6, 1]
插 7:  [9, 8, 4, 5, 6, 1, 7]  7 的双亲是位置 3 的 4，7 > 4 → 交换 → [9, 8, 7, 5, 6, 1, 4]
```
H = **9, 8, 7, 5, 6, 1, 4**，选 B
⚠️ **“依次插入”建堆**和**“自下而上”建堆**的结果**可能不同**！题目说“依次插入”就一个个上浮，说“建堆”就用 ⌊n/2⌋ 往前下沉的方法。

### 📐 删除堆顶
1. 把**最后一个元素**移到堆顶（替代被删的堆顶）
2. 堆长度减 1
3. 对新堆顶做**下沉**
- 时间 O(log n)

📝 **经典真题（2015 年真题）**：已知小根堆为 8, 15, 10, 21, 34, 16, 12，删除关键字 8 之后需重建堆，在此过程中，关键字之间的比较次数是？
1. 最后一个元素 12 移到堆顶：12, 15, 10, 21, 34, 16
2. 12 下沉：孩子 15 和 10 比较（**第 1 次**），较小的是 10；12 与 10 比较（**第 2 次**），12 > 10 → 交换 → 10, 15, 12, 21, 34, 16
3. 12 在位置 3，只有一个孩子 16（位置 6），12 与 16 比较（**第 3 次**），12 < 16，结束
共 **3** 次

## 五、堆排序（⭐⭐⭐）

### 📐 思想
1. 先把 n 个元素**建成大根堆**
2. 把**堆顶（最大值）与堆的最后一个元素交换**，最大值就放到了最终位置
3. 把剩下的 n − 1 个元素**重新调整成堆**（只需对新堆顶下沉一次）
4. 重复 2、3，直到堆中只剩一个元素

**大根堆排出来是递增序列**（每次把最大的放到后面）。

```c
void HeapSort(ElemType A[], int len) {
    BuildMaxHeap(A, len);                  // 初始建堆
    for (int i = len; i > 1; i--) {        // n-1 趟交换和调整
        swap(A[i], A[1]);                  // 堆顶与堆底交换
        HeadAdjust(A, 1, i - 1);           // 调整剩余 i-1 个元素为堆
    }
}
```

### ✏️ 过程演示（接着上面建好的堆 87 45 78 32 17 65 53 09）
| 趟 | 交换堆顶与末尾，再下沉 | 结果（竖线后是已排好的） |
|---|---|---|
| 1 | 87↔09，09 下沉 | 78 45 65 32 17 09 53 \| 87 |
| 2 | 78↔53，53 下沉 | 65 45 53 32 17 09 \| 78 87 |
| 3 | 65↔09，09 下沉 | 53 45 09 32 17 \| 65 78 87 |
| 4 | 53↔17，17 下沉 | 45 32 09 17 \| 53 65 78 87 |
| 5 | 45↔17，17 下沉 | 32 17 09 \| 45 53 65 78 87 |
| 6 | 32↔09，09 下沉 | 17 09 \| 32 45 53 65 78 87 |
| 7 | 17↔09 | 09 \| 17 32 45 53 65 78 87 |
最终：**09 17 32 45 53 65 78 87**

### 📐 性能
- 建堆 O(n)，每次调整 O(log n)，共 n − 1 次 → **O(n log n)**（最好、最坏、平均都是）
- 空间 **O(1)**
- **不稳定**：反例 **{2, 2̲, 1}**（本身已是大根堆）：第 1 趟堆顶 2 与末尾 1 交换 → 1, 2̲ | 2，下沉 → 2̲, 1 | 2；第 2 趟 2̲ 与 1 交换 → 1 | 2̲, 2。最终 1 2̲ 2，两个 2 的顺序颠倒 ✗
- 只适用于**顺序存储**
- 每一趟确定一个元素的最终位置（最大值）
- 适合**从大量元素中选出前几个最大/最小的**

## 六、堆的应用：Top-K 问题（⭐⭐ 2022 年第 42 题）

📝 **真题（2022 年第 42 题，10 分）**：现有 n（n > 100000）个数保存在一维数组 M 中，需要查找 M 中**最小的 10 个数**。请回答：
(1) 设计一个完成上述查找任务的算法，要求平均情况下的比较次数尽可能少，简述其算法思想（不需要程序实现）。
(2) 说明你所设计的算法平均情况下的时间复杂度和空间复杂度。

**答**：
(1) **算法思想**：用一个含 10 个元素的**大根堆**（堆顶是这 10 个数中最大的）。
- 先用 M 的前 10 个数建立大根堆
- 依次扫描剩下的 n − 10 个数，每个数与堆顶比较：
  - 若**比堆顶小**：用它替换堆顶，然后对堆顶做下沉调整，重新成为大根堆
  - 若比堆顶大或相等：丢弃
- 扫描结束后，堆中的 10 个数就是最小的 10 个数

🧒 **为什么用大根堆找最小的？** 堆里存的是“目前为止最小的 10 个候选”，堆顶是其中**最大的**——也就是**入围门槛**。新来的数只要比门槛小，就能挤掉门槛进入候选；否则直接淘汰。

(2) **复杂度**：每个元素最多与堆顶比较 1 次，调整一次需 O(log 10) = O(1)，所以时间复杂度 **O(n)**；堆的大小固定为 10，空间复杂度 **O(1)**。

**另一种可行方法**：做 10 趟简单选择（或冒泡），每趟选出一个最小的，比较次数约 10n，时间 O(n)，空间 O(1)。但平均比较次数比堆的方法多（堆的方法中大部分元素只需比较 1 次）。

> 💡 同理：找**最大**的 k 个数，用**小根堆**。

## ⚠️ 易错点
1. 简单选择：比较次数**永远** n(n−1)/2；移动次数最少（最坏 3(n−1)）
2. 简单选择、堆排序都**不稳定**
3. 建堆从 **⌊n/2⌋** 开始往前下沉；建堆时间 **O(n)**
4. “依次插入”建堆（上浮）与“自下而上”建堆（下沉）结果可能不同
5. 下沉每层比较 2 次（只有一个孩子时 1 次）；上浮每层 1 次
6. 大根堆 → 递增排序；Top-K 最小用大根堆
7. 堆不是二叉排序树

## 📋 本课小结

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|---|
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | ✗ |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | ✗ |

| 堆操作 | 方法 | 时间 |
|---|---|---|
| 建堆 | 从 ⌊n/2⌋ 往前逐个下沉 | O(n) |
| 插入 | 放末尾，上浮 | O(log n) |
| 删除堆顶 | 末尾元素移到堆顶，下沉 | O(log n) |
| 堆排序 | 建堆 + (n−1) 次“交换 + 下沉” | O(n log n) |
