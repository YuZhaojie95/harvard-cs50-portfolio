# 数据结构 第 18 课 · 图的遍历：BFS 与 DFS

> 🎯 **本课目标**
> 1. **掌握广度优先搜索（BFS）**：思想、代码（队列）、手工求序列、复杂度、生成树、求无权图最短路径
> 2. **掌握深度优先搜索（DFS）**：思想、代码（递归/栈）、手工求序列、复杂度、生成树/森林
> 3. 能用遍历判断**连通性**、求**连通分量个数**、判断两点之间是否有路径
> 4. 能判断一个序列**是否可能是** BFS/DFS 序列，能数出可能的序列个数
>
> 408 真题：2012、2015、2020 年等都考过。BFS 和 DFS 也是后面**最小生成树、最短路径、拓扑排序**的基础。

---

## 🚪 课前引入：找人的两种方法

你在一个大迷宫般的商场里走丢了，要找朋友。
- **方法 A（BFS）**：先把离你**一步之遥**的所有店都看一遍，再看两步之遥的所有店……像**水波纹**一圈圈扩散
- **方法 B（DFS）**：选一条路**一直走到底**，走不通了**退回上一个路口**，换一条没走过的路继续……像**走迷宫**

两种方法都能把商场每家店看一遍，这就是**图的遍历**：从某个顶点出发，**每个顶点访问且仅访问一次**。

**图遍历的难点**：图中可能有**回路**，走着走着会回到访问过的顶点。所以要用一个 **visited[] 数组**记录每个顶点是否访问过。

---

## 一、广度优先搜索 BFS（⭐⭐⭐）

### 📐 思想
类似**二叉树的层序遍历**：
1. 访问起点 v
2. 依次访问 v 的**所有未访问过的邻接点** w₁, w₂, …
3. 再依次访问 w₁ 的所有未访问邻接点、w₂ 的所有未访问邻接点……
4. 直到所有能到达的顶点都被访问

**用队列**：先访问的顶点，它的邻接点也要先访问 → 先进先出。

### 📐 代码
```c
bool visited[MAX_VERTEX_NUM];           // 访问标记数组

void BFS(Graph G, int v) {              // 从顶点 v 出发广度优先遍历
    visit(v);
    visited[v] = true;
    EnQueue(Q, v);
    while (!IsEmpty(Q)) {
        DeQueue(Q, v);                  // 队头顶点出队
        for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w)) {
            if (!visited[w]) {          // w 是 v 的尚未访问的邻接点
                visit(w);
                visited[w] = true;      // ⚠️ 入队时就标记，防止重复入队
                EnQueue(Q, w);
            }
        }
    }
}

void BFSTraverse(Graph G) {             // 对整个图进行 BFS（可能不连通）
    for (int i = 0; i < G.vexnum; i++) visited[i] = false;
    InitQueue(Q);
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i])                // 对每个连通分量调用一次 BFS
            BFS(G, i);
}
```
⚠️ **为什么要有 BFSTraverse？** 如果图**不连通**，从一个顶点出发只能访问它所在的连通分量。所以要对每个没访问过的顶点都调用一次 BFS。
📐 **对无向图，调用 BFS 的次数 = 连通分量的个数**。

### ✏️ 手工求 BFS 序列
```
      1 ─── 2 ─── 5
      │     │
      3 ─── 4
      │
      6
邻接点按编号从小到大：
1: 2, 3        2: 1, 4, 5     3: 1, 4, 6
4: 2, 3        5: 2           6: 3
```
从 1 出发：
| 步骤 | 出队 | 访问并入队的新顶点 | 队列 |
|---|---|---|---|
| 初始 | — | 1 | [1] |
| 1 | 1 | 2, 3 | [2, 3] |
| 2 | 2 | 4, 5（1 已访问） | [3, 4, 5] |
| 3 | 3 | 6（1、4 已访问） | [4, 5, 6] |
| 4 | 4 | —（2、3 已访问） | [5, 6] |
| 5 | 5 | — | [6] |
| 6 | 6 | — | [] |
BFS 序列：**1, 2, 3, 4, 5, 6**

⚠️ **BFS 序列的唯一性**：
- 用**邻接矩阵**存储：邻接点按下标顺序，BFS 序列**唯一**
- 用**邻接表**存储：邻接点按链表顺序，而邻接表不唯一，所以 BFS 序列**不唯一**

### 📐 复杂度
每个顶点入队一次，每条边（或每个邻接关系）检查一次：
| 存储 | 时间 | 原因 |
|---|---|---|
| 邻接矩阵 | **O(\|V\|²)** | 每个顶点找邻接点要扫描一整行 |
| 邻接表 | **O(\|V\| + \|E\|)** | 每个顶点 O(1)，每个边结点 O(1) |
空间：队列和 visited 数组，**O(\|V\|)**

📝 **真题（2012 年真题）**：对有 n 个结点、e 条边且使用**邻接表**存储的有向图进行广度优先遍历，时间复杂度是？→ **O(n + e)**

### 📐 BFS 求单源最短路径（无权图，⭐⭐）
**无权图**（或所有边权相同）中，BFS **第一次访问到某顶点时经过的边数，就是起点到它的最短路径长度**。
🧒 因为 BFS 是一圈一圈往外扩的，离起点近的一定先被访问。
```c
void BFS_MIN_Distance(Graph G, int u) {
    int d[MAX_VERTEX_NUM], path[MAX_VERTEX_NUM];
    for (int i = 0; i < G.vexnum; i++) { d[i] = INF; path[i] = -1; }
    d[u] = 0; visited[u] = true;
    EnQueue(Q, u);
    while (!IsEmpty(Q)) {
        DeQueue(Q, u);
        for (int w = FirstNeighbor(G, u); w >= 0; w = NextNeighbor(G, u, w))
            if (!visited[w]) {
                visited[w] = true;
                d[w] = d[u] + 1;        // 路径长度加 1
                path[w] = u;            // 记录前驱，用于还原路径
                EnQueue(Q, w);
            }
    }
}
```
上图从 1 出发：d[2] = d[3] = 1，d[4] = d[5] = d[6] = 2。

### 📐 广度优先生成树
BFS 过程中，把“**从 v 访问到 w**”的边保留下来，就得到一棵**广度优先生成树**（非连通图得到**生成森林**）。
上例的广度优先生成树：边 (1,2)、(1,3)、(2,4)、(2,5)、(3,6)
- 邻接矩阵存储时生成树**唯一**；邻接表存储时**不唯一**
- BFS 生成树的高度是**最小的**（从根到每个顶点的路径都是最短路径）

## 二、深度优先搜索 DFS（⭐⭐⭐）

### 📐 思想
类似**树的先序遍历**：
1. 访问起点 v
2. 找 v 的**第一个未访问**的邻接点 w，从 w 出发**递归**进行 DFS
3. w 这条路走完了，**回退**到 v，再找 v 的下一个未访问邻接点，继续
4. 直到 v 的所有邻接点都访问过

**用栈**（递归本身就是用系统栈）：后访问的顶点先回溯。

### 📐 代码
```c
bool visited[MAX_VERTEX_NUM];

void DFS(Graph G, int v) {
    visit(v);
    visited[v] = true;
    for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w))
        if (!visited[w])
            DFS(G, w);                  // 递归访问 w
}

void DFSTraverse(Graph G) {
    for (int v = 0; v < G.vexnum; v++) visited[v] = false;
    for (int v = 0; v < G.vexnum; v++)
        if (!visited[v])                // 每个连通分量调用一次
            DFS(G, v);
}
```

### ✏️ 手工求 DFS 序列（同上图，从 1 出发，邻接点从小到大）
```
访问 1 → 1 的第一个未访问邻接点 2
  访问 2 → 2 的邻接点：1（已访问）、4
    访问 4 → 4 的邻接点：2（已访问）、3
      访问 3 → 3 的邻接点：1、4（已访问）、6
        访问 6 → 6 的邻接点 3 已访问 → 回退
      3 的邻接点都访问完 → 回退
    4 完 → 回退
  2 的下一个邻接点 5
    访问 5 → 回退
  2 完 → 回退
1 的下一个邻接点 3 已访问 → 结束
```
DFS 序列：**1, 2, 4, 3, 6, 5**

**递归调用栈的变化**：
```
[1] → [1,2] → [1,2,4] → [1,2,4,3] → [1,2,4,3,6] → [1,2,4,3] → [1,2,4] → [1,2] → [1,2,5] → [1,2] → [1] → []
```

### 📐 复杂度
和 BFS 完全一样：
| 存储 | 时间 |
|---|---|
| 邻接矩阵 | **O(\|V\|²)** |
| 邻接表 | **O(\|V\| + \|E\|)** |
空间：递归栈最深 O(\|V\|)

### 📐 深度优先生成树（森林）
DFS 过程中经过的边构成**深度优先生成树**。上例：(1,2)、(2,4)、(4,3)、(3,6)、(2,5)

### 📐 DFS 的非递归实现
用一个栈：顶点入栈时访问；取栈顶，找它的一个未访问邻接点，访问并入栈；没有未访问邻接点就出栈。

## 三、BFS vs DFS 对比

| | BFS | DFS |
|---|---|---|
| 类比 | 树的层序遍历 | 树的先序遍历 |
| 辅助结构 | **队列** | **栈**（递归） |
| 邻接矩阵时间 | O(\|V\|²) | O(\|V\|²) |
| 邻接表时间 | O(\|V\|+\|E\|) | O(\|V\|+\|E\|) |
| 空间 | O(\|V\|) | O(\|V\|) |
| 特有用途 | **无权图单源最短路径** | **拓扑排序、判断有向图是否有环、求关键路径** |
| 序列唯一性 | 邻接矩阵唯一；邻接表不唯一 | 同左 |

## 四、图的遍历与连通性（⭐⭐）

1. **无向图**：调用 BFS/DFS 的**次数 = 连通分量个数**；若从任一顶点出发一次就能访问所有顶点，则图**连通**
2. **有向图**：从一个顶点出发能否访问所有顶点，与**起点**有关。
   - 若从**任一**顶点出发都能访问到所有顶点 → 强连通
   - 非强连通的有向图，调用次数**不一定**等于强连通分量个数
3. **判断顶点 i 到 j 是否有路径**：从 i 出发做 BFS 或 DFS，看 j 是否被访问到

```c
bool HasPath(ALGraph G, int i, int j) {    // DFS 判断 i 到 j 是否有路径
    if (i == j) return true;
    visited[i] = true;
    for (ArcNode *p = G.vertices[i].first; p != NULL; p = p->next) {
        int k = p->adjvex;
        if (!visited[k] && HasPath(G, k, j)) return true;
    }
    return false;
}
```

## 五、判断遍历序列 & 计数（⭐⭐ 选择题）

### 📐 判断一个序列是不是 DFS 序列
**规则**：DFS 访问完 u 之后，下一个访问的顶点 w 必须是：
- u 的某个**未访问**的邻接点；或者
- u 已经“走投无路”（所有邻接点都访问过了），**回溯**到最近的、还有未访问邻接点的祖先 x，w 是 x 的邻接点

### 📐 判断一个序列是不是 BFS 序列
**规则**：BFS 是**按层**的，而且**先被访问的顶点，它的邻接点也要先被访问**。
检查：对序列中的每个顶点，它的“新邻接点”应该连续出现在队列（序列）中，且顺序与其“父亲”的顺序一致。

📝 **真题（2015 年真题）**：设有向图 G = (V, E)，V = {v₀, v₁, v₂, v₃}，E = {<v₀,v₁>, <v₀,v₂>, <v₀,v₃>, <v₁,v₃>}。若从 v₀ 开始对图进行**深度优先遍历**，可能得到的不同遍历序列个数是？
```
      v0
    ↙  ↓  ↘
  v1   v2   v3
    ↘______↗
   （v1 → v3）
```
v₀ 之后可以先去 v₁、v₂ 或 v₃：
- **先去 v₁**：v₁ → v₃（v₁ 唯一的出边）→ 回到 v₀ → v₂：序列 **v₀ v₁ v₃ v₂**（1 种）
- **先去 v₂**：v₂ 没有出边，回到 v₀，再选 v₁ 或 v₃：
  - 选 v₁：v₁ → v₃：**v₀ v₂ v₁ v₃**
  - 选 v₃：v₃ 之后回 v₀ 选 v₁：**v₀ v₂ v₃ v₁**
- **先去 v₃**：v₃ 没有出边，回到 v₀，选 v₁ 或 v₂：
  - 选 v₁：v₁ 的出边 v₃ 已访问，回 v₀ 选 v₂：**v₀ v₃ v₁ v₂**
  - 选 v₂：**v₀ v₃ v₂ v₁**
共 **5** 种。

📝 **真题（2020 年第 6 题）**：修改递归方式实现的图的深度优先搜索（DFS）算法，将输出（访问）顶点信息的语句**移到退出递归前**（即执行输出语句后立刻退出递归）。采用修改后的算法遍历**有向无环图** G，若输出结果中包含 G 中的全部顶点，则输出的顶点序列是 G 的？
🧒 修改后，一个顶点要等它**所有能到达的顶点都输出完**后才输出。在有向无环图中，若有弧 <u, v>，v 一定比 u **先**输出。这正是**逆拓扑有序序列**。
答案 **B（逆拓扑有序序列）**。（第 21 课会用它来求拓扑排序）

## ⚠️ 易错点
1. 图可能不连通，要用 Traverse 函数对每个未访问顶点调用
2. BFS 在**入队时**就标记 visited，否则同一个顶点可能多次入队
3. 邻接矩阵 O(V²)，邻接表 O(V+E)——BFS、DFS 一样
4. 邻接表存储时遍历序列和生成树**不唯一**
5. BFS 只能求**无权图**的最短路径
6. 有向图的遍历结果与起点有关

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| BFS | 队列；层层扩展；入队时标记 |
| DFS | 递归/栈；一条路走到底，回溯 |
| 时间 | 邻接矩阵 O(\|V\|²)；邻接表 O(\|V\|+\|E\|) |
| 空间 | O(\|V\|) |
| 调用次数 | 无向图 = 连通分量数 |
| BFS 应用 | 无权图单源最短路径；生成树高度最小 |
| DFS 应用 | 拓扑排序、判环、关键路径；退出递归时输出 = 逆拓扑序 |
| 唯一性 | 邻接矩阵唯一，邻接表不唯一 |

1. 邻接关系：A: B, C；B: A, D, E；C: A, D；D: B, C, G；E: B, F；F: E；G: D。

5. BFS 从 v 出发，最后一个出队（被访问）的顶点就是距离 v 最远的顶点之一（BFS 按距离由近到远访问）
