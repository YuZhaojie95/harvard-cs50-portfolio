# 数据结构 第 28 课 · 交换类排序（冒泡排序、快速排序）

> 🎯 **本课目标**
> 1. 掌握冒泡排序：代码（带提前结束标志）、每趟结果、复杂度、稳定性
> 2. **彻底掌握快速排序**：划分（Partition）代码、手工模拟一趟划分、递归过程、最好/最坏/平均复杂度、空间复杂度、不稳定性
> 3. 会判断“某序列是否可能是快排第 k 趟的结果”，会找“这次划分的枢轴”
>
> 快速排序是**平均性能最好**的内部排序，也是 408 最爱考的排序之一：2023 年第 11 题（找枢轴），2022 年第 11 题（为什么不用快排），历年多次考“第二趟结果”。

## 🚪 课前引入：排队时交换位置

- **冒泡**：体育课按身高排队，老师从队尾开始，**两两比较相邻的同学**，高的往后站……一趟下来最矮的“浮”到了最前面
- **快排**：选一个同学当“**标杆**”，比他矮的站左边，比他高的站右边。标杆的位置就确定了。然后左右两边各自再选标杆……

两种方法的核心动作都是“**交换**”。

## 一、冒泡排序（⭐）

### 📐 思想
从后往前（或从前往后）**两两比较相邻元素**，若逆序则交换。一趟下来，**最小的元素“冒”到最前面**（或最大的沉到最后），它的位置就**确定**了。下一趟不再考虑它。最多 n − 1 趟。

### 📐 代码（从后往前冒，带标志）
```c
void BubbleSort(ElemType A[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool flag = false;                    // 本趟是否发生交换
        for (int j = n - 1; j > i; j--)       // 从后往前比较
            if (A[j - 1] > A[j]) {            // 逆序则交换（不含相等 → 稳定）
                swap(A[j - 1], A[j]);
                flag = true;
            }
        if (flag == false) return;            // 本趟没有交换，说明已经有序
    }
}
```

### ✏️ 过程演示
初始：**49 38 65 97 76 13 27 49̲**
```
第 1 趟: 13 49 38 65 97 76 27 49̲    （13 冒到最前）
第 2 趟: 13 27 49 38 65 97 76 49̲    （27 就位）
第 3 趟: 13 27 38 49 49̲ 65 97 76    （38 就位）
第 4 趟: 13 27 38 49 49̲ 65 76 97    （49 就位）
第 5 趟: 没有交换 → 提前结束
```

### 📐 性能
| | 比较次数 | 交换次数 | 时间 |
|---|---|---|---|
| **最好**（已有序） | n − 1（一趟无交换就结束） | 0 | **O(n)** |
| **最坏**（逆序） | n(n−1)/2 | n(n−1)/2（移动 3n(n−1)/2 次） | **O(n²)** |
| 平均 | | | **O(n²)** |
- 空间 **O(1)**，**稳定**（相等不交换）
- **每一趟都能确定一个元素的最终位置**（全局有序：前面已确定的元素都在最终位置）
- 冒泡产生的有序子序列是**全局有序**的（与直接插入不同：直接插入前面有序但不是最终位置）

## 二、快速排序（⭐⭐⭐）

### 📐 思想（分治）
1. 在待排序表中任取一个元素 **pivot（枢轴）**，通常取**第一个**元素
2. 通过**一趟排序（划分）**，把表分成两部分：左边的元素都 **≤ pivot**，右边的都 **≥ pivot**，pivot 放在它的**最终位置**上
3. 对左右两部分**分别递归**进行快速排序，直到每部分只有 1 个或 0 个元素

### 📐 划分（Partition）代码（⭐⭐⭐ 必须能默写）
```c
int Partition(ElemType A[], int low, int high) {
    ElemType pivot = A[low];                   // 第一个元素作为枢轴，A[low] 空出来
    while (low < high) {
        while (low < high && A[high] >= pivot) --high;
        A[low] = A[high];                      // 比枢轴小的移到左端（填 low 的坑）
        while (low < high && A[low] <= pivot) ++low;
        A[high] = A[low];                      // 比枢轴大的移到右端（填 high 的坑）
    }
    A[low] = pivot;                            // 枢轴放到最终位置
    return low;                                // 返回枢轴的位置
}

void QuickSort(ElemType A[], int low, int high) {
    if (low < high) {
        int pivotpos = Partition(A, low, high);
        QuickSort(A, low, pivotpos - 1);       // 递归左子表
        QuickSort(A, pivotpos + 1, high);      // 递归右子表
    }
}
```
🧒 **“挖坑填坑”理解**：把 pivot 拿出来，low 处就有一个“坑”。
1. high 从右往左找**比 pivot 小**的，找到了就填到 low 的坑里，现在 high 处成了坑
2. low 从左往右找**比 pivot 大**的，找到了就填到 high 的坑里，现在 low 处成了坑
3. 交替进行，直到 low 和 high 相遇，把 pivot 放进最后的坑里

### ✏️ 手工模拟一趟划分（⭐⭐⭐ 一定要自己跟一遍）
初始：**49 38 65 97 76 13 27 49̲**（下标 0~7），pivot = 49
```
下标:        0   1   2   3   4   5   6   7
初始:       [49] 38  65  97  76  13  27  49̲     pivot=49，low=0（坑），high=7

① high 往左找 <49：49̲ 不小于(≥49，high--)，27 < 49 → 填到 low=0
            27  38  65  97  76  13  [ ]  49̲     坑在 high=6
② low 往右找 >49：27、38 不大于，65 > 49（low=2）→ 填到 high=6
            27  38  [ ] 97  76  13  65  49̲     坑在 low=2
③ high 往左找 <49：65 不小于(high=5)，13 < 49 → 填到 low=2
            27  38  13  97  76  [ ] 65  49̲     坑在 high=5
④ low 往右找 >49：13 不大于(low=3)，97 > 49 → 填到 high=5
            27  38  13  [ ] 76  97  65  49̲     坑在 low=3
⑤ high 往左找 <49：97 不小于(high=4)，76 不小于(high=3)，low == high，停
⑥ pivot 放入 low=3
结果:       27  38  13  49  76  97  65  49̲
```
49 左边都 ≤ 49，右边都 ≥ 49，**49 在最终位置**。

**后续递归**：
```
第 1 趟后:   [27 38 13] 49 [76 97 65 49̲]
左 [27 38 13] 以 27 为枢轴 → [13] 27 [38]
右 [76 97 65 49̲] 以 76 为枢轴 → [49̲ 65] 76 [97]
[49̲ 65] 以 49̲ 为枢轴 → 49̲ [65]
最终:        13 27 38 49 49̲ 65 76 97
```
**递归树**（每个结点是一次 Partition 的枢轴）：
```
            49
          /    \
        27      76
       /  \    /  \
     13   38  49̲   97
                \
                 65
```

### 📐 性能分析（⭐⭐⭐）
**时间**：每一层递归的 Partition 总共处理 O(n) 个元素，递归**深度**决定总时间。
- **最好**：每次枢轴都把表**平分**，递归深度 log₂n → **O(n log n)**
- **最坏**：每次枢轴都是**最大或最小**的元素（表**本来就有序或逆序**），划分极不平衡（0 和 n−1），递归深度 n → **O(n²)**
  - 比较次数 (n−1) + (n−2) + … + 1 = n(n−1)/2
- **平均**：**O(n log n)**，而且常数很小，是**所有内部排序算法中平均性能最优**的

**空间**：递归需要**栈**
- 最好 **O(log n)**，最坏 **O(n)**，平均 **O(log n)**

**稳定性**：**不稳定**
- 反例：**3 2 2̲**，pivot = 3：high 找到 2̲ < 3 填到位置 0 → 2̲ 2 _ … 最终 2̲ 2 3，两个 2 的顺序颠倒 ✗

### 📐 优化方法（了解）
- **枢轴选取**：取头、尾、中间三个元素的**中值**作为枢轴（三数取中），或**随机**选取，避免有序时退化
- 递归到子表很小时（如 < 10 个元素），改用直接插入排序

### 📐 “趟”的定义与第 k 趟结果（⭐⭐）
**定义**：对**尚未确定最终位置的所有元素**进行一遍处理称为一“趟”。
- 第 1 趟：对整个表划分一次，确定 **1** 个元素
- 第 2 趟：对第 1 趟产生的左、右两个子表**各**划分一次
  - 若第 1 趟的枢轴在表的**最左或最右端**（另一侧子表为空），第 2 趟只划分一个子表 → 第 2 趟后**至少 2 个**元素在最终位置
  - 否则第 2 趟划分两个子表 → **至少 3 个**元素在最终位置

**判断方法**：找出序列中**所有“已在最终位置”的元素**（它左边都比它小、右边都比它大），检查数量和分布是否符合上面的规律。

📝 **经典真题（2019 年真题）**：排序过程中，对尚未确定最终位置的所有元素进行一遍处理称为一“趟”。下列序列中，**不可能**是快速排序第二趟结果的是：
A. 5, 2, 16, 12, 28, 60, 32, 72
B. 2, 16, 5, 28, 12, 60, 32, 72
C. 2, 12, 16, 5, 28, 32, 72, 60
D. 5, 2, 12, 28, 16, 32, 72, 60

最终有序序列：2, 5, 12, 16, 28, 32, 60, 72。找每个选项中**在最终位置且左小右大**的元素：
- A：**28**、**72** → 72 在最右端（第 1 趟枢轴），第 2 趟在左子表中确定 28 ✓ 可能
- B：**2**、**72** → 第 1 趟枢轴可以是 2（最左端）或 72（最右端），第 2 趟确定另一个 ✓ 可能
- C：**2**、**28**、**32** → 第 1 趟 28，第 2 趟左右各确定一个（2 和 32）✓ 可能
- D：**12**、**32** → 两个都不在端点。若第 1 趟枢轴是 12，第 2 趟要在左 [5, 2] 和右子表中**各**确定一个，但左边 5、2 都不在最终位置 ✗；若第 1 趟是 32，同理右边 72、60 都不在最终位置 ✗
答案 **D**。

📝 **真题（2023 年第 11 题）**：使用快速排序算法对数据进行升序排序，若经过一次划分后得到的数据序列是 68, 11, 70, 23, 80, 77, 48, 81, 93, 88，则该次划分的枢轴是：A. 11 B. 70 C. 80 D. 81
**枢轴一定在最终位置：左边全部比它小，右边全部比它大。**
- 11：左边 68 > 11 ✗
- 70：右边有 23、48 < 70 ✗
- 80：右边有 77、48 < 80 ✗
- **81**：左边 68, 11, 70, 23, 80, 77, 48 都 < 81，右边 93, 88 都 > 81 ✓
答案 **D**。

## 三、冒泡 vs 快排

| | 冒泡排序 | 快速排序 |
|---|---|---|
| 最好 | O(n)（有序） | O(n log n) |
| 平均 | O(n²) | **O(n log n)**（最快） |
| 最坏 | O(n²)（逆序） | **O(n²)（有序或逆序）** |
| 空间 | O(1) | **O(log n)**（递归栈） |
| 稳定性 | **稳定** | **不稳定** |
| 每趟确定 | 1 个元素的最终位置 | 1 个（第 1 趟），之后每个子表 1 个 |
| 初始有序时 | **最快** | **最慢** |
| 适用 | 顺序表、链表 | 顺序表 |

⚠️ **最反直觉的一点**：快排在**已经有序**时反而最慢！（每次枢轴都是最小值，划分成 0 和 n−1）

---

## ⚠️ 易错点
1. 冒泡带标志时最好 O(n)
2. 快排的划分：**high 先动**（因为坑在 low），找小的；然后 low 动，找大的
3. 快排最坏情况是**初始有序或逆序**
4. 快排空间 O(log n)，不是 O(1)
5. 快排**不稳定**
6. “第 2 趟结果”至少 2 个或 3 个元素在最终位置
7. 枢轴判断：左边**全部**小于它，右边**全部**大于它

---

## 📋 本课小结

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|---|
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | ✓ |
| 快排 | O(n log n) | O(n log n) | O(n²) | O(log n) | ✗ |

快排关键：挖坑填坑；有序时最坏；递归深度决定时间和空间。
