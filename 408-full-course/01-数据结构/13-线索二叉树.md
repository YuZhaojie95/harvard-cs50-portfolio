# 数据结构 第 13 课 · 线索二叉树

> 🎯 **本课目标**
> 1. 理解为什么要线索化：利用 n + 1 个空指针存放前驱、后继
> 2. 掌握线索二叉树的结点结构（ltag、rtag）
> 3. **会手工画出**先序、中序、后序线索二叉树
> 4. 掌握中序线索化的代码，以及在中序线索树中找前驱、后继、遍历
> 5. 知道**哪种线索树找前驱/后继容易，哪种难**（选择题常考）
>
> 408 真题：2010、2013、2014 年都考过线索二叉树（画线索、判断线索指向谁）。

---

## 🚪 课前引入

上一课我们知道：n 个结点的二叉链表有 **n + 1 个空指针**，白白浪费了。
另一方面，遍历一次二叉树要用递归或栈，如果经常需要“找某个结点在中序序列中的**下一个**是谁”，每次都遍历太慢了。

能不能把这两件事结合起来？**用空着的指针，记下这个结点在遍历序列中的前驱和后继！** 这就是“线索”。

🧒 就像一本书，每页右下角写着“下一页是第几页”——即使书被打乱装订，你也能顺着找下去。

## 一、线索二叉树的概念

### 📐 规定
- 若结点**没有左孩子**，令 lchild 指向它的**前驱**
- 若结点**没有右孩子**，令 rchild 指向它的**后继**
- 这种指向前驱、后继的指针叫**线索**，加上线索的二叉树叫**线索二叉树**

### 📐 结点结构
为了区分指针指向的是**孩子**还是**线索**，增加两个标志位：
```
┌───────┬──────┬──────┬──────┬───────┐
│ ltag  │lchild│ data │rchild│ rtag  │
└───────┴──────┴──────┴──────┴───────┘
ltag = 0：lchild 指向左孩子        ltag = 1：lchild 指向前驱（线索）
rtag = 0：rchild 指向右孩子        rtag = 1：rchild 指向后继（线索）
```
```c
typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;                // 左、右线索标志
} ThreadNode, *ThreadTree;
```
- 以某种遍历方式线索化，就叫**先序 / 中序 / 后序线索二叉树**
- 线索二叉树是一种**物理结构**（存储结构）

## 二、手工画线索二叉树（⭐⭐）

**方法（三步）**：
1. 写出对应的遍历序列
2. 找出所有**空指针**（没有左孩子的左指针、没有右孩子的右指针）
3. 空的左指针 → 指向该结点在序列中的**前一个**；空的右指针 → 指向**后一个**；没有前驱/后继的指向 **NULL**

✏️ **例**：
```
        A
       / \
      B   C
     / \
    D   E
```
### 中序线索化
中序序列：**D B E A C**
| 结点 | 左指针 | 右指针 |
|---|---|---|
| D | 无左孩子 → 前驱 **NULL**（D 是第一个） | 无右孩子 → 后继 **B** |
| B | 左孩子 D | 右孩子 E |
| E | 无左孩子 → 前驱 **B** | 无右孩子 → 后继 **A** |
| A | 左孩子 B | 右孩子 C |
| C | 无左孩子 → 前驱 **A** | 无右孩子 → 后继 **NULL**（C 是最后一个） |

### 先序线索化
先序序列：**A B D E C**
| 结点 | 左线索 | 右线索 |
|---|---|---|
| D | 前驱 **B** | 后继 **E** |
| E | 前驱 **D** | 后继 **C** |
| C | 前驱 **E** | 后继 **NULL** |

### 后序线索化
后序序列：**D E B C A**
| 结点 | 左线索 | 右线索 |
|---|---|---|
| D | 前驱 **NULL** | 后继 **E** |
| E | 前驱 **D** | 后继 **B** |
| C | 前驱 **B** | 后继 **A** |

### 📐 空指针个数（⭐）
- **中序线索树**：恰好 **2** 个空指针（第一个结点的左线索、最后一个结点的右线索）
- 先序、后序线索树：1 或 2 个
- 通常会**增加一个头结点**：头结点的 lchild 指向根，rchild 指向遍历序列的最后一个结点；第一个结点的左线索和最后一个结点的右线索都指向头结点 → 形成一个**双向循环链表**，没有空指针

## 三、中序线索化的代码（⭐）

**思想**：中序遍历，用一个全局指针 **pre** 始终指向**刚刚访问过的结点**（即当前结点的前驱）。访问当前结点 p 时：
- 若 p 没有左孩子 → p->lchild = pre，ltag = 1（p 的前驱是 pre）
- 若 pre 没有右孩子 → pre->rchild = p，rtag = 1（pre 的后继是 p）
- 然后 pre = p

```c
ThreadNode *pre = NULL;                  // 全局变量，指向当前访问结点的前驱

void visit(ThreadNode *q) {
    if (q->lchild == NULL) {             // 左子树为空，建立前驱线索
        q->lchild = pre;
        q->ltag = 1;
    }
    if (pre != NULL && pre->rchild == NULL) {   // 建立前驱结点的后继线索
        pre->rchild = q;
        pre->rtag = 1;
    }
    pre = q;
}

void InThread(ThreadTree T) {            // 中序遍历，边遍历边线索化
    if (T != NULL) {
        InThread(T->lchild);
        visit(T);
        InThread(T->rchild);
    }
}

void CreateInThread(ThreadTree T) {
    pre = NULL;
    if (T != NULL) {
        InThread(T);
        if (pre->rchild == NULL)         // 处理遍历的最后一个结点
            pre->rtag = 1;
    }
}
```
🧒 **为什么“后继”要在访问下一个结点时才设置？** 因为访问 p 时我们还不知道它的后继是谁，要等访问到下一个结点时才知道。所以每次都是“**给上一个结点补后继**”。

⚠️ **先序线索化的“转圈”问题**：先序是“根左右”，访问根时如果把 lchild 改成了线索，接下来“遍历左子树”就会沿着线索又跑回前驱，导致死循环。所以先序线索化时要加判断：**只有 ltag == 0 时才去遍历左子树**。
```c
void PreThread(ThreadTree T) {
    if (T != NULL) {
        visit(T);
        if (T->ltag == 0) PreThread(T->lchild);   // lchild 不是线索才遍历
        PreThread(T->rchild);
    }
}
```

## 四、中序线索树的遍历（⭐⭐）

### 📐 找中序后继
结点 p 的**中序后继**：
- 若 **rtag == 1**：后继就是 p->rchild（线索直接指向后继）
- 若 **rtag == 0**（有右子树）：后继是**右子树中最左下的结点**（右子树中序遍历的第一个）

```c
ThreadNode *FirstNode(ThreadNode *p) {          // 以 p 为根的子树中，中序第一个结点
    while (p->ltag == 0) p = p->lchild;          // 一直往左下走
    return p;
}
ThreadNode *NextNode(ThreadNode *p) {           // p 的中序后继
    if (p->rtag == 0) return FirstNode(p->rchild);
    return p->rchild;
}
void InOrder(ThreadTree T) {                    // 不用递归、不用栈的中序遍历
    for (ThreadNode *p = FirstNode(T); p != NULL; p = NextNode(p))
        visit(p);
}
```
空间复杂度 **O(1)**！这是线索二叉树的最大好处。

### 📐 找中序前驱
- 若 **ltag == 1**：前驱就是 p->lchild
- 若 **ltag == 0**：前驱是**左子树中最右下的结点**

## 五、先序、后序线索树找前驱后继（⭐⭐ 选择题）

### 先序线索树
**找后继（容易）**：
- 有左孩子 → 后继是**左孩子**
- 没有左孩子但有右孩子 → 后继是**右孩子**
- 是叶子 → rchild 就是后继线索

**找前驱（困难）**：先序是“根左右”，p 的前驱可能是它的**双亲**或双亲左子树中的某个结点，而二叉链表**找不到双亲**。必须用三叉链表（带 parent 指针）或从头遍历。

### 后序线索树
**找前驱（容易）**：
- 有右孩子 → 前驱是**右孩子**
- 没有右孩子但有左孩子 → 前驱是**左孩子**
- 叶子 → lchild 就是前驱线索

**找后继（困难）**：后序是“左右根”，p 的后继要么是**双亲**，要么是双亲右子树中后序第一个结点，同样需要知道双亲。
具体规则（需要双亲信息）：
- p 是根 → 没有后继
- p 是双亲的**右孩子**，或是左孩子且双亲**没有右子树** → 后继是**双亲**
- p 是双亲的左孩子，且双亲**有右子树** → 后继是双亲右子树中**后序遍历的第一个结点**

### 📊 总结
| 线索树 | 找前驱 | 找后继 |
|---|---|---|
| 中序 | ✓ 容易 | ✓ 容易 |
| 先序 | ✗ 需要双亲 | ✓ 容易 |
| 后序 | ✓ 容易 | ✗ 需要双亲（**仍需要栈**的支持） |

🧒 **记忆**：“先序找前驱难，后序找后继难”——难的都是**指向根方向**的那一个（先序中前驱往往在上面；后序中后继往往在上面）。
📝 所以常考结论：**后序线索树的遍历仍需要栈的支持**（或三叉链表）。

📝 **真题（2013 年真题）**：若 X 是**后序线索二叉树**中的**叶结点**，且 X 存在**左兄弟** Y，则 X 的右线索指向的是？
- X 有左兄弟 Y → X 是双亲的**右孩子**
- 后序“左右根”：右孩子 X 之后紧接着就是双亲
- X 是叶子，rchild 是线索，指向后继 → **X 的父结点**

📝 **经典题**：中序线索二叉树中，若某结点有左孩子，则其前驱是？
→ **左子树中最右下的结点**

📝 **经典题**：n 个结点的线索二叉树中，线索的数目是？
→ 空指针数 **n + 1**（每个空指针都变成了线索，包括指向 NULL 的那两个）

---

## ⚠️ 易错点
1. ltag/rtag = 1 表示**线索**，= 0 表示**孩子**
2. 画线索前**先写出对应的遍历序列**
3. 线索指向的是“**遍历序列中的**”前驱后继，不是树中的双亲
4. 中序线索树有 2 个空指针
5. 先序找前驱难、后序找后继难
6. 先序线索化时要防止沿着线索“转圈”

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 目的 | 利用 n+1 个空指针；加快找前驱后继；遍历无需栈 |
| 标志 | tag=0 孩子，tag=1 线索 |
| 手工画 | 写序列 → 空左指前驱，空右指后继 |
| 线索化代码 | 全局 pre；访问时补“自己的前驱”和“pre 的后继” |
| 中序后继 | rtag=1 → rchild；否则右子树最左下 |
| 中序前驱 | ltag=1 → lchild；否则左子树最右下 |
| 难点 | 先序找前驱难；后序找后继难 |
