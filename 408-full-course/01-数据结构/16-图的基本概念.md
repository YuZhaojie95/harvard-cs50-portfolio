## 一、图的定义

### 📐 定义
图 G 由**顶点集 V** 和**边集 E** 组成，记为 **G = (V, E)**。
- V(G)：顶点的**有限非空**集合（⚠️ **图不能一个顶点都没有**，但可以一条边都没有）
- E(G)：顶点之间关系（边）的集合
- |V| 表示顶点个数（也叫图的**阶**），|E| 表示边数

⚠️ **线性表可以是空表、树可以是空树，但图不能是空图**（顶点集非空）。

## 二、基本术语（⭐⭐）

### 2.1 有向图与无向图
**无向图**：边是**无序对**，记作 **(v, w)**，(v, w) = (w, v)。
```
    A ─── B
    │   ╱ │         G1 = ({A,B,C,D}, {(A,B),(A,C),(B,C),(B,D)})
    │ ╱   │
    C     D
```
**有向图**：边是**有序对**，叫**弧**，记作 **<v, w>**，v 是**弧尾**，w 是**弧头**，表示从 v 指向 w。<v, w> ≠ <w, v>。
```
    A ──→ B          G2 = ({A,B,C}, {<A,B>,<B,C>,<C,A>})
     ↖   ↙
       C
```
🧒 记忆：箭头从“尾巴”出发，指向“头”。

### 2.2 简单图与多重图
- **简单图**：① 不存在重复边 ② 不存在顶点到自身的边（自环）
- **多重图**：两个顶点之间的边数多于一条，或允许自环
- **数据结构中只讨论简单图**

### 2.3 完全图（简单完全图）
- **无向完全图**：任意两个顶点之间**都有边**，n 个顶点有 **n(n−1)/2** 条边
- **有向完全图**：任意两个顶点之间都有**方向相反的两条弧**，有 **n(n−1)** 条弧

所以：无向图边数范围 **0 ~ n(n−1)/2**；有向图弧数范围 **0 ~ n(n−1)**。

### 2.4 子图
G' = (V', E')，若 V' ⊆ V 且 E' ⊆ E，则 G' 是 G 的**子图**。
- 若 V' = V（顶点全部保留），则 G' 是 G 的**生成子图**
- ⚠️ 并不是任意几个顶点和任意几条边都能构成子图——**边的两个端点必须都在顶点集里**

### 2.5 连通、连通图、连通分量（无向图）
- **连通**：顶点 v 到 w 有路径存在
- **连通图**：图中**任意两个顶点都连通**
- **连通分量**：无向图中的**极大连通子图**（“极大”：再加任何一个顶点都不连通了）

```
  A ─ B     D ─ E     G
  │ ╱       │
  C         F
这个图有 3 个连通分量：{A,B,C}、{D,E,F}、{G}
```

### 2.6 强连通、强连通图、强连通分量（有向图）
- **强连通**：从 v 到 w **和**从 w 到 v 都有路径
- **强连通图**：任意一对顶点都是强连通的
- **强连通分量**：有向图中的**极大强连通子图**

### 2.7 生成树、生成森林
- **生成树**：连通图的**包含全部顶点的极小连通子图**
  - n 个顶点的生成树有 **n − 1 条边**
  - 砍去一条边 → 变成非连通；加上一条边 → 形成回路
- **生成森林**：非连通图中，各连通分量的生成树构成的森林

⚠️ **极大连通子图**（连通分量）要包含尽可能多的顶点和边；**极小连通子图**（生成树）要在保持连通的前提下边数尽可能少。

### 2.8 顶点的度、入度、出度
- **无向图**：顶点 v 的**度 TD(v)** = 依附于该顶点的边数
  $$\sum_{i=1}^{n} TD(v_i) = 2e$$
  （每条边贡献 2 度——它的两个端点各 1 度）
- **有向图**：
  - **入度 ID(v)**：以 v 为**终点**（箭头指向 v）的弧数
  - **出度 OD(v)**：以 v 为**起点**的弧数
  - **度 TD(v) = ID(v) + OD(v)**
  $$\sum ID(v_i) = \sum OD(v_i) = e$$

📐 **推论**：无向图中，度为**奇数**的顶点个数一定是**偶数**（因为度数之和 2e 是偶数）。

### 2.9 边的权和网
- **权**：边上带的数值（距离、费用、时间……）
- **网（带权图）**：边上带有权值的图

### 2.10 稠密图、稀疏图
边数很少的图叫**稀疏图**（一般 |E| < |V|log|V|），反之叫**稠密图**。这是相对的说法，决定了存储方式的选择（下一课）。

### 2.11 路径、路径长度、回路
- **路径**：顶点 vₚ 到 v_q 的一个**顶点序列**
- **路径长度**：路径上**边的数目**（带权图中是路径上边的**权值之和**）
- **回路（环）**：第一个顶点和最后一个顶点相同的路径
- **简单路径**：顶点**不重复**出现的路径
- **简单回路**：除第一个和最后一个顶点外，其余顶点不重复的回路
- **距离**：从 u 到 v 的**最短路径**长度；不存在路径时距离为 ∞

### 2.12 有向树
**一个顶点的入度为 0、其余顶点的入度均为 1** 的有向图。

## 三、顶点数与边数的关系（⭐⭐⭐ 计算题）

### 结论汇总
| 问题 | 答案 | 理由 |
|---|---|---|
| n 个顶点的无向图最多几条边 | n(n−1)/2 | 完全图 |
| n 个顶点的有向图最多几条弧 | n(n−1) | 有向完全图 |
| n 个顶点的**连通**无向图**最少**几条边 | **n − 1** | 生成树 |
| n 个顶点的**强连通**有向图**最少**几条弧 | **n** | 围成一个环 |
| n 个顶点的无向图，若边数 > n − 1，则 | **一定有回路** | 树已经用了 n−1 条 |
| n 个顶点的无向图，**非连通**时最多几条边 | **C(n−1, 2) = (n−1)(n−2)/2** | n−1 个顶点构成完全图，剩一个孤立点 |
| n 个顶点的无向图，**保证任何情况下都连通**最少几条边 | **C(n−1, 2) + 1** | 比“非连通最多边数”多 1 条 |
| n 个顶点、e 条边的无向图，连通分量至少几个 | 若 e < n−1，至少 n − e 个 | 每条边最多把两个分量连成一个 |

📝 **真题（2010 年真题）**：若无向图 G = (V, E) 中含有 7 个顶点，要保证图 G 在**任何情况下都是连通的**，则需要的边数最少是？
🧒 思路：先让它“**尽量不连通**”——6 个顶点构成完全图（C(6,2) = 15 条边），第 7 个顶点孤立。这时有 15 条边却不连通。**再加 1 条边**，无论加在哪（只能连到孤立点上，因为 6 个点已经完全连满了），图一定连通。
→ **15 + 1 = 16**

📝 **真题（2022 年第 6 题）**：对于无向图 G = (V, E)，下列选项中正确的是：
- A. 当 |V| > |E| 时，G 一定是连通的 ✗（边太少，更可能不连通）
- B. 当 |V| < |E| 时，G 一定是连通的 ✗（边可能全挤在一部分顶点里）
- C. 当 |V| = |E| − 1 时，G 一定是不连通的 ✗（边数 = 顶点数 + 1，完全可以连通）
- D. **当 |V| > |E| + 1 时，G 一定是不连通的** ✓（即 |E| < |V| − 1，连通至少需要 |V| − 1 条边，不够）
答案 **D**。

📝 **真题（2009 年真题）**：下列关于无向连通图特性的叙述中，正确的是：
I. 所有顶点的度之和为偶数 ✓（= 2e）
II. 边数大于顶点个数减 1 ✗（树的边数恰好等于 n − 1）
III. 至少有一个顶点的度为 1 ✗（环形图中所有顶点度都是 2）
→ **只有 I**

📝 **真题（2017 年真题）**：已知无向图 G 含有 16 条边，其中度为 4 的顶点个数为 3，度为 3 的顶点个数为 4，其他顶点的度均小于 3。图 G 所含的顶点个数**至少**是？
- 度数之和 = 2 × 16 = 32
- 已知部分：4 × 3 + 3 × 4 = 24，剩余度数 32 − 24 = 8
- 其他顶点的度 < 3，最大为 2 → 要顶点最少，每个都取度 2 → 至少 8 / 2 = 4 个
- 总共至少 3 + 4 + 4 = **11** 个

📝 **真题（2025 年第 6 题）**：关于图的叙述，正确的是：
- A. 有向图必存在入度为 0 的顶点 ✗（有向环中所有顶点入度都是 1）
- B. 有向无环图的拓扑有序序列存在且唯一 ✗（存在，但不一定唯一）
- C. **各顶点的度均大于等于 2 的无向图必有回路** ✓
- D. 可用 BFS 算法求出带权图中每一对顶点间的最短路径 ✗（BFS 只适用于无权图）
答案 **C**。

🧒 **C 为什么对？** 反证：假设没有回路，那么每个连通分量都是一棵树。树至少有 2 个度为 1 的叶子（n ≥ 2 时）……与“所有顶点度 ≥ 2”矛盾。或者直观理解：从任一顶点出发，每到一个顶点，因为它度 ≥ 2，总能从“另一条边”离开，顶点是有限的，最终一定会走回走过的顶点——形成回路。

## ⚠️ 易错点
1. 图的**顶点集不能为空**
2. 无向图 (v,w) 圆括号；有向图 <v,w> 尖括号
3. 路径长度：无权图是**边数**，带权图是**权值和**
4. 连通分量是**极大**连通子图；生成树是**极小**连通子图
5. 无向图度数之和 = **2e**；有向图入度和 = 出度和 = **e**
6. 保证连通的最少边数 = C(n−1, 2) + 1，不是 n − 1

---

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 完全图 | 无向 n(n−1)/2，有向 n(n−1) |
| 连通 | 无向图任意两点有路径 |
| 强连通 | 有向图任意两点**互相**可达 |
| 连通分量 | 极大连通子图 |
| 生成树 | 极小连通子图，n − 1 条边 |
| 度数关系 | 无向 ΣTD = 2e；有向 ΣID = ΣOD = e |
| 连通最少边 | 无向 n − 1；强连通 n |
| 保证连通 | C(n−1, 2) + 1 |
| 必有回路 | 边数 > n − 1；或所有顶点度 ≥ 2 |

## 🏋️ 课后练习

1. 10 个顶点的无向完全图有多少条边？有向完全图有多少条弧？
2. 一个无向图有 12 个顶点，要保证它一定连通，至少需要多少条边？
3. 一个有向图有 6 个顶点，要成为强连通图，至少需要几条弧？
4. 无向图有 20 条边，度为 3 的顶点 6 个，其余顶点度都是 2，这个图有多少个顶点？
5. 具有 n 个顶点的无向图，有 n − 1 条边，是否一定是一棵树（连通无环）？
6. 一个无向图有 10 个顶点、6 条边，最少有几个连通分量？

<details>
<summary>📖 答案</summary>

1. 无向 10×9/2 = **45**；有向 10×9 = **90**
2. C(11, 2) + 1 = 55 + 1 = **56**
3. **6**（围成一个环）
4. 度数之和 40 = 18 + 2x → x = 11 → 共 6 + 11 = **17** 个顶点
5. **不一定**。例如 4 个顶点、3 条边，可能 3 条边构成一个三角形，第 4 个顶点孤立——不连通、有环。只有“连通 + n−1 条边”或“无环 + n−1 条边”才一定是树
6. 每条边最多减少 1 个连通分量：10 − 6 = **4** 个
</details>
