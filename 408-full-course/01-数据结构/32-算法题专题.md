## 一、评分标准与答题策略

### 📐 评分标准（历年惯例）
| 部分 | 分值（以 13 分为例） | 要求 |
|---|---|---|
| **(1) 基本设计思想** | 约 4 分 | 用文字说清楚算法的思路 |
| **(2) 算法实现** | 约 7 分 | C/C++ 代码，**关键之处给出注释** |
| **(3) 时间、空间复杂度** | 约 2 分 | 与自己的算法一致即可 |

题目通常要求“**时间上尽可能高效**”或“**时间和空间两方面都尽可能高效**”：
- 给出**最优解**：满分
- 给出**正确但不是最优**的解（如 O(n²) 暴力法）：一般扣 3~5 分，**仍能拿 8~10 分**
- **空着：0 分**

### 🎯 答题策略（⭐⭐⭐）
1. **先写暴力解保底**：读完题 5 分钟内想不出最优解，就写暴力解。思路正确、代码正确、复杂度写对，就能拿大部分分
2. **设计思想要写清楚**：用 3~6 句话说明“用了什么方法、每一步做什么”，阅卷老师先看这个
3. **代码不求完美编译**：分号、头文件这些小错误基本不扣分；但**逻辑要对**、**边界要考虑**
4. **一定要写注释**：让阅卷老师一眼看懂你在干什么
5. **复杂度要和代码一致**：写了 O(n²) 的代码就别写 O(n)
6. 可以用 C++：引用 `&`、`bool`、`new`、`swap`、`sort`（用 sort 要说明复杂度 O(n log n)）
7. 时间分配：**20~25 分钟**

### 📐 答题格式模板
```
(1) 算法的基本设计思想：
    ……（说明方法、步骤）

(2) 算法实现：
    // 结构定义（题目给了就不用写）
    返回类型 函数名(参数) {
        // 关键步骤注释
        ...
    }

(3) 时间复杂度为 O(…)，空间复杂度为 O(…)。
```

## 二、常见题型与套路总表（⭐⭐⭐）

| 数据结构 | 题型 | 常用方法 |
|---|---|---|
| **数组/顺序表** | 找最值、配对、逆置、移位 | 一次扫描 + 几个变量；**双指针**；三次逆置 |
| | 找缺失的数、出现次数、去重 | **辅助数组计数/标记**（空间换时间） |
| | 找主元素 | 摩尔投票 |
| | 有序数组/多个有序数组 | **多指针归并**；二分 |
| | 找第 k 小/中位数/划分 | 快排划分（O(n) 平均）；排序 O(n log n) |
| **链表** | 逆置 | **头插法** |
| | 倒数第 k 个、中间结点、判环 | **快慢指针 / 前后指针** |
| | 公共结点 | 先求长度，长的先走差值步 |
| | 删除特定结点 | **pre + p 双指针** |
| | 重排 | 找中点 + 逆置后半 + 合并 |
| **二叉树** | 求结点数、叶子数、高度、宽度、WPL | **递归**（空树出口 + 组合左右结果） |
| | 按层处理 | **层序遍历（队列）** |
| | 判断 BST | **中序遍历是否递增** |
| | 表达式树 | 中序 + 加括号 |
| | 判断完全二叉树 | 层序，空结点也入队 |
| **图（邻接矩阵）** | 求度、出度、入度 | **行和 / 列和** |
| | 连通性、路径 | DFS / BFS |
| | 拓扑相关 | 入度数组 + 队列/栈 |

### 📝 2016 年真题（算法题）：集合划分
> 已知由 n（n ≥ 2）个正整数构成的集合 A = {aₖ}（0 ≤ k < n），将其划分为两个不相交的子集 A₁ 和 A₂，元素个数分别是 n₁ 和 n₂，A₁ 和 A₂ 中元素之和分别为 S₁ 和 S₂。设计一个尽可能高效的划分算法，满足 |n₁ − n₂| 最小且 |S₁ − S₂| 最大。

**(1) 设计思想**：
- |n₁ − n₂| 最小 → 两个子集的元素个数尽量相等：n₁ = ⌊n/2⌋，n₂ = n − n₁
- |S₁ − S₂| 最大 → **最小的 ⌊n/2⌋ 个数放进 A₁**，其余放进 A₂
- 所以问题变成：**找出第 ⌊n/2⌋ 小的元素，并把比它小的放左边、比它大的放右边**
- 用**快速排序的划分思想**：每次划分后，若枢轴的位置 i 恰好等于 ⌊n/2⌋ − 1（下标从 0），划分完成；若 i < ⌊n/2⌋ − 1，只需继续划分右边；否则只继续划分左边。**每次只处理一侧**，平均 O(n)
- （简单方法：先排序 O(n log n)，前一半给 A₁，也能拿大部分分）

**(2) 代码**：
```c
int setPartition(int a[], int n) {
    int pivotkey, low = 0, low0 = 0, high = n - 1, high0 = n - 1;
    int k = n / 2, flag = 1, s1 = 0, s2 = 0;
    while (flag) {
        pivotkey = a[low];                              // 选第一个元素为枢轴
        while (low < high) {                            // 一趟划分
            while (low < high && a[high] >= pivotkey) --high;
            if (low != high) a[low] = a[high];
            while (low < high && a[low] <= pivotkey) ++low;
            if (low != high) a[high] = a[low];
        }
        a[low] = pivotkey;
        if (low == k - 1) flag = 0;                     // 枢轴恰好是第 k 小，结束
        else if (low < k - 1) {                         // 第 k 小在右边
            low0 = ++low; high = high0;
        } else {                                        // 第 k 小在左边
            high0 = --high; low = low0;
        }
    }
    for (int i = 0; i < k; i++) s1 += a[i];             // A1 = a[0..k-1]
    for (int i = k; i < n; i++) s2 += a[i];             // A2 = a[k..n-1]
    return s2 - s1;
}
```
**(3)** 平均时间 **O(n)**，空间 **O(1)**

### 📝 2020 年第 41 题：三元组最小距离（13 分）
> 定义三元组 (a, b, c)（a、b、c 均为整数）的距离 D = |a − b| + |b − c| + |c − a|。给定 3 个非空整数集合 S₁、S₂ 和 S₃，按升序分别存储在 3 个数组中。设计一个尽可能高效的算法，计算并输出所有可能的三元组 (a, b, c)（a ∈ S₁，b ∈ S₂，c ∈ S₃）中的最小距离。例如 S₁ = {−1, 0, 9}，S₂ = {−25, −10, 10, 11}，S₃ = {2, 9, 17, 30, 41}，则最小距离为 2，相应的三元组为 (9, 10, 9)。

**(1) 设计思想**：
- **关键观察**：设三个数中最小的是 min、最大的是 max，则 D = 2(max − min)（画在数轴上，D 等于“最小值到最大值的距离”的 2 倍）
- 要让 D 变小，只能**让最小值变大**（最大值不能变小，因为数组是升序的，指针只能往后走）
- 所以：用三个下标 i、j、k 分别指向三个数组的开头；每次计算当前 D，更新最小值 Dmin；然后把**三者中最小的那个元素的下标后移一位**；任一数组扫描完就结束

**(2) 代码**：
```c
#define INT_MAX 0x7fffffff
int abs_(int a) { return a < 0 ? -a : a; }
bool xls_min(int a, int b, int c) {         // a 是否是三者中最小的
    return a <= b && a <= c;
}
int findMinofTrip(int A[], int n, int B[], int m, int C[], int p) {
    int i = 0, j = 0, k = 0, D_min = INT_MAX, D;
    while (i < n && j < m && k < p && D_min > 0) {
        D = abs_(A[i] - B[j]) + abs_(B[j] - C[k]) + abs_(C[k] - A[i]);
        if (D < D_min) D_min = D;                    // 更新最小距离
        if (xls_min(A[i], B[j], C[k])) i++;          // 最小值所在数组的下标后移
        else if (xls_min(B[j], C[k], A[i])) j++;
        else k++;
    }
    return D_min;
}
```
**(3)** 时间 **O(n + m + p)**，空间 **O(1)**
（暴力法：三重循环枚举所有三元组 O(nmp)，也能拿部分分。）

### 📝 2021 年第 41 题：EL 路径（15 分）
> 已知无向连通图 G 由顶点集 V 和边集 E 组成，|E| > 0，当 G 中度为奇数的顶点个数为**不大于 2 的偶数**时，G 存在包含所有边且长度为 |E| 的路径（称为 EL 路径）。设图 G 采用邻接矩阵存储：
> ```c
> typedef struct {
>     int numVertices, numEdges;      // 图中实际的顶点数和边数
>     char VerticesList[MAXV];        // 顶点表
>     int Edge[MAXV][MAXV];           // 邻接矩阵
> } MGraph;
> ```
> 设计算法 int IsExistEL(MGraph G)，判断 G 是否存在 EL 路径，若存在则返回 1，否则返回 0。

**(1) 设计思想**：
- “不大于 2 的偶数”即 **0 或 2**
- 无向图邻接矩阵中，**第 i 行元素之和就是顶点 i 的度**
- 逐行求和，统计度为奇数的顶点个数 count；若 count 为 0 或 2 返回 1，否则返回 0

**(2) 代码**：
```c
int IsExistEL(MGraph G) {
    int degree, count = 0;                           // count：度为奇数的顶点个数
    for (int i = 0; i < G.numVertices; i++) {
        degree = 0;
        for (int j = 0; j < G.numVertices; j++)
            degree += G.Edge[i][j];                  // 第 i 行之和 = 顶点 i 的度
        if (degree % 2 != 0) count++;                // 度为奇数
    }
    if (count == 0 || count == 2) return 1;
    return 0;
}
```
**(3)** 时间 **O(n²)**，空间 **O(1)**
🧒 这其实就是“一笔画”（欧拉路径）的判定定理。

### 📝 2022 年第 41 题：判断顺序存储的二叉树是否为二叉搜索树（13 分）
> 已知非空二叉树 T 的结点值均为正整数，采用顺序存储方式保存：
> ```c
> typedef struct {                 // MAX_SIZE 为已定义常量
>     int SqBiTNode[MAX_SIZE];     // 保存二叉树结点值的数组
>     int ElemNum;                 // 实际占用的数组元素个数
> } SqBiTree;
> ```
> T 中不存在的结点在数组 SqBiTNode 中用 −1 表示。请设计一个尽可能高效的算法，判定一棵采用这种方式存储的二叉树是否为二叉搜索树，若是则返回 true，否则返回 false。

**(1) 设计思想**：
- **二叉搜索树的中序遍历序列严格递增**
- 顺序存储中（下标从 0），结点 i 的左孩子是 2i + 1，右孩子是 2i + 2
- 对树进行中序遍历，用变量 val 记录**上一个访问的结点值**，若当前结点值 ≤ val，则不是 BST
- 结点值都是正整数，val 初值设为 0（或 −1）

**(2) 代码**：
```cpp
bool judgeInOrderBST(SqBiTree bt, int k, int &val) {   // 以下标 k 为根的子树
    if (k < bt.ElemNum && bt.SqBiTNode[k] != -1) {
        if (!judgeInOrderBST(bt, 2 * k + 1, val)) return false;   // 左子树
        if (bt.SqBiTNode[k] <= val) return false;                  // 不递增
        val = bt.SqBiTNode[k];                                     // 更新“上一个值”
        if (!judgeInOrderBST(bt, 2 * k + 2, val)) return false;   // 右子树
    }
    return true;
}
bool isBST(SqBiTree bt) {
    int val = 0;                          // 结点值均为正整数
    return judgeInOrderBST(bt, 0, val);
}
```
**另一种思路**：对每个结点，检查它是否大于左子树的最大值、小于右子树的最小值（更复杂）。
**(3)** 时间 **O(n)**，空间 **O(log n)~O(n)**（递归栈，与树高有关）

### 📝 2023 年第 41 题：K 顶点（13 分）
> 已知有向图 G 采用邻接矩阵存储（结构同 2021 年）。将图中**出度大于入度**的顶点称为 K 顶点。设计算法 int printVertices(MGraph G)，对给定的任意非空有向图 G，输出 G 中所有的 K 顶点，并返回 K 顶点的个数。

**(1) 设计思想**：
- 有向图邻接矩阵中，**第 i 行之和是顶点 i 的出度，第 i 列之和是顶点 i 的入度**
- 对每个顶点 i，同时累加第 i 行和第 i 列，比较出度和入度；若出度 > 入度，输出该顶点并计数

**(2) 代码**：
```c
int printVertices(MGraph G) {
    int indegree, outdegree, count = 0;
    for (int i = 0; i < G.numVertices; i++) {
        indegree = outdegree = 0;
        for (int j = 0; j < G.numVertices; j++) {
            outdegree += G.Edge[i][j];         // 第 i 行：出度
            indegree  += G.Edge[j][i];         // 第 i 列：入度
        }
        if (outdegree > indegree) {            // K 顶点
            printf("%c ", G.VerticesList[i]);
            count++;
        }
    }
    return count;
}
```
**(3)** 时间 **O(n²)**，空间 **O(1)**

### 📝 2025 年第 41 题：乘积最大值（13 分）
> 设有两个长度均为 n 的一维整型数组 A 和 res，对数组 A 中的每个元素 A[i]，计算 A[i] 与 A[j]（0 ≤ i ≤ j ≤ n − 1）乘积的最大值，并将其保存到 res[i] 中。例如，若 A[] = {1, 4, −9, 6}，则得到 res[] = {6, 24, 81, 36}。现给定数组 A，请设计一个时间和空间上尽可能高效的算法 calMulMax，求 res 中各元素的值。函数原型为 void calMulMax(int A[], int res[], int n)。

**(1) 设计思想**：
- 暴力法：对每个 i 枚举 j = i ~ n−1，O(n²)
- **优化**：对固定的 A[i]，
  - 若 **A[i] ≥ 0**，与 A[i..n−1] 中的**最大值**相乘最大
  - 若 **A[i] < 0**，与 A[i..n−1] 中的**最小值**相乘最大（负负得正）
- 所以**从右往左**扫描，维护当前后缀 A[i..n−1] 的最大值 max 和最小值 min，即可 O(1) 算出每个 res[i]

**(2) 代码**：
```c
void calMulMax(int A[], int res[], int n) {
    int max = A[n - 1], min = A[n - 1];        // A[i..n-1] 的最大值、最小值
    for (int i = n - 1; i >= 0; i--) {
        if (A[i] > max) max = A[i];            // 更新后缀最大值
        if (A[i] < min) min = A[i];            // 更新后缀最小值
        if (A[i] >= 0) res[i] = A[i] * max;    // 非负数乘最大值
        else res[i] = A[i] * min;              // 负数乘最小值
    }
}
```
**验证**：A = {1, 4, −9, 6}
| i | A[i] | max | min | res[i] |
|---|---|---|---|---|
| 3 | 6 | 6 | 6 | 6 × 6 = 36 |
| 2 | −9 | 6 | −9 | −9 × −9 = 81 |
| 1 | 4 | 6 | −9 | 4 × 6 = 24 |
| 0 | 1 | 6 | −9 | 1 × 6 = 6 |
res = {6, 24, 81, 36} ✓

**(3)** 时间 **O(n)**，空间 **O(1)**
