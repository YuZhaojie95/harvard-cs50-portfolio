# 第一部分：二叉排序树（BST）

## 一、定义

**二叉排序树**（二叉查找树，BST）是一棵空树，或者满足：
1. 若左子树非空，则**左子树上所有结点**的值均**小于**根结点的值
2. 若右子树非空，则**右子树上所有结点**的值均**大于**根结点的值
3. 左、右子树也分别是二叉排序树

```
            50
          /    \
        30      70
       /  \    /  \
     20   40  60   80
```
**最重要的性质**：**对二叉排序树进行中序遍历，得到递增有序序列**。
（上图中序：20 30 40 50 60 70 80）

⚠️ 定义里是“左子树上**所有**结点 < 根”，不只是左孩子 < 根。判断一棵树是不是 BST，**用中序遍历看是否递增**最保险（2022 年第 41 题就是这个思路）。

## 二、查找

从根开始：
- 等于根 → 找到
- 小于根 → 去左子树找
- 大于根 → 去右子树找

```c
BSTNode *BST_Search(BiTree T, ElemType key) {        // 非递归
    while (T != NULL && key != T->data) {
        if (key < T->data) T = T->lchild;
        else T = T->rchild;
    }
    return T;                                          // 失败返回 NULL
}
```
查找长度 = 从根到目标结点经过的结点数（= 目标结点的层数）。

## 三、插入

**新插入的结点一定是叶结点**：先查找，查找失败的位置就是插入位置。
```c
int BST_Insert(BiTree &T, ElemType k) {
    if (T == NULL) {                                   // 找到插入位置
        T = (BiTree)malloc(sizeof(BSTNode));
        T->data = k;
        T->lchild = T->rchild = NULL;
        return 1;
    }
    if (k == T->data) return 0;                        // 已存在，插入失败
    if (k < T->data) return BST_Insert(T->lchild, k);
    return BST_Insert(T->rchild, k);
}
```

## 四、构造

从空树开始，依次插入每个关键字。
✏️ 依次插入 {45, 24, 53, 45, 12, 24, 90}：
```
插 45:  45
插 24:  45        插 53:   45
       /                  /  \
      24                24    53
插 45（重复，不插）
插 12:     45         插 24（重复）   插 90:      45
          /  \                                 /  \
        24    53                             24    53
       /                                    /        \
      12                                   12         90
```

⚠️ **同样的关键字集合，插入顺序不同，得到的 BST 形态可能不同**：
- 依次插入 1, 2, 3, 4, 5 → 退化成一条向右的链（高度 5）
- 依次插入 3, 2, 4, 1, 5 → 比较平衡（高度 3）

📝 **真题（2020 年第 5 题）**：下列给定的关键字输入序列中，**不能**生成下面二叉排序树的是：
```
        4
       / \
      2   5
     / \
    1   3
```
A. 4, 5, 2, 1, 3 &nbsp; B. 4, 5, 1, 2, 3 &nbsp; C. 4, 2, 5, 3, 1 &nbsp; D. 4, 2, 1, 3, 5
🧒 **判断规则**：在 BST 中，**祖先一定比子孙先插入**（因为新结点总是作为叶子插入）。
- 这棵树中，2 是 1 和 3 的祖先 → **2 必须在 1、3 之前插入**
- B 中 1 在 2 之前 → 1 会先成为 4 的左孩子，与树不符 ✗
答案 **B**。

## 五、删除（⭐⭐⭐）

设要删除的结点为 z：
**情况 1：z 是叶结点** → 直接删除
**情况 2：z 只有左子树或只有右子树** → 让 z 的子树**顶替** z 的位置（z 的双亲直接指向 z 的孩子）
**情况 3：z 有左右两棵子树** → 用 z 的**直接后继**（右子树中**最左下**的结点，即中序遍历中 z 的下一个）或**直接前驱**（左子树中**最右下**的结点）替代 z，然后从二叉排序树中删去这个直接后继（或前驱），就转换成了情况 1 或 2

✏️ **例**：在下面的树中删除 50
```
删除前：             用直接后继 55 替代：        （或用直接前驱 40 替代）
        50                  55                          40
       /  \                /  \                        /  \
     30    70            30    70                    30    70
    /  \   / \          /  \   / \                  /     / \
   20  40 60  80       20  40 60  80               20    60  80
          /                                             /
         55                                            55
```
- 直接后继：从 50 的右孩子 70 出发，一直往左走：70 → 60 → 55，55 没有左孩子了，就是它
- 55 是叶子，直接删掉，把 55 放到 50 的位置

### 📐 删除后再插入（⭐ 选择题）
📝 **经典题（2013 年真题）**：在任意一棵非空二叉排序树 T1 中，删除某结点 v 之后形成二叉排序树 T2，再将 v 插入 T2 形成二叉排序树 T3。下列关于 T1 与 T3 的叙述中，正确的是：
I. 若 v 是 T1 的叶结点，则 T1 与 T3 不同
II. 若 v 是 T1 的叶结点，则 T1 与 T3 相同
III. 若 v 不是 T1 的叶结点，则 T1 与 T3 不同
IV. 若 v 不是 T1 的叶结点，则 T1 与 T3 相同
- v 是叶子：删除后再插入，会**回到原来的位置** → 相同，**II ✓**
- v 不是叶子：删除时被别的结点替代或子树上移；重新插入后 v 成为**叶子** → 一定不同，**III ✓**
答案：**II 和 III**

## 六、查找效率分析

- 查找成功的 ASL = Σ(每个结点的层数) / n
- 查找失败的 ASL = Σ(每个失败结点的父结点层数) / (n + 1)
- **最好**：树是平衡的，高度 ⌊log₂n⌋ + 1，ASL ≈ O(log n)
- **最坏**：插入序列有序，树退化成**单支树**，高度 n，ASL = (n+1)/2，O(n)

✏️ 对比上面两棵树（1~5 顺序插入 vs 平衡插入）：
- 单支树：ASL成功 = (1+2+3+4+5)/5 = 3
- 平衡树（3 为根，2、4 在第 2 层，1、5 在第 3 层）：ASL成功 = (1 + 2×2 + 3×2)/5 = 11/5 = 2.2

### 📐 BST 与折半查找的比较
| | 二叉排序树 | 折半查找 |
|---|---|---|
| 判定树 | 与插入顺序有关，**不唯一** | **唯一** |
| 平均性能 | 最好 O(log n)，最坏 O(n) | O(log n) |
| 插入删除 | **O(log n)**（不用移动元素） | O(n)（要移动元素） |
| 适用 | **动态查找表** | 静态查找表 |

# 第二部分：平衡二叉树（AVL）

## 七、定义

为了避免 BST 退化，规定：**任一结点的左、右子树的高度差的绝对值不超过 1**。这样的 BST 叫**平衡二叉树**（AVL 树）。

**平衡因子（BF）= 左子树高度 − 右子树高度**，AVL 树中所有结点的 BF 只能是 **−1、0、1**。
```
      8 (BF=1)                  8 (BF=2) ← 不平衡！
     /  \                      /
    4    9                    4
   / \                       / \
  2   6                     2   6
平衡二叉树                  不是平衡二叉树
```

## 八、插入与四种旋转（⭐⭐⭐）

### 📐 基本思路
1. 按 BST 的规则插入新结点
2. 从新结点往上检查各祖先的平衡因子
3. 找到**第一个**（离新结点**最近**的）平衡因子绝对值 > 1 的结点 A，以 A 为根的子树叫**最小不平衡子树**
4. 只需要调整这棵最小不平衡子树，整棵树就恢复平衡

### 📐 四种不平衡类型
根据**新结点插在 A 的哪里**来分类（看从 A 往下的**前两步**）：

| 类型 | 新结点插在 | 调整方法 |
|---|---|---|
| **LL** | A 的**左**孩子的**左**子树 | **右旋一次** |
| **RR** | A 的**右**孩子的**右**子树 | **左旋一次** |
| **LR** | A 的**左**孩子的**右**子树 | 先左旋，再右旋 |
| **RL** | A 的**右**孩子的**左**子树 | 先右旋，再左旋 |

### 📐 LL 型：右旋
```
         A (BF=2)                  B
        / \                       / \
       B   AR      右旋 →        BL   A
      / \                       ↑    / \
     BL  BR                   新结点 BR  AR
     ↑
   新结点
```
**操作**：A 的左孩子 B **向右上旋转**代替 A 成为根；A 成为 B 的**右孩子**；B 原来的右子树 BR 成为 A 的**左子树**。
🧒 **口诀**：“**儿子上位**”——左儿子 B 当爹，原来的爹 A 变成它的右儿子，B 多出来的右子树过继给 A 当左子树。

```c
BSTNode *RightRotate(BSTNode *A) {
    BSTNode *B = A->lchild;
    A->lchild = B->rchild;    // BR 过继给 A
    B->rchild = A;            // A 成为 B 的右孩子
    return B;                 // B 成为新的根（由调用者挂回原位置）
}
```

### 📐 RR 型：左旋（与 LL 对称）
A 的右孩子 B **向左上旋转**代替 A；A 成为 B 的**左孩子**；B 原来的左子树 BL 成为 A 的**右子树**。

### 📐 LR 型：先左旋再右旋
```
        A                       A                        C
       / \                     / \                     /   \
      B   AR    先对 B 左旋 →  C   AR    再对 A 右旋 →  B     A
     / \                      / \                    / \   / \
    BL  C                    B   CR                 BL CL CR  AR
       / \                  / \
      CL  CR               BL  CL
（新结点在 CL 或 CR 中）
```
🧒 **口诀**：“**孙子上位**”——A 的左孩子的右孩子 C 直接升为根，B 做它的左孩子，A 做它的右孩子；C 原来的左子树 CL 给 B 做右子树，C 原来的右子树 CR 给 A 做左子树。

### 📐 RL 型：先右旋再左旋（与 LR 对称）
A 的右孩子的左孩子 C 升为根，A 做 C 的左孩子，B 做 C 的右孩子；CL 给 A 做右子树，CR 给 B 做左子树。

### 🎯 考场快速做法（强烈推荐）
不用死记旋转步骤，记住一个事实：**旋转后仍然是 BST，而且“中间值”当根**。
1. 找到最小不平衡子树的根 A
2. 从 A 往新结点方向走两步，得到 A、B、C 三个结点（C 可能就是新结点本身）
3. 把 A、B、C 三个结点按**大小排序**，**中间那个当根**，小的当左孩子，大的当右孩子
4. 其余子树按 BST 的大小关系挂回去

### ✏️ 例题：依次插入 15, 3, 7, 10, 9, 8 构造 AVL 树
**插入 15、3**：
```
  15
  /
 3
```
**插入 7**：15 的 BF = 2，新结点 7 在 15 的左孩子（3）的**右**子树 → **LR 型**
A=15，B=3，C=7 → 中间值 7 当根
```
   15                7
   /                / \
  3       →        3   15
   \
    7
```
**插入 10**：10 > 7 → 15 → 10 < 15 → 15 的左孩子。检查：15 的 BF=1，7 的 BF=−1，平衡
```
     7
    / \
   3   15
       /
      10
```
**插入 9**：9 > 7 → 15 → 10 → 9 < 10 → 10 的左孩子。
检查：10 的 BF=1；15 的 BF=**2** ✗ → 最小不平衡子树根 A=15。新结点 9 在 15 的左孩子（10）的**左**子树 → **LL 型**
A=15，B=10，C=9 → 中间值 10 当根
```
     7                    7
    / \                  / \
   3   15      →        3   10
       /                   /  \
      10                  9    15
      /
     9
```
**插入 8**：8 > 7 → 10 → 8 < 10 → 9 → 8 < 9 → 9 的左孩子。
检查：9 的 BF=1；10 的 BF=1；7 的 BF = 1 − 3 = **−2** ✗ → A=7。新结点在 7 的右孩子（10）的**左**子树 → **RL 型**
A=7，B=10，C=9 → 中间值 9 当根；7 做左孩子（带着 3），10 做右孩子（带着 15）；9 原来的左子树 8 给 7 做右子树
```
       7                           9
      / \                        /   \
     3   10          →          7     10
         / \                   / \      \
        9   15                3   8      15
       /
      8
```
**最终 AVL 树**：根 9，左子树 7（孩子 3、8），右子树 10（右孩子 15）。

📝 **真题（2021 年第 6 题）**：给定平衡二叉树（根 20，左孩子 16，右孩子 30，30 的左右孩子为 25 和 40），**插入关键字 23 后**，根中的关键字是？
1. 23 > 20 → 30 → 23 < 30 → 25 → 23 < 25 → 25 的左孩子
2. 往上检查：25 的 BF=1，30 的 BF=1，20 的 BF = 1 − 3 = **−2** ✗ → A = 20
3. 23 在 20 的右孩子（30）的**左**子树中 → **RL 型**
4. A=20，B=30，C=25 → 中间值 **25** 当根
```
       20                            25
      /  \                         /    \
     16   30          →          20      30
         /  \                   /  \       \
        25   40               16   23       40
       /
      23
```
答案：根是 **25**，选 D。

## 九、删除（了解）
1. 按 BST 的方法删除结点
2. 从被删结点往上检查，找到第一个不平衡的结点，进行旋转调整
3. ⚠️ 与插入不同：**删除后的调整可能要一直向上传播到根**（插入只需调整一次）

📝 **经典题（2019 年真题）**：在任意一棵非空 AVL 树 T1 中，删除某结点 v 之后形成 AVL 树 T2，再将 v 插入 T2 形成 AVL 树 T3。下列叙述正确的是：
I. 若 v 是 T1 的叶结点，则 T1 与 T3 **可能不相同** ✓（删除叶子可能引起旋转，再插入就回不到原来的样子了）
II. 若 v 不是 T1 的叶结点，则 T1 与 T3 一定不相同 ✗（插入时的旋转可能恰好恢复原样）
III. 若 v 不是 T1 的叶结点，则 T1 与 T3 一定相同 ✗
答案：**仅 I**

## 十、AVL 树的高度与结点数（⭐⭐⭐）

### 📐 高度为 h 的 AVL 树最少有多少个结点？
设 nₕ 为高度为 h 的 AVL 树的**最少**结点数：
$$n_0 = 0,\quad n_1 = 1,\quad n_2 = 2,\quad n_h = n_{h-1} + n_{h-2} + 1$$
🧒 **推导**：要结点最少，就让根的一棵子树高 h−1（结点最少），另一棵高 h−2（尽量矮，但高度差不能超过 1），再加上根本身。

| h | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| nₕ（最少结点数） | 1 | 2 | 4 | 7 | 12 | 20 | 33 |

- 这种“结点最少”的 AVL 树中，**所有非叶结点的平衡因子都是 1（或都是 −1）**
- **n 个结点的 AVL 树的最大高度**：找最大的 h 使 nₕ ≤ n
- AVL 树的高度为 **O(log n)**，查找、插入、删除都是 **O(log n)**

📝 **经典题（2012 年真题）**：若平衡二叉树的高度为 6，且所有非叶结点的平衡因子均为 1，则该平衡二叉树的结点总数为？
→ 就是 n₆ = **20**

📝 **经典题**：含有 20 个结点的平衡二叉树的最大深度是？
→ n₆ = 20 ≤ 20 < n₇ = 33 → **6**

📝 **经典题（2015 年真题）**：现有一棵无重复关键字的 AVL 树，对其进行中序遍历可得到一个**降序**序列。下列正确的是：
- A. 根结点的度一定为 2 ✗（只有 2 个结点时根的度为 1）
- B. 树中最小元素一定是叶结点 ✗
- C. 最后插入的元素一定是叶结点 ✗（插入后可能旋转，它可能被转上去）
- D. **树中最大元素一定无左子树** ✓（中序降序说明“左大右小”，最大元素在最左下，没有左孩子）

---

## ⚠️ 易错点
1. BST 判定要看**左子树所有结点**，用中序是否递增判断
2. 新插入的结点一定是**叶子**；祖先必须比子孙先插入
3. 删除有两个孩子的结点，用**直接后继（右子树最左）或直接前驱（左子树最右）**替代
4. AVL 调整的是**最小不平衡子树**（离新结点最近的不平衡结点）
5. LL/RR/LR/RL 看的是新结点相对于 **A** 的位置（前两步）
6. nₕ = nₕ₋₁ + nₕ₋₂ + 1，不是斐波那契数列本身

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| BST 性质 | 左 < 根 < 右；中序递增 |
| BST 插入 | 新结点是叶子；祖先先于子孙插入 |
| BST 删除 | 叶子直接删；单子树顶替；双子树用后继/前驱替代 |
| BST 效率 | 最好 O(log n)，最坏 O(n)（单支树） |
| AVL | 所有结点 \|BF\| ≤ 1 |
| 旋转 | LL 右旋；RR 左旋；LR 先左后右；RL 先右后左 |
| 快速法 | A、B、C 三个结点中间值当根 |
| 最少结点 | nₕ = nₕ₋₁ + nₕ₋₂ + 1：1, 2, 4, 7, 12, 20, 33 |
| 复杂度 | AVL 查找/插入/删除 O(log n) |
