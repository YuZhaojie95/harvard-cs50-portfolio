## 一、数据结构

### 📐 复杂度与线性表
- 顺序表：按位查找 **O(1)**；插入/删除平均移动 **n/2**、**(n−1)/2** 个元素
- 单链表：按位/按值查找 O(n)；已知结点后插 O(1)
- 循环队列：队空 `front == rear`；队满 `(rear+1) % M == front`；长度 `(rear − front + M) % M`
- n 个元素进栈，出栈序列个数 = **卡特兰数 C(2n,n)/(n+1)**
- 对称矩阵下三角（行优先，下标从 1）：a[i][j] → k = **i(i−1)/2 + j − 1**（i ≥ j）
- KMP：next 数组、nextval 数组（[第 9 课](../01-数据结构/09-串与KMP.md)）

### 📐 树
- 结点数 = 总度数 + 1；**n₀ = n₂ + 1**
- 高为 h 的二叉树最多 **2ʰ − 1** 个结点；n 个结点的完全二叉树高度 **⌈log₂(n+1)⌉**
- 完全二叉树：结点 i 的双亲 **⌊i/2⌋**，左孩子 **2i**，右孩子 **2i+1**；叶子从 **⌊n/2⌋+1** 开始
- n 个结点二叉链表：空指针 **n + 1** 个
- 森林 ↔ 二叉树：**左孩子右兄弟**；森林先序 = 二叉树先序，森林中序（后根）= 二叉树中序
- 哈夫曼树：n 个叶子共 **2n − 1** 个结点，**没有度为 1 的结点**；WPL = 所有非叶结点权值之和
- 前序 + 中序、后序 + 中序、层序 + 中序可以唯一确定二叉树；前序 + 后序不行

### 📐 图
- 无向完全图 **n(n−1)/2** 条边；有向完全图 **n(n−1)** 条边
- 连通图至少 **n − 1** 条边；n 个顶点保证连通至少 **(n−1)(n−2)/2 + 1** 条边
- 邻接矩阵空间 O(n²)；邻接表 O(n + e)；BFS/DFS 时间：矩阵 O(n²)，表 O(n + e)
- Prim O(n²) 适合稠密图；Kruskal O(e log e) 适合稀疏图
- Dijkstra 不能处理**负权边**；Floyd O(n³) 可以处理负权边（无负权回路）
- 关键路径：ve 从前往后取**最大**；vl 从后往前取**最小**；**l − e = 0** 的活动是关键活动

### 📐 查找
- 折半查找最多比较 **⌊log₂n⌋ + 1** 次
- 分块查找（块内、索引都顺序）：最优块长 **√n**
- 平衡二叉树高度 h 的最少结点：**N(h) = N(h−1) + N(h−2) + 1**（1, 2, 4, 7, 12, 20, 33…）
- m 阶 B 树：根至少 2 棵子树；非根结点至少 **⌈m/2⌉** 棵子树（**⌈m/2⌉ − 1** 个关键字），最多 m 棵子树
- 散列：装填因子 α = n / 表长；**ASL 与 α 有关，与 n 无关**；线性探测会“聚集”

### 📐 排序（⭐⭐⭐）
| 算法 | 平均 | 最坏 | 最好 | 空间 | 稳定 |
|---|---|---|---|---|---|
| 直接插入 | n² | n² | **n** | 1 | ✅ |
| 折半插入 | n² | n² | n log n | 1 | ✅ |
| 希尔 | 约 n^1.3 | n² | —— | 1 | ❌ |
| 冒泡 | n² | n² | **n** | 1 | ✅ |
| 快速 | n log n | **n²** | n log n | **log n** | ❌ |
| 简单选择 | n² | n² | n² | 1 | ❌ |
| 堆 | n log n | n log n | n log n | 1 | ❌ |
| 归并 | n log n | n log n | n log n | **n** | ✅ |
| 基数 | d(n + r) | d(n + r) | d(n + r) | r | ✅ |
- 口诀：**“快些（希）选堆”不稳定**
- 每趟能确定一个元素最终位置：冒泡、简单选择、快速（枢轴）、堆
- 外部排序：k 路归并趟数 **⌈log_k r⌉**；败者树比较次数 ⌈log₂k⌉

## 二、计算机组成原理

### 📐 性能
- CPU 时间 = 指令数 × CPI × 时钟周期 = 指令数 × CPI / 主频
- MIPS = 主频 / (CPI × 10⁶)

### 📐 数据表示
- n 位补码范围 **[−2ⁿ⁻¹, 2ⁿ⁻¹ − 1]**；无符号 [0, 2ⁿ − 1]
- 移码 = 补码符号位取反（偏置 2ⁿ⁻¹）；IEEE 754 阶码偏置 **127**（float）/ **1023**（double）
- float：1 + 8 + 23，值 = (−1)ˢ × **1.M** × 2^(E−127)；E 全 0 非规格化，E 全 1 为 ∞/NaN
- 溢出：**OF = 最高位进位 ⊕ 次高位进位**；无符号 **CF**（减法 CF = 借位）
- 符号扩展：补码高位补符号位；无符号补 0
- 小端：**低字节在低地址**；对齐：k 字节数据地址是 k 的倍数，结构体大小是最大成员的倍数

### 📐 存储器
- 位扩展：数据线加宽；字扩展：地址线增加，片选；芯片数 = 总容量 / 单片容量
- 交叉存储：连续地址分布在不同模块；m 体交叉，理想带宽提升 m 倍
- 磁盘：访问时间 = **寻道 + 平均旋转延迟（半圈）+ 传输时间**
- **Cache**：Tag = 地址位数 − 组号位 − 块内位；**比较器个数 = 路数**，位数 = Tag；行位数 = V + Tag + 数据 +（脏位）+（LRU log₂K）
- 平均访问时间 = t_c + (1 − H) t_m（先 Cache 后主存）
- 单缓冲、双缓冲见操作系统
- **TLB ⊂ 页表，Cache ⊂ 主存**：TLB 命中而页缺失 ✗；页缺失而 Cache 命中 ✗
- VIPT 条件：Cache 每路大小（组数 × 块大小）≤ 页大小

### 📐 指令与 CPU
- 扩展操作码：下一层可用数 = 上一层剩余 × 2^扩展位
- 相对寻址：EA = **(PC) + A**，PC 已指向下一条
- MAR 位数 = 地址线；MDR 位数 = 数据线；IR = 指令字长
- 字段直接编码：每字段 **⌈log₂(k+1)⌉** 位；下址字段 ⌈log₂(微指令总数)⌉
- **流水线**：n 条指令 k 段：(k + n − 1)Δt；有转发 load-use 阻塞 **1**，ALU 相关阻塞 **0**；无转发紧跟相关阻塞 **2**
- 故障（缺页）返回**本条**；自陷（系统调用）返回**下一条**

### 📐 总线与 I/O
- 带宽 = **工作频率 × 宽度**
- 中断 CPU 占用 = 每秒中断次数 × 每次周期数 / 主频
- DMA：周期挪用；**DMA 优先于 CPU**；DMA 只在开始和结束需要 CPU
- 屏蔽字 **1 = 屏蔽**；处理优先级可改，响应优先级不可改

## 三、操作系统

- 用户态 → 内核态：**只能通过中断/异常（陷入）**；陷入指令是**非特权**指令
- 进程状态：阻塞 → 运行 ✗；就绪 → 阻塞 ✗
- **周转 = 完成 − 到达**；带权周转 = 周转 / 运行；响应比 = 1 + 等待 / 服务
- 记录型信号量：P 后 **< 0** 阻塞；V 后 **≤ 0** 唤醒；|S| = 等待数
- **同步 P 在前，互斥 P 在后**
- 死锁最少资源 = **Σ(kᵢ − 1) + 1**；银行家：Need = Max − Allocation，Work += **Allocation**
- 分页：物理地址 = **页框号 × 页大小 + 偏移**；段式：**基址 + 偏移**（检查越界）
- 快表 EAT（串行）= t + T + (1 − α)T
- 缺页 EAT = (1 − p) × ma + p × 缺页时间
- 虚存最大容量 = **2^地址位数**；实际 = min(内存 + 外存, 最大)
- 置换：**只有 FIFO 有 Belady**；CLOCK 最多 2 轮；改进型 CLOCK 最多 4 轮
- 驻留集 ≥ 工作集，否则抖动
- 混合索引最大文件 = (直接数 + n + n² + n³) × 块大小，n = 块大小 / 地址项大小
- 位示图：盘块号 b = n·i + j（从 0 开始）
- 单缓冲每块 **max(C, T) + M**；双缓冲 **max(T, M + C)**
- 磁盘调度：SSTF 可能饥饿；SCAN 到尽头；LOOK 到最远请求；C-SCAN 返回不处理
- 引导：ROM → MBR → PBR → OS 初始化；格式化：物理 → 分区 → 逻辑 → 装 OS

## 四、计算机网络

- 网络中 k/M/G = **10³/10⁶/10⁹**
- 发送时延 = 长度 / 速率；传播时延 = 距离 / 速度；时延带宽积 = 传播时延 × 带宽
- 分组交换：(k + n − 1) × p / b
- **奈氏**：2W log₂V；**香农**：W log₂(1 + S/N)，**dB = 10 lg(S/N)**
- 曼彻斯特波特率 = 2 × 比特率；**差分曼彻斯特：起点跳变 = 0**
- CRC：补 r 个 0，模 2 除（异或）；海明：2^r ≥ k + r + 1；码距 d：检错 d−1，纠错 ⌊(d−1)/2⌋
- SW 利用率 = T_D / (T_D + RTT + T_A)；**GBN W ≤ 2ⁿ − 1；SR W ≤ 2ⁿ⁻¹**
- CSMA/CD：**最短帧长 = 2τ × C**；以太网 64B（51.2μs）；退避 r ∈ [0, 2^min(k,10) − 1]，16 次丢弃
- 以太网帧：6 + 6 + 2 + (46~1500) + 4；MTU 1500
- 802.11：地址 1 接收者，地址 2 发送者；SIFS 最短，DIFS 最长
- 集线器：不隔离；交换机：隔离冲突域；路由器：都隔离
- IP 首部 20~60B；首部长度单位 **4B**，片偏移单位 **8B**；TCP 6、UDP 17、ICMP 1
- 子网：网络地址 = IP AND 掩码；主机数 **2^h − 2**；块大小 = 256 − 掩码关键字节
- 私有地址：**10/8、172.16/12、192.168/16**
- ARP 请求广播、响应单播；DHCP：UDP 67/68，Discover/Request 源 0.0.0.0、目的 255.255.255.255
- RIP：UDP 520、跳数 ≤ 15、30s；OSPF：IP 89、洪泛、Dijkstra；BGP：TCP 179、路径向量
- IPv6：128 位、首部 40B、无检验和、路由器不分片
- 端口：FTP 21/20、SSH 22、Telnet 23、SMTP 25、DNS 53、HTTP 80、POP3 110、IMAP 143、HTTPS 443
- UDP 首部 8B；TCP 首部 20~60B；**SYN、FIN 消耗一个序号**
- TIME-WAIT 等 **2MSL**；三次握手、四次挥手
- 发送窗口 = min(rwnd, cwnd)；慢开始 ×2，拥塞避免 +1；**超时 → cwnd = 1**；**3 个重复 ACK → cwnd = ssthresh = cwnd/2**
- DNS：主机→本地递归，本地→其他迭代；HTTP 非持久每对象 2 RTT，持久流水线共 1 RTT
