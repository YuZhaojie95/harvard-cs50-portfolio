# 冲刺篇 第 3 课 · 零基础冲刺 120 分的复习计划

> 🎯 目标：**408 拿到 120 分**（满分 150）。
> 这份计划假设你**零基础**、每天能投入 **3~4 小时**给 408，总共约 **8~9 个月**。时间更少就按比例压缩，但**顺序不要变**。

---

## 一、120 分是什么概念

| 部分 | 满分 | 120 分目标 | 说明 |
|---|---|---|---|
| 选择题（40 题） | 80 | **64~68**（错 6~8 题） | 选择题是基本盘，必须稳 |
| 数据结构大题（41、42） | 约 23~25 | **16~18** | 算法题写出暴力解也有 9~11 分 |
| 组成原理大题（43、44） | 约 21~23 | **13~15** | Cache、虚拟存储是重点 |
| 操作系统大题（45、46） | 约 15 | **10~12** | PV 题套路固定，要拿满 |
| 网络大题（47） | 9 | **6~7** | “放电影”题，送分为主 |
| **合计** | 150 | **≈ 120** | |

📌 **结论**：选择题错 7 题以内 + 大题拿 50 分左右，就能到 120。不需要每道题都会，但**常考点一定不能丢**。

## 二、四个阶段

### 📅 第一阶段：基础（约 3.5 个月）——把本课程从头学一遍
**目标**：每个知识点都“听懂了、会做例题”。
| 周次 | 内容 | 课程 |
|---|---|---|
| 第 1 周 | 预备知识：数制、C 语言、复杂度 | [00-导学与预备](../00-导学与预备/00-课程导学.md) |
| 第 2~5 周 | **数据结构**：线性表、栈队列、串、树 | 数据结构第 1~15 课 |
| 第 6~7 周 | 数据结构：图、查找 | 数据结构第 16~26 课 |
| 第 8 周 | 数据结构：排序、算法题专题 | 数据结构第 27~32 课 |
| 第 9~10 周 | **组成原理**：数据表示与运算 | 组成原理第 1~6 课 |
| 第 11~12 周 | 组成原理：存储系统（**重点**） | 组成原理第 7~12 课 |
| 第 13~14 周 | 组成原理：指令系统、CPU、流水线 | 组成原理第 13~19 课 |
| 第 15 周 | 组成原理：总线、I/O | 组成原理第 20~21 课 |

**方法**：
- 每课先读“🎯 本课目标”，再读正文，**例题自己动手算一遍**（不要只看）
- 每课的“🏋️ 课后练习”**必须做**，做完对答案
- 看不懂的地方**先标记**，继续往下学，学完一章再回头看——很多概念学到后面自然就懂了

| 第 18~19 周 | 操作系统：内存管理（**重点**） | 操作系统第 9~12 课 |

### 📅 第三阶段：真题（约 1.5 个月）
**目标**：把 2020~2025 五套真题（以及能找到的 2009~2019 年真题）**全部做透**。
1. **按科目**做历年真题选择题（例如先做所有年份的数据结构选择题），找出薄弱章节，回到课程复习
2. **整套限时模拟**：每周做 1~2 套，**严格 180 分钟**
3. 对照 [真题考点索引](01-真题考点索引.md) 批改，错题回到对应课程
4. 大题按 [大题答题模板](02-大题答题模板.md) **规范书写**
5. 建立**错题本**：每道错题写清“错因 + 正确思路 + 对应课程”

### 📅 第四阶段：冲刺（最后 1 个月）
- 每周 2 套**模拟题**，保持手感
- 背熟 [考前速记](04-考前速记.md) 中的公式和结论
- 最后 10 天：**只看错题本和速记**，不做新难题
- 考前 3 天：调整作息，按考试时间（下午 14:00~17:00）做一套题

## 四、学习方法建议

1. **“看懂”不等于“会做”**：每个例题都要**合上书自己做一遍**
2. **公式要理解推导**，不要死记（比如为什么 GBN 窗口 ≤ 2ⁿ − 1），理解了才不会在变形题上出错
3. **多画图**：树、图、页表、时空图、拓扑图——408 很多题靠画图解决
4. **错题比新题重要**：一道错题反复弄懂，胜过做十道新题
5. **两个版本配合使用**：
   - 本课程（**完整版**，`408-full-course/`）：用于**第一遍系统学习**和查漏补缺
   - `408-tutorial/`（**精简版**）：用于**复习和考前快速回顾**
6. **保持节奏**：每天固定时间学 408，比周末突击效果好得多

## 五、时间不够怎么办？

若只剩 **3~4 个月**：
- 第 1 个月：数据结构 + 组成原理的**必须拿满**部分
- 第 2 个月：操作系统 + 网络的**必须拿满**部分
- 第 3 个月：五套真题 + 错题
- 最后几周：速记 + 模拟

📌 **优先保证选择题正确率**，大题只抓 **PV、Cache、页表、子网划分、TCP** 这几类最稳的题型。
