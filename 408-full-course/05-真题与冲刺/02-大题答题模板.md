# 冲刺篇 第 2 课 · 大题答题模板（41~47 题）

> 🎯 408 的 7 道大题共 **70 分**，想考 120 分，大题至少要拿 **45~50 分**。
> 大题不是“会不会”的问题，而是“**写没写到得分点**”的问题。这一课把每道大题的**固定套路**和**得分点**整理成模板。

---

## 总原则

1. **先写结论，再写理由**：阅卷老师是按点给分的，结论写在最前面最显眼
2. **每一问单独作答**，标清 (1)(2)(3)，不要混在一起
3. **写出计算过程和公式**：结果错了，过程也能得分
4. **不会的问也要写**：写出相关的概念、公式、思路，往往能拿到一半分
5. 时间分配：选择题 **60~70 分钟**，大题 **110~120 分钟**；**算法题（41 题）最后写**也可以，但不要空着

## 一、第 41 题：数据结构算法设计题（13~15 分）

### 📐 答题三段式（必须严格按这个结构写）
```
(1) 算法的基本设计思想：
    ……（用 3~6 句话讲清楚：用什么方法 / 什么数据结构 / 怎么遍历 / 核心判断是什么）

(2) 算法实现（C 或 C++），关键之处给出注释：
    ……代码……

(3) 时间复杂度 O(…)，空间复杂度 O(…)
```

### 📐 得分策略
| 你的水平 | 策略 | 大约得分 |
|---|---|---|
| 想到最优解 | 写最优解，注释清楚 | 满分 |
| 只想到暴力解 | **一定要写暴力解**（如两重循环、排序后处理），标明复杂度 | 最多扣 3~5 分，能拿 **9~11 分** |
| 什么都想不到 | 写清楚题意分析、数据结构定义、遍历框架 | 3~5 分 |

⚠️ **暴力解的分数远高于空白**！真题中 2020 年（三元组最小距离）、2025 年（乘积最大值）的暴力解都能拿大部分分。

### 📐 常见套路（见[数据结构 第 32 课 · 算法题专题](../01-数据结构/32-算法题专题.md)）
- **数组**：排序 + 双指针、计数（辅助数组）、多指针同时扫描（2020-41）、前缀/后缀最值（2025-41）
- **链表**：快慢指针、头插法逆置、双指针找公共结点
- **树**：递归遍历（先/中/后序）、层次遍历（队列）、**中序遍历判断 BST**（2022-41）
- **图**：遍历邻接矩阵统计度（2021-41 欧拉路径、2023-41 K 顶点）

### 📐 代码书写规范
- 先写**数据结构定义**（题目给了就直接用）
- 变量名有意义，关键语句加注释
- 注意**边界**：空表、一个元素、下标越界
- 需要辅助数组时用 `malloc`，最后可以 `free`

### 📐 Cache 题模板（出现频率最高）
```
① 块内地址 = log₂(块大小) 位
② 行数 = Cache 容量 / 块大小；组数 = 行数 / 路数
③ 组号（行号）= log₂(组数) 位
④ Tag = 地址位数 − 组号位数 − 块内地址位数
⑤ 行位数 = 有效位 1 + Tag + 数据位 + (脏位：回写法) + (LRU 位：log₂路数)
⑥ 缺失次数：看数组总大小 / 块大小、起始地址是否块对齐、访问顺序、是否冲突
⑦ 命中率 = 1 − 缺失次数 / 总访问次数
⑧ 平均访问时间 = 命中时间 + 缺失率 × 缺失损失
```

### 📐 机器级代码题模板
- 指令地址：**上一条地址 + 上一条指令长度**
- 相对寻址目标 = **(PC) + 偏移量**，(PC) 是**下一条指令**的地址
- 立即数、位移量在机器码中按**小端**排列 → 判断大小端
- 循环：向回跳的条件转移；`jg/jl` 有符号，`ja/jb` 无符号
- 缺页：指令/数据所在页之前是否访问过

### 📐 答题要点
- **写出地址的二进制划分**（Tag | Index | Offset），标明位数
- 十六进制地址计算时，写出加了多少（如 +100H）
- 涉及“为什么”时，一句话讲原理

## 四、第 45 题：PV 操作（7~8 分）

### 📐 答题模板（见[操作系统 第 7 课](../03-操作系统/07-PV大题专题与管程.md)）
```
① 信号量定义（每个都要写含义和初值）：
   semaphore mutex = 1;   // 互斥访问 ……
   semaphore empty = n;   // 空闲 …… 数
   semaphore full = 0;    // …… 的数量

② 进程描述：
   Process A() {
       while (1) {
           P(empty);     // 同步 P 在前
           P(mutex);     // 互斥 P 在后
           ……
           V(mutex);
           V(full);
       }
   }
```

### 📐 检查清单
- [ ] 每个信号量写了**含义**和**初值**
- [ ] **同步 P 在互斥 P 之前**（否则可能死锁）
- [ ] P、V **成对**，没有遗漏
- [ ] 只有一个进程使用的资源**不设**信号量
- [ ] 同一进程内的先后顺序**不需要**信号量
- [ ] “最多 k 个”用资源信号量 = k；“连续做 k 次”用互斥信号量包住循环
- [ ] 多资源时检查是否会**死锁**

### 📐 地址转换题模板
```
① 写出逻辑地址的划分：| 页目录号 | 页号 | 页内偏移 |（各几位）
② 把十六进制地址写成二进制，切分出每一段
③ 页目录项地址 = 页目录基址 + 页目录号 × 项长
④ 页表项地址 = 页表所在页框号 × 页大小 + 页号 × 项长
⑤ 物理地址 = 页框号 × 页大小 + 页内偏移
```

### 📐 文件多级索引模板
```
① 每块能放的地址项 n = 块大小 / 地址项大小
② 直接 a 项：a × 块大小；一级：n × 块大小；二级：n² × 块大小……
③ 累加，看文件大小落在哪一段
④ 读盘次数 = 索引级数 + 1（顶层 inode 已在内存时）
```

## 六、第 47 题：计算机网络综合题（9 分）

见[计算机网络 第 17 课 · 网络综合大题专题](../04-计算机网络/17-网络综合大题专题.md)。

### 📐 “放电影”模板
```
① 标注拓扑：每个接口的 IP/前缀、MAC；设备类型；私有地址 → NAT
② 按时间顺序：DHCP → ARP → DNS → TCP 握手 → HTTP → TCP 挥手
③ 每一跳：IP 不变（除 NAT），MAC 变，TTL − 1
④ 计算：发送时延 = 长度/速率；传播时延 = 距离/速度；RTT；窗口；cwnd
```

### 📐 高频得分点
- 协议封装：**DNS → UDP → IP → 以太网帧**；HTTP/FTP/SMTP → TCP
- 广播地址：ARP 请求、DHCP Discover/Request 的目的 MAC **FF-FF-FF-FF-FF-FF**，DHCP 的源 IP **0.0.0.0**、目的 IP **255.255.255.255**
- 802.11 四地址：**地址 1 接收者，地址 2 发送者**
- TCP：SYN/FIN 消耗序号；ack = 期望的下一个字节；cwnd 慢开始 ×2、拥塞避免 +1
- CSMA/CD：2τ ≤ 最短帧发送时间

## ⚠️ 最后的提醒

- 大题**不要空着**，写出相关概念也有分
- 字迹工整，答案**写在规定区域**
- 计算题的**单位**（B / b、ms / μs、K = 10³ 还是 2¹⁰）一定写清楚
- 多检查“**看错题目条件**”：值越大优先级越高还是越低？编号从 0 还是 1 开始？十进制还是十六进制？
