## 🚪 课前引入

网络大题的特点是：**给一张拓扑图 + 一个场景**（访问网页、传文件、获取 IP 地址……），然后一问接一问地考你**这个过程中发生了什么**。它往往**跨越多层**：
- 应用层：DNS、HTTP、FTP、DHCP
- 传输层：TCP 握手、序号、拥塞窗口
- 网络层：IP 地址、子网、NAT、路由
- 数据链路层：MAC 地址、ARP、交换机、802.11、CSMA/CD

只要你能在脑子里“**放电影**”，把整个通信过程一帧一帧地演出来，这类题就不难。

## 一、通用解题思路（⭐⭐⭐）

### 📐 第一步：读图，标注信息
- 每台主机、路由器接口的 **IP 地址/前缀**、**MAC 地址**
- 哪些设备是**路由器**（隔离广播域）、**交换机**（隔离冲突域）、**集线器**（什么都不隔离）、**AP**
- 哪些是**私有地址**（10.x、172.16~31.x、192.168.x）→ 可能涉及 **NAT**
- 哪些主机在**同一子网**（用前缀判断）

### 📐 第二步：按时间顺序“放电影”
以“主机 H 访问 www.xxx.com”为例，完整过程：
1. **（若需要）DHCP** 获取 IP 地址：Discover（广播）→ Offer → Request（广播）→ ACK
2. **DNS 解析**：
   - H 判断本地域名服务器是否同一子网 → **ARP** 查它的 MAC（或查网关的 MAC）
   - 向本地域名服务器发送 DNS 查询（**UDP 53**）
   - 本地域名服务器递归/迭代查询 → 返回 IP
3. **TCP 三次握手**：H 判断 Web 服务器在外网 → **ARP** 查默认网关 MAC → 发 SYN……
4. **HTTP 请求/响应**（TCP 80）
5. 经过路由器时：**IP 地址不变**（除 NAT），**MAC 地址每跳都变**，**TTL − 1**
6. 经过 NAT 路由器时：**源 IP + 源端口**被替换
7. **TCP 四次挥手**

### 📐 第三步：逐问作答，写清理由
- 地址题：写出**完整的**十六进制/点分十进制
- 过程题：按**时间顺序**写，写出协议名称
- 计算题：写出公式和中间步骤

## 二、2020 年第 47 题（9 分）：NAT

> 某校园网有两个局域网，通过路由器 R1、R2 和 R3 互联后接入 Internet，S1 和 S2 为以太网交换机。局域网采用静态 IP 地址配置。R1 连接 Internet，R1 的两个接口 203.10.2.1/30、203.10.2.5/30 分别与 R2 的外网接口 203.10.2.2/30、R3 的外网接口 203.10.2.6/30 相连；R2 和 R3 都实现 NAT，内网接口都是 192.168.1.1。R2 经 S1 连接 Web 服务器（192.168.1.2）和 H1（192.168.1.3）；R3 经 S2 连接 H2（192.168.1.2）和 H3（192.168.1.3）。NAT 转换表结构为 | 外网 IP 地址 | 端口号 | 内网 IP 地址 | 端口号 |。
> 1）为使 H2 和 H3 能够访问 Web 服务器（使用默认端口号），需要进行什么配置？
> 2）若 H2 主动访问 Web 服务器时，将 HTTP 请求报文封装到 IP 数据报 P 中发送，则 H2 发送 P 的源 IP 地址和目的 IP 地址分别是什么？经过 R3 转发后，P 的源 IP 地址和目的 IP 地址分别是什么？经过 R2 转发后，P 的源 IP 地址和目的 IP 地址分别是什么？

**1）** 在 R2 上配置**静态 NAT 映射**（端口映射），使外网可以主动访问内网的 Web 服务器：
| 外网 IP 地址 | 端口号 | 内网 IP 地址 | 端口号 |
|---|---|---|---|
| 203.10.2.2 | 80 | 192.168.1.2 | 80 |

**2）**
| 位置 | 源 IP | 目的 IP |
|---|---|---|
| H2 发出 | 192.168.1.2 | 203.10.2.2 |
| 经 R3（NAT）后 | 203.10.2.6 | 203.10.2.2 |
| 经 R2（NAT）后 | 203.10.2.6 | 192.168.1.2 |

🧒 **思考**：为什么 H2 的目的地址写 203.10.2.2 而不是 192.168.1.2？——H2 所在内网也有一台 192.168.1.2（就是 H2 自己！），而且私有地址在公网上无法路由。H2 只能访问 Web 服务器**对外公布**的地址。

## 三、2021 年第 47 题（9 分）：DNS + ARP + 交换机

> 某网络拓扑如图所示，以太网交换机 S 通过路由器 R 与 Internet 互联。路由器部分接口、本地域名服务器、H1、H2 的 IP 地址和 MAC 地址如图中所示：
> - R：192.168.1.1/25，00-11-22-33-44-aa（接 S 的端口 2）
> - 本地域名服务器：192.168.1.126/25，00-11-22-33-44-bb（接 S 的端口 1）
> - H2：192.168.1.3/25，00-11-22-33-44-dd（接 S 的端口 3）
> - H1：192.168.1.2/25，00-11-22-33-44-cc（接 S 的端口 4）
>
> 在 t₀ 时刻 H1 的 ARP 表和 S 的交换表均为空，H1 在此刻利用浏览器通过域名 www.abc.com 请求访问 Web 服务器，在 t₁ 时刻（t₁ > t₀）S 第一次收到了封装 HTTP 请求报文的以太网帧，假设从 t₀ 到 t₁ 期间网络未发生任何与此次 Web 访问无关的网络通信。
> 1）从 t₀ 到 t₁ 期间，H1 除了 HTTP 之外还运行了哪个应用层协议？从应用层到数据链路层，该应用层协议报文是通过哪些协议进行逐层封装的？
> 2）若 S 的交换表结构为 < MAC 地址, 端口 >，则 t₁ 时刻 S 交换表的内容是什么？
> 3）从 t₀ 到 t₁ 期间，H2 至少会接收到几个与此次 Web 访问相关的帧？接收到的是什么帧？帧的目的 MAC 地址是什么？

**1）** H1 还运行了 **DNS** 协议（把域名 www.abc.com 解析为 IP 地址）。封装过程：**DNS 报文 → UDP 用户数据报 → IP 数据报 → 以太网帧**（CSMA/CD 以太网 802.3）

**2）** 从 t₀ 到 t₁，H1 先后与本地域名服务器、路由器 R 通信（ARP、DNS、TCP 握手），S 学习到了三个 MAC 地址：
| MAC 地址 | 端口 |
|---|---|
| 00-11-22-33-44-cc | 4 |
| 00-11-22-33-44-bb | 1 |
| 00-11-22-33-44-aa | 2 |

**3）** H2 至少收到 **2 个帧**，都是 **ARP 请求帧**：
- 第 1 个：H1 查询**本地域名服务器**（192.168.1.126，同一子网 /25）的 MAC 地址
- 第 2 个：H1 查询**默认网关 R**（192.168.1.1）的 MAC 地址（Web 服务器在外网）
- 目的 MAC 地址都是 **FF-FF-FF-FF-FF-FF**（广播）
- 其余的帧（ARP 响应、DNS、TCP）都是单播帧，S 已经学习到目的端口，不会转发给 H2

## 四、2022 年第 47 题（9 分）：设备选择 + CSMA/CD + DHCP + 802.11

> 某网络拓扑如图所示，R 为路由器，S 为以太网交换机，AP 是 802.11 接入点，路由器的 E0 接口和 DHCP 服务器的 IP 地址配置如图中所示；H1 与 H2 属于同一个广播域，但不属于同一个冲突域；H2 和 H3 属于同一个冲突域；H4 和 H5 已经接入网络，并通过 DHCP 动态获取了 IP 地址。现有路由器、100BaseT 以太网交换机和 100BaseT 集线器（Hub）三类设备各若干台。
> - R 的一个接口连接设备 1；设备 1 连接 H1 和设备 2；设备 2 连接 H2、H3
> - R 的 E0：192.168.0.1/25，00-11-11-11-11-A1，连接交换机 S
> - S 连接 DHCP 服务器（192.168.0.2/25，00-11-11-11-11-B1）和 AP（00-11-11-11-11-C1）
> - H4：192.168.0.3/25，00-11-11-11-11-D1；H5：192.168.0.4/25，00-11-11-11-11-E1（均通过 AP 接入）
>
> 1）设备 1 和设备 2 应该分别选择哪类设备？
> 2）若信号传播速度为 2 × 10⁸ m/s，以太网最小帧长为 64B，信号通过设备 2 时会产生额外的 1.51μs 的时间延迟，则 H2 与 H3 之间可以相距的最远距离是多少？
> 3）在 H4 通过 DHCP 动态获取 IP 地址过程中，H4 首先发送了 DHCP 报文 M，M 是哪种 DHCP 报文？路由器 E0 接口能否收到封装 M 的以太网帧？S 向 DHCP 服务器转发的封装 M 的以太网帧的目的 MAC 地址是什么？
> 4）若 H4 向 H5 发送一个 IP 分组 P，则 H5 收到的封装 P 的 802.11 帧的地址 1、地址 2 和地址 3 分别是什么？

**1）**
- 设备 1：H1 和 H2 在同一广播域、不同冲突域 → 能隔离冲突域但不隔离广播域 → **以太网交换机**
- 设备 2：H2 和 H3 在同一冲突域 → **集线器**

**2）** 100BaseT：发送最短帧 512 bit 需要 512 / 10⁸ = **5.12μs**（争用期，往返）
- 2 × (d / (2 × 10⁸) + 1.51 × 10⁻⁶) ≤ 5.12 × 10⁻⁶
- d / (2 × 10⁸) ≤ 1.05 × 10⁻⁶ → **d ≤ 210m**

**3）**
- M 是 **DHCP 发现（Discover）**报文
- M 被封装在**广播帧**中，交换机 S 向所有端口转发，路由器 **E0 接口能收到**（但路由器不会把它转发到其他网络）
- 目的 MAC 地址是 **FF-FF-FF-FF-FF-FF**

**4）** H5 收到的帧是 **AP 转发给 H5** 的（From DS = 1）：
- 地址 1（接收端）= **00-11-11-11-11-E1**（H5）
- 地址 2（发送端）= **00-11-11-11-11-C1**（AP）
- 地址 3（源地址）= **00-11-11-11-11-D1**（H4）

## 六、2025 年第 47 题（9 分）：卫星链路 + GBN + 子网划分

> 如题 47 图所示，卫星天通一号的轨道高度是 36000km，电磁波传播速度为 300000km/s。TR1 和 TR2 用于收发卫星信号，采用全双工调制解调，其收发速率为 200Kbps。工程部网络（管理区子网中有主机 H：10.10.10.33/26，经交换机 S1 连到路由器 R1；R1 还连接作业区子网和生活区子网）通过 R1—TR1—卫星—TR2—R2 连接到公司总部网络（R2 连接 Internet 和公司总部服务器）。
> (1) 忽略卫星信号中继，TR1、TR2 调制解调开销，则 R1 到 R2 之间的卫星链路单向传播时延是多少？主机 H 向总部服务器传输数据时可达到的最大吞吐量是多少？若忽略各层协议首部开销，以及以太网的传播时延，则 H → server 上传一个 4000B 的文件，至少需要多长时间？（3 分）
> (2) 基于 GBN 为卫星链路设计单向可靠的链路层协议 SLP，支持 R1 → R2 发送数据。SLP 数据帧长 1500B，忽略 ACK 帧长度，要求 SLP 单向信道利用率不低于 80%，则发送窗口至少为多少？SLP 帧序号至少为多少？（3 分）
> (3) 总部给工程部分配 IP 地址空间 10.10.10.0/24，再划分为 3 个子网，生活区子网不少于 120 个，作业子网、管理区子网 IP 均不少于 60 个，H 已正确配置 IP。问作业区子网、管理区子网、生活区子网地址各是多少？（3 分）

**(1)**
- 单向传播时延：上行 36000km + 下行 36000km = 72000km，72000 / 300000 = **0.24s = 240ms**
- 最大吞吐量：瓶颈是卫星链路 **200kbps**
- 上传 4000B：发送时延 = 4000 × 8 / 200000 = **0.16s**；再加卫星链路传播时延 0.24s（以太网部分速率高、传播时延忽略，其发送时延相对很小也可忽略）→ 至少约 **0.4s = 400ms**

**(2)**（详见第 4 课）
- T_D = 1500 × 8 / 200000 = **60ms**，RTT = 2 × 240 = **480ms**
- W × 60 / (60 + 480) ≥ 0.8 → W ≥ 7.2 → **发送窗口至少 8**
- GBN：W ≤ 2ⁿ − 1 → 2ⁿ ≥ 9 → **帧序号至少 4 位**

**(3)**（详见第 8 课）
| 子网 | 地址 |
|---|---|
| **管理区**（H 所在） | **10.10.10.0/26** |
| **作业区** | **10.10.10.64/26** |
| **生活区** | **10.10.10.128/25** |

## 七、综合练习：一次完整的网页访问

✏️ 主机 H（192.168.1.10/24，MAC h）通过交换机连接路由器 R 的内网接口（192.168.1.1，MAC r1），R 实现 NAT，外网接口 202.1.1.1（MAC r2），通过 ISP 路由器（MAC isp）连接互联网。本地域名服务器 202.2.2.2 在 ISP 处。H 刚开机，ARP 缓存为空，DNS 缓存为空。H 访问 http://www.example.com（IP 为 93.184.216.34），请按顺序写出 H 发出的前几个分组。

| 顺序 | 协议 | 说明 | 源 IP → 目的 IP | 源 MAC → 目的 MAC |
|---|---|---|---|---|
| 1 | **ARP 请求** | 查网关 192.168.1.1 的 MAC（本地域名服务器在外网） | —— | h → **FF-FF-FF-FF-FF-FF** |
| 2 | ARP 响应（R 发） | 192.168.1.1 的 MAC 是 r1 | —— | r1 → h |
| 3 | **DNS 查询**（UDP 53） | 查询 www.example.com | 192.168.1.10 → 202.2.2.2（经 NAT 后源变为 202.1.1.1） | h → r1 |
| 4 | DNS 响应 | 93.184.216.34 | —— | —— |
| 5 | **TCP SYN**（端口 80） | 三次握手第一步 | 192.168.1.10 → 93.184.216.34（经 NAT 后源变为 202.1.1.1:新端口） | h → r1（ARP 缓存已有 r1，不必再 ARP） |
| 6 | TCP SYN+ACK | | | |
| 7 | TCP ACK + **HTTP GET** | 第三次握手可携带请求 | | |

📌 要点：
- 本地域名服务器在**外网**，所以第一个 ARP 查的是**网关**的 MAC，而不是域名服务器的
- 之后访问 Web 服务器也是先交给网关，**ARP 缓存已经有了**，不需要再次 ARP
- 出 NAT 时源 IP（和源端口）被替换；在 R 到 ISP 这一段，帧的源 MAC 是 r2，目的 MAC 是 isp

## ⚠️ 易错点

1. **同一子网直接 ARP 目的主机；不同子网 ARP 网关**
2. 交换机**只学习源 MAC**；广播帧/未知目的的帧会泛洪
3. **ARP 请求、DHCP Discover/Request 都是广播**（FF-FF-FF-FF-FF-FF）
4. 802.11：**地址 1 接收者、地址 2 发送者、地址 3 另一端**
5. NAT：私有网络主机访问外网，改**源地址**；外网访问内网服务器，需**静态映射**，改**目的地址**
6. 卫星链路单向传播时延 = **上行 + 下行**
7. 集线器的额外时延在往返中要算**两次**
8. DNS 封装：**DNS → UDP → IP → 以太网帧**
