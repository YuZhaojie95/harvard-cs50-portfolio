## 🚪 课前引入

IP 地址就像**电话号码**：`010-12345678`
- `010` 是**区号**（北京）——对应 IP 地址的**网络号**
- `12345678` 是**本地号码**——对应 IP 地址的**主机号**

打电话时，交换机先看区号把电话转到北京，再在北京内部按本地号码接通。路由器转发 IP 分组也是这样：**先看网络号，把分组送到目的网络，再在网络内部送到主机**。

问题是：一个 IP 地址 `192.168.1.100`，**哪几位是网络号、哪几位是主机号**？——这就是本课的核心。

## 一、IP 地址基础（⭐⭐）

### 📐 IP 地址
- **IP 地址**：全世界唯一的 **32 位（4 字节）**标识符，标识**路由器主机的接口**
- 通常用**点分十进制**表示：每 8 位一组，转成十进制，用点隔开
  - 例：`11000000 10101000 00000001 01100100` → **192.168.1.100**
- **IP 地址 = {< 网络号 >, < 主机号 >}**
- ⚠️ IP 地址标识的是**接口**，不是主机：一台路由器有多个接口，就有**多个 IP 地址**

### 📐 二进制速查（⭐⭐⭐ 必须熟练）
| 二进制 | 十进制 | 二进制 | 十进制 |
|---|---|---|---|
| 1000 0000 | 128 | 1111 1000 | 248 |
| 1100 0000 | 192 | 1111 1100 | 252 |
| 1110 0000 | 224 | 1111 1110 | 254 |
| 1111 0000 | 240 | 1111 1111 | 255 |

## 二、分类的 IP 地址（⭐⭐）

| 类别 | 首位 | 网络号 | 主机号 | 第一个字节范围 | 默认子网掩码 | 可用网络数 | 每个网络最大主机数 |
|---|---|---|---|---|---|---|---|
| **A** | **0** | 8 位 | 24 位 | **1 ~ 126** | 255.0.0.0 | 2⁷ − 2 = 126 | 2²⁴ − 2 |
| **B** | **10** | 16 位 | 16 位 | **128 ~ 191** | 255.255.0.0 | 2¹⁴ | 2¹⁶ − 2 = 65534 |
| **C** | **110** | 24 位 | 8 位 | **192 ~ 223** | 255.255.255.0 | 2²¹ | 2⁸ − 2 = **254** |
| D | 1110 | —— | —— | 224 ~ 239 | —— | **多播地址** | |
| E | 1111 | —— | —— | 240 ~ 255 | —— | 保留 | |

⚠️ A 类网络号 0 和 127 不能用（0 表示本网络，127 是环回地址），所以可用 A 类网络 **126** 个。

### 📐 特殊 IP 地址（⭐⭐⭐）
| 网络号 | 主机号 | 作为源地址 | 作为目的地址 | 含义 |
|---|---|---|---|---|
| **全 0** | **全 0** | ✅ | ❌ | **本网络上的本主机**（0.0.0.0，DHCP 请求时主机还没有 IP，就用它作源地址） |
| 全 0 | 特定值 | ✅ | ❌ | 本网络上的某台主机 |
| **全 1** | **全 1** | ❌ | ✅ | **受限广播地址**（255.255.255.255，只在**本网络**内广播，路由器**不转发**） |
| 特定值 | **全 0** | ❌ | ❌ | **网络地址**（表示一个网络，不能分配给主机） |
| 特定值 | **全 1** | ❌ | ✅ | **直接广播地址**（对特定网络上的所有主机广播） |
| **127** | 任意（非全 0/全 1） | ✅ | ✅ | **环回地址**（本机软件测试，如 127.0.0.1） |

📌 所以**主机号全 0 和全 1 都不能分配给主机**，每个网络可用主机数 = **2^主机位数 − 2**。

### 📐 私有 IP 地址（⭐⭐）
只用于机构**内部**通信，互联网上的路由器**不转发**目的地址是私有地址的分组：
| 类 | 私有地址范围 | 网段数 |
|---|---|---|
| A | **10.0.0.0 ~ 10.255.255.255** | 1 个 A 类网 |
| B | **172.16.0.0 ~ 172.31.255.255** | 16 个 B 类网 |
| C | **192.168.0.0 ~ 192.168.255.255** | 256 个 C 类网 |

私有地址的主机要访问互联网，需要 **NAT**（下一课）。

## 三、子网划分与子网掩码（⭐⭐⭐）

### 📐 为什么要划分子网
分类 IP 地址的问题：
- **利用率低**：一个 B 类网可以容纳 65534 台主机，但一个单位可能只有几千台
- **不够灵活**：一个单位有多个部门，希望各部门网络独立

**子网划分**：从**主机号**中**借用若干位**作为**子网号**：
```
划分前：|    网络号    |          主机号           |
划分后：|    网络号    |  子网号  |     主机号      |
         |<── 网络前缀（网络号 + 子网号）──>|
```
- 划分子网纯属一个单位**内部**的事情，对外仍然表现为一个网络
- 子网号可以全 0、全 1 吗？——**考试中现在一般允许**（CIDR 以后），除非题目明确说明不允许。主机号依然**不能全 0 或全 1**

### 📐 子网掩码（⭐⭐⭐）
**子网掩码**：与 IP 地址相对应的 32 位二进制串，**网络号和子网号对应的位为 1，主机号对应的位为 0**。
- 例：B 类地址借 8 位做子网号 → 子网掩码 **255.255.255.0**
- **网络地址 = IP 地址 AND 子网掩码**（逐位与）

📝 **真题（2022 年第 35 题）**：若某主机的 IP 地址是 183.80.72.48，子网掩码是 255.255.192.0，则该主机所在网络的网络地址是：A. 183.80.0.0　B. 183.80.64.0　C. 183.80.72.0　D. 183.80.192.0
- 前两个字节掩码为 255，照抄：183.80
- 第三个字节：72 AND 192 = 0100 1000 AND 1100 0000 = 0100 0000 = **64**
- 第四个字节：48 AND 0 = 0
- 网络地址 **183.80.64.0** → 选 **B**

### 📐 子网计算的“标准四步”（⭐⭐⭐）
给定 IP 地址和子网掩码（或前缀长度 /n）：
1. **找关键字节**：掩码中既不是 255 也不是 0 的那个字节（称为“兴趣字节”）
2. **网络地址**：关键字节 AND 掩码字节，之后的字节全 0
3. **块大小** = 256 − 掩码的关键字节；**广播地址** = 网络地址的关键字节 + 块大小 − 1，之后的字节全 255
4. **可用主机范围** = 网络地址 + 1 ~ 广播地址 − 1；**主机数** = 2^主机位数 − 2

✏️ **例**：IP 地址 **192.168.10.77/27**，求网络地址、广播地址、可用主机范围、可用主机数。
- /27 → 掩码 255.255.255.**224**（1110 0000）
- 关键字节是第 4 字节：77 AND 224 = 0100 1101 AND 1110 0000 = 0100 0000 = **64** → 网络地址 **192.168.10.64**
- 块大小 = 256 − 224 = **32** → 广播地址 = 64 + 32 − 1 = **95** → **192.168.10.95**
- 可用主机：**192.168.10.65 ~ 192.168.10.94**，共 2⁵ − 2 = **30** 台

📝 **真题（2023 年第 39 题）**：主机 168.16.84.24/20 所在子网的最小可分配 IP 地址和最大可分配 IP 地址分别是：
A. 168.16.80.1，168.16.84.254　B. 168.16.80.1，168.16.95.254　C. 168.16.84.1，168.16.84.254　D. 168.16.84.1，168.16.95.254
- /20 → 掩码 255.255.**240**.0，关键字节是第 3 字节
- 84 AND 240 = 0101 0100 AND 1111 0000 = 0101 0000 = **80** → 网络地址 **168.16.80.0**
- 块大小 256 − 240 = 16 → 第 3 字节范围 80 ~ 95 → 广播地址 **168.16.95.255**
- 最小可分配 **168.16.80.1**，最大可分配 **168.16.95.254** → 选 **B**

📝 **真题（2022 年第 36 题）**：下图所示网络中的主机 H 的子网掩码与默认网关分别是：
```
Internet ── 路由器 ──(192.168.1.1/30)── 路由器 ──(192.168.1.62/27)── 交换机 ── H（192.168.1.60）
```
A. 255.255.255.192，192.168.1.1　B. 255.255.255.192，192.168.1.62　C. 255.255.255.224，192.168.1.1　D. 255.255.255.224，192.168.1.62
- H 所在网络是与它**直接相连的路由器接口** 192.168.1.62/27 所在的网络
- /27 → 子网掩码 **255.255.255.224**
- 默认网关 = 该路由器接口的地址 **192.168.1.62**（H 的 60 和 62 都在 192.168.1.32/27 中：32~63）
→ 选 **D**

## 四、无分类编址 CIDR（⭐⭐⭐）

### 📐 CIDR（无分类域间路由选择）
- **消除了传统的 A 类、B 类和 C 类地址以及划分子网的概念**，因而可以更加有效地分配 IPv4 的地址空间
- IP 地址 = **{< 网络前缀 >, < 主机号 >}**，使用**斜线记法**：`IP 地址/网络前缀位数`，如 **128.14.35.7/20**
- **CIDR 地址块**：网络前缀相同的连续的 IP 地址组成的“CIDR 地址块”。一个 CIDR 地址块可以表示很多地址，这种地址的聚合常称为**路由聚合**，或构成**超网**
- 例：128.14.32.0/20 地址块：最小地址 128.14.32.0，最大地址 128.14.47.255，共 2¹² = 4096 个地址

### 📐 路由聚合（构成超网）（⭐⭐⭐）
**把多个网络前缀相同的小网络合并成一个大网络**，路由表中只需要一条路由，减少路由表项。
**方法**：把各网络地址写成二进制，找出**最长的公共前缀**。

✏️ **例**：把以下 4 个网络聚合：
- 172.18.**129**.0/24 → 第 3 字节 1000 0001
- 172.18.**130**.0/24 → 1000 0010
- 172.18.**132**.0/24 → 1000 0100
- 172.18.**133**.0/24 → 1000 0101
- 公共前缀：前两个字节 16 位 + 第 3 字节前 **5** 位（10000）= **21** 位
- 聚合后：172.18.**128**.0/21（1000 0000）

⚠️ 聚合后的地址块 172.18.128.0/21 范围是 172.18.128.0 ~ 172.18.135.255，其中**包含了**原来没有的 128、131、134、135 这几个网络——路由聚合可能会“**过度聚合**”，只要这些网络不在别的方向，就没问题。

### 📐 最长前缀匹配（⭐⭐⭐）
使用 CIDR 时，查找路由表可能得到**几个匹配结果**（跟网络掩码按位相与），应选择具有**最长网络前缀**的路由。前缀越长，其地址块越小，因而路由越**具体**。

✏️ **例**：路由表：
| 目的网络 | 下一跳 |
|---|---|
| 206.0.64.0/18 | R1 |
| 206.0.68.0/22 | R2 |
| 206.0.71.128/25 | R3 |
| 0.0.0.0/0（默认路由） | R4 |

目的地址 **206.0.71.130** 应转发到哪？
- 206.0.71.130 的第 3 字节 71 = 0100 0111，第 4 字节 130 = 1000 0010
- /18：206.0.**64**.0（第 3 字节前 2 位 01）→ 71 的前 2 位 01 ✓ 匹配
- /22：206.0.**68**.0（第 3 字节前 6 位 010001）→ 71 = 010001**11**，前 6 位 010001 ✓ 匹配
- /25：206.0.71.**128**（第 4 字节前 1 位 1）→ 130 的第 1 位是 1 ✓ 匹配
- 默认路由总是匹配
- 最长前缀是 **/25** → 转发给 **R3**

### 📐 子网划分的判断题
📝 **真题（2021 年第 35 题）**：现将一个 IP 网络划分为 3 个子网，若其中一个子网是 192.168.9.128/26，则下列网络中，**不可能**是另外两个子网之一的是：A. 192.168.9.0/25　B. 192.168.9.0/26　C. 192.168.9.192/26　D. 192.168.9.192/27
- 思路：3 个子网**互不重叠**，合起来恰好是**一个完整的网络**（一个地址块）
- A：192.168.9.0/25（0~127）+ 128/26（128~191）+ 192/26（192~255）= 192.168.9.0/24 ✓ 可能
- C：同上，192/26 可以是第三个 ✓
- D：192.168.9.128/26（128~191）+ 192/27（192~223）+ 224/27（224~255）= 192.168.9.128/25 ✓ 可能
- **B**：192.168.9.0/26（0~63）+ 128/26（128~191），要合成一个地址块至少要 192.168.9.0/24，剩下 64~127 和 192~255 **两段不连续**的地址，**无法用一个子网**覆盖 → 不可能
→ 选 **B**

## 五、子网规划（地址分配）大题（⭐⭐⭐）

### 📐 方法（按主机数从大到小分配）
1. 算出每个子网需要的**主机位数 h**：2^h − 2 ≥ 需要的主机数（**别忘了 −2**，还有的题要算上路由器接口）
2. 前缀长度 = 32 − h
3. **从大到小**依次分配：大的子网先分，保证地址块**对齐**（每个子网的网络地址必须是其块大小的整数倍）
4. 写出每个子网的网络地址、前缀/掩码、地址范围

📝 **真题（2025 年第 47 题第 3 问）**：总部给工程部分配 IP 地址空间 10.10.10.0/24，再划分为 3 个子网，生活区子网不少于 120 个，作业子网、管理区子网 IP 均不少于 60 个，H 已正确配置 IP（H 在管理区子网，IP 为 10.10.10.33/26）。问作业区子网、管理区子网、生活区子网地址各是多少？
1. 生活区 ≥ 120 → 2⁷ − 2 = 126 ≥ 120 → 主机位 7 → **/25**（128 个地址）
2. 作业区、管理区 ≥ 60 → 2⁶ − 2 = 62 ≥ 60 → 主机位 6 → **/26**（64 个地址）
3. 总共 128 + 64 + 64 = 256，恰好用完 /24
4. **H 的地址 10.10.10.33/26** 所在的 /26 子网：33 AND 192 = 0 → **10.10.10.0/26**，这就是**管理区**
5. 剩下的 64~255：一个 /26 和一个 /25。/25 必须对齐到 128 的倍数 → **10.10.10.128/25** 为**生活区**；**10.10.10.64/26** 为**作业区**

| 子网 | 网络地址 | 地址范围 |
|---|---|---|
| **管理区** | **10.10.10.0/26** | 10.10.10.0 ~ 10.10.10.63 |
| **作业区** | **10.10.10.64/26** | 10.10.10.64 ~ 10.10.10.127 |
| **生活区** | **10.10.10.128/25** | 10.10.10.128 ~ 10.10.10.255 |

✏️ **例（从大到小分配）**：某单位分配到 **202.118.1.0/24**，要划分给 4 个部门，分别需要 **100、50、20、10** 台主机。
- 100 台 → h = 7（126）→ /25：**202.118.1.0/25**（0~127）
- 50 台 → h = 6（62）→ /26：**202.118.1.128/26**（128~191）
- 20 台 → h = 5（30）→ /27：**202.118.1.192/27**（192~223）
- 10 台 → h = 4（14）→ /28：**202.118.1.224/28**（224~239）
- 剩余 202.118.1.240/28 备用

## ⚠️ 易错点

1. IP 地址标识的是**接口**
2. A 类 1~126，B 类 128~191，C 类 192~223，D 类多播 224~239
3. **主机号全 0 = 网络地址，全 1 = 广播地址**，都不能分配给主机，主机数 **2^h − 2**
4. **0.0.0.0** 只能作源地址；**255.255.255.255** 只能作目的地址（受限广播，路由器不转发）
5. 私有地址：**10/8、172.16/12、192.168/16**
6. **网络地址 = IP AND 掩码**
7. 块大小 = 256 − 关键字节掩码；**广播地址 = 网络地址 + 块大小 − 1**
8. 默认网关 = 与主机同一子网的**路由器接口地址**
9. 路由聚合：找**最长公共前缀**
10. **最长前缀匹配**：多条路由都匹配时选前缀最长的
11. 子网规划：**从大到小**分配，网络地址必须是块大小的整数倍

4. /22 共 1024 个地址（211.71.136.0 ~ 211.71.139.255）。400 → h = 9（510）→ /23：**211.71.136.0/23**；200 → h = 8（254）→ /24：**211.71.138.0/24**；100 → h = 7（126）→ /25：**211.71.139.0/25**；50 → h = 6（62）→ /26：**211.71.139.128/26** 和 **211.71.139.192/26**
5. 掩码 /26，130 AND 192 = 128 → 子网 202.100.5.128/26，可用 129~190。默认网关必须在同一子网且不是网络/广播地址 → **(b) 202.100.5.129**（191 是广播地址）
