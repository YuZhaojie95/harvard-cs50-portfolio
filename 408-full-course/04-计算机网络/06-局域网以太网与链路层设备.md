## 一、局域网概述（⭐）

### 📐 局域网的特点
**局域网（LAN）**：在某一区域内由多台计算机互联成的计算机组，使用**广播信道**。
- 覆盖的地理范围较小，只在一个相对独立的局部范围内联网，如一座或集中的建筑群内
- 使用专门铺设的传输介质（双绞线、同轴电缆）进行联网，数据传输速率高
- 通信延迟时间短，误码率低，可靠性较高
- 各站为**平等关系**，共享传输信道
- 多采用**分布式控制和广播式通信**，能进行广播和组播

### 📐 决定局域网特性的主要要素
- **网络拓扑**：星形、总线形、环形、树形
- **传输介质**：双绞线（主流）、同轴电缆、光纤、电磁波
- **介质访问控制方法**：CSMA/CD（总线/星形）、令牌总线、令牌环、CSMA/CA

### 📐 局域网的分类
- **以太网**：应用最为广泛，符合 **IEEE 802.3**，逻辑拓扑是总线形，物理拓扑是星形或拓展星形，使用 **CSMA/CD**
- **令牌环网**：IEEE 802.5，物理上星形，逻辑上环形，几乎不用了
- **FDDI 网**：光纤分布式数字接口，逻辑拓扑是环形，物理拓扑是双环
- **ATM 网**：较新型的单元交换技术，使用 53 字节固定长度的单元进行交换
- **无线局域网（WLAN）**：IEEE **802.11**

### 📐 IEEE 802 标准与 MAC、LLC 子层
IEEE 802 标准把数据链路层划分为两个子层：
- **逻辑链路控制（LLC）子层**：识别网络层协议，然后对它们进行封装。LLC 报头告诉数据链路层一旦帧被接收到时，应当对数据包做何处理。为网络层提供服务：无确认无连接、面向连接、带确认无连接、高速传送
- **介质访问控制（MAC）子层**：MAC 子层的主要功能包括**数据帧的封装/卸装、帧的寻址和识别、帧的接收与发送、链路的管理、帧的差错控制**等。MAC 子层的存在**屏蔽了不同物理链路种类的差异性**
- 📌 由于以太网在局域网中处于垄断地位，**LLC 子层已经基本不用了**，现在的网卡上一般只装有 MAC 协议

## 二、以太网（⭐⭐⭐）

### 📐 以太网概述
- 以太网（Ethernet）指的是由 Xerox 公司创建并由 Xerox、Intel 和 DEC 公司联合开发的**基带总线局域网规范**，是当今现有局域网采用的**最通用的通信协议标准**
- 以太网使用 **CSMA/CD** 技术
- 以太网提供**无连接、不可靠**的服务：
  - **无连接**：发送方和接收方之间无“握手过程”
  - **不可靠**：不对发送方的数据帧**编号**，接收方**不向发送方进行确认**，差错帧直接**丢弃**，差错纠正由**高层**负责
  - 以太网只实现**无差错接收**，不实现可靠传输

### 📐 以太网的传输介质与拓扑
- 以太网拓扑：**逻辑上总线型，物理上星型**（使用集线器/交换机）
- **10BASE-T 以太网**：“10”表示 10Mbps，“BASE”表示基带传输，“T”表示**双绞线**
  - 物理上采用**星型**拓扑，逻辑上总线型，每段双绞线最长为 **100m**
  - 采用**曼彻斯特编码**
  - 采用 **CSMA/CD** 介质访问控制

### 📐 MAC 地址（⭐⭐）
- 每块**网卡（适配器）**出厂时都有一个全球唯一的 **48 位二进制**地址（**6 字节**），称为**物理地址 / MAC 地址 / 硬件地址**
- 前 24 位代表**厂家**（由 IEEE 规定），后 24 位由**厂家自己**指定
- 常用 **6 个十六进制数**表示，如 `02-60-8c-e4-b1-21`
- **广播 MAC 地址：FF-FF-FF-FF-FF-FF**（全 1）

📐 **网卡（网络接口卡、适配器）**的功能：
- 实现**数据链路层和物理层**的功能
- 进行**串行/并行转换**；对数据进行**缓存**；在计算机的操作系统中安装设备驱动程序；实现以太网协议
- 网卡工作在**物理层和数据链路层**

### 📐 以太网 MAC 帧（Ethernet V2 标准）（⭐⭐⭐）
```
 字节:     6           6         2        46 ~ 1500        4
     ┌───────────┬──────────┬───────┬──────────────────┬──────┐
     │ 目的地址   │  源地址   │ 类型   │      数据         │ FCS  │
     └───────────┴──────────┴───────┴──────────────────┴──────┘
     |<────────────────── MAC 帧（64 ~ 1518 字节）──────────────>|
  物理层还会在帧前面加上：
     ┌──────────────────────┬─────────┐
     │ 前同步码（7 字节）      │帧开始定界符│   ← 8 字节，不属于 MAC 帧
     │ 1010...10             │10101011 │
     └──────────────────────┴─────────┘
```
| 字段 | 长度 | 作用 |
|---|---|---|
| **前导码** | 8B（7B 前同步码 + 1B 帧开始定界符） | 使接收端与发送端**时钟同步**；**物理层**添加，不算在帧长内 |
| **目的地址** | **6B** | 接收方 MAC 地址（**放在最前面**，便于尽早判断是否接收） |
| **源地址** | **6B** | 发送方 MAC 地址 |
| **类型** | **2B** | 指出数据域中携带的数据应交给**哪个协议实体**处理（如 0x0800 表示 IP，0x0806 表示 ARP） |
| **数据** | **46 ~ 1500B** | 包含高层的协议消息（IP 数据报）。**最小 46B**（因为 CSMA/CD 算法要求最短帧长 64B：64 − 6 − 6 − 2 − 4 = 46）；**最大 1500B**（= **MTU**） |
| **FCS（校验码）** | **4B** | **CRC** 校验，校验范围为**目的地址到数据**（不含前导码） |

📐 关键数字：
- **MAC 帧长度 64 ~ 1518 字节**（首部 14B + 尾部 4B = 18B）
- 数据部分 **46 ~ 1500 字节**；不足 46 字节要**填充**
- **以太网的 MTU = 1500B**
- 以太网帧**没有“帧结束定界符”**：以太网使用曼彻斯特编码，帧结束后电压不再跳变，接收方由此知道帧结束

✏️ **例**：IP 数据报只有 20 字节（仅首部），封装成以太网帧后，数据字段要**填充 26 字节**达到 46 字节，帧长 = 14 + 46 + 4 = **64 字节**。接收方如何知道哪些是填充？——由上层的 **IP 首部中的总长度字段**判断。

### 📐 高速以太网
- **100BASE-T 以太网**：在双绞线上传送 100Mbps 基带信号的星型拓扑以太网，仍使用 IEEE 802.3 的 **CSMA/CD** 协议。支持**全双工和半双工**，可在全双工方式下工作而**无冲突**（此时不使用 CSMA/CD）
- **吉比特以太网（1Gbps）**：在光纤或双绞线上传送 1Gbps 信号，支持全双工和半双工，全双工时不需要 CSMA/CD
- **10 吉比特以太网（10Gbps）**：在光纤上传送 10Gbps 信号，**只支持全双工**，**无争用问题**（不使用 CSMA/CD）

📌 高速以太网争用期不变（仍保证 64B 最短帧），速率提高 → 争用期变短 → **最大电缆长度相应减小**（或者增加最短帧长）。

## 三、无线局域网 IEEE 802.11（⭐⭐）

### 📐 无线局域网的组成
- **有固定基础设施无线局域网**：802.11 规定无线局域网的最小构件是**基本服务集 BSS**。一个 BSS 包括一个**基站（接入点 AP）**和若干个移动站。BSS 中的站可以在本 BSS 内直接通信，与其他 BSS 通信要通过 AP
  - **服务集标识符 SSID**：AP 的名字（你在手机上看到的 Wi-Fi 名称）
  - **基本服务区 BSA**：一个 BSS 覆盖的地理范围
  - **扩展服务集 ESS**：一个 BSS 可以是孤立的，也可通过 AP 连接到一个**分配系统 DS**，然后再连接到另一个 BSS，就构成了一个 ESS；**门户（portal）**让 802.11 接入有线以太网
- **无固定基础设施无线局域网的自组织网络（Ad Hoc）**：没有 AP，由一些平等状态的移动站相互通信组成的临时网络，各结点地位平等，中间结点都为转发结点，因此**都具有路由器的功能**

### 📐 802.11 帧的地址字段（⭐⭐⭐）
802.11 帧首部有**四个地址字段**，其含义取决于帧控制字段中的 **“去往 AP（To DS）”**和 **“来自 AP（From DS）”**两个比特：

| To DS | From DS | 地址 1（**接收端**） | 地址 2（**发送端**） | 地址 3 | 地址 4 | 场景 |
|---|---|---|---|---|---|---|
| 0 | 0 | 目的地址 | 源地址 | BSSID | —— | 同一 BSS 内直接通信（Ad Hoc） |
| **0** | **1** | **目的地址** | **AP 地址（BSSID）** | **源地址** | —— | **AP 发给站点** |
| **1** | **0** | **AP 地址（BSSID）** | **源地址** | **目的地址** | —— | **站点发给 AP** |
| 1 | 1 | 接收 AP 地址 | 发送 AP 地址 | 目的地址 | 源地址 | AP 之间的无线分配系统 |

🧒 **记忆口诀**：**地址 1 永远是“这一跳”的接收者，地址 2 永远是“这一跳”的发送者，地址 3 是剩下那个“另一端”的地址**。

✏️ **例**：站点 A 通过 AP 给站点 B 发送帧（A、B 在同一个 BSS 中）：
- **A → AP**（To DS = 1，From DS = 0）：地址 1 = **AP**，地址 2 = **A**，地址 3 = **B**
- **AP → B**（To DS = 0，From DS = 1）：地址 1 = **B**，地址 2 = **AP**，地址 3 = **A**

📝 **真题（2022 年第 47 题第 4 问）**：H4（MAC 00-11-11-11-11-D1）和 H5（MAC 00-11-11-11-11-E1）通过 AP（MAC 00-11-11-11-11-C1）接入网络。若 H4 向 H5 发送一个 IP 分组 P，则 H5 收到的封装 P 的 802.11 帧的地址 1、地址 2 和地址 3 分别是什么？
- H5 收到的帧是 **AP 发给 H5** 的（From DS = 1）
- 地址 1 = 接收端 = **H5：00-11-11-11-11-E1**
- 地址 2 = 发送端 = **AP：00-11-11-11-11-C1**
- 地址 3 = 源站 = **H4：00-11-11-11-11-D1**

⚠️ 802.11 使用 **CSMA/CA**（上一课），并且需要 **ACK**。

## 四、VLAN 虚拟局域网（⭐⭐）

### 📐 为什么需要 VLAN
传统局域网的问题：一个以太网是一个**广播域**，当一个以太网包含的计算机太多时，往往会导致：
- 以太网中出现**大量的广播帧**，特别是经常使用的 ARP 和 DHCP 协议
- 一个单位的不同部门共享一个局域网，**对信息保密和网络安全不利**

### 📐 VLAN 的概念
**虚拟局域网（VLAN）**：是一种将局域网内的设备**划分成与物理位置无关的逻辑组**的技术，这些逻辑组有某些共同的需求。每个 VLAN 是一个单独的**广播域**/不同的子网。
- 🧒 一个大办公室里坐着财务部和技术部的人，虽然物理上混坐，但通过 VLAN，财务部的广播只有财务部的人听得到
- VLAN 的划分方式：**基于接口**（交换机端口）、**基于 MAC 地址**、基于 IP 地址（跨越路由器的多个局域网）

### 📐 802.1Q 帧
- 在标准以太网帧的**源地址后面**插入一个 **4 字节的 VLAN 标签**（其中 **12 位 VID** 标识 VLAN 号，最多 4096 个 VLAN）
- 插入标签后，以太网帧的**最大长度变为 1522 字节**
- 交换机之间的**干线（Trunk）链路**上传输的是带标签的 802.1Q 帧；交换机与主机之间的**接入链路（Access）**上传输的是普通以太网帧（主机看不到标签）
- ⚠️ **不同 VLAN 之间的通信需要经过路由器**（或三层交换机）

## 五、广域网与 PPP 协议（⭐）

### 📐 广域网
**广域网（WAN）**通常是指覆盖范围很广（远超一个城市的范围）的长距离网络。广域网是**因特网的核心部分**，其任务是长距离运送主机所发送的数据。连接广域网各结点交换机的链路都是**高速链路**，距离可达几千千米。
- 广域网**使用点对点链路**，不使用局域网的广播技术
- 广域网的**网络层**决定了它是否是广域网（覆盖物理层、数据链路层、网络层）；局域网只涉及物理层和数据链路层

### 📐 PPP 协议（点对点协议）
**PPP 协议**是目前使用**最广泛的数据链路层协议**，用户使用拨号电话接入因特网时一般都使用 PPP 协议。**只支持全双工链路**。
- PPP 协议应满足的要求：**简单**（对于链路层的帧，无需纠错，**无需序号，无需流量控制**）、**封装成帧**（帧定界符）、**透明传输**（与帧定界符一样比特组合的数据应该如何处理：异步线路用**字节填充**，同步线路用**比特填充**）、多种网络层协议（封装的 IP 数据报可以采用多种协议）、多种类型链路（串行/并行，同步/异步，电/光……）、**差错检测**（错就丢弃）、检测连接状态（链路是否正常工作）、最大传送单元（数据部分最大长度 MRU）、网络层地址协商（知道通信双方的网络层地址）、数据压缩协商
- PPP 协议**无需满足**的要求：**纠错、流量控制、序号、不支持多点线路**
- PPP 协议的三个组成部分：
  1. 一个将 IP 数据报**封装**到串行链路（同步串行/异步串行）的方法
  2. **链路控制协议 LCP**：建立并维护数据链路连接（身份验证）
  3. **网络控制协议 NCP**：PPP 可支持多种网络层协议，每个不同的网络层协议都要一个相应的 NCP 来配置，为网络层协议建立和配置逻辑连接
- PPP 帧格式：标志字段 **7E**（首尾各 1 字节）、地址字段 FF、控制字段 03、协议字段 2B、信息部分（≤ 1500B）、FCS 2B

## 六、数据链路层设备（⭐⭐⭐）

### 📐 网桥
**网桥**根据 MAC 帧的**目的地址**对帧进行**转发和过滤**。当网桥收到一个帧时，并不向所有接口转发此帧，而是先检查此帧的目的 MAC 地址，然后再确定将该帧转发到哪一个接口，或者是把它丢弃（即过滤）。
- **网段**：一般指一个计算机网络中使用同一物理层设备（传输介质，中继器，集线器等）能够直接通讯的那一部分
- 网桥的优点：
  1. **过滤通信量，增大吞吐量**
  2. 扩大了物理范围
  3. 提高了可靠性
  4. 可互连不同物理层、不同 MAC 子层和不同速率的以太网
- 网桥**分隔了冲突域**：网桥的每个接口是一个独立的冲突域

### 📐 以太网交换机（⭐⭐⭐）
**以太网交换机**实质上就是一个**多接口的网桥**，可以使每个接口都直接与某台单主机或另一个集线器相连，**工作在全双工方式**。
- 交换机能**同时连通许多对**的接口，使每一对相互通信的主机都能像独占通信介质那样，**无碰撞**地传输数据
- **独占带宽**：每个端口的带宽都是独享的。对于普通 10Mbps 的共享式以太网，若共有 N 个用户，则每个用户占有的平均带宽只有总带宽的 N 分之一；而用交换机，每个用户都独占 10Mbps，**总容量 = N × 10Mbps**
- 交换机的**每个端口是一个冲突域**；所有端口仍然在**同一个广播域**中（交换机**不隔离广播域**）

#### 交换机的两种交换方式
| 方式 | 做法 | 特点 |
|---|---|---|
| **直通式交换** | 检查**目的地址（6B）**后就立即转发 | **延迟小**；可靠性低，**无法检测差错帧**，无法支持不同速率端口的交换 |
| **存储转发式交换** | 将帧放入**高速缓存**，并**检查是否正确**，正确则转发，错误则丢弃 | 延迟大；可靠性高，可以支持不同速率端口的交换 |

✏️ 直通式交换的转发时延 = 6B × 8 / 数据率；如 100Mbps：48 / 10⁸ = **0.48μs**

#### 交换机的自学习功能（⭐⭐⭐）
交换机内部有一个**交换表**（MAC 地址表），记录 **< MAC 地址, 端口 >**，初始为空。
1. **学习**：交换机收到一帧后，**先查交换表中有没有该帧的源 MAC 地址**，若没有，就把 **< 源 MAC 地址, 进入端口 >** 写入交换表（交换表项还有有效时间，过期删除）
2. **转发**：再查交换表中有没有该帧的**目的 MAC 地址**：
   - **有**：从对应端口转发（若对应端口就是进入端口，则**丢弃**——不需要转发）
   - **没有**：向**除进入端口以外的所有端口**转发（**泛洪/广播**）
   - 目的地址是**广播地址**（FF-FF-FF-FF-FF-FF）：向所有其他端口**广播**

✏️ **例**：交换机端口 1 连 A，端口 2 连 B，端口 3 连 C，交换表初始为空。
| 事件 | 学习（写入交换表） | 转发 |
|---|---|---|
| A 发给 B | < A, 1 > | 表中无 B → **泛洪**到 2、3 |
| B 发给 A | < B, 2 > | 表中有 A → 只从端口 **1** 转发 |
| C 发给 A | < C, 3 > | 表中有 A → 只从端口 **1** 转发 |
| A 发给 C | （A 已存在） | 表中有 C → 只从端口 **3** 转发 |

📝 **真题（2021 年第 47 题第 2、3 问）**：网络拓扑中，以太网交换机 S 的端口 1 连本地域名服务器（192.168.1.126/25，MAC 00-11-22-33-44-bb），端口 2 连路由器 R（192.168.1.1/25，MAC 00-11-22-33-44-aa），端口 3 连 H2（192.168.1.3/25，MAC 00-11-22-33-44-dd），端口 4 连 H1（192.168.1.2/25，MAC 00-11-22-33-44-cc）。在 t₀ 时刻 H1 的 ARP 表和 S 的交换表均为空，H1 在此刻利用浏览器通过域名 www.abc.com 请求访问 Web 服务器，在 t₁ 时刻（t₁ > t₀）S 第一次收到了封装 HTTP 请求报文的以太网帧，假设从 t₀ 到 t₁ 期间网络未发生任何与此次 Web 访问无关的网络通信。
> (2) 若 S 的交换表结构为 < MAC 地址, 端口 >，则 t₁ 时刻 S 交换表的内容是什么？
> (3) 从 t₀ 到 t₁ 期间，H2 至少会接收到几个与此次 Web 访问相关的帧？接收到的是什么帧？帧的目的 MAC 地址是什么？

**分析过程**（从 t₀ 到 t₁ 发生了什么）：
1. H1 要先进行 **DNS 查询**。本地域名服务器 192.168.1.126 与 H1 在同一子网（/25：192.168.1.0~127），H1 需要知道它的 MAC 地址 → 发送 **ARP 请求（广播）**
   - S 学习 < cc, 4 >，广播到端口 1、2、3（**H2 收到第 1 个帧**）
2. 域名服务器回复 **ARP 响应**（单播给 H1）→ S 学习 < bb, 1 >，从端口 4 转发
3. H1 发送 DNS 查询 → 域名服务器解析（可能要向外查询，经过 R……）→ 返回 DNS 响应
4. Web 服务器在外网，H1 要把 HTTP 请求发给**默认网关 R**，需要 R 的 MAC 地址 → 发送 **ARP 请求（广播）**（**H2 收到第 2 个帧**）
5. R 回复 ARP 响应 → S 学习 < aa, 2 >
6. H1 与 Web 服务器建立 TCP 连接（三次握手，经过 R）……然后发送 HTTP 请求 → t₁ 时刻 S 收到

**(2)** t₁ 时刻 S 的交换表：
| MAC 地址 | 端口 |
|---|---|
| 00-11-22-33-44-cc | 4 |
| 00-11-22-33-44-bb | 1 |
| 00-11-22-33-44-aa | 2 |

**(3)** H2 至少收到 **2 个**帧，都是 **ARP 请求帧**（H1 查询本地域名服务器的 MAC 地址、查询默认网关 R 的 MAC 地址），目的 MAC 地址都是**广播地址 FF-FF-FF-FF-FF-FF**。（其他帧都是单播，交换机已学到目的端口，不会发给 H2。）

### 📐 冲突域与广播域（⭐⭐⭐）
- **冲突域**：在同一个冲突域中的每一个结点都能收到所有被发送的帧。简单地说就是**同一时间内只能有一台设备发送信息的范围**
- **广播域**：网络中能接收任一设备发出的**广播帧**的所有设备的集合。简单地说如果站点发出一个广播信号，所有能接收收到这个信号的设备范围称为一个广播域

| 设备 | 工作层 | 能否隔离冲突域 | 能否隔离广播域 |
|---|---|---|---|
| **中继器、集线器** | 物理层 | ❌ | ❌ |
| **网桥、交换机** | 数据链路层 | ✅（每个端口一个冲突域） | ❌ |
| **路由器** | 网络层 | ✅ | ✅（每个端口一个广播域） |

📐 **计算方法**：
- **广播域个数** = 被**路由器**分隔出来的区域数（路由器每个接口连的网络是一个广播域）
- **冲突域个数** = 被**交换机/网桥/路由器**的端口分隔出来的区域数；**集线器及其连接的所有主机是同一个冲突域**

📝 **真题（2020 年第 35 题）**：在下图所示的网络中，冲突域和广播域的个数分别是：
```
            交换机1 ────── 路由器 ────── 交换机2
           /       \                   /       \
       集线器1    集线器2           集线器3    集线器4
       /    \     /    \           /    \     /    \
     主机  主机  主机  主机        主机  主机  主机  主机
```
A. 2, 2　B. 2, 4　C. 4, 2　D. 4, 4
- **广播域**：路由器把网络分成左右两部分 → **2 个**
- **冲突域**：每个集线器连同它下面的主机是一个冲突域 → **4 个**（交换机与路由器之间、交换机与集线器之间的链路是交换机端口的一部分，本题按每个集线器所在的网段计数）
- → 选 **C**

📝 **真题（2022 年第 47 题第 1 问）**：某网络中 H1 与 H2 属于同一个广播域，但不属于同一个冲突域；H2 和 H3 属于同一个冲突域。现有路由器、100BaseT 以太网交换机和 100BaseT 集线器（Hub）三类设备各若干台。R 连接设备 1，设备 1 连接 H1 和设备 2，设备 2 连接 H2 和 H3。设备 1 和设备 2 应该分别选择哪类设备？
- H1 与 H2：同一广播域但不同冲突域 → 设备 1 能隔离冲突域但不能隔离广播域 → **以太网交换机**
- H2 与 H3：同一冲突域 → 设备 2 不能隔离冲突域 → **集线器**

## ⚠️ 易错点

1. MAC 地址 **48 位（6B）**；广播地址 **FF-FF-FF-FF-FF-FF**
2. 以太网帧：**目的 6 + 源 6 + 类型 2 + 数据 46~1500 + FCS 4 = 64~1518B**；前导码 8B 不算
3. 以太网 **MTU = 1500B**；数据不足 46B 要填充
4. 以太网提供**无连接、不可靠**服务；只保证无差错接收
5. 802.11：**地址 1 = 这一跳的接收者，地址 2 = 这一跳的发送者**；AP → 站点时地址 3 是**源地址**，站点 → AP 时地址 3 是**目的地址**
6. VLAN 标签 **4B**，插在**源地址之后**，VID **12 位**；VLAN 帧最大 1522B；不同 VLAN 通信要经过**路由器**
7. PPP：**全双工**、不需要纠错、流量控制、序号
8. 交换机**先学习源地址，再按目的地址转发**；找不到目的地址就**泛洪**
9. **集线器不隔离冲突域；交换机隔离冲突域但不隔离广播域；路由器都隔离**
10. 直通式交换**只看目的地址**，不检错；存储转发**检错**

## 📋 本课小结

| 知识点 | 要点 |
|---|---|
| 以太网 | 无连接不可靠；CSMA/CD；10BASE-T 星形；MAC 48 位 |
| 以太网帧 | 6+6+2+(46~1500)+4 = 64~1518B |
| 802.11 | 4 个地址；To DS/From DS；CSMA/CA + ACK |
| VLAN | 逻辑划分广播域；802.1Q 4B 标签 |
| PPP | 点对点、全双工；LCP、NCP |
| 交换机 | 多端口网桥；自学习；直通/存储转发 |
| 冲突域/广播域 | 集线器都不隔离；交换机隔离冲突域；路由器都隔离 |

## 🏋️ 课后练习

1. 一个 IP 数据报长 1480B，封装成以太网帧后帧长为多少？若 IP 数据报长 30B 呢？
2. 站点 A 通过 AP 向有线网络中的服务器 S 发送一个帧，A 发出的 802.11 帧中地址 1、2、3 分别是什么？
3. 一个 24 端口的交换机，每个端口连接一台主机，有几个冲突域和几个广播域？若 24 个端口各连接一个集线器，每个集线器连 5 台主机呢？
4. 交换机的交换表初始为空，A（端口 1）先后发帧给 B（端口 2）和 C（端口 3），然后 C 发帧给 A，B 发帧给 C。写出每次的转发情况。
5. 判断：(a) 交换机可以隔离广播域；(b) 以太网帧中有帧结束定界符；(c) 直通式交换可以检测差错帧。

<details>
<summary>📖 答案</summary>

1. 1480 + 18 = **1498B**；30B 小于 46B，要填充到 46B，帧长 = 46 + 18 = **64B**
2. A → AP（To DS = 1）：地址 1 = **AP**，地址 2 = **A**，地址 3 = **S**
3. 每端口连主机：**24 个冲突域，1 个广播域**；每端口连集线器：仍是 **24 个冲突域**（每个集线器及其 5 台主机是一个冲突域），**1 个广播域**
4. A→B：学习 < A,1 >，表中无 B → 泛洪到 2、3；A→C：表中无 C → 泛洪到 2、3；C→A：学习 < C,3 >，表中有 A → 只发端口 1；B→C：学习 < B,2 >，表中有 C → 只发端口 3
5. (a) **错**；(b) **错**，由于曼彻斯特编码，帧结束后电压不再跳变；(c) **错**
