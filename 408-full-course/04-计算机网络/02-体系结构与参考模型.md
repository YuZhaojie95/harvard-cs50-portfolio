你要给远方的朋友寄一封信：

2. 装进**信封**，写上地址（封装）
3. 投进**邮筒**，邮局按地址**分拣**、**运输**

计算机网络也是这样**分层**设计的，这就是**网络体系结构**。

## 一、分层结构与基本概念（⭐⭐）

### 📐 为什么要分层
计算机网络非常复杂（要考虑编码、差错、寻址、路由、可靠性、应用……），**分层**可以把复杂问题分解为若干个较小的、易于处理的局部问题。
- 各层之间是**独立**的：每层只实现一种相对独立的功能
- **灵活性好**：某层的实现方式改变，只要接口不变，就不影响其他层
- **易于实现和维护**
- 能**促进标准化**工作

### 📐 分层的基本原则
1. 每层都实现一种**相对独立的功能**，降低大系统的复杂度
2. 各层之间界面自然清晰，易于理解，**相互交流尽可能少**
3. 各层功能的精确定义**独立于具体的实现方法**，可以采用最合适的技术来实现
4. **保持下层对上层的独立性**，上层单向使用下层提供的服务
5. 整个分层结构应能促进标准化工作

### 📐 基本概念（⭐⭐⭐）
- **实体**：第 n 层中的**活动元素**（任何可以发送或接收信息的硬件或软件进程）称为 n 层实体。**不同机器上的同一层**称为**对等层**，同一层的实体称为**对等实体**
- **协议**：为进行网络中的数据交换而建立的**规则、标准或约定**。协议是控制**两个（或多个）对等实体**进行通信的规则的集合，是**水平**的
- **服务**：**下层为紧邻的上层**提供的功能调用，是**垂直**的
- **接口（服务访问点 SAP）**：同一结点内**相邻两层**间交换信息的连接点，是一个系统内部的规定。每层只能为紧邻的层次之间定义接口，不能跨层定义接口

⚠️ **协议与服务的区别**（⭐⭐）：
- **协议是水平的**（对等实体之间），**服务是垂直的**（下层对上层）
- 在协议的控制下，两个对等实体间的通信使得本层能够向上一层提供服务。要实现本层协议，还需要使用下面一层所提供的服务
- **协议是“透明”的**：上层看不见下层的协议，只能看见下层提供的服务
- 并非在一个层内完成的全部功能都称为服务，只有那些能够被**高一层实体“看得见”**的功能才称为服务

### 📐 协议的三要素（⭐⭐⭐）
1. **语法**：规定传输数据的**格式**（数据与控制信息的结构或格式），如“首部 20 字节，前 4 位是版本号……”
2. **语义**：规定所要完成的**功能**，即需要发出何种控制信息、完成何种动作及做出何种应答，如“收到 SYN 就要回 SYN+ACK”
3. **同步（时序）**：规定执行各种操作的**条件、时序关系**等，即事件实现顺序的详细说明，如“先发请求，等收到确认后再发数据”

🧒 **比喻：两个人打电话**
- 语法：说**什么语言**、话怎么组织（“喂，你好，我是……”）
- 语义：每句话**是什么意思**、该怎么回应（听到“喂”要回答“你好”）
- 同步：**什么时候说**（一方说完另一方再说；先拨号，接通后再说话）

📝 **真题（2020 年第 33 题）**：下图描述的协议要素是（发送方与接收方之间一来一回的时间顺序图）：I. 语法　II. 语义　III. 时序
A. 仅 I　B. 仅 II　C. 仅 III　D. I、II 和 III
→ **C**（图中描述的是**时间先后顺序**，即时序/同步）

### 📐 数据单元
- **服务数据单元（SDU）**：为完成用户所要求的功能而应传送的数据，第 n 层的 SDU 记为 n-SDU（即上一层交下来的数据）
- **协议控制信息（PCI）**：控制协议操作的信息（首部、尾部），n-PCI
- **协议数据单元（PDU）**：对等层次之间传送的数据单位，第 n 层的 PDU 记为 n-PDU
- 📐 **n-PDU = n-SDU + n-PCI**；**n-SDU = (n+1)-PDU**

### 📐 服务的分类
- **面向连接服务**：通信前双方必须先**建立连接**，分配相应的资源（如缓冲区），以保证通信能正常进行，传输结束后释放连接和所占用的资源（**建立连接、数据传输、连接释放**三个阶段）。如 **TCP**
- **无连接服务**：通信前双方**不需要**先建立连接，需要发送数据时可直接发送，把每个带有目的地址的包（报文分组）传送到线路上，由系统选定路线进行传输。这是一种不可靠的服务，常被描述为“**尽最大努力交付**”，它并不保证通信的可靠性。如 **IP、UDP**
- **可靠服务**：网络具有纠错、检错、应答机制，能保证数据正确、可靠地传送到目的地
- **不可靠服务**：网络只是尽量正确、可靠地传送，而不能保证数据正确、可靠地传送到目的地，是一种尽力而为的服务

## 二、OSI 参考模型（⭐⭐⭐）

国际标准化组织（ISO）提出的**开放系统互连参考模型（OSI/RM）**，共 **7 层**：
```
       主机 A                                    主机 B
 7  应用层     ◄─────── 应用层协议 ───────►     应用层
 6  表示层     ◄───────────────────────►       表示层
 5  会话层     ◄───────────────────────►       会话层
 4  传输层     ◄─────── 端到端 ─────────►       传输层
 3  网络层  ◄──► 网络层 ◄──► 网络层  ◄──►       网络层
 2  数据链路层◄► 链路层 ◄──► 链路层  ◄──►       数据链路层
 1  物理层  ◄──► 物理层 ◄──► 物理层  ◄──►       物理层
                  路由器        路由器
```
- **下三层**（物理层、数据链路层、网络层）：**通信子网**，**点到点**（相邻结点之间）
- **传输层**：承上启下，**端到端**（源主机进程到目的主机进程）
- **上三层**（会话层、表示层、应用层）：**资源子网**
- 中间结点（路由器）只需要实现**下三层**

### 📐 各层功能（⭐⭐⭐）
| 层 | 传输单位 | 主要功能 | 典型协议/设备 |
|---|---|---|---|
| **7 应用层** | 报文 | 为**特定应用程序**提供服务（用户与网络的界面） | HTTP、FTP、SMTP、DNS |
| **6 表示层** | —— | 处理两个通信系统中交换信息的**表示方式**：**数据格式转换**、**数据加密解密**、**数据压缩恢复** | JPEG、ASCII |
| **5 会话层** | —— | 允许不同主机上的各个进程之间进行会话：**建立、管理、终止会话**；**同步**（在数据中插入校验点/同步点，出现故障时可以从校验点恢复，不必从头传） | RPC |
| **4 传输层** | 报文段（TCP）/ 用户数据报（UDP） | 负责主机中两个**进程**之间的通信（**端到端**）：**可靠传输**、**流量控制**、**差错控制**、**拥塞控制**、复用分用、服务质量 | TCP、UDP |
| **3 网络层** | **分组（数据报）** | 把分组从源主机**选择合适的路由**传送到目的主机：**路由选择**、**分组转发**、**拥塞控制**、网际互连、流量控制、差错控制 | IP、ICMP、ARP；**路由器** |
| **2 数据链路层** | **帧** | 把网络层交下来的 IP 数据报**组装成帧**，在两个**相邻结点**之间的链路上传送：**成帧**、**差错控制**、**流量控制**、**介质访问控制**（广播信道） | PPP、以太网；**交换机、网桥** |
| **1 物理层** | **比特** | 在物理媒体上**透明地传输比特流**：定义接口特性（机械、电气、功能、过程特性）、传输模式（单工、半双工、双工）、传输速率、比特同步、比特编码 | **集线器、中继器** |

⚠️ 注意：
- **流量控制**：数据链路层（相邻结点之间）、传输层（端到端）都有
- **差错控制**：数据链路层、网络层、传输层都可以有
- **拥塞控制**：网络层、传输层
- **路由选择只在网络层**
- **数据格式转换、加密解密在表示层**；**会话同步（校验点）在会话层**

📝 **真题（2022 年第 33 题）**：在 ISO/OSI 参考模型中，实现两个相邻结点间流量控制功能的是：A. 物理层　B. 数据链路层　C. 网络层　D. 传输层
→ **B**（**相邻结点**之间 → 数据链路层；**端到端**的流量控制 → 传输层）

## 三、TCP/IP 模型（⭐⭐⭐）

实际使用的互联网体系结构，共 **4 层**：
| TCP/IP 层 | 对应 OSI 层 | 功能 | 协议 |
|---|---|---|---|
| **应用层** | 应用层 + 表示层 + 会话层 | 提供各种应用服务 | HTTP、FTP、SMTP、DNS、DHCP |
| **传输层** | 传输层 | 进程间端到端通信 | **TCP、UDP** |
| **网际层（网络层）** | 网络层 | 分组的路由选择与转发（**无连接、不可靠**） | **IP**、ICMP、IGMP、ARP |
| **网络接口层** | 数据链路层 + 物理层 | 从主机或结点接收 IP 分组，并把它们发送到指定的物理网络上（没有具体定义） | 以太网、PPP 等 |

📌 TCP/IP 的特点：
- **IP 可以应用到各式各样的网络上**（Everything over IP），又能为各式各样的应用提供服务（IP over Everything）——“**沙漏形**”结构，IP 是“细腰”
- 网络层只提供**无连接**的服务，可靠性由传输层的 TCP 保证

📝 **真题（2021 年第 33 题）**：在 TCP/IP 参考模型中，由传输层相邻的下一层实现的主要功能是：A. 对话管理　B. 路由选择　C. 端到端报文段传输　D. 结点到结点流量控制
→ **B**（传输层的下一层是**网际层（网络层）**，主要功能是**路由选择**和分组转发。A 是会话层；C 是传输层；D 是数据链路层）

### 📐 OSI 与 TCP/IP 的比较（⭐⭐）
**相同点**：
1. 都采取**分层**的体系结构，而且分层的功能也大体相似
2. 都是基于**独立的协议栈**的概念
3. 都可以解决**异构网络的互连**，实现不同厂家生产的计算机之间的通信

**不同点**：
| | OSI | TCP/IP |
|---|---|---|
| 层数 | 7 层 | 4 层 |
| 概念 | 精确定义了**服务、协议、接口**三个概念，理论完整 | 没有明确区分三者 |
| 设计顺序 | 先有模型，后有协议（**通用**，但协议实现复杂） | **先有协议，后有模型**（模型是对已有协议的描述） |
| 网络层 | 支持**无连接和面向连接** | **只有无连接** |
| 传输层 | **只有面向连接** | **无连接（UDP）和面向连接（TCP）都支持** |
| 地位 | 法律上的国际标准 | **事实上的国际标准** |

⚠️ 记忆：**OSI 网络层两种都有、传输层只面向连接；TCP/IP 正好反过来：网络层只无连接、传输层两种都有**。

### 📐 五层教学模型（⭐⭐）
综合 OSI 和 TCP/IP 的优点，教学中常用的 5 层模型：
```
5  应用层        报文        ← 支持各种网络应用：HTTP、SMTP、FTP
4  传输层        报文段      ← 进程-进程的数据传输：TCP、UDP
3  网络层        数据报      ← 源主机到目的主机的数据分组路由与转发：IP、ICMP、OSPF
2  数据链路层    帧          ← 把网络层传下来的数据报组装成帧：以太网、PPP
1  物理层        比特        ← 比特传输
```
**本课程之后的第 3~17 课就按这 5 层自下而上展开。**

## 四、数据的封装与解封装（⭐⭐）

### 📐 封装过程
发送方从上到下，每一层都给上层交下来的数据**加上本层的首部**（数据链路层还加尾部），这叫**封装**：
```
应用层：                           [ 数据 ]                       报文
传输层：                   [TCP首部][ 数据 ]                       报文段
网络层：             [IP首部][TCP首部][ 数据 ]                     IP 数据报（分组）
数据链路层：[帧首部][IP首部][TCP首部][ 数据 ][帧尾部]               帧
物理层：    0101110101001......                                    比特流
```
接收方从下到上，每一层**去掉本层的首部**，把数据交给上一层，这叫**解封装**。

### 📐 各层 PDU 名称与设备（⭐⭐⭐ 背下来）
| 层 | PDU 名称 | 互连设备 | 设备作用 |
|---|---|---|---|
| 应用层 | 报文（message） | 网关 | 协议转换 |
| 传输层 | **报文段**（segment，TCP）/ **用户数据报**（UDP） | 网关 | |
| 网络层 | **IP 数据报 / 分组**（packet） | **路由器** | 根据 IP 地址转发，**隔离广播域** |
| 数据链路层 | **帧**（frame） | **交换机、网桥** | 根据 MAC 地址转发，**隔离冲突域** |
| 物理层 | **比特**（bit） | **集线器、中继器** | 放大/再生信号，**不能隔离冲突域** |

🧒 **记忆口诀**：“**物比、链帧、网包、传段、应报**”（物理层比特，链路层帧，网络层分组/包，传输层报文段，应用层报文）。

⚠️ 一个**路由器**需要实现**物理层、数据链路层、网络层**三层；一个**交换机**需要实现物理层和数据链路层两层；**集线器**只实现物理层。**主机**实现全部 5 层。

## ⚠️ 易错点

1. **协议是水平的**（对等实体之间），**服务是垂直的**（下层为上层）
2. 协议三要素：**语法（格式）、语义（含义/动作）、同步（时序）**
3. **n-PDU = n-SDU + n-PCI**
4. **相邻结点**之间：数据链路层；**端到端**：传输层
5. **路由选择只在网络层**
6. 表示层：**格式转换、加密、压缩**；会话层：**建立会话、同步（校验点）**
7. OSI：网络层有连接/无连接，传输层只面向连接；**TCP/IP：网络层只无连接，传输层两种都有**
8. TCP/IP 的网络接口层对应 OSI 的**物理层 + 数据链路层**；应用层对应 OSI 的**上三层**
9. 路由器**隔离广播域**；交换机**隔离冲突域**；集线器**都不隔离**

## 🏋️ 课后练习

1. 下列功能分别属于 OSI 的哪一层：(a) 数据加密；(b) 路由选择；(c) 比特同步；(d) 端到端流量控制；(e) 成帧；(f) 在数据流中插入同步点。
2. 判断：(a) 服务是下层向上层提供的；(b) 上层可以看到下层的协议；(c) TCP/IP 的网络层提供面向连接的服务；(d) 路由器需要实现传输层。
3. 若应用层产生 1000B 数据，传输层加 20B 首部，网络层加 20B 首部，数据链路层加 18B 首尾。求最终在物理层传输的数据中，应用层数据所占的比例。
4. 在 OSI 模型中，第 n 层的 SDU 与第 n + 1 层的 PDU 有什么关系？

<details>
<summary>📖 答案</summary>

1. (a) **表示层**；(b) **网络层**；(c) **物理层**；(d) **传输层**；(e) **数据链路层**；(f) **会话层**
2. (a) **对**；(b) **错**，协议对上层透明；(c) **错**，只提供无连接服务；(d) **错**，路由器只需实现下三层
3. 1000 / (1000 + 20 + 20 + 18) = 1000 / 1058 ≈ **94.5%**
4. **n-SDU = (n+1)-PDU**：上一层的协议数据单元交给下一层后，就成为下一层的服务数据单元
</details>
