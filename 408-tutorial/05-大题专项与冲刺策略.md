## 14.2 第 41 题：算法设计题（13~15 分）

### 📖 评分标准（按惯例）
1. **基本设计思想**（约 4 分）：用文字说清楚思路
2. **算法实现**（约 7 分）：C/C++ 代码 + 关键注释
3. **时间和空间复杂度**（约 2 分）

⭐ **最重要的策略**：
- **想不出最优解，就写暴力解！** 暴力解思路正确、代码正确，一般能拿到 **9~11 分**（13 分制）。空着是 0 分。
- 代码**不用追求能编译通过**，但逻辑要对，变量要有含义，要写注释。
- 可以用 C++ 的 `bool`、`swap`、`new`、`vector`、`sort` 等（用 `sort` 要写清楚复杂度 O(n log n)）。
- **先写思想，再写代码**，思想里要点明用了什么方法（“双指针”“后缀最大值”“中序遍历判断递增”）。

### ✏️ 真题 1：2025 年第 41 题（数组，13 分）
> 两个长度为 n 的数组 A 和 res，对每个 A[i]，求 A[i] 与 A[j]（i ≤ j ≤ n−1）乘积的最大值存入 res[i]。例如 A = {1, 4, −9, 6}，res = {6, 24, 81, 36}。

**(1) 设计思想**：
- 暴力法：对每个 i，枚举 j = i ~ n−1，求最大乘积，O(n²)。
- 优化：**A[i] ≥ 0 时，乘积最大的是 A[i] × (A[i..n−1] 中的最大值)；A[i] < 0 时，是 A[i] × (A[i..n−1] 中的最小值)**。
- 所以**从右往左**扫描一遍，边扫边维护“当前后缀的最大值 mx 和最小值 mn”，即可求出每个 res[i]。

**(2) 代码**：
```c
void calMulMax(int A[], int res[], int n) {
    int mx = A[n - 1], mn = A[n - 1];   // A[i..n-1] 的最大值和最小值
    for (int i = n - 1; i >= 0; i--) {
        if (A[i] > mx) mx = A[i];       // 更新后缀最大值
        if (A[i] < mn) mn = A[i];       // 更新后缀最小值
        if (A[i] >= 0)
            res[i] = A[i] * mx;         // 非负数乘最大值
        else
            res[i] = A[i] * mn;         // 负数乘最小值（负负得正最大）
    }
}
```
**(3)** 时间 O(n)，空间 O(1)。

验证：i=3：mx=mn=6，res=36；i=2：A=−9，mn=−9，res=81；i=1：A=4，mx=6，res=24；i=0：A=1，mx=6，res=6 ✓

### ✏️ 真题 2：2020 年第 41 题（三个有序数组，13 分）
> 三元组 (a, b, c) 的距离 D = |a−b| + |b−c| + |c−a|。给定 3 个升序数组 S1、S2、S3，求所有三元组中的最小距离。

**(1) 设计思想**：
- 关键观察：设 a ≤ b ≤ c，则 D = 2(c − a)，**只由最大值和最小值决定**。
- 用三个下标 i、j、k 分别指向三个数组开头。每次计算当前三元组的 D，更新最小值；然后**让三者中最小的那个下标后移**（只有增大最小值才可能让 D 变小）。
- 任一数组扫完就结束。

**(2) 代码**：
```c
#define INF 0x7fffffff
int abs_(int x) { return x < 0 ? -x : x; }

int findMinTrip(int A[], int n, int B[], int m, int C[], int p) {
    int i = 0, j = 0, k = 0, Dmin = INF, D;
    while (i < n && j < m && k < p && Dmin > 0) {
        D = abs_(A[i] - B[j]) + abs_(B[j] - C[k]) + abs_(C[k] - A[i]);
        if (D < Dmin) Dmin = D;                          // 更新最小距离
        if (A[i] <= B[j] && A[i] <= C[k]) i++;           // A[i] 最小，后移 i
        else if (B[j] <= A[i] && B[j] <= C[k]) j++;      // B[j] 最小，后移 j
        else k++;                                         // C[k] 最小，后移 k
    }
    return Dmin;
}
```
**(3)** 时间 O(n + m + p)，空间 O(1)。

### ✏️ 真题 3：2021 年第 41 题（图的邻接矩阵，15 分）
> 无向连通图 G 用邻接矩阵存储。当度为奇数的顶点个数为 0 或 2 时存在 EL 路径（一笔画）。判断是否存在。

**(1) 设计思想**：邻接矩阵第 i 行的元素之和就是顶点 i 的度。逐行求和，统计度为奇数的顶点个数；若为 0 或 2 返回 1，否则返回 0。

**(2) 代码**：
```c
int IsExistEL(MGraph G) {
    int oddCount = 0;                             // 度为奇数的顶点个数
    for (int i = 0; i < G.numVertices; i++) {
        int degree = 0;
        for (int j = 0; j < G.numVertices; j++)
            degree += G.Edge[i][j];               // 第 i 行之和 = 顶点 i 的度
        if (degree % 2 == 1) oddCount++;
    }
    return (oddCount == 0 || oddCount == 2) ? 1 : 0;
}
```
**(3)** 时间 O(n²)，空间 O(1)。

### ✏️ 真题 4：2023 年第 41 题（有向图，13 分）
> 出度大于入度的顶点称为 K 顶点。输出有向图 G（邻接矩阵）中所有 K 顶点，并返回个数。

**(1) 设计思想**：邻接矩阵中**第 i 行之和是出度，第 i 列之和是入度**。对每个顶点分别求出度和入度并比较。

**(2) 代码**：
```c
int printVertices(MGraph G) {
    int count = 0;
    for (int i = 0; i < G.numVertices; i++) {
        int indeg = 0, outdeg = 0;
        for (int j = 0; j < G.numVertices; j++) {
            outdeg += G.Edge[i][j];               // 第 i 行：出度
            indeg  += G.Edge[j][i];               // 第 i 列：入度
        }
        if (outdeg > indeg) {                     // 是 K 顶点
            printf("%c ", G.VerticesList[i]);
            count++;
        }
    }
    return count;
}
```
**(3)** 时间 O(n²)，空间 O(1)。

### ✏️ 真题 5：2022 年第 41 题（二叉树，13 分）
> 二叉树按顺序存储在数组 SqBiTNode 中（根在下标 0，结点 i 的左右孩子是 2i+1 和 2i+2），−1 表示空结点。判断它是否为二叉排序树。

**(1) 设计思想**：**二叉排序树的中序遍历序列严格递增**。对顺序存储的树做中序遍历，用变量 prev 记录上一个访问的结点值，若当前值 ≤ prev 则不是 BST。

**(2) 代码**（C++）：
```cpp
bool inOrder(SqBiTree &T, int i, int &prev) {
    if (i >= T.ElemNum || T.SqBiTNode[i] == -1)
        return true;                                  // 空树
    if (!inOrder(T, 2 * i + 1, prev)) return false;   // 左子树
    if (T.SqBiTNode[i] <= prev) return false;         // 不递增，不是 BST
    prev = T.SqBiTNode[i];                            // 记录当前值
    return inOrder(T, 2 * i + 2, prev);               // 右子树
}
bool isBST(SqBiTree T) {
    int prev = 0;              // 结点值均为正整数，初值取 0 即可
    return inOrder(T, 0, prev);
}
```
**(3)** 时间 O(n)，空间 O(h)（递归栈，h 为树高）。

## 14.4 第 43、44 题：组成原理综合题（20~23 分）

### 📖 题型 A：Cache 综合（⭐⭐⭐ 最高频）
**答题步骤**：
1. **地址划分**：块内地址 = log₂(块大小)；组数 = Cache 容量 / 块大小 / 路数；Tag = 地址位数 − 组号位数 − 块内位数
2. **Cache 行结构**：有效位 1 + 脏位（回写才有）+ LRU 位（log₂路数）+ Tag + 数据
3. **某地址映射到哪组**：取地址中间的“组号”字段
4. **缺失次数**：
   - 数组总大小 / 块大小 = 占用块数（**注意起始地址是否对齐块边界**，不对齐要多 1 块）
   - 顺序访问、Cache 装得下时：缺失次数 = 块数
   - 读写同一元素：第一次读缺失，写命中
   - **按列访问二维数组**：每次访问都可能在不同块 → 缺失次数暴增（看 Cache 能否装下一“列”涉及的所有块）
5. **命中率 / 平均访问时间**：命中率 = 1 − 缺失数/总访问数；平均时间 = 命中时间 + 缺失率 × 缺失损失

### 📖 题型 B：虚拟存储（页表、TLB）
1. 页内偏移 = log₂(页大小)；虚页号 = 剩余高位
2. 页表项地址 = 页表起始 + 页号 × 项长
3. TLB 组相联：TLB 组号 = 虚页号低位，TLB 标记 = 虚页号高位
4. 数组跨了几页 → 缺页几次
5. **VIPT**：Cache 的组号 + 块内地址 如果都落在页内偏移里，就可以用虚拟地址直接索引 Cache

### 📖 题型 C：指令系统与机器级代码
- 操作码位数、寄存器个数、寻址范围（第 2 篇（三）6.1~6.2）
- 相对寻址目标地址 = **下一条指令地址** + 偏移（偏移是补码）
- 从机器码判断大小端：看立即数/地址在指令字节中的**排列顺序**（低位字节在前 → 小端）
- 判断溢出、符号扩展还是零扩展

### 📖 题型 D：数据通路 / 控制器
- 写出指令各阶段的**微操作序列**和**控制信号**（取指：PC→MAR，读，MDR→IR，PC+1）
- 单总线：每个周期只能有一个部件往总线送数据

### 📖 题型 E：运算器（补码、乘除法、浮点）
- 补码加减、OF/CF/SF/ZF 的求法（第 2 篇（一）4.6）
- 乘法溢出判断：无符号看高 n 位是否全 0；有符号看高 n 位是否全等于低 n 位的符号位
- 除法异常：除数为 0；最小负数 ÷ (−1)

### 📖 题型 F：I/O 计算
- 中断/DMA 占 CPU 时间百分比（第 2 篇（四）经典计算）
- 磁盘访问时间 = 寻道 + 半圈 + 传输
- 周期挪用 DMA 请求次数 = 数据量 / 接口缓冲寄存器大小

## 14.5 第 45、46 题：操作系统综合题（14~17 分）

### 📖 第 45 题：PV 同步（⭐⭐⭐）
**五步模板**（详见第 3 篇（一）8.10）：
1. 列出**进程**及其动作（写成 `while(1){…}`）
2. 找**互斥**（共享资源、共享缓冲区、共享工具）→ mutex = 1
3. 找**同步**（谁等谁：“A 完成后 B 才能…”）→ 初值 0，**前 V 后 P**
4. 找**资源计数**（“最多 n 个”“缓冲区大小为 n”）→ 初值 n
5. 写代码，检查：**先同步 P 后互斥 P**；每个 P 都有对应 V；没有死锁

**必须写清楚每个信号量的含义和初值！**（格式：`semaphore empty = 3; // 表示……`）

**2023 年第 45 题（swap 实现互斥）要点**：
```c
bool lock = FALSE;           // 共享变量
// 进入区
bool key = TRUE;
while (key == TRUE)          // 错误写法是 if，必须用 while 反复尝试
    swap(key, lock);
// 临界区
// 退出区
lock = FALSE;                // 错误写法是 lock = TRUE
```
**能否用普通函数 newSwap(&key, &lock) 代替 swap 指令？** → **不能**。swap 指令由硬件保证**原子性**（执行中不可被打断），而函数由多条指令组成，执行过程中可能被中断，两个进程可能同时读到 lock = FALSE，都进入临界区。

### 📖 第 46 题常见题型
- **地址转换**：分页、二级页表、段页式（第 3 篇（二））
- **页面置换**：LRU、CLOCK 手工模拟
- **文件系统**：索引结点、混合索引、FAT、目录项、打开文件过程（第 3 篇（三））
- **进程状态与系统调用流程**（2023 年 46 题）：
  > 进程 P 执行系统调用从键盘读一个字符。操作有：① 把 P 插入就绪队列；② 把 P 插入阻塞队列；③ 把字符从键盘控制器读入系统缓冲区；④ 启动键盘中断处理程序；⑤ P 从系统调用返回；⑥ 用户在键盘上输入字符。
  - 正确顺序：**② → ⑥ → ④ → ③ → ① → ⑤**（P 发起读请求后没有数据，先阻塞；用户按键 → 键盘中断 → 中断处理程序把字符读入缓冲区 → 唤醒 P 放入就绪队列 → P 被调度后从系统调用返回）
  - ② 之后 CPU 一定切换到其他进程；① 之后调度程序才能选中 P
  - ③ 属于**键盘驱动程序**
  - 键盘中断处理程序执行时，P 处于**阻塞态**，CPU 处于**内核态**
- **进程地址空间**（2025 年 46 题，第 3 篇（二）9.1）
- **磁盘调度、磁盘访问时间**

## 14.6 第 47 题：计算机网络综合题（9 分）

### 📖 常考组合
1. **IP 地址类**：网络地址、子网划分、可用主机数、路由表、路由聚合、最长前缀匹配
2. **地址变化类**：分组经过交换机、路由器、NAT 时，**源/目的 IP 和 MAC** 各是什么
3. **协议过程类**：DHCP 四步、ARP 请求响应、DNS 查询、HTTP/FTP 连接
4. **TCP 类**：三次握手序号、拥塞窗口变化、发送完文件需要的时间
5. **链路层类**：冲突域/广播域、CSMA/CD 最短帧长/最远距离、802.11 地址、停等/GBN 信道利用率

### ✏️ 2023 年第 47 题（FTP + TCP）要点
> H 通过 FTP 上传 18000 B 的文件 F。数据连接初始序号 100，MSS = 1000 B，拥塞窗口初始门限 4 MSS，RTT = 10 ms，忽略传输时延，不丢包。
1. FTP 控制连接是**持久**的，数据连接是**非持久**的；登录服务器时建立的是**控制连接**
2. SYN 用掉序号 100 → F 的第一个字节序号 **101**；F 占 101 ~ 18100，H 的 FIN 序号 18101，服务器第二次挥手的 ACK 确认号 = **18102**
3. 收到确认号 2101（确认了前 2 个段）时：初始 cwnd = 1 MSS，收到第 1 个确认 → 2，第 2 个确认 → **3 MSS = 3000 B**；
   收到确认号 7101 时：第 3 个确认后 cwnd = 4 MSS（到门限，进入拥塞避免），此后每轮 +1，一轮的 4 个确认收完后 cwnd = **5 MSS = 5000 B**
4. 从请求建立数据连接到确认 F 全部收到：握手 1 RTT；发送轮次 cwnd = 1、2、4、5、6，共发 1+2+4+5+6 = 18 段，5 RTT → 至少 **6 RTT = 60 ms**；平均发送速率 = 18000 B / 60 ms = **300 KB/s（2.4 Mbps）**

### ⏰ 时间分配（180 分钟）
| 部分 | 时间 |
|---|---|

| 41 算法题 | 20~25 分钟 |
| 42 | 10~15 分钟 |
| 43 + 44 | 30 分钟 |
| 45 + 46 | 25 分钟 |
| 47 | 10~15 分钟 |
| 检查 | 剩余时间 |

### 📖 技巧
1. **选择题遇到算不出来的，先标记跳过**，别在一道 2 分的题上耗 10 分钟
2. **大题先做有把握的**：比如网络 47 题、PV 45 题通常比 41 题更稳
3. **大题一定要写过程**：公式、中间结果都写上，结果错了也有步骤分
4. **单位要写清楚**：B / b，K = 2¹⁰ 还是 10³，ms / μs
5. **41 题时间不够就写暴力解**，写清思路和复杂度
6. 选择题**“下列说法错误的是”** 要圈出“错误”二字，防止看反

### 📖 最容易丢分的 15 个陷阱（考前必看）
1. 存储容量 K = 2¹⁰，速率 k = 10³
2. 按**字**编址还是按**字节**编址
3. 数组下标从 0 还是 1 开始；矩阵行优先还是列优先
4. 循环队列 rear 指向队尾元素还是队尾后一个位置
5. 相对寻址用的是**已经加过的 PC**
6. 补码范围比原码多一个负数
7. IEEE 754 的偏置是 127，尾数有隐藏的 1
8. 小端：**低字节放低地址**；结构体要**对齐**
9. Cache 回写才有脏位；直接映射不需要替换算法位
10. DRAM 地址引脚**减半**
11. 中断在**指令执行完**后响应；DMA 在**存储周期结束**后就能响应
12. 生产者消费者：**先同步 P，后互斥 P**
13. IP 首部长度单位 4 B，片偏移单位 8 B
14. SYN、FIN 各消耗一个序号
15. 可用主机数要 **−2**；子网起始地址必须是块大小的倍数

## 14.10 最后的话

🧒 408 看起来很吓人，其实它考的都是**有限的、固定的**知识点，**真题会反复考同样的东西**（你看 Cache、PV、子网划分，年年都考）。

1. **先懂比喻，再记定义**——本教程每个知识点的 🧒 部分就是帮你“懂”的
2. **每学一个知识点，马上做真题**——真题是最好的老师
3. **反复看小结表格**——考前能把所有表格默写出来，120 分就稳了
