# 第一部分：指令系统

## 6.1 指令格式

### 🧒 大白话
一条指令就像一句**命令**：“**把** 3 号抽屉的数 **加到** 5 号抽屉里”。
- “加”是**操作码（OP）**：做什么
- “3 号抽屉、5 号抽屉”是**地址码（A）**：对谁做

```
┌──────────┬──────────┬──────────┐
│  操作码   │ 地址码 A1 │ 地址码 A2 │
└──────────┴──────────┴──────────┘
```

### 📖 按地址码个数分
| 类型 | 格式 | 功能 | 例子 |
|---|---|---|---|
| 零地址 | OP | 不需要操作数，或操作数在栈顶 | 停机、空操作、栈运算 |
| 一地址 | OP A1 | (ACC) OP (A1) → ACC | 单操作数运算、累加器型 |
| 二地址 | OP A1 A2 | (A1) OP (A2) → A1 | 最常见 |
| 三地址 | OP A1 A2 A3 | (A1) OP (A2) → A3 | |

- **定长指令字**：所有指令一样长（RISC）
- **变长指令字**：指令长短不一（CISC，如 x86）

### 📖 扩展操作码（⭐ 计算题）
🧒 **大白话**：指令总长度固定（比如 16 位），地址码少的指令，就把“省下来”的位拿去当操作码用。就像电话号码：短号码的前缀**不能**和长号码冲突。

**原则**：短操作码**不能是**长操作码的前缀。所以要给更长的操作码**留出编码**。

**真题（2022 年第 19 题）**：16 位定长指令，扩展操作码，每个地址码 6 位，有零、一、二地址三种指令。二地址指令 12 条，一地址指令 254 条，零地址指令最多几条？
1. **二地址**：16 − 6 − 6 = **4 位操作码** → 共 2⁴ = 16 种，用了 12 种，**剩 4 种**留作扩展
2. **一地址**：操作码 = 4 + 6 = 10 位。能用的编码 = 4（剩下的前缀）× 2⁶ = **256 种**，用了 254 种，**剩 2 种**
3. **零地址**：操作码 = 16 位。能用的编码 = 2 × 2⁶ = **128 种**
4. 选 D（128）

🧒 **口诀**：“**剩下的 × 2^新增位数**”，一层一层往下算。

## 6.2 寻址方式（⭐⭐⭐ 必考）

### 🧒 大白话
指令里的地址码 A 叫**形式地址**。它不一定就是操作数真正在哪儿（**有效地址 EA**）。
寻址方式就是“**怎么根据 A 找到真正的数据**”，就像寻宝游戏的不同玩法：

| 寻址方式 | 有效地址 EA | 访存次数（取数据） | 大白话 |
|---|---|---|---|
| **立即寻址** | 没有 EA，**A 就是操作数本身** | 0 | 纸条上直接写着宝物 |
| **直接寻址** | EA = A | 1 | 纸条上写着宝物在几号柜 |
| **间接寻址** | EA = (A)，即主存 A 单元里的内容 | 2 | 纸条写着几号柜，柜里又是一张纸条写着宝物在哪 |
| **寄存器寻址** | 操作数在寄存器 Rᵢ 里 | 0 | 宝物就在手边抽屉里 |
| **寄存器间接** | EA = (Rᵢ) | 1 | 抽屉里放着一张纸条，写着宝物在几号柜 |
| **相对寻址** | EA = **(PC) + A** | 1 | “从我现在的位置往后数 A 步” |
| **基址寻址** | EA = **(BR) + A** | 1 | “从基地往后数 A 步” |
| **变址寻址** | EA = **(IX) + A** | 1 | A 是起点，变址寄存器一直在变（适合数组） |
| **堆栈寻址** | 操作数在栈顶，地址由 SP 给出 | 看情况 | |

> `(X)` 表示“X 里面存的内容”。

### 📖 要点
1. **立即寻址最快**（不访存），但数的范围受 A 的位数限制
2. **相对寻址**：PC 是**取完指令后已经加过的值**（指向下一条指令）！
   例：指令在 2000H，长 2 字节，A = 06H，相对寻址跳转目标 = 2002H + 06H = **2008H**
   - 相对寻址便于程序**浮动**（整体搬到别处，相对距离不变），广泛用于**转移指令**
   - A 通常是**补码**，可正可负
3. **基址 vs 变址**（选择题常考）：
   - **基址**：基址寄存器由**操作系统**管理，程序执行中**不变**，A 可变 → 面向**系统**，解决程序**浮动/重定位**
   - **变址**：变址寄存器由**用户**设置，执行中**不断变化**，A 不变 → 面向**用户**，处理**数组、循环**
4. 直接寻址的范围：**真题（2020 年第 16 题）**：16 位定长指令，48 条指令，4 种寻址方式，单地址指令直接寻址的范围？
   - 48 条 → 操作码 6 位；4 种寻址方式 → 2 位；剩 16 − 6 − 2 = **8 位**地址
   - 直接寻址 EA = A，A 是无符号数 → **0 ~ 255**，选 A

### 📖 指令寻址
- **顺序寻址**：PC + “1”（一条指令的长度）
- **跳跃寻址**：由转移指令给出新地址

## 6.3 CISC 和 RISC

| 比较 | CISC（复杂指令集） | RISC（精简指令集） |
|---|---|---|
| 指令数目 | 多、复杂 | 少、简单常用 |
| 指令长度 | **变长** | **定长** |
| 寻址方式 | 多 | 少 |
| 访存 | 很多指令能访存 | **只有 Load/Store 能访存** |
| 寄存器 | 少 | **多**（常用寄存器传参数） |
| 控制器 | 多用**微程序** | 多用**硬布线** |
| 流水线 | 难 | **非常适合流水线** |
| 代表 | x86 | ARM、MIPS、RISC-V |

**真题（2025 年第 17 题）**：关于 RISC 错误的是 **C. 难以采用流水线数据通路实现微架构**（恰恰相反，RISC 最适合流水线）。

## 6.4 程序的机器级表示（x86 汇编入门）

### 🧒 为什么要学？
408 近年喜欢给一段 C 代码和它对应的汇编代码，问你“某条指令是干什么的”“循环执行几次”“某变量在哪个寄存器”。你不需要会写汇编，**能看懂**就行。

### 📖 常见寄存器（32 位 x86）
`eax, ebx, ecx, edx, esi, edi`（通用）；`esp`（栈顶指针）；`ebp`（栈帧基址）；`eip`（就是 PC）

### 📖 常见指令（Intel 格式：`指令 目的, 源`）
| 指令 | 含义 |
|---|---|
| `mov eax, ebx` | eax ← ebx |
| `mov eax, [ebx]` | eax ← 主存中地址 ebx 处的 4 字节（方括号 = 访存） |
| `mov eax, [ebx + ecx*4 + 8]` | 数组访问：基址 + 下标 × 元素大小 + 偏移 |
| `lea eax, [ebx + 8]` | eax ← ebx + 8（**只算地址，不访存**） |
| `add / sub / imul` | 加 / 减 / 乘 |
| `and / or / xor / not` | 逻辑运算；`xor eax, eax` 常用来清零 |
| `shl / shr / sar` | 左移 / 逻辑右移 / 算术右移 |
| `cmp a, b` | 算 a − b，**只设置标志位**，不保存结果 |
| `test a, b` | 算 a & b，只设置标志位 |
| `jmp L` | 无条件跳转 |
| `je / jne / jg / jl / ja / jb` | 条件跳转（等于 / 不等 / 有符号大于 / 有符号小于 / 无符号大于 / 无符号小于） |
| `push / pop` | 入栈 / 出栈（esp 减 4 / 加 4，**栈向低地址增长**） |
| `call f` | 把返回地址压栈，跳到 f |
| `ret` | 从栈里弹出返回地址，跳回去 |

> 📌 AT&T 格式（`movl %ebx, %eax`）是“**源在前，目的在后**”，寄存器前加 %，立即数前加 $。考试会说明用哪种格式。

### 📖 函数调用的栈帧
```
高地址
│ 调用者的栈帧          │
│ 参数 n ... 参数 1     │ ← 调用者从右往左压入参数
│ 返回地址              │ ← call 指令压入
│ 旧的 ebp             │ ← 被调用函数 push ebp
│ 局部变量              │ ← ebp 以下
│ ...                  │ ← esp（栈顶）
低地址
```
被调用函数开头常见：`push ebp; mov ebp, esp; sub esp, N`（保存旧帧，建立新帧，给局部变量留空间）
结尾常见：`mov esp, ebp; pop ebp; ret`（或 `leave; ret`）
- 参数用 `[ebp + 8]`、`[ebp + 12]` 访问；局部变量用 `[ebp − 4]` 等访问
- 返回值放在 **eax**

### 📖 if 和循环长什么样
```c
if (a > b) x = 1;         // C 代码
```
```
cmp eax, ebx      ; 比较 a 和 b
jle SKIP          ; 如果 a <= b，跳过（条件取反！）
mov ecx, 1
SKIP:
```
循环就是“比较 + 条件跳回前面”。

## 6.5 真题精讲：2021 年第 43 题（指令格式综合，15 分）

> 16 位字长，按字节编址，地址线 20 位，数据线 8 位，16 位定长指令：
> ```
> R 型: | 000000 (6) | rs (2) | rt (2) | rd (2) | op1 (4) |   R[rd] ← R[rs] op1 R[rt]
> I 型: | op2 (6)    | rs (2) | rt (2) | imm (6)          |   ALU 运算、条件转移、访存
> J 型: | op3 (6)    | target (10)                       |   PC 低 10 位 ← target
> ```

**(1) ALU 宽度？可寻址主存多大？IR、MAR、MDR 各几位？**
- ALU 宽度 = 字长 = **16 位**
- 地址线 20 位，按字节编址 → **2²⁰ B = 1 MB**
- IR = 指令长度 = **16 位**；MAR = 地址线 = **20 位**；MDR = 数据线 = **8 位**

**(2) R 型最多几种操作？I 型 + J 型最多几种？通用寄存器最多几个？**
- R 型：op1 有 4 位 → **16 种**
- I 型和 J 型用 6 位操作码，但 000000 被 R 型占用 → 2⁶ − 1 = **63 种**
- 寄存器编号 2 位 → **4 个**

**(3) op1 = 0010 是带符号减法，0011 是带符号乘法。指令 01B2H 功能？R1 = B052H，R2 = 0008H，执行 01B2H 和 01B3H 后 R3 各是多少？溢出吗？**
- 01B2H = `000000 01 10 11 0010` → rs = 1，rt = 2，rd = 3，op1 = 0010（减法）
  → 功能：**R[3] ← R[1] − R[2]**
- 执行 01B2H：B052H − 0008H = **B04AH**。负数 − 正数 = 负数，**不溢出**
- 执行 01B3H（乘法）：B052H × 0008H = 5 8290H，只保留低 16 位 **8290H**。
  B052H = −20398，× 8 = −163184，超出 16 位补码范围 −32768 ~ 32767 → **溢出**

**(4) I 型访存指令 imm 是带符号偏移量，地址计算时零扩展还是符号扩展？**
→ **符号扩展**（补码变长要补符号位）

**(5) 无条件转移可以用哪种格式？**
→ **J 型**（target 直接给出转移目标地址，PC 低 10 位 ← target）。

# 第二部分：中央处理器（CPU）

## 6.6 CPU 的功能和结构

### 🧒 大白话
CPU = **运算器**（干活的手） + **控制器**（指挥的大脑）。

- **运算器**：ALU、通用寄存器组、暂存寄存器、累加器、移位器、程序状态字寄存器 PSW
- **控制器**：程序计数器 PC、指令寄存器 IR、指令译码器、**控制单元 CU**（产生控制信号）、时序系统、MAR、MDR

**真题（2025 年第 19 题）**：错误的是 **A. 通用寄存器组中应该包含程序计数器**（PC 是控制器里的专用寄存器，不在通用寄存器组里）。

## 6.7 指令周期（⭐）

一条指令的执行过程分几个阶段（机器周期）：
```
取指周期 → (间址周期) → 执行周期 → (中断周期)
```
- **取指周期**：按 PC 取指令到 IR，PC 加 1
- **间址周期**：如果是间接寻址，去取有效地址
- **执行周期**：真正执行
- **中断周期**：执行完检查有没有中断请求，有就保存断点、转去中断服务

**取指周期的微操作（⭐ 必背）**：
```
① (PC) → MAR          把 PC 中的地址送 MAR
② M(MAR) → MDR        主存读，数据送 MDR（同时发“读”信号）
③ (MDR) → IR          指令送 IR
④ (PC) + 1 → PC        PC 指向下一条指令
```
🧒 取指令对所有指令都一样，所以叫**公共操作**。

> 📌 CPU 怎么区分取出来的是指令还是数据？→ **看是在哪个阶段取的**：取指周期取出的是指令，执行周期取出的是数据。

## 6.8 数据通路（⭐ 2022 年 43 题）

### 🧒 大白话
数据通路就是 CPU 内部各部件之间**数据流动的“马路”**。
- **单总线结构**：所有部件都挂在一条内部总线上。像**一条单车道**，**同一时刻只能有一个部件往总线上送数据**。
- **多总线/专用通路**：多条路，可以同时传多个数据，快但复杂。

数据通路由**组合逻辑元件**（ALU、多路选择器、译码器：输出只看当前输入）和**时序逻辑元件**（寄存器：有记忆）组成。
**真题（2021 年第 18 题）**：数据通路错误的是 **C. 不包含用于异常事件检测及响应的电路**（其实包含，比如溢出检测、中断响应要改 PC）。

### 📖 控制信号的写法
- `PCout`：PC 的内容送到总线；`MARin`：总线上的数据写入 MAR
- `MemR`：主存读；`MemW`：主存写
- `MDRout`、`MDRin`、`IRin` 同理

**真题（2022 年第 43 题第 4 问）**：单总线结构，取指阶段（不考虑 PC 增量）控制信号序列？主存读 5 个周期，取指至少几个周期？
```
C1:  PCout, MARin         ; PC → MAR
C2:  MemR                 ; 读主存
...  （共 5 个周期读出数据送入 MDR）
C7:  MDRout, IRin         ; MDR → IR
```
共 1 + 5 + 1 = **7 个时钟周期**。

**为什么 ALU 的输入/输出要设暂存器 Y、Z？**（同题第 2 问）
🧒 单总线**一次只能传一个数据**，而 ALU 要两个输入：先把一个操作数通过总线送到 Y 里存着，下一拍再把另一个送过去。ALU 的结果也不能马上放上总线（总线正在被输入占用），先存到 Z 里。

## 6.9 控制器（⭐）

### 📖 硬布线控制器
🧒 用**逻辑电路**直接“焊死”：给什么输入（指令操作码、时序、状态），就输出什么控制信号。
- **速度快**，但设计复杂、**难修改扩展**
- **RISC** 多用

### 📖 微程序控制器
🧒 把每条指令的执行过程写成一个“**小程序**”（微程序），存在 CPU 内部的**控制存储器（CM，一般是 ROM）**里，执行时一条条读出来产生控制信号。
- **慢**一些，但**规整、易修改扩展**
- **CISC** 多用

**几个概念（层层包含）**：
- **微命令**：一个控制信号（如 PCout）
- **微操作**：微命令引起的一个基本操作
- **微指令**：一个时钟周期内要发出的**一组微命令**
- **微程序**：一条机器指令对应的**一串微指令**
- **控制存储器 CM**：存所有微程序，**在 CPU 内部**，用 ROM 实现
- **微指令寄存器 μIR**、**微地址寄存器 μPC**

**微指令格式（⭐ 计算）**：
- **水平型**：一条微指令能发出多个并行的微命令，速度快，微指令长
- **垂直型**：像机器指令一样有微操作码，一条只做一两件事，微指令短，速度慢
- **字段直接编码**：把**互斥的**微命令分到同一个字段里编码，一个字段有 n 个微命令时需要 **⌈log₂(n + 1)⌉ 位**（**+1 是要留一个编码表示“什么都不做”**）

**例**：某字段有 7 个互斥微命令 → log₂(7+1) = **3 位**；有 8 个 → log₂9 → **4 位**。

**微指令数计算**：若机器有 m 条指令，每条指令的执行阶段平均 k 条微指令，再加上所有指令**共用**的取指微程序（比如 2 条），总数 = m × k + 2（公共部分只算一次）。

## 6.10 单周期 / 多周期 CPU

| | 单周期 CPU | 多周期 CPU |
|---|---|---|
| 每条指令 | **一个时钟周期**完成 | 分成多个时钟周期 |
| CPI | **= 1** | > 1 |
| 时钟周期 | 以**最慢的指令**为准（长） | 以最慢的**阶段**为准（短） |
| 部件复用 | 不能复用（一个周期内同一部件只能用一次） | 可复用 |
| 控制器 | 简单 | 复杂 |

**真题（2020 年第 17 题）**：理想情况下 CPI = 1 的是 **单周期 CPU** 和 **基本流水线 CPU**（选 B）。多周期 CPI > 1；超标量 CPI < 1（一个周期能完成多条指令）。

**真题（2025 年第 18 题）**：错误的是 **B. 程序的 CPI 与 Cache 缺失率无关**（缺失会让访存指令要多等很多周期，CPI 变大）。

## 6.11 指令流水线（⭐⭐⭐）

### 🧒 大白话：洗衣服
洗衣服有三步：**洗**（30 分钟）→ **烘**（30 分钟）→ **叠**（30 分钟）。
- 不用流水线：一桶一桶来，洗完一桶要 90 分钟，4 桶要 360 分钟
- 用流水线：第 1 桶去烘的时候，第 2 桶就可以开始洗了！4 桶只要 90 + 3 × 30 = **180 分钟**

```
时间 →   1    2    3    4    5    6
第1桶:  洗   烘   叠
第2桶:       洗   烘   叠
第3桶:            洗   烘   叠
第4桶:                 洗   烘   叠
```

### 📖 经典五段流水线
| 阶段 | 做什么 |
|---|---|
| **IF** | 取指令 |
| **ID** | 译码、读寄存器 |
| **EX** | 执行（ALU 运算、算地址） |
| **MEM** | 访存（Load/Store） |
| **WB** | 写回寄存器 |

**流水段的时间以最长的那一段为准**（2025 年第 18 题 D 选项正确）。

### 📖 性能计算（⭐ 必背公式）
k 段流水线，每段时间 Δt，执行 n 条指令：
- **总时间** = (k + n − 1) × Δt
  🧒 第 1 条指令要走完 k 段，之后每过 Δt 就完成一条
- **吞吐率** TP = n / ((k + n − 1)Δt)，n 很大时趋近 1/Δt
- **加速比** S = 不用流水线的时间 / 用流水线的时间 = nkΔt / ((k + n − 1)Δt)，n 很大时趋近 **k**
- **效率** E = 各段实际忙碌的时空面积 / 总面积 = n / (k + n − 1)

**例**：5 段流水线，每段 2 ns，执行 100 条指令：
- 时间 = (5 + 99) × 2 = 208 ns
- 不用流水线 = 100 × 5 × 2 = 1000 ns，加速比 ≈ 4.8

### 📖 流水线冒险（⭐⭐ 相关/冲突）
🧒 流水线不是总那么顺利，会遇到三种“堵车”：

**① 结构冒险（资源冲突）**：两条指令同一时刻要用**同一个部件**。
- 例：一条指令在 MEM 访存，另一条在 IF 取指，都要访问存储器
- 解决：**指令 Cache 和数据 Cache 分开**；或者让后面的暂停

**② 数据冒险（数据相关，⭐ 最常考）**：后面的指令要用前面指令的**结果**，但前面的还没写回。
```
I1: add R1, R2, R3     ; R1 ← R2 + R3（第 5 拍才写回 R1）
I2: sub R4, R1, R5     ; 要读 R1（第 3 拍就要读！）→ 读到旧值，出错
```
- 这种叫 **RAW（写后读）**，是五段流水线中唯一会真正发生的数据冒险
- 解决：
  - **暂停（插入气泡/空操作 nop）**：让 I2 等一等
  - **数据转发（旁路）**：I1 在 EX 段算出结果后**直接送给** I2 的 EX 段使用，不用等写回
  - **编译器调整指令顺序**
- ⚠️ **Load-Use 冒险**：`load` 指令要到 MEM 段结束才拿到数据，紧跟着使用它的指令**即使有转发也要暂停 1 个周期**

**③ 控制冒险（控制相关）**：遇到**转移指令**，在确定跳不跳之前，后面该取哪条指令不知道。
- 解决：暂停、**分支预测**、延迟转移、尽早判断转移条件

### 📖 高级流水线
- **超标量**：一个时钟周期**同时发射多条**指令（多条流水线），CPI < 1
- **超流水线**：把流水段分得**更细**，时钟频率更高
- **动态调度**：乱序执行

## 6.12 多处理器（2022 年新增）

### 📖 Flynn 分类
| 类型 | 含义 | 例子 |
|---|---|---|
| SISD | 单指令流单数据流 | 传统单核 CPU |
| **SIMD** | 单指令流**多数据流**（一条指令同时处理一组数据） | **向量处理器**、GPU |
| MISD | 多指令流单数据流 | 实际上不存在 |
| **MIMD** | 多指令流多数据流 | **多核处理器、多处理器系统** |

### 📖 硬件多线程
🧒 一个 CPU 核同时保存多个线程的状态（寄存器、PC 各一份），一个线程卡住（比如等内存）时马上切换到另一个。
- **细粒度**：每个时钟周期切换
- **粗粒度**：遇到长时间阻塞（如 Cache 缺失）才切换
- **同时多线程（SMT）**：同一个周期里发射多个线程的指令（Intel 超线程）

**真题（2022 年第 22 题）**：错误的是 **C. 硬件多线程技术只可用于多核处理器**（单核也能用）。
其他正确选项：多核属于 MIMD；向量处理器属于 SIMD；**SMP（对称多处理器）中所有处理器共享单一物理地址空间**。

- **UMA**：所有处理器访问所有内存的时间一样
- **NUMA**：访问本地内存快，访问别的处理器的内存慢

## 6.13 异常和中断（⭐⭐ 组成原理 + 操作系统都考）

### 🧒 大白话
CPU 正在专心干活，突然有“意外情况”要处理：
- **内部异常**：是 CPU **自己**执行指令时发现的问题（“我算除法时发现除数是 0！”）
- **外部中断**：是**外面**的设备来“敲门”（“键盘被按了！”“网卡收到数据了！”“定时器到时间了！”）

### 📖 分类（⭐⭐ 必背）
```
异常和中断
├── 内部异常（与当前执行的指令有关，同步）
│    ├── 故障（Fault）：可能修复 → 返回【当前指令】重新执行
│    │        例：缺页、除数为 0（除 0 一般直接终止进程）、非法操作码
│    ├── 自陷（Trap）：事先安排好的 → 返回【下一条指令】
│    │        例：系统调用（trap 指令）、断点、单步跟踪
│    └── 终止（Abort）：硬件出了严重错误，无法恢复
│             例：控制器出错、存储器校验错
└── 外部中断（与当前指令无关，异步）
     ├── 可屏蔽中断（INTR）：I/O 设备请求、定时器到时
     └── 不可屏蔽中断（NMI）：掉电等紧急情况
```

**检测时机**：
- **异常**：在指令执行**过程中**检测
- **中断**：在**每条指令执行完**之后检测

### 📖 真题连击
**真题（2021 年第 21 题）**：处理后必须**回到当前指令重新执行**的是？→ **B. 页缺失**（缺的页调进来后要重新执行刚才那条访存指令）。系统调用是自陷，返回下一条；DMA 结束、打印机缺纸是外部中断，也是返回下一条（因为是在指令执行完后才响应的）。

**真题（2020 年第 18 题）**：关于自陷，错误的是 **A. 自陷是通过陷阱指令预先设定的一类外部中断事件**（自陷是**内部**异常）。
其余正确：自陷可用于断点和单步跟踪；发生后 CPU 转去执行操作系统内核程序；处理完返回陷阱指令的**下一条**。

**真题（2020 年第 20 题）**：属于外部中断的是？访存时缺页（✗，内部故障）、**定时器到时 ✓**、**网络数据包到达 ✓** → 选 C。

**真题（2025 年第 22 题）**：会触发外部中断请求的是 **A. DMA 传送结束**（DMA 控制器发中断通知 CPU）。“执行断点指令”是内部自陷。

### 📖 异常/中断的响应过程（硬件完成）
1. **关中断**（防止处理保存现场时又被打断）
2. **保存断点和程序状态**（PC、PSW 压栈或存到特定寄存器）
3. **识别异常/中断源，转到对应的处理程序**（通过**中断向量表**找入口地址）
这三步由**硬件**完成，叫**中断隐指令**（不是真正的指令，程序员看不到）。
之后由**操作系统的处理程序**（软件）接手：保存通用寄存器、处理、恢复、返回。

**2025 年第 44 题第 2 问：除法异常时 CPU 要做什么？**
→ 检测到除法异常（除数为 0，或 −2³¹ ÷ −1 溢出）后：**关中断，保存断点（当前指令地址）和程序状态字，根据异常类型号找到异常处理程序入口，转去执行**（切换到内核态）。

## 6.14 本篇小结

| 知识点 | 一句话 |
|---|---|
| 扩展操作码 | 剩下的编码 × 2^新增位数 |
| 立即寻址 | 操作数在指令里，0 次访存 |
| 间接寻址 | 2 次访存 |
| 相对寻址 | EA = (PC) + A，PC 已经加过 |
| 基址 vs 变址 | 基址 OS 管不变（重定位）；变址用户管在变（数组） |
| RISC | 定长、Load/Store、寄存器多、硬布线、适合流水线 |
| 取指微操作 | PC→MAR，M→MDR，MDR→IR，PC+1 |
| 微程序 | 控存在 CPU 内（ROM）；字段编码 ⌈log₂(n+1)⌉ 位 |
| 单周期 | CPI = 1，时钟周期取最慢指令 |
| 流水线 | (k+n−1)Δt；数据冒险用转发/暂停；Load-Use 仍要停 1 拍 |
| Flynn | 向量机 SIMD，多核 MIMD |
| 异常 | 故障返回本条（缺页）；自陷返回下一条（系统调用）；中断在指令执行完后响应 |

## 6.15 课后练习

1. 某指令地址 1000H，长 2 字节，采用相对寻址，形式地址 A = FFF0H（补码），转移目标地址？
2. 某微指令有一个字段包含 12 个互斥的微命令，该字段至少几位？
3. 4 段流水线，每段 10 ns，执行 20 条指令，总时间？加速比？
4. 下面哪些是自陷？(a) 整数除 0 (b) 系统调用 (c) 键盘输入 (d) 断点指令

<details>
<summary>答案</summary>

1. PC 取指后 = 1002H，FFF0H = −16，目标 = 1002H − 10H = **0FF2H**
2. ⌈log₂13⌉ = 4 位
3. (4 + 19) × 10 = 230 ns；加速比 = 20 × 4 × 10 / 230 ≈ 3.48
4. (b)(d)。(a) 是故障，(c) 是外部中断
</details>
