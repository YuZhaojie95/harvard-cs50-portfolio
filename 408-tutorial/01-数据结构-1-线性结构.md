# 第 1 篇 · 数据结构（一）：线性结构

> 数据结构占 **45 分**：选择题 11 道（22 分）+ 第 41 题算法题（13~15 分）+ 第 42 题应用题（8~10 分）。
> 本篇讲“排成一条线”的结构：**线性表、栈、队列、数组、串**。

**先说“数据结构”是什么：**
🧒 你有一堆玩具，可以**排成一排**（线性表），可以**摞成一摞**（栈），可以**排队**（队列），可以**像家谱一样分叉**（树），也可以**像地铁线路图一样互相连**（图）。
“数据结构”就是研究：**数据怎么摆（逻辑结构）+ 在内存里怎么存（存储结构）+ 怎么操作（算法）**。

两种最基本的存储方式：
- **顺序存储**：像电影院**一排连着的座位**，挨着坐。找第 5 个人很快（直接数过去），但中间插一个人，后面所有人都要挪。
- **链式存储**：像**寻宝游戏**，每个人手里有一张纸条写着下一个人在哪。插人很方便（改纸条），但找第 5 个人要从头一个个问过去。

## 1.1 线性表

### 🧒 大白话
线性表就是**一排数据，有先后顺序**：第 1 个、第 2 个、……、第 n 个。除了第一个，每个都有“前一个”；除了最后一个，每个都有“后一个”。

### 1.1.1 顺序表（用数组存）

```c
#define MaxSize 50
typedef struct {
    int data[MaxSize];  // 一排座位
    int length;         // 现在坐了几个人
} SqList;
```

| 操作 | 时间复杂度 | 为什么 |
|---|---|---|
| 按位置找（第 i 个） | **O(1)** | 直接 data[i-1]，“随机存取” |
| 按值找 | O(n) | 要一个个比 |
| 插入 | O(n) | 后面的人都要往后挪一格 |
| 删除 | O(n) | 后面的人都要往前挪一格 |

> 📌 **插入/删除平均移动次数**（n 个元素）：插入平均移动 **n/2** 个，删除平均移动 **(n−1)/2** 个。

### 1.1.2 单链表

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

**头结点**：在第一个真正的数据前面，放一个“不存数据的哨兵结点”。
🧒 就像火车头：不载客，但有了它，“在第 1 节车厢前面插车厢”和“在中间插车厢”就能用**同一套动作**，写代码不用特殊处理。

#### 插入（把 s 插到 p 后面）——⭐ 必会
```c
s->next = p->next;   // ① 新结点先拉住 p 原来的后继
p->next = s;         // ② p 再拉住新结点
```
🧒 **口诀：先连后断**。顺序反了，p 原来的后继就“丢了”（没人记得它的门牌号）。

#### 删除（删掉 p 后面的结点 q）——⭐ 必会
```c
q = p->next;         // q 是要删的
p->next = q->next;   // p 直接跳过 q，拉住 q 的后继
free(q);             // 释放 q
```

#### 头插法 vs 尾插法建表
- **头插法**：每个新结点都插在头结点后面 → 读入顺序和链表顺序**相反**（可以用来“逆置链表”！）。
- **尾插法**：每个新结点都接在尾巴后面 → 顺序**相同**，需要一个尾指针 r。

### 1.1.3 双链表、循环链表

- **双链表**：每个结点有 `prior`（前一个）和 `next`（后一个）两根指针。可以往回走。
  插入 s 到 p 之后（4 步，顺序很重要）：
  ```c
  s->next = p->next;
  p->next->prior = s;
  s->prior = p;
  p->next = s;       // 这一步必须在前两步之后
  ```
- **循环单链表**：最后一个结点的 next 指回头结点，首尾相连成圈。
  常设**尾指针 r**：因为 r->next 就是头结点，这样找头、找尾都是 O(1)。
- **循环双链表**：双链表 + 首尾相连。

### ✏️ 真题（2021 年第 1 题）
> 带头结点的非空单循环链表，头指针 h，尾指针 p，临时指针 q。删除链表**第一个元素**，正确的是：
> A. `h->next = h->next->next; q = h->next; free(q);`
> B. `q = h->next; h->next = h->next->next; free(q);`
> C. `q = h->next; h->next = q->next; if(p != q) p = h; free(q);`
> D. `q = h->next; h->next = q->next; if(p == q) p = h; free(q);`

**分析：**
- A 错：先改了 h->next，再让 q = h->next，q 指向的是第二个元素，删错了。
- B 看起来对，但**漏了一种情况**：如果链表只有一个元素，那它既是第一个也是最后一个（p == q）。删掉后 p 就指向了一块被释放的内存！必须让尾指针回到头结点 `p = h`。
- 所以选 **D**：只有当“删的就是尾结点”时才修改尾指针。

> ⚠️ **链表题万能检查法**：写完代码后，拿“**空表、只有 1 个元素、删第一个、删最后一个**”这几种特殊情况各走一遍。

### 📊 顺序表 vs 链表（常考选择题）

| 比较项 | 顺序表 | 链表 |
|---|---|---|
| 按序号访问 | O(1) 随机存取 | O(n) 顺序存取 |
| 插入删除 | 要移动元素 O(n) | 只改指针 O(1)（找到位置后） |
| 存储密度 | 高（=1） | 低（还要存指针） |
| 空间分配 | 预先分配，可能浪费或不够 | 用多少申请多少 |

## 1.2 栈（Stack）

### 🧒 大白话
栈就是一摞**盘子**：
- 放盘子只能放在**最上面**（入栈 Push）
- 拿盘子只能拿**最上面**那个（出栈 Pop）
- 所以**后放的先拿**：**后进先出（LIFO）**

```
   ┌───┐  ← 栈顶（top），只能在这里进出
   │ c │
   │ b │
   │ a │
   └───┘  ← 栈底
```

### 📖 顺序栈
```c
typedef struct {
    int data[MaxSize];
    int top;          // 栈顶下标；初始 top = -1 表示空栈
} SqStack;
// 入栈：data[++top] = x;   （先加再放）
// 出栈：x = data[top--];   （先取再减）
// 栈空：top == -1；栈满：top == MaxSize-1
```
> ⚠️ 有的题目规定 top 初值为 0（指向“下一个空位”），那就变成 `data[top++] = x`、`x = data[--top]`。**做题先看 top 的初值！**

**共享栈**：两个栈共用一个数组，一个从左往右长，一个从右往左长，中间“碰头”时才满（`top1 + 1 == top2`）。省空间。

### 📖 出栈序列问题（⭐ 年年考）

**真题（2020 年第 2 题）**：入栈序列 a,b,c,d,e，操作 Push, Push, Pop, Push, Pop, Push, Push, Pop，出栈序列？

跟着做就行：
```
Push a      栈：a
Push b      栈：a b
Pop  → b    栈：a
Push c      栈：a c
Pop  → c    栈：a
Push d      栈：a d
Push e      栈：a d e
Pop  → e    栈：a d
```
出栈序列 **b, c, e**，选 D。

**判断某个出栈序列是否合法的技巧：**
🧒 某个元素出栈时，**比它先入栈、还没出栈**的元素，一定是按“**倒序**”待在栈里的，将来也必须**倒序**出来。

例：入栈 1,2,3,4，出栈能不能是 3,1,2,4？
3 先出，说明 1、2 已经在栈里，且 2 压在 1 上面。下一个能出的只能是 2 或者后面新进的，**不可能是 1** → 不合法。

> 📌 **卡特兰数**：n 个不同元素依次入栈，不同出栈序列的个数 = $\frac{1}{n+1}C_{2n}^{n}$。
> n=3 时是 5 个，n=4 时是 14 个。这个公式也等于“n 个结点能构成的不同二叉树的形态数”。

### 📖 栈的应用

#### ① 括号匹配
从左往右扫，遇到左括号就入栈；遇到右括号就看栈顶是否是配对的左括号，是就弹出，否则不匹配。最后栈空才算完全匹配。

**真题（2025 年第 2 题）**：栈容量只有 3，哪个表达式处理不了？
🧒 其实就是在问：**哪个表达式括号嵌套超过 3 层**？选项 D `[a−(b+[c*(d+e)−f]+g+h)]` 里，`[ ( [ (` 同时在栈里 4 个，放不下 → 选 D。

#### ② 表达式求值：中缀 → 后缀（⭐）
- **中缀**：`a + b * c`（我们平时写的）
- **后缀（逆波兰）**：`a b c * +`（运算符写在两个操作数后面，计算机最喜欢，不需要括号）

**手算中缀转后缀（考试用这个，最快）：**
1. 按运算顺序给每个运算加上括号：`(a + (b * c))`
2. 把每个运算符**挪到它所在括号的右括号后面**：`(a (b c)* )+`
3. 去掉括号：`a b c * +`

**计算后缀表达式**：从左往右，遇到数就入栈，遇到运算符就弹出两个数（**先弹出的是右操作数**），算完结果再入栈。

**用栈做中缀转后缀（机算规则）**：
- 遇到操作数：直接输出
- 遇到 `(`：入栈
- 遇到 `)`：不断弹出并输出，直到弹出 `(`
- 遇到运算符：把栈里**优先级 ≥ 它**的运算符都弹出输出（遇到 `(` 停），再把它入栈
- 最后把栈里剩下的全部弹出

#### ③ 递归
函数调用自己，每次调用都会在“**系统栈**”里压入一层（保存参数、局部变量、返回地址）。递归深度 d → 空间复杂度 O(d)。

## 1.3 队列（Queue）

### 🧒 大白话
队列就是**排队买奶茶**：从**队尾**进，从**队头**出。先来的先买：**先进先出（FIFO）**。

### 📖 循环队列（⭐⭐ 必考公式）

🧒 用数组做队列有个问题：队头一直往后走，前面空出来的位置浪费了。
解决：把数组**首尾接起来变成一个圈**，走到头就绕回 0 号位置。“绕回”用 **% MaxSize**（取余）实现。

```c
typedef struct {
    int data[MaxSize];
    int front, rear;  // front 指队头元素，rear 指队尾元素的“下一个空位”
} SqQueue;
```

| 操作 | 公式 |
|---|---|
| 初始 | front = rear = 0 |
| 入队 | data[rear] = x; rear = (rear + 1) % MaxSize |
| 出队 | x = data[front]; front = (front + 1) % MaxSize |
| **队空** | front == rear |
| **队满**（牺牲一个单元） | (rear + 1) % MaxSize == front |
| **元素个数** | (rear − front + MaxSize) % MaxSize |

🧒 **为什么要“牺牲一个单元”？** 如果把所有格子都装满，rear 会绕一圈追上 front，这时 front == rear，和“队空”长得一模一样，分不清！所以故意空一格：rear 的**下一格**是 front 就算满。
（另外两种区分方法：加一个 size 计数变量，或加一个 tag 标记最近一次是入队还是出队。）

> ⚠️ 真题经常改规定，比如“rear 指向队尾元素本身”。这时公式要跟着变。**做题先确认 front、rear 指向哪里，再自己推公式**，不要死背。

### 📖 链队列
带头指针 front 和尾指针 rear 的单链表。入队在尾部插，出队在头部删。
⚠️ 当删除的是**最后一个元素**时，要把 rear 也改回来（和 2021 年第 1 题同一个坑）。

### 📖 双端队列（⭐ 选择题常考）
两端都能进、都能出。
- **输入受限**：一端只能出，另一端能进能出。
- **输出受限**：一端只能进，另一端能进能出。

**真题（2021 年第 2 题）**：Q 的一端只能入队，另一端能入能出。入队序列 1,2,3,4,5，不能得到的出队序列？
🧒 方法：所有元素只能从“出口”那头出来。先看第一个出来的是几，就说明它之前的元素都已经在队里。倒推出“当时队里从左到右是什么样”，再检查能不能摆出来。

- D 选项 4,1,3,2,5：4 先出，1~4 都在队里；接下来依次出 1、3、2，说明队里从出口往里是 4,1,3,2，也就是 3 夹在 1 和 2 中间。
- 但 1、2 进来时要么 2 在 1 左边，要么在右边，它们是**紧挨着**的，3 后来只能放在两端，**插不进中间** → 不可能，选 **D**。

### 📖 队列的应用
- 层次遍历（二叉树、图的 BFS）
- 操作系统里的就绪队列、打印机缓冲区

## 1.4 数组和特殊矩阵压缩（⭐ 选择题年年有）

### 1.4.1 二维数组的存储

二维数组 A[m][n] 在内存里还是**排成一行**存的：
- **行优先**（C 语言）：先存第 0 行全部，再存第 1 行……
- **列优先**：先存第 0 列全部，再存第 1 列……

**行优先地址公式**（下标从 0 开始，每个元素占 L 字节）：
```
LOC(a[i][j]) = LOC(a[0][0]) + (i × n + j) × L
```
🧒 就是“**前面有几个元素**”× 每个元素大小。第 i 行前面有 i 整行，每行 n 个；本行前面还有 j 个。

**真题（2021 年第 3 题）**：行优先，每个元素 1 个单元，A[0][0] 地址 100，A[3][3] 地址 220，求 A[5][5]。
- 220 − 100 = 120 = 3n + 3 → n = 39（每行 39 个元素）
- A[5][5] = 100 + 5×39 + 5 = **300**，选 B。

### 1.4.2 特殊矩阵的压缩存储

🧒 有些矩阵很“有规律”，比如**对称矩阵**（a[i][j] = a[j][i]），存一半就够了，另一半照着抄。这就叫**压缩存储**：把需要存的元素一个挨一个放进一维数组 B。

**万能方法（强烈推荐，不用背公式）：数一数“我前面有几个元素”。**

**真题（2020 年第 1 题）**：10×10 对称矩阵 M，把**上三角**部分（i ≤ j，下标从 1 开始）**按列优先**存入 C 语言一维数组 N（下标从 0 开始），问 m₇,₂ 在 N 中的下标。

一步一步来：
1. m₇,₂ 在下三角（7 > 2），不存！但对称矩阵 m₇,₂ = m₂,₇，所以找 **m₂,₇**。
2. 上三角按列存：第 1 列存 1 个（m₁₁），第 2 列存 2 个，……第 j 列存 j 个。
3. m₂,₇ 在第 7 列，前面 6 列一共 1+2+3+4+5+6 = 21 个。
4. 在第 7 列里，它是第 2 个（m₁,₇、m₂,₇），前面还有 1 个。
5. 前面一共 21 + 1 = 22 个 → 因为 N 下标从 0 开始，所以它的下标就是 **22**，选 C。

> 🎯 **考试时四个坑**：
> ① 矩阵下标从 0 还是 1 开始？② 数组下标从 0 还是 1 开始？③ 行优先还是列优先？④ 存上三角还是下三角？
> 用“数前面有几个”的方法，这四个坑都能自然避开。

**常见特殊矩阵：**

| 矩阵 | 特点 | 需要存的元素个数 |
|---|---|---|
| 对称矩阵 | a[i][j] = a[j][i] | n(n+1)/2 |
| 三角矩阵 | 上（或下）三角全是同一个常数 c | n(n+1)/2 + 1（多存一个 c） |
| 三对角矩阵 | 只有主对角线和它上下各一条线非零 | 3n − 2 |
| 稀疏矩阵 | 非零元素很少 | 用**三元组**（行, 列, 值）或**十字链表**存，**失去随机存取特性** |

三对角矩阵（行优先，下标都从 1 开始、数组从 0 开始）：a[i][j] 前面有 `3(i−1) − 1 + (j − i + 1)` 个元素 → 下标 k = 2i + j − 3。（推的时候就想：前 i−1 行，第 1 行只有 2 个，其余每行 3 个。）

## 1.5 串与 KMP 算法

### 🧒 大白话
**串**就是字符串，比如 "hello"。最重要的操作叫**模式匹配**：在一篇长文章（主串 S）里找一个词（模式串 T）出现在哪。

### 1.5.1 朴素匹配（暴力法）
把 T 对准 S 的第 1 个字符开始逐个比较；一旦不一样，T **往右挪一格**，从头再比。
最坏时间 O(m × n)。
🧒 缺点：明明已经比对过的信息全浪费了，主串指针要“回退”。

### 1.5.2 KMP 算法（⭐ 难点，慢慢看）

🧒 **核心想法**：比到一半发现不对时，**主串指针不回头**，只把模式串“聪明地”往右多挪几格。挪多少？看**已经匹配成功的那一段**里，“**开头**”和“**结尾**”有多长是一样的。

举例：主串 `...abaabx...`，模式串 `abaabc`。
比到第 6 个字符时，主串是 x，模式串是 c，不一样。
但前 5 个 `abaab` 已经匹配成功了。观察 `abaab`：
- 开头的 `ab` 和结尾的 `ab` 一样！
- 所以可以直接把模式串的开头 `ab` 对准主串刚才那段结尾的 `ab`，接着比第 3 个字符，**不用从头比**。

#### 步骤 1：求“部分匹配值（PM）”
对模式串的**每个前缀**，找“**最长的相等前后缀**”长度（前后缀都不能是整个串自己）。

以 `abaabc` 为例：

| 前缀子串 | 前缀们 | 后缀们 | 最长相等 | PM |
|---|---|---|---|---|
| a | 无 | 无 | — | 0 |
| ab | a | b | — | 0 |
| aba | a, ab | a, ba | a | 1 |
| abaa | a, ab, aba | a, aa, baa | a | 1 |
| abaab | a, ab, aba, abaa | b, ab, aab, baab | ab | 2 |
| abaabc | … | … | 无 | 0 |

PM = `0 0 1 1 2 0`

#### 步骤 2：失配时怎么挪
**右移位数 = 已匹配的字符数 − 最后一个匹配字符对应的 PM 值**

上例：在第 6 个字符失配，已匹配 5 个，第 5 个字符的 PM 是 2 → 右移 5 − 2 = 3 位。

#### 步骤 3：next 数组（教材写法）
把 PM 整体**右移一位**，第一位补 −1，就得到 next（下标从 0 开始的写法）；
如果串下标从 1 开始（王道/严蔚敏教材写法），再把每个值 **+1**：

| j | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 模式串 | a | b | a | a | b | c |
| PM | 0 | 0 | 1 | 1 | 2 | 0 |
| next（从 1 开始） | 0 | 1 | 1 | 2 | 2 | 3 |

含义：在模式串第 j 个字符失配时，下一步用模式串的第 next[j] 个字符去和主串**当前字符**比较（next = 0 表示主串指针后移一位、模式串从头开始）。

> 📌 **快速求 next（下标从 1 开始）**：next[1]=0，next[2]=1；之后 next[j] = “前 j−1 个字符的最长相等前后缀长度” + 1。

**KMP 时间复杂度 O(m + n)**，主串指针**不回溯**。

#### nextval（改进）
如果 T[j] == T[next[j]]，那么用 T[next[j]] 去比也注定失败，干脆继续往前跳：
`nextval[j] = nextval[next[j]]`（当 T[j] == T[next[j]] 时），否则 `nextval[j] = next[j]`。

> 🎯 408 对 KMP 的考法：求 next/nextval 数组、问匹配过程中比较了几次、问失配后下一次比较哪两个字符。**会手算 PM 表就能拿下 90%**。

## 1.6 本篇小结（考前 5 分钟看这里）

| 知识点 | 一句话记住 |
|---|---|
| 顺序表 | 随机存取 O(1)，插删 O(n) |
| 链表插入 | 先连后断：`s->next=p->next; p->next=s;` |
| 链表特殊情况 | 删最后一个元素时要改尾指针 |
| 栈 | 后进先出；出栈序列题跟着模拟 |
| 卡特兰数 | $\frac{1}{n+1}C_{2n}^n$，n=3→5，n=4→14 |
| 中缀转后缀 | 加括号 → 运算符挪到右括号后 → 去括号 |
| 循环队列 | 空：f==r；满：(r+1)%M==f；个数：(r−f+M)%M |
| 双端队列 | 倒推队内状态，检查能否摆出 |
| 数组地址 | “前面有几个元素” × 元素大小 |
| 压缩矩阵 | 同样“数前面有几个”，注意 4 个坑 |
| KMP | 求 PM → next；主串不回溯；O(m+n) |
