# 第一部分：计算机系统概述

## 4.1 冯·诺依曼计算机

### 🧒 大白话
想象一个**厨房**：
- **存储器** = 冰箱和菜谱本：放食材（数据）和菜谱（程序/指令）
- **运算器** = 砧板和刀：真正切菜、炒菜的地方（做加减乘除）
- **控制器** = 厨师长：看菜谱，指挥“先拿什么、再切什么”
- **输入设备** = 送菜的门（键盘、鼠标）
- **输出设备** = 上菜的窗口（显示器、打印机）

冯·诺依曼最伟大的想法：**“存储程序”**——把菜谱（程序）和食材（数据）**一起放在冰箱（存储器）里**，厨师长按顺序一条条读菜谱执行。

### 📖 冯·诺依曼机的特点（选择题）
1. 由**运算器、控制器、存储器、输入设备、输出设备** 5 大部件组成
2. **指令和数据以同等地位存在存储器中**，形式上没有区别（都是二进制），但计算机能区分（**取指阶段取出的是指令，执行阶段取出的是数据**）
3. 指令由**操作码**（做什么）和**地址码**（对谁做）组成
4. 早期以**运算器**为中心，现代计算机以**存储器**为中心
5. **存储程序**：程序执行前要先放进主存，然后按地址顺序执行

**CPU = 运算器 + 控制器**；**主机 = CPU + 主存**。

### 📖 各部件里的寄存器（⭐ 必须认识）
🧒 寄存器就是 CPU 内部的**小抽屉**，速度最快，但数量很少。

| 寄存器 | 全称 | 干什么的 | 大白话 |
|---|---|---|---|
| PC | 程序计数器 | 存**下一条指令的地址** | 厨师长的书签：下一步看菜谱第几行 |
| IR | 指令寄存器 | 存**当前正在执行的指令** | 当前正在读的那行菜谱 |
| MAR | 存储器地址寄存器 | 存要访问的**主存地址** | 要去冰箱第几格拿东西 |
| MDR | 存储器数据寄存器 | 存从主存读出/要写入的**数据** | 从冰箱拿出来的那样东西 |
| ACC | 累加器 | 存运算结果 | 砧板 |
| GPR | 通用寄存器 | 程序员可用的暂存 | 手边的几个小碗 |
| PSW/FR | 程序状态字/标志寄存器 | 存 ZF、SF、OF、CF 等标志 | 记录“刚才的结果是不是 0、是不是负数、有没有溢出” |

> 📌 **位数规律**：MAR 位数 = 地址线位数（决定能访问多大内存）；MDR 位数 = 存储字长（一次读写多少位）。
> 例：MAR 32 位 → 可访问 2³² 个单元。

**真题（2020 年第 12 题）**：哪些部件的位数一定等于机器字长？ALU、指令寄存器、通用寄存器、浮点寄存器
→ **ALU 和通用寄存器**（机器字长就是 CPU 一次能处理的整数位数，由 ALU 和通用寄存器决定）。指令长度可变；浮点寄存器常是 64/80 位。选 B。

**真题（2021 年第 17 题）**：汇编程序员可见的寄存器？
🧒 “可见”就是“能在汇编指令里用到”：**PC（跳转指令能改它）、通用寄存器、基址寄存器、标志寄存器（条件跳转要看它）**是可见的；**IR、MAR、MDR、微指令寄存器**是 CPU 内部自己用的，程序员看不见。

## 4.2 程序是怎么变成能运行的东西的

```
hello.c ──预处理──→ hello.i ──编译──→ hello.s ──汇编──→ hello.o ──链接──→ hello（可执行文件）
 (源程序)  处理#include   (汇编语言)  翻成机器指令  (目标文件)   合并库函数
```
**真题（2022 年第 20 题）**：主要过程是 **预处理 → 编译 → 汇编 → 链接**，选 A。

- **编译程序**：把高级语言**整个翻译**成机器语言（像翻译一整本书）
- **解释程序**：翻译一句**执行一句**，不生成目标程序（像同声传译）
- **汇编程序**：把汇编语言翻译成机器语言

### 📖 ISA（指令集体系结构）是什么
🧒 ISA 是**软件和硬件之间的“合同”**：规定了“机器能听懂哪些指令、指令长什么样、有哪些寄存器程序员能用、怎么寻址”。
而**具体怎么用电路实现**（用什么加法器、用微程序还是硬布线、单总线还是多总线），叫**微架构（微体系结构）**，不属于 ISA。

**真题（2022 年第 18 题）**：属于 ISA 的是 **I. 指令格式和类型、III. 通用寄存器个数和位数**；时钟周期、加法器进位方式属于具体实现。选 B。
**真题（2025 年第 16 题）**：由 ISA 规定的是 **B. 是否采用定长指令字格式**。（阵列乘法器、微程序控制器、单总线数据通路都是实现层面的。）

## 4.3 性能指标（⭐⭐ 必考计算）

| 指标 | 含义 |
|---|---|
| **机器字长** | CPU 一次能处理的二进制位数（= 通用寄存器位数） |
| **时钟周期** | CPU 最小的时间单位（“心跳一次”） |
| **主频** | 时钟频率 = 1/时钟周期。1 GHz → 时钟周期 1 ns |
| **CPI** | 执行一条指令平均需要几个时钟周期 |
| **IPC** | 每个时钟周期执行几条指令 = 1/CPI |
| **MIPS** | 每秒执行多少**百万**条指令 = 主频 / (CPI × 10⁶) |
| **FLOPS** | 每秒浮点运算次数（MFLOPS=10⁶，GFLOPS=10⁹，TFLOPS=10¹²，PFLOPS=10¹⁵） |

**核心公式（背熟！）：**
```
CPU 执行时间 = 指令条数 × CPI × 时钟周期 = 指令条数 × CPI / 主频
```

**真题（2022 年第 12 题）**：主频 1 GHz，程序执行 10000 条指令，80% 的指令 CPI = 1，20% 的 CPI = 10。平均 CPI 和执行时间？
- 平均 CPI = 0.8 × 1 + 0.2 × 10 = **2.8**
- 时间 = 10000 × 2.8 / 10⁹ = 2.8 × 10⁻⁵ s = **28 μs**，选 A

**真题（2021 年第 12 题）**：93.0146 PFLOPS 约等于每秒多少次浮点运算？
- P = 10¹⁵，93 × 10¹⁵ = 9.3 × 10¹⁶；1 亿 = 10⁸，1 亿亿 = 10¹⁶ → **9.3 亿亿次**，选 D

> ⚠️ **时间单位换算**：1 s = 10³ ms = 10⁶ μs = 10⁹ ns。频率里 1 GHz = 10⁹ Hz（**不是 2³⁰**）。

# 第二部分：数据的表示

## 4.4 字符与校验码

### 📖 ASCII 码（记三个就够）
| 字符 | 十进制 | 十六进制 |
|---|---|---|
| '0' | 48 | 30H |
| 'A' | 65 | 41H |
| 'a' | 97 | 61H |
其他按顺序往后推：'1' = 31H，'B' = 42H，'b' = 62H。大写和小写差 32（20H）。

### 📖 奇偶校验
🧒 在数据后面加 1 位，让“1 的个数”凑成奇数（奇校验）或偶数（偶校验）。
- 只能**发现奇数个位出错**，不能发现偶数个位出错，**不能纠错**。

### 📖 码距与检错纠错能力（⭐）
**码距**：两个编码之间**有几位不同**。一个编码集合的码距 = 任意两个合法编码之间码距的**最小值**。
- 码距 d 可以**检出 d−1 位**错误
- 码距 d 可以**纠正 ⌊(d−1)/2⌋ 位**错误

🧒 为什么？码距为 4，意味着从一个合法编码变成另一个合法编码至少要错 4 位。错 1~3 位时，结果不是任何合法编码，所以能发现；错 1 位时，离原来的编码最近（距离 1，离别的至少 3），所以能猜回去（纠错）。

**真题（2025 年第 34 题）**：编码集 {1001 1010, 0101 1100, 1111 0000, 0000 1111}，检错纠错能力？
- 两两异或数 1 的个数：第 1、2 个 → 11000110 → 4 位不同；第 1、3 个 → 4；第 1、4 个 → 4；第 2、3 个 → 4；第 2、4 个 → 4；第 3、4 个 → 8
- 码距 = 4 → 检 3 位、纠 1 位，选 **C**

### 📖 海明码（汉明码）
- 设数据 n 位，校验位 k 位，要满足 **2ᵏ ≥ n + k + 1**
  （例：8 位数据 → k = 4，因为 2⁴ = 16 ≥ 8 + 4 + 1 = 13）
- 校验位放在第 1, 2, 4, 8, … 位（2 的幂次位置）
- 第 i 个校验位负责检查“位置编号的二进制第 i 位为 1”的所有位
- 能**纠正 1 位错**（码距 3）；加一个总校验位可“纠 1 检 2”
- 接收方算出的校验结果（指误字）组成的二进制数就是**出错的位置**

### 📖 CRC 循环冗余校验（计网也会考）
🧒 发送方和接收方约定一个“除数”（生成多项式 G(x)，r+1 位）。
1. 数据后面补 **r 个 0**
2. 用**模 2 除法**（异或，不借位）除以 G，得到 r 位余数
3. 把余数接在数据后面发送
4. 接收方用收到的整串除以 G，**余数为 0 就认为没错**

✏️ 例：数据 101001，G(x) = x³ + x² + 1 → 除数 1101（r = 3）
被除数 = 101001 后面补 3 个 0 = **101001000**，一步一步做模 2 除法（首位是 1 就异或 1101，首位是 0 就只“落下一位”）：
```
1010 ⊕ 1101 = 0111 → 留下 111，落下一位 0 → 1110
1110 ⊕ 1101 = 0011 → 留下 011，落下一位 1 → 0111（首位 0，本位商 0）→ 留下 111，落下 0 → 1110
1110 ⊕ 1101 = 0011 → 留下 011，落下 0 → 0110（首位 0）→ 留下 110，落下 0 → 1100
1100 ⊕ 1101 = 0001 → 位全部用完，余数 = 001
```
发送 101001**001**。（生成多项式选得好时）CRC 能检测所有长度 ≤ r 的突发错误和绝大多数其他错误。在计算机网络的数据链路层**只检错不纠错**。

## 4.5 定点数的表示：原码、反码、补码、移码（⭐⭐⭐ 基础中的基础）

### 🧒 为什么需要这么多“码”？
计算机只有 0 和 1，**没有“负号”**。怎么表示 −5？于是人们想了好几种办法。

### 📖 原码
**最高位当符号位**（0 正 1 负），剩下的是绝对值。
- +5 = 0000 0101，−5 = 1000 0101
- 缺点：**0 有两种表示**（+0 = 0000 0000，−0 = 1000 0000）；加减法要先判断符号，电路复杂

### 📖 补码（⭐ 计算机真正用的）
🧒 **钟表的启发**：钟表上，从 3 点往回拨 2 格和往前拨 10 格，结果一样都是 1 点。
所以在 12 进制的钟表上，“−2” 和 “+10” 是等价的！10 就是 −2 的“补码”（模 12）。

同理，8 位二进制的“钟表”有 256 格（模 2⁸ = 256）。**−5 的补码 = 256 − 5 = 251 = 1111 1011**。
这样**减法就能变成加法**，电路只要一个加法器！

**求补码的快速方法：**
- 正数：补码 = 原码
- 负数：原码符号位不变，**数值位取反，再加 1**
- **更快的手算技巧**：从右往左，**第一个 1 及其右边不变，左边全部取反**（符号位也是 1）

✏️ **例**：−20 的 8 位补码
- 20 = 0001 0100
- 从右往左，第一个 1 在倒数第 3 位：`100` 不变，左边 `00010` 取反成 `11101`
- 结果：**1110 1100**（= ECH）

**补码 → 真值**：最高位权值是**负的**。
例：1110 1100 = −128 + 64 + 32 + 8 + 4 = −20 ✓
（或者：再求一次补码得到绝对值：1110 1100 → 0001 0100 = 20，所以是 −20）

**[−x]补 的求法**：把 [x]补 **连同符号位一起**取反加 1。

### 📖 反码（过渡用，了解）
负数：原码符号位不变，数值位取反。0 也有两种表示。

### 📖 移码
**移码 = 补码的符号位取反**（在偏置值为 2ⁿ 时）。
🧒 移码的好处：**大的数移码也大**，比较大小直接当无符号数比就行。所以浮点数的**阶码**用移码。
- −5：补码 1111 1011 → 移码 0111 1011
- +5：补码 0000 0101 → 移码 1000 0101

### 📊 表示范围（n+1 位，1 位符号，n 位数值；⭐⭐ 必背）

| 码制 | 整数范围 | 8 位时 | 0 的表示 |
|---|---|---|---|
| 无符号数（全部 n+1 位是数值） | 0 ~ 2ⁿ⁺¹ − 1 | 0 ~ 255 | 唯一 |
| 原码 | −(2ⁿ − 1) ~ 2ⁿ − 1 | −127 ~ 127 | 两个 |
| 反码 | −(2ⁿ − 1) ~ 2ⁿ − 1 | −127 ~ 127 | 两个 |
| **补码** | **−2ⁿ ~ 2ⁿ − 1** | **−128 ~ 127** | **唯一** |
| 移码 | −2ⁿ ~ 2ⁿ − 1 | −128 ~ 127 | 唯一 |

补码比原码多表示一个数：**−2ⁿ**（8 位时是 1000 0000 = −128）。
**真题（2022 年第 13 题）**：32 位补码能表示的整数范围是 **−2³¹ ~ 2³¹ − 1**，选 B。

> 📌 几个特殊的补码（8 位）：0111 1111 = 127（最大）；1000 0000 = −128（最小）；1111 1111 = **−1**。
> 16 位时：7FFFH = 32767，8000H = −32768，FFFFH = −1。

### ✏️ 真题（2021 年第 13 题）：同一串位，有符号和无符号含义不同
x, y, z 的机器数分别是 FFFDH、FFDFH、7FFCH（16 位）。
- **当无符号数**：7FFC < FFDF < FFFD → z < y < x
- **当补码**：FFFDH = −3，FFDFH = −33，7FFCH = 32764 → y < x < z
- 选 D（带符号时 y < x < z）

### 📖 扩展：短变长
- **零扩展**（无符号数）：高位补 0
- **符号扩展**（补码）：高位补**符号位**
  - 例：8 位 −3 = FDH → 16 位 FFFDH；8 位 5 = 05H → 0005H

### 📖 C 语言里的类型转换（⭐ 近年高频）
**核心原则：机器数（那串 0/1）不变，只是“换一种眼光看它”。**
- 同长度 有符号 ↔ 无符号：**位不变**，解释变了
- 短 → 长：有符号数做**符号扩展**，无符号数做**零扩展**
- 长 → 短：直接**截掉高位**

**真题（2025 年第 12 题）**：`short si = −32767; unsigned int ui = si;` ui 的值？
1. −32767 的 16 位补码：32767 = 7FFFH → 取反加 1 → **8001H**
2. short → int（有符号数变长）：符号扩展 → **FFFF 8001H**
3. 当无符号数看：FFFF 8001H = 2³² − 32767 = **2³² − 2¹⁵ + 1**，选 D

## 4.6 定点数的运算

### 📖 移位
| 类型 | 左移 | 右移 |
|---|---|---|
| **逻辑移位**（无符号数） | 低位补 0 | **高位补 0** |
| **算术移位**（补码） | 低位补 0 | **高位补符号位** |

- 左移一位 ≈ ×2，右移一位 ≈ ÷2
- 算术左移时如果符号位变了，说明溢出

### 📖 补码加减法
- [A + B]补 = [A]补 + [B]补
- [A − B]补 = [A]补 + [−B]补
- 电路：一个加法器 + 一个“取反”控制。减法时 B 各位取反，最低位进位 Cin = 1（相当于取反加 1）

### 📖 溢出判断（⭐⭐）
**溢出**：结果超出了表示范围。**只有“同号相加”或“异号相减”才可能溢出**。

三种判断方法：
1. **符号法**：两个正数相加得负数，或两个负数相加得正数 → 溢出
2. **双符号位法**（变形补码）：结果符号位是 01 → 正溢出；10 → 负溢出；00 或 11 → 正常
3. **进位法**：**最高位（符号位）的进位 ⊕ 次高位的进位 = 1** → 溢出

### 📖 标志位（⭐⭐ 大题常考）
| 标志 | 含义 | 怎么得到 | 对谁有意义 |
|---|---|---|---|
| **ZF** | 结果为 0 | 结果全 0 时 ZF = 1 | 都有 |
| **SF** | 结果为负 | = 结果的最高位 | 有符号数 |
| **OF** | 溢出 | 同上面的溢出判断 | **有符号数** |
| **CF** | 进位/借位 | 加法：CF = 最高位进位；减法：CF = 最高位进位取反（即有借位时为 1） | **无符号数** |

**真题（2022 年第 43 题第 1 问）**：ALU 输入 A、B，输出 F，最高位 A₁₅、B₁₅、F₁₅。写出 SF 和 OF 表达式。
- SF = F₁₅
- A 加 B 时：OF = A₁₅·B₁₅·F̄₁₅ + Ā₁₅·B̄₁₅·F₁₅（两个负数加出正数，或两个正数加出负数）
- A 减 B 时：OF = A₁₅·B̄₁₅·F̄₁₅ + Ā₁₅·B₁₅·F₁₅（负 − 正 = 正，或 正 − 负 = 负）

**真题（2025 年第 14 题）**：8 位机，[x]补 = A3H，[y]补 = 75H，用补码加减运算器算 x − y，结果和 OF？
1. x = A3H = 1010 0011 = −93；y = 75H = 117；x − y = −210，超出 −128 ~ 127 → **溢出**
2. 机器怎么算：[−y]补 = 8BH，A3H + 8BH = 12EH，只保留 8 位 → **2EH = 46**
3. 检查：负数 − 正数 = 正数 → OF = 1。选 **D（46, 1）**

### 📖 乘法和除法
🧒 **乘法就是“移位 + 加法”**：就像我们手算竖式乘法，看乘数的每一位，是 1 就把被乘数（移过位的）加上去。

**真题（2020 年第 43 题）要点：**
1. 没有乘法指令也能算乘法 → 因为**乘法可以用加法和移位来实现**（用软件循环）
2. 用 ALU + 移位器 + 寄存器实现乘法指令时，**控制逻辑**的作用：控制循环次数（计数器）、根据乘数当前位决定是否做加法、控制部分积和乘数的移位
3. 执行时间：**没有乘法指令（软件实现）最长**；**阵列乘法器（纯硬件并行）最短**；ALU + 移位器的硬件循环居中
4. n 位 × n 位得 2n 位乘积，只取低 n 位时可能溢出：
   - x = 2³¹ − 1，y = 2 → 乘积 = 2³² − 2 = **0000 0000 FFFF FFFEH**（有符号、无符号乘法结果都一样）
   - umul 返回低 32 位 FFFF FFFEH = 2³² − 2，**高 32 位全 0 → 不溢出**
   - imul 返回 FFFF FFFEH 当补码是 **−2**，显然不对 → **溢出**
   - **判断规则**：无符号乘法：**高 n 位全为 0** 才不溢出；有符号乘法：**高 n 位的每一位都等于低 n 位的最高位**（符号扩展的样子）才不溢出

**除法**：用“减法 + 移位”实现（恢复余数法、不恢复余数法/加减交替法）。
**除法异常**（2025 年第 44 题）：
- **除数为 0**
- **有符号数 −2ⁿ⁻¹ ÷ (−1)**：结果 2ⁿ⁻¹ 超出范围（例如 32 位 −2³¹ ÷ −1 = 2³¹ 放不下）

### 📖 加法器（了解）
- **全加器**：输入 Aᵢ、Bᵢ、进位 Cᵢ，输出本位和 Sᵢ = Aᵢ⊕Bᵢ⊕Cᵢ，进位 Cᵢ₊₁ = AᵢBᵢ + (Aᵢ⊕Bᵢ)Cᵢ
- **串行进位**：一位一位往上传进位，慢
- **先行进位（并行进位）**：提前算出所有进位，快

## 4.7 浮点数（⭐⭐⭐ IEEE 754 年年考）

### 🧒 大白话：科学计数法
我们写很大或很小的数用科学计数法：123000 = 1.23 × 10⁵。
浮点数就是**二进制的科学计数法**：N = **尾数 M × 2^阶码 E**
- 阶码决定“能表示多大/多小”（范围）
- 尾数决定“能表示多准”（精度）

### 📖 IEEE 754 单精度（float，32 位）

```
┌────┬──────────┬─────────────────────────┐
│ S  │  阶码 E   │       尾数 M（23位）     │
│1位 │  8 位     │                         │
└────┴──────────┴─────────────────────────┘
真值 = (−1)^S × 1.M × 2^(E − 127)
```
- **S**：符号，0 正 1 负
- **E**：阶码，用**移码**存，偏置值 **127**（真正的指数 = E − 127）
- **M**：尾数，规格化后形如 1.xxxx，**那个“1.”省略不存**（隐藏位），只存小数点后面的 23 位

**双精度（double，64 位）**：1 位 S，**11** 位 E（偏置 **1023**），**52** 位 M。

### 📖 十进制 → IEEE 754（⭐ 必会四步）

**真题（2022 年第 14 题）**：−0.4375 的单精度表示？
1. **转二进制**：0.4375 = 0.0111₂（0.4375×2=0.875→0，×2=1.75→1，0.75×2=1.5→1，0.5×2=1→1）
2. **规格化**：0.0111 = **1.11 × 2⁻²**
3. **求各字段**：S = 1；E = −2 + 127 = 125 = **0111 1101**；M = **1100…0**（小数点后面的 11，后面补 0）
4. **拼起来**，4 位一组转十六进制：
   ```
   1 01111101 11000000000000000000000
   1011 1110 1110 0000 0000 0000 0000 0000
    B    E    E    0    0    0    0    0
   ```
   结果 **BEE0 0000H**，选 A

### 📖 IEEE 754 → 十进制（反过来）

**真题（2025 年第 13 题）**：float x 的机器数为 4730 0000H，x = ?
1. 展开：0100 0111 0011 0000 …
2. 切分：S = 0 | E = 1000 1110 = 142 | M = 011 0000…
3. 指数 = 142 − 127 = 15；尾数 = 1.011₂ = 1 + 0.25 + 0.125 = 1.375
4. x = **1.375 × 2¹⁵**，选 D

**真题（2020 年第 13 题）**：x 可能是 int（补码）或 float，机器数 C800 0000H，x 可能是？
- 当 int：1100 1000 0…0 是负数，= −(2³² − C800 0000H) = −3800 0000H = **−7 × 2²⁷**
- 当 float：S = 1，E = 1001 0000 = 144 → 指数 17，M = 0 → −1.0 × 2¹⁷ = **−2¹⁷**
- 选项里只有 A（−7 × 2²⁷）符合

### 📖 特殊值（E 全 0 或全 1）
| E | M | 表示 |
|---|---|---|
| 全 0 | 全 0 | **±0** |
| 全 0 | 非 0 | 非规格化数：(−1)^S × **0.M** × 2⁻¹²⁶（隐藏位是 0） |
| 全 1 | 全 0 | **±∞** |
| 全 1 | 非 0 | **NaN**（不是一个数，比如 0/0） |
| 1 ~ 254 | 任意 | 规格化数 |

**范围**：
- 最大正数：E = 254，M 全 1 → (2 − 2⁻²³) × 2¹²⁷
- 最小规格化正数：E = 1，M 全 0 → 1.0 × 2⁻¹²⁶

### 📖 能不能精确表示？
能写成“有限位二进制小数”且尾数不超过 23 位的才能精确表示。
**真题（2021 年第 14 题）**：1.2、1.25、2.0、2.5 中不能精确表示的是 **1.2**（0.2 转二进制无限循环）。

### 📖 浮点加减运算（五步）
1. **对阶**：**小阶向大阶看齐**（小的那个尾数右移，阶码加），因为右移丢掉的是低位，误差小
2. **尾数加减**
3. **规格化**：结果不是 1.xxx 的形式就调整（左规/右规）
4. **舍入**：多出的位要舍掉（就近舍入、截断等）
5. **溢出判断**：**阶码**上溢 → 溢出；阶码下溢 → 当 0 处理

### 📖 C 语言中的浮点类型转换
| 转换 | 结果 |
|---|---|
| int → float | **可能丢失精度**（int 有 31 位有效数字，float 尾数只有 24 位） |
| int → double | 精确 |
| float → double | 精确 |
| double → float | 可能溢出、可能丢精度 |
| float/double → int | 小数部分**截断**（向 0 取整），可能溢出 |

## 4.8 数据的存储和排列（⭐⭐ 近年必考）

### 📖 大端和小端
一个 int 有 4 个字节，放进内存时谁放在低地址？
- **大端（Big Endian）**：**高位字节放在低地址**（跟我们读数字的顺序一样，“大头在前”）
- **小端（Little Endian）**：**低位字节放在低地址**（x86 是小端）

例：int x = 0x12345678，存在地址 0x100 开始：
```
地址：     0x100  0x101  0x102  0x103
大端：      12     34     56     78
小端：      78     56     34     12
```
🧒 记忆：**小端 = “小的（低位）在前（低地址）”**。

### 📖 边界对齐
🧒 CPU 读内存喜欢“整块整块”地读。如果一个 4 字节的 int 跨越了两个“块”，就要读两次，慢。
所以编译器规定：**一个 n 字节的数据，起始地址必须是 n 的整数倍**（short 放在 2 的倍数，int 放在 4 的倍数，double 放在 8 的倍数）。不够就**填充**空字节。
结构体总大小要是**最大成员大小的整数倍**。

**真题（2020 年第 14 题）**：小端、按边界对齐，`struct record { short x1; int x2; } a;` 首地址 2020 FE00H，x2 的机器数为 1234 0000H，34H 在哪个地址？
```
偏移:  0  1  │ 2  3  │ 4    5    6    7
内容:  x1    │ 填充  │ x2 (int 必须从 4 的倍数开始)
```
- x2 从 2020 FE04H 开始
- 小端：FE04 = 00，FE05 = 00，FE06 = **34**，FE07 = 12
- 答案 **2020 FE06H**，选 D

**真题（2025 年第 15 题）**：`struct record { int id; char name[10]; int salary; } employee[200];` 起始地址 0000 A0B0H，小端对齐，employee[1].id = 1234 5678H，56H 的地址？
1. 结构体大小：id 占 0~3；name 占 4~13；salary 必须从 4 的倍数开始 → 16~19。总共 **20 字节**（是 4 的倍数 ✓）
2. employee[1] 起始 = A0B0H + 20 = A0B0H + 14H = **A0C4H**
3. id = 12345678H 小端存放：A0C4 = 78，A0C5 = **56**，A0C6 = 34，A0C7 = 12
4. 答案 **0000 A0C5H**，选 C

## 4.10 课后练习

1. 求 −100 的 8 位补码和移码。
2. 8 位补码 1000 0001 的真值？
3. 把 12.5 表示成 IEEE 754 单精度（十六进制）。
4. `char c = −1; unsigned short us = c;` us 的值是多少？
5. 某程序在 2 GHz 的 CPU 上执行 5 × 10⁸ 条指令，CPI 为 2，执行时间？MIPS？

<details>
<summary>答案</summary>

1. 100 = 0110 0100 → 补码 1001 1100（9CH）；移码 0001 1100（1CH）
2. −128 + 1 = −127
3. 12.5 = 1100.1₂ = 1.1001 × 2³；S=0，E=130=1000 0010，M=1001 0…；`0 10000010 1001000…` → 0100 0001 0100 1000 0… = **4148 0000H**
4. char −1 = FFH，符号扩展成 FFFFH，当无符号数 = 65535
5. 时间 = 5×10⁸ × 2 / (2×10⁹) = 0.5 s；MIPS = 2×10⁹ / (2 × 10⁶) = 1000
</details>
