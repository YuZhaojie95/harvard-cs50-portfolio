# 第一部分：计算机网络体系结构

## 11.1 计算机网络是什么

### 🧒 大白话
计算机网络就是**把很多台电脑连起来，让它们能互相“说话”、共享东西**。
比如你用微信发消息给朋友：你的手机 → 家里的路由器 → 运营商的网络 → …… → 朋友的手机。

### 📖 组成
- **边缘部分**：用户直接使用的主机（手机、电脑、服务器）
- **核心部分**：大量网络和连接它们的**路由器**，为边缘部分提供连通和交换服务

### 📖 按范围分
广域网 WAN（城市之间、国家之间）> 城域网 MAN > **局域网 LAN**（一栋楼、一个学校）> 个人区域网 PAN（蓝牙）

## 11.2 三种交换方式（⭐ 2025 年考过计算）

### 🧒 大白话
- **电路交换** = **打电话**：通话前先“拨号”**建立一条专用线路**，通话期间这条线路**只属于你们俩**，挂断后才释放
- **报文交换** = **寄一整个大包裹**：整个包裹在每个中转站都要**全部收下**，再转发给下一站（存储转发）
- **分组交换** = **把大包裹拆成很多小箱子**寄：每个小箱子独立转发，中转站收到一个小箱子就可以转发，**多个小箱子可以同时在路上**（流水线！）

| | 电路交换 | 报文交换 | 分组交换 |
|---|---|---|---|
| 建立连接 | 需要 | 不需要 | 不需要 |
| 独占线路 | 是 | 否 | 否 |
| 存储转发 | 否 | 是（整个报文） | 是（分组） |
| 适合 | 大量连续数据（电话） | — | **突发数据（计算机网络）** |

### 📖 时延计算（⭐）
**发送时延（传输时延）** = 数据长度 / 发送速率（把数据“推”到线路上的时间）
**传播时延** = 信道长度 / 电磁波传播速率（信号在线路上“跑”的时间）

**例**：主机 A 经过 1 个路由器发 1000 KB 的文件给主机 B，每段链路 10 Mbps，忽略传播时延。
- **报文交换**：每段都要发送整个文件：8000 kb / 10 Mbps = 0.8 s，两段 = **1.6 s**
- **分组交换**：分成 1000 个 1 KB 分组，每个分组发送时延 0.8 ms
  - 第一个分组到达 B：2 × 0.8 ms
  - 之后每 0.8 ms 到达一个 → 总时间 = (1000 + 1) × 0.8 ms ≈ **0.8008 s**（接近一半！）
- 通用公式：**n 个分组经过 k 段链路（k − 1 个路由器）：时间 = (n + k − 1) × 一个分组的发送时延**（和流水线公式一模一样！）

**真题（2025 年第 33 题）**：H1 → R1 → R2 → H2，三段链路速率分别 10 Mbps、100 Mbps、1000 Mbps，发 2 MB 文件（1M = 10⁶）。电路交换建立时间 32 μs、速率 10 Mbps；分组交换分组长 400 B（忽略首部）；报文交换。比较三者时间。
- 电路交换：32 μs + 16 Mb / 10 Mbps = 32 μs + 1.6 s ≈ **1.600032 s**
- 报文交换：16 Mb 在三段上依次发送：1.6 + 0.16 + 0.016 = **1.776 s**
- 分组交换：瓶颈是第一段 10 Mbps。每个分组 3200 b：第一段发送 320 μs，第二段 32 μs，第三段 3.2 μs。最后一个分组离开 H1 的时刻 = 1.6 s，再经过后两段 35.2 μs → 约 **1.6000352 s**
- 所以 **T报文 > T分组 > T电路**，选 **B**

## 11.3 性能指标（⭐）

| 指标 | 含义 | 注意 |
|---|---|---|
| **速率** | 每秒传送多少比特 | 单位 bps，k = 10³，M = 10⁶ |
| **带宽** | 通信线路能传送数据的能力（最高速率） | |
| **吞吐量** | 单位时间实际通过的数据量 | 受最慢的链路限制 |
| **时延** | 发送时延 + 传播时延 + 处理时延 + 排队时延 | |
| **时延带宽积** | 传播时延 × 带宽 | 🧒 “管道里能装多少比特” |
| **往返时延 RTT** | 从发送到收到确认的时间 | |
| **信道利用率** | 有数据通过的时间 / 总时间 | |

> ⚠️ 提高带宽只能减少**发送时延**，不能减少传播时延（信号跑的速度是物理决定的）。

## 11.4 分层结构（⭐⭐）

### 🧒 为什么要分层？
寄快递：你只管打包写地址，**快递员**负责收件，**分拣中心**负责路线，**货车司机**负责开车。每层只管自己的事，只和上下层打交道。

### 📖 几个概念
- **协议**：**同一层**的双方通信时遵守的规则（水平的）
  - 协议三要素：**语法**（数据格式）、**语义**（每部分的含义、要做什么动作）、**同步/时序**（事件发生的顺序）
- **服务**：下层为**上层**提供的功能（垂直的）
- **接口（服务访问点 SAP）**：上下层之间交换信息的地方
- **PDU（协议数据单元）**：同层之间传送的数据单位 = SDU（上层交下来的数据）+ PCI（本层加的首部）

**真题（2020 年第 33 题）**：图中描述了“发起连接请求 → 确认 → 数据传送”的**事件顺序**，描述的是协议要素中的 **时序**（选 C）。

### 📖 OSI 七层 vs TCP/IP 四层 vs 教学五层
| OSI 七层 | 五层（408 用这个学） | TCP/IP 四层 | 数据单位 | 典型设备/协议 |
|---|---|---|---|---|
| 应用层 | **应用层** | 应用层 | 报文 | HTTP、DNS、SMTP、FTP |
| 表示层 | ↑ | ↑ | | |
| 会话层 | ↑ | ↑ | | |
| 传输层 | **传输层** | 传输层 | 报文段（TCP）/ 用户数据报（UDP） | TCP、UDP |
| 网络层 | **网络层** | 网际层 | **分组 / IP 数据报** | IP、ICMP、ARP、**路由器** |
| 数据链路层 | **数据链路层** | 网络接口层 | **帧** | 以太网、PPP、**交换机** |
| 物理层 | **物理层** | ↓ | **比特** | **集线器、中继器** |

🧒 **口诀**：“**物联网输会示用**”（物理、链路、网络、传输、会话、表示、应用）

**各层最核心的功能（选择题）**：
- **物理层**：透明地传送比特流
- **数据链路层**：**相邻结点**之间传帧（**结点到结点**），差错控制、流量控制
- **网络层**：**主机到主机**，**路由选择**、分组转发
- **传输层**：**进程到进程（端到端）**，可靠传输、流量控制、拥塞控制
- **应用层**：为应用程序提供服务

**真题（2021 年第 33 题）**：TCP/IP 模型中，**传输层相邻的下一层**（网络层/网际层）实现的主要功能是 **B. 路由选择**。
**真题（2022 年第 33 题）**：OSI 模型中，实现**两个相邻结点间流量控制**的是 **B. 数据链路层**。（传输层是端到端的流量控制。）

# 第二部分：物理层

## 11.5 基本概念

### 📖 几个术语
- **码元**：一个固定时长的信号波形，代表一定数量的比特。有 K 种状态的码元，每个码元携带 **log₂K** 比特
- **波特率（码元速率）**：每秒传多少个码元（单位 Baud）
- **比特率（数据率）** = 波特率 × log₂K
- **单工**（只能单向，广播）、**半双工**（双向但不能同时，对讲机）、**全双工**（双向同时，电话）

### 📖 两个极限公式（⭐⭐⭐ 必背）

**① 奈奎斯特定理（无噪声）**：
```
最大数据率 = 2W × log₂V   (b/s)
```
W：带宽（Hz），V：码元的离散状态数
🧒 理想信道每秒最多传 **2W 个码元**，每个码元带 log₂V 位。

**② 香农定理（有噪声）**：
```
最大数据率 = W × log₂(1 + S/N)   (b/s)
```
S/N：信噪比（功率比）。常用**分贝**表示：**信噪比(dB) = 10 log₁₀(S/N)**
- 30 dB → S/N = 1000；20 dB → 100；10 dB → 10

**真题（2022 年第 34 题）**：带宽 200 kHz 的**无噪声**信道，**4 个幅值**的 ASK 调制，最大数据率？
→ 2 × 200k × log₂4 = **800 kbps**，选 C

> 🎯 若题目**同时**给了调制状态数和信噪比，两个公式都算，**取较小值**。

## 11.6 编码与调制

### 📖 数字数据 → 数字信号（编码，⭐）
| 编码 | 规则 |
|---|---|
| 不归零 NRZ | 高电平 1，低电平 0 |
| 归零 RZ | 每个码元中间都回到 0 |
| **曼彻斯特编码** | 每个码元**中间都有跳变**；中间跳变**既表示时钟又表示数据**（常见约定：**由高到低表示 1**，由低到高表示 0，或反之，**题目会说明**）。**以太网**使用 |
| **差分曼彻斯特** | 每个码元中间都有跳变（只作时钟）；**码元开始处有跳变表示 0，没有跳变表示 1** |

🧒 曼彻斯特编码**自带时钟**（每位中间都跳），所以收发双方容易同步；代价是**信号频率是数据率的 2 倍**（10 Mbps 以太网要 20 M 波特）。

**真题（2021 年第 34 题）**：给出一段差分曼彻斯特编码波形，求比特串 → 看**每个码元开始处**：有跳变是 0，没跳变是 1。

### 📖 数字数据 → 模拟信号（调制）
- **调幅 ASK**：用不同**振幅**表示 0 和 1
- **调频 FSK**：用不同**频率**
- **调相 PSK**：用不同**相位**
- **QAM**：幅度 + 相位结合，一个码元状态更多

### 📖 模拟数据 → 数字信号：PCM
采样 → 量化 → 编码。**采样定理**：采样频率 ≥ 信号最高频率的 **2 倍**。

## 11.7 传输介质和物理层设备
- **双绞线**（最常用，100BASE-T 中的 T）、**同轴电缆**、**光纤**（多模、单模；带宽大、抗干扰）、无线
- **中继器**：放大/再生信号，延长距离；**两端必须是同一种协议**
- **集线器（Hub）**：多端口的中继器，**所有端口在同一个冲突域**，把收到的信号**广播**到其他所有端口

> 📌 **5-4-3 规则**：10BASE5 以太网中，最多 5 个网段、4 个中继器，其中只有 3 个网段可以挂主机。

# 第三部分：数据链路层（⭐⭐⭐）

## 11.8 基本功能
- **封装成帧**：给网络层交来的数据加上**帧头和帧尾**，标记帧的开始和结束
  - 透明传输：数据里出现了和帧定界符一样的比特组合怎么办？→ **字节填充**（加转义字符）或 **零比特填充**（数据中每出现 **5 个连续的 1**，就在后面**插入一个 0**，HDLC 用）
- **差错控制**：CRC 检错（见组成原理篇 4.4 节）。数据链路层一般**只检错不纠错**，出错的帧直接丢弃
- **流量控制**：发送方不要发得太快，把接收方淹没
- **可靠传输**：通过确认和重传实现

## 11.9 流量控制与可靠传输：三种协议（⭐⭐⭐ 必考计算）

### 🧒 滑动窗口大白话
- **发送窗口**：发送方**不用等确认、可以连续发送**的帧的数量上限
- **接收窗口**：接收方**可以接收**的帧的范围
- 收到确认后，窗口**向前滑动**

### ① 停止-等待协议（SW）
🧒 **发一帧，等确认，收到确认后再发下一帧**。发送窗口 = 1，接收窗口 = 1。
- 帧编号只需要 1 位（0 和 1 交替）
- 超时重传：发出后启动计时器，超时没收到确认就重发

**信道利用率（⭐⭐）**：
```
U = 发送一帧的时间 / (发送一帧的时间 + RTT + 发送确认帧的时间)
  = T_D / (T_D + RTT + T_A)
```
（确认帧很短时 T_A 可忽略）

**真题（2020 年第 36 题）**：停止-等待，数据帧和确认帧都是 1000 B，速率 10 kbps，单向传播时延 200 ms，最大信道利用率？
- T_D = 1000 × 8 / 10000 = **0.8 s**；T_A = 0.8 s；RTT = 0.4 s
- U = 0.8 / (0.8 + 0.4 + 0.8) = 0.8 / 2.0 = **40%**，选 D
- ⚠️ 这题确认帧很长，**不能忽略**！

### ② 后退 N 帧协议（GBN）
🧒 **可以连续发 N 帧**不用等确认。接收方**只按顺序收**（接收窗口 = 1）：如果中间某帧丢了，后面的都扔掉。发送方超时后，**从丢的那帧开始，后面已发的全部重发**（“后退 N 帧”）。
- **累积确认**：确认号 n 表示“n 号帧及之前的都收到了”
- 用 n 位编号时：**发送窗口 W_T ≤ 2ⁿ − 1**（接收窗口 = 1）

### ③ 选择重传协议（SR）
🧒 接收方**也有窗口**，乱序到达的正确帧**先存起来**；发送方**只重传出错的那一帧**。
- **逐帧确认**
- 用 n 位编号时：**W_T + W_R ≤ 2ⁿ**，一般 **W_T = W_R = 2ⁿ⁻¹**

### 📖 连续 ARQ 的信道利用率（⭐）
发送窗口为 W：
```
U = W × T_D / (T_D + RTT)    （结果大于 1 时取 1）
```
🧒 在“发出第一帧到收到它的确认”这段时间里，最多能发 W 帧。

**窗口大小怎么求**：要让信道利用率达到某个值，W ≥ 目标利用率 × (T_D + RTT) / T_D。

**真题（2025 年第 47 题第 2 问）**：卫星链路，基于 GBN 设计协议，帧长 1500 B，速率 200 kbps，单向传播时延 = 36000 km / 300000 km/s = **0.12 s**（RTT 0.24 s），忽略 ACK 帧长度，要求信道利用率 ≥ 80%，发送窗口至少多大？帧序号至少几位？
- T_D = 1500 × 8 / 200000 = **0.06 s**
- W × 0.06 / (0.06 + 0.24) ≥ 0.8 → W ≥ 0.8 × 0.3 / 0.06 = **4**
- GBN：W ≤ 2ⁿ − 1 → 2ⁿ ≥ 5 → n = **3 位**

## 11.10 介质访问控制（⭐⭐）

### 🧒 大白话
很多台电脑共用一根线（或同一片无线电频道）——就像**一个教室里很多人要说话**。谁说？怎么避免两个人同时说？

### 📖 信道划分（静态分配）
- **频分复用 FDM**：每人分一个频段（收音机的不同频道）
- **时分复用 TDM**：每人轮流用一小段时间
- **波分复用 WDM**：光纤里用不同波长的光
- **码分复用 CDMA**：每人一个**码片序列**，大家同时说，靠码片序列区分
  - 各站码片序列**两两正交**（规格化内积为 0）
  - 发 1 就发自己的码片序列，发 0 发码片序列的反码
  - 接收方用某站的码片序列和收到的叠加信号做**规格化内积**：结果 1 → 该站发 1；−1 → 发 0；0 → 没发

### 📖 随机访问（⭐⭐）

#### ALOHA（了解）
想发就发，冲突了随机等一会儿再发。

#### CSMA（载波监听多路访问）
🧒 “**先听后说**”：发送前先听线路上有没有人在说话。
- 1-坚持：听到忙就一直听，一空闲马上发
- 非坚持：听到忙就过一段随机时间再听
- p-坚持：空闲时以概率 p 发送

#### CSMA/CD（⭐⭐⭐ 以太网用）
🧒 “**先听后说，边说边听，冲突停止，随机重发**”。
- 为什么还会冲突？因为**信号传播需要时间**：A 发出的信号还没传到 B，B 听着线路是空的，也开始发了
- **争用期（冲突窗口）= 2τ**（τ 是单程端到端传播时延）：发送方最迟要经过 2τ 才能确定自己的帧没有冲突
- **最短帧长 = 2τ × 数据率**（⭐）
  🧒 帧必须足够长，保证**还在发送的时候**就能听到冲突，否则发完了才冲突就不知道了
  - 以太网：争用期 **51.2 μs**，10 Mbps → 最短帧长 **64 B**（512 bit）
  - 帧短于 64 B 的都是冲突后中止的**无效帧**
- **二进制指数退避算法**（⭐）：
  1. 基本退避时间 = 争用期 2τ（10 Mbps 以太网 51.2 μs）
  2. 第 k 次重传：k = min(重传次数, 10)，从 {0, 1, …, 2ᵏ − 1} 中随机选一个 r
  3. 等待 r × 争用期 后重传
  4. 重传 **16 次**仍失败就放弃，报告上层

**真题（2025 年第 35 题）**：10BASE-T 以太网，甲乙在同一冲突域，**连续发生 11 次冲突**，甲再次发送前的**最大**等待时间？
- k = min(11, 10) = **10**，r 最大 = 2¹⁰ − 1 = **1023**
- 最大时间 = 1023 × 51.2 μs = 52377.6 μs = **52.3776 ms**，选 C

**真题（2022 年第 47 题第 2 问）**：信号传播速度 2 × 10⁸ m/s，以太网最小帧长 64 B，速率 100 Mbps（100BASE-T），信号通过设备 2（集线器）的时延 1.51 μs，H2 和 H3 之间最远距离？
- 发送 64 B 的时间 = 512 / 100M = **5.12 μs**，这必须 ≥ 2 × 单程时延
- 单程时延 ≤ 2.56 μs，扣掉集线器 1.51 μs，传播时延 ≤ 1.05 μs
- 距离 ≤ 1.05 μs × 2 × 10⁸ m/s = **210 m**

#### CSMA/CA（⭐ 无线局域网 802.11 用）
🧒 无线网络里**边说边听做不到**（自己的信号太强，听不见别人），而且有“**隐蔽站**”问题（A 和 C 都能和 B 通信，但彼此听不到）。所以改成“**尽量避免冲突**”：
1. 信道空闲时，先等一个 **DIFS** 时间
2. 发送数据帧
3. 接收方正确收到后，等 **SIFS** 时间，回一个 **ACK**
4. 发送方收到 ACK 才算成功（**无线网络需要确认**，因为无法检测冲突）
5. 信道忙的话，用退避算法等待
- 可选：**RTS/CTS**（预约信道）：发送前先发“请求发送 RTS”，接收方回“允许发送 CTS”，其他站听到后就不发了
- 帧间间隔：**SIFS（最短）< PIFS < DIFS（最长）**。SIFS 用于 ACK、CTS 等需要“立即响应”的帧

**真题（2020 年第 37 题）**：802.11 中 H 与 AP 之间发送帧的过程，IFS1~IFS4 中最长的是 **IFS1**（发送数据帧**前**等待的 DIFS 最长；ACK、CTS 前等待的是 SIFS）。

### 📖 轮询访问：令牌传递
令牌在环上传递，拿到令牌的站才能发送。不会冲突，适合负载重的网络。

## 11.11 局域网和以太网

### 📖 以太网
- 使用 **CSMA/CD**（半双工时），**无连接、不可靠**（不编号、不确认）
- **MAC 地址**：48 位，全球唯一，固化在网卡里，如 `00-11-22-33-44-55`
  - **广播地址**：FF-FF-FF-FF-FF-FF
- **以太网帧（MAC 帧）格式**：目的 MAC（6 B）+ 源 MAC（6 B）+ 类型（2 B）+ **数据（46 ~ 1500 B）** + FCS（4 B，CRC 校验）
  - 数据字段不足 46 B 要填充 → 最短帧 = 6 + 6 + 2 + 46 + 4 = **64 B**
  - **MTU = 1500 B**（数据部分最大值）
- 10BASE-T：10 Mbps，基带传输，**双绞线**，星形拓扑

### 📖 VLAN（虚拟局域网）
在交换机上按需要把主机划分成不同的逻辑组，**每个 VLAN 是一个广播域**。
- 802.1Q 帧：在以太网帧中插入 **4 字节的 VLAN 标记**（含 12 位 VLAN ID）

### 📖 无线局域网 802.11
- 基本服务集 BSS：一个 **AP（接入点）** + 若干移动站
- **802.11 帧有 4 个地址字段**（⭐）。最常见的情况（去往 AP 或从 AP 来）只用前 3 个：

| 情况 | 地址 1（接收方） | 地址 2（发送方） | 地址 3 |
|---|---|---|---|
| 站 → AP（To AP = 1） | AP 的 MAC | 源站 MAC | **目的**地址 |
| AP → 站（From AP = 1） | 目的站 MAC | AP 的 MAC | **源**地址 |

🧒 **地址 1 永远是“这一跳的接收者”，地址 2 永远是“这一跳的发送者”**，地址 3 补充“另一端”的地址。

**真题（2022 年第 47 题第 4 问）**：H4 向 H5 发 IP 分组 P（两者都在同一个 AP 下），H5 收到的帧（**AP → H5** 这一段）：地址 1 = **H5 的 MAC**，地址 2 = **AP 的 MAC**，地址 3 = **H4 的 MAC**（源）。

## 11.12 数据链路层设备（⭐⭐）

### 📖 交换机（以太网交换机、二层交换机）
🧒 集线器是“**大喇叭**”，收到什么都广播给所有人；交换机是“**聪明的邮递员**”，它**记住每个 MAC 地址在哪个端口**，只把帧发到目的主机所在的端口。

**自学习过程**（⭐）：
1. 收到一个帧，把“**源 MAC 地址 ↔ 进入端口**”记入**交换表**（学习）
2. 查交换表找**目的 MAC**：
   - 找到了，且不是进来的那个端口 → **只从那个端口转发**
   - 找到了，但就是进来的端口 → 丢弃（不用转发）
   - **没找到** → **从除进入端口外的所有端口广播（泛洪）**
3. 广播帧（目的 FF-FF-…）→ 泛洪

**交换机的两种转发方式**：
- **存储转发**：整个帧收完、校验无误再转发（可靠，时延大）
- **直通交换**：只看到**目的 MAC（前 6 字节）**就开始转发（快，但不检查错误）

### 📖 冲突域和广播域（⭐⭐ 必考）
- **冲突域**：同时发送会发生冲突的范围
- **广播域**：一个广播帧能到达的范围

| 设备 | 所在层 | 隔离冲突域？ | 隔离广播域？ |
|---|---|---|---|
| 集线器、中继器 | 物理层 | ✗ | ✗ |
| 交换机、网桥 | 链路层 | **✓（每个端口一个冲突域）** | ✗ |
| 路由器 | 网络层 | ✓ | **✓（每个端口一个广播域）** |

**真题（2020 年第 35 题）**：图中一台路由器连着一台以太网交换机和其他设备，数冲突域和广播域——
🧒 方法：**路由器的每个接口 = 一个广播域**；**交换机的每个端口 = 一个冲突域**（集线器连着的所有主机算同一个冲突域）。

**真题（2022 年第 47 题第 1 问）**：H1 与 H2 属于同一个广播域但不属于同一个冲突域；H2 和 H3 属于同一个冲突域。→ 设备 1（隔开 H1 和 H2 的冲突域，但不隔广播域）是**交换机**；设备 2（H2、H3 在同一冲突域）是**集线器**。

## 11.14 课后练习

1. 信道带宽 3 kHz，信噪比 30 dB，最大数据率？
2. 用 3 位编号，GBN 发送窗口最大多少？SR 呢？
3. 以太网速率提高到 1 Gbps，要保持最短帧长 64 B 不变，最大距离如何变化？
4. 交换机刚启动，交换表为空。A 发给 B 一帧，交换机怎么处理？然后 B 回复 A 呢？

<details>
<summary>答案</summary>

1. S/N = 1000，3k × log₂1001 ≈ 3k × 10 ≈ 30 kbps
2. GBN：2³ − 1 = 7；SR：2² = 4
3. 发送 64 B 的时间缩短为原来的 1/100（相对 10 Mbps），争用期变短，最大距离也要缩短为原来的 1/100（或者增大最短帧长）
4. A→B：记录 A 所在端口，B 不在表中 → 泛洪；B→A：记录 B 所在端口，A 在表中 → 只从 A 的端口转发
</details>
