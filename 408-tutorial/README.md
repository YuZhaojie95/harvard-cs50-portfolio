# 408 计算机学科专业基础 · 零基础完全教程

> 写给**完全零基础**、目标 **408 考 120 分**的你。
> 这套教程根据 **2020、2021、2022、2023、2025 年 408 真题**的难度和考点编写，覆盖考试大纲的全部知识点：数据结构、计算机组成原理、操作系统、计算机网络。
>
> 📚 这是**精简版**。想要像老师上课一样逐个知识点细讲的**完整版**（约 110 课），请看 [`408-full-course/`](../408-full-course/README.md)。

## 📖 这套教程怎么用

每个知识点都按同样的结构讲：

| 标记 | 含义 |
|---|---|
| 🧒 **大白话** | 先用生活中的比喻讲明白“它是什么、为什么需要它”，像给 8 岁小孩讲故事 |
| 📖 **正式说法** | 再讲教材上的定义、公式、规则（考试要用的） |
| ✏️ **例题 / 真题** | 马上用真题练手，一步一步算给你看 |
| ⚠️ **易错点** | 考试最容易掉进去的坑 |
| ⭐ | 重要程度：⭐ 常考，⭐⭐ 很常考，⭐⭐⭐ 几乎年年考 |

每章最后有**小结表格**（考前背这个）和**课后练习**（带答案）。

## 🎯 推荐学习路线

```
预备篇（2~3 周）
   ↓
数据结构（线性结构 → 树与图 → 查找排序）
   ↓
组成原理（数据运算 → 存储系统 → 指令与CPU → 总线I/O）
   ↓
操作系统（进程 → 内存 → 文件与I/O）
   ↓
计算机网络（链路层 → 网络层 → 传输层应用层）
   ↓
大题专项 + 历年真题（按年份计时做） + 错题本
```

- 组成原理的“虚拟存储器”和操作系统的“内存管理”是**同一个东西从两个角度讲**，学到时对照着看。
- 组成原理的“中断/DMA”和操作系统的“I/O 管理”也互相关联。
- CRC、码距在组成原理里讲，计算机网络的数据链路层会再用到。
