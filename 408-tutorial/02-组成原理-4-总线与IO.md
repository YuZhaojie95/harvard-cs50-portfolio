# 第 2 篇 · 计算机组成原理（四）：总线 + 输入输出系统

> 总线 1~2 道选择题；I/O 2~3 道选择题，偶尔出大题（2022 年 44 题磁盘 + DMA）。
> 这一章概念多、计算少，**理解了比喻就能拿分**。

# 第一部分：总线

## 7.1 总线是什么

### 🧒 大白话
总线就是电脑里的**公共马路**。CPU、内存、硬盘、键盘……各个部件都连在这条马路上，靠它互相送数据。
- 公共马路的特点：**同一时刻只能有一个部件在“说话”（发送）**，但可以有多个部件在“听”（接收）。
- 所以需要“**交通警察**”（总线仲裁）决定谁先用。

### 📖 分类
**按位置分：**
- **片内总线**：CPU 芯片内部
- **系统总线**：CPU、主存、I/O 接口之间
- **I/O 总线**：连接中低速 I/O 设备
- **通信总线**：计算机与计算机之间

**系统总线按传输内容分（⭐）：**
| 总线 | 传什么 | 方向 |
|---|---|---|
| **数据总线** | 数据 | **双向** |
| **地址总线** | 地址 | **单向**（CPU 发出） |
| **控制总线** | 控制信号（读、写、中断请求…） | 单根单向，整体双向 |

> 📌 地址总线位数决定**主存最大容量**；数据总线位数决定**一次传多少数据**。

**按结构分**：单总线（所有部件挂一条，简单但慢）、双总线、三总线（主存总线 + I/O 总线 + DMA 总线）。

## 7.2 总线的性能指标（⭐ 计算）

| 指标 | 含义 |
|---|---|
| **总线宽度** | 数据总线的根数（一次能并行传几位） |
| **总线时钟频率** | 时钟的频率 |
| **总线工作频率** | 每秒传送几次数据（一个时钟周期可能传 2 次、4 次） |
| **总线传输周期** | 完成一次总线操作所需时间 |
| **总线带宽** | 每秒传送的**数据量** = **总线宽度 × 工作频率** |

**真题（2020 年第 19 题）**：QPI 总线，点对点全双工，每个方向同时传 20 位（**16 位数据** + 4 位校验），每个时钟周期传 2 次。带宽 = 每秒传送次数 × 2B × 2。时钟频率 2.4 GHz，带宽？
- 每秒传送次数 = 2.4 G × 2 = 4.8 G 次
- 带宽 = 4.8 G × 2B（每次 16 位数据 = 2B）× 2（两个方向）= **19.2 GB/s**，选 C

**真题（2025 年第 20 题）**：同步并行总线，每个时钟周期传 4 次（quad-pumped），**工作频率 1333 MHz（实际单位 MT/s，每秒传送 1333 M 次）**，宽度 64 位。带宽？
- ⚠️ 陷阱：题目给的已经是**每秒传送次数**（1333 M 次/秒），**不要再乘 4**！
- 带宽 = 1333 M × 64 位 / 8 = 1333 M × 8 B ≈ **10.66 GB/s**，选 A

## 7.3 总线仲裁
多个部件同时想用总线，谁先用？
- **集中式**（有一个仲裁器）：
  - **链式查询**：授权信号像**接力棒**一样一个一个传，离仲裁器近的优先级高。线少，但对电路故障敏感，远处的可能“饿死”
  - **计数器定时查询**：用计数器轮流问，优先级可变
  - **独立请求**：每个设备单独一根请求线和授权线，**最快最灵活**，但线最多
- **分布式**：没有中央仲裁器，各设备自己竞争

## 7.4 总线定时（⭐）
- **同步定时**：大家都听**统一的时钟**节拍。简单快速，但要迁就最慢的设备，适合**速度差不多、距离短**的部件
- **异步定时**：没有统一时钟，靠“**握手**”信号（请求 → 回答）一问一答
  - **不互锁**：请求发出后过一会儿自己撤销，不管对方收没收到
  - **半互锁**：请求要等到回答才撤销，回答自己过一会儿撤销
  - **全互锁**：请求等回答才撤销，回答等请求撤销才撤销（最可靠）
  - 适合**速度差异大**的设备
- **半同步**：同步 + 一个“等待”信号（慢设备可以让大家等一下）
- **分离式**：发完请求就**释放总线**，对方准备好数据后再申请总线发回来，提高总线利用率

**突发（Burst）传送**：发一次地址，**连续传多个数据**（后面的地址自动递增），读取一整个 Cache 块时很常用。

**真题（2021 年第 19 题）**：错误的是 **C. 异步总线由握手信号定时，一次握手过程完成一位数据交换**（一次握手完成的是**一次数据交换**，一个字或一个数据单位，不是 1 位）。
其他正确：同步总线的时钟频率不一定等于工作频率（一个周期可以传多次）；突发传送可以连续传多个数据。

# 第二部分：输入输出系统

## 7.5 I/O 接口

### 🧒 大白话
CPU 说“普通话”，打印机、键盘、磁盘各说“方言”，而且速度差别巨大。
**I/O 接口**就是**翻译 + 中转站**：
- 暂存数据（**数据缓冲**，解决速度不匹配）
- 转换数据格式（串行 ↔ 并行）
- 记录设备状态（“忙”“就绪”“出错”）
- 接收 CPU 的命令并传给设备
- 地址译码，选择设备

### 📖 接口里的寄存器（叫“**端口**”）
- **数据端口**：数据缓冲寄存器
- **状态端口**：状态寄存器
- **控制端口**：控制寄存器
（状态和控制常常可以合用一个端口）

**真题（2021 年第 20 题）**：不属于 I/O 接口的是 **A. 磁盘驱动器**（驱动器是**设备本身**的一部分）。打印机适配器、网络控制器（网卡）、可编程中断控制器都是接口。

### 📖 I/O 端口编址
- **统一编址（存储器映射）**：I/O 端口占用一部分**主存地址**，用普通的访存指令（mov）访问 I/O。不需要专门的 I/O 指令，但占用了主存地址空间
- **独立编址（I/O 映射）**：I/O 端口有自己**单独的地址空间**，要用**专门的 I/O 指令**（in、out）。x86 就是这样

> 📌 **I/O 指令是特权指令**，只能在内核态执行（2021 年第 23 题）。用户程序要做 I/O 必须通过系统调用让操作系统来做。

## 7.6 I/O 方式（⭐⭐⭐ 必考）

### 🧒 总比喻：你在等快递
- **程序查询**：你**每隔一分钟跑到门口看一眼**快递到没到。什么都干不了，只能反复看。（CPU 一直在循环查询）
- **程序中断**：你在家安心看书，**快递员按门铃**时你再去开门。（设备准备好了就发中断通知 CPU）
- **DMA**：你雇了个**管家**，快递来了管家直接签收、搬进仓库，全部搬完才告诉你一声。（DMA 控制器直接在设备和内存之间搬一整块数据，完成后才中断 CPU）
- **通道**：管家升级成**物流经理**，能执行一整套物流程序（通道程序），管很多设备。

### 7.6.1 程序查询方式
CPU 反复读状态寄存器，直到设备就绪，再传一个数据。
- **CPU 和外设串行工作**，CPU 大量时间浪费在“等”上（忙等）
- 例：计算“查询开销占 CPU 时间的百分比”

### 7.6.2 程序中断方式（⭐⭐）

#### 📖 中断的完整过程
1. **中断请求**：设备准备好数据，向 CPU 发中断请求信号
2. **中断判优**：多个请求同时来，按优先级选一个
3. **中断响应**（CPU 满足下面 3 个条件才响应）：
   - ① 有中断请求（且没被屏蔽）
   - ② CPU 处于**开中断**状态（中断允许触发器 IF = 1）
   - ③ **当前指令执行完了**
4. **中断隐指令**（硬件自动完成）：**关中断 → 保存断点（PC）和 PSW → 引出中断服务程序（找入口地址）**
5. **中断服务程序**（软件，操作系统完成）：
   ```
   保护现场（保存通用寄存器、屏蔽字）
   → 开中断（多重中断时才开，允许更高级的中断打断我）
   → 执行中断服务（真正的数据传送）
   → 关中断
   → 恢复现场
   → 开中断
   → 中断返回
   ```

**找中断服务程序入口的方法**：
- **向量中断**：每个中断源有一个**中断向量**（中断类型号）→ 查**中断向量表**得到入口地址（硬件方法）
- 软件查询法

**真题（2021 年第 22 题，多重中断中 CPU 响应中断）**：错误的是 **A. 仅在用户态下 CPU 才能检测和响应中断**（内核态也能响应中断，比如在处理低级中断时响应高级中断）。
其余正确：只有检测到中断请求才进入中断响应周期；进入中断响应周期时一定是开中断状态；检测到中断请求说明一定有未被屏蔽的请求。

**真题（2020 年第 21 题）**：错误的是 **B. 一旦可屏蔽中断请求信号有效，CPU 将立即响应**（要等**当前指令执行完**，而且要处于开中断状态）。
其余正确：关中断时也能响应 NMI（不可屏蔽中断）；NMI 优先级比可屏蔽中断高；**中断屏蔽字可以改变可屏蔽中断的处理优先级**。

**真题（2022 年第 21 题，中断 I/O 方式）**：不正确的是 **C. 外设准备数据的时间应小于中断处理时间**（恰恰相反：如果设备很快就准备好了下一个数据，而 CPU 中断处理还没完，就会**丢数据**，所以外设准备数据的时间应**大于**中断处理时间）。
其余正确：适合键盘、针式打印机等**字符型**慢设备；数据传送通过软件（中断服务程序）完成；外设准备数据时 CPU 可以运行其他进程。

#### 📖 单重中断 vs 多重中断
- **单重中断**：处理一个中断时不允许被别的中断打断（服务程序里不开中断）
- **多重中断（中断嵌套）**：处理低级中断时，允许**更高级**的中断打断

#### 📖 中断屏蔽字（⭐ 常考）
🧒 **响应优先级**是硬件固定的（谁先被 CPU 看到）；但**处理优先级**可以用**屏蔽字**来改。
屏蔽字里每一位对应一个中断源，**1 表示屏蔽（不让它打断我）**，0 表示允许。
- 每个中断源的屏蔽字**总会屏蔽自己**（自己那位是 1）
- 处理优先级**越高**，屏蔽字里的 **1 越多**（屏蔽的越多）

**例**：4 个中断源，响应优先级 1 > 2 > 3 > 4，希望处理优先级变成 **1 > 4 > 3 > 2**。
| 中断源 | 屏蔽 1 | 屏蔽 2 | 屏蔽 3 | 屏蔽 4 |
|---|---|---|---|---|
| 1（最高） | 1 | 1 | 1 | 1 |
| 2（最低） | 0 | 1 | 0 | 0 |
| 3 | 0 | 1 | 1 | 0 |
| 4 | 0 | 1 | 1 | 1 |
🧒 规则：**我屏蔽所有比我低的和我自己**，不屏蔽比我高的。

### 7.6.3 DMA 方式（⭐⭐⭐）

#### 📖 为什么需要 DMA
磁盘、网卡这种**高速**设备，一次传一大块数据。如果每传一个字都中断一次 CPU，CPU 就忙死了。
**DMA（直接存储器访问）**：由 **DMA 控制器**接管总线，**直接在设备和主存之间传数据，不经过 CPU**。

#### 📖 DMA 传送过程
1. **预处理**（CPU 做）：告诉 DMA 控制器“从哪个设备、传到主存哪个地址、传多少字节”
2. **数据传送**（DMA 控制器做）：每准备好一个数据单位，就申请总线，直接写进主存；**CPU 此时可以干别的**
3. **后处理**：整块传完后，DMA 控制器**发一个中断**通知 CPU（“DMA 传送结束”中断），CPU 做收尾工作

#### 📖 DMA 与 CPU 争抢主存的三种方式
- **停止 CPU 访存**：DMA 传送期间 CPU 完全不能访问主存
- **周期挪用（周期窃取）**：DMA 每传一个数据就“借用”一个存储周期。如果此时 CPU 也要访存，**DMA 优先**（因为 I/O 数据不及时取走会丢失）
- **DMA 与 CPU 交替访存**：把存储周期一分为二，一半给 CPU，一半给 DMA

**真题（2020 年第 22 题）**：周期挪用 DMA，数据块 512 字节，接口有 32 位数据缓冲寄存器。输入时，错误的是？
- A. 每准备好 32 位数据，DMA 控制器就发出一次总线请求 ✓
- B. 相对于 CPU，DMA 控制器的总线使用权优先级更高 ✓
- C. **在整个数据块传送过程中，CPU 不可以访问主存** ✗（周期挪用方式下，DMA 只是偶尔借一个周期，其他时间 CPU 照样可以访存）
- D. 数据块传送结束时产生“DMA 传送结束”中断请求 ✓

**真题（2025 年第 21 题）**：适合用 DMA 的设备？键盘（✗，慢速字符设备）、**网卡 ✓**、**固态硬盘 ✓**、针式打印机（✗）→ 选 B

**真题（2022 年第 44 题第 3 问）**：周期挪用 DMA，磁盘控制器数据缓冲区 64 位，一个扇区 512 字节，DMA 向 CPU 发了多少次总线请求？
→ 每 64 位（8 字节）请求一次：512 / 8 = **64 次**。
若 CPU 也要访存，DMA 能获得总线吗？→ **能**，DMA 优先级更高（否则磁盘数据会被新数据覆盖而丢失）。

#### 📊 中断 vs DMA（⭐ 比较题）
| 比较 | 中断方式 | DMA 方式 |
|---|---|---|
| 数据传送由谁完成 | **CPU 执行程序**（软件） | **DMA 控制器**（硬件） |
| 传送单位 | 一个字 / 一个字符 | **一整块** |
| 中断次数 | 每个数据一次 | **整块传完才一次** |
| CPU 响应时机 | **指令执行完后** | 一个**存储周期（总线周期）结束后**就能响应 DMA 请求 |
| 适用设备 | 低速字符设备（键盘、打印机） | 高速块设备（磁盘、网卡、SSD） |
| 能否处理异常事件 | 能 | 不能（只负责传数据） |
| 优先级 | 较低 | **高于中断** |

> ⚠️ DMA 请求的响应时机比中断灵活：CPU 在**任何一个机器周期结束时**都可以响应 DMA 请求（只要把总线让出去），而中断要等**指令执行完**。

### ✏️ 经典计算：CPU 用于 I/O 的时间占比
> CPU 主频 500 MHz。某外设数据传输率 0.5 MB/s（这里 M = 10⁶），按 32 位（4 字节）传送。
> (1) 中断方式，每次中断服务（含响应）需 500 个时钟周期，CPU 用于该外设 I/O 的时间占比？
> (2) DMA 方式，每次传 5000 字节块，每次 DMA 预处理 + 后处理共 500 个时钟周期，占比？

**(1) 中断方式**
- 每秒中断次数 = 0.5 × 10⁶ / 4 = 1.25 × 10⁵ 次
- 每秒占用周期 = 1.25 × 10⁵ × 500 = 6.25 × 10⁷
- 占比 = 6.25 × 10⁷ / (500 × 10⁶) = **12.5%**

**(2) DMA 方式**
- 每秒 DMA 次数 = 0.5 × 10⁶ / 5000 = 100 次
- 每秒占用周期 = 100 × 500 = 5 × 10⁴
- 占比 = 5 × 10⁴ / (5 × 10⁸) = **0.01%**

🧒 看到了吧，DMA 让 CPU 轻松了一千多倍！

### 7.6.4 通道方式（了解）
**通道**是一个**专门处理 I/O 的小处理器**，能执行“通道程序”，一个通道可以管理多台设备。CPU 只需发一条 I/O 指令启动通道，剩下的全交给通道。
- 字节多路通道（多台低速设备）、选择通道（一次只服务一台高速设备）、数组多路通道

## 7.7 本篇小结

| 知识点 | 一句话 |
|---|---|
| 总线 | 同一时刻只有一个发送者 |
| 数据/地址/控制总线 | 数据双向；地址单向 |
| 总线带宽 | 宽度 × 工作频率（看清是时钟频率还是传送频率） |
| 同步 vs 异步 | 统一时钟 vs 握手；异步一次握手传一个数据 |
| I/O 接口 | 数据缓冲、状态、控制端口；驱动器不是接口 |
| 编址 | 统一编址用访存指令；独立编址用 I/O 指令 |
| 中断响应条件 | 有未屏蔽请求 + 开中断 + 指令执行完 |
| 中断隐指令 | 关中断、保存断点、引出服务程序（硬件） |
| 屏蔽字 | 1 = 屏蔽；处理优先级越高，1 越多 |
| 中断 I/O | 适合慢速设备；外设准备时间要大于中断处理时间 |
| DMA | 整块传送，结束时中断一次；优先级高于 CPU |
| 周期挪用 | CPU 仍可访存；冲突时 DMA 优先 |

## 7.8 课后练习

1. 32 位总线，时钟频率 100 MHz，每 2 个时钟周期传送一次数据，带宽是多少？
2. 下列哪些操作由硬件（中断隐指令）完成？(a) 关中断 (b) 保存通用寄存器 (c) 保存断点 (d) 执行中断服务
3. 为什么 DMA 请求的优先级比 CPU 访存高？
4. 5 个中断源 A~E，响应优先级 A>B>C>D>E，要使处理优先级为 A>D>C>B>E，写出 D 的屏蔽字（顺序 ABCDE）。

<details>
<summary>答案</summary>

1. 每秒传送 100M / 2 = 50M 次，带宽 = 50M × 4B = 200 MB/s
2. (a)(c)。(b) 保存通用寄存器和 (d) 由中断服务程序（软件）完成
3. I/O 设备的数据如果不及时取走，下一个数据来时会覆盖它，造成数据丢失；而 CPU 晚一点访存没关系
4. D 屏蔽自己和比它低的 C、B、E：A=0, B=1, C=1, D=1, E=1 → **01111**
</details>
