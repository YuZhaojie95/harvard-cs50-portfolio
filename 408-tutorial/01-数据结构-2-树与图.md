# 第一部分：树

## 2.1 树的基本概念

### 🧒 大白话
树就像**家谱**，或者一棵**倒着长的树**：
- 最上面的祖先叫**根**
- 每个人可以有好几个孩子
- 没有孩子的人叫**叶子**

```
          A          ← 根，第 1 层
        / | \
       B  C  D       ← 第 2 层
      / \     \
     E   F     G     ← 第 3 层（E、F、G、C 都是叶子）
```

### 📖 术语（必须会）

| 术语 | 意思 | 上图例子 |
|---|---|---|
| 结点的度 | 这个结点有几个孩子 | A 的度 = 3，B 的度 = 2 |
| 树的度 | 所有结点度的最大值 | 3 |
| 叶子结点 | 度为 0 的结点 | C, E, F, G |
| 分支结点 | 度 > 0 的结点 | A, B, D |
| 层次/深度 | 从根往下数第几层（根是第 1 层） | E 在第 3 层 |
| 高度 | 树一共有几层 | 3 |
| 有序树 | 孩子有左右顺序之分 | 二叉树就是有序树 |
| 森林 | 好几棵互不相交的树 | 把 A 去掉，剩下的就是森林 |

### 📖 树的性质（⭐ 选择题常用）

**性质 1：结点数 = 所有结点的度之和 + 1**
🧒 除了根，每个结点都“挂”在一根树枝上；每根树枝对应父亲的一个度。所以“树枝数 = 结点数 − 1”。

写成公式：设度为 i 的结点有 nᵢ 个，
- 总结点数 n = n₀ + n₁ + n₂ + … + nₘ
- 总结点数 n = 1 + (0·n₀ + 1·n₁ + 2·n₂ + … + m·nₘ)

两个等式联立，就能解大部分“求叶子数”的题。

**例**：一棵树有 2 个度为 3 的结点，1 个度为 2 的结点，3 个度为 1 的结点，其余是叶子。叶子几个？
- n = 1 + 3×2 + 2×1 + 1×3 = 12
- n₀ = 12 − 2 − 1 − 3 = 6

**性质 2：m 叉树第 i 层最多 mⁱ⁻¹ 个结点；高度为 h 的 m 叉树最多 (mʰ − 1)/(m − 1) 个结点。**

**真题（2022 年第 4 题）**：三叉树 T 有 244 个结点，高度至少是？
🧒 “高度至少”→ 让每层都尽量塞满。高度 h 的三叉树最多 (3ʰ − 1)/2 个结点：
- h = 5：(243 − 1)/2 = 121 < 244，不够
- h = 6：(729 − 1)/2 = 364 ≥ 244，够了
答案 **6**，选 C。

## 2.2 二叉树（⭐⭐⭐ 重中之重）

### 🧒 大白话
二叉树就是**每个人最多 2 个孩子**，而且孩子分**左**和**右**（就算只有一个孩子，也要说清是左孩子还是右孩子）。

### 📖 特殊的二叉树

**满二叉树**：每一层都塞满了。高度 h 就有 2ʰ − 1 个结点。

**完全二叉树**：从上到下、从左到右**一个挨一个**地放，中间不能有空位，只有最后一层可以不满（而且只能缺右边的）。
```
满二叉树:          完全二叉树:        不是完全二叉树:
      1                 1                  1
    /   \             /   \              /   \
   2     3           2     3            2     3
  / \   / \         / \                  \
 4   5 6   7       4   5                  5     ← 4 号位置空了
```

**完全二叉树按层编号**（从 1 开始）的超级有用性质：
- 结点 i 的**父亲**是 ⌊i/2⌋
- 结点 i 的**左孩子**是 2i，**右孩子**是 2i+1
- n 个结点的完全二叉树，高度 = ⌊log₂n⌋ + 1
- 编号 i ≤ ⌊n/2⌋ 的是分支结点，其余是叶子
- **度为 1 的结点最多只有 1 个**（n 为偶数时有 1 个，奇数时 0 个）

### 📖 二叉树的核心性质（必背）

**n₀ = n₂ + 1**（叶子数 = 度为 2 的结点数 + 1）

🧒 推导：n = n₀ + n₁ + n₂，又 n = 1 + n₁ + 2n₂，两式相减得 n₀ = n₂ + 1。

**例**：完全二叉树有 1000 个结点，叶子几个？
- 1000 是偶数，所以 n₁ = 1
- n₀ + 1 + n₂ = 1000，n₀ = n₂ + 1 → 2n₂ + 2 = 1000 → n₂ = 499，**n₀ = 500**
- （更快：叶子数 = n − ⌊n/2⌋ = 1000 − 500 = 500）

### 📖 二叉树的存储

**顺序存储**：按完全二叉树的编号放进数组。不存在的结点空着。
- 适合完全二叉树；普通二叉树很浪费。
- **真题（2020 年第 3 题）**：高度 5、10 个结点的任意二叉树，顺序存储至少要几个单元？
  🧒 “任意”二叉树都要装得下 → 最坏情况下，最底层最右边的位置可能有结点，编号是 2⁵ − 1 = 31 → 需要 **31** 个，选 A。

**链式存储（二叉链表）**：
```c
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```
> 📌 n 个结点的二叉链表，一共 2n 个指针，其中 n − 1 个指向孩子，所以有 **n + 1 个空指针**。（线索二叉树就是利用这些空指针）

## 2.3 二叉树的遍历（⭐⭐⭐ 必考）

### 🧒 大白话
“遍历”就是**把每个结点都拜访一次**。按什么时候访问根，分三种：
- **先序**（根 左 右）：先看自己，再看左边孩子们，再看右边孩子们
- **中序**（左 根 右）：先看左边，再看自己，再看右边
- **后序**（左 右 根）：先看左右，最后看自己
- **层序**：一层一层从左到右

```
        A
       / \
      B   C
     / \   \
    D   E   F
```
- 先序：A B D E C F
- 中序：D B E A C F
- 后序：D E B F C A
- 层序：A B C D E F

**中序的“投影法”技巧**：把每个结点垂直往下“拍扁”到一条线上，从左到右读出来就是中序。

### 📖 递归代码（41 题常用模板）
```c
void PreOrder(BiTree T) {
    if (T != NULL) {
        visit(T);               // 访问根
        PreOrder(T->lchild);    // 递归左子树
        PreOrder(T->rchild);    // 递归右子树
    }
}
// 中序：把 visit 放中间；后序：把 visit 放最后
```
时间 O(n)，空间 O(h)（h 是树高，递归栈深度）。

**层序遍历**用队列：根入队 → 循环（出队一个，访问它，把它的左右孩子入队）直到队空。

### 📖 由遍历序列还原二叉树（⭐）

**规则**：必须有**中序**！
- 先序 + 中序 ✓ ；后序 + 中序 ✓ ；层序 + 中序 ✓
- 先序 + 后序 ✗（不能唯一确定）

**方法**：先序的第一个（或后序的最后一个）是根 → 在中序里找到根，左边是左子树、右边是右子树 → 对左右子树递归。

**例**：先序 `A B D E C F`，中序 `D B E A C F`
1. 根是 A；中序中 A 左边 `D B E` 是左子树，右边 `C F` 是右子树
2. 左子树先序 `B D E`，根 B；中序 `D B E` → D 在左，E 在右
3. 右子树先序 `C F`，根 C；中序 `C F` → F 在 C 的右边
就还原成上面那棵树。

### 📖 真题：中序相邻（2022 年第 3 题）
若 p 和 q 在中序序列中相邻，且 p 在 q 前面，下面哪个**不可能**？
I. q 是 p 的双亲；II. q 是 p 的右孩子；III. q 是 p 的右兄弟；IV. q 是 p 的双亲的双亲。

🧒 想想中序“左 根 右”：
- I 可能：p 是 q 的左孩子（且 p 没有右子树），中序里 p 紧挨着 q 前面。
- II 可能：q 是 p 的右孩子，且 q 没有左子树，中序里 p 后面紧接着就是 q。
- III 不可能：p 和 q 是兄弟，那中序里它们中间一定隔着**父亲**。
- IV 可能：比如 x 是 q 的左孩子，p 是 x 的右孩子且 p 没有右子树，中序里是 …x, p, q…，q 正是 p 的爷爷。
答案：**仅 III**，选 B。

## 2.4 线索二叉树

### 🧒 大白话
n 个结点有 n+1 个空指针，**白白浪费**。
线索二叉树把这些空指针利用起来：
- 空的左指针 → 指向**前驱**（遍历序列中的前一个）
- 空的右指针 → 指向**后继**（遍历序列中的后一个）
这样以后遍历就不用递归、不用栈了。

为了区分“指针指的是孩子还是线索”，每个结点多两个标志位：
- ltag = 0：lchild 指左孩子；ltag = 1：lchild 是前驱线索
- rtag 同理

### 📖 要点
- 按哪种遍历线索化，就叫“先序/中序/后序线索二叉树”。
- **中序线索树**找后继最方便；**后序线索树**找后继仍然需要知道双亲（不方便），**先序线索树**找前驱不方便。
- 考法：给一棵树画出线索；问某结点的线索指向谁。**先写出对应遍历序列**，前驱后继一看便知。

## 2.5 树、森林与二叉树的转换（⭐ 选择题常考）

### 🧒 大白话：“左孩子右兄弟”
一个普通的树，某个人可能有 5 个孩子，不好存。转换规则：
- 每个结点的**左指针**指向它的**第一个孩子**（大儿子）
- 每个结点的**右指针**指向它的**下一个兄弟**（弟弟）

```
普通树:            转成二叉树:
     A                  A
   / | \               /
  B  C  D             B
 / \                 / \
E   F               E   C
                     \   \
                      F   D
```
森林转二叉树：先把每棵树各自转换，再把第 2 棵树的根当成第 1 棵树根的**右孩子**，第 3 棵当第 2 棵根的右孩子……

**推论**：二叉树的根沿着**右指针一路往下**，有几个结点，森林就有几棵树。

### 📖 遍历对应关系（必背）

| 树 | 森林 | 对应的二叉树 |
|---|---|---|
| 先根遍历 | 先序遍历 | **先序遍历** |
| 后根遍历 | 中序遍历（有的书叫后根） | **中序遍历** |

**真题（2021 年第 4 题）**：森林 F 对应二叉树 T，T 的先序 `a,b,d,c,e,g,f`，中序 `b,d,a,e,g,c,f`，F 有几棵树？
1. 还原 T：根 a；中序中 a 左边 `b,d`，右边 `e,g,c,f`
2. a 的右子树先序 `c,e,g,f`，根是 c；中序里 c 右边是 `f` → c 的右孩子是 f
3. 从根一路往右：a → c → f，共 **3** 个 → 森林有 3 棵树，选 C。

**真题（2020 年第 4 题）**：森林 F 的先根序列 `a,b,c,d,e,f`，中根序列 `b,a,d,f,e,c`，对应二叉树 T 的后序？
→ 森林先序 = T 的先序，森林中根 = T 的中序。用先序+中序还原 T，再写后序：`b,f,e,d,c,a`，选 C。

### 📖 树的存储结构
1. **双亲表示法**：数组，每个结点记录父亲的下标。找父亲快，找孩子慢。
2. **孩子表示法**：每个结点挂一个链表，存它所有孩子。
3. **孩子兄弟表示法**：就是上面的“左孩子右兄弟”，本质是二叉链表。

## 2.6 哈夫曼树和哈夫曼编码（⭐⭐ 年年考）

### 🧒 大白话
**带权路径长度（WPL）**：每个叶子有个“重量”（权值），它离根越远，“扛”得越累。
WPL = 每个叶子的（权值 × 到根的路径长度）加起来。

哈夫曼树就是让 WPL **最小**的二叉树。
🧒 道理很简单：**重的放离根近的地方，轻的放远处**。

### 📖 构造方法（每次挑两个最轻的合并）
1. 把所有权值看成 n 棵只有一个结点的树
2. 挑出**最小的两个**，合成一棵新树，新根的权 = 两者之和
3. 把新树放回去，重复第 2 步，直到只剩一棵树

**真题（2021 年第 5 题）**：5 个叶子权值 10, 12, 16, 21, 30，最小 WPL？
```
{10,12,16,21,30} → 合并 10+12 = 22
{16,21,22,30}    → 合并 16+21 = 37
{22,30,37}       → 合并 22+30 = 52
{37,52}          → 合并 37+52 = 89
```
**秒算技巧**：WPL = **所有新生成结点的权值之和** = 22 + 37 + 52 + 89 = **200**，选 B。

### 📖 哈夫曼树的性质
- n 个叶子 → 一共合并 n−1 次 → 总结点数 **2n − 1**
- **没有度为 1 的结点**
- 哈夫曼树**不唯一**（左右可以交换，权值相同时选法也不同），但 WPL 一定相同
- （2022 年第 5 题：同一字符集的哈夫曼编码树 T1 与定长编码树 T2 比较，正确的是“**频次不同的字符在 T2 中处于相同的层**”——定长编码所有字符都在同一层；T1、T2 的结点数不一定相同。）

### 📖 哈夫曼编码与前缀码
把哈夫曼树的左分支记 0、右分支记 1，从根走到叶子的 0/1 串就是这个字符的编码。
- 出现越多的字符编码越短 → 总长度最短
- **前缀码**：任何一个编码都不是另一个编码的开头部分 → 解码时不会有歧义

**真题（2020 年第 42 题，10 分）**：
1. 什么数据结构适合保存前缀编码？→ **二叉树**（0 走左，1 走右，字符放在叶子上）
2. 怎么译码？→ 从根出发，读到 0 往左、读到 1 往右，走到叶子就输出这个字符，再回到根继续
3. 怎么判断一组编码是否有前缀特性？→ 把编码一个个插入二叉树。插入过程中如果**经过了一个已经是叶子（已有字符）的结点**，或者**最后停在了一个已有孩子的结点上**，就不是前缀码。

## 2.7 并查集

### 🧒 大白话
管理很多“小团体”：
- **查（Find）**：问某人属于哪个团体（找他们团体的“老大”）
- **并（Union）**：把两个团体合并

用双亲表示法实现：每个人记住自己的上级，老大的上级记为 −1（或者负的团体人数）。
Find 就是一直找上级直到老大；Union 就是让一个老大认另一个老大为上级。

### 📖 优化
- **按大小/按秩合并**：让小团体并到大团体下面 → 树高不超过 ⌊log₂n⌋ + 1，Find 为 O(log n)
- **路径压缩**：Find 时顺手让路上所有人直接挂到老大下面 → 几乎 O(1)
- 应用：Kruskal 算法判断是否成环、判断图的连通分量。

## 2.8 二叉排序树（BST）

### 🧒 大白话
一个很“讲规矩”的二叉树：**左边都比我小，右边都比我大**。
找东西时，比根小就往左，比根大就往右，像猜数字游戏一样。

```
        50
       /  \
     30    70
    /  \     \
  20   40     80
```
**中序遍历 BST 得到的一定是递增序列！**（非常重要的性质）

### 📖 操作
- **查找**：从根开始比，平均 O(log n)，最坏（退化成一条线）O(n)
- **插入**：查找失败的位置就是插入的位置（新结点一定是叶子）
- **删除**：
  1. 删叶子：直接删
  2. 只有一个孩子：让孩子顶替
  3. 有两个孩子：用**中序直接后继**（右子树最左下的结点）或直接前驱顶替，再删掉那个后继

**真题（2020 年第 5 题）**：哪个序列**不能**生成下面这棵 BST？（根 4，左孩子 2，2 的孩子 1 和 3，右孩子 5）
- A `4,5,2,1,3` ✓；C `4,2,5,3,1` ✓；D `4,2,1,3,5` ✓
- B `4,5,1,2,3`：1 先于 2 插入，1 会成为 4 的左孩子，**不是 2** → 选 B
🧒 规律：**每个结点都必须在它的所有后代之前插入**。

### 📖 平均查找长度（ASL）
- 查找成功 ASL = Σ（每个结点所在层数）/ n
- 查找失败 ASL = Σ（每个空指针位置的“父结点所在层数”）/ (n+1)

## 2.9 平衡二叉树（AVL）

### 🧒 大白话
BST 最怕“长歪”变成一条线。AVL 树规定：**每个结点左右两边的高度差不能超过 1**。
- **平衡因子** = 左子树高 − 右子树高，只能是 −1、0、1

### 📖 插入后失衡怎么办：旋转（⭐）
插入新结点后，从插入点往上找，**第一个**平衡因子变成 ±2 的结点叫 A（最小不平衡子树的根）。看新结点插在 A 的哪里：

| 类型 | 插在 A 的哪里 | 怎么转 |
|---|---|---|
| LL | 左孩子的左子树 | A 的左孩子 B **右旋**上来当根 |
| RR | 右孩子的右子树 | A 的右孩子 B **左旋**上来当根 |
| LR | 左孩子的右子树 | 先左旋再右旋：让 A 的左孩子的右孩子 C 上来当根 |
| RL | 右孩子的左子树 | 先右旋再左旋：让 A 的右孩子的左孩子 C 上来当根 |

🧒 **最简单的记法**：LL/RR 就是“**儿子**上位当爹”；LR/RL 就是“**孙子**上位当爷爷”。上位后，按大小关系把其他结点重新挂好（保持左小右大）。

**真题（2021 年第 6 题）**：AVL 树：根 20，左孩子 16，右孩子 30，30 的孩子是 25 和 40。插入 23 后根是什么？
```
插入前:       插入 23 后:          RL 旋转后:
    20            20                   25
   /  \          /  \                /    \
  16   30       16   30            20      30
      /  \          /  \          /  \       \
     25  40        25  40        16  23       40
                  /
                 23
```
1. 23 > 20 往右，< 30 往左，< 25 往左 → 挂在 25 的左边
2. 从下往上检查：20 的左高 1、右高 3，差 2，失衡，A = 20
3. 新结点在 A 的**右**孩子（30）的**左**子树里 → **RL 型** → 孙子 25 上位当根
4. 根变成 **25**，选 D

### 📖 AVL 的高度与结点数
高度为 h 的 AVL 树**最少**结点数 nₕ：n₀ = 0，n₁ = 1，n₂ = 2，**nₕ = nₕ₋₁ + nₕ₋₂ + 1**
→ n₃ = 4，n₄ = 7，n₅ = 12，n₆ = 20 … 常考“高度为 h 的 AVL 树至少多少个结点”。

AVL 查找时间复杂度 O(log n)。

## 2.10 红黑树（2022 年后新增考点）

### 🧒 大白话
AVL 太“严格”，插入删除时经常要旋转。红黑树是一种“**差不多平衡就行**”的 BST，旋转更少，插入删除更快。

### 📖 五条规则
1. 每个结点是**红**或**黑**
2. **根是黑的**
3. 叶子（虚构的 NIL 空结点）都是黑的
4. **红结点的孩子必须是黑的**（不能有两个红结点相连）
5. 从任一结点到它所有 NIL 的路径上，**黑结点数相同**（叫“黑高”）

### 📖 推论（考选择题）
- 从根到叶子的**最长路径不超过最短路径的 2 倍**（最短全黑，最长红黑相间）
- n 个内部结点的红黑树，高度 **h ≤ 2log₂(n+1)**，查找/插入/删除都是 O(log n)
- 黑高为 bh 的红黑树，内部结点至少 2^bh − 1 个
- **新插入的结点默认是红色**（染红不会破坏规则 5）
- 插入后若出现“红红相连”：看**叔叔**的颜色
  - 叔叔红 → 父、叔染黑，爷爷染红，把问题交给爷爷继续检查
  - 叔叔黑 → 像 AVL 一样旋转（LL/RR/LR/RL），再交换颜色
- AVL 更平衡、查找略快；红黑树插删时旋转更少。**红黑树不一定是 AVL 树**（它左右子树高度差可以超过 1）。

# 第二部分：图

## 2.11 图的基本概念

### 🧒 大白话
图就像**地铁线路图 / 朋友关系网**：
- **顶点（V）**：一个个站点 / 人
- **边（E）**：站点之间的连线 / 朋友关系
- **无向图**：关系是双向的（我是你朋友，你也是我朋友）
- **有向图**：关系是单向的（我关注了你，你不一定关注我），有向的边叫**弧**

### 📖 术语
| 术语 | 说明 |
|---|---|
| 度 | 无向图：连着几条边。有向图：**入度**（箭头指向我）+ **出度**（我指出去） |
| 度之和 | 无向图所有顶点度之和 = **2\|E\|**；有向图入度和 = 出度和 = \|E\| |
| 路径、回路 | 从一个点走到另一个点经过的顶点序列；起点终点相同叫回路（环） |
| 简单路径 | 顶点不重复的路径 |
| 连通图 | 无向图中任意两点都有路径相通 |
| 强连通图 | 有向图中任意两点**互相**可达 |
| 连通分量 | 无向图中的“极大连通子图”（一个个独立的小岛） |
| 生成树 | 包含全部 n 个顶点、只有 n−1 条边的连通子图（去掉一条边就不连通，加一条边就有环） |
| 完全图 | 任意两点都有边。无向完全图 n(n−1)/2 条边，有向完全图 n(n−1) 条 |
| 带权图（网） | 边上有数值（距离、费用） |

### 📖 边数与连通性（选择题）
- n 个顶点的无向图，要**连通**至少 n−1 条边
- n 个顶点的无向图，要**保证一定连通**（无论怎么连），至少需要 C(n−1, 2) + 1 条边（前 n−1 个点先两两连满，再加一条连到第 n 个点）
- n 个顶点的有向图要强连通，至少 n 条边（围成一个环）
- 边数 > n−1 的无向图**一定有环**

**真题（2022 年第 6 题）**：无向图 G=(V,E)，正确的是？
- A. |V| > |E| 时一定连通 ✗（点多边少，更可能不连通）
- B. |V| < |E| 时一定连通 ✗（边可能都挤在一堆点里）
- C. |V| = |E| − 1 时一定不连通 ✗
- D. **|V| > |E| + 1 时一定不连通** ✓（连通至少需要 |V| − 1 条边，现在 |E| < |V| − 1，不够）

**真题（2025 年第 6 题）**：正确的是？
- A. 有向图必存在入度为 0 的顶点 ✗（一个环里每个点入度都是 1）
- B. 有向无环图的拓扑序列存在且唯一 ✗（存在，但不一定唯一）
- C. **各顶点度都 ≥ 2 的无向图必有回路** ✓（一直往前走，不回头，点有限，总会走回走过的点）
- D. 可用 BFS 求带权图中每对顶点之间的最短路径 ✗（BFS 只能处理不带权/权值都相同的图）

## 2.12 图的存储（⭐）

### 📖 邻接矩阵
用一个 n×n 的表格：A[i][j] = 1 表示 i 到 j 有边（带权图就存权值，无边存 ∞）。
```
    A  B  C
A [ 0  1  1 ]
B [ 1  0  0 ]
C [ 1  0  0 ]
```
- 空间 O(n²)，适合**稠密图**
- 判断两点间有没有边：O(1)
- 无向图的矩阵是**对称**的，可以压缩存一半
- 第 i 行非零个数 = 顶点 i 的（出）度；第 i 列非零个数 = 入度
- 📌 **Aⁿ[i][j]** = 从 i 到 j 长度为 n 的路径条数

### 📖 邻接表
每个顶点挂一个链表，链表里放它的所有邻居。
```
A → B → C
B → A
C → A
```
- 空间 O(n + e)，适合**稀疏图**
- 无向图每条边存两次（2e 个边结点），有向图存 e 次
- 找某点的所有出边方便；找入边要遍历整个表（可以另建**逆邻接表**）
- 邻接表**不唯一**（链表里的顺序可以不同）

### 📖 十字链表和邻接多重表（了解）
- **十字链表**：存**有向图**，同时方便找出边和入边
- **邻接多重表**：存**无向图**，每条边只存一次

## 2.13 图的遍历：BFS 和 DFS（⭐⭐⭐）

### 🧒 大白话
- **BFS（广度优先）**：像**水波纹**一样一圈一圈往外扩。先访问离起点 1 步的所有点，再访问 2 步的……（用**队列**）
- **DFS（深度优先）**：像**走迷宫**，一条路走到黑，走不通了再退回上一个岔路口换路。（用**递归/栈**）

```
    1 — 2 — 5
    |   |
    3 — 4
    |
    6
```
从 1 出发（邻居按编号从小到大访问）：
- BFS：1, 2, 3, 4, 5, 6（第一圈 2、3；第二圈是 2 的邻居 4、5 和 3 的邻居 6）
- DFS：1 → 2 → 4 → 3 → 6（回退）→ 回到 2 → 5，得到 1, 2, 4, 3, 6, 5

### 📖 DFS 代码模板
```c
bool visited[MAXV];
void DFS(Graph G, int v) {
    visit(v);
    visited[v] = true;
    for (每个 v 的邻居 w)
        if (!visited[w])
            DFS(G, w);
}
void DFSTraverse(Graph G) {           // 图可能不连通，每个没访问过的点都要作为起点
    for (int v = 0; v < G.vexnum; v++) visited[v] = false;
    for (int v = 0; v < G.vexnum; v++)
        if (!visited[v]) DFS(G, v);    // 调用几次 DFS = 有几个连通分量
}
```

### 📖 复杂度
| 存储方式 | BFS / DFS 时间 |
|---|---|
| 邻接矩阵 | O(n²) |
| 邻接表 | O(n + e) |

空间都是 O(n)（队列或递归栈）。

### 📖 应用
- **BFS 求不带权图的单源最短路径**（第一次访问到某点时的层数就是最短距离）
- 判断连通性、求连通分量
- **DFS 判断有向图是否有环**；DFS 求拓扑序列

**真题（2020 年第 6 题）**：把 DFS 中“访问顶点”的语句挪到“递归返回前”，遍历有向无环图，输出的是？
🧒 这样一个点要等它**能到达的所有点**都输出后才输出，就是“后序 DFS”。在 DAG 里，谁排在后面谁先输出 → **逆拓扑有序序列**，选 B。

## 2.14 最小生成树（MST）

### 🧒 大白话
有 n 个村庄要修路，让所有村庄都连通，每条路有造价。怎么修**总造价最少**？答案就是最小生成树（n 个点、n−1 条边、总权值最小）。

### 📖 Prim 算法（“以点扩张”）
1. 从任意一个点开始，放进“已连通集合”
2. 每次从“集合内 → 集合外”的所有边里挑**最便宜**的一条，把那个外面的点拉进来
3. 重复直到所有点都进来

时间 O(n²)，适合**稠密图**。

### 📖 Kruskal 算法（“以边合并”）
1. 把所有边按权值从小到大排好
2. 从小到大挑边：如果这条边连接的两个点**还不连通**（不会形成环），就选它；否则跳过
3. 选够 n−1 条边为止

时间 O(e log e)，适合**稀疏图**。判断是否成环用**并查集**。

### ✏️ 例题
6 个村庄 A~F，可修的路和造价（无向图）：

| 边 | A-B | A-C | B-C | B-D | C-D | C-E | D-E | D-F | E-F |
|---|---|---|---|---|---|---|---|---|---|
| 权值 | 4 | 1 | 2 | 5 | 8 | 10 | 2 | 6 | 3 |

**Kruskal**：按权值排序：A-C(1), B-C(2), D-E(2), E-F(3), A-B(4), B-D(5), D-F(6), C-D(8), C-E(10)
- 选 A-C(1) ✓、B-C(2) ✓、D-E(2) ✓、E-F(3) ✓
- A-B(4)：A、B 已经通过 C 连通了，会成环 ✗
- B-D(5)：把 {A,B,C} 和 {D,E,F} 连起来 ✓ → 已经 5 条边，结束
- 总权值 1 + 2 + 2 + 3 + 5 = **13**

**Prim（从 A 开始）**：A → 选 A-C(1) → 选 C-B(2) → 选 B-D(5) → 选 D-E(2) → 选 E-F(3)，总权值也是 13。

> 📌 **MST 的性质**：
> - 各边权值**互不相同**时，MST **唯一**
> - 权值有相同的，MST 可能不唯一，但**总权值唯一**
> - 考题常问“Kruskal/Prim 依次选的边是什么” → 老老实实模拟

## 2.15 最短路径

### 📖 Dijkstra（单源最短路，⭐⭐）

🧒 **大白话**：从家出发去各个地方。我先确定“离家**最近**的地方”，它的最短距离一定已经确定了（因为绕别的路只会更远）。然后看看**经过这个地方**，能不能让去其他地方的路变短。重复。

**步骤：**
1. dist[起点] = 0，其他 = 起点直达的距离（没有直达就是 ∞）
2. 在还没确定的顶点里，选 dist **最小**的 u，标记为“已确定”
3. 用 u 更新：对 u 的每个邻居 v，若 dist[u] + w(u,v) < dist[v]，就更新 dist[v]
4. 重复 2、3

✏️ **例题**：有向图，从顶点 1 出发。边：1→2(10)、1→4(5)、2→3(1)、2→4(2)、4→2(3)、4→3(9)、4→5(2)、3→5(4)、5→3(6)、5→1(7)

| 轮次 | 选中 | dist[2] | dist[3] | dist[4] | dist[5] |
|---|---|---|---|---|---|
| 初始 | 1 | 10 | ∞ | **5** | ∞ |
| 1 | 4 (5) | 8 | 14 | ✓5 | **7** |
| 2 | 5 (7) | **8** | 13 | ✓ | ✓7 |
| 3 | 2 (8) | ✓8 | **9** | ✓ | ✓ |
| 4 | 3 (9) | ✓ | ✓9 | ✓ | ✓ |

最终：到 2 是 8，到 3 是 9，到 4 是 5，到 5 是 7。
（解释：第 1 轮选 4 后，经过 4 到 2 = 5+3 = 8 < 10，更新；到 3 = 5+9 = 14；到 5 = 5+2 = 7。）

> ⚠️ **Dijkstra 不能处理负权边！**（已确定的点可能被后来的负边“变得更短”）
> 时间复杂度 O(n²)。

### 📖 Floyd（所有点对之间的最短路）
🧒 大白话：依次让每个顶点 k 当“中转站”，看看 i → k → j 是否比 i → j 更近。
```c
for (k = 0; k < n; k++)          // 中转点放最外层！
    for (i = 0; i < n; i++)
        for (j = 0; j < n; j++)
            if (A[i][k] + A[k][j] < A[i][j])
                A[i][j] = A[i][k] + A[k][j];
```
- 时间 O(n³)
- **可以有负权边，但不能有负权回路**

### 📊 三种最短路算法比较
| | BFS | Dijkstra | Floyd |
|---|---|---|---|
| 解决 | 单源，无权图 | 单源，带权图 | 所有点对 |
| 负权边 | — | ✗ | ✓（无负环） |
| 时间 | O(n+e) 或 O(n²) | O(n²) | O(n³) |

## 2.16 拓扑排序（有向无环图 DAG）

### 🧒 大白话
大学选课：学《数据结构》前必须先学《C 语言》。把所有课排个顺序，保证**每门课的先修课都排在它前面**——这就是拓扑排序。

**AOV 网**：用顶点表示活动，用有向边表示“谁必须在谁之前”。

### 📖 方法
1. 找一个**入度为 0** 的顶点（没有先修课的课），输出它
2. 删掉它和它发出的所有边（它的后续课的入度 −1）
3. 重复，直到所有点都输出；如果中途找不到入度为 0 的点 → 说明**有环**

- 每一步如果有多个入度为 0 的点可以选 → 拓扑序列**不唯一**
- 用邻接表时间 O(n + e)，邻接矩阵 O(n²)
- 也可以用 DFS：按 DFS **结束时间从大到小**排列（逆后序）

> 📌 若邻接矩阵是**三角矩阵**（对角线以下全 0），则图无环，拓扑序列存在。

## 2.17 关键路径（AOE 网，⭐⭐ 2025 年 42 题大题！）

### 🧒 大白话
装修房子：刷墙 3 天、铺地板 2 天、买家具 1 天……有些活可以**同时干**，有些必须**等前面干完**。
问：整个装修**最快多少天完工**？哪些活**一天都不能拖**？

**AOE 网**：**边**表示活动（带持续时间），**顶点**表示事件（“某些活都干完了”这个时刻）。
- 只有一个入度为 0 的**源点**（开工），一个出度为 0 的**汇点**（完工）
- **关键路径**：从源点到汇点**路径长度最长**的那条路（最长的那条链决定了工期！）
- **关键活动**：关键路径上的活动，拖延一天整个工期就拖延一天

### 📖 四个量（⭐ 必须会算）

| 符号 | 含义 | 怎么算 |
|---|---|---|
| ve(k) | 事件 k **最早**发生时间 | 从前往后，**取最大**：ve(k) = max{ve(j) + 活动时间}，ve(源点) = 0 |
| vl(k) | 事件 k **最迟**发生时间 | 从后往前，**取最小**：vl(j) = min{vl(k) − 活动时间}，vl(汇点) = ve(汇点) |
| e(i) | 活动 i **最早**开始时间 | = 该活动**起点**事件的 ve |
| l(i) | 活动 i **最迟**开始时间 | = 该活动**终点**事件的 vl − 活动时间 |

**时间余量 d(i) = l(i) − e(i)**：这个活动能“摸鱼”几天。**d = 0 的就是关键活动**。

🧒 为什么 ve 取最大？因为一个事件要等**所有**前面的活动都完成才能发生，得等最慢的那个。
为什么 vl 取最小？因为要保证**所有**后续活动都来得及，得照顾最紧的那个。

### ✏️ 例题
```
活动:  a1: V1→V2 (3)    a2: V1→V3 (2)
       a3: V2→V4 (2)    a4: V2→V5 (3)
       a5: V3→V4 (4)    a6: V3→V6 (3)
       a7: V4→V6 (2)    a8: V5→V6 (1)
```

**第 1 步：从前往后算 ve（取最大）**
| 事件 | V1 | V2 | V3 | V4 | V5 | V6 |
|---|---|---|---|---|---|---|
| ve | 0 | 3 | 2 | max(3+2, 2+4)=**6** | 3+3=6 | max(6+2, 6+1, 2+3)=**8** |

**第 2 步：从后往前算 vl（取最小）**
| 事件 | V6 | V5 | V4 | V3 | V2 | V1 |
|---|---|---|---|---|---|---|
| vl | 8 | 8−1=7 | 8−2=6 | min(6−4, 8−3)=**2** | min(6−2, 7−3)=**4** | min(4−3, 2−2)=**0** |

**第 3 步：算每个活动的 e、l、d**
| 活动 | a1 | a2 | a3 | a4 | a5 | a6 | a7 | a8 |
|---|---|---|---|---|---|---|---|---|
| e = ve(起点) | 0 | 0 | 3 | 3 | 2 | 2 | 6 | 6 |
| l = vl(终点) − 时间 | 1 | **0** | 4 | 4 | **2** | 5 | **6** | 7 |
| d = l − e | 1 | **0** | 1 | 1 | **0** | 3 | **0** | 1 |

**结论**：关键活动 a2、a5、a7，关键路径 V1 → V3 → V4 → V6，工期 **8**。时间余量最大的是 a6（余量 3）。

### 📖 重要结论（⭐ 选择题）
**真题（2020 年第 8 题）**：
- A. 关键路径是边数最多的路径 ✗（是**长度**最长，不是边数最多）
- B. **关键路径是从源点到汇点路径长度最长的路径** ✓
- C. 增加任一关键活动的时间不会延长工期 ✗（会延长）
- D. 缩短任一关键活动的时间一定缩短工期 ✗（如果有**多条**关键路径，只缩短其中一条上的活动没用；缩太多也可能让它不再是关键活动）

> 🎯 **2025 年 42 题**考法预览：求最短工期和关键活动；和某活动**可能同时进行**的活动（时间区间有重叠的）；时间余量最大的活动；某活动推迟开始后，它最多还能持续多久（= 余量允许的范围）；压缩哪个活动能保证不延期。**把上面四张表算熟，这道 10 分题就是送分题。**

| 图的存储 | 矩阵 O(n²) 稠密；邻接表 O(n+e) 稀疏 |
| BFS/DFS | 队列 / 栈；矩阵 O(n²)，邻接表 O(n+e) |
| MST | Prim 加点 O(n²)；Kruskal 加边 O(e log e) |
| 最短路 | Dijkstra 不能负权 O(n²)；Floyd O(n³) |
| 拓扑排序 | 反复删入度为 0 的点 |
| 关键路径 | ve 前推取大，vl 后推取小，d = l − e = 0 为关键 |

## 2.19 课后练习

1. 一棵二叉树有 20 个叶子、10 个度为 1 的结点，总共多少个结点？
2. 后序 `D E B F C A`，中序 `D B E A C F`，求先序。
3. 将 `3, 1, 4, 5, 9, 2, 6` 依次插入空 AVL 树，画出最终结果。
4. 高度为 5 的 AVL 树最少有几个结点？

<details>
<summary>答案</summary>

1. n₂ = 19，n = 20 + 10 + 19 = 49
2. `A B D E C F`
3. 插 3、1、4、5 都不失衡；插 9 时结点 4 失衡（RR 型）→ 5 上位，4、9 成为 5 的孩子；插 2（挂在 1 的右边）不失衡；插 6（挂在 9 的左边）：检查 5 的平衡因子 −1、3 的平衡因子 −1（左高 2、右高 3），都不失衡。最终：根 3；左孩子 1（1 的右孩子 2）；右孩子 5（5 的左孩子 4，右孩子 9，9 的左孩子 6）。
4. n₅ = 12
